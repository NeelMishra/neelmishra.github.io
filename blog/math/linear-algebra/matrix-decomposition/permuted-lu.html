    Permuted LU: swap the zero pivot, then solve

    October 2026 · 11 min read

    Before you start: Gaussian elimination, and what a multiplier is. The Cholesky note used an LU factorization that never swapped rows. This one has to.

    This is video 7 of the Matrix Decompositions playlist, Permuted LU Decomposition Example by FiveMinuteLectures (7 June 2025, 4 minutes 47 seconds). A zero pivot is removed by a row swap. The same swap is recorded in a permutation matrix \(P\), and the factorization is \(PA=LU\). The upload points ahead to Cholesky, already written here, and points back to an LU solve that is still later in this playlist. The triangular solve is written out below.

    A zero in the pivot

    Ordinary elimination divides by the pivot. If that entry is \(0\), the multiplier is not defined, and nothing below it can be cleared. The opening picture is

    $$\begin{bmatrix}0&0&-4\\1&2&3\\1&0&2\end{bmatrix}.$$

    The \((1,1)\) entry is \(0\). The first nonzero row below it is row 2, so the lecture swaps those two rows and gets

    $$\begin{bmatrix}1&2&3\\0&0&-4\\1&0&2\end{bmatrix}.$$

    That is the whole of the picture. It does not finish \(L\), \(U\), and \(P\) for this matrix. The swap is with the first nonzero row below the pivot, not with the largest entry in the column.

    The footnote says this is only for square nonsingular matrices. Nonsingular is what makes a swap available: some entry in the active column has to be nonzero, or no row exchange produces a pivot, and the matrix is singular. This opening matrix is nonsingular. Expanding along the first row,

    $$\det= (-4)\cdot(1\cdot 0-2\cdot 1)=(-4)(-2)=8.$$

    A zero pivot and a nonzero determinant can sit in the same matrix. That is the case the permutation is for.

    The system

    The worked example is

    $$x_1+2x_2+x_3=2,\qquad 2x_1+4x_2+x_3=7,\qquad x_2=2.$$

    In matrix form,

    $$A=\begin{bmatrix}1&2&1\\2&4&1\\0&1&0\end{bmatrix},\qquad b=\begin{bmatrix}2\\7\\2\end{bmatrix},\qquad Ax=b.$$

    The first pivot is \(1\), so column 1 does not need a swap. The trouble shows up at the second pivot.

    Four steps, and the wrong right-hand side

    The procedure slide is: eliminate \(A\), store the negatives of the constants used in the row operations in \(L\), and store each row swap in \(P\). Then multiply \(Ax=b\) on the left by \(P\), replace \(PA\) by \(LU\), and solve the triangular systems. The later slide writes the replacement correctly:

    $$PA=LU,\qquad PAx=Pb,\qquad LUx=Pb.$$

    Step 4a says to begin by solving \(Ly=b\). The boxed equation is \(LUx=Pb\), so the right-hand side of the first triangular system is \(Pb\), not \(b\). The two disagree. The solve below uses \(Pb\). Using \(b\) produces a vector that does not satisfy \(Ax=b\).

    First column

    \(U\) starts as \(A\). \(L\) starts with \(1\)s on the diagonal and blanks below. \(P\) starts as \(I\). The lecture multiplies row 1 by \(-2\) and adds it to row 2:

    $$\begin{bmatrix}2&4&1\end{bmatrix}+(-2)\begin{bmatrix}1&2&1\end{bmatrix}=\begin{bmatrix}0&0&-1\end{bmatrix}.$$

    The constant in that operation is \(-2\). \(L\) stores its negative, so \(L_{21}=2\). That is the same \(2\) you would subtract: row 2 minus \(2\) times row 1 is the same calculation. The \((3,1)\) entry is already \(0\), so no operation is needed there, and \(L_{31}=0\). \(P\) is unchanged, because no rows moved. After this column,

    $$U=\begin{bmatrix}1&2&1\\0&0&-1\\0&1&0\end{bmatrix},\qquad L=\begin{bmatrix}1&0&0\\2&1&0\\0&&1\end{bmatrix},\qquad P=I.$$

    The blank in \(L\) is the multiplier that has not been chosen yet. The \((2,2)\) entry of \(U\) is \(0\). Dividing by it is the same failure as in the opening picture.

    Swap rows 2 and 3

    The lecture swaps row 2 with row 3, the only row below the current pivot. It does not swap with row 1. That row already has its zeros, and a swap with it would put them back under the first pivot. After the swap,

    $$U=\begin{bmatrix}1&2&1\\0&1&0\\0&0&-1\end{bmatrix}.$$

    The new pivot is \(1\). The same two rows of \(P\) are swapped, which is how a swap is recorded: do to \(I\) whatever was done to \(U\).

    $$P=\begin{bmatrix}1&0&0\\0&0&1\\0&1&0\end{bmatrix}.$$

    \(L\) is not swapped as a pair of whole rows. The lecture swaps only \(L_{21}\) with \(L_{31}\), the multipliers already stored in column 1. The \(1\)s on the diagonal stay where they are. Swapping the whole rows would move a \(1\) off the diagonal and leave the unit pattern broken. After that exchange, and after writing the last multiplier,

    $$L=\begin{bmatrix}1&0&0\\0&1&0\\2&0&1\end{bmatrix}.$$

    The \(0\) in \(L_{32}\) is the entry under the new pivot. That entry of \(U\) is already \(0\), so there is nothing to eliminate. The three factors on the settled slide are these \(L\), \(U\), and \(P\).

    Check \(PA=LU\)

    \(P\) swaps rows 2 and 3, so \(PA\) is \(A\) with those rows exchanged:

    $$PA=\begin{bmatrix}1&2&1\\0&1&0\\2&4&1\end{bmatrix}.$$

    Row 3 of \(LU\) is \(2\) times row 1 of \(U\), plus row 3 of \(U\):

    $$2\begin{bmatrix}1&2&1\end{bmatrix}+\begin{bmatrix}0&0&-1\end{bmatrix}=\begin{bmatrix}2&4&1\end{bmatrix}.$$

    Rows 1 and 2 of \(L\) just copy rows 1 and 2 of \(U\). The product is \(PA\). This \(P\) is a single transposition, so \(P^2=I\) and \(P^{-1}=P\). Multiplying \(PA=LU\) on the left by \(P\) gives \(A=PLU\) as well. The lecture writes \(PA=LU\).

    The same determinant check uses both factorizations. \(\det L=1\) and \(\det U=-1\), so \(\det(PA)=-1\). One transposition has determinant \(-1\), so \(\det A=1\). Expanding along the first row,

    $$\det A=1\cdot(0-1)-2\cdot(0-0)+1\cdot(2-0)=-1+2=1.$$

    Solve \(LUx=Pb\)

    The lecture stops at the boxed equation and leaves the triangular solve to the LU video. Set \(y=Ux\), so the two systems are \(Ly=Pb\) and \(Ux=y\). First apply \(P\) to \(b\). The same row swap sends \(7\) to the bottom and \(2\) to the middle:

    $$Pb=\begin{bmatrix}2\\2\\7\end{bmatrix}.$$

    Forward substitution in \(Ly=Pb\). The first two rows of \(L\) are unit rows, so \(y_1=2\) and \(y_2=2\). The third row is \(2y_1+y_3=7\), hence \(y_3=3\).

    $$y=\begin{bmatrix}2\\2\\3\end{bmatrix}.$$

    Back substitution in \(Ux=y\). The last row is \(-x_3=3\), so \(x_3=-3\). The middle row is \(x_2=2\). The first row is \(x_1+2x_2+x_3=2\):

    $$x_1+4-3=2,\qquad x_1=1,\qquad x=\begin{bmatrix}1\\2\\-3\end{bmatrix}.$$

    That satisfies the original three equations: \(1+4-3=2\), \(2+8-3=7\), and \(x_2=2\).

    A = [[1, 2, 1], [2, 4, 1], [0, 1, 0]]
x = [1, 2, -3]
Ax = [sum(A[i][k] * x[k] for k in range(3)) for i in range(3)]
assert Ax == [2, 7, 2]

    What \(Ly=b\) produces

    If the right-hand side is the original \(b=(2,7,2)\), the same \(L\) gives \(y=(2,7,-2)\). Then \(Ux=y\) gives \(x_3=2\), \(x_2=7\), and \(x_1+14+2=2\), so \(x_1=-14\). The vector is \((-14,7,2)\). Multiplying by \(A\) returns \((2,2,7)\), which is \(Pb\), not \(b\). The step list solved the permuted system and treated the answer as if the rows of \(b\) had not moved.

    Checks

    Why does a zero in position \((1,1)\) not by itself make the matrix singular?

    The opening matrix has determinant \(8\). Singular means every candidate pivot in the active column is zero, so no swap can create one.

    Why is \(2\) stored in \(L\), when the row operation used \(-2\)?

    The operation was "add \(-2\) times row 1." \(L\) stores the negative of that constant, which is the multiplier in "subtract \(2\) times row 1." Both descriptions give the row \((0,0,-1)\).

    Why swap only \(L_{21}\) with \(L_{31}\), not the whole rows?

    Those are the multipliers already stored. The diagonal \(1\)s have to stay on the diagonal. A whole-row swap would move one of them.

    The step list says \(Ly=b\). Which right-hand side solves \(Ax=b\)?

    \(Pb=(2,2,7)\). With that vector, \(x=(1,2,-3)\). With \(b\), the computed \(x=(-14,7,2)\) satisfies \(Ax=Pb\) instead.

    Why not swap row 2 with row 1 when the second pivot is zero?

    Row 1 has already been used to clear column 1. Swapping it back down would put a nonzero under the first pivot.
