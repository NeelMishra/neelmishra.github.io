Tree Attention Masks, RoPE Depth Offsets, and Multi-Path Verification

When a drafter proposes multiple branching continuations rather than a single linear chain, how do we verify every branch in one target forward pass without cross-branch contamination? We derive topological tree packing, 2D ancestor attention masks, shared-depth RoPE position IDs, and SpecInfer's lossless multi-path recursive rejection sampling.

1. Why Candidate Trees Beat Linear Chains

In standard linear speculative decoding (Chapter 1.3), the draft model commits to a single path of length $\gamma$: $(x_1, x_2, \dots, x_\gamma)$. If the target distribution $p(\cdot \mid x_{\le t})$ has high entropy at step $1$—for instance, after the prompt "The capital of South Africa is" where "Pretoria", "Cape", and "Bloemfontein" all carry substantial probability—any single draft choice $x_1$ has a high chance of rejection. And the moment $x_1$ is rejected, the remaining $\gamma - 1$ draft tokens $(x_2, \dots, x_\gamma)$ are discarded unread.

Yet recall from the GPU Roofline analysis in Chapter 1.1 that at small batch sizes ($B = 1\text{--}4$), a single target forward pass is overwhelmingly memory-bandwidth bound by streaming the model weights $W_{\text{target}}$ from HBM into SRAM. Evaluating $M = 16$ or $M = 32$ candidate tokens in a single forward pass costs nearly the same wall-clock latency as evaluating $\gamma = 4$ tokens along a single chain!

SpecInfer (Miao et al., 2024), Medusa (Chapter 2.1), and EAGLE-2/3 (Chapter 2.2) exploit this excess arithmetic headroom by organizing candidate tokens into a rooted token tree $\mathcal{T} = (V, E)$:

  • The root node $u_0$ is the last verified token $x_t$ from the prefix $x_{1:t}$.
  • Each interior or leaf node $u_i \in V \setminus \{u_0\}$ ($i = 1, \dots, M-1$) represents a candidate token at depth $d(u_i) \ge 1$ conditioned on the unique ancestor path $\operatorname{Path}(u_0 \to u_i)$ from the root.
  • Instead of replicating the prefix KV cache $x_{1:t-1}$ across $B_{\text{branches}}$ separate batch rows—which would multiply KV-cache memory bandwidth by $B_{\text{branches}}$—Tree Attention packs all $M$ nodes of $\mathcal{T}$ into a single sequence of length $M$ and verifies the entire tree in one forward pass.

2. Topological Tree Packing and RoPE Depth Offsets

To feed a 2D tree $\mathcal{T}$ into a standard Transformer decoder layer that expects a 1D tensor of shape $[B, M, d_{\text{model}}]$, we must solve two structural problems: how to order the nodes in 1D, and what positional indices to pass to Rotary Position Embeddings (RoPE).

2.1 Topological (Breadth-First or Depth-First) Ordering

We flatten the nodes of $\mathcal{T}$ into a 1D array $\mathbf{u} = [u_0, u_1, \dots, u_{M-1}]$ using any topological sort (typically Breadth-First Search order by depth) such that every parent node appears strictly to the left of all of its descendants:

$$\forall (u_i, u_j) \in E: \quad u_i = \operatorname{parent}(u_j) \implies i < j$$

Why is $i < j$ important? Because hardware-optimized attention kernels (such as FlashAttention with block-sparse masks) skip all tiles strictly above the main diagonal ($j > i$). By guaranteeing that ancestors always have smaller 1D array indices than their descendants ($j \le i$), our tree attention mask remains strictly lower-triangular—meaning we never have to attend "into the future" of the packed 1D buffer.

2.2 Depth-Matched RoPE Position IDs

In a standard linear sequence, token at 1D buffer index $i$ receives position ID $L_{\text{prefix}} + i$, where $L_{\text{prefix}} = t - 1$ is the number of already-cached prefix tokens. In a packed candidate tree, however, sibling nodes at the same tree depth $d$ represent alternative hypotheses for the exact same sequence position!

If we mistakenly assigned standard sequential position IDs $L_{\text{prefix}} + i$ to the packed tree, the second sibling at depth $1$ would receive position ID $L_{\text{prefix}} + 2$ instead of $L_{\text{prefix}} + 1$, corrupting its RoPE rotation angle $\theta_k \cdot \text{pos}$ and violating lossless verification. Instead, every node $u_i \in \mathcal{T}$ is assigned a position ID equal to the prefix length plus its tree depth $d(u_i)$:

$$\operatorname{pos}(u_i) = L_{\text{prefix}} + \operatorname{depth}(u_i), \qquad \operatorname{depth}(u_0) = 0$$

For example, in the 5-node tree of Figure 1 where root $u_0 = x_t$ sits at index $L_{\text{prefix}} = 10$:

  • Index $i = 0$ (Root $u_0$): $\operatorname{depth}(u_0) = 0 \implies \operatorname{pos}(u_0) = 10$.
  • Indices $i = 1, 2$ (Siblings $u_1, u_2$ at Depth 1): $\operatorname{depth}(u_1) = \operatorname{depth}(u_2) = 1 \implies \operatorname{pos}(u_1) = \operatorname{pos}(u_2) = 11$.
  • Indices $i = 3, 4$ (Nodes $u_3, u_4$ at Depth 2): $\operatorname{depth}(u_3) = \operatorname{depth}(u_4) = 2 \implies \operatorname{pos}(u_3) = \operatorname{pos}(u_4) = 12$.

3. Constructing the 2D Non-Causal Ancestor Attention Mask

Once the $M$ tree nodes are packed into $\mathbf{u} = [u_0, \dots, u_{M-1}]$ and rotated by their depth-matched RoPE embeddings, we must ensure that when the target model computes the hidden state at node $u_i$, its query vector $\mathbf{q}_i$ attends only to:

  1. All $L_{\text{prefix}}$ tokens in the shared prefix KV cache, and
  2. The nodes in $\mathcal{T}$ that lie on the unique ancestor path from the root $u_0$ to $u_i$ (inclusive).

Formally, let $\operatorname{Anc}(u_i) \subseteq V$ denote the set of ancestors of $u_i$ in $\mathcal{T}$ (including $u_i$ itself). The additive attention mask $M^{\text{tree}} \in \{0, -\infty\}^{M \times M}$ over the $M$ packed tree tokens is defined entrywise for query row $i \in \{0, \dots, M-1\}$ and key column $j \in \{0, \dots, M-1\}$ as:

$$M^{\text{tree}}_{i,j} = \begin{cases} 0 & \text{if } u_j \in \operatorname{Anc}(u_i) \\ -\infty & \text{otherwise} \end{cases}$$

Concatenated with the all-zero prefix mask $\mathbf{0}_{M \times L_{\text{prefix}}}$ for the shared prefix KV cache, the full attention score matrix before softmax has shape $M \times (L_{\text{prefix}} + M)$:

$$S_{i, k} = \frac{\mathbf{q}_i \mathbf{k}_k^\top}{\sqrt{d_k}} + M^{\text{full}}_{i, k}, \qquad M^{\text{full}} = \left[\, \mathbf{0}_{M \times L_{\text{prefix}}} \;\middle|\; M^{\text{tree}}_{M \times M} \,\right]$$

4. Lossless Multi-Path Recursive Rejection Sampling (SpecInfer)

After the target model completes its single tree-attention forward pass, we have a target next-token distribution $p(\cdot \mid \operatorname{Path}(u_0 \to u_i))$ at every node $u_i \in \mathcal{T}$. How do we verify a tree of candidates while guaranteeing that the accepted path is distributed identically to standard autoregressive sampling from the target model $p$?

4.1 Greedy Decoding ($T = 0$) on a Tree

When decoding greedily ($T = 0$), verification is a deterministic top-down walk starting at the root $u_{\text{curr}} = u_0$:

  1. Compute the greedy target token at the current node: $t^* = \arg\max_{v \in \mathcal{V}} p(v \mid \operatorname{Path}(u_0 \to u_{\text{curr}}))$.
  2. Check whether any child $c \in \operatorname{Children}(u_{\text{curr}})$ has token label $\operatorname{token}(c) = t^*$.
  3. If a matching child $c^*$ exists, accept $t^*$, advance $u_{\text{curr}} \leftarrow c^*$, and repeat for the next depth level.
  4. If no child matches $t^*$ (or $u_{\text{curr}}$ is a leaf), emit $t^*$ as the bonus token and terminate the step.

4.2 Stochastic Sampling ($T > 0$): Multi-Round Residual Rejection Sampling

When sampling stochastically ($T > 0$), simply testing $K$ sibling branches independently against the original target distribution $p^{(0)}(\cdot) = p(\cdot \mid \operatorname{Path}(u_0 \to u_{\text{curr}}))$ would bias the output distribution toward tokens covered by multiple draft branches. Instead, SpecInfer (Miao et al., 2024) generalizes modified rejection sampling (Chapter 1.3) to $K$ sibling candidates $c_1, \dots, c_K \in \operatorname{Children}(u_{\text{curr}})$ with draft distributions $q^{(1)}, \dots, q^{(K)}$ via sequential residual updates:

$$\begin{aligned} \text{Initialize:} \quad & p^{(0)}(v) = p\big(v \;\big|\; \operatorname{Path}(u_0 \to u_{\text{curr}})\big) \\[6pt] \text{For sibling } b = 1, \dots, K: \quad & x^{(b)} = \operatorname{token}(c_b) \sim q^{(b)}(\cdot), \quad r_b \sim \operatorname{Uniform}(0, 1) \\[4pt] & \text{If } r_b \le \frac{p^{(b-1)}(x^{(b)})}{q^{(b)}(x^{(b)})}: \quad \textbf{Accept } c_b, \text{ set } u_{\text{curr}} \leftarrow c_b, \text{ descend to next depth!} \\[6pt] & \text{Else (Reject } c_b\text{): update residual target distribution } p^{(b)} \text{ via} \\[4pt] & p^{(b)}(v) = \frac{\max\!\big(0,\; p^{(b-1)}(v) - q^{(b)}(v)\big)}{\sum_{v' \in \mathcal{V}} \max\!\big(0,\; p^{(b-1)}(v') - q^{(b)}(v')\big)} \end{aligned}$$

If all $K$ sibling branches at $u_{\text{curr}}$ are rejected, we draw the bonus/correction token directly from the final residual distribution $x_{\text{bonus}} \sim p^{(K)}(\cdot)$ and terminate the verification step.

Why Sampling Without Replacement Works with a Single Draft Distribution

When a single drafter (such as EAGLE or Medusa) proposes top-$K$ sibling tokens at a node by sampling without replacement from a single draft distribution $q$, we can model each draw $b \in \{1, \dots, K\}$ as sampling from the renormalized remaining draft distribution:

$$q^{(b)}(v) = \begin{cases} \dfrac{q(v)}{1 - \sum_{m=1}^{b-1} q(x^{(m)})} & \text{if } v \notin \{x^{(1)}, \dots, x^{(b-1)}\} \\ 0 & \text{otherwise} \end{cases}$$

By induction on $b = 1, \dots, K$ (applying the single-step proof from Chapter 1.3 at each round), after testing $b$ siblings, the combined law of accepting one of $\{c_1, \dots, c_K\}$ or drawing from $p^{(K)}$ is exactly $p^{(0)}(v)$ for every $v \in \mathcal{V}$. Furthermore, because each rejected sibling $c_b$ carves out overlap mass $\sum_v \min(p^{(b-1)}(v), q^{(b)}(v))$, the cumulative acceptance probability at depth $d$ strictly increases with the branching factor $K$.

5. Worked Numerical Trace: 5-Node Candidate Tree

Suppose our toy vocabulary is $\mathcal{V} = \{\text{A}, \text{B}, \text{C}, \text{D}\}$ and we verify the 5-node tree from Figure 1:

  • Root $u_0$: prefix token $x_t$.
  • Depth 1 siblings under $u_0$: $u_1$ proposes token $\text{A}$ (drawn from $q^{(1)}$) and $u_2$ proposes token $\text{B}$ (drawn from $q^{(2)}$).
  • Depth 2 children: $u_3$ under $u_1$ proposes token $\text{C}$, and $u_4$ under $u_2$ proposes token $\text{D}$.

Let us trace the multi-path verification at Depth 1 under $u_0$:

Quantity / Step Token $\text{A}$ Token $\text{B}$ Token $\text{C}$ Token $\text{D}$ Decision & Action
Initial Target $p^{(0)}(v \mid u_0)$ $0.20$ $0.50$ $0.20$ $0.10$ Computed by row $0$ of tree attention
Sibling 1 Draft $q^{(1)}(v)$ ($x^{(1)} = \text{A}$) $0.50$ $0.30$ $0.10$ $0.10$ Ratio $\frac{p^{(0)}(\text{A})}{q^{(1)}(\text{A})} = \frac{0.20}{0.50} = 0.40$. Draw $r_1 = 0.65 > 0.40 \implies$ Reject $u_1$ (prune subtree $u_3$).
Unnormalized $[p^{(0)}(v) - q^{(1)}(v)]_+$ $0.00$ $0.20$ $0.10$ $0.00$ Sum of positive residuals $= 0.20 + 0.10 = 0.30$
Residual Target $p^{(1)}(v \mid u_0)$ $0.00$ $0.667$ $0.333$ $0.00$ Notice $\text{B}$'s target mass rose from $0.50$ to $0.667$!
Sibling 2 Draft $q^{(2)}(v)$ ($x^{(2)} = \text{B}$) $0.00$ $0.60$ $0.20$ $0.20$ Ratio $\min\!\big(1, \frac{p^{(1)}(\text{B})}{q^{(2)}(\text{B})}\big) = \min\!\big(1, \frac{0.667}{0.60}\big) = 1.00 \implies$ Accept $u_2$ ($\text{B}$)!

Look closely at what happened: in standard single-path speculative decoding, rejecting the first draft choice $u_1 = \text{A}$ would have immediately terminated the step. With multi-path tree verification, rejecting $u_1 = \text{A}$ updated the target distribution to $p^{(1)}$ and allowed us to test sibling $u_2 = \text{B}$, which was accepted with probability $1.0$! Next, verification descends to $u_2$ (whose target logits $p(\cdot \mid u_0, u_2)$ are already waiting in row $2$ of our single tree-attention pass) and tests its child $u_4 = \text{D}$, accepting $\text{D}$ plus a bonus token from row $4$ if $u_4$ also passes.

6. Reference PyTorch Implementation

Below is a self-contained PyTorch implementation demonstrating how to build the 2D ancestor mask $M^{\text{tree}}$ and RoPE depth offsets from a parent-pointer array, followed by SpecInfer's lossless multi-path recursive rejection sampler: 

import torch
import torch.nn.functional as F
from typing import List, Tuple

def build_tree_mask_and_positions(
    parents: List[int],
    prefix_len: int,
    device: torch.device = torch.device("cpu"),
) -> Tuple[torch.Tensor, torch.Tensor]:
    """
    Constructs the 2D additive tree attention mask and RoPE position IDs
    from a topologically sorted parent-pointer array.

    Args:
        parents: Length-M list where parents[i] is the 1D index of u_i's parent
                 in the tree (parents[0] == -1 for the root u_0, and parents[i] < i).
        prefix_len: Number of already-cached prefix tokens before the root u_0.
    Returns:
        full_mask: [1, 1, M, prefix_len + M] additive float mask (0.0 or -inf).
        position_ids: [1, M] long tensor of depth-matched RoPE position IDs.
    """
    M = len(parents)
    depths = [0] * M
    # Bool ancestor matrix: anc[i, j] == True iff u_j is an ancestor of u_i
    anc = torch.zeros((M, M), dtype=torch.bool, device=device)

    for i in range(M):
        anc[i, i] = True
        p = parents[i]
        if p >= 0:
            assert p < i, "Tree nodes must be topologically sorted (parent < child)."
            depths[i] = depths[p] + 1
            anc[i] |= anc[p]  # Inherit all ancestors of parent p

    # Convert boolean ancestor matrix into additive mask in {0.0, -inf}
    tree_mask = torch.full((M, M), float("-inf"), device=device)
    tree_mask.masked_fill_(anc, 0.0)

    # All tree nodes attend freely to the shared prefix KV cache
    prefix_mask = torch.zeros((M, prefix_len), device=device)
    full_mask = torch.cat([prefix_mask, tree_mask], dim=-1).unsqueeze(0).unsqueeze(0)

    position_ids = torch.tensor(
        [prefix_len + d for d in depths], dtype=torch.long, device=device
    ).unsqueeze(0)
    return full_mask, position_ids


def verify_candidate_tree(
    parents: List[int],
    node_tokens: List[int],
    draft_probs: torch.Tensor,   # [M, V]: q^{(b)} distribution used to sample node i
    target_probs: torch.Tensor,  # [M, V]: p(. | Path(u_0 -> u_i)) from tree attention
) -> Tuple[List[int], List[int]]:
    """
    Lossless multi-path recursive rejection sampling over a candidate tree.

    Returns:
        accepted_tokens: Sequence of accepted draft tokens + 1 final bonus token.
        accepted_node_indices: 1D tree indices along the accepted path (for KV compaction).
    """
    M, V = target_probs.shape
    children_map = {i: [] for i in range(M)}
    for idx, p in enumerate(parents):
        if p >= 0:
            children_map[p].append(idx)

    accepted_tokens: List[int] = []
    accepted_node_indices: List[int] = [0]  # Always starts at root u_0
    curr_node = 0

    while True:
        p_res = target_probs[curr_node].clone()
        siblings = children_map[curr_node]
        matched_child = None

        for child_idx in siblings:
            cand_token = node_tokens[child_idx]
            q_dist = draft_probs[child_idx]

            p_val = p_res[cand_token].item()
            q_val = max(q_dist[cand_token].item(), 1e-12)
            r = torch.rand(1).item()

            if r <= (p_val / q_val):
                # Sibling accepted! Advance down this branch
                accepted_tokens.append(cand_token)
                accepted_node_indices.append(child_idx)
                matched_child = child_idx
                break
            else:
                # Sibling rejected: update residual target distribution p^{(b)}
                p_res = torch.clamp(p_res - q_dist, min=0.0)
                mass = p_res.sum()
                if mass > 1e-12:
                    p_res = p_res / mass
                else:
                    p_res = target_probs[curr_node].clone()
                    break

        if matched_child is not None:
            curr_node = matched_child
        else:
            # Either curr_node is a leaf or all siblings were rejected:
            # sample bonus/correction token from the residual distribution p_res
            bonus_token = torch.multinomial(p_res, num_samples=1).item()
            accepted_tokens.append(bonus_token)
            break

    return accepted_tokens, accepted_node_indices


if __name__ == "__main__":
    # 5-node tree from Figure 1: u_0 (root), u_1 & u_2 (depth 1), u_3 (under u_1), u_4 (under u_2)
    parents = [-1, 0, 0, 1, 2]
    mask, pos_ids = build_tree_mask_and_positions(parents, prefix_len=10)
    print("Position IDs:", pos_ids.tolist())
    print("Tree Mask (5x5 slice):\n", mask[0, 0, :, 10:])

7. Summary and What Comes Next

By flattening a candidate tree $\mathcal{T}$ of $M$ nodes in topological order, assigning each node its tree depth $L_{\text{prefix}} + \operatorname{depth}(u_i)$ as its RoPE position offset, and applying the 2D ancestor mask $M^{\text{tree}}_{i,j}$, a single target forward pass computes exact conditional distributions across all branches simultaneously. Combined with SpecInfer's multi-path recursive rejection sampling, candidate trees dramatically boost the expected accepted path length $\mathbb{E}[\tau]$ when the target distribution is uncertain.

However, verifying a tree of $M = 32$ nodes and accepting a single path of length $a + 1 = 5$ leaves $M - a = 28$ rejected KV-cache slots scattered across our attention buffers!
