    Neural Networks: Follow One Prediction Forward and One Gradient Back

    September 2026 · 16 min read + gradient lab

    A neural network is a sequence of small, inspectable calculations. Follow one example through the whole sequence, then trace how its error changes the weights that produced it.

    What you will learn: why a hidden layer needs a nonlinearity, how backpropagation assigns a derivative to every parameter, and how the same machinery predicts the next token from embeddings.

    Prerequisites: weighted sums, probabilities, and the idea that a derivative measures a local rate of change. The embeddings companion explains the token vectors used later. Every number needed for the worked example appears here.

    An original companion to Jurafsky and Martin’s Chapter 6, “Neural Networks”, in the August 19, 2026 draft. The examples, illustrations, and interactive calculation were created for this article.

    1. One unit: weigh, add, transform

    A computational unit receives numbers x₁, …, xₙ. It multiplies each by a learned weight, adds a learned bias, and transforms the result with an activation function:

    a = w₁x₁ + ⋯ + wₙxₙ + b
    h = g(a)

    The weights decide which inputs matter and in which direction. The bias shifts the response even when all inputs are zero. Here a is the preactivation, before the transformation, and h is the resulting activation. We will use this notation consistently; other sources sometimes use z for the preactivation.

    Our hidden units use ReLU: g(a) = max(0, a). A positive input passes through unchanged; a negative input becomes zero. This produces a bend in the function. A network combines many such bends to form a more flexible mapping from inputs to outputs.

    Other activations serve different purposes. The sigmoid, σ(z) = 1/(1 + e−z), maps a scalar to a number between zero and one, useful for a binary probability. The hyperbolic tangent maps to values between −1 and 1. Both saturate for large input magnitudes, where their derivatives become small. ReLU has derivative one on its positive side, but zero on its negative side. It helps with some gradient problems; it does not make all optimization difficulties disappear.

    Why transform at all? Two affine layers without a hidden nonlinearity collapse into one:

    U(Wx + b) + c = (UW)x + (Ub + c)

    Adding depth in that case changes the parameterization, but not the family of functions represented. The hidden nonlinearity is what lets a multilayer network express something beyond an affine map followed by the final output function.

    2. Learn a representation where the answer becomes simple

    Consider two binary inputs. XOR returns one when exactly one input is one: (0,1) and (1,0) are positive; (0,0) and (1,1) are negative. A single straight decision boundary cannot separate these opposite corners of a square.

    A hidden layer can change the coordinates. Try two units:

    h₁ = ReLU(x₁ − x₂)
    h₂ = ReLU(x₂ − x₁)
    Predict 1 when h₁ + h₂ > 0.5.

    The two equal-input cases both become (0,0). The unequal cases become (1,0) and (0,1). In this new space, a single line separates the classes. In fact, h₁ + h₂ = |x₁ − x₂|, which equals XOR on binary inputs.

    This is representation learning: earlier layers construct features that later layers can use. A hidden unit does not need a human-readable name such as “negation detector.” What matters is whether the combined representation helps predict the targets. Expressive power also does not guarantee that a particular training run will find a good solution.

    3. Work through one complete prediction

    Now use a separate, trainable example. Let the input be x = [1, 2] and its binary target be y = 1. Our network has two hidden ReLU units and one sigmoid output. This is a small multilayer perceptron, or MLP. Treat input vectors as columns.

    a = Wx + b,   h = ReLU(a)
    z = v₁h₁ + v₂h₂ + c,   p = σ(z)
    All nine starting parameters
    PartWeightsBias
    Hidden unit 1W₁₁ = 0.4; W₁₂ = 0.3b₁ = 0.1
    Hidden unit 2W₂₁ = −0.5; W₂₂ = 0.1b₂ = 0.1
    Outputv₁ = 0.6; v₂ = −0.4c = −0.1

    The first hidden preactivation is a₁ = 0.4(1) + 0.3(2) + 0.1 = 1.1. The second is a₂ = −0.5(1) + 0.1(2) + 0.1 = −0.2. After ReLU, h = [1.1, 0]. The output logit, an unrestricted score before the probability transformation, is z = 0.6(1.1) − 0.4(0) − 0.1 = 0.56.

    Applying sigmoid gives p ≈ 0.636453. This is the probability of class one; class zero gets 1 − p. For target one, the binary cross-entropy loss is:

    L = −[y ln p + (1 − y) ln(1 − p)]
    When y = 1: L = −ln(0.636453) ≈ 0.451845

    Natural logarithms make the loss units nats. The loss penalizes low probability on the observed target. It still distinguishes predictions that get the same hard label: probabilities 0.51 and 0.99 both predict class one, but their confidence and losses differ greatly.

    4. Backpropagation is the chain rule applied locally

    The derivative ∂L/∂θ answers a precise question: if parameter θ changes slightly while the other parameters stay fixed, how does the loss change? A computation graph records the operations connecting each parameter to the loss. Follow those paths backward, multiplying derivatives along a path and adding contributions where paths meet.

    For a sigmoid output with binary cross-entropy, the derivative simplifies to ∂L/∂z = p − y. Call this quantity δ. In our example, δ ≈ −0.363547. Increasing the logit slightly should reduce the loss because the observed target is one.

    The output is z = v₁h₁ + v₂h₂ + c. Holding its inputs fixed, its derivatives with respect to v₁, v₂, and c are h₁, h₂, and one. Therefore:

    ∂L/∂v₁ = δh₁ ≈ −0.399902
    ∂L/∂v₂ = δh₂ = 0
    ∂L/∂c = δ ≈ −0.363547

    To reach a hidden preactivation, first go through its output weight, then through ReLU. For a₁ > 0, the ReLU derivative is one. Thus ∂L/∂a₁ = δv₁ ≈ −0.218128. Since a₂ < 0, its ReLU derivative is zero, giving ∂L/∂a₂ = 0.

    Finally, a₁ = W₁₁x₁ + W₁₂x₂ + b₁, so:

    ∂L/∂W₁₁ = (∂L/∂a₁)x₁ ≈ −0.218128
    ∂L/∂W₁₂ = (∂L/∂a₁)x₂ ≈ −0.436257
    ∂L/∂b₁ = ∂L/∂a₁ ≈ −0.218128

    All three parameters feeding hidden unit two have zero gradients on this example. This does not prove that the unit is permanently inactive: a different input might give it a positive preactivation. At exactly zero, ReLU has no ordinary derivative; software must choose a convention. Our lab chooses zero at that point.

    Backpropagation and updating are separate operations. First compute all gradients at the same current parameter values. Then an optimizer uses them to update the parameters. Updating the output weights before calculating the hidden gradients would change the function midway through differentiating it.

    5. Take one learning step, then recompute

    Gradient descent subtracts a learning rate times the gradient: θnew = θ − η ∂L/∂θ. With η = 0.1, negative gradients make the corresponding parameters increase. Our first row becomes W₁₁ ≈ 0.421813, W₁₂ ≈ 0.343626, and b₁ ≈ 0.121813. The output parameters become v₁ ≈ 0.639990 and c ≈ −0.063645. The remaining four parameters stay unchanged.

    Run a fresh forward pass with all these updates. The active hidden value becomes about 1.230877, the new logit 0.724104, the probability 0.673510, and the loss 0.395252. This example’s loss fell from 0.451845. It is one successful local update, not a promise about unseen examples or arbitrarily large learning rates.

    6. Open and close a gradient path

    Change the second hidden bias below. With our fixed input, its preactivation is a₂ = b₂ − 0.3. Below 0.3, the unit is inactive; above 0.3, its weights receive gradients.     7. Turn one example into a training procedure

    For a minibatch of B examples, compute the mean loss and its gradient. A parameter shared by every example receives the sum of their gradient contributions divided by B. One example can push a weight upward while another pushes it downward; the batch combines that evidence.

    for inputs, targets in training_batches:
    clear_previous_gradients()
    logits = model(inputs)
    loss = mean_cross_entropy_from_logits(logits, targets)
    compute_gradients(loss)
    update_all_parameters()

    In practice, numerical libraries combine the probability and log-loss calculations into stable operations on logits. Computing a sigmoid or softmax and then taking logs naively can underflow. The pseudocode also clears old gradients because many automatic differentiation systems accumulate them by default.

    Matrix shapes make batching easier to check. With examples stored as rows, X has shape B × d, hidden weights W have shape m × d, and H = ReLU(XWᵀ + b) has shape B × m. The bias is broadcast over examples. The transpose follows from the chosen convention, not from a change in the model.

    Random initialization gives hidden units different starting roles. If every unit starts identically, symmetry can make their gradients identical too, wasting the extra units. The initialization scale matters as well: huge or tiny activations can make optimization difficult. These details affect learning even when the forward equations look straightforward.

    8. Replace handcrafted features with token embeddings

    For text, the input numbers often come from an embedding matrix E, with one row per vocabulary token. A token ID is a lookup key, not a magnitude: token 80 is not intrinsically twice token 40. Looking up row 80 retrieves its learned vector.

    Suppose a tiny five-token vocabulary has two-dimensional embeddings, so E has shape 5 × 2. For a two-token context, concatenate the retrieved vectors in order. If e(the) = [0.2, 0.7] and e(bird) = [0.8, −0.1], the input is x = [0.2, 0.7, 0.8, −0.1]. Reversing the tokens changes their positions in this four-number vector.

    For a hidden width of three, use W ∈ ℝ3×4 and an output matrix U ∈ ℝ5×3. The output logits become a distribution through softmax: pⱼ = exp(zⱼ)/∑ₖ exp(zₖ). If the actual next token is sings, the loss is −ln p(sings). The gradient at the logits is p − y, now a vector with a one-hot target.

    When embeddings are trainable, gradients continue through the hidden layer into the looked-up rows of E. Multiple occurrences of a token contribute to that same row. With separate input and output parameters, unused input rows receive no lookup gradient on that batch; weight tying or other parameter sharing can change that accounting.

    Unlike a count table that gives every context its own row, this model shares weights and embeddings across contexts. Similar token vectors can lead to similar predictions, providing a route to generalization. The feedforward model here still has a fixed context window; replacing counts with a neural network does not by itself provide unlimited memory.

    For a document classifier, mean-pooling token vectors is a compact alternative to concatenation. But pooling static embeddings discards order: the same bag of tokens yields the same mean. Whether that is acceptable depends on the task. For next-token prediction, the difference between bird eats worm and worm eats bird is a reason to preserve order.

    9. Training behavior and evaluation behavior differ

    During training, gradients update the parameters. During ordinary validation and testing, parameters stay fixed. Use development data to choose learning rates, architecture, dropout, and stopping time; reserve the test set for the final evaluation. Falling training loss shows increasingly good fit to the training data, which can coexist with worsening performance on new examples.

    Dropout randomly zeroes selected activations during training. With drop probability q, the common inverted-dropout convention scales each retained activation by 1/(1 − q). If a value is four and q = 0.5, it becomes either zero or eight; its expected value stays four.

    At ordinary evaluation, disable this random masking and use the unmodified activation. The training-time scaling makes an extra evaluation-time scaling unnecessary. Preserving an activation’s expectation does not mean the entire nonlinear network’s output equals its expectation under dropout. Also, disabling gradient recording and switching dropout to evaluation behavior are separate controls.

    The same discipline applies to language models: compute loss only on eligible targets, handle padding consistently, and never let future target tokens enter their own contexts. A well-trained network can still fail if the data pipeline quietly changes the prediction problem.

    10. Check your understanding

    Why does a stack of affine layers need hidden nonlinearities?

    Without them, the stack can be rewritten as one affine map. ReLU changes the response depending on the input region, allowing a hidden representation that a single affine transformation cannot produce.

    Why is the W₁₂ gradient twice the W₁₁ gradient?

    Both receive the same upstream derivative, ∂L/∂a₁. Their local derivatives are their inputs: x₂ = 2 and x₁ = 1. Multiplying gives −0.436257 and −0.218128 respectively.

    Does a zero gradient on hidden unit two mean it is useless forever?

    No. Its preactivation is negative for this particular input and parameter setting. Another input can activate it. A unit that stays inactive throughout training is a broader problem than one zero gradient.

    What gets learned when a token embedding is trained jointly with the language model?

    The numerical coordinates in that token’s embedding row receive gradients from the prediction loss. The token ID remains a discrete lookup key; gradient descent does not change the vocabulary ID itself.

    With inverted dropout at q = 0.25, what happens to an activation of 3?

    During training it becomes zero with probability 0.25, or 3/0.75 = 4 otherwise. Its expectation is 3. At ordinary evaluation it remains 3, with dropout disabled.
