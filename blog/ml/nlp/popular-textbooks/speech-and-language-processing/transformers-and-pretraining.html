    07 / Context, learning, and generation

    Transformers and Pretraining: From Attention Weights to the Next Token

    September 2026 · 23 min read + attention lab

    A transformer repeatedly mixes information across token positions, transforms the result, and predicts what comes next. We will follow the numbers through attention, then connect that calculation to pretraining and text generation.

    The route: compute one attention row → assemble a decoder block → predict shifted targets → generate with a decoding rule. By the end, you should be able to explain why a model can train on every position together while ordinary generation produces new tokens sequentially.

    Before you begin: the neural networks companion introduces embedding lookup, softmax, cross-entropy, and backpropagation. We reuse that machinery. This chapter focuses on a causal, decoder-only transformer; other transformer architectures use different information-flow rules.

    An original learning companion to Jurafsky and Martin’s Chapter 7, “Transformers and Pretraining”, in the August 19, 2026 draft. All numerical examples, diagrams, and the lab are original. Toy attention weights illustrate mechanics rather than measurements from a trained language model.

    1. One token ID, many contextual representations

    Consider the word bat after the cave sheltered a and after the player swung a. Its initial token embedding may be the same lookup vector in both cases. A useful later representation should reflect the different preceding contexts.

    A transformer maintains one vector at every token position. Each layer updates those vectors using the representations from the layer below. Self-attention lets a position collect information from selected other positions. A feedforward network then transforms the information at each position. Stacking these operations builds contextual representations.

    For a causal language model, position i may read positions 1 … i, including itself, but no later position. This is consistent with predicting token i + 1: the input token at i is already known. A token’s representation cannot incorporate a disambiguating word that has not yet appeared.

    The word “attention” names a mathematical operation. Its weights tell us how a particular head combines vectors; they do not automatically provide a complete explanation of the model’s prediction. Values, output projections, other heads, and subsequent layers also matter.

    2. Separate matching from the information being moved

    Write the current layer’s input as a matrix X with N rows and d columns. A row is one token position; d is the model width. The input to a head is often a normalized version of the residual representation, which we will place inside the full block shortly.

    An attention head makes three learned projections:

    Q = XWQ,   K = XWK,   V = XWV
    • A query is the vector used by the receiving position to score potential sources.
    • A key is the vector each source presents for that comparison.
    • A value is the information contributed when that source receives weight.

    Queries and keys need the same width so their dot product is defined. Values can have a different width. Separate projections let matching and content use different coordinates instead of requiring one vector to serve both jobs.

    Row-vector convention for one head; batch dimension omitted
    ObjectShapeMeaning
    XN × dCurrent input representations
    WQ, WKd × dkLearned matching projections
    Q, KN × dkOne query and key per position
    WV; Vd × dv; N × dvValue projection and resulting values
    QKᵀN × NEvery query compared with every key
    A; AVN × N; N × dvAttention weights; weighted value vectors

    The matrix entry (QKᵀ)ᵢⱼ is qᵢ · kⱼ. Row i asks where position i should collect information. Dot products are compatibility scores, not probabilities; they can be negative and need not sum to one.

    Divide each score by √dk. Under a simple assumption of independent, zero-mean, unit-variance coordinates, an unscaled dot product has variance proportional to dk. This scaling counteracts that growth and helps avoid an unnecessarily saturated softmax. It does not constrain the scores to a fixed range or guarantee good training.

    S = QKᵀ / √dk
    A = softmaxrow(S + M)
    Head output = AV

    The causal mask has Mᵢⱼ = 0 when j ≤ i and −∞ when j > i. Apply it before softmax. Exponentiating a masked score gives zero, so future positions receive no weight. Setting a forbidden score to zero instead would leave exp(0) = 1 in the denominator.

    3. Calculate a head output by hand

    Use four token positions: a small bird sings. We will compute the attention output at position 3, bird, which will eventually help predict position 4. These tiny projected vectors are chosen to make the arithmetic visible; they are not linguistic features assigned by hand in a real model.

    Set dk = dv = 2 and q₃ = [√2, 0]. The keys and values are:

    Four sources; only the first three are visible from position 3
    Position / tokenKey kⱼValue vⱼScaled score q₃ · kⱼ / √2
    1 / a[1, 0][2, 0]1
    2 / small[0, 1][0, 2]0
    3 / bird[1, 1][1, 3]1
    4 / sings[3, 0][4, −1]3, then masked

    The scaled scores are [1, 0, 1, 3]. The last score is largest, but its position is in the future. Masking gives [1, 0, 1, −∞]. The softmax denominator is e + 1 + e = 2e + 1:

    A₃ = [e/(2e + 1), 1/(2e + 1), e/(2e + 1), 0]
    ≈ [0.422319, 0.155362, 0.422319, 0]

    Now weight the values, not the keys or the query:

    o₃ = 0.422319[2, 0] + 0.155362[0, 2]
    + 0.422319[1, 3] + 0[4, −1]
    ≈ [1.266956, 1.577681]

    These coordinates are not output-token probabilities. They are a two-dimensional vector for this head. The attention weights sum to one, but the head’s output coordinates have no such requirement.

    Without the mask, the future token receives weight about 0.757313, and the output changes to approximately [3.336726, −0.374431]. That computation may be mathematically valid attention, but it violates our next-token task at position 3: the representation can now read the token it is supposed to predict.

    4. Experiment: future information must not matter

    Keep position 3 selected and the causal mask enabled. Move the fourth key’s first coordinate: its raw score changes, but the output must remain identical. Turn the mask off to see the same change affect the output. This tests information flow, not just whether a matrix looks triangular.

    5. Attention is one part of a transformer block

    Multihead attention runs several heads in parallel, each with its own projections. One head might weight a nearby pattern while another combines distant information, but those roles are learned and need not have clean linguistic names. Concatenate the head outputs, then use a learned output matrix to return to model width:

    MultiHead(X) = concat(o¹, …, oᴴ)WO
    concat shape: N × (H dv)
    WO shape: (H dv) × d

    For example, with d = 8, two heads, and dv = 4, concatenation produces eight coordinates per position and WO is 8 × 8. Heads are parallel components of a layer; they are not successive layers.

    A common pre-norm decoder block has two residual additions:

    R = X + MultiHead(LayerNorm(X))
    Y = R + FFN(LayerNorm(R))

    The residual connection adds a module’s result to the existing representation. Matching input and output widths makes the addition possible and lets blocks stack. The skip path helps preserve information and provides a direct route for gradients; it does not bypass the need to learn useful updates.

    Layer normalization computes a mean and variance across the d coordinates of each token vector, independently of other positions and examples. It then applies learned coordinate-wise scale and shift:

    LayerNorm(x) = γ ⊙ (x − μ) / √(variance + ε) + β

    The small ε prevents division by zero. This operation is not a softmax, and its output is not a probability distribution. RMSNorm is a related variant that rescales by the root mean square without subtracting the mean.

    The feedforward network mixes coordinates within a position, often expanding from width d to a larger hidden width and projecting back. The same weights apply to every position in that layer, while different layers generally have different weights. Gated variants such as SwiGLU multiply one transformed vector by a learned nonlinear gate before projecting back. Their details change; the distinction between mixing tokens and transforming a token’s features remains useful.

    6. Tell the model where tokens are, then produce logits

    Token lookup alone gives repeated token IDs the same initial vector. The model also needs information about position. A simple scheme adds a learned position vector to each token embedding. The sum has width d, so it fits the residual stream. Sinusoidal encodings supply deterministic position patterns instead.

    Position can also enter attention itself. Rotary position embeddings (RoPE) rotate coordinate pairs in queries and keys according to their positions, causing dot products to depend on relative displacement. This is not the same operation as adding a position vector to the token embedding. Position mechanisms and the causal mask have different jobs: one represents order or distance, while the other restricts which information is available. A causal mask alone does not explicitly encode every token’s distance from another.

    After the decoder stack, a final normalization and a learned projection produce one logit per vocabulary entry. If the final states have shape N × d, the output matrix has shape d × |𝒱|, and logits have shape N × |𝒱|. Here 𝒱 is the vocabulary, distinct from the value matrix V.

    Applying softmax across vocabulary entries gives the next-token distribution for each position. This language-modeling head is a different meaning of “head” from an attention head. The output projection may share parameters with the transpose of the input embedding table, called weight tying. It is not an inverse that recovers the input token: the final state has been transformed to help predict the following token.

    7. Pretraining supplies the targets from the text itself

    Take the token sequence <s> a bird sings </s>. Build an input sequence from all but the final token, and a target sequence from all but the first:

    Inputs:   [start, a, bird, sings]
    Targets: [a, bird, sings, end]

    At the input bird, the target is sings. The representation at that position may use start a bird. Although sings appears later in the input tensor, the causal mask prevents this row from reading it. Including the diagonal of the mask is correct because the current input is not its own target.

    This is self-supervised learning: the text provides its own labels. It is also teacher forcing: the model sees the observed training prefix, even if its previous prediction would have been wrong. We do not replace each next training input with the model’s sampled guess.

    For eligible target positions 𝒯, minimize mean negative log likelihood:

    L = −(1/|𝒯|) ∑t ∈ 𝒯 ln Pθ(targetₜ | permitted input prefixₜ)

    Suppose the probabilities of our four correct targets are 0.6, 0.5, 0.25, and 0.8. Their product is 0.06. Mean loss is −ln(0.06)/4 ≈ 0.703353 nats per target; perplexity is exp(L) ≈ 2.020516. These are illustrative model outputs, separate from the earlier attention weights. The n-gram companion explains why perplexity comparisons require consistent tokenization and evaluation conventions.

    Backpropagation carries the loss through the vocabulary projection, all decoder blocks, and the input embeddings. Training updates shared parameters from many positions and sequences. Future target labels influence gradients during learning; that is expected. They must not be available as future inputs when computing an earlier position’s prediction.

    Two independent masks: an attention mask controls which input positions a representation may read. A loss mask controls which target positions count toward the objective. Ignoring padding targets in the loss does not automatically stop attention from reading padding or a forbidden document segment.

    All masks must be correct in every decoder layer. A later layer cannot repair information already leaked by an earlier unmasked layer. A practical check is to change tokens after position i and confirm that logits at position i remain unchanged, with stochastic training effects such as dropout disabled.

    8. Scale changes the workload, not the prediction contract

    Pretraining data typically mixes sources, but volume alone is not a recipe. Tokenization, document boundaries, duplication, language balance, and source quality all change the distribution the model learns. Repeating a document increases its influence without necessarily adding new information. Evaluation examples that leak into training can make held-out results look better than generalization warrants.

    When packing short documents into one sequence, specify the boundary policy. An end-of-document token marks a boundary; it does not by itself prevent attention across it. Some training setups allow previous-document context, while others use a block-diagonal mask. Either can be an intentional choice, but the implementation should match the defined training problem.

    Three quantities are easy to confuse: parameter count measures stored model capacity, training-token count measures exposure to data, and context length limits the tokens available in a particular forward computation. A model can train on billions of tokens while seeing only a much shorter window at any one time. A larger context window also does not prove that the model reliably uses every distant detail.

    For dense attention, the conceptual score matrix has N² entries per head. Doubling sequence length therefore quadruples the number of pairwise scores. Efficient kernels can avoid materializing that entire matrix in memory, but exact dense attention still performs pairwise work. Layers, model width, batch size, and feedforward computation also contribute to cost; attention is not the whole training bill.

    Under a fixed computation budget, making the model larger leaves fewer resources for processing tokens. Too little data for the chosen capacity wastes an opportunity to learn; increasing data with an undersized model can also hit limitations. Scaling relationships describe empirical trends under particular data and optimization conditions. They are not guarantees that another parameter increase will solve a specific reasoning or factuality problem.

    9. A distribution still needs a rule for choosing a token

    At generation time, run the model on a prompt, take the final position’s vocabulary logits, choose a token, append it, and repeat. The model supplies a distribution; the decoding rule decides how to turn that distribution into a continuation.

    Use this invented four-token distribution after a bird: sings 0.50, waits 0.25, flies 0.15, and end 0.10. We can choose logits equal to the natural logs of these probabilities, because their softmax recovers the same distribution.

    One context, four different selection distributions
    Rulesingswaitsfliesend
    Original sampling0.50000.25000.15000.1000
    Temperature T = 0.50.72460.18120.06520.0290
    Top-k, k = 20.66670.333300
    Top-p, p = 0.80.55560.27780.16670

    Greedy decoding selects the largest logit, here sings. With fixed tie-breaking, it is deterministic for fixed logits. A locally most likely token need not begin the most likely complete sequence: a slightly less likely first choice can have much more probable continuations.

    Temperature divides logits by a positive T before softmax. Equivalently, a base probability becomes proportional to pⱼ1/T. At T = 0.5, square the four probabilities and renormalize; 0.25 divided by their squared sum 0.345 gives 0.724638 for sings. Low temperature sharpens the distribution; high temperature flattens it. It does not reorder logits.

    T = 0 is undefined in the division formula. An interface that offers zero usually interprets it as a separate greedy mode. As positive temperature approaches zero, probability concentrates on the maxima; with an exact tie, the mathematical limit shares mass among the tied maxima. Lower temperature does not verify facts or turn an uncertain prediction into knowledge.

    Top-k retains the k highest-probability tokens, zeros the rest, renormalizes, and samples. With k = 2, retain mass 0.75 and divide 0.50 and 0.25 by it. Define how ties at the cutoff are handled; in our examples, use stable vocabulary order to keep exactly k tokens.

    Top-p, or nucleus sampling, sorts by descending probability and retains the smallest prefix whose cumulative probability reaches or exceeds p. At p = 0.8, the first two tokens sum to 0.75, so include the third, reaching 0.90. Then renormalize those three. Top-p means a fraction of probability mass, not a fraction of vocabulary entries, and includes the token that crosses the threshold.

    The table applies each method separately to the original distribution. Combining methods requires an explicit order. One possible pipeline is temperature → top-k and renormalize → top-p on that new distribution and renormalize → sample. Other implementations may order filtering differently; the surviving tokens can change. After a token is selected, the next step computes a new distribution, so these four numbers do not stay fixed throughout a generated paragraph.

    10. Parallel training, sequential generation, and the KV cache

    During training, the full observed input sequence is already known. At a given layer, every position can calculate its output from the previous layer’s representations in parallel. Causal masking restricts dependencies without requiring us to calculate row 1 before row 2 inside that layer. Layers themselves remain sequential.

    During ordinary autoregressive generation, token t + 1 is not known until we select it. The distribution for token t + 2 depends on that choice. This creates a sequential dependency across new tokens, even though the internal matrix operations and different requests can still be parallelized. Stop when an end token is selected or another explicit stopping rule is met.

    A key-value cache avoids recomputing earlier positions at every generation step. In a causal decoder with fixed parameters, extending the prefix does not change earlier hidden states. Store each layer’s earlier keys and values, compute the new position’s query/key/value, and attend using the cached sources plus the new one.

    The cache saves repeated work; it does not remove the dependence on the newly chosen token. It also consumes memory that grows with sequence length, layers, and the stored key/value dimensions. Prompt processing, often called prefill, can process the prompt positions together; subsequent decoding extends the prefix step by step.

    11. Check your understanding

    Why is replacing a future score with zero insufficient?

    Softmax exponentiates it to one, leaving it with nonzero weight. A forbidden position needs zero probability after normalization, conventionally obtained by a score of negative infinity before softmax.

    With N = 5, d = 8, and dₖ = dᵥ = 2, what are the shapes?

    WQ and WK are 8 × 2; Q and K are 5 × 2; QKᵀ is 5 × 5. V is 5 × 2, and a single head’s AV output is 5 × 2. A projection after concatenating heads returns to model width 8.

    Why may the bird row attend to bird without cheating?

    The input at that row is bird, but its target is the following token, sings. The causal mask includes the current input and excludes later inputs. Predicting the same unshifted token while allowing self-attention would define a different and potentially trivial task.

    Does masking only the last layer prevent future leakage?

    No. An earlier layer could already have copied future information into a permitted row. Every relevant attention layer must respect the intended information boundary.

    Why does top-p = 0.8 retain three candidates in our example?

    The first two sum to 0.75, which is below the cutoff. The third takes cumulative probability to 0.90, so it must be included. Renormalization then gives probabilities 5/9, 5/18, and 1/6.

    Does a KV cache change the learned model probabilities?

    Correct caching reuses computations that would otherwise be repeated, preserving the intended model computation up to numerical effects. It does not change the learned weights or the decoding rule.
