    Hierarchical Agglomerative Clustering, Linkage Geometry & Cluster Evaluation

    November 2026 · 15 min read

    Think about how biologists organize species into genera, families, orders, and kingdoms—or how an e-commerce catalog nests running shoes inside athletic footwear inside apparel. Asking for a single "correct" number of flat clusters $K$ misses the multi-scale reality: at coarse resolution there are $3$ broad families, while zooming in reveals $18$ tight sub-tribes.

    Hierarchical Agglomerative Clustering (HAC) builds that entire nested taxonomy in a single deterministic pass—with zero random seeds and without specifying $K$ upfront. Starting with $n$ singleton leaves, it repeatedly merges the two closest clusters across $n - 1$ steps until one root cluster spans the whole dataset, recording every merge height in a binary tree called a dendrogram. Slice that dendrogram horizontally high up for coarse macro-segments, or slice it lower down for fine micro-segments!

    1. Measuring Distance Between Clusters: The Four Classical Linkages

    When two points $x, y \in \mathbb R^d$ are singletons, their dissimilarity $d(x, y)$ is clear. Once clusters $A$ and $B$ contain multiple observations ($|A|, |B| \ge 1$), how do we define inter-cluster dissimilarity $D(A, B)$? That choice—the linkage criterion—completely transforms the shapes HAC discovers:

    Comparison of the four classical agglomerative linkage criteria on clusters $A, B \subset \mathbb R^d$.
    Linkage Criterion Inter-Cluster Distance $D(A, B)$ Induced Geometry & Failure Mode
    Single (Nearest Neighbor) $\min_{x \in A,\; y \in B} d(x, y)$ Equivalent to building Kruskal's Minimum Spanning Tree (MST)! Captures curved ribbons, but suffers severely from chaining: one noisy bridge point fuses two huge distant clusters early.
    Complete (Farthest Neighbor) $\max_{x \in A,\; y \in B} d(x, y)$ Minimizes the maximum diameter of $A \cup B$. Resists chaining and yields compact, roughly equal-diameter spheres, but can split one large true cluster in half.
    Average (UPGMA) $\dfrac{1}{|A|\cdot|B|} \sum_{x \in A} \sum_{y \in B} d(x, y)$ Compromise between Single and Complete; robust to single bridge points and usable with any dissimilarity matrix (e.g., sequence edit distances in phylogenetics).
    Ward's Minimum Variance $\Delta\operatorname{WCSS}(A, B) = \dfrac{|A|\cdot|B|}{|A| + |B|}\,\|\mu_A - \mu_B\|_2^2$
    (SciPy dendrogram height: $\sqrt{2\,\Delta\operatorname{WCSS}}$)    		 Greedily minimizes the step-by-step jump in K-Means WCSS inertia (requires Euclidean geometry). Tends to produce balanced, compact spherical clusters of similar size.

    Notice the beauty of Ward's algebraic shortcut: instead of scanning every point in $A \cup B$ around their new combined mean $\mu_{A \cup B} = \frac{|A|\mu_A + |B|\mu_B}{|A| + |B|}$, expanding squared norms proves that the exact jump in WCSS equals the centroid separation $\|\mu_A - \mu_B\|_2^2$ weighted by half the harmonic mean $\frac{|A|\cdot|B|}{|A| + |B|}$! Note one convention detail when reading plots: scipy.cluster.hierarchy.linkage(..., method="ward") stores $d_{\text{Ward}}(A, B) = \sqrt{2\,\Delta\operatorname{WCSS}(A, B)}$ so that when $|A| = |B| = 1$, $\sqrt{2 \cdot \frac{1}{2}\|x_i - x_j\|_2^2} = \|x_i - x_j\|_2$ matches ordinary Euclidean distance.

    2. Worked 4-Point Merge Trace: Watching Single-Linkage Chaining Live

    Let us trace all $n - 1 = 3$ merges by hand on four 1D points $A = 0,\; B = 2,\; C = 5,\; D = 9$. Their $4 \times 4$ pairwise distance matrix has $d(A,B) = 2$, $d(B,C) = 3$, $d(C,D) = 4$, $d(A,C) = 5$, $d(B,D) = 7$, and $d(A,D) = 9$. Watch what happens right after Merge 1:

    Step-by-step 3-merge trace on $\{A=0,\; B=2,\; C=5,\; D=9\}$ under Single, Complete, and Ward linkage.
    Merge Step Single Linkage ($\min$) Complete Linkage ($\max$) Ward's Linkage ($\sqrt{2\,\Delta\operatorname{WCSS}}$)
    Step 1
    4 $\to$ 3 clusters    		 Merge $\{A\}, \{B\} \to \{A,B\}$
    Height $= \mathbf{2.0}$    		 Merge $\{A\}, \{B\} \to \{A,B\}$
    Height $= \mathbf{2.0}$    		 Merge $\{A\}, \{B\} \to \{A,B\}$ ($\mu_{AB}=1$)
    $\Delta\operatorname{WCSS}=2 \implies$ Height $= \mathbf{2.0}$
    Step 2
    3 $\to$ 2 clusters    		 $D(\{A,B\},\{C\}) = \min(5, 3) = \mathbf{3.0} < 4.0$!
    Chains $\{A,B\} \cup \{C\} \to \{A,B,C\}$ at $\mathbf{3.0}$    		 $D(\{A,B\},\{C\}) = \max(5, 3) = 5.0 > \mathbf{4.0}$!
    Merges $\{C\} \cup \{D\} \to \{C,D\}$ at $\mathbf{4.0}$    		 $\Delta(\{A,B\},\{C\}) = \frac{2\cdot 1}{3}(1-5)^2 = 10.67$,
    $\Delta(\{C\},\{D\}) = \frac{1\cdot 1}{2}(5-9)^2 = \mathbf{8.0} \implies \{C,D\}$ at $\sqrt{16} = \mathbf{4.0}$
    Step 3
    2 $\to$ 1 root    		 Merge $\{A,B,C\} \cup \{D\}$
    Height $= \min(9, 7, 4) = \mathbf{4.0}$    		 Merge $\{A,B\} \cup \{C,D\}$
    Height $= \max(9, 7, 5, 3) = \mathbf{9.0}$    		 Merge $\{A,B\}$ ($\mu=1$) $\cup$ $\{C,D\}$ ($\mu=7$)
    $\Delta = \frac{2\cdot 2}{4}(1-7)^2 = 36 \implies \sqrt{72} \approx \mathbf{8.4853}$
    Cut at $K = 2$: Lopsided $\{A, B, C\} \mid \{D\}$ Balanced $\{A, B\} \mid \{C, D\}$ Balanced $\{A, B\} \mid \{C, D\}$

    Memory & Time Scaling Limit: Standard HAC stores the $n(n-1)/2$ pairwise distance triangle in $O(n^2)$ memory and merges clusters in $O(n^2 \log n)$ time via priority queues (or optimal $O(n^2)$ time via SLINK for Single linkage and nearest-neighbor chains for Ward/Complete/Average). Once $n \gtrsim 50{,}000$, $O(n^2)$ RAM becomes prohibitive—switch to Mini-Batch $K$-Means, BIRCH, or spatial-indexed HDBSCAN.

    3. Rigorous Cluster Evaluation: Internal vs. External Metrics

    Because any clustering algorithm will gladly return cluster IDs even on pure uniform Gaussian white noise, validation is mandatory. Cluster metrics divide into two families depending on whether ground-truth reference classes exist:

    Summary of standard Internal (unsupervised) and External (benchmark) cluster evaluation metrics.
    Metric Type Formula / Definition Range & Direction
    Silhouette Score
    Rousseeuw (1987)    		 Internal $s(i) = \dfrac{b(i) - a(i)}{\max\bigl(a(i), b(i)\bigr)}$, averaged over $i=1,\ldots,n$ ($a(i)$: mean own-cluster dist; $b(i)$: lowest mean other-cluster dist; $0$ if $|C|=1$). $[-1, +1]$
    Higher is better
    Davies–Bouldin Index Internal $\operatorname{DBI} = \dfrac{1}{K}\sum_{k=1}^K \max_{j \ne k} \dfrac{\sigma_k + \sigma_j}{\|\mu_k - \mu_j\|_2}$ ($\sigma_k$: mean distance of $C_k$ points to $\mu_k$). $[0, \infty)$
    Lower is better
    Calinski–Harabasz
    Variance Ratio    		 Internal $\operatorname{CH} = \dfrac{\operatorname{Tr}(B_K) / (K - 1)}{\operatorname{Tr}(W_K) / (n - K)}$ (ratio of between-cluster dispersion to within-cluster WCSS, like an ANOVA $F$-statistic). $[0, \infty)$
    Higher is better
    Adjusted Rand Index (ARI) External Chance-corrected fraction of the $\binom{n}{2}$ point pairs agreed upon (same-cluster or split) between predicted $U$ and true $V$: $\dfrac{\operatorname{RI} - \mathbb E[\operatorname{RI}]}{\max(\operatorname{RI}) - \mathbb E[\operatorname{RI}]}$. $[-1, +1]$
    ($0$ = random, $1$ = exact)
    Normalized Mutual Info (NMI) External $\operatorname{NMI}(U, V) = \dfrac{2\,I(U; V)}{H(U) + H(V)}$, measuring reduction in class entropy $H(V)$ given cluster ID $U$ (use AMI when $K$ is large). $[0, 1]$
    Higher is better

    Worked Metric Check & The Non-Convex Silhouette Trap!

    First check our 4-point example $\{A=0, B=2, C=5, D=9\}$ against reference labels $V = [0, 0, 1, 1]$:

    • Compact cut $\{A, B\} \mid \{C, D\}$: For $A=0$, $a(A) = |0 - 2| = 2$ and $b(A) = \frac{|0-5| + |0-9|}{2} = 7 \implies s(A) = \frac{7 - 2}{7} = \frac{5}{7} \approx 0.7143$. Across all four points $s = [\frac{5}{7},\; \frac{3}{5},\; 0,\; \frac{1}{2}]$, giving mean Silhouette $\mathbf{0.4536}$ (vs. $\mathbf{0.3135}$ for chained $\{A,B,C\} \mid \{D\}$). Meanwhile, why do we need Adjusted Rand Index instead of raw Rand Index? On chained $U_{\text{chain}} = [0, 0, 0, 1]$, $3$ of the $\binom{4}{2} = 6$ pairs agree with $V = [0, 0, 1, 1]$, inflating raw $\operatorname{RI} = 3/6 = \mathbf{0.50}$, whereas chance-corrected $\operatorname{ARI} = \mathbf{0.0000}$ rightly flags zero above-chance agreement!
    • Warning — Why Convex Internal Metrics Lie on Moons & Rings: Silhouette, Davies–Bouldin, and Calinski–Harabasz all measure straight-line Euclidean distances across space. On two interlocking crescents (make_moons), opposite tips of the same crescent sit far apart in straight-line Euclidean distance, while the belly of the other crescent pokes close in between! As our Python check below verifies, wrong convex $K$-Means gets a higher Silhouette score ($0.4877$) than $100\%$-accurate DBSCAN ($0.3308$, $\operatorname{ARI} = 1.0000$)! Never tune non-convex density clusterers like DBSCAN using Euclidean Silhouette—use density-aware validation such as DBCV (Density-Based Clustering Validation) or visual manifold inspection instead.
    Show the complete Python verification 
    import numpy as np
from scipy.cluster.hierarchy import linkage
from sklearn.cluster import DBSCAN, KMeans
from sklearn.datasets import make_moons
from sklearn.metrics import (
    adjusted_rand_score,
    calinski_harabasz_score,
    davies_bouldin_score,
    normalized_mutual_info_score,
    rand_score,
    silhouette_samples,
    silhouette_score,
)

# 1. Verify all 3 merges on {A=0, B=2, C=5, D=9} across Single, Complete, and Ward
X4 = np.array([[0.0], [2.0], [5.0], [9.0]])
for method in ["single", "complete", "ward"]:
    Z = linkage(X4, method=method)
    print(f"{method:8s} merge heights:", np.round(Z[:, 2], 4))
# single  : [2.     3.     4.    ]  <-- chains C at 3.0!
# complete: [2.     4.     9.    ]
# ward    : [2.     4.     8.4853]  <-- sqrt(72)

# 2. Verify Internal & External metrics on {A,B}|{C,D} vs chained {A,B,C}|{D}
y_ref = np.array([0, 0, 1, 1])
u_compact = np.array([0, 0, 1, 1])
u_chained = np.array([0, 0, 0, 1])

print("Compact per-point silhouette:", np.round(silhouette_samples(X4, u_compact), 4))  # [0.7143 0.6 0. 0.5]
print("Compact Sil / DBI / CH      :", round(silhouette_score(X4, u_compact), 4),
      round(davies_bouldin_score(X4, u_compact), 4), round(calinski_harabasz_score(X4, u_compact), 4))
print("Chained RI vs ARI vs NMI    :", rand_score(y_ref, u_chained),
      adjusted_rand_score(y_ref, u_chained), round(normalized_mutual_info_score(y_ref, u_chained), 4))
# RI = 0.5, yet chance-adjusted ARI = 0.0!

# 3. Demonstrate the non-convex Silhouette paradox on make_moons
X_m, y_m = make_moons(n_samples=300, noise=0.05, random_state=42)
km_pred = KMeans(n_clusters=2, n_init=10, random_state=42).fit_predict(X_m)
db_pred = DBSCAN(eps=0.2, min_samples=5).fit_predict(X_m)
print(f"Moons K-Means -> Silhouette: {silhouette_score(X_m, km_pred):.4f}, ARI: {adjusted_rand_score(y_m, km_pred):.4f}")
print(f"Moons DBSCAN  -> Silhouette: {silhouette_score(X_m, db_pred):.4f}, ARI: {adjusted_rand_score(y_m, db_pred):.4f}")
