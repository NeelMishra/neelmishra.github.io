    LDA Classification: From Class Distributions to a Prediction

    October 2026 · 12 min read

    Classification follow-up to PCA and LDA.pdf · View a handwritten page

    The Fisher LDA guide finds a direction that separates class means relative to the spread inside each class. That projection gives each point a score, but we still need a rule to turn scores into labels. Here we build an LDA classifier: it models each class around its own center and assumes the classes share the same overall spread. We will fit it from eight labeled rows and classify a new point.

    Start with two measurements and a class label

    This small example uses simple numbers so we can follow every step. Each row is one point, with two measurements, $x_1$ and $x_2$, and a known class label, A or B. The point $(4,4)$ will be our new example; it is not used to fit the model.

    What does the LDA classifier assume?

    The classifier assumes that measurements within each class form a bell-shaped cloud. Each class has its own center, but all classes share the same shape and orientation, described by one covariance matrix:

    $$x\mid c\sim\mathcal N(\mu_c,\Sigma).$$

    The mean $\mu_c$ is the center of class $c$. The covariance $\Sigma$ describes how spread out the points are and whether the measurements move together. The prior $\pi_c=P(c)$ is how common a class is before we look at a new point's measurements. The density and inverse formulas below assume that $\Sigma$ is positive definite, so it has an inverse.

    A shared covariance does not require circular clouds or independent measurements. The same matrix can describe tilted elliptical clouds for every class. The Gaussian assumption belongs to this probability model; the Fisher projection derivation does not need it.

    Estimate the class means and priors

    Find each class center by averaging its rows one measurement at a time. For A, the first average is $(1+3+2+2)/4=2$ and the second is $(2+2+1+3)/4=2$. Doing the same for B gives (6, 4). Here we estimate each prior from its fraction of training rows; both classes have four of the eight points:

    Estimate the shared covariance

    To measure spread, subtract a point's own class mean. For each class, the four differences are $(-1,0)$, $(1,0)$, $(0,-1)$, and $(0,1)$. Squaring and adding the first coordinates gives 2; the second coordinates also give 2. Every difference pair has a zero coordinate, so every cross-product is zero.

    Add the spread from both classes, then divide by all eight training points. This gives the maximum-likelihood estimate of their shared covariance:

    $$\hat\Sigma =\frac1n\sum_c\sum_{i\in c} (x_i-\hat\mu_c)(x_i-\hat\mu_c)^\top.$$
    $$\hat\Sigma =\frac18\begin{bmatrix}4&0\\0&4\end{bmatrix} =\begin{bmatrix}0.5&0\\0&0.5\end{bmatrix}.$$

    The numerator is the total within-class scatter, $S_W$, so this estimate is $\hat\Sigma=S_W/n$. We deliberately use the maximum-likelihood denominator $n=8$. The unbiased pooled estimate would divide by $n-C=6$, where $C=2$ classes; it would give a different covariance and different probability estimates. Keep the convention consistent throughout the calculation.

    Here $\hat\Sigma^{-1}=2I$, where $I$ is the identity matrix. Both measurements have the same spread, and their covariance is zero in this example. Other datasets can have nonzero off-diagonal entries, which means the measurements vary together.

    Turn the fitted distributions into class probabilities

    For a new point $x$, ask two questions for each class: how well do its measurements fit that class, and how common is the class before seeing the point? Bayes' rule combines those answers:

    $$P(c\mid x)= \frac{\overbrace{p(x\mid c)}^{\text{likelihood}}\, \overbrace{\pi_c}^{\text{prior}}} {\sum_k p(x\mid k)\pi_k}.$$

    Here $k$ runs over all classes. The numerator combines the fit of the point with the class's prior. The denominator scales the results so the class probabilities add to 1. These updated probabilities are called posteriors. If mistakes have equal cost, choose the class with the largest one.

    For our two measurements, the Gaussian likelihood is:

    $$\begin{gathered} p(x\mid c)=\frac1{2\pi\sqrt{|\Sigma|}}\\ {}\times\exp\left[-\frac12 (x-\mu_c)^\top\Sigma^{-1}(x-\mu_c)\right]. \end{gathered}$$

    $|\Sigma|$ is the determinant. The expression in the exponent is the squared Mahalanobis distance: distance from the class center adjusted for feature spread and correlations. Smaller distance means greater likelihood. This need not match ordinary Euclidean distance. Also, $p(x\mid c)$ is a density, not the probability of seeing that exact continuous-valued point; the posterior class probabilities are obtained by Bayes' rule.

    Why the class scores are linear

    The denominator in Bayes' rule is identical for every class. To find the most likely class, compare $p(x\mid c)\pi_c$. Taking the log preserves their ordering. For two measurements, the Gaussian expression gives:

    $$\begin{aligned} \ell_c(x)&=\log[p(x\mid c)\pi_c]\\ &=-\log(2\pi)-\frac12\log|\Sigma|\\ &\quad-\frac12(x-\mu_c)^\top\Sigma^{-1}(x-\mu_c)+\log\pi_c. \end{aligned}$$

    Write $Q=\Sigma^{-1}$ to make the expansion easier to read. Since $Q$ is symmetric, the two cross-terms are the same scalar:

    $$\begin{aligned} (x-\mu_c)^\top Q(x-\mu_c) &=x^\top Qx-x^\top Q\mu_c\\ &\quad-\mu_c^\top Qx+\mu_c^\top Q\mu_c\\ &=x^\top Qx-2x^\top Q\mu_c+\mu_c^\top Q\mu_c. \end{aligned}$$

    Multiply this expansion by $-1/2$ and add the prior term. The terms $-\log(2\pi)$, $-\tfrac12\log|\Sigma|$, and $-\tfrac12x^\top Qx$ are shared by all classes. Remove those shared terms to get the score:

    $$\begin{aligned} \delta_c(x)={}&x^\top\Sigma^{-1}\mu_c\\ &-\frac12\mu_c^\top\Sigma^{-1}\mu_c+\log\pi_c. \end{aligned}$$

    Each score is a weighted sum of the measurements plus a constant: no class-dependent $x_1^2$, $x_2^2$, or $x_1x_2$ term remains. That cancellation relies on the shared covariance. The score differs from the log posterior by a term common to all classes for the same point; it is not itself a probability.

    Now substitute $\Sigma^{-1}=2I$, the two class centers, and their equal priors. For A, the two feature weights are $2(2,2)=(4,4)$ and the constant from its center is $-8$. Doing the same for B gives:

    $$\begin{aligned} \delta_A(x)&=4x_1+4x_2-8+\log0.5,\\ \delta_B(x)&=12x_1+8x_2-52+\log0.5. \end{aligned}$$

    Classify the new point (4, 4)

    Put $(4,4)$ into both scores. The prior term $\log0.5$ is the same for each class, so it does not affect which score is larger.

    Predict class B because its score is larger. To turn the scores into probabilities, exponentiate them and scale them so they add to 1. The difference between the scores is 4:

    $$\begin{aligned} P(B\mid x) &=\frac1{1+\exp(\delta_A-\delta_B)}\\ &=\frac1{1+e^{-4}}\approx0.9820. \end{aligned}$$

    Under this fitted model, the new point has about 98.2% probability of belonging to B and 1.8% of belonging to A. This is a model probability, not evidence that the classifier achieves 98.2% accuracy on new data.

    Read the decision boundary

    The boundary is where the two scores tie. To derive it for two classes, let $g=\mu_B-\mu_A$ and $\beta=\Sigma^{-1}g$. Subtract the class scores:

    $$\begin{aligned} \delta_B(x)-\delta_A(x) &=x^\top\Sigma^{-1}g\\ &\quad-\frac12(\mu_B^\top\Sigma^{-1}\mu_B-\mu_A^\top\Sigma^{-1}\mu_A)\\ &\quad+\log\frac{\pi_B}{\pi_A}\\ &=\beta^\top\left(x-\frac{\mu_A+\mu_B}{2}\right) +\log\frac{\pi_B}{\pi_A}. \end{aligned}$$

    For the last equality, symmetry gives $\mu_B^\top\Sigma^{-1}\mu_B-\mu_A^\top\Sigma^{-1}\mu_A=(\mu_A+\mu_B)^\top\Sigma^{-1}g$. Equal priors make the logarithm zero. The boundary is then halfway between the two class means along the classifier's score direction, not necessarily the ordinary Euclidean perpendicular bisector.

    In our example, $g=(4,2)^\top$, $\beta=2g=(8,4)^\top$, and the midpoint is $(4,3)$. Class B wins where $\delta_B-\delta_A>0$:

    $$\delta_B-\delta_A=8x_1+4x_2-44.$$

    The scores tie on the line $2x_1+x_2=11$. Points with $2x_1+x_2>11$ are assigned to B; points on the other side are assigned to A. For our point, $2(4)+4=12$, so it falls on B's side.

    Holding the class means and covariance fixed, a larger prior for B adds a larger $\log(\pi_B/\pi_A)$ and expands B's region. With more than two classes, calculate one score per class and choose the largest.

    How this connects to the LDA projection

    Using the same training data and covariance estimate $\Sigma=S_W/n$, the classifier's weights are $\beta=nS_W^{-1}(\mu_B-\mu_A)$. They point along the Fisher direction derived in the projection guide. For this guide's eight rows:

    $$\begin{aligned} S_W&=\begin{bmatrix}4&0\\0&4\end{bmatrix},\quad g=\begin{bmatrix}4\\2\end{bmatrix},\\ u=S_W^{-1}g&=\begin{bmatrix}1\\0.5\end{bmatrix},\quad \beta=8u=\begin{bmatrix}8\\4\end{bmatrix}. \end{aligned}$$

    The projection guide uses a different ten-point dataset, so its numerical weights differ. The method is the same. Fisher's criterion chooses an axis; the Gaussian classifier adds a threshold from its class means and priors. In two dimensions, the boundary is perpendicular to $\beta$, so it is a different line from the projection axis. A prediction method performs this comparison directly; you do not need a separate projection step.

    Check the prediction in Python

    This code uses the same covariance calculation as our worked example. The lsqr option fits the classifier directly, without making a separate projection first.

    import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

X = np.array([
    [1, 2], [3, 2], [2, 1], [2, 3],
    [5, 4], [7, 4], [6, 3], [6, 5],
], dtype=float)
y = np.array(["A"] * 4 + ["B"] * 4)
model = LinearDiscriminantAnalysis(solver="lsqr").fit(X, y)
print(model.covariance_)                 # [[0.5, 0.0], [0.0, 0.5]]
print(model.predict([[4, 4]]))           # ['B']
print(model.classes_)                   # ['A', 'B']
print(model.predict_proba([[4, 4]]))     # [[0.01798621, 0.98201379]]

    Fit the class centers, priors, covariance, and any preprocessing using training data only. Then check predictions on separate held-out data. If there are more features than training points, shrinking the covariance estimate can make it more stable. If classes need different covariance shapes, quadratic discriminant analysis (QDA) removes LDA's shared-shape assumption and can produce curved boundaries.
