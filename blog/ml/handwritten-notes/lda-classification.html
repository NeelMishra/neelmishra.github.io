    LDA Classification: From Class Distributions to a Prediction

    October 2026 · 8 min read

    Classification follow-up to PCA and LDA.pdf · View a handwritten page

    The Fisher LDA guide finds a direction that separates class means relative to their spread. LDA can also predict a class directly: fit a probability distribution for each class, then use Bayes' rule to compare them. We will fit the model from eight visible rows and classify one new point.

    Start with two measurements and a class label

    This teaching dataset uses simple numbers so we can follow every calculation. Each point has two measurements, $x_1$ and $x_2$, and belongs to class A or B.

    What does the LDA classifier assume?

    Within each class, the measurements follow a multivariate Gaussian distribution. Each class has its own mean, but all classes share one covariance matrix:

    $$x\mid c\sim\mathcal N(\mu_c,\Sigma).$$

    The mean $\mu_c$ locates the class center. The covariance $\Sigma$ describes the spread and how the measurements vary together. Sharing it gives the class distributions the same shape and orientation. The class prior $\pi_c=P(c)$ describes how common each class is before seeing a point's measurements.

    Estimate the class means and priors

    Average each measurement within its class. For A, the first mean is $(1+3+2+2)/4=2$ and the second is $(2+2+1+3)/4=2$. Repeat for B, and use class counts for the priors:

    A4(2, 2)4/8 = 0.5
    B4(6, 4)4/8 = 0.5

    Estimate the shared covariance

    Subtract each point's own class mean. In both classes, the resulting deviations are $(-1,0)$, $(1,0)$, $(0,-1)$, and $(0,1)$. Within each class, the squared deviations sum to 2 for each measurement, and the cross-products sum to zero.

    Add both classes' scatter matrices and divide by all eight rows. This is the maximum-likelihood covariance estimate:

    $$\hat\Sigma =\frac1n\sum_c\sum_{i\in c} (x_i-\hat\mu_c)(x_i-\hat\mu_c)^\top.$$
    $$\hat\Sigma =\frac18\begin{bmatrix}4&0\\0&4\end{bmatrix} =\begin{bmatrix}0.5&0\\0&0.5\end{bmatrix}.$$

    The inverse is $\hat\Sigma^{-1}=2I$, where $I$ is the identity matrix. We will use these fitted values below. LDA permits nonzero off-diagonal entries; they are zero here because of our particular data.

    Turn the fitted distributions into class probabilities

    For a new point $x$, Bayes' rule combines how well each class explains its measurements with that class's prior:

    $$P(c\mid x)= \frac{\overbrace{p(x\mid c)}^{\text{likelihood}}\, \overbrace{\pi_c}^{\text{prior}}} {\sum_k p(x\mid k)\pi_k}.$$

    Here $k$ runs over the classes. The numerator gives a class's unnormalized weight; the denominator makes the probabilities sum to one. With equal costs for mistakes, predict the class with the largest posterior probability.

    For our two measurements, the Gaussian likelihood is:

    $$\begin{gathered} p(x\mid c)=\frac1{2\pi\sqrt{|\Sigma|}}\\ {}\times\exp\left[-\frac12 (x-\mu_c)^\top\Sigma^{-1}(x-\mu_c)\right]. \end{gathered}$$

    $|\Sigma|$ is the determinant. The quadratic expression is a squared distance from the class mean that accounts for covariance. A smaller distance gives a larger likelihood.

    Why the class scores are linear

    Take the log of likelihood times prior and remove terms shared by every class. The score to maximize is:

    $$\begin{aligned} \delta_c(x)={}&x^\top\Sigma^{-1}\mu_c\\ &-\frac12\mu_c^\top\Sigma^{-1}\mu_c+\log\pi_c. \end{aligned}$$

    The term $-\tfrac12x^\top\Sigma^{-1}x$ is the same for every class because the covariance is shared, so it cancels when comparing scores. What remains is linear in $x$. A score is a log-posterior up to a common additive term; it is not itself a probability.

    Substitute $\Sigma^{-1}=2I$, the two means, and equal priors. For A, the linear coefficients are $2(2,2)=(4,4)$ and the constant is $-\tfrac12(2)(2^2+2^2)=-8$. Applying the same calculation to B gives:

    $$\begin{aligned} \delta_A(x)&=4x_1+4x_2-8+\log0.5,\\ \delta_B(x)&=12x_1+8x_2-52+\log0.5. \end{aligned}$$

    Classify the new point (4, 4)

    Put the new measurements into both scores. The prior contribution $\log0.5$ is identical, so it does not change their ordering.

    Compare the two fitted scores for the same new point.
    ClassScore calculationScore
    A$4(4)+4(4)-8+\log0.5$23.3069

    Predict class B because its score is larger. To obtain the posterior probability, exponentiate the scores and normalize. Their difference is exactly 4:

    $$\begin{aligned} P(B\mid x) &=\frac1{1+\exp(\delta_A-\delta_B)}\\ &=\frac1{1+e^{-4}}\approx0.9820. \end{aligned}$$

    The fitted model assigns about 98.2% probability to B and 1.8% to A.

    Read the decision boundary

    Class B wins when $\delta_B-\delta_A>0$. With equal priors, our score difference is:

    $$\delta_B-\delta_A=8x_1+4x_2-44.$$

    The scores tie on the straight line $2x_1+x_2=11$. Predict B on the side where $2x_1+x_2>11$, and A on the other side. Our new point gives $2(4)+4=12$, confirming B.

    Different priors add $\log(\pi_B/\pi_A)$ to the score difference. Holding means and covariance fixed, a larger prior for B expands the region assigned to B. For more than two classes, compute one score per class and choose the largest.

    How this connects to the LDA projection

    For two classes, the score difference uses the direction $\Sigma^{-1}(\mu_B-\mu_A)$. Since the shared covariance is the within-class scatter divided by a common count, this is proportional to the Fisher direction from the projection guide. The classifier also supplies the threshold through its class means and priors. You can call its prediction method directly without a separate projection step.

    Check the prediction in Python

    This uses the same maximum-likelihood covariance convention as our calculation. The lsqr solver fits the classifier directly.

    import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

X = np.array([
    [1, 2], [3, 2], [2, 1], [2, 3],
    [5, 4], [7, 4], [6, 3], [6, 5],
], dtype=float)
y = np.array(["A"] * 4 + ["B"] * 4)
model = LinearDiscriminantAnalysis(solver="lsqr").fit(X, y)
print(model.covariance_)                 # [[0.5, 0.0], [0.0, 0.5]]
print(model.predict([[4, 4]]))           # ['B']
print(model.classes_)                   # ['A', 'B']
print(model.predict_proba([[4, 4]]))     # [[0.01798621, 0.98201379]]

    Fit the means, priors, covariance, and any preprocessing using training data only. Check predictions on held-out data. If features outnumber the available observations, covariance shrinkage can make the estimate more stable. If classes need different covariance shapes, QDA relaxes LDA's shared-covariance assumption and can produce curved boundaries.
