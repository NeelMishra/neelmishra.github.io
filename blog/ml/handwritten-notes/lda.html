    Fisher LDA: Find a Projection That Separates Classes

    October 2026 · 5 min read

    Expanded from PCA and LDA.pdf · View a handwritten page

    Linear discriminant analysis (LDA) can choose a projection using class labels. Fisher's criterion rewards class means that are far apart after projection while keeping each class's spread small. We will calculate that direction using the ten points in the handwritten notes.

    Start with the labeled points in the notes

    A direction can have large variance without separating the classes we care about. LDA uses labels to compare between-class separation with within-class spread. Here are the ten points listed on page 4 of the original notes:

    Average within each class: $\mu_A=(3,3.6)$ and $\mu_B=(8.4,7.6)$. Their difference is $(5.4,4)$. Projecting along that difference would separate the means, but it would not yet account for how broadly the classes spread in each direction.

    Measure spread around each class mean

    For each point, subtract its own class mean, form the outer product of that difference with itself, and add. For A1, the deviation is $(1,-2.6)$, contributing:

    $$ \begin{bmatrix}1\\-2.6\end{bmatrix} \begin{bmatrix}1&-2.6\end{bmatrix} =\begin{bmatrix}1&-2.6\\-2.6&6.76\end{bmatrix}.$$

    Summing all five contributions in each class gives:

    $$S_A=\begin{bmatrix}4&-2\\-2&13.2\end{bmatrix}, \quad S_B^{\mathrm{class}}=\begin{bmatrix}9.2&-0.2\\-0.2&13.2\end{bmatrix}.$$

    Add them to get the within-class scatter matrix:

    $$S_W=\begin{bmatrix}13.2&-2.2\\-2.2&26.4\end{bmatrix}.$$

    Here “scatter” is an unnormalized sum. Dividing this entire matrix by a common constant rescales the Fisher score without changing its best direction. Dividing each class's contribution by a different count, however, changes class weighting when sizes differ. Keeping sums explicit avoids mixing those conventions.

    Balance separation against spread

    For two classes, Fisher's criterion is the squared gap between projected means divided by their combined projected scatter:

    $$J(w)= \frac{\left[w^\top(\mu_B-\mu_A)\right]^2} {w^\top S_Ww}.$$

    Multiplying $w$ by a constant scales both numerator and denominator equally, so only direction matters. If $S_W$ is invertible, the maximizing direction is proportional to $S_W^{-1}(\mu_B-\mu_A)$. Solve the corresponding linear system:

    $$ \begin{bmatrix}13.2&-2.2\\-2.2&26.4\end{bmatrix}w =\begin{bmatrix}5.4\\4\end{bmatrix}.$$

    The solution is approximately $(0.44046,0.18822)$. Normalizing its length gives $v=(0.91956,0.39295)$. A point becomes one coordinate, $z=v^\top x=0.91956x_1+0.39295x_2$. For A1, this is about $0.91956(4)+0.39295(1)=4.0712$.

    The projected class means are approximately 4.1733 and 10.7107. This direction accounts for the observed within-class spread as well as the gap between means.

    import numpy as np

A = np.array([[4,1], [2,4], [2,3], [3,6], [4,4]], dtype=float)
B = np.array([[9,10], [6,8], [9,5], [8,7], [10,8]], dtype=float)
ma, mb = A.mean(0), B.mean(0)
Ac, Bc = A-ma, B-mb
within = Ac.T @ Ac + Bc.T @ Bc
w = np.linalg.solve(within, mb-ma)
v = w / np.linalg.norm(w)
print(within)  # [[13.2, -2.2], [-2.2, 26.4]]
print(v)       # [0.91955932, 0.39295122]

    Generalize the same idea to several classes

    Let $n_c$ be a class's size, $\mu_c$ its mean, and $\mu$ the overall, sample-weighted mean. Define:

    $$S_W=\sum_c\sum_{i\in c} (x_i-\mu_c)(x_i-\mu_c)^\top.$$
    $$S_{\mathrm{between}}=\sum_c n_c (\mu_c-\mu)(\mu_c-\mu)^\top.$$

    The class counts weight the between-class scatter. Solve the generalized eigenvector problem $S_{\mathrm{between}}v=\lambda S_Wv$ and keep directions with the largest eigenvalues. With $C$ classes and $d$ inputs, at most $\min(d,C-1)$ directions can separate class means. In our two-class example, that leaves one direction.

    What this projection does and does not give us

    Fisher's criterion uses class means and scatter; computing it does not require Gaussian class distributions. It can miss useful differences when classes have the same mean or are arranged in curved patterns. If the within-class scatter is singular, regularization can stabilize the calculation.
