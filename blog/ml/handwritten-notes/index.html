    Handwritten Machine Learning Notes

    October 2026 · 3 min read

    These six guides expand my handwritten machine learning notes into worked explanations. Each begins with visible data, follows the calculation, and then connects it to the general formula. The original PDFs and selected page scans sit alongside the explanations.

    Follow the ideas from estimation to prediction

    Start with a coin to understand likelihood and Bayesian updating. Carry the same ideas into linear regression, then compare two ways to build a classifier. The final two guides group observations and reduce their dimensions.

    01
    MLE, MAP, and Bayesian Prediction

    Five coin tosses take us from likelihood to a posterior distribution and the next-toss prediction.

     02
    Linear Regression: From Gaussian Noise to Ridge

    Fit three students' scores, derive squared error, and calculate how a prior shrinks the slope.

     03
    Naïve Bayes: From Word Counts to a Prediction

    Use four messages to calculate class priors, smoothing, log scores, and a spam probability.

     04
    Logistic Regression: From Scores to Learning

    Turn scores into probabilities and work through cross-entropy, gradients, and one training update.

     05
    K-means: Build and Check the Clusters

    Group six points, move their centers, and calculate elbow, silhouette, and Dunn scores.

     06
    PCA and LDA: Choose What a Projection Preserves

    Calculate a PCA projection and complete the ten-point LDA example from the handwritten notes.

    Keep the data beside the calculation

    The first four guides build on likelihood, but each repeats the data needed for its own example. The clustering and projection guides can be read independently. Basic algebra is enough to start; derivatives and matrix notation are introduced where they explain a calculation.

    Each guide has a section called “From the handwritten notes.” Open it to compare a selected original page with the expanded explanation. Where the handwritten derivation skips an intermediate step or uses a different convention, the surrounding text spells out the calculation. All essential formulas are also written as searchable text.

    Reproduce the worked numbers

    The companion Python script recreates the numerical examples and three explanatory figures. It checks the hand calculations against numerical solvers and scikit-learn, including the original LDA data. The small tables printed in each guide contain all the observations used.

    python -m pip install -r requirements.txt
python calculations.py

    Run these commands from this notes folder. The script writes the figures and numerical results into its assets directory. The original PDFs and their page scans are preserved separately.
