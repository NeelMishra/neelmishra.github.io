    Distance Metrics, Feature Scaling & Mahalanobis Geometry in KNN

    October 2026 · 12 min read

    Because KNN has no learned weights $\hat\beta$ to rescale or rotate input coordinates automatically, choosing the distance function $d(x, q)$ and preprocessing the feature scales completely determine which training observations enter the neighborhood $\mathcal N_K(q)$.

    1. Metric Axioms and Why They Matter for Indexing

    A function $d: \mathcal X \times \mathcal X \to [0, \infty)$ is a true metric if for all $x, y, z \in \mathcal X$:

    1. Non-negativity & identity of indiscernibles: $d(x, y) \ge 0$, with $d(x, y) = 0 \iff x = y$.
    2. Symmetry: $d(x, y) = d(y, x)$.
    3. Triangle inequality: $d(x, z) \le d(x, y) + d(y, z)$.

    The triangle inequality is not merely theoretical: exact spatial accelerators like Ball Trees use the lower bound $d(q, x) \ge d(q, c) - R$ (where $c$ is a ball center and $R$ is its radius) to prune entire subtrees without inspecting individual points.

    2. The Minkowski $L_r$ Family: Manhattan, Euclidean, and Chebyshev

    For continuous vectors $x, q \in \mathbb R^p$ and order $r \ge 1$, the Minkowski distance is:

    $$d_r(x, q) = \left(\sum_{j=1}^p |x_j - q_j|^r\right)^{1/r}.$$

    3. Cosine Distance and Exact Equivalence on Unit Vectors

    For text TF-IDF vectors or learned embeddings where direction matters more than vector magnitude, cosine similarity and cosine distance are defined as:

    $$\operatorname{sim}_{\cos}(x, q) = \frac{x^\top q}{\lVert x\rVert_2\,\lVert q\rVert_2}, \qquad d_{\cos}(x, q) = 1 - \operatorname{sim}_{\cos}(x, q).$$

    If every training vector and query vector is first $L_2$-normalized to unit length ($\tilde x = x/\lVert x\rVert_2$, $\tilde q = q/\lVert q\rVert_2$), squared Euclidean distance satisfies:

    $$\lVert \tilde x - \tilde q\rVert_2^2 = \lVert \tilde x\rVert_2^2 + \lVert \tilde q\rVert_2^2 - 2\tilde x^\top \tilde q = 2\bigl(1 - \operatorname{sim}_{\cos}(x, q)\bigr) = 2\,d_{\cos}(x, q).$$

    Thus, ranking by Euclidean distance on $L_2$-normalized vectors produces the exact same $K$ nearest neighbors as ranking by cosine similarity.

    4. Feature Scaling Without Data Leakage

    If feature 1 is measured in dollars ($[20{,}000, 200{,}000]$) and feature 2 in years ($[20, 70]$), then $(x_{i1} - q_1)^2 \sim 10^8$ overwhelms $(x_{i2} - q_2)^2 \sim 10^2$, reducing 2D KNN to a 1D lookup on income alone (see the worked 3-profile calculation in the Handwritten Notes). Three standard scalers address this:

    • Z-score Standardization: $z_{ij} = (x_{ij} - \mu_j)/\sigma_j$, where $\mu_j$ and $\sigma_j$ are the training mean and standard deviation.
    • Min–Max Normalization: $u_{ij} = (x_{ij} - \min_j)/(\max_j - \min_j) \in [0, 1]$ on the training split (sensitive to extreme outliers).
    • Robust Scaling: $r_{ij} = (x_{ij} - \operatorname{median}_j)/\operatorname{IQR}_j$, using the interquartile range $Q_{75} - Q_{25}$ when heavy-tailed outliers would inflate $\sigma_j$.
    Never fit the scaler on the full dataset before splitting. Compute $\mu_j, \sigma_j$ (or $\min_j, \max_j$) strictly on the training rows inside each cross-validation fold, then apply that frozen transformation to validation and test queries.

    5. Mahalanobis Distance: Accounting for Correlated Features

    Standardizing each column independently equalizes marginal variances, but if two features are strongly correlated (or a column is duplicated), Euclidean distance double-counts the shared direction. Given the training sample covariance matrix $\hat\Sigma \in \mathbb R^{p \times p}$, the Mahalanobis distance is:

    $$d_M(x, q) = \sqrt{(x - q)^\top \hat\Sigma^{-1} (x - q)}.$$

    Writing the Cholesky or symmetric square-root factorization $\hat\Sigma^{-1} = W^\top W$, we have $d_M(x, q) = \lVert Wx - Wq\rVert_2$. Mahalanobis distance is therefore equivalent to whitening the feature space so that the training covariance becomes the identity matrix $I_p$, turning tilted elliptical contours into spheres before running ordinary Euclidean KNN.
