    K-Nearest Neighbors (KNN): Overview, Voronoi Geometry & Reading Guide

    October 2026 · 14 min read

    How would you estimate the selling price of a house on your street if you knew no calculus and no regression formulas? You would look up the five most comparable homes that recently sold nearby and average their prices. $K$-Nearest Neighbors (KNN) turns that everyday reasoning into a mathematically rigorous, non-parametric estimator.

    Whereas eager parametric models such as linear regression and logistic regression spend compute at training time to distil the dataset $\mathcal D = \{(x_i, y_i)\}_{i=1}^n$ into a fixed parameter vector $\hat\beta \in \mathbb R^{p+1}$ and then discard the raw rows, KNN is an instance-based (lazy) learner: it stores the training observations (or organizes them into a spatial tree) and defers local estimation until a specific query point $q \in \mathbb R^p$ arrives.

    Looking for the step-by-step handwritten-notes walkthrough? Read the companion K-Nearest Neighbors handwritten-notes guide for a six-point table with exact integer distances, hand-verified $K=1, 3, 5$ majority votes, inverse-distance weights, and the Income-vs.-Age feature scaling calculation.

    1. Lazy vs. Eager Learning: Architectural Trade-Offs

    Before writing formulas, clarify when keeping the raw training set in memory is an engineering superpower—and when it becomes a bottleneck:

    Structural trade-offs between lazy instance-based KNN and eager parametric / tree-based models on $n$ rows and $p$ features.

    2. The Neighborhood Operator and Local Prediction

    Define every symbol explicitly before combining them. Let $\mathcal D = \{(x_i, y_i)\}_{i=1}^n$ be $n$ stored training pairs where each feature vector $x_i \in \mathbb R^p$ has $p$ coordinates and $y_i$ is either a discrete class label in $\{1, \dots, C\}$ or a real regression target in $\mathbb R$. Let $q \in \mathbb R^p$ be a query vector and $d: \mathbb R^p \times \mathbb R^p \to [0, \infty)$ be a chosen distance metric.

    For a fixed query $q$, sort the training indices into a permutation $(1), (2), \dots, (n)$ ordered from closest to farthest from $q$:

    $$d\bigl(x_{(1)}, q\bigr) \le d\bigl(x_{(2)}, q\bigr) \le \cdots \le d\bigl(x_{(K)}, q\bigr) \le \cdots \le d\bigl(x_{(n)}, q\bigr).$$

    Let $K \in \{1, \dots, n\}$ be the chosen integer neighbor count, $r_K(q) = d\bigl(x_{(K)}, q\bigr)$ be the radius to the $K$-th closest training point, and $\mathcal N_K(q) = \{(1), (2), \dots, (K)\}$ be the index set of those $K$ nearest neighbors. Writing $\mathbb I(\cdot)$ for the $0/1$ indicator function ($1$ when its condition holds, $0$ otherwise), unweighted KNN forms local estimates directly over $\mathcal N_K(q)$:

    • Classification posterior & majority vote: $$\hat P(Y = c \mid X = q) = \frac{1}{K}\sum_{i \in \mathcal N_K(q)} \mathbb I(y_i = c), \qquad \hat y(q) = \arg\max_{c \in \{1,\dots,C\}} \hat P(Y = c \mid X = q).$$
    • Regression conditional mean estimate: $$\hat f(q) = \frac{1}{K}\sum_{i \in \mathcal N_K(q)} y_i.$$

    3. Voronoi Tessellations and Decision Boundaries

    Even though KNN stores no hyperplane weights, $1$-NN under Euclidean distance $d(x, q) = \lVert q - x\rVert_2$ induces an exact geometric partition of $\mathbb R^p$. Each training point $x_i$ owns a region $V_i$ called its Voronoi cell—the set of all queries closer to $x_i$ than to any other training point $x_j$:

    $$V_i = \bigl\{q \in \mathbb R^p : \lVert q - x_i\rVert_2 \le \lVert q - x_j\rVert_2 \;\text{for all } j \ne i\bigr\}.$$

    Squaring both norms and canceling $\lVert q\rVert_2^2$ on both sides reveals why every Voronoi cell is a convex polyhedron:

    $$\lVert q\rVert_2^2 - 2x_i^\top q + \lVert x_i\rVert_2^2 \le \lVert q\rVert_2^2 - 2x_j^\top q + \lVert x_j\rVert_2^2 \iff (x_j - x_i)^\top q \le \frac{1}{2}\bigl(\lVert x_j\rVert_2^2 - \lVert x_i\rVert_2^2\bigr).$$

    Each inequality defines a closed half-space bounded by the perpendicular bisector hyperplane halfway between $x_i$ and $x_j$, and the intersection of $n - 1$ half-spaces is always convex. The global $1$-NN decision boundary is the union of Voronoi facets separating cells of different classes. Raising $K$ from $1$ to $5$ replaces single-point ownership with an average over $K$-order Voronoi regions, erasing isolated noise islands.

    4. Why Simple 1-NN Works: Step-by-Step Cover–Hart Derivation

    It is tempting to dismiss $1$-NN—copying the label of a single nearest neighbor without averaging—as statistically naive. Thomas Cover and Peter Hart proved a startling theorem in 1967: with abundant training data in a fixed metric space, even $1$-NN incurs an asymptotic error rate at most twice the lowest error rate achievable by any classifier in existence.

    Follow the proof step by step, defining every probability along the way:

    1. Define the true posterior and the Bayes optimal error $r^*(x)$: In binary classification with $Y \in \{0, 1\}$, let $\eta(x) = P(Y = 1 \mid X = x) \in [0, 1]$ be nature's true conditional probability of Class 1 at input $x$. Even an omniscient oracle that knows $\eta(x)$ exactly must guess $1$ when $\eta(x) \ge 1/2$ and $0$ when $\eta(x) < 1/2$. That oracle is the Bayes optimal classifier $f^*(x) = \mathbb I\bigl(\eta(x) \ge 1/2\bigr)$, and its pointwise error probability at $x$ is $$r^*(x) = \min\bigl\{\eta(x),\, 1 - \eta(x)\bigr\} \in [0, 0.5], \qquad \mathcal R^* = \mathbb E_X\bigl[r^*(X)\bigr].$$ Here $\mathcal R^*$ is the irreducible Bayes risk—no classifier, parametric or deep neural, can ever beat $\mathcal R^*$.
    2. Nearest-neighbor convergence as $n \to \infty$: On a separable metric space, wherever the input density is positive, the closest training point $X_{(1)}$ satisfies $d(X_{(1)}, x) \to 0$ with probability $1$ as $n \to \infty$ (Cover & Hart Lemma). Assuming $\eta(\cdot)$ is continuous at $x$, the neighbor's label $Y_{(1)}$ has conditional success probability $\eta(X_{(1)}) \to \eta(x)$.
    3. Compute the asymptotic $1$-NN conditional error $r_{1\text{-NN}}(x)$: Given $X = x$ and $X_{(1)} \approx x$, the test label $Y$ and the training neighbor's label $Y_{(1)}$ are independent Bernoulli draws with the same parameter $\eta(x)$! A $1$-NN mistake ($Y_{(1)} \ne Y$) occurs in two mutually exclusive ways—either $(Y = 1, Y_{(1)} = 0)$ or $(Y = 0, Y_{(1)} = 1)$: $$r_{1\text{-NN}}(x) = \lim_{n\to\infty} P(Y_{(1)} \ne Y \mid X = x) = \eta(x)\bigl(1 - \eta(x)\bigr) + \bigl(1 - \eta(x)\bigr)\eta(x) = 2\,\eta(x)\bigl(1 - \eta(x)\bigr).$$
    4. Express $r_{1\text{-NN}}(x)$ directly in terms of $r^*(x)$: Whether $r^*(x) = \eta(x)$ (when $\eta \le 1/2$) or $r^*(x) = 1 - \eta(x)$ (when $\eta > 1/2$), the product $\eta(x)\bigl(1 - \eta(x)\bigr)$ equals $r^*(x)\bigl(1 - r^*(x)\bigr)$! Therefore, at every point $x$, $$r_{1\text{-NN}}(x) = 2\,r^*(x)\bigl(1 - r^*(x)\bigr) \le 2\,r^*(x).$$
    5. Integrate over $X$ via Jensen's inequality: Define $g(u) = 2u(1 - u) = 2u - 2u^2$. Because $g''(u) = -4 < 0$, $g$ is strictly concave, so $\mathbb E\bigl[g(r^*(X))\bigr] \le g\bigl(\mathbb E[r^*(X)]\bigr)$. Taking expectations over $X$ yields the Cover–Hart bound: $$\mathcal R^* \;\le\; \mathcal R_{1\text{-NN}}^\infty = \mathbb E\bigl[2r^*(X)\bigl(1 - r^*(X)\bigr)\bigr] \;\le\; 2\,\mathcal R^*(1 - \mathcal R^*) \;\le\; 2\,\mathcal R^*.$$

    For $C \ge 2$ classes, Cover & Hart also proved the tighter multiclass bound $\mathcal R_{1\text{-NN}}^\infty \le \mathcal R^*\bigl(2 - \frac{C}{C-1}\mathcal R^*\bigr)$. Furthermore, if $K$ grows with sample size such that $K \to \infty$ while $K/n \to 0$, local averaging eliminates the factor of $2$ completely and $\mathcal R_{K\text{-NN}} \to \mathcal R^*$ for every distribution of $(X, Y)$ (Stone's universal consistency theorem, 1977).

    5. Dual View: Fixed-Radius Parzen Windows vs. Variable-Radius KNN

    Both Kernel Density Estimation (Parzen windows) and KNN estimate local probability density via $\hat p(q) = \frac{K}{n\,V_K(q)}$, where $V_K(q)$ is the volume of a local ball enclosing $K$ training observations:

    • Parzen / Kernel Density Estimation: fixes the ball radius $h$ (so volume $V_h$ is constant everywhere) and counts how many points $K(q)$ land inside. In sparse tails of $\mathbb R^p$, $K(q)$ can drop to $0$, leaving $\hat P(Y \mid q) = 0/0$ undefined.
    • $K$-Nearest Neighbors: fixes the statistical sample count $K$ and lets the radius $r_K(q)$ adapt automatically—shrinking to high spatial resolution where data is dense and expanding smoothly in sparse regions so $\mathcal N_K(q)$ is never empty.
    Verify Cover–Hart and Stone's K-NN convergence empirically in Python 
    import numpy as np
from scipy.stats import norm
from sklearn.neighbors import KNeighborsClassifier

# 1D binary problem: Class 0 ~ N(-1, 1), Class 1 ~ N(+1, 1) with equal priors (0.5 each)
# Exact Bayes decision boundary is x = 0, so R* = P(N(1, 1) < 0) = Phi(-1) = 0.158655
rng = np.random.default_rng(42)
n_train, n_test = 25_000, 40_000
y_tr = rng.integers(0, 2, size=n_train)
X_tr = rng.normal(np.where(y_tr == 1, 1.0, -1.0), 1.0)[:, None]
y_te = rng.integers(0, 2, size=n_test)
X_te = rng.normal(np.where(y_te == 1, 1.0, -1.0), 1.0)[:, None]

R_star = norm.cdf(-1.0)
cover_hart_bound = 2.0 * R_star * (1.0 - R_star)
err_1nn = np.mean(KNeighborsClassifier(n_neighbors=1).fit(X_tr, y_tr).predict(X_te) != y_te)
err_35nn = np.mean(KNeighborsClassifier(n_neighbors=35).fit(X_tr, y_tr).predict(X_te) != y_te)

print(f"Bayes optimal R*          = {R_star:.4f}")
print(f"1-NN test error           = {err_1nn:.4f}  <= Cover-Hart 2R*(1-R*) = {cover_hart_bound:.4f}")
print(f"35-NN test error          = {err_35nn:.4f}  (approaches R* as K grows!)")
