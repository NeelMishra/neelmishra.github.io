    Linear Discriminant Analysis (LDA)

    September 2026 · 16 min read

    LDA finds a linear projection that separates labeled classes relative to their spread. The labels are part of fitting the projection. This makes it useful when a smaller representation should preserve a particular classification signal.

    Start with the projection idea from PCA. A direction turns each feature vector into one score. LDA changes how we choose that direction: class means should be far apart compared with the variation inside each class. We will work through two classes before briefly extending the idea.

    The widest direction can hide the classes

    Our eight observations have two features. Class A contains (−4, −2), (−4, −1), (4, −2), and (4, −1). Class B contains (−4, 1), (−4, 2), (4, 1), and (4, 2). The first feature varies widely, but both classes have exactly the same first-feature values.

    PCA keeps the horizontal direction first, retaining about 86.5% of the total variance. Its scores put A and B on top of each other. Keeping the vertical direction instead separates all eight training points. Rotate the line to see what happens between those choices:

    This is a controlled training example, not evidence of generalization. It shows why a high PCA variance percentage need not imply a useful class representation.

    Measure separation against the spread inside each class

    Let $w$ be the projection’s feature weights. A point $x_i$ gets score $z_i=w^\top x_i$: multiply its feature values by the corresponding weights and add. Let $\bar z_A$ and $\bar z_B$ be the mean scores for classes A and B.

    We want a large gap between those two means. But a gap of 3 is less useful when each class spreads across scores from −100 to 100 than when each class is tightly grouped. Compare the squared mean gap with the sum of squared deviations from each point’s own class mean. If $y_i$ records point $i$’s class, the two-class Fisher criterion is

    $$F(w)=\frac{(\bar z_B-\bar z_A)^2}{\sum_i(z_i-\bar z_{y_i})^2}.$$

    For the horizontal direction, both means are zero, so the numerator is zero. For the vertical direction, the means are −1.5 and 1.5. The squared gap is 9. Each of eight points is 0.5 from its own class mean, so the denominator is $8\times0.5^2=2$. The ratio is therefore 4.5.

    Multiplying every score by 10 multiplies both parts by 100 and leaves the ratio unchanged. We cannot improve it merely by stretching the score axis. Its value is a separation criterion, not an accuracy or probability.

    Find the direction without trying every angle

    Keep track of spread in the original feature coordinates using the within-class scatter matrix, $S_W$. First subtract each row’s own class mean. Its diagonal entries sum the squared residuals of each feature; its off-diagonal entries sum products of residuals from different features.

    Let $\mu_A,\mu_B$ be the original class-mean vectors, and let $d=\mu_B-\mu_A$ be their difference. When $S_W$ is positive definite, a direction maximizing the ratio is found by solving $S_Ww=d$. In our example:

    $$\underbrace{\begin{bmatrix}128&0\\0&2\end{bmatrix}}_{S_W}\begin{bmatrix}w_1\\w_2\end{bmatrix}=\underbrace{\begin{bmatrix}0\\3\end{bmatrix}}_d.$$

    The first equation gives $w_1=0$; the second gives $w_2=1.5$. Normalize to unit length for an easy-to-read score: $w=(0,1)$. The result keeps the second feature. In general, the off-diagonal entries matter too: LDA adjusts for correlated variation within the classes.

    Optional: why solving that system maximizes the ratio

    For $N$ rows, the matrix just described is $S_W=\sum_{i=1}^N(x_i-\mu_{y_i})(x_i-\mu_{y_i})^\top$. The projected mean gap is $w^\top d$ and the projected within-class scatter is $w^\top S_Ww$.

    Assume $S_W$ is positive definite, so its square root and inverse exist. Define $u=S_W^{1/2}w$ and $v=S_W^{-1/2}d$. The ratio becomes $(u^\top v)^2/(u^\top u)$. By the Cauchy–Schwarz inequality, it is at most $v^\top v$, with equality when $u$ points along $v$. Substituting back gives $w\propto S_W^{-1}d$. In code, solve the system rather than constructing an inverse. The direction has no unique scale or sign.

    If the class means coincide, the numerator is zero in every direction. If the scatter is singular, this inverse-based derivation does not apply; the handling of that case is a modeling and numerical choice.

    Fit with labels; transform new points with the saved direction

    Once the direction is fitted, a new point only needs its features. Use the same weights and score origin as during fitting. Here we put score zero at the midpoint of the two training class means. That midpoint is (0, 0), so a new point (8, 1.2) gets score 1.2.

    Python: fit the direction and compare it with scikit-learn
    import numpy as np
from sklearn.decomposition import PCA
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

X = np.array([[-4, -2], [-4, -1], [4, -2], [4, -1],
              [-4,  1], [-4,  2], [4,  1], [4,  2]], dtype=float)
y = np.repeat([0, 1], 4)  # A = 0, B = 1.
means = np.array([X[y == c].mean(axis=0) for c in [0, 1]])
residuals = X - means[y]  # Center each row at its own class mean.
SW = residuals.T @ residuals
w = np.linalg.solve(SW, means[1] - means[0])
w /= np.linalg.norm(w)  # Fix a convenient score scale.
origin = (means[0] + means[1]) / 2

def transform(new):
    return (np.asarray(new) - origin) @ w

print(SW)                      # [[128, 0], [0, 2]]
print(w)                       # [0, 1]
print(transform([[8, 1.2]]))    # [1.2]

pca = PCA(n_components=1).fit(X)
print(pca.explained_variance_ratio_)  # About [0.8649].
lda = LinearDiscriminantAnalysis(solver="eigen", n_components=1).fit(X, y)
reference_direction = lda.scalings_[:, 0].copy()
reference_direction /= np.linalg.norm(reference_direction)
# Compare axes, allowing an arbitrary sign.
np.testing.assert_allclose(np.outer(w, w),
                           np.outer(reference_direction, reference_direction), atol=1e-10)
# Coordinate scale and origin can differ across implementations.
np.testing.assert_array_equal(lda.predict(X), y)  # Training check, not a test score.

    The NumPy calculation uses a unit-length direction. Library transforms can choose a different scale or origin; compare the learned axis, or align the coordinates, before treating different score values as a bug.

    A projection and a classifier are related choices

    The projection gives a score. A classifier also needs a rule for assigning a class. In our symmetric example, a threshold at zero separates the observed A and B points.

    The usual probabilistic LDA classifier models a Gaussian distribution for each class, with different means but a shared covariance matrix. It combines these models with class priors to make predictions. Those assumptions produce a linear decision boundary. The Fisher separation calculation itself does not require the observations to be Gaussian. Its usefulness on new data still has to be checked.

    Optional: how class priors affect the decision rule

    Let $\Sigma$ be the shared covariance and $q_A,q_B$ the class prior probabilities. Define classifier weights $\beta$ by solving $\Sigma\beta=\mu_B-\mu_A$. The difference between the two class log scores is

    $$\ell_B(x)-\ell_A(x)=\beta^\top\!\left(x-\frac{\mu_A+\mu_B}{2}\right)+\log\frac{q_B}{q_A}.$$

    Choose B when this difference is positive. Equal priors remove the logarithm and put the boundary halfway between the projected means. A larger prior for B shifts the boundary in its favor. Unlike a projection axis, the classifier coefficient scale matters relative to the prior term. The empirical covariance estimate and its normalization therefore matter too.

    Why C classes give at most C − 1 directions

    Multiclass LDA first accounts for the spread within the classes. In the resulting coordinates, two class means define a line; three can span a plane. After centering, $C$ class means span at most $C-1$ dimensions. LDA finds separating directions in that space. With $D$ input features, the maximum output size is $\min(D,C-1)$, and the effective rank may be smaller.

    Two classes therefore yield at most one discriminant component. Requesting more cannot create additional class-mean directions. LDA’s reported explained-variance ratios refer to its discriminant components; they should not be read as PCA percentages of the original data’s variance.

    Where to be careful

    • Class means may miss the signal. If A occupies opposite corners of a square and B occupies the other two corners, both means coincide. Fisher’s numerator is zero, even though the labels have a nonlinear pattern.
    • Within-class scatter can be poorly estimated. Few rows, many features or duplicate features can make it singular or unstable. Regularization or a suitable rank-aware solver may be needed; a tiny denominator is not evidence of reliable separation.
    • Preprocessing is part of the fit. Imputation, feature transformations, solver and regularization choices belong inside training and validation. In exact arithmetic, unregularized LDA can adjust to invertible linear feature rescaling; numerical conditioning and regularization still make preprocessing consequential.
    Scikit-learn solver choices for reduction

    The default solver="svd" supports transform but not shrinkage. The eigen solver supports both transformation and shrinkage; lsqr supports shrinkage but does not implement transform. The n_components setting limits transformed coordinates; it does not limit the classifier’s predict calculation. See the API documentation when choosing a configuration.

    Optional implementation: two features, two classes

    This C++ example fits the Fisher projection and applies it to new points. It solves a 2 × 2 system directly, normalizes the direction, and places the origin halfway between the class means. It rejects singular or nearly singular scatter; adding regularization would be a separate extension.

    C++17: compute means, scatter and the projection
    #include <array>
#include <cmath>
#include <stdexcept>
#include <vector>
using Point = std::array<double, 2>;
struct FisherProjection { Point origin, direction; };

FisherProjection fit_fisher(const std::vector<Point>& X,
                            const std::vector<int>& y) {
    if (X.size() != y.size() || X.empty())
        throw std::invalid_argument("matching nonempty X and y required");
    std::array<std::size_t, 2> count{0, 0};
    for (std::size_t i = 0; i < X.size(); ++i) {
        if (y[i] != 0 && y[i] != 1)
            throw std::invalid_argument("labels must be 0 or 1");
        for (double v : X[i]) if (!std::isfinite(v))
            throw std::invalid_argument("finite features required");
        ++count[y[i]];
    }
    if (count[0] < 2 || count[1] < 2)
        throw std::invalid_argument("need at least two rows in each class");
    std::array<Point, 2> mean{};
    for (std::size_t i = 0; i < X.size(); ++i)
        for (int j = 0; j < 2; ++j) mean[y[i]][j] += X[i][j] / count[y[i]];
    double a = 0, b = 0, c = 0;
    for (std::size_t i = 0; i < X.size(); ++i) {
        double dx = X[i][0] - mean[y[i]][0], dy = X[i][1] - mean[y[i]][1];
        a += dx*dx; b += dx*dy; c += dy*dy;
    }
    if (!std::isfinite(a) || !std::isfinite(b) || !std::isfinite(c))
        throw std::overflow_error("scatter overflow");
    // Rescale the 2x2 system; a common scalar does not change its direction.
    double scale = std::fmax(a, c);
    if (!(scale > 0)) throw std::invalid_argument("zero within-class scatter");
    a /= scale; b /= scale; c /= scale;
    double det = a*c - b*b;
    if (!(det > 1e-12))
        throw std::invalid_argument("singular or ill-conditioned scatter");
    Point d{mean[1][0] - mean[0][0], mean[1][1] - mean[0][1]};
    Point u{(c*d[0] - b*d[1])/det, (a*d[1] - b*d[0])/det};
    double length = std::hypot(u[0], u[1]);
    if (!std::isfinite(length)) throw std::overflow_error("direction overflow");
    if (!(length > 0)) throw std::invalid_argument("identical class means");
    return {{mean[0][0]/2 + mean[1][0]/2, mean[0][1]/2 + mean[1][1]/2},
            {u[0]/length, u[1]/length}};
}

double transform(const FisherProjection& model, const Point& x) {
    for (double v : x) if (!std::isfinite(v))
        throw std::invalid_argument("finite new point required");
    double z = (x[0] - model.origin[0])*model.direction[0]
             + (x[1] - model.origin[1])*model.direction[1];
    if (!std::isfinite(z)) throw std::overflow_error("score overflow");
    return z;
}

    With the eight rows above and labels {0, 0, 0, 0, 1, 1, 1, 1}, fit_fisher returns direction (0, 1), and transform(model, {8, 1.2}) returns 1.2. The determinant cutoff is a simple numerical guard for this teaching implementation, not an automatic regularization method.
