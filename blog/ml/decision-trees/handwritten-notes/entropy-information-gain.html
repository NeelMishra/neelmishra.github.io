    Entropy, Gini & Information Gain

    September 2026 · 4 min read

    The scan introduces a way to compare candidate splits: measure how mixed the labels are before and after splitting. This companion keeps the notation consistent; the worked impurity chapter supplies the longer explanation.

    Turn class proportions into uncertainty

    A node containing only A has no training-label uncertainty. An equal mix of A and B has more. Let $p_k$ be the fraction of rows belonging to class $k$. Using base-2 logarithms, entropy is measured in bits:

    $$H=-\sum_k p_k\log_2 p_k.$$

    An absent class contributes zero. An equal two-class mixture gives 1 bit; a pure node gives 0. The logarithm’s base must be specified before interpreting the units.

    A second way to measure the mixture

    Using the same proportions, Gini impurity is $G=1-\sum_k p_k^2$. It is the chance that two independently drawn labels from the node disagree. A 50/50 mixture gives 0.5; a pure node gives 0.

    Gini and entropy have different numeric scales. Both favor concentrated child labels, but they can select different splits. Avoiding logarithms alone does not establish a meaningful training-speed advantage.

    Subtract the children’s weighted uncertainty

    A child containing three quarters of the parent’s rows should count three times as much as the other child. If their entropies are 0.8 and 0, the average after splitting is 0.75 × 0.8 + 0.25 × 0 = 0.6 bits. Subtract this from the parent’s entropy to obtain information gain.

    The figure calculates gain for ordered labels A, A, B, A, B, B, B, B. It includes each child’s row fraction when comparing thresholds.

    Eight points carry two classes (green = A, orange = B). Each candidate threshold splits them into left and right sets; the bars show each side's entropy, and the running best information gain is tracked.

    Read ID3 as a greedy construction rule

    ID3 selects a feature using information gain, creates its branches, and repeats on the rows in each branch. A pure node becomes a leaf; when no usable feature remains, a mixed node needs a fallback such as its majority class.

    The threshold animation illustrates entropy-based binary splitting. Classic categorical ID3 can make more than two branches, so the animation is not a complete implementation of that original algorithm. Continue to the entropy/KL connection if you want the information-theory interpretation.
