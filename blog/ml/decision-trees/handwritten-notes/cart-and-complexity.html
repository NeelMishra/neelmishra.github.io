    CART, Complexity & Pruning

    September 2026 · 4 min read

    This page reads the scan in three pieces: what a regression leaf predicts, how the threshold search reuses work, and how tree size affects generalization.

    A regression leaf predicts an average

    For targets 2, 4, and 9, the mean is 5. Predicting 5 gives squared errors 9, 1, and 16, totaling 26. Training looks for splits that reduce this cost across the children.

    Let $S$ be the rows in a node, $y_i$ their targets, and $\bar y_S$ their mean. The total squared error is:

    $$L(S)=\sum_{i\in S}(y_i-\bar y_S)^2.$$

    If an implementation uses mean squared error instead, weight each child by its row fraction when combining scores. If it uses total squared error, add the child totals directly.

    Avoid rescanning every candidate’s rows

    Let $N$ be the node’s row count, $D$ the feature count, and $K$ the class count. A naive classification search repeatedly counts labels for up to $N$ boundaries per feature, doing roughly $O(D(N^2+NK))$ work. The repeated row scans are the expensive part.

    Sort once, then update the two sides

    Sorting one feature costs $O(N\log N)$. Move rows from right to left while maintaining class counts. If each candidate’s impurity is recomputed from its $K$ counts, the sweep costs $O(NK)$. Across all features, the node’s search costs $O(D(N\log N+NK))$.

    ▶ The Sorted Sweep: One Counter Changes per Step

    Each moved row increments one left class count and decrements one right class count. Updating those counters is constant work; scoring all class proportions can require more work.

    With fixed $K$, sorting dominates. More elaborate running impurity statistics can also avoid a full class-count scan. The implementation note handles repeated values and numeric boundaries.

    Give extra leaves a reason to stay

    Depth limits and minimum leaf sizes stop growth early. Post-pruning removes branches from a grown tree. Cost-complexity pruning charges for each retained leaf; the pruning chapter explains that objective and its example.

    Select these controls using validation data. Pruning trades training fit for simplicity; it does not automatically identify which splits represent noise.

    Read depth as a capacity control

    A shallow tree may be too coarse for the task. A deep tree can fit finer patterns but may react strongly to small changes in training data. These are tendencies to evaluate, not guarantees that every shallow tree underfits or every deep tree overfits.
