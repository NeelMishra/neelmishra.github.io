    Bagging: From One Unstable Tree to a Forest

    September 2026 · 11 min read

    An unpruned decision tree is like an expert who memorizes every quirk of the cases on their desk: expressive enough to capture sharp non-linear interactions (low bias), yet brittle when a handful of training rows change (high variance). Because tree splits are chosen greedily from the root downward, shifting one early threshold changes every descendant region and alters predictions across feature space. Bootstrap Aggregation (Bagging), introduced by Leo Breiman (1996), asks a direct question: if we cannot collect $B$ fresh datasets from the real world, can we stabilize a high-variance learner by training $B$ trees in parallel on resampled copies of the data we already have and averaging their answers?

    This chapter builds the intuition, derives the exact correlated-estimator variance equation that governs every randomized forest, and maps out the five-part Bagging series. If you want a refresher on how a single CART node selects a threshold and computes a leaf value, start with the Decision Tree foundations.

    1. Plain-English Intuition: Why a Committee Beats a Soloist

    Suppose three regression trees estimate the rent of the same apartment at $\$2{,}100$, $\$2{,}700$, and $\$2{,}400$, while the true market average for similar apartments is $\$2{,}450$. Individually, the first tree under-predicts by $\$350$ and the second over-predicts by $\$250$. Their simple average is $\$2{,}400$—within $\$50$ of the truth—because upward and downward errors partially cancel.

    Notice two immediate boundaries on when this committee trick works:

    • Deterministic learners need perturbed inputs: Training the exact same deterministic CART algorithm five times on identical training rows produces five identical copies of the same tree. Averaging $[2100, 2100, 2100, 2100, 2100]$ still yields $2100$. To create productive disagreement without new data, bagging draws each tree's training set of size $n$ with replacement (a bootstrap sample), duplicating some rows and omitting roughly $(1 - 1/n)^n \approx e^{-1} \approx 36.8\%$ of the rows as out-of-bag (OOB) examples.
    • Averaging reduces variance, not bias: If every tree systematically under-prices penthouse apartments by $\$400$ because all trees are depth-1 stumps, averaging 500 stumps simply converges to that same $\$400$ under-estimate. Bagging shines when base learners have low bias and high variance—such as deep, unpruned decision trees—whereas sequential boosting targets high-bias shallow learners.

    2. The Correlated-Estimator Variance Identity

    Why doesn't adding infinitely many bootstrap trees drive prediction variance all the way to zero? Because two bootstrap samples drawn from the same finite training set $\mathcal D$ share roughly $1 - (1 - 2/n + 1/n^n) \approx 40\%$–$63\%$ of their unique rows, their fitted trees remain positively correlated across repeated draws of $\mathcal D$.

    Fix a query point $x_0$ and define every symbol explicitly:

    • $Z_b = \hat T_b(x_0)$: the prediction of the $b$-th randomized tree at $x_0$ ($b = 1, \dots, B$), viewed as a random variable over repeated draws of the training set $\mathcal D$ and the resampling seed.
    • $\bar Z = \frac{1}{B}\sum_{b=1}^B Z_b$: the ensemble average prediction across all $B$ trees.
    • $\mu = \mathbb E[Z_b]$: the expected prediction of one tree (so $\mathbb E[\bar Z] = \mu$—averaging leaves bias unchanged!).
    • $\sigma^2 = \operatorname{Var}(Z_b) > 0$: the pointwise prediction variance of a single tree.
    • $\rho = \frac{\operatorname{Cov}(Z_b, Z_{b'})}{\sigma^2}$ for $b \ne b'$: the average pairwise Pearson correlation between two distinct trees in the ensemble.

    Expanding the variance of the sum $\sum_{b=1}^B Z_b$ into $B$ diagonal variance terms and $B(B-1)$ off-diagonal covariance terms gives the fundamental variance law of bagging and random forests:

    $$\begin{aligned} \operatorname{Var}(\bar Z) &= \frac{1}{B^2}\left(\sum_{b=1}^B \operatorname{Var}(Z_b) + \sum_{b=1}^B \sum_{b' \ne b} \operatorname{Cov}(Z_b, Z_{b'})\right) \\ &= \frac{B\sigma^2 + B(B - 1)\rho\sigma^2}{B^2} = \rho\sigma^2 + \frac{1 - \rho}{B}\sigma^2. \end{aligned}$$

    Read the two pieces on the right-hand side separately:

    1. The finite-committee term $\frac{1-\rho}{B}\sigma^2$: shrinks at rate $O(1/B)$ as you train more trees. Increasing n_estimators ($B$) never causes variance-driven overfitting; it simply removes Monte Carlo resampling noise.
    2. The correlation floor $\rho\sigma^2$: never disappears no matter how large $B$ grows ($\lim_{B\to\infty}\operatorname{Var}(\bar Z) = \rho\sigma^2$). When one dominant feature forces every bagged tree to make the same top-level split ($\rho \approx 0.4$–$0.7$), bagging hits a high ceiling—motivating Random Forests, which restrict each split search to a random subset of $m_{\text{try}} < p$ features to push $\rho$ down!

    3. Comparing the Randomized Tree Ensemble Family

    Once you view ensemble building through two independent knobs—how rows are sampled, how features are sampled, and how thresholds are chosen—five classic algorithms organize into one unified table:

    Side-by-side comparison of randomized parallel ensembles in scikit-learn and statistical learning literature.
    Method Row Sampling Feature Sampling Threshold Search OOB Score? Bias / Variance & Speed Profile
    Bagging
    (Breiman, 1996)    		 Bootstrap ($n$ with replacement) All $p$ features at every node Exact greedy impurity scan Yes ($\approx 36.8\%$ OOB per tree) Lowest per-tree bias, highest $\rho$ when strong predictors dominate.
    Pasting
    (Breiman, 1999)    		 Subsample $s < n$ without replacement All $p$ features Exact greedy scan Yes (unused $n - s$ rows) Useful on massive datasets where $s \ll n$ fits comfortably in RAM.
    Random Subspaces
    (Ho, 1998)    		 All $n$ rows (no row resampling) Subset $m < p$ fixed per tree Exact greedy scan No (every row used) Strong on wide correlated data ($p \gg n$), weak if $m$ misses key signals for an entire tree.
    Random Forests
    (Breiman, 2001)    		 Bootstrap ($n$ with replacement) Fresh random $m_{\text{try}} < p$ at each node Exact greedy scan on $m_{\text{try}}$ features Yes Gold-standard default: fresh per-node subsets lower $\rho$ without starving a whole tree of top features.
    Extra-Trees
    (Geurts et al., 2006)    		 Usually all $n$ rows (bootstrap=False) Fresh random $m_{\text{try}} \le p$ at each node 1 random cut per candidate feature, pick best Only if bootstrap=True Lowest $\rho$ and fastest training (skips threshold sweeps), at the cost of slightly higher bias.
    Verify the correlated-estimator variance law empirically in Python 
    import numpy as np

rng = np.random.default_rng(42)
trials, B_max, sigma2, rho = 40_000, 500, 10.0, 0.4
# Generate equicorrelated normal predictions Z_b = sqrt(rho)*shared + sqrt(1-rho)*idiosyncratic
shared = rng.normal(0.0, np.sqrt(rho * sigma2), size=(trials, 1))
idio = rng.normal(0.0, np.sqrt((1.0 - rho) * sigma2), size=(trials, B_max))
Z = shared + idio

for B in [1, 5, 50, 500]:
    emp_var = Z[:, :B].mean(axis=1).var()
    exact_var = rho * sigma2 + ((1.0 - rho) / B) * sigma2
    print(f"B={B:3d} | exact={exact_var:6.3f} | empirical={emp_var:6.3f}")
