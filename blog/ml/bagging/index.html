    Bagging: From One Unstable Tree to a Forest

    September 2026 · 4 min read

    A decision tree can change sharply when a few training rows change. A different first split changes the later questions, so the final prediction may move even when the underlying problem has barely changed. Bagging asks: can we stabilize that prediction by averaging several plausible trees?

    This path starts with the sampling mechanism and ends with the decisions you need to defend in an interview. You need to know how a tree chooses a split and predicts from a leaf; the tree foundations explain those steps. No probability beyond averages is needed to begin; derivations appear after examples.

    One model, then a committee

    Imagine training three regression trees that predict 4, 7, and 7 for the same apartment. Their average is 6. The arithmetic is easy. The important question is why those trees disagree: we train them on different resamples of the same training data. That creates variation we can average over, without collecting new labels.

    If every tree makes exactly the same mistake, averaging repeats it. If some predict too high while others predict too low, their fluctuations partly cancel. This is the thread connecting bootstrapping, the variance formula, and random forests.

    Read in order, then explain it back

    1. Bootstrap aggregation and random forests

      Draw rows with replacement, average predictions, derive the correlation floor, and compute an out-of-bag score from actual fitted stumps.

    2. Continue to boosting

      Once you know what averaging can fix, study a different idea: teach the next learner to correct the current ensemble.

    Before opening the next chapter

    Try explaining why training the same deterministic tree five times on identical rows does not create five useful independent opinions. Then ask what training with replacement changes. Keep that question in mind as you follow the five-row example.

    Learning target: be able to trace one row through sampling, fitting, prediction, and evaluation. Saying “bagging reduces variance” is only the starting point; you should be able to explain when and why.
