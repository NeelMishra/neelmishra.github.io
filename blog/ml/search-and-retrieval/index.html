    Search & Retrieval: Reading Guide

    September 2026 · 3 min read

    Understand approximate search algorithms, benchmark the index, and follow the linked evaluation series from judgments to online experiments.

    Reading order

    01
    HNSW and Annoy: Two Ways to Avoid Comparing Every Vector

    Trace graph navigation and random-projection trees, distinguish build and search parameters, and understand exact reranking of approximate candidates.

    02
    Benchmark Vector Search: Recall, Tail Latency, Memory, and Filters

    Build an exact baseline, measure approximation under a controlled workload, and report a quality–cost curve rather than one unexplained latency number.

    Evaluate the system, from relevance to user outcomes

    Continue to the seven-part evaluation series: ground truth, precision/recall/MAP/MRR, nDCG, stage diagnosis, uncertainty, online tests, and RAG evaluation.

    How to use these notes

    Start with the worked example in each chapter. Calculate the answer before changing the interactive figure, then use the self-check to test the distinction the chapter teaches. The numerical examples are deliberately small enough to audit by hand; they are teaching examples, not production benchmarks.

    Follow the prerequisites when a concept is unfamiliar. Related notes link to existing foundations so each chapter can concentrate on its own question.
