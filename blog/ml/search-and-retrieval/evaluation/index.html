    Search & Retrieval · Evaluation: Reading Guide

    September 2026 · 3 min read

    A complete evaluation sequence: define relevance, compute ranking metrics, diagnose pipeline stages, estimate uncertainty, and validate user outcomes.

    Reading order

    01
    Search Evaluation Starts with Relevance, Not a Metric

    Build query sets and relevance judgments, handle incomplete labels, and prevent temporal and entity leakage before computing a score.

    02
    Precision, Recall, MAP, and MRR: One Ranking, Four Questions

    Compute every metric by hand, distinguish AP from precision, state AP@K conventions, and explore rankings directly.

    03
    nDCG: How Much Does the Order of Useful Results Matter?

    Derive DCG and nDCG with graded relevance, compare gain functions, and separate ranking quality from diversity and catalog coverage.

    04
    Evaluate Retrieval and Reranking Separately

    Distinguish ANN recall from relevance recall, calculate a candidate-set ceiling, and diagnose losses at each search stage.

    05
    Did Search Improve? Paired Tests, Bootstrap Intervals, and Slices

    Estimate uncertainty over queries, preserve pairing, handle repeated users, and distinguish statistical evidence from product significance.

    06
    Clicks Are Feedback, Not Relevance Labels

    Understand position bias, exposure, inverse propensity weighting, randomized experiments, and the gap between offline ranking gains and user outcomes.

    07
    RAG Evaluation: Find the Evidence, Use It, and Cite It

    Separate evidence retrieval, context construction, answer correctness, faithfulness, citation quality, and abstention with controlled counterfactuals.

    How to use these notes

    Start with the worked example in each chapter. Calculate the answer before changing the interactive figure, then use the self-check to test the distinction the chapter teaches. The numerical examples are deliberately small enough to audit by hand; they are teaching examples, not production benchmarks.

    Follow the prerequisites when a concept is unfamiliar. Related notes link to existing foundations so each chapter can concentrate on its own question.

    Download the runnable ranking-metrics lab. It uses only the Python standard library and implements the conventions used in these chapters, including explicit policies for unjudged results and queries with no known relevant documents.
