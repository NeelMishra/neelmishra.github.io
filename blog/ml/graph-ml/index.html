    Graph ML for Risk Modeling: Reading Guide

    September 2026 · 3 min read

    Build a graph, turn relationships into evidence, and test whether that evidence survives a realistic deployment split.

    Reading order

    01
    Graph-Based Risk Modeling: Start with the Relationships

    Build a typed application graph, distinguish strong and weak relations, and avoid turning shared infrastructure into guilt by association.

    02
    From Neighborhood Evidence to a Risk Score

    Compute weighted graph features, smooth small neighborhoods, distinguish propagation from message passing, and combine graph evidence with a tabular model.

    03
    Evaluate Graph Risk at a Fixed Precision and a Realistic Time Cutoff

    Choose operating thresholds without test leakage, evaluate connected and unseen entities, and separate graph gains from investigation bias.

    How to use these notes

    Start with the worked example in each chapter. Calculate the answer before changing the interactive figure, then use the self-check to test the distinction the chapter teaches. The numerical examples are deliberately small enough to audit by hand; they are teaching examples, not production benchmarks.

    Follow the prerequisites when a concept is unfamiliar. Related notes link to existing foundations so each chapter can concentrate on its own question.
