    Regression: Overview and Model Guide

    July 2026 · 15 min read

    Every regression problem starts with a practical question: given observed inputs $X$ (such as study hours, square footage, or dosage), what should we expect for an outcome $Y$? Rather than memorizing noisy individual rows, regression estimates a systematic summary of $Y$ at each value of $X$—most often the conditional average, a class probability, a quantile, or an event rate.

    Choosing the right regression model is much easier once you inspect two things first: the support of $Y$ (which numerical values $Y$ can legally take) and the estimand (which property of $Y\mid X$ your decision requires). An unrestricted continuous quantity usually starts with linear regression. A $0/1$ event starts with logistic regression. Nonnegative counts, skewed positive amounts, and right-censored survival times call for specialized families so predictions respect the geometry of the outcome.

    This page is the entry map for the entire regression series. It shows how linear and logistic regression build on the same linear score, proves why their link and loss functions differ on a hand-checkable six-row dataset, previews what statistical assumptions actually buy, and routes each modeling problem to the right chapter.

    Average Value Versus Class Probability

    Suppose we observe $n$ data rows. Row $i$ has a predictor vector $x_i \in \mathbb{R}^p$ (for $p$ raw features) and a scalar response $y_i$. Even among population members with the exact same feature vector $x$, outcomes vary because of unmeasured factors and randomness. Squared-error regression targets the population conditional mean:

    $$\mu(x) = E[Y \mid X = x].$$

    When the outcome is binary, $Y \in \{0, 1\}$, the conditional mean simplifies directly to the probability of a positive event:

    $$E[Y \mid X = x] = 0 \cdot P(Y = 0 \mid X = x) + 1 \cdot P(Y = 1 \mid X = x) = P(Y = 1 \mid X = x).$$

    Linear regression and logistic regression therefore ask the same foundational question—what is $E[Y \mid X = x]$?—under different constraints on $Y$. A general continuous mean can be any real number in $(-\infty, \infty)$, whereas a probability must stay inside $[0, 1]$ and its sampling variance $p(x)\big(1 - p(x)\big)$ automatically shrinks near $0$ and $1$.

    One Linear Score, Different Link and Loss Functions

    Both models begin by prepending a $1$ for the intercept $\beta_0$ to form an augmented feature row $\phi(x) = (1, x_1, \ldots, x_p)^\top \in \mathbb{R}^{p+1}$ (optionally including engineered terms such as $x_1^2$ or $x_1 x_2$). Multiplying by the parameter vector $\beta = (\beta_0, \beta_1, \ldots, \beta_p)^\top$ produces a single real-valued linear predictor (or score) $s$:

    $$s(x) = \phi(x)^\top \beta = \beta_0 + \sum_{j=1}^p \beta_j x_j.$$

    A link function $g(\cdot)$ bridges the conditional mean $\mu(x) = E[Y \mid X = x]$ to this unbounded score via $g\big(\mu(x)\big) = s(x)$:

    • Linear regression (identity link): $g(\mu) = \mu$, so $\hat\mu(x) = s(x)$. Coefficients are fitted by minimizing residual sum of squares $\sum_{i=1}^n (y_i - s(x_i))^2$, because expected squared error $E[(Y - a)^2 \mid X = x]$ is uniquely minimized at $a = E[Y \mid X = x]$.
    • Logistic regression (logit link): $g(p) = \log\frac{p}{1 - p} = s(x)$, modeling log-odds linearly. Inverting the logit applies the logistic sigmoid $\sigma(s) = \frac{1}{1 + e^{-s}} \in (0, 1)$. Coefficients are fitted by minimizing negative Bernoulli log-likelihood (log-loss) $-\sum_{i=1}^n \big[y_i \log \hat p_i + (1 - y_i)\log(1 - \hat p_i)\big]$, a strictly proper scoring rule minimized at the true conditional probability $P(Y = 1 \mid X = x)$.
    • Classification thresholds come second: Logistic regression outputs calibrated probabilities, not hard $0/1$ labels. Converting $\hat p(x)$ into an action uses a separate decision threshold $\tau \in (0, 1)$ determined by false-positive and false-negative costs.

    Check the algebra on $y_{\text{bin}}$: here $\bar x = 3.5$, $\bar y_{\text{bin}} = 0.5$, $S_{xx} = \sum_{i=1}^6 (x_i - 3.5)^2 = 17.5$, and $S_{xy} = \sum_{i=1}^6 (x_i - 3.5)(y_{\text{bin},i} - 0.5) = 3.5$. Ordinary least squares therefore produces the exact rational line $\hat p_{\text{LPM}}(x) = -0.2 + 0.2x$. Inside $x \in [2, 5]$ it looks reasonable, but at $x = 0$ it predicts $-0.20$ and at $x = 8$ it predicts $1.40$. By contrast, logistic regression finds $\hat\beta_{\text{logit}} = (-4.2491, 1.2140)^\top$, whose $50\%$ probability point sits smoothly at $x = 4.2491 / 1.2140 = 3.5000$ while saturating toward $0$ and $1$ at the tails.

    Interview trap: What robust standard errors fix—and do not fix—in the Linear Probability Model. When $Y \in \{0, 1\}$, the conditional error variance is $\operatorname{Var}(Y \mid X = x) = p(x)\big(1 - p(x)\big)$, which changes with $x$ whenever the slope is nonzero. Heteroscedasticity-consistent (HC) standard errors repair the invalid homoscedastic OLS variance formula, and LPM slopes can approximate average marginal effects near the center of the data. However, HC standard errors do not prevent fitted probabilities below $0$ or above $1$, and constant marginal effects $\partial p / \partial x_j = \beta_j$ cannot hold globally for a bounded outcome.

    Failure Modes Shared Across Every Regression Family

    • Target leakage: Including any feature recorded or updated after the outcome occurs (or fitting scalers, imputers, or feature selectors on the full dataset before splitting) inflates validation metrics while failing in production.
    • Omitted confounding: Coefficients measure conditional associations given the included columns. Turning $\hat\beta_j$ into a causal claim requires an identification argument (randomization, natural experiment, or credible adjustment set), never a small $p$-value alone.
    • Multicollinearity: Strongly correlated columns leave in-support predictions stable while making individual coefficients noisy and sensitive to tiny sample changes.
    • Unsupported extrapolation: Evaluating $\phi(x_0)^\top \hat\beta$ far outside the training feature hull trusts the Parametric shape where zero observations exist to verify it.

    Reproduce the Six-Row Comparison

    The script below verifies the exact rational LPM fit $\hat p_{\text{LPM}}(x) = -0.2 + 0.2x$, the continuous OLS fit, and the binary logistic MLE on the six-row dataset.

    Show the complete numerical check 
    import numpy as np
from scipy import optimize

x = np.array([1., 2., 3., 4., 5., 6.])
y_cont = np.array([2.2, 3.8, 5.1, 5.6, 7.4, 8.3])
y_bin = np.array([0., 0., 1., 0., 1., 1.])
X = np.column_stack([np.ones_like(x), x])

beta_cont = np.linalg.lstsq(X, y_cont, rcond=None)[0]
beta_lpm = np.linalg.lstsq(X, y_bin, rcond=None)[0]
assert np.allclose(beta_cont, [1.22, 20.9 / 17.5])
assert np.allclose(beta_lpm, [-0.2, 0.2])

def neg_log_likelihood(beta):
    score = X @ beta
    return np.sum(np.logaddexp(0.0, score) - y_bin * score)

res = optimize.minimize(neg_log_likelihood, np.zeros(2), method="BFGS")
beta_logit = res.x
assert np.allclose(beta_logit, [-4.24909843, 1.21402848], atol=1e-6)

grid = np.array([0., 1., 2., 3., 4., 5., 6., 8.])
Xg = np.column_stack([np.ones_like(grid), grid])
p_lpm = Xg @ beta_lpm
p_logit = 1.0 / (1.0 + np.exp(-(Xg @ beta_logit)))
for xv, pl, pg in zip(grid, p_lpm, p_logit):
    print(f"x={xv:3.0f} | LPM={pl:7.4f} | Logistic={pg:7.4f}")
