    Linear Regression: Essential Interview Derivations

    July 2026 · 19 min read

    Strong interview answers never stop at reciting $\hat\beta = (X^\top X)^{-1}X^\top y$. Interviewers probe which exact assumption makes each step legal and what still survives when that assumption fails. Below are the nine foundational derivations of the linear-regression track—each self-contained in four to six lines, paired with its exact failure boundary and verified on a single four-row reference dataset ($X \in \mathbb{R}^{n \times p}$ denotes the $n \times p$ design matrix with $p$ total columns unless partitioned).

    1. Normal Equations, Global Convexity, and Rank Uniqueness

    Assumptions: Real $X \in \mathbb{R}^{n \times p}$ and $y \in \mathbb{R}^n$ (no probabilistic assumptions). Expand $L(b) := \|y - Xb\|_2^2 = y^\top y - 2b^\top X^\top y + b^\top X^\top X b$:

    $$\nabla_b L(b) = -2X^\top y + 2X^\top X b = 0 \iff X^\top X \hat\beta = X^\top y, \qquad \nabla_b^2 L(b) = 2X^\top X \succeq 0.$$

    Equivalently, for any $\hat\beta$ solving $X^\top(y - X\hat\beta) = 0$ ($e := y - X\hat\beta$) and any $b \in \mathbb{R}^p$, $\|y - Xb\|_2^2 = \|e + X(\hat\beta - b)\|_2^2 = \|e\|_2^2 + \|X(\hat\beta - b)\|_2^2 \ge \|e\|_2^2$.

    Boundary trap: When $\operatorname{rank}(X) < p$, $X^\top X$ is singular so $\hat\beta$ is nonunique ($\hat\beta^+ + \mathcal{N}(X)$), yet the fitted projection $\hat y = X\hat\beta = X X^+ y$ and residual $e$ remain strictly unique!

    2. Orthogonal Projection, Hat Matrix $H$, and Centered $R^2$

    Assumptions: $\operatorname{rank}(X) = p$ ($H := X(X^\top X)^{-1}X^\top$; or $H = X X^+$ at rank $r$). Direct multiplication gives $H^\top = H$, $H^2 = H$, $(I_n - H)H = 0$, and $\operatorname{tr}(H) = \operatorname{tr}(I_r) = r$. Because $\hat y = Hy \perp e = (I_n - H)y$ ($\hat y^\top e = y^\top H(I_n - H)y = 0$),

    $$\|y\|_2^2 = \|\hat y\|_2^2 + \|e\|_2^2.$$

    Boundary trap: The centered ANOVA split $\text{SST} = \text{SSR} + \text{SSE}$ and $R^2 = 1 - \text{SSE}/\text{SST} \in [0, 1]$ require both $\mathbf{1}_n \in \mathcal{C}(X)$ (an intercept, ensuring $\mathbf{1}_n^\top e = 0$ and $(\hat y - \bar y\mathbf{1}_n)^\top e = 0$) and non-constant target $S_{yy} = \text{SST} > 0$.

    3. Unbiasedness, Unbiased $s^2 = \text{SSE}/(n - p)$, and Sandwich Covariance

    Assumptions: $y = X\beta + \varepsilon$, $\operatorname{rank}(X) = p$, and strict exogeneity $E[\varepsilon \mid X] = 0$. Then $\hat\beta - \beta = (X^\top X)^{-1}X^\top\varepsilon$ gives $E[\hat\beta \mid X] = \beta$. For $\Omega := \operatorname{Var}(\varepsilon \mid X)$,

    $$\operatorname{Var}(\hat\beta \mid X) = (X^\top X)^{-1} X^\top \Omega X (X^\top X)^{-1} \;\xrightarrow{\Omega = \sigma^2 I_n}\; \sigma^2(X^\top X)^{-1}.$$

    Under $\Omega = \sigma^2 I_n$ and $n > p$, $e = (I_n - H)\varepsilon$ implies $E[\text{SSE} \mid X] = \operatorname{tr}((I_n - H)\sigma^2 I_n) = \sigma^2(n - p)$, so $E[s^2 \mid X] = \sigma^2$.

    Boundary trap: Heteroscedasticity ($\Omega \ne \sigma^2 I_n$) leaves $\hat\beta$ unbiased under $E[\varepsilon \mid X] = 0$ while invalidating $\sigma^2(X^\top X)^{-1}$ (use HC3); normality is needed only for exact finite-sample $t_{n-p}$ and $F_{q, n-p}$ laws.

    4. Gauss-Markov Theorem: OLS Is BLUE

    Assumptions: $y = X\beta + \varepsilon$, $\operatorname{rank}(X) = p$, $E[\varepsilon \mid X] = 0$, $\operatorname{Var}(\varepsilon \mid X) = \sigma^2 I_n$. Any linear estimator $\tilde\beta = C y$ satisfying $E[\tilde\beta \mid X] = C X \beta = \beta$ for all $\beta \in \mathbb{R}^p$ obeys $CX = I_p$. Let $D := C - (X^\top X)^{-1}X^\top$; then $DX = 0$, so

    $$\operatorname{Var}(\tilde\beta \mid X) = \sigma^2 C C^\top = \sigma^2(X^\top X)^{-1} + \sigma^2 D D^\top \succeq \operatorname{Var}(\hat\beta \mid X).$$

    Boundary trap: BLUE restricts to linear unbiased estimators under spherical variance. Biased Ridge can achieve lower MSE; under $\Omega \ne \sigma^2 I_n$, GLS $(X^\top\Omega^{-1}X)^{-1}X^\top\Omega^{-1}y$ is BLUE; under heavy tails, LAD/Huber can achieve lower asymptotic variance.

    5. Expected Squared Prediction Error (Bias-Variance-Noise Split)

    Assumptions: At fixed query $x_0$, $Y_0 = f(x_0) + \varepsilon_0$ with $E[\varepsilon_0] = 0$, $\operatorname{Var}(\varepsilon_0) = \sigma_0^2$, and $\varepsilon_0$ independent of training draw $D$. Let $\mu_{\hat f} := E_D[\hat f_D(x_0)]$ and decompose $Y_0 - \hat f_D(x_0) = \varepsilon_0 + (f(x_0) - \mu_{\hat f}) + (\mu_{\hat f} - \hat f_D(x_0))$:

    $$E_{D,\varepsilon_0}\!\left[(Y_0 - \hat f_D(x_0))^2\right] = \sigma_0^2 + \big(\mu_{\hat f} - f(x_0)\big)^2 + E_D\!\left[(\hat f_D(x_0) - \mu_{\hat f})^2\right] = \sigma_0^2 + \operatorname{Bias}^2 + \operatorname{Var}.$$

    Boundary trap: Population $\operatorname{Bias}^2$ depends on the unknown true $f(x_0)$ (or $\beta$). In a single observed dataset, shrinking $\hat\beta_1 \mapsto k\hat\beta_1$ ($k \in (0, 1)$) produces an observable sample shrinkage $(k - 1)\hat\beta_1$, which must not be conflated with population bias $(k - 1)\beta_1$!

    6. Ridge Closed Form, Unpenalized Intercept, and Bias vs. Shrinkage

    Assumptions: Symmetric PSD penalty matrix $\Lambda \succeq 0$ such that $X^\top X + \Lambda \succ 0$ (e.g., all-parameter $\Lambda = \lambda I_p$ for any $\lambda > 0$, or standard unpenalized-intercept $\Lambda_0 = \lambda \operatorname{diag}(0, 1, \ldots, 1)$ when $\mathbf{1}_n \ne 0$). Minimizing $\|y - Xb\|_2^2 + b^\top \Lambda b$ gives

    $$\hat\beta_\Lambda = (X^\top X + \Lambda)^{-1} X^\top y = (X^\top X + \Lambda)^{-1}(X^\top X)\hat\beta_{\text{OLS}},$$ $$E[\hat\beta_\Lambda - \beta \mid X] = -(X^\top X + \Lambda)^{-1}\Lambda \beta \quad (\text{population bias}), \qquad \hat\beta_\Lambda - \hat\beta_{\text{OLS}} = -(X^\top X + \Lambda)^{-1}\Lambda \hat\beta_{\text{OLS}} \quad (\text{sample shrinkage}).$$

    Boundary trap: Penalizing the intercept ($\Lambda = \lambda I_p$) destroys shift equivariance ($y + c\mathbf{1}_n$ distorts slopes!). With $\Lambda_0 = \lambda\operatorname{diag}(0, 1)$ in simple regression, $\hat\beta_{1,\text{ridge}} = \frac{S_{xy}}{S_{xx} + \lambda}$ and $\hat\beta_{0,\text{ridge}} = \bar y - \hat\beta_{1,\text{ridge}}\bar x$.

    7. Frisch-Waugh-Lovell Residualization and Exact VIF

    Assumptions: Full-rank partition $X = [X_1, X_2]$, $M_1 := I_n - X_1(X_1^\top X_1)^{-1}X_1^\top$. Eliminating $\hat\beta_1 = (X_1^\top X_1)^{-1}X_1^\top(y - X_2\hat\beta_2)$ from $X_2^\top(y - X_1\hat\beta_1 - X_2\hat\beta_2) = 0$ and using $M_1^\top M_1 = M_1$ gives

    $$\hat\beta_2 = (X_2^\top M_1 X_2)^{-1} X_2^\top M_1 y = (\tilde X_2^\top \tilde X_2)^{-1}\tilde X_2^\top \tilde y, \qquad e_{\text{full}} = \tilde y - \tilde X_2 \hat\beta_2.$$

    For a single non-constant predictor $x_j$ ($S_{jj} > 0$, $R_j^2 < 1$) when $\mathbf{1}_n \in \mathcal{C}(X_1)$, $\|M_1 x_j\|_2^2 = S_{jj}(1 - R_j^2)$ yields $\operatorname{Var}(\hat\beta_j \mid X) = \frac{\sigma^2}{S_{jj}(1 - R_j^2)} = \frac{\sigma^2}{S_{jj}}\operatorname{VIF}_j$.

    8. Lasso Coordinate Subdifferential KKT and Soft-Thresholding

    Assumptions: Per-sample objective $\frac{1}{2n}\|r^{(-j)} - x_j \beta_j\|_2^2 + \gamma |\beta_j|$ ($\gamma = \lambda\alpha > 0$), with $v_j := \frac{1}{n}\|x_j\|_2^2 > 0$ and $z_j := \frac{1}{n}x_j^\top r^{(-j)}$. Subgradient optimality $0 \in v_j \beta_j - z_j + \gamma\,\partial|\beta_j|$ ($\partial|0| = [-1, 1]$) gives

    $$\hat\beta_j = \frac{\operatorname{sign}(z_j)\max(|z_j| - \gamma,\, 0)}{v_j} \qquad \big(\hat\beta_j = 0 \iff |z_j| \le \gamma\big).$$

    9. Sherman-Morrison Leave-One-Out Residual $e_{(i)}$, PRESS, and Cook's $D_i$

    Assumptions: $\operatorname{rank}(X) = p$ and $h_{ii} := x_i^\top(X^\top X)^{-1}x_i < 1$ (so $X_{(i)}$ retains full rank $p$). Applying Sherman-Morrison $(A - x_i x_i^\top)^{-1} = A^{-1} + \frac{A^{-1}x_i x_i^\top A^{-1}}{1 - h_{ii}}$ to $A = X^\top X$ and $X_{(i)}^\top y_{(i)} = X^\top y - x_i y_i$ gives

    $$\hat\beta - \hat\beta_{(i)} = \frac{(X^\top X)^{-1} x_i e_i}{1 - h_{ii}} \implies e_{(i)} = y_i - x_i^\top \hat\beta_{(i)} = \frac{e_i}{1 - h_{ii}}, \qquad D_i = \frac{e_i^2}{p\,s^2}\frac{h_{ii}}{(1 - h_{ii})^2}.$$

    Reproduce Every Number on This Page

    Show the complete numerical check 
    import numpy as np

x = np.array([1., 2., 3., 4.])
y = np.array([2., 3., 5., 4.])
z = np.array([1., 0., 1., 0.])
X = np.column_stack([np.ones(4), x])
n, p = X.shape

# 1-4. Normal equations, projection, unbiased s^2, and Gauss-Markov weight check
beta = np.linalg.solve(X.T @ X, X.T @ y)
yhat = X @ beta
e = y - yhat
s2 = np.sum(e ** 2) / (n - p)
assert np.allclose(beta, [1.5, 0.8])
assert np.allclose(X.T @ e, [0.0, 0.0])
assert np.isclose(y @ y, (yhat @ yhat) + (e @ e))
assert np.isclose(s2, 0.90)

c_ols = (x - x.mean()) / np.sum((x - x.mean()) ** 2)
d_pert = np.array([1., -3., 3., -1.]) * 0.05  # d_pert @ 1 == 0 and d_pert @ x == 0
assert np.isclose(d_pert.sum(), 0.0) and np.isclose(d_pert @ x, 0.0)
assert np.sum((c_ols + d_pert) ** 2) > np.sum(c_ols ** 2)

# 6. All-parameter Ridge vs unpenalized-intercept Ridge (lambda = 1)
b_ridge_all = np.linalg.solve(X.T @ X + np.eye(2), X.T @ y)
b_ridge_unpen = np.linalg.solve(X.T @ X + np.diag([0., 1.]), X.T @ y)
assert np.allclose(b_ridge_all, [0.8, 1.0])
assert np.allclose(b_ridge_unpen, [11.0 / 6.0, 2.0 / 3.0])
assert np.allclose(b_ridge_all - beta, -np.linalg.inv(X.T @ X + np.eye(2)) @ beta)

# 7-9. FWL with control z, Lasso soft-threshold, and Sherman-Morrison PRESS / Cook's D
Xz = np.column_stack([np.ones(4), x, z])
bz = np.linalg.lstsq(Xz, y, rcond=None)[0]
Z = np.column_stack([np.ones(4), z])
MZ = np.eye(4) - Z @ np.linalg.inv(Z.T @ Z) @ Z.T
fwl_b1 = ((MZ @ x) @ (MZ @ y)) / ((MZ @ x) @ (MZ @ x))
assert np.allclose(bz, [0.5, 1.0, 1.0]) and np.isclose(fwl_b1, 1.0)

h = np.diag(X @ np.linalg.inv(X.T @ X) @ X.T)
loo = e / (1.0 - h)
cook = (e ** 2 / (p * s2)) * (h / (1.0 - h) ** 2)
assert np.allclose(h, [0.7, 0.3, 0.3, 0.7])
assert np.isclose(np.sum(loo ** 2), 8.93424036)
assert np.isclose(cook[3], 2.11728395)

# Signed t-statistic flip under negative scaling c = -2
c = -2.0
X_neg = np.column_stack([np.ones(4), c * x])
b_neg = np.linalg.lstsq(X_neg, y, rcond=None)[0]
se_pos = np.sqrt(s2 * np.linalg.inv(X.T @ X)[1, 1])
se_neg = np.sqrt(s2 * np.linalg.inv(X_neg.T @ X_neg)[1, 1])
assert np.isclose(b_neg[1] / se_neg, -(beta[1] / se_pos))
print("All nine interview derivations and negative-scaling sign checks verified.")
