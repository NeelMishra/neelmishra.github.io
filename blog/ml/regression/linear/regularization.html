    Ridge, Lasso, and Elastic Net

    July 2026 · 18 min read

    Gauss-Markov proved that OLS has the smallest variance among unbiased linear estimators—yet when predictors are collinear or $p$ approaches (or exceeds) $n$, insisting on zero bias forces $\operatorname{Var}(\hat\beta)$ to explode along tiny singular values $\sigma_j$. Regularization breaks that bottleneck by adding a penalty on the slope magnitudes $\beta \in \mathbb{R}^p$ (leaving the intercept $\beta_0$ unpenalized so shifting $y \mapsto y + c$ simply shifts $\hat\beta_0 \mapsto \hat\beta_0 + c$). Because penalties depend on coefficient sizes, always standardize continuous predictors ($x_{ij} \leftarrow (x_{ij} - \bar x_j)/s_j$ using training-set moments) before penalizing.

    Reconciling the Two Standard Penalty Normalizations

    Libraries write regularized least squares in two different scalings that differ by a factor of $n$ (or $2n$). Keeping them explicit avoids $n$-fold tuning bugs when porting hyperparameters between glmnet / ElasticNet and Ridge:

    • Per-sample coordinate-descent convention (glmnet / sklearn.linear_model.Lasso & ElasticNet): $$\min_{\beta_0 \in \mathbb{R},\,\beta \in \mathbb{R}^p} \left\{ \frac{1}{2n}\|y - \beta_0 \mathbf{1}_n - X\beta\|_2^2 + \lambda_{\text{avg}}\left[\alpha \|\beta\|_1 + \frac{1 - \alpha}{2}\|\beta\|_2^2\right] \right\}, \qquad \alpha \in [0, 1].$$ Here $\alpha = 0$ is pure $L_2$ (Ridge), $\alpha = 1$ is pure $L_1$ (Lasso), and $\alpha \in (0, 1)$ is Elastic Net. When the columns of $X \in \mathbb{R}^{n \times p}$ are centered ($\mathbf{1}_n^\top X = 0$), differentiating with respect to $\beta_0$ gives $\hat\beta_0 = \bar y$ for every $(\lambda_{\text{avg}}, \alpha)$, allowing us to replace $y - \beta_0 \mathbf{1}_n$ by the centered vector $y_c := y - \bar y \mathbf{1}_n$.
    • Unscaled sum-of-squares Ridge convention (sklearn.linear_model.Ridge): $$\min_{\beta \in \mathbb{R}^p} \Big\{ \|y_c - X\beta\|_2^2 + \lambda_{\text{sum}} \|\beta\|_2^2 \Big\} \quad\Longrightarrow\quad \hat\beta_{\text{ridge}} = (X^\top X + \lambda_{\text{sum}} I_p)^{-1} X^\top y_c.$$ Multiplying the $\alpha = 0$ per-sample objective by $2n$ produces $\|y_c - X\beta\|_2^2 + (n\lambda_{\text{avg}})\|\beta\|_2^2$, giving the exact conversion $\lambda_{\text{sum}} = n\,\lambda_{\text{avg}}$!

    Ridge Regression: SVD Spectral Filtering and Bias-Variance Tradeoff

    Let centered $X = U \Sigma V^\top$ have thin SVD singular values $\sigma_1 \ge \cdots \ge \sigma_r > 0$. Substituting into $\hat\beta_{\text{ridge}} = (X^\top X + \lambda_{\text{sum}} I_p)^{-1} X^\top y_c$ yields

    $$\hat\beta_{\text{ridge}} = \sum_{j=1}^r \underbrace{\frac{\sigma_j^2}{\sigma_j^2 + \lambda_{\text{sum}}}}_{\text{filter } \in\,(0,1)} \frac{u_j^\top y_c}{\sigma_j}\,v_j, \qquad \hat y_c = \sum_{j=1}^r \frac{\sigma_j^2}{\sigma_j^2 + \lambda_{\text{sum}}}(u_j^\top y_c)\,u_j, \qquad \operatorname{df}(\lambda_{\text{sum}}) = \sum_{j=1}^r \frac{\sigma_j^2}{\sigma_j^2 + \lambda_{\text{sum}}}.$$

    Compare this with SVD OLS ($\sum_j (u_j^\top y_c / \sigma_j) v_j$): directions with large $\sigma_j^2 \gg \lambda_{\text{sum}}$ pass through nearly untouched, whereas collinear/noisy directions with $\sigma_j^2 \ll \lambda_{\text{sum}}$ are strongly damped, and $X^\top X + \lambda_{\text{sum}} I_p \succ 0$ is invertible for every $\lambda_{\text{sum}} > 0$ even when $p > n$! Under Gaussian noise $y_c \mid X \sim \mathcal{N}(X\beta, \sigma^2 I_n)$ and prior $\beta \sim \mathcal{N}(0, \tau^2 I_p)$, $\hat\beta_{\text{ridge}}$ is also the exact Bayesian MAP / posterior mean with $\lambda_{\text{sum}} = \sigma^2 / \tau^2$.

    To see why MSE strictly beats OLS at small $\lambda > 0$, take a single orthonormal direction ($\sigma_1 = 1$) where $\hat\beta_{\text{OLS}} \sim (\beta, \sigma^2)$ and $\hat\beta_\lambda = \frac{\hat\beta_{\text{OLS}}}{1 + \lambda}$: then $\operatorname{Bias}^2(\hat\beta_\lambda) = \left(\frac{\lambda \beta}{1 + \lambda}\right)^2$ has derivative $0$ at $\lambda = 0$, whereas $\operatorname{Var}(\hat\beta_\lambda) = \frac{\sigma^2}{(1 + \lambda)^2}$ has strictly negative derivative $-2\sigma^2 < 0$ at $\lambda = 0$! Minimizing $\operatorname{MSE}(\lambda) = \frac{\lambda^2 \beta^2 + \sigma^2}{(1 + \lambda)^2}$ gives exact theoretical optimum $\lambda^\star = \sigma^2 / \beta^2$ (for $\beta = 0.4$ and $\sigma^2 = 1$, $\lambda^\star = 1 / 0.16 = 6.25$, cutting MSE from $1.000$ to $\frac{0.16}{1.16} \approx 0.1379$).

    Subdifferential KKT Proof of Soft-Thresholding (Lasso & Elastic Net)

    Why does $L_1$ set coefficients to exact zero while $L_2$ only shrinks them asymptotically toward zero? Let us derive the exact coordinate-descent update under the per-sample objective (writing $\lambda = \lambda_{\text{avg}}$). Fix all coefficients $\beta_k$ ($k \ne j$), define the partial residual excluding feature $j$ as $r^{(-j)} := y_c - \sum_{k \ne j} x_k \beta_k$, and define two scalars BEFORE differentiating:

    $$v_j := \frac{1}{n}\|x_j\|_2^2 > 0 \quad (\text{equals } 1 \text{ when } x_j \text{ has unit mean-square}), \qquad z_j := \frac{1}{n} x_j^\top r^{(-j)}.$$

    Up to constants independent of $\beta_j$, the per-sample objective as a function of $\beta_j$ alone is

    $$g(\beta_j) = \frac{1}{2} v_j \beta_j^2 - z_j \beta_j + \frac{\lambda(1 - \alpha)}{2}\beta_j^2 + \lambda\alpha |\beta_j|.$$

    Because $|\beta_j|$ has a sharp corner at $0$, its convex subdifferential is $\partial|\beta_j| = \{+1\}$ for $\beta_j > 0$, $\{-1\}$ for $\beta_j < 0$, and the entire interval $[-1, +1]$ at $\beta_j = 0$. A point $\beta_j$ minimizes convex $g$ if and only if $0 \in \partial g(\beta_j)$:

    $$0 \in \big(v_j + \lambda(1 - \alpha)\big)\beta_j - z_j + \lambda\alpha\,\partial|\beta_j|.$$

    Check the three mutually exclusive cases directly:

    1. Case $z_j > \lambda\alpha$: Choosing $\beta_j > 0$ sets $\partial|\beta_j| = \{+1\}$, giving $\beta_j = \frac{z_j - \lambda\alpha}{v_j + \lambda(1 - \alpha)} > 0$.
    2. Case $z_j < -\lambda\alpha$: Choosing $\beta_j < 0$ sets $\partial|\beta_j| = \{-1\}$, giving $\beta_j = \frac{z_j + \lambda\alpha}{v_j + \lambda(1 - \alpha)} < 0$.
    3. Dead-zone case $|z_j| \le \lambda\alpha$: Setting $\beta_j = 0$ requires $0 \in -z_j + \lambda\alpha [-1, +1] \iff \frac{z_j}{\lambda\alpha} \in [-1, +1]$, which holds! Hence $\beta_j = 0$ is the exact global minimizer whenever $|z_j| \le \lambda\alpha$.

    Combining all three cases via the soft-thresholding operator $S(z, \gamma) := \operatorname{sign}(z)\max(|z| - \gamma, 0)$ yields

    $$\beta_j \leftarrow \frac{S(z_j,\,\lambda\alpha)}{v_j + \lambda(1 - \alpha)} \qquad \Big(\text{simplifying to } \frac{S(z_j,\,\lambda\alpha)}{1 + \lambda(1 - \alpha)} \text{ when } v_j = \frac{1}{n}\|x_j\|_2^2 = 1\Big).$$

    Notice the entry threshold: every slope is identically zero ($\hat\beta = 0$) whenever $\lambda \ge \lambda_{\max} := \frac{1}{\alpha} \max_{1 \le j \le p} \frac{1}{n}|x_j^\top y_c|$ ($\alpha > 0$).

    Grouped Predictors, Naive Inference Traps, and Fold-Safe Cross-Validation

    • Duplicate / correlated groups ($x_1 \approx x_2$): If $x_1 = x_2$, any split $\beta_1 + \beta_2 = s$ yields identical $X\beta$. Strict convexity of $\beta_1^2 + \beta_2^2$ forces Ridge (and Elastic Net with $\alpha < 1$) to split weight evenly ($\hat\beta_1 = \hat\beta_2 = s/2$), whereas $|\beta_1| + |\beta_2| = |s|$ is flat across all same-sign splits, causing Lasso to pick one copy arbitrarily and saturate at $\le \min(n, p)$ nonzero predictors.
    • Post-selection inference trap: Do not plug Lasso-selected variables directly into classical OLS $t$-tests on the same dataset! Data-driven variable screening invalidates nominal $p$-values unless sample splitting or selective inference adjustments are used; likewise, sparse truth does not guarantee support recovery when correlated columns violate the irrepresentable condition.
    • Fold-safe tuning: Compute feature means $\bar x_j$, standard deviations $s_j$, missing-value imputers, and warm-started $\lambda$ paths strictly inside each training fold (using forward-chaining splits on time series), and serialize $(\bar x, s, \hat\beta_0, \hat\beta, \lambda, \alpha, \text{convention})$ together in your deployment artifact.

    Reproduce Every Number on This Page

    Show the complete numerical check 
    import numpy as np

# 1. Four-row orthogonal standardized dataset: Ridge, Lasso, Elastic Net
x1 = np.array([-1., -1., 1., 1.])
x2 = np.array([-1., 1., -1., 1.])
X = np.column_stack([x1, x2])
yc = np.array([-2.2, -1.4, 1.4, 2.2])
n = len(yc)

assert np.allclose(np.mean(X, axis=0), [0.0, 0.0])
assert np.allclose(np.sum(X ** 2, axis=0) / n, [1.0, 1.0])
z = (X.T @ yc) / n
assert np.allclose(z, [1.8, 0.4])

def soft(u, gamma):
    return np.sign(u) * np.maximum(np.abs(u) - gamma, 0.0)

for lam in [0.0, 0.25, 0.5, 1.0, 2.0]:
    # Verify lambda_sum = n * lambda_avg equivalence for Ridge
    b_ridge_cd = z / (1.0 + lam)
    lam_sum = n * lam
    b_ridge_mat = np.linalg.solve(X.T @ X + lam_sum * np.eye(2), X.T @ yc)
    assert np.allclose(b_ridge_cd, b_ridge_mat)

    # Verify subdifferential KKT condition 0 in (1 + lam*(1-a))*b - z + lam*a*subdiff(|b|)
    for alpha in [1.0, 0.5]:
        b = soft(z, lam * alpha) / (1.0 + lam * (1.0 - alpha))
        grad_smooth = (1.0 + lam * (1.0 - alpha)) * b - z
        for j in range(2):
            if b[j] > 0:
                assert np.isclose(grad_smooth[j] + lam * alpha, 0.0)
            elif b[j] < 0:
                assert np.isclose(grad_smooth[j] - lam * alpha, 0.0)
            else:
                assert np.abs(grad_smooth[j]) <= lam * alpha + 1e-12

# 2. Bias-variance optimal scalar lambda* = sigma^2 / beta^2 = 1 / 0.16 = 6.25
beta_true, sigma2 = 0.4, 1.0
lam_star = sigma2 / (beta_true ** 2)
mse_star = (lam_star ** 2 * beta_true ** 2 + sigma2) / ((1.0 + lam_star) ** 2)
assert np.isclose(lam_star, 6.25) and np.isclose(mse_star, 0.16 / 1.16)
print("All lambda-scaling, KKT soft-thresholding, and Ridge MSE checks verified.")
