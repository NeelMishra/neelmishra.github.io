    Residual Diagnostics, Influence, and Evaluation Metrics

    July 2026 · 18 min read

    A single summary number such as training $R^2$ or RMSE can easily hide curvature, heteroscedasticity, serial correlation, or a single row quietly steering the entire fitted hyperplane. Diagnostics inspect the geometry of residuals and leverages inside your fit; evaluation measures loss on appropriately split out-of-sample data. Throughout this entire chapter, let $X \in \mathbb{R}^{n \times p}$ denote the full-column-rank augmented design matrix with $p$ total columns (including the intercept), so $\operatorname{tr}(H) = p$ and $s^2 := \frac{\text{SSE}}{n - p}$ ($n > p$).

    Raw, Studentized, and Leave-One-Out Deletion Residuals

    Even when the true disturbances $\varepsilon \mid X$ are perfectly homoscedastic ($\operatorname{Var}(\varepsilon \mid X) = \sigma^2 I_n$), the observable OLS residuals $e = (I_n - H)y = (I_n - H)\varepsilon$ do not have constant variance! Because $(I_n - H)$ is symmetric idempotent, $\operatorname{Var}(e \mid X) = \sigma^2(I_n - H)$, giving

    $$\operatorname{Var}(e_i \mid X) = \sigma^2 (1 - h_{ii}), \qquad h_{ii} = x_i^\top (X^\top X)^{-1} x_i \in \left[\frac{1}{n},\, 1\right].$$

    A point near the edge of predictor space ($h_{ii} = 0.85$) pulls the fitted hyperplane toward itself, mechanically shrinking its raw residual standard deviation to $\sqrt{0.15}\,\sigma \approx 0.39\sigma$. Three standardized quantities restore fair row-by-row comparison (requiring $h_{ii} < 1$):

    • Internally studentized residual: $r_i := \frac{e_i}{s\sqrt{1 - h_{ii}}}$.
    • Exact leave-one-out (LOO) deletion residual $e_{(i)} := y_i - x_i^\top \hat\beta_{(i)}$: Applying the Sherman-Morrison rank-one inverse formula $(X^\top X - x_i x_i^\top)^{-1} = (X^\top X)^{-1} + \frac{(X^\top X)^{-1}x_i x_i^\top (X^\top X)^{-1}}{1 - h_{ii}}$ yields $\hat\beta - \hat\beta_{(i)} = \frac{(X^\top X)^{-1} x_i e_i}{1 - h_{ii}}$ and therefore $$e_{(i)} = y_i - x_i^\top \hat\beta + x_i^\top(\hat\beta - \hat\beta_{(i)}) = e_i + \frac{h_{ii} e_i}{1 - h_{ii}} = \frac{e_i}{1 - h_{ii}}, \qquad \text{PRESS} := \sum_{i=1}^n \left(\frac{e_i}{1 - h_{ii}}\right)^2.$$ PRESS (Allen, 1974) computes exact $n$-fold leave-one-out OLS squared error from a single matrix factorization!
    • Externally studentized (deleted-$t$) residual: $t_i := \frac{e_i}{s_{(i)}\sqrt{1 - h_{ii}}} = r_i \sqrt{\frac{n - p - 1}{n - p - r_i^2}}$, which follows an exact Student-$t_{n - p - 1}$ distribution under Gaussian errors when row $i$ is not an outlier ($n > p + 1$).

    Leverage Is Potential; Cook's Distance Is Realized Influence

    High leverage $h_{ii}$ (often flagged above $2p/n$) only measures distance in $X$-space; if $y_i$ sits right on the trend of the other $n - 1$ rows, deleting row $i$ barely moves $\hat\beta$. Cook's distance (Cook, 1977) measures the normalized quadratic shift in the entire fitted vector $\hat y - \hat y_{(i)} = X(\hat\beta - \hat\beta_{(i)})$:

    $$D_i := \frac{\|X(\hat\beta - \hat\beta_{(i)})\|_2^2}{p\,s^2} = \frac{e_i^2}{p\,s^2}\frac{h_{ii}}{(1 - h_{ii})^2} = \frac{r_i^2}{p}\frac{h_{ii}}{1 - h_{ii}}.$$

    Notice how $D_i$ multiplies outlier size ($r_i^2 / p$) by the leverage odds ratio $h_{ii} / (1 - h_{ii})$! Inspect all five rows on $x = (-2, -1, 0, 1, 4)^\top$, $y = (-2.1, -0.8, 0.2, 1.1, 2.7)^\top$ ($n = 5, p = 2$, $\hat y = -0.0906 + 0.7764x$, $s^2 = 0.1894$, $\text{PRESS} = 3.9590$):

    Evaluation Metrics and Worked Overfitting ($R^2_{\text{train}} = 1$ vs. $R^2_{\text{oos}} < 0$)

    On held-out test rows $\{(x_j^{\text{te}}, y_j^{\text{te}})\}_{j=1}^{m}$, two out-of-sample $R^2$ conventions exist in the literature and software—always state which baseline mean is in your denominator:

    $$R^2_{\text{oos}}(\bar y_{\text{train}}) := 1 - \frac{\sum_{j=1}^m (y_j^{\text{te}} - \hat y_j^{\text{te}})^2}{\sum_{j=1}^m (y_j^{\text{te}} - \bar y_{\text{train}})^2}, \qquad R^2_{\text{oos}}(\bar y_{\text{test}}) := 1 - \frac{\sum_{j=1}^m (y_j^{\text{te}} - \hat y_j^{\text{te}})^2}{\sum_{j=1}^m (y_j^{\text{te}} - \bar y_{\text{test}})^2}.$$

    The first (Campbell & Thompson, 2008) compares against the best constant forecast $\bar y_{\text{train}}$ available without peeking at test outcomes; the second (sklearn.metrics.r2_score) centers by $\bar y_{\text{test}}$. Both can be arbitrarily negative when an overparameterized model memorizes training noise!     Bootstrap Resampling: Pairs & Wild Bootstrap vs. Naive Residual Bootstrap

    When sample sizes are modest or error tails are non-normal, practitioners frequently reach for the bootstrap—but choosing the wrong bootstrap breaks under heteroscedasticity:

    • Naive i.i.d. residual bootstrap (invalid under heteroscedasticity): Fits $\hat\beta$, resamples scaled residuals $e_{I_i}^*$ uniformly across all rows, and sets $y_i^* = x_i^\top \hat\beta + e_{I_i}^*$. Shuffling residuals across different $x_i$ rows forces constant variance across $X$, producing inconsistent SEs whenever $\operatorname{Var}(\varepsilon_i \mid x_i) = \sigma_i^2$ varies with $x_i$!
    • Pairs (case) bootstrap: Resamples full rows $(x_i^*, y_i^*)$ with replacement. Valid for independent heteroscedastic rows as $n \to \infty$, though in very small samples or sparse dummy designs a bootstrap draw $X^*$ can occasionally become rank-deficient.
    • Wild bootstrap (Wu, 1986; Liu, 1988; Davidson & Flachaire, 2008): Keeps the exact design matrix $X$ fixed and generates $y_i^* = x_i^\top \hat\beta + v_i\,\frac{e_i}{1 - h_{ii}}$, where $v_i$ are independent auxiliary multipliers with $E[v_i] = 0$ and $E[v_i^2] = 1$ (most simply Rademacher signs $P(v_i = +1) = P(v_i = -1) = \frac{1}{2}$). Because $E[(y_i^* - x_i^\top\hat\beta)^2 \mid X, y] = \frac{e_i^2}{(1 - h_{ii})^2}$, each row retains its own local variance scale while preserving exact $X$ conditioning! (For time series or clustered panels, use block or cluster-wild bootstrap.)

    Show the complete numerical check 
    import numpy as np

# 1. Five-row influence, Sherman-Morrison LOO residuals, PRESS, and Cook's distance
x = np.array([-2., -1., 0., 1., 4.])
y = np.array([-2.1, -0.8, 0.2, 1.1, 2.7])
X = np.column_stack([np.ones_like(x), x])
n, p = X.shape
beta = np.linalg.lstsq(X, y, rcond=None)[0]
e = y - X @ beta
H = X @ np.linalg.inv(X.T @ X) @ X.T
h = np.diag(H)
s2 = np.sum(e ** 2) / (n - p)
cook = (e ** 2 / (p * s2)) * (h / (1.0 - h) ** 2)
loo_shortcut = e / (1.0 - h)

# Verify Sherman-Morrison shortcut against explicit row-by-row refitting!
loo_exact = np.empty(n)
for i in range(n):
    mask = np.arange(n) != i
    bi = np.linalg.lstsq(X[mask], y[mask], rcond=None)[0]
    loo_exact[i] = y[i] - X[i] @ bi
assert np.allclose(loo_shortcut, loo_exact)
assert np.isclose(np.sum(loo_shortcut ** 2), 3.9590, atol=1e-4)
assert np.isclose(cook[4], 5.9732, atol=1e-4)

# 2. Six-train / four-test overfitting walkthrough (seed=15 integer noise columns)
rng = np.random.default_rng(15)
N_tr = rng.integers(-3, 4, size=(6, 4))
N_te = rng.integers(-3, 4, size=(4, 4))
x_tr = np.array([-3., -1., 0., 1., 2., 4.])
y_tr = np.array([-2.5, -1.8, 2.2, 1.9, 4.8, 6.2])
x_te = np.array([-2., 0., 1., 3.])
y_te = np.array([-1.9, 0.8, 2.7, 3.4])
X_tr = np.column_stack([np.ones(6), x_tr, N_tr])
X_te = np.column_stack([np.ones(4), x_te, N_te])
assert np.linalg.matrix_rank(X_tr) == 6

sst_tr = np.sum((y_tr - y_tr.mean()) ** 2)
sst_oos_trmean = np.sum((y_te - y_tr.mean()) ** 2)
expected_oos = [0.8062, 0.8044, 0.7706, -0.3237, -1.8712]
for idx, k_cols in enumerate(range(2, 7)):
    bk = np.linalg.lstsq(X_tr[:, :k_cols], y_tr, rcond=None)[0]
    r2_tr = 1.0 - np.sum((y_tr - X_tr[:, :k_cols] @ bk) ** 2) / sst_tr
    r2_oos = 1.0 - np.sum((y_te - X_te[:, :k_cols] @ bk) ** 2) / sst_oos_trmean
    assert np.isclose(r2_oos, expected_oos[idx], atol=1e-4)
    if k_cols == 6:
        assert np.isclose(r2_tr, 1.0)
print("Sherman-Morrison PRESS, Cook's D, and out-of-sample R2 collapse verified.")
