    Gauss-Markov, Standard Errors, Tests, and Intervals

    July 2026 · 18 min read

    Part 2 treated $y \in \mathbb{R}^n$ as a fixed vector of numbers and projected it onto $\mathcal{C}(X)$. Statistical inference begins the moment we ask what would happen if we drew a fresh sample of disturbances $\varepsilon$ at the same design matrix $X \in \mathbb{R}^{n \times k}$ ($k = p + 1$ with an intercept and $p$ predictors). Substituting $y = X\beta + \varepsilon$ into $\hat\beta = (X^\top X)^{-1}X^\top y$ reveals the fundamental decomposition of the OLS estimator:

    $$\hat\beta = \beta + (X^\top X)^{-1} X^\top \varepsilon.$$

    Every property on this page—unbiasedness, Gauss-Markov efficiency, homoscedastic versus sandwich standard errors, $t$ and $F$ tests, and the gap between confidence intervals for the mean and prediction intervals for a new row—flows directly from that single equation.

    Layered Assumptions and Exact Finite-Sample Unbiasedness

    Not every textbook assumption is needed for every result. Keeping the rungs separate prevents over-claiming or discarding valid tools:

    Exact map from linear-model assumptions to finite-sample and asymptotic guarantees ($k = p + 1$ parameters, $n > k$).
    Assumption layerMathematical conditionWhat it unlocks
    A1–A2: Linearity & full rank$y = X\beta + \varepsilon$, $\operatorname{rank}(X) = k$Unique $\hat\beta$ and algebraic decomposition $\hat\beta - \beta = (X^\top X)^{-1}X^\top\varepsilon$
    A3: Strict exogeneity$E[\varepsilon \mid X] = 0$Finite-sample unbiasedness $E[\hat\beta \mid X] = \beta$ (even under heteroscedasticity or non-normality)
    A4: Spherical disturbances$\operatorname{Var}(\varepsilon \mid X) = \sigma^2 I_n$$\operatorname{Var}(\hat\beta \mid X) = \sigma^2(X^\top X)^{-1}$, unbiased $\hat\sigma^2 = \text{SSE}/(n-k)$, and Gauss-Markov BLUE
    A5: Conditional normality$\varepsilon \mid X \sim \mathcal{N}(0, \sigma^2 I_n)$Exact finite-sample Student-$t_{n-k}$, $F_{q, n-k}$, prediction intervals, and Cramér-Rao efficiency among all unbiased estimators

    Verify unbiasedness directly under A1–A3 alone: conditioning on $X$ treats $(X^\top X)^{-1}X^\top$ as deterministic, so $E[\hat\beta \mid X] = \beta + (X^\top X)^{-1}X^\top E[\varepsilon \mid X] = \beta$.

    The Gauss-Markov Theorem (Loewner Matrix Proof)

    Under A1–A4, OLS is BLUE—the Best Linear Unbiased Estimator of $\beta$. Precisely, consider any estimator $\tilde\beta = A y$ that is linear in $y$ (where $A \in \mathbb{R}^{k \times n}$ may depend on $X$) and conditionally unbiased for every $\beta \in \mathbb{R}^k$:

    $$E[\tilde\beta \mid X] = A X \beta = \beta \quad \forall \beta \in \mathbb{R}^k \quad\Longleftrightarrow\quad A X = I_k.$$

    Define the discrepancy matrix $D := A - (X^\top X)^{-1}X^\top$. Multiplying on the right by $X$ gives $DX = AX - (X^\top X)^{-1}(X^\top X) = I_k - I_k = 0$. Now compute the conditional covariance of $\tilde\beta$ under $\operatorname{Var}(y \mid X) = \sigma^2 I_n$:

    $$\operatorname{Var}(\tilde\beta \mid X) = \sigma^2 A A^\top = \sigma^2 \Big((X^\top X)^{-1}X^\top + D\Big)\Big(X(X^\top X)^{-1} + D^\top\Big) = \sigma^2(X^\top X)^{-1} + \sigma^2 D D^\top,$$

    because both cross terms $D X (X^\top X)^{-1}$ and $(X^\top X)^{-1} X^\top D^\top$ vanish identically via $DX = 0$. Since $D D^\top$ is positive semidefinite ($c^\top D D^\top c = \|D^\top c\|_2^2 \ge 0$ for every contrast vector $c \in \mathbb{R}^k$), we obtain

    $$\operatorname{Var}(c^\top \tilde\beta \mid X) - \operatorname{Var}(c^\top \hat\beta \mid X) = \sigma^2 \|D^\top c\|_2^2 \ge 0 \qquad \forall c \in \mathbb{R}^k,$$

    with equality for all $c$ if and only if $D = 0$ ($\tilde\beta = \hat\beta$). Remember the exact boundaries of BLUE: (1) biased linear estimators such as Ridge can achieve smaller mean squared error when collinearity is high; (2) under heavy-tailed non-Gaussian errors, nonlinear unbiased estimators such as sample medians/LAD can have smaller variance than OLS; and (3) when $\operatorname{Var}(\varepsilon \mid X) = \Omega \ne \sigma^2 I_n$, Generalized Least Squares $\hat\beta_{\text{GLS}} = (X^\top \Omega^{-1} X)^{-1} X^\top \Omega^{-1} y$ replaces OLS as BLUE.

    Unbiased $\hat\sigma^2$ and Homoscedastic Versus Sandwich Standard Errors

    Why does the unbiased residual variance estimator divide by $n - k = n - p - 1$ instead of $n$? Write $e = My = M(X\beta + \varepsilon) = M\varepsilon$ because $MX = 0$. Under A4 ($E[\varepsilon\varepsilon^\top \mid X] = \sigma^2 I_n$), using the cyclic trace trick $\operatorname{tr}(AB) = \operatorname{tr}(BA)$ and idempotence $M^2 = M$ gives

    $$E[\text{SSE} \mid X] = E[\varepsilon^\top M^\top M \varepsilon \mid X] = \operatorname{tr}\big(M\, E[\varepsilon\varepsilon^\top \mid X]\big) = \sigma^2 \operatorname{tr}(I_n - H) = \sigma^2 (n - k).$$

    Therefore $\hat\sigma^2 := \frac{\text{SSE}}{n - k}$ satisfies $E[\hat\sigma^2 \mid X] = \sigma^2$ (requiring $n > k$). For a general error covariance $\Omega := \operatorname{Var}(\varepsilon \mid X)$, however, the exact conditional covariance of $\hat\beta$ is the sandwich matrix

    $$\operatorname{Var}(\hat\beta \mid X) = (X^\top X)^{-1} X^\top \Omega X (X^\top X)^{-1}.$$
    Classical and heteroscedasticity-consistent (HC) covariance estimators $\widehat{\operatorname{Var}}(\hat\beta) = (X^\top X)^{-1}\big(\sum_{i=1}^n \hat\omega_i x_i x_i^\top\big)(X^\top X)^{-1}$.
    EstimatorMeat weight $\hat\omega_i$When to use and finite-sample behavior
    Classical OLS$\hat\sigma^2$ (simplifies to $\hat\sigma^2(X^\top X)^{-1}$)Valid only under homoscedastic, uncorrelated errors ($\Omega = \sigma^2 I_n$)
    HC0 (White, 1980)$e_i^2$Consistent as $n \to \infty$ for independent heteroscedastic rows, but downward-biased in small samples because $\operatorname{Var}(e_i \mid X) = \sigma^2(1 - h_{ii})$ under homoscedasticity
    HC1$\frac{n}{n - k}\,e_i^2$Global degrees-of-freedom rescaling; common software default, still under-corrects individual high-leverage rows
    HC2$\frac{e_i^2}{1 - h_{ii}}$Unbiased for $\sigma^2(X^\top X)^{-1}$ when $\Omega = \sigma^2 I_n$ (requires $h_{ii} < 1$)
    HC3 (recommended)$\frac{e_i^2}{(1 - h_{ii})^2}$Jackknife-related leverage penalty; markedly superior finite-sample CI coverage when high-leverage rows carry larger error variance

    Exact Gaussian $t$ and $F$ Tests Versus Large-Sample CLT

    Under A5 ($\varepsilon \mid X \sim \mathcal{N}(0, \sigma^2 I_n)$), $\hat\beta \mid X \sim \mathcal{N}\big(\beta, \sigma^2(X^\top X)^{-1}\big)$ and $\operatorname{Cov}(X^\top\varepsilon, M\varepsilon \mid X) = \sigma^2 X^\top M = 0$. Jointly normal uncorrelated vectors are independent, so $\hat\beta$ is independent of $\text{SSE}/\sigma^2 \sim \chi^2_{n-k}$. Consequently, for testing $H_0: \beta_j = \beta_{j0}$ or $q$ joint linear restrictions $H_0: R\beta = r$ ($\operatorname{rank}(R) = q$),

    $$t_j = \frac{\hat\beta_j - \beta_{j0}}{\hat\sigma\sqrt{[(X^\top X)^{-1}]_{jj}}} \sim t_{n-k}, \qquad F = \frac{(R\hat\beta - r)^\top\big[R\,\widehat{\operatorname{Var}}(\hat\beta)R^\top\big]^{-1}(R\hat\beta - r)}{q} = \frac{(\text{SSE}_R - \text{SSE}_U)/q}{\text{SSE}_U/(n - k)} \sim F_{q,\,n-k}$$

    hold exactly in finite samples (where the rightmost $\text{SSE}_R - \text{SSE}_U$ equality uses the classical covariance $\hat\sigma^2(X^\top X)^{-1}$). Without A5, if independent rows satisfy finite moments and negligible maximum leverage ($\max_i h_{ii} \to 0$), the Lindeberg-Feller CLT makes $t_j \xrightarrow{d} \mathcal{N}(0, 1)$ and $qF \xrightarrow{d} \chi^2_q$ asymptotically when paired with HC covariance.

    Mean-Response Confidence Interval Versus New-Observation Prediction Interval

    At a query feature vector $x_0 = (1, x_{01}, \ldots, x_{0p})^\top$, there are two completely different estimation targets:

    • Mean response $\mu_0 = x_0^\top \beta$: Estimation error is $x_0^\top(\hat\beta - \beta)$ with conditional variance $\sigma^2 q(x_0)$, where $q(x_0) := x_0^\top (X^\top X)^{-1} x_0 = \frac{1}{n} + \frac{(x_0 - \bar x)^2}{S_{xx}}$ (for $p = 1$). Its $100(1 - \alpha)\%$ CI is $$x_0^\top \hat\beta \;\pm\; t_{\alpha/2,\,n-k}\,\hat\sigma \sqrt{x_0^\top (X^\top X)^{-1} x_0},$$ whose width shrinks to zero as $n \to \infty$.
    • Single future realization $Y_0 = x_0^\top \beta + \varepsilon_0$: Prediction error is $Y_0 - x_0^\top \hat\beta = \varepsilon_0 - x_0^\top(\hat\beta - \beta)$. Assuming (i) $\varepsilon_0$ is independent of training $\varepsilon$, (ii) $\operatorname{Var}(\varepsilon_0 \mid x_0) = \sigma^2$ matches training homoscedasticity, and (iii) both $\varepsilon$ and $\varepsilon_0$ are Gaussian, $\operatorname{Var}(Y_0 - x_0^\top \hat\beta \mid X, x_0) = \sigma^2\big(1 + x_0^\top(X^\top X)^{-1}x_0\big)$, giving the $100(1 - \alpha)\%$ prediction interval $$x_0^\top \hat\beta \;\pm\; t_{\alpha/2,\,n-k}\,\hat\sigma \sqrt{1 + x_0^\top (X^\top X)^{-1} x_0}.$$
    Interview trap: Large $n$ does NOT rescue a parametric $t$ prediction interval when $\varepsilon_0$ is non-normal or heteroscedastic! As $n \to \infty$, $x_0^\top(X^\top X)^{-1}x_0 \to 0$ and the CLT makes $\hat\beta$ normal, so the mean CI becomes valid without normal errors. By contrast, the prediction interval converges to $\mu_0 \pm z_{\alpha/2}\sigma$, which still assumes the single unaveraged future shock $\varepsilon_0$ is Gaussian with constant variance $\sigma^2$. Under skewed, heavy-tailed, or heteroscedastic noise, use quantile regression or split conformal prediction instead.

    Reproduce Every Number on This Page

    Show the complete numerical check 
    import numpy as np
from scipy import stats

# 1. Six-row dataset: leverage, unbiased sigma^2, 95% mean CI vs PI
x = np.array([1., 2., 3., 4., 5., 6.])
y = np.array([2.2, 3.8, 5.1, 5.6, 7.4, 8.3])
X = np.column_stack([np.ones_like(x), x])
XtX_inv = np.linalg.inv(X.T @ X)
beta = XtX_inv @ (X.T @ y)
e = y - X @ beta
H = X @ XtX_inv @ X.T
h = np.diag(H)
sigma_hat = np.sqrt(np.sum(e ** 2) / 4.0)
t_crit = stats.t.ppf(0.975, df=4)

assert np.allclose(h, [0.52380952, 0.2952381, 0.18095238, 0.18095238, 0.2952381, 0.52380952])
assert np.isclose(np.sum(h), 2.0)

v_mid = np.array([1.0, 3.5])
q_mid = v_mid @ XtX_inv @ v_mid
mu_mid = v_mid @ beta
ci_mid = (mu_mid - t_crit * sigma_hat * np.sqrt(q_mid), mu_mid + t_crit * sigma_hat * np.sqrt(q_mid))
pi_mid = (mu_mid - t_crit * sigma_hat * np.sqrt(1.0 + q_mid), mu_mid + t_crit * sigma_hat * np.sqrt(1.0 + q_mid))
assert np.allclose(ci_mid, [5.0509, 5.7491], atol=1e-4)
assert np.allclose(pi_mid, [4.4764, 6.3236], atol=1e-4)

# 2. Six constructed n=5 teaching samples + genuine 10,000-trial Monte Carlo coverage check
sets = np.array([
    [2.6, 5.2, 7.1, 8.9, 11.2],
    [3.5, 4.8, 7.3, 9.1, 10.6],
    [2.1, 4.75, 7.1, 9.35, 11.7],
    [2.0, 5.8, 6.6, 10.0, 10.4],
    [3.6, 5.2, 6.5, 8.6, 11.1],
    [2.8, 5.7, 6.7, 9.5, 10.9],
])
x5 = np.arange(1., 6.)
t3 = stats.t.ppf(0.975, df=3)
b1s = ((x5 - 3.0) @ (sets - sets.mean(axis=1, keepdims=True)).T) / 10.0
assert np.isclose(b1s.mean(), 2.04333333)

rng = np.random.default_rng(2026)
eps_mc = rng.normal(0.0, 0.6, size=(10_000, 5))
y_mc = 1.0 + 2.0 * x5[None, :] + eps_mc
b1_mc = ((y_mc - y_mc.mean(axis=1, keepdims=True)) @ (x5 - 3.0)) / 10.0
b0_mc = y_mc.mean(axis=1) - 3.0 * b1_mc
sse_mc = np.sum((y_mc - (b0_mc[:, None] + b1_mc[:, None] * x5[None, :])) ** 2, axis=1)
se_mc = np.sqrt((sse_mc / 3.0) / 10.0)
coverage = np.mean(np.abs(b1_mc - 2.0) <= t3 * se_mc)
assert 0.943 <= coverage <= 0.957
print(f"10,000-trial exact t_3 empirical coverage: {coverage:.4f}")
