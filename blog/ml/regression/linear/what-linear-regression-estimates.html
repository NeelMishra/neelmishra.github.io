    What Linear Regression Estimates

    July 2026 · 17 min read

    Before writing down a single matrix inverse, ask the most important modeling question: what population quantity is ordinary least squares (OLS) actually trying to estimate? In plain English, linear regression does not uncover a deterministic law that holds without error on every row, nor does a small $p$-value make a slope causal. Depending on what is true about the data-generating process, the exact same OLS formula estimates one of three progressively stronger targets: a best straight-line approximation, a true conditional average, or a causal intervention effect.

    Throughout this chapter, let $(X, Y)$ be a random pair drawn from a joint distribution $P(X, Y)$ with finite second moments ($E[Y^2] < \infty$ and $E[\|X\|_2^2] < \infty$), where $X = (1, X_1, \ldots, X_p)^\top \in \mathbb{R}^{p+1}$ includes the leading intercept constant $1$.

    Three Distinct Objects: CEF, Best Linear Predictor, and Sample OLS

    Most confusion in regression interviews disappears once you separate two fixed population objects from one noisy sample object:

    1. The Conditional Expectation Function (CEF), $\mu(x) := E[Y \mid X = x]$: At each input vector $x$, $\mu(x)$ is the true population average of $Y$. By the law of iterated expectations, decomposing $Y - g(X) = (Y - \mu(X)) + (\mu(X) - g(X))$ yields $$E\big[(Y - g(X))^2\big] = E\big[(Y - \mu(X))^2\big] + E\big[(\mu(X) - g(X))^2\big]$$ for every measurable function $g(X)$ because $E[(Y - \mu(X))(\mu(X) - g(X))] = 0$. Therefore $\mu(X)$ is the global minimizer of expected squared prediction error over all possible functions of $X$.
    2. The Population Best Linear Predictor (BLP), $X^\top \beta^*$: Linear regression restricts $g(X)$ to linear combinations $X^\top b$. Setting $g(X) = X^\top b$ in the decomposition above shows that minimizing $E[(Y - X^\top b)^2]$ is identical to minimizing the $P(X)$-weighted squared approximation error to the true CEF: $$\beta^* = \operatorname*{arg\,min}_{b \in \mathbb{R}^{p+1}} E\big[(Y - X^\top b)^2\big] = \operatorname*{arg\,min}_{b \in \mathbb{R}^{p+1}} E\big[(\mu(X) - X^\top b)^2\big].$$ Differentiating with respect to $b$ gives the population normal equations $E[X(Y - X^\top \beta^*)] = 0$. Whenever $E[XX^\top]$ is invertible, the unique population BLP parameter is $$\beta^* = \big(E[XX^\top]\big)^{-1} E[XY].$$ For a single scalar predictor $X_1$ with $X = (1, X_1)^\top$, this simplifies to $$b^* = \frac{\operatorname{Cov}(X_1, Y)}{\operatorname{Var}(X_1)} = \frac{\operatorname{Cov}(X_1, \mu(X_1))}{\operatorname{Var}(X_1)}, \qquad a^* = E[Y] - b^* E[X_1].$$
    3. The Sample OLS Estimator, $\hat\beta_n = (X_{\text{mat}}^\top X_{\text{mat}})^{-1} X_{\text{mat}}^\top y$: Computed from $n$ observed rows, $\hat\beta_n$ is a random vector that fluctuates from sample to sample. Under i.i.d. sampling with finite second moments and invertible $E[XX^\top]$, the weak law of large numbers and continuous mapping theorem give $\hat\beta_n \xrightarrow{p} \beta^*$ as $n \to \infty$—even when $\mu(x)$ is curved!
    Crucial subtlety: $E[Xu] = 0$ is automatic for the BLP, whereas $E[\varepsilon \mid X] = 0$ is a substantive assumption. Define the population projection residual $u := Y - X^\top \beta^*$. By construction of $\beta^*$, $E[Xu] = 0$ (meaning $E[u] = 0$ and $\operatorname{Cov}(X_j, u) = 0$ for every $j$) holds by algebra for any joint distribution with finite second moments. That weak orthogonality does not mean $E[u \mid X] = 0$: if $\mu(x)$ is curved, $E[u \mid X = x] = \mu(x) - x^\top \beta^*$ is nonzero at specific $x$ values and merely averages to zero across $P(X)$.

    Worked Nonlinear Example: More Data Stabilizes the Line, Not the Missing Curve

    Suppose the true population conditional mean on a discrete input $X_1 \in \{1, 2, 3, 4, 5, 6, 7\}$ is quadratic:

    $$\mu(x) = 2 + 3x - 0.3x^2.$$

    Under a discrete uniform input distribution $P(X_1 = x) = \frac{1}{7}$ on $\{1, \ldots, 7\}$, we have $E[X_1] = 4$, $\operatorname{Var}(X_1) = 4$, $E[\mu(X_1)] = 8.0$, and $\operatorname{Cov}(X_1, \mu(X_1)) = 2.4$. Therefore the population best linear predictor is

    $$b^* = \frac{2.4}{4} = 0.6000, \qquad a^* = 8.0 - 0.6(4) = 5.6000 \quad\Longrightarrow\quad \text{BLP}(x) = 5.6 + 0.6x.$$

    Notice what happens if the true curve $\mu(x)$ stays completely unchanged, but the marginal distribution $P(X_1)$ shifts! On uniform $\{1, 2, 3\}$ (left side of the arch), the population BLP is $3.0 + 1.8x$ (steep positive slope $+1.80$); on uniform $\{5, 6, 7\}$ (past the peak at $x = 5$), the population BLP flips sign to $12.6 - 0.6x$ (negative slope $-0.60$). Under misspecification, the population parameter $\beta^*$ depends on $P(X)$.

    Omitted-Variable Bias and Bad Controls

    Suppose the true conditional expectation uses two predictors,

    $$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \varepsilon, \qquad E[\varepsilon \mid X_1, X_2] = 0,$$

    but we fit the short regression of $Y$ on $(1, X_1)$ alone. Let $X_2 = \delta_0 + \delta_1 X_1 + v$ be the population linear projection of the omitted variable $X_2$ onto $(1, X_1)$, where $\delta_1 = \operatorname{Cov}(X_1, X_2) / \operatorname{Var}(X_1)$ and $\operatorname{Cov}(X_1, v) = 0$. Substituting $X_2$ into the structural equation gives

    $$Y = (\beta_0 + \beta_2 \delta_0) + (\beta_1 + \beta_2 \delta_1) X_1 + (\beta_2 v + \varepsilon) \quad\Longrightarrow\quad \operatorname{plim}_{n \to \infty} \hat\beta_1^{\text{short}} = \beta_1 + \underbrace{\beta_2 \delta_1}_{\text{OVB}}.$$

    An omitted variable biases $\hat\beta_1^{\text{short}}$ unless either $\beta_2 = 0$ (the omitted variable does not directly affect $Y$) or $\delta_1 = 0$ ($X_1$ and $X_2$ are uncorrelated in the population). For instance, if $\beta_1 = 2$, $\beta_2 = 3$, and $\delta_1 = 0.5$, the short regression converges to $2 + 3(0.5) = 3.5$ regardless of how large $n$ grows or whether HC3 standard errors are used. Simpson's paradox is the extreme case where $\beta_2 \delta_1$ is large enough to reverse the sign of $\beta_1$.

    Interview trap: "Control for everything" can create bias. Conditioning on pre-treatment confounders removes omitted-variable bias, whereas conditioning on a post-treatment mediator blocks part of the causal pathway and conditioning on a collider (a variable caused by both $X_1$ and $Y$, such as selecting only hospitalized patients or admitted applicants) opens a spurious non-causal association even when $X_1$ and $Y$ are independent in the population.

    Measurement Error in $X$: Classical Attenuation Versus Berkson Error

    What happens when the outcome $Y = \beta_0 + \beta_1 X_1 + \varepsilon$ ($E[\varepsilon \mid X_1] = 0$) depends on a true scalar predictor $X_1$, but we only observe a noisy proxy $X_{1,\text{obs}}$? The answer depends critically on the error mechanism:

    • Classical additive measurement error ($X_{1,\text{obs}} = X_1 + u$): Suppose sensor or survey noise $u$ satisfies $E[u] = 0$, $\operatorname{Cov}(X_1, u) = 0$, and $\operatorname{Cov}(u, \varepsilon) = 0$. Regressing $Y$ on $(1, X_{1,\text{obs}})$ estimates $$\beta_{1,\text{obs}}^* = \frac{\operatorname{Cov}(X_1 + u,\, \beta_0 + \beta_1 X_1 + \varepsilon)}{\operatorname{Var}(X_1 + u)} = \frac{\sigma_{X_1}^2}{\sigma_{X_1}^2 + \sigma_u^2}\,\beta_1 = \lambda_{\text{rel}}\,\beta_1,$$ where $\lambda_{\text{rel}} \in (0, 1)$ is the reliability ratio. Classical error biases the single-regressor slope strictly toward zero (attenuation bias). Note the boundary conditions: if $u$ correlates with $X_1$ or $\varepsilon$, the bias need not shrink toward zero; and in multiple regression with correlated controls $Z$, classical error in $X_1$ not only attenuates $\hat\beta_1$ more severely via conditional variance $\sigma_{X_1 \mid Z}^2 / (\sigma_{X_1 \mid Z}^2 + \sigma_u^2)$, it also biases the slopes on the cleanly measured controls $Z$!
    • Berkson error ($X_1 = X_{1,\text{set}} + u$): When an experimenter sets a target dose or furnace temperature $X_{1,\text{set}}$ and actual exposure fluctuates as $X_1 = X_{1,\text{set}} + u$ with $E[u \mid X_{1,\text{set}}] = 0$ and $\operatorname{Cov}(u, \varepsilon) = 0$, substituting into $Y$ gives $Y = \beta_0 + \beta_1 X_{1,\text{set}} + (\beta_1 u + \varepsilon)$. Because $X_{1,\text{set}}$ is uncorrelated with $\beta_1 u + \varepsilon$, OLS on $X_{1,\text{set}}$ has zero attenuation bias ($\beta_{1,\text{obs}}^* = \beta_1$), merely absorbing $\beta_1^2 \sigma_u^2$ into the residual variance.

    Interpolation, Multivariate Extrapolation, and Key Edge Cases

    A point prediction $\hat y_0 = x_0^\top \hat\beta$ estimates the conditional mean at $x_0$, whereas a realized future outcome $Y_0 = \mu(x_0) + \varepsilon_0$ adds irreducible noise $\varepsilon_0$. On our quadratic example, predicting at $x_0 = 4$ (inside $\{1, \ldots, 7\}$) interpolates across observed support; predicting at $x_0 = 10$ via $5.6 + 0.6(10) = 11.6$ extrapolates linearly where the true parabola has already fallen to $\mu(10) = 2 + 30 - 30 = 2.0$! In $p \ge 2$ dimensions, a query point can fall inside the marginal range of every individual coordinate while still lying far outside the joint convex hull (or Mahalanobis ellipsoid) of training rows—for example, a $350\text{ m}^2$ apartment listed with $1$ bedroom when height/area and room count were strongly correlated in training.

    import numpy as np

# 1. Population quadratic CEF and marginal-distribution-dependent BLP
xs = np.arange(1., 8.)
mu = 2.0 + 3.0 * xs - 0.3 * xs ** 2

def pop_blp(x_sub, mu_sub):
    b = np.cov(x_sub, mu_sub, bias=True)[0, 1] / np.var(x_sub)
    a = mu_sub.mean() - b * x_sub.mean()
    return a, b

a_full, b_full = pop_blp(xs, mu)
a_left, b_left = pop_blp(xs[:3], mu[:3])
a_right, b_right = pop_blp(xs[4:], mu[4:])
assert np.allclose([a_full, b_full], [5.6, 0.6])
assert np.allclose([a_left, b_left], [3.0, 1.8])
assert np.allclose([a_right, b_right], [12.6, -0.6])
assert np.allclose(mu - (a_full + b_full * xs), [-1.5, 0.0, 0.9, 1.2, 0.9, 0.0, -1.5])

# 2. Constructed 7x5 replicate table and sample OLS trajectory
noise = np.array([
    [0.4, -0.3, 0.2, -0.4, 0.5],
    [-0.5, 0.3, -0.2, 0.4, -0.3],
    [0.3, -0.4, 0.5, -0.2, 0.3],
    [-0.2, 0.5, -0.3, 0.3, -0.5],
    [0.5, -0.2, 0.4, -0.5, 0.2],
    [-0.3, 0.4, -0.5, 0.2, -0.4],
    [0.2, -0.5, 0.3, -0.3, 0.4],
])
Y_rep = mu[:, None] + noise
expected_fits = [
    (5.65714286, 0.60000000),
    (5.62857143, 0.59642857),
    (5.65714286, 0.59285714),
    (5.63928571, 0.59107143),
    (5.65428571, 0.58857143),
]
for k in range(1, 6):
    yk = Y_rep[:, :k].reshape(-1)
    xk = np.repeat(xs, k)
    Xk = np.column_stack([np.ones_like(xk), xk])
    ak, bk = np.linalg.lstsq(Xk, yk, rcond=None)[0]
    assert np.allclose([ak, bk], expected_fits[k - 1])

# 3. OVB and Classical vs Berkson measurement error check
rng = np.random.default_rng(42)
n = 200_000
x1 = rng.normal(0.0, 2.0, size=n)  # Var(X1) = 4
x2 = 1.0 + 0.5 * x1 + rng.normal(0.0, 1.0, size=n)
y_ovb = 1.0 + 2.0 * x1 + 3.0 * x2 + rng.normal(0.0, 1.0, size=n)
b_short = np.polyfit(x1, y_ovb, 1)[0]
assert np.isclose(b_short, 3.5, atol=0.02)

u = rng.normal(0.0, 1.0, size=n)  # Var(u) = 1 -> reliability 4 / (4 + 1) = 0.8
y_clean = 1.0 + 2.0 * x1 + rng.normal(0.0, 1.0, size=n)
b_classical = np.polyfit(x1 + u, y_clean, 1)[0]
assert np.isclose(b_classical, 2.0 * (4.0 / 5.0), atol=0.02)

x_set = rng.normal(0.0, 2.0, size=n)
x_actual = x_set + u
y_berkson = 1.0 + 2.0 * x_actual + rng.normal(0.0, 1.0, size=n)
b_berkson = np.polyfit(x_set, y_berkson, 1)[0]
assert np.isclose(b_berkson, 2.0, atol=0.02)
print("All BLP, OVB, and measurement-error identities verified.")
