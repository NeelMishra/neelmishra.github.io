    Multicollinearity, VIF, and the FWL Theorem

    July 2026 · 17 min read

    People often describe multiple regression as measuring the slope on $x_j$ while "holding all other predictors fixed." In a real observational dataset with continuous features, you rarely have duplicate rows where every other column takes identical values. How, then, does ordinary least squares isolate a single predictor? The answer is the Frisch-Waugh-Lovell (FWL) theorem: OLS algebraically subtracts the linear projection of both $y$ and $x_j$ onto the remaining columns, and fits a simple regression on the leftover residuals. When $x_j$ is nearly explained by the other columns, almost no leftover variation remains—making individual slope estimates wildly sensitive even while joint predictions $\hat y = X\hat\beta$ stay stable.

    The Frisch-Waugh-Lovell Theorem (Coefficients and Residuals)

    Partition a full-column-rank design matrix $X = [X_1, X_2] \in \mathbb{R}^{n \times (k_1 + k_2)}$ into control columns $X_1 \in \mathbb{R}^{n \times k_1}$ (for example, the intercept $\mathbf{1}_n$ plus nuisance covariates) and target predictors $X_2 \in \mathbb{R}^{n \times k_2}$:

    $$y = X_1 \hat\beta_1 + X_2 \hat\beta_2 + e, \qquad X_1^\top e = 0, \qquad X_2^\top e = 0.$$

    Define the orthogonal projector $P_1 := X_1(X_1^\top X_1)^{-1}X_1^\top$ and residual-maker (annihilator) $M_1 := I_n - P_1$, satisfying $M_1^\top = M_1$, $M_1^2 = M_1$, and $M_1 X_1 = 0$. Left-multiplying the model equation by $X_1^\top$ gives $X_1^\top X_1 \hat\beta_1 + X_1^\top X_2 \hat\beta_2 = X_1^\top y$, or

    $$\hat\beta_1 = (X_1^\top X_1)^{-1}X_1^\top(y - X_2 \hat\beta_2).$$

    Substituting $\hat\beta_1$ into $X_1 \hat\beta_1$ yields $P_1(y - X_2 \hat\beta_2)$, so the full residual vector simplifies immediately to

    $$e = y - P_1(y - X_2 \hat\beta_2) - X_2 \hat\beta_2 = M_1 y - M_1 X_2 \hat\beta_2 = \tilde y - \tilde X_2 \hat\beta_2,$$

    where $\tilde y := M_1 y$ is the residual from regressing $y$ on $X_1$ and $\tilde X_2 := M_1 X_2$ is the column-wise residual matrix from regressing $X_2$ on $X_1$. Finally, enforcing $X_2^\top e = 0$ and using $M_1 = M_1^\top M_1$ gives

    $$X_2^\top M_1(M_1 y - M_1 X_2 \hat\beta_2) = 0 \quad\Longleftrightarrow\quad \tilde X_2^\top \tilde X_2 \hat\beta_2 = \tilde X_2^\top \tilde y \quad\Longleftrightarrow\quad \hat\beta_2 = (\tilde X_2^\top \tilde X_2)^{-1}\tilde X_2^\top \tilde y.$$
    Two FWL payoffs and one degrees-of-freedom trap: FWL proves both coefficient identity ($\hat\beta_2$ from regressing $\tilde y$ on $\tilde X_2$ equals $\hat\beta_2$ from the full regression) and exact row-by-row residual identity ($\tilde y - \tilde X_2 \hat\beta_2 = e$). However, if you run the partial regression $\tilde y \sim \tilde X_2$ inside an off-the-shelf OLS routine, its naive standard error divides $\text{SSE}$ by $n - k_2$ instead of the true full-model degrees of freedom $n - k_1 - k_2$—you must rescale by $\sqrt{(n - k_2)/(n - k_1 - k_2)}$!

    Deriving the Variance Inflation Factor $\operatorname{VIF}_j$ and Its Exact Conditions

    Apply FWL to a single non-intercept predictor $X_2 = x_j \in \mathbb{R}^n$, letting $X_1 = Z \in \mathbb{R}^{n \times p}$ hold the intercept $\mathbf{1}_n$ plus the other $p - 1$ predictors. By block matrix inversion (or directly from $\hat\beta_j = (\tilde x_j^\top \tilde x_j)^{-1}\tilde x_j^\top(Z\beta_{-j} + x_j \beta_j + \varepsilon) = \beta_j + (\tilde x_j^\top \tilde x_j)^{-1}\tilde x_j^\top\varepsilon$ since $M_Z Z = 0$), the $(j, j)$ diagonal entry of $(X^\top X)^{-1}$ is $\|\tilde x_j\|_2^{-2}$. Under homoscedasticity $\operatorname{Var}(\varepsilon \mid X) = \sigma^2 I_n$,

    $$\operatorname{Var}(\hat\beta_j \mid X) = \frac{\sigma^2}{\|\tilde x_j\|_2^2}.$$

    Now state the three conditions required to rewrite $\|\tilde x_j\|_2^2$ in terms of an auxiliary $R_j^2$:

    1. An intercept $\mathbf{1}_n$ lies in $\mathcal{C}(Z)$ (so both the main regression and the auxiliary regression of $x_j$ on $Z$ include an intercept).
    2. Predictor $x_j$ is non-constant: $S_{jj} := \sum_{i=1}^n (x_{ij} - \bar x_j)^2 > 0$.
    3. Predictor $x_j$ is not an exact linear combination of $Z$: $\|\tilde x_j\|_2^2 > 0$, equivalently $R_j^2 < 1$.

    Under (1)–(3), the centered auxiliary coefficient of determination from regressing $x_j$ on $Z$ is $R_j^2 = 1 - \frac{\|\tilde x_j\|_2^2}{S_{jj}}$, so $\|\tilde x_j\|_2^2 = S_{jj}(1 - R_j^2)$ and

    $$\operatorname{Var}(\hat\beta_j \mid X) = \frac{\sigma^2}{S_{jj}} \cdot \frac{1}{1 - R_j^2} = \frac{\sigma^2}{S_{jj}}\,\operatorname{VIF}_j, \qquad \operatorname{VIF}_j := \frac{1}{1 - R_j^2} \ge 1.$$

    Interpretation is immediate: if $R_j^2 = 0$ ($x_j$ is orthogonal to all other centered predictors), $\operatorname{VIF}_j = 1$; if $R_j^2 = 0.90$, $\operatorname{VIF}_j = 10$ and $\operatorname{se}(\hat\beta_j)$ is $\sqrt{10} \approx 3.16\times$ larger than an orthogonal design with the same spread $S_{jj}$; as $R_j^2 \to 1$, $\operatorname{VIF}_j \to \infty$. (Without an intercept in the model, centered $R_j^2$ no longer matches $(X^\top X)^{-1}_{jj}$; and for multi-column categorical or spline blocks, Fox & Monette's Generalized VIF $\operatorname{GVIF} = \frac{\det R_{22} \det R_{11}}{\det R}$ replaces single-column VIF.)

    Complete Four-Row FWL and VIF Walkthrough

    Consider four rows with control $z = (-1, -1, 1, 1)^\top$, target predictor $x = (1, 3, 2, 4)^\top$, and outcome $y = (5, 7, 11, 17)^\top$. Because $x$ tends to be larger when $z = +1$ ($\operatorname{Cov}(x, z) > 0$), a naive regression of $y$ on $(1, x)$ alone conflates $x$ with $z$ and yields slope $S_{xy}/S_{xx} = 16/5 = 3.20$. Watch how FWL strips out $Z = [\mathbf{1}_4, z]$ cleanly:

    Every algebraic identity checks out by hand: $\tilde x^\top \tilde x = 1 + 1 + 1 + 1 = 4$, $\tilde x^\top \tilde y = 1 + 1 + 3 + 3 = 8$, so $\hat\beta_x = \frac{8}{4} = 2.0000$—matching full OLS $\hat\beta = (5, 2, 3)^\top$! Partial residuals $\tilde y - 2\tilde x = (1, -1, -1, 1)^\top$ equal full residuals $y - \hat y$ identically, and since $S_{xx} = \sum(x_i - 2.5)^2 = 5.0$, the auxiliary $R_{x \mid z}^2 = 1 - \frac{4}{5} = 0.20$ gives $\operatorname{VIF}_x = \frac{1}{1 - 0.20} = 1.25$.

    Prediction Stability Versus Parameter Stability, and Practical Remedies

    Why can $X\hat\beta$ stay accurate even when $\operatorname{VIF}_j = 200$? Suppose $x_2 \approx x_1$. In observation space $\mathbb{R}^n$, $\mathcal{C}([x_1, x_2])$ is still a well-defined 2D plane, so the orthogonal projection $\hat y = Hy$ barely moves when noise perturbs $y$; inside parameter space, however, $(10\hat\beta_1 - 9\hat\beta_2)$ and $(-8\hat\beta_1 + 9\hat\beta_2)$ produce nearly identical predictions $x_1\hat\beta_1 + x_2\hat\beta_2$ whenever test points preserve $x_2 \approx x_1$! Predictions break only when deployment breaks the historical correlation between $x_1$ and $x_2$ ($x_0^\top(X^\top X)^{-1}x_0$ explodes along the near-null eigenvector of $X^\top X$).

    Reproduce Every Number on This Page

    Show the complete numerical check 
    import numpy as np

z = np.array([-1., -1., 1., 1.])
x = np.array([1., 3., 2., 4.])
y = np.array([5., 7., 11., 17.])

# Full OLS vs naive short OLS
X = np.column_stack([np.ones_like(x), x, z])
beta_full = np.linalg.lstsq(X, y, rcond=None)[0]
e_full = y - X @ beta_full
beta_naive = np.polyfit(x, y, 1)[0]
assert np.allclose(beta_full, [5.0, 2.0, 3.0])
assert np.isclose(beta_naive, 3.2)

# FWL residualization against Z = [1, z]
Z = np.column_stack([np.ones_like(z), z])
PZ = Z @ np.linalg.inv(Z.T @ Z) @ Z.T
MZ = np.eye(4) - PZ
x_tilde = MZ @ x
y_tilde = MZ @ y
beta_x_fwl = (x_tilde @ y_tilde) / (x_tilde @ x_tilde)
e_fwl = y_tilde - beta_x_fwl * x_tilde

assert np.allclose(PZ @ x, [2., 2., 3., 3.])
assert np.allclose(x_tilde, [-1., 1., -1., 1.])
assert np.allclose(PZ @ y, [6., 6., 14., 14.])
assert np.allclose(y_tilde, [-1., 1., -3., 3.])
assert np.isclose(beta_x_fwl, beta_full[1])
assert np.allclose(e_fwl, e_full)

# Exact VIF identity: [(X^T X)^(-1)]_{1,1} == VIF_x / S_xx
s_xx = np.sum((x - x.mean()) ** 2)
r2_xz = 1.0 - (x_tilde @ x_tilde) / s_xx
vif_x = 1.0 / (1.0 - r2_xz)
xtx_inv_xx = np.linalg.inv(X.T @ X)[1, 1]
assert np.isclose(r2_xz, 0.20)
assert np.isclose(vif_x, 1.25)
assert np.isclose(xtx_inv_xx, vif_x / s_xx)
print(f"FWL slope={beta_x_fwl:.4f}, R2_x|z={r2_xz:.4f}, VIF_x={vif_x:.4f}")
