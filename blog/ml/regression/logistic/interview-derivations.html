    Logistic Regression: Essential Interview Derivations

    July 2026 · 19 min read

    Memorizing ten isolated logistic regression equations for an interview or qualifying exam is fragile; seeing how every formula drops out of a single five-line chain makes the entire subject effortless to reconstruct on a blank whiteboard. Once you map a linear log-odds score $z = \beta^\top\tilde x$ through the logistic sigmoid $\sigma(z)$ and write down the Bernoulli log-likelihood, the residual gradient, Fisher-weighted Hessian, IRLS Newton step, multiclass softmax Jacobian, ridge coercivity, and Bayes cost threshold follow one after another with zero hand-waving.

    Derivation 1: Canonical Logit Link, Sigmoid Symmetry, and Derivative

    Let $\tilde x = (1, x_1, \dots, x_d)^\top \in \mathbb{R}^{d+1}$ be the intercept-augmented feature vector and $z = \beta^\top\tilde x \in (-\infty, +\infty)$ the linear predictor. Setting $z$ equal to the log-odds $\operatorname{logit}(p) = \ln\frac{p}{1-p}$ and solving for $p \in (0,1)$ defines the logistic sigmoid:

    $$\frac{p}{1-p} = e^z \iff p = \sigma(z) = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}, \qquad 1 - \sigma(z) = \frac{e^{-z}}{1 + e^{-z}} = \sigma(-z).$$

    Differentiating $(1 + e^{-z})^{-1}$ by the chain rule factors directly into Bernoulli variance $p(1-p)$:

    $$\sigma'(z) = \frac{d}{dz}(1 + e^{-z})^{-1} = \frac{e^{-z}}{(1 + e^{-z})^2} = \underbrace{\frac{1}{1 + e^{-z}}}_{\sigma(z)}\underbrace{\frac{e^{-z}}{1 + e^{-z}}}_{1 - \sigma(z)} = \sigma(z)\big(1 - \sigma(z)\big) \in \Big(0, \frac{1}{4}\Big],$$

    achieving its global maximum $\frac{1}{4}$ at $z = 0$ ($p = 0.5$) and decaying exponentially toward $0$ as $|z| \to \infty$.

    Derivation 2: Bernoulli MLE, Sign-Aware Softplus, and Proper Scoring

    For binary outcome $y_i \in \{0,1\}$ with $p_i = \Pr(Y_i = 1 \mid x_i) = \sigma(z_i)$, the compact Bernoulli PMF $\Pr(Y_i = y_i \mid x_i) = p_i^{y_i}(1 - p_i)^{1 - y_i}$ yields independent-sample log-likelihood $\ell(\beta) = \sum_{i=1}^n [y_i\ln p_i + (1-y_i)\ln(1-p_i)]$. Substituting $\ln\frac{p_i}{1-p_i} = z_i$ and $-\ln(1-p_i) = \ln(1 + e^{z_i}) = \operatorname{softplus}(z_i)$, maximizing $\ell(\beta)$ is identical to minimizing mean binary cross-entropy (log-loss):

    $$J(\beta) = -\frac{1}{n}\ell(\beta) = \frac{1}{n}\sum_{i=1}^{n}\big[\operatorname{softplus}(z_i) - y_i z_i\big] = \frac{1}{n}\sum_{i=1}^{n}\Big[\max(z_i, 0) + \ln\!\big(1 + e^{-|z_i|}\big) - y_i z_i\Big],$$

    where the sign-split form evaluates $e^{-|z_i|} \le 1$ so IEEE-754 float64 never overflows when $z_i \gg 709$.

    Population vs finite-sample calibration nuance: At the population level, expected log-loss $\mathbb{E}_{Y\sim\operatorname{Bern}(q)}[-Y\ln p - (1-Y)\ln(1-p)] = H(q) + D_{\mathrm{KL}}(q\,\|\,p)$ is uniquely minimized at $p = q$ (a strictly proper scoring rule). In finite samples or under model misspecification, logistic MLE does not guarantee conditional calibration $\Pr(Y{=}1\mid \hat p{=}q)=q$ everywhere; an unpenalized intercept only enforces aggregate in-sample balance $\frac{1}{n}\sum_{i=1}^n \hat p_i = \bar y$.

    Derivation 3: Residual Gradient and Central Finite-Difference Verification

    Differentiating single-row loss $\ell_i(z_i) = \ln(1 + e^{z_i}) - y_i z_i$ with respect to $z_i$ cancels the sigmoid denominator cleanly:

    $$\frac{\partial \ell_i}{\partial z_i} = \frac{e^{z_i}}{1 + e^{z_i}} - y_i = \sigma(z_i) - y_i = p_i - y_i.$$

    Applying $\frac{\partial z_i}{\partial \beta} = \tilde x_i$ and stacking rows $X \in \mathbb{R}^{n \times (d+1)}$, $p, y \in \mathbb{R}^n$ produces the matrix gradient:

    $$\nabla_\beta J(\beta) = \frac{1}{n}\sum_{i=1}^{n}(p_i - y_i)\,\tilde x_i = \frac{1}{n}X^\top(p - y).$$

    How should you unit-test custom gradient code? Taylor-expanding $J(\beta \pm \varepsilon e_j) = J(\beta) \pm \varepsilon \nabla_j J(\beta) + \frac{\varepsilon^2}{2}\nabla^2_{jj}J(\beta) \pm \frac{\varepsilon^3}{6}J^{(3)}_{jjj}(\beta) + O(\varepsilon^4)$ cancels the even $\varepsilon^2$ term in a central difference, leaving $O(\varepsilon^2) + O(u/\varepsilon)$ total error (minimized near $\varepsilon \approx u^{1/3} \approx 6\times 10^{-6}$ at $\sim 10^{-11}$ accuracy for float64 unit roundoff $u \approx 2.2\times 10^{-16}$), whereas a one-sided forward difference retains $O(\varepsilon)$ truncation error ($\sim 10^{-6}$ at $\varepsilon = 10^{-5}$):

    Six-row gradient verification at $\beta = (0.2, -0.5, 0.8)^\top$ ($J(\beta) = 1.043097$, step $\varepsilon = 10^{-5}$): central differences match analytic $\frac{1}{n}X^\top(p-y)$ to $11\text{--}12$ digits, outperforming forward differences by five orders of magnitude.

    Derivation 4: Positive-Semidefinite Hessian, Convexity, and Separation

    Differentiating $\nabla_\beta J(\beta) = \frac{1}{n}\sum_{i=1}^n (\sigma(\tilde x_i^\top\beta) - y_i)\tilde x_i$ a second time via $\frac{\partial p_i}{\partial \beta^\top} = p_i(1-p_i)\tilde x_i^\top$ gives the exact Fisher-weighted Hessian ($W = \operatorname{diag}(p_i(1-p_i))$):

    $$\nabla^2_\beta J(\beta) = \frac{1}{n}\sum_{i=1}^{n}p_i(1-p_i)\,\tilde x_i\tilde x_i^\top = \frac{1}{n}X^\top W X.$$

    For every vector $v \in \mathbb{R}^{d+1}$, the quadratic form is a sum of nonnegative squares bounded above using $p_i(1-p_i) \le \frac{1}{4}$:

    $$0 \le v^\top\nabla^2_\beta J(\beta)\,v = \frac{1}{n}\sum_{i=1}^{n}\underbrace{p_i(1-p_i)}_{> 0\text{ for finite }\beta}(\tilde x_i^\top v)^2 \le \frac{1}{4n}\|Xv\|_2^2 \implies 0 \preceq \nabla^2_\beta J(\beta) \preceq \frac{1}{4n}X^\top X.$$
    Uniqueness vs existence trap: If $\operatorname{rank}(X) = d+1$, then $X v \ne 0$ for every $v \ne 0$, so $\nabla^2_\beta J(\beta) \succ 0$ at every finite $\beta$ and $J(\beta)$ is strictly convex. Strict convexity guarantees at most one finite minimizer, not that one exists! Under Albert & Anderson (1984) complete separation ($(2y_i-1)\tilde x_i^\top u > 0$ for all $i$), $J(t u) \downarrow 0$ strictly as $t \to +\infty$, so the infimum is unattained at any finite $\hat\beta$.

    Derivation 5: One Newton Step Is Weighted Least Squares (IRLS)

    Substituting $\nabla J = \frac{1}{n}X^\top(p - y)$ and $\nabla^2 J = \frac{1}{n}X^\top W X$ into Newton's update $\beta^{+} = \beta - (\nabla^2 J)^{-1}\nabla J$ cancels $\frac{1}{n}$ and absorbs $\beta = (X^\top W X)^{-1}(X^\top W X)\beta$ into a single normal equation:

    $$\beta^{+} = \beta + \big(X^\top W X\big)^{-1}X^\top(y - p) = \big(X^\top W X\big)^{-1}X^\top W\,\underbrace{\big(X\beta + W^{-1}(y - p)\big)}_{\xi\text{ (working response)}},$$

    where $\xi_i = z_i + \frac{y_i - p_i}{p_i(1 - p_i)}$ is the first-order Taylor linearization of $\operatorname{logit}(y)$ around $p_i$. Solving the SPD linear system $(X^\top W X)\beta^{+} = X^\top W \xi$ via Cholesky/QR at each iteration is Iteratively Reweighted Least Squares (IRLS).

    Derivation 6: Max-Shifted Softmax, Its Jacobian, and Mean Gradient $\frac{1}{n}X^\top(\hat P - Y)$

    For $K$ classes with logit vector $z = W^\top\tilde x \in \mathbb{R}^K$ ($W \in \mathbb{R}^{(d+1)\times K}$) and $p_k = \frac{e^{z_k}}{\sum_{c=1}^K e^{z_c}}$, subtracting $m = \max_c z_c$ prevents overflow because $e^{z_c - m} \le 1$ and $\sum_c e^{z_c - m} \ge 1$:

    $$\operatorname{LSE}(z) = m + \ln\sum_{c=1}^{K} e^{z_c - m}, \qquad \ln p_k = z_k - \operatorname{LSE}(z).$$

    Differentiating $p_k = e^{z_k}\big(\sum_c e^{z_c}\big)^{-1}$ with respect to $z_j$ yields the symmetric PSD Jacobian ($\delta_{kj} = \mathbb{I}(k=j)$):

    $$\frac{\partial p_k}{\partial z_j} = p_k\big(\delta_{kj} - p_j\big), \qquad \frac{\partial}{\partial z_j}\Big(-\sum_{k=1}^{K} y_k \ln p_k\Big) = -\sum_{k=1}^{K} y_k\big(\delta_{kj} - p_j\big) = \Big(\sum_{k=1}^{K} y_k\Big)p_j - y_j = p_j - y_j$$

    since the one-hot target satisfies $\sum_{k=1}^K y_k = 1$! Stacking $n$ rows into $X \in \mathbb{R}^{n\times(d+1)}$, $\hat P \in \mathbb{R}^{n\times K}$, and one-hot $Y \in \{0,1\}^{n\times K}$, the mean cross-entropy objective $J(W) = -\frac{1}{n}\sum_{i=1}^n \sum_{k=1}^K y_{ik}\ln \hat p_{ik}$ has exact matrix gradient:

    $$\nabla_W J(W) = \frac{1}{n}X^\top\big(\hat P - Y\big) \in \mathbb{R}^{(d+1)\times K}$$

    (whereas the unaveraged sum objective $-\sum_i \sum_k y_{ik}\ln\hat p_{ik}$ has gradient $X^\top(\hat P - Y)$—always keep the $\frac{1}{n}$ convention matched between loss and gradient!).

    Derivation 7: $L_2$ Coercivity Restores Finite, Unique Existence

    Let $R = \operatorname{diag}(0, 1, \dots, 1) \in \mathbb{R}^{(d+1)\times(d+1)}$ penalize slopes $\beta_{1:d}$ while sparing the intercept $\beta_0$:

    $$J_\lambda(\beta) = J(\beta) + \frac{\lambda}{2}\beta^\top R\beta, \qquad \nabla J_\lambda(\beta) = \frac{1}{n}X^\top(p - y) + \lambda R\beta, \qquad \nabla^2 J_\lambda(\beta) = \frac{1}{n}X^\top W X + \lambda R.$$

    Whenever $\lambda > 0$ and both classes appear in training ($0 < \bar y < 1$), $J_\lambda(\beta) \to +\infty$ as $\|\beta\|_2 \to \infty$ (coercivity) and $\nabla^2 J_\lambda(\beta) \succ 0$ everywhere—guaranteeing a unique, finite minimizer $\hat\beta_\lambda$ even under complete separation or exact collinearity among features.

    Derivation 8: Conditional Odds Ratios, Marginal Slopes, and Non-Collapsibility

    Assuming no interaction or nonlinear terms involve $x_j$, holding $\tilde x_{-j}$ fixed and incrementing $x_j \mapsto x_j + c$ adds $c\beta_j$ to the log-odds, multiplying conditional odds by $e^{c\beta_j}$ ($e^{\beta_j}$ for $c = 1$):

    $$\ln\frac{p(x_j + c, \tilde x_{-j})}{1 - p(x_j + c, \tilde x_{-j})} - \ln\frac{p(x_j, \tilde x_{-j})}{1 - p(x_j, \tilde x_{-j})} = c\beta_j, \qquad \frac{\partial p}{\partial x_j} = \beta_j\,p(1 - p),$$

    while the $p = 0.5$ contour $\beta^\top\tilde x = 0$ is a linear hyperplane. Remember two classic interview qualifiers from Part 1: (i) probability slopes $\beta_j p(1-p)$ depend on baseline risk $p$, and (ii) because $\sigma$ is nonlinear, conditional odds ratios are non-collapsible—omitting an independent predictor $Z \perp\!\!\!\perp X_j$ pulls the marginal odds ratio strictly toward $1$!

    Derivation 9: Bayes Optimal Threshold and Label-Shift Intercept Adjustment

    Given calibrated posterior $p = \Pr(Y=1\mid x)$ and $2\times 2$ cost matrix $C_{\mathrm{TP}}, C_{\mathrm{TN}}, C_{\mathrm{FP}}, C_{\mathrm{FN}}$ satisfying dominance $C_{\mathrm{FP}} > C_{\mathrm{TN}}$ and $C_{\mathrm{FN}} > C_{\mathrm{TP}}$, predict $\hat y = 1$ iff expected positive-action cost $p C_{\mathrm{TP}} + (1-p)C_{\mathrm{FP}}$ does not exceed expected negative-action cost $p C_{\mathrm{FN}} + (1-p)C_{\mathrm{TN}}$:

    $$p \ge \tau^\star = \frac{C_{\mathrm{FP}} - C_{\mathrm{TN}}}{(C_{\mathrm{FP}} - C_{\mathrm{TN}}) + (C_{\mathrm{FN}} - C_{\mathrm{TP}})} \xrightarrow{C_{\mathrm{TP}} = C_{\mathrm{TN}} = 0} \frac{C_{\mathrm{FP}}}{C_{\mathrm{FP}} + C_{\mathrm{FN}}}.$$

    If class prevalence changes from $\pi_{\mathrm{train}}$ to $\pi_{\mathrm{dep}}$ under label shift ($P(X\mid Y)$ invariant), first update $\operatorname{logit}(p_{\mathrm{dep}}) = \operatorname{logit}(p_{\mathrm{train}}) + \operatorname{logit}(\pi_{\mathrm{dep}}) - \operatorname{logit}(\pi_{\mathrm{train}})$, then apply $\tau^\star$ directly.

    High-Frequency Interview Distinctions

    Interview PromptCrisp First-Principles Answer
    Why not minimize $\frac{1}{2n}\sum_i (\sigma(z_i) - y_i)^2$?Squared sigmoid loss is non-convex ($\frac{d^2}{dz^2}\frac{1}{2}(\sigma(z)-0)^2 < 0$ for $z > \ln 2$) and suffers vanishing gradients $(p_i-y_i)p_i(1-p_i) \to 0$ on confident errors; log-loss divides out $p_i(1-p_i)$ via the canonical link!
    Does squaring every probability $\hat p_i \mapsto \hat p_i^2$ change ROC-AUC or AP?No—$q \mapsto q^2$ is strictly increasing on $[0,1]$, preserving all pairwise ranks. Log-loss, Brier score, ECE, and optimal threshold decisions degrade sharply.
    Why does PR-AUC drop under $1{:}500$ class imbalance when ROC-AUC stays $0.96$?PR does not ignore negatives—false positives $\mathrm{FP}(\tau)$ sit in $\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$! Instead PR omits true negatives $\mathrm{TN}(\tau)$, which inflate the ROC denominator $N = \mathrm{FP}+\mathrm{TN}$.
    Does unpenalized $K$-class softmax have a unique MLE?No—adding $c \in \mathbb{R}^{d+1}$ to every column of $W$ leaves all probabilities unchanged. Adding ridge $\frac{\lambda}{2}\|W_{1:d,:}\|_F^2$ forces $\sum_k \hat W_{1:d,k} = 0$ and shrinks probabilities toward uniform.
    Does tuning decision threshold $\tau$ calibrate a model?Never—$\tau$ converts probabilities into hard $\{0,1\}$ actions without changing $\hat p_i$. Calibrate scores first (Platt / isotonic), then apply $\tau^\star$.

    import numpy as np

# 1. Binary gradient, Hessian PSD bound, IRLS identity, and central vs forward FD check
X = np.array([[1, 0.5, -1.0], [1, -1.5, 0.7], [1, 2.0, 0.3],
              [1, -0.4, -0.8], [1, 1.2, 1.5], [1, -2.1, -0.2]])
Y = np.array([1.0, 0.0, 1.0, 0.0, 1.0, 0.0])
beta = np.array([0.2, -0.5, 0.8])

def loss(b):
    z = X @ b
    return np.mean(np.maximum(z, 0.0) + np.log1p(np.exp(-np.abs(z))) - Y * z)

z = X @ beta
p = np.where(z >= 0, 1 / (1 + np.exp(-z)), np.exp(z) / (1 + np.exp(z)))
w = p * (1 - p)
grad = (X.T @ (p - Y)) / len(Y)
hess = (X.T * w) @ X / len(Y)

eps = 1e-5
cfd = np.array([(loss(beta + eps * e) - loss(beta - eps * e)) / (2 * eps) for e in np.eye(3)])
ffd = np.array([(loss(beta + eps * e) - loss(beta)) / eps for e in np.eye(3)])
assert np.max(np.abs(grad - cfd)) < 1e-11 and np.max(np.abs(grad - ffd)) > 5e-7

# Verify Newton step == IRLS weighted normal equation
beta_newton = beta - np.linalg.solve(hess, grad)
xi = z + (Y - p) / w
beta_irls = np.linalg.solve((X.T * w) @ X, (X.T * w) @ xi)
assert np.allclose(beta_newton, beta_irls)

# 2. Verify mean K-class softmax gradient (1/n) * X^T (P - Y_onehot)
W = np.array([[0.1, -0.2, 0.0], [0.4, -0.3, 0.2], [-0.5, 0.6, -0.1]])
Y_mc = np.eye(3)[[0, 1, 2, 0, 2, 1]]
def mc_loss(Wm):
    Z = X @ Wm
    m = Z.max(axis=1, keepdims=True)
    lse = m + np.log(np.sum(np.exp(Z - m), axis=1, keepdims=True))
    return -np.mean(np.sum(Y_mc * (Z - lse), axis=1))

Z = X @ W
P = np.exp(Z - Z.max(axis=1, keepdims=True))
P /= P.sum(axis=1, keepdims=True)
grad_W = (X.T @ (P - Y_mc)) / len(X)
E01 = np.zeros_like(W); E01[1, 2] = eps
assert np.isclose(grad_W[1, 2], (mc_loss(W + E01) - mc_loss(W - E01)) / (2 * eps), atol=1e-10)
print(f"J(beta)={loss(beta):.6f}, max|grad - central_FD|={np.max(np.abs(grad - cfd)):.2e}, IRLS==Newton OK, Softmax 1/n grad OK")
