    Multiclass Logistic and Softmax Regression

    July 2026 · 20 min read

    When an outcome belongs to exactly one of $K \ge 3$ mutually exclusive categories—such as routing a support ticket to billing, technical, or cancellation—every prediction must divide a single unit of probability across all $K$ classes. Fitting $K$ separate binary "one-vs-rest" (OvR) models lets each classifier estimate $\Pr(Y=k\mid x)$ in isolation without knowing the others exist: in ambiguous regions their probabilities can sum to $0.30$, while in overlapping regions they can sum to $1.75$.

    Multinomial logistic regression (softmax regression) couples all $K$ linear scores inside a single normalizing denominator so that $\hat p_k(x) > 0$ and $\sum_{k=1}^K \hat p_k(x) = 1$ identically, extending the Bernoulli exponential-family geometry cleanly to categorical outcomes.

    One-vs-Rest vs. Joint Multinomial Softmax

    For augmented feature vector $\tilde x = (1, x_1, \dots, x_d)^\top \in \mathbb{R}^{d+1}$, assign each class $k \in \{1,\dots,K\}$ a parameter column $\beta_k = (\beta_{0,k}, \beta_{1:d,k}^\top)^\top \in \mathbb{R}^{d+1}$, stacked into the weight matrix $W = [\beta_1, \dots, \beta_K] \in \mathbb{R}^{(d+1)\times K}$ with logit vector $z = W^\top \tilde x = (z_1,\dots,z_K)^\top \in \mathbb{R}^K$. Softmax exponentiates each score to make it strictly positive and normalizes by their sum:

    $$\hat p_k = \Pr(Y = k \mid x; W) = \operatorname{softmax}(z)_k = \frac{e^{z_k}}{\sum_{l=1}^{K} e^{z_l}}, \qquad k = 1,\dots,K.$$

    Pairwise log-odds between any two classes $k$ and $l$ remain strictly linear in $\tilde x$: $\ln(\hat p_k / \hat p_l) = z_k - z_l = (\beta_k - \beta_l)^\top \tilde x$. When $K = 2$, dividing numerator and denominator by $e^{z_2}$ recovers binary logistic regression with parameter $\beta = \beta_1 - \beta_2$:

    $$\hat p_1 = \frac{e^{z_1}}{e^{z_1} + e^{z_2}} = \frac{1}{1 + e^{-(z_1 - z_2)}} = \sigma(z_1 - z_2).$$

    Whereas OvR fits $K$ decoupled binary problems (appropriate for multi-label tagging where classes are non-exclusive, or as a embarrassingly parallel heuristic followed by ad-hoc $L_1$ normalization $\tilde q_k / \sum_l \tilde q_l$), multinomial softmax optimizes the exact joint categorical likelihood.

    Shift Invariance, Stable Log-Sum-Exp, and Worked 3-Class Walkthrough

    Adding any scalar $c \in \mathbb{R}$ to every logit leaves softmax unchanged because $e^c$ factors out of numerator and denominator: $\operatorname{softmax}(z + c\mathbf{1}_K) = \operatorname{softmax}(z)$. Choosing $c = -m$ where $m = \max_{1\le l\le K} z_l$ guarantees every exponent $z_k - m \le 0$ lies safely in $(0,1]$, with at least one term equal to $e^0 = 1$ (ruling out both overflow to $\infty$ and simultaneous underflow to $0/0$):

    $$\operatorname{softmax}(z)_k = \frac{e^{z_k - m}}{\sum_{l=1}^{K} e^{z_l - m}}, \qquad \operatorname{LSE}(z) = \ln\sum_{l=1}^{K} e^{z_l} = m + \ln\sum_{l=1}^{K} e^{z_l - m}.$$

    For a row whose true class is $c_i \in \{1,\dots,K\}$—encoded as one-hot vector $y_i = e_{c_i} \in \{0,1\}^K$ with $y_{i,c_i}=1$ and $0$ elsewhere—the single-row categorical cross-entropy loss is

    $$\ell_i(z_i, y_i) = -\sum_{k=1}^{K} y_{ik}\ln \hat p_{ik} = -\ln \hat p_{i,c_i} = \operatorname{LSE}(z_i) - z_{i,c_i}.$$

    Differentiating $\operatorname{LSE}(z_i) - z_{i,c_i}$ with respect to $z_{ik}$ gives $\frac{\partial \ell_i}{\partial z_{ik}} = \hat p_{ik} - y_{ik}$. Notice that $\sum_{k=1}^K (\hat p_{ik} - y_{ik}) = 1 - 1 = 0$: boosting the true class's logit simultaneously pushes down every rival class's logit in exact proportion to its predicted probability share!

    Matrix Gradient and Variance-Form Block Hessian

    Stacking row probabilities into $\hat P \in (0,1)^{n\times K}$ and one-hot labels into $Y \in \{0,1\}^{n\times K}$, the mean categorical cross-entropy $J(W) = \frac{1}{n}\sum_{i=1}^n [\operatorname{LSE}(z_i) - z_{i,c_i}]$ has compact matrix gradient:

    $$\nabla_W J(W) = \frac{1}{n}X^\top\big(\hat P - Y\big) \in \mathbb{R}^{(d+1)\times K}, \qquad \nabla_{\beta_k} J(W) = \frac{1}{n}\sum_{i=1}^{n}(\hat p_{ik} - y_{ik})\tilde x_i.$$

    Using $\frac{\partial \hat p_k}{\partial z_l} = \hat p_k(\delta_{kl} - \hat p_l)$, the $(d+1)\times(d+1)$ second-derivative block coupling $\beta_k$ and $\beta_l$ is

    $$\nabla^2_{\beta_k,\beta_l} J(W) = \frac{1}{n}\sum_{i=1}^{n}\hat p_{ik}(\delta_{kl} - \hat p_{il})\,\tilde x_i \tilde x_i^\top, \qquad M(p_i) = \operatorname{diag}(p_i) - p_i p_i^\top \in \mathbb{R}^{K\times K}.$$

    Why is $M(p_i)$ always positive semidefinite—and why is it singular? For any test vector $u = (u_1,\dots,u_K)^\top \in \mathbb{R}^K$, let $C \sim \mathrm{Categorical}(p_i)$:

    $$u^\top\big(\operatorname{diag}(p_i) - p_i p_i^\top\big)u = \sum_{k=1}^{K} p_{ik} u_k^2 - \left(\sum_{k=1}^{K} p_{ik} u_k\right)^2 = \operatorname{Var}_{C\sim p_i}(u_C) = \sum_{k=1}^{K} p_{ik}(u_k - \bar u_i)^2 \ge 0.$$

    Variance is always non-negative (proving global convexity of $J(W)$!), and since every $p_{ik} > 0$ at finite $W$, $\operatorname{Var}(u_C) = 0$ if and only if $u_1 = \dots = u_K$, meaning $\ker M(p_i) = \operatorname{span}\{\mathbf{1}_K\}$.

    Gauge Identifiability vs. $L_2$ Shrinkage: A Crucial Distinction

    Because $\ker M(p_i) = \operatorname{span}\{\mathbf{1}_K\}$, shifting every class column by a common vector $v \in \mathbb{R}^{d+1}$ ($\beta_k \mapsto \beta_k + v$ for all $k=1,\dots,K$) leaves every logit difference $z_{ik} - z_{il}$ and every probability $\hat p_{ik}$ unchanged. Unregularized softmax ($\lambda = 0$) therefore has $(d+1)(K-1)$ identifiable degrees of freedom, which can be fixed without altering $\hat p(x)$ by either:

    • Reference-class coding ($\beta_K = 0$): pins class $K$ as baseline so $\beta_k^\top \tilde x = \ln(\hat p_k / \hat p_K)$ for $k=1,\dots,K-1$ (standard in econometrics and statsmodels.MNLogit).
    • Sum-to-zero coding ($\sum_{k=1}^K \beta_k = 0$): centers logits around the geometric mean probability $\beta_k^\top \tilde x = \ln\big(\hat p_k / (\prod_l \hat p_l)^{1/K}\big)$.
    Do not confuse $\lambda=0$ gauge choice with $\lambda > 0$ $L_2$ regularization! Adding a symmetric slope penalty $J_{L_2}(W) = J(W) + \frac{\lambda}{2}\sum_{k=1}^K \|\beta_{1:d,k}\|_2^2$ ($\lambda > 0$) does not merely pick the centered gauge representative of the unregularized model:
    1. Summing the stationary conditions $\sum_{k=1}^K \nabla_{\beta_{1:d,k}} J_{L_2}(\hat W) = \frac{1}{n}X_{1:d}^\top\sum_{k=1}^K(\hat P_{\cdot k} - Y_{\cdot k}) + \lambda\sum_{k=1}^K \hat\beta_{1:d,k} = \lambda\sum_{k=1}^K \hat\beta_{1:d,k} = 0$ automatically enforces $\sum_{k=1}^K \hat\beta_{1:d,k} = 0$.
    2. And simultaneously, $\lambda > 0$ actively shrinks pairwise slope differences $\|\hat\beta_{1:d,k} - \hat\beta_{1:d,l}\|_2$ toward $0$, pulling predicted probabilities $\hat p(x)$ away from the unregularized MLE toward uniform/base-rate probabilities! Moreover, penalizing only $K-1$ classes with $\beta_K = 0$ breaks label symmetry and yields different probabilities depending on which class is chosen as reference $K$.

    Convex Piecewise-Linear Decision Regions and Cost-Sensitive Actions

    Under equal $0\text{--}1$ misclassification loss, $\arg\max_k \hat p_k(x) = \arg\max_k z_k(x)$. Each region $\mathcal{R}_k = \{x\in\mathbb{R}^d : (\beta_k - \beta_l)^\top \tilde x \ge 0\;\forall l \ne k\}$ is an intersection of $K-1$ closed half-spaces—hence convex and piecewise-linear, with pairwise boundaries meeting at a triple point in $\mathbb{R}^2$. Under general action-class cost matrix $C(a, k)$ (cost of taking action $a$ when true class is $k$), the Bayes decision rule minimizes expected conditional risk:

    $$\hat a(x) = \arg\min_{a \in \mathcal{A}} \sum_{k=1}^{K} C(a, k)\,\hat p_k(x).$$

    Verify Max-Shift Softmax, Hessian Variance Form, and Gauge vs. $L_2$ Shrinkage in Python

    Show the complete numerical check 
    import numpy as np
from scipy.optimize import minimize
from scipy.special import softmax, logsumexp

# 1. Single-row 3-class worked table + float64 overflow safety
z = np.array([12.0, 10.0, 8.0])
m = np.max(z)
p = np.exp(z - m) / np.sum(np.exp(z - m))
lse = m + np.log(np.sum(np.exp(z - m)))
grad_z = p - np.array([1.0, 0.0, 0.0])
assert np.allclose(p, [0.86681333, 0.11731043, 0.01587624])
assert np.isclose(lse - z[0], -np.log(p[0]))
assert np.isclose(np.sum(grad_z), 0.0)

z_big = np.array([1000.0, 1001.0, 1002.0])
p_big = np.exp(z_big - np.max(z_big)) / np.sum(np.exp(z_big - np.max(z_big)))
assert np.allclose(p_big, [0.09003057, 0.24472847, 0.66524096])

# 2. Verify gauge invariance at lambda=0 vs shrinkage & ref-dependence at lambda=0.2
xm = np.array([-2.0, -1.0, -0.5, 0.0, 0.5, 0.8, 1.0, 1.2, 2.0])
ym = np.array([0, 0, 1, 0, 1, 1, 2, 1, 2])
X = np.column_stack([np.ones_like(xm), xm])
Y = np.eye(3)[ym]
n = len(xm)

def fit_multinomial(lam, ref=None):
    if ref is None:
        def obj(th):
            W = th.reshape(2, 3)
            Z = X @ W
            loss = np.mean(logsumexp(Z, axis=1) - Z[np.arange(n), ym]) + 0.5 * lam * np.sum(W[1] ** 2)
            G = (X.T @ (softmax(Z, axis=1) - Y)) / n
            G[1] += lam * W[1]
            return loss, G.ravel()
        W = minimize(obj, np.zeros(6), jac=True, method="BFGS", options={"gtol": 1e-12}).x.reshape(2, 3)
        W[0] -= np.mean(W[0])
        return W
    free = [k for k in range(3) if k != ref]
    def obj_r(th):
        W = np.zeros((2, 3))
        W[:, free] = th.reshape(2, 2)
        Z = X @ W
        loss = np.mean(logsumexp(Z, axis=1) - Z[np.arange(n), ym]) + 0.5 * lam * np.sum(W[1, free] ** 2)
        G = (X.T @ (softmax(Z, axis=1) - Y))[:, free] / n
        G[1] += lam * W[1, free]
        return loss, G.ravel()
    W = np.zeros((2, 3))
    W[:, free] = minimize(obj_r, np.zeros(4), jac=True, method="BFGS", options={"gtol": 1e-12}).x.reshape(2, 2)
    return W

xq = np.array([1.0, 1.5])
p0_sym = softmax(xq @ fit_multinomial(0.0, ref=None))
p0_ref = softmax(xq @ fit_multinomial(0.0, ref=2))
assert np.allclose(p0_sym, p0_ref, atol=1e-7)  # Gauge-equivalent at lambda=0!

W_l2 = fit_multinomial(0.2, ref=None)
assert np.isclose(np.sum(W_l2[1]), 0.0, atol=1e-9)  # Symmetric L2 enforces sum_k w_k = 0
p_l2_sym = softmax(xq @ W_l2)
p_l2_ref2 = softmax(xq @ fit_multinomial(0.2, ref=2))
assert not np.allclose(p0_sym, p_l2_sym, atol=1e-2)  # L2 shrinks probabilities!
assert not np.allclose(p_l2_sym, p_l2_ref2, atol=1e-2)  # Ref-class L2 differs!
print("p(1.5) MLE:", np.round(p0_sym, 4), "Sym L2:", np.round(p_l2_sym, 4), "Ref3 L2:", np.round(p_l2_ref2, 4))
