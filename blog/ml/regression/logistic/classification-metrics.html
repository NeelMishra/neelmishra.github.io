    Confusion Matrix, ROC-AUC, PR-AUC, and Log-Loss

    July 2026 · 21 min read

    Why do two engineers evaluating the exact same logistic regression model often disagree about whether it is ready to ship? Usually because they are grading different layers of its output! A binary probabilistic model produces three distinct objects, and each object has its own metric family:

    1. A relative ordering of scores $s_1,\dots,s_n$: do true positives bubble above true negatives across thresholds? Graded by ranking metrics (ROC-AUC, Average Precision).
    2. A hard binary action $\hat y_i = \mathbb{I}(\hat p_i \ge \tau)$ at one chosen cut $\tau$: how many positives are caught and how many false alarms fire? Graded by confusion-matrix metrics (Precision, Recall, Specificity, $F_\beta$, MCC).
    3. A numerical probability $\hat p_i \in (0,1)$: when the model says $0.80$, does the event actually happen $80\%$ of the time? Graded by strictly proper scoring rules (Log-loss, Brier score).

    Confusion-Matrix Rates, $F_\beta$ Harmonic Weighting, and MCC

    Fix a threshold $\tau \in (0,1)$ and partition the $n = P + N$ observations ($P$ actual positives $y_i=1$, $N$ actual negatives $y_i=0$) into true positives ($\mathrm{TP}$), false positives ($\mathrm{FP}$), false negatives ($\mathrm{FN}$), and true negatives ($\mathrm{TN}$). Notice which denominator each rate conditions on:

    $$\mathrm{Precision} = \Pr(Y{=}1\mid \hat Y{=}1) = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FP}}, \qquad \mathrm{Recall} = \mathrm{TPR} = \Pr(\hat Y{=}1\mid Y{=}1) = \frac{\mathrm{TP}}{P},$$ $$\mathrm{Specificity} = \mathrm{TNR} = \Pr(\hat Y{=}0\mid Y{=}0) = \frac{\mathrm{TN}}{N}, \qquad \mathrm{FPR} = 1 - \mathrm{TNR} = \Pr(\hat Y{=}1\mid Y{=}0) = \frac{\mathrm{FP}}{N}.$$

    When $99\%$ of rows are negative, a trivial classifier predicting $\hat y_i \equiv 0$ achieves $99\%$ accuracy ($\frac{\mathrm{TP}+\mathrm{TN}}{n}$) with $0\%$ recall. Single-number threshold summaries avoid this trap in different ways:

    • $F_\beta$ score (Van Rijsbergen, 1979): the weighted harmonic mean assigning weight $\frac{1}{1+\beta^2}$ to $\mathrm{Prec}^{-1}$ and $\frac{\beta^2}{1+\beta^2}$ to $\mathrm{Rec}^{-1}$ so recall is valued $\beta$ times as much as precision: $$F_\beta = \left(\frac{1}{1+\beta^2}\frac{1}{\mathrm{Prec}} + \frac{\beta^2}{1+\beta^2}\frac{1}{\mathrm{Rec}}\right)^{-1} = \frac{(1+\beta^2)\,\mathrm{Prec}\cdot\mathrm{Rec}}{\beta^2\,\mathrm{Prec} + \mathrm{Rec}} = \frac{(1+\beta^2)\,\mathrm{TP}}{(1+\beta^2)\,\mathrm{TP} + \beta^2\,\mathrm{FN} + \mathrm{FP}}.$$ Notice $\mathrm{TN}$ never enters $F_\beta$.
    • Matthews Correlation Coefficient (MCC): the exact Pearson product-moment correlation ($\phi$-coefficient) between binary vectors $\hat Y$ and $Y$, symmetric across all four cells: $$\mathrm{MCC} = \frac{\mathrm{TP}\cdot\mathrm{TN} - \mathrm{FP}\cdot\mathrm{FN}}{\sqrt{(\mathrm{TP}+\mathrm{FP})(\mathrm{TP}+\mathrm{FN})(\mathrm{TN}+\mathrm{FP})(\mathrm{TN}+\mathrm{FN})}} \in [-1, +1],$$ defined by convention as $0$ whenever a row or column sum vanishes (such as $\hat y_i \equiv 0$).

    ROC-AUC and the Exact Wilcoxon–Mann–Whitney Tie Formula

    Sweeping $\tau$ from $+\infty$ down to $-\infty$ traces the Receiver Operating Characteristic (ROC) curve $(\mathrm{FPR}(\tau), \mathrm{TPR}(\tau))$ from $(0,0)$ to $(1,1)$. By Green's theorem / trapezoidal integration across score groups, the geometric area under the ROC curve equals the Wilcoxon–Mann–Whitney statistic (Hanley & McNeil, 1982; Fawcett, 2006)—including an explicit half-credit term for tied positive-negative pairs:

    $$\mathrm{AUC}_{\mathrm{ROC}} = \Pr(S^+ > S^-) + \frac{1}{2}\Pr(S^+ = S^-) = \frac{1}{P N}\sum_{i : y_i = 1}\sum_{j : y_j = 0}\Big[\mathbb{I}(s_i > s_j) + \frac{1}{2}\mathbb{I}(s_i = s_j)\Big].$$

    Why must ties receive exact weight $\frac{1}{2}$? Geometrically, if a tied score threshold admits $\Delta\mathrm{TP}$ positives and $\Delta\mathrm{FP}$ negatives simultaneously, the ROC curve moves diagonally from $(\mathrm{FPR}_0, \mathrm{TPR}_0)$ to $(\mathrm{FPR}_0 + \frac{\Delta\mathrm{FP}}{N}, \mathrm{TPR}_0 + \frac{\Delta\mathrm{TP}}{P})$, adding trapezoid area $\frac{\Delta\mathrm{FP}}{N}\mathrm{TPR}_0 + \frac{1}{2}\frac{\Delta\mathrm{FP}\cdot\Delta\mathrm{TP}}{NP}$—identical to awarding $\frac{1}{2}$ to each of the $\Delta\mathrm{TP}\cdot\Delta\mathrm{FP}$ tied pairs! Omitting the $\frac{1}{2}$ term would wrongly award a constant score $s_i \equiv c$ an AUC of $0$ instead of $0.5$.

    Precision–Recall, True-Negative Inflation, and Average Precision Step Rectangles

    Clarifying a common myth: PR curves do NOT "ignore negatives"! Look at $\mathrm{Prec}(\tau) = \frac{\mathrm{TP}(\tau)}{\mathrm{TP}(\tau) + \mathrm{FP}(\tau)}$: false positives $\mathrm{FP}(\tau)$ are negative observations scored above $\tau$! High-scoring negatives severely penalize precision. What PR omits is true negatives $\mathrm{TN}(\tau)$—the vast pool of easy negatives sitting safely below $\tau$. In a $1{:}200$ rare-event screen ($P=50, N=10{,}000$), admitting $100$ upper-tail negatives yields a tiny $\mathrm{FPR} = 100/10{,}000 = 1.0\%$ on the ROC curve, yet swamps the $50$ positives so $\mathrm{Prec} = 50/(50+100) = 33.3\%$ on the PR curve!

    How should we integrate under a discrete PR curve? Davis & Goadrich (2006) showed that naive linear trapezoidal interpolation between sparse PR points is overly optimistic because straight lines in ROC space map to hyperbolic curves $\frac{\mathrm{TP}_0 + x}{\mathrm{TP}_0 + x + \mathrm{FP}_0 + \alpha x}$ in PR space. Standard libraries (sklearn.metrics.average_precision_score) therefore compute Average Precision (AP) as the exact area of right-continuous step-function rectangles evaluated at every recall jump:

    $$\mathrm{AP} = \sum_{k=1}^{n}\big(R_k - R_{k-1}\big) P_k = \frac{1}{P}\sum_{k=1}^{n} y_{(k)}\,P_k,$$

    where $(1),\dots,(n)$ sorts scores descending, $R_0 = 0$, and $P_k, R_k$ are precision and recall after admitting the top $k$ items. Whereas random ranking always has $\mathbb{E}[\mathrm{AUC}_{\mathrm{ROC}}] = 0.50$, random ranking has $\mathbb{E}[\mathrm{AP}] \approx \frac{P}{P+N}$ (the class prevalence).

    Strictly Proper Scoring Rules and Sampling Uncertainty

    Any strictly increasing score distortion—such as replacing $\hat p$ with $\hat p^3$ or $0.5 + 0.01\hat p$—leaves ROC-AUC and AP completely unchanged while ruining cost-based decisions! Evaluating probabilities directly requires strictly proper scoring rules (Gneiting & Raftery, 2007):

    $$\mathrm{LogLoss} = -\frac{1}{n}\sum_{i=1}^{n}\big[y_i\ln \hat p_i + (1-y_i)\ln(1-\hat p_i)\big], \qquad \mathrm{Brier} = \frac{1}{n}\sum_{i=1}^{n}(\hat p_i - y_i)^2.$$

    Finally, finite test sets carry non-negligible variance—especially when $P$ is small! Report DeLong (1988) or cluster-paired bootstrap confidence intervals for ROC-AUC, stratified bootstrap intervals for AP, and Wilson score intervals (never naive Wald $\hat p \pm 1.96\sqrt{\hat p(1-\hat p)/n}$, which collapses at $0$ or $1$) for binomial rates.

    Show the complete numerical check 
    import numpy as np
from sklearn.metrics import roc_auc_score, average_precision_score, matthews_corrcoef

S = np.array([0.95, 0.90, 0.80, 0.75, 0.65, 0.55, 0.50, 0.40, 0.30, 0.20])
Y = np.array([1, 1, 0, 1, 1, 0, 1, 0, 0, 0])

# 1. Exact WMW formula with half-credit ties vs sklearn.metrics.roc_auc_score
def wmw_auc(y, s):
    pos, neg = s[y == 1], s[y == 0]
    wins = np.sum(pos[:, None] > neg[None, :])
    ties = np.sum(pos[:, None] == neg[None, :])
    return (wins + 0.5 * ties) / (len(pos) * len(neg))

assert np.isclose(wmw_auc(Y, S), 21 / 25) and np.isclose(roc_auc_score(Y, S), 0.84)
S_tied = np.array([0.95, 0.90, 0.75, 0.75, 0.65, 0.55, 0.50, 0.40, 0.30, 0.20])
assert np.isclose(wmw_auc(Y, S_tied), 21.5 / 25) and np.isclose(roc_auc_score(Y, S_tied), 0.86)

# 2. Exact right-continuous step-rectangle Average Precision
pos_ranks = np.where(Y == 1)[0] + 1  # [1, 2, 4, 5, 7]
precs_at_pos = np.cumsum(Y)[Y == 1] / pos_ranks
ap_manual = np.mean(precs_at_pos)
assert np.isclose(ap_manual, (1 + 1 + 0.75 + 0.80 + 5 / 7) / 5)
assert np.isclose(ap_manual, average_precision_score(Y, S))
print(f"AUC={wmw_auc(Y, S):.4f}, Tied AUC={wmw_auc(Y, S_tied):.4f}, AP={ap_manual:.4f}, MCC@0.5={matthews_corrcoef(Y, S>=0.5):.4f}")
