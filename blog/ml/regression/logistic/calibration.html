    Probability Calibration and Reliability

    July 2026 · 20 min read

    Suppose a sepsis risk model outputs $\hat p = 0.50$ for an emergency patient, and a second team cubes every output so the dashboard displays $\hat p^3 = 0.125$. Because $q \mapsto q^3$ is strictly increasing on $(0,1)$, both models sort every patient in the exact same order—their ROC-AUC and Average Precision are identical to sixteen decimal places! Yet if clinical protocol initiates treatment at risk $\tau^\star = 0.20$ (derived from mistake costs in Part 6), cubing the score silently withholds treatment from a $50\%$-risk patient.

    Decision-making, expected-value pricing ($p \cdot \text{loss}$), and multi-model ensembling require predicted numbers to behave like genuine frequencies. That agreement between forecast probability and empirical event rate is probability calibration.

    Conditional Calibration, Calibration-in-the-Large, and Sharpness

    Let $Y \in \{0,1\}$ denote the binary outcome and $\hat P = f(X) \in (0,1)$ denote the model's predicted probability on random test draw $(X,Y)$. Distinguish three concepts before inspecting any chart:

    • Conditional (level-wise) calibration: among all test cases assigned forecast $q \in (0,1)$, the true event frequency equals $q$: $$\Pr\big(Y = 1 \mid \hat P = q\big) = q \quad \text{for almost every } q \in (0,1).$$
    • Calibration-in-the-large (mean calibration): the average predicted probability matches the overall prevalence $\mathbb{E}[\hat P] = \Pr(Y = 1)$. Necessary, far from sufficient! An overconfident model predicting $0.05$ when the rate is $0.20$ and $0.95$ when the rate is $0.80$ passes $\mathbb{E}[\hat P] = 0.50 = \Pr(Y=1)$ while misstating risk at both tails.
    • Sharpness (refinement): the concentration of $\hat P$ toward $0$ and $1$ when $X$ carries genuine signal. Predicting the constant base rate $\hat P \equiv \pi$ is perfectly calibrated at its single forecast atom $q = \pi$, yet has zero discrimination ($\mathrm{AUC} = 0.5$). Good probabilistic forecasters maximize sharpness subject to being calibrated (Gneiting, Balabdaoui, & Raftery, 2007).
    What does logistic regression guarantee on its own? If an unpenalized intercept $\beta_0$ is included in unweighted MLE (or ridge/lasso on slopes only), the intercept stationary condition $\frac{\partial J}{\partial \beta_0} = \frac{1}{n}\sum_{i=1}^n (\hat p_i - y_i) = 0$ forces exact in-sample calibration-in-the-large ($\bar{\hat p}_{\mathrm{train}} = \bar y_{\mathrm{train}}$). It does not guarantee conditional calibration when the log-odds surface is misspecified (omitted nonlinearities or interactions), when $L_2$/$L_1$ penalties shrink slopes, when high-dimensional overfitting inflates test logits, or when deployment prevalence shifts.

    Cox's Calibration Intercept and Slope

    Before binning anything, Cox (1958) and Steyerberg (2019) summarize calibration smoothly on a held-out validation set by regressing $Y_i$ on the frozen model's log-odds $z_i = \operatorname{logit}(\hat p_i) = \ln\frac{\hat p_i}{1-\hat p_i}$:

    $$\operatorname{logit}\Pr(Y_i = 1 \mid z_i) = \alpha + \gamma\,z_i,$$

    where $\alpha \in \mathbb{R}$ is the calibration intercept and $\gamma \in \mathbb{R}$ is the calibration slope. Ideal calibration yields $(\alpha, \gamma) = (0, 1)$:

    1. Offset intercept $\hat\alpha_{\mathrm{offset}}$ (fixing $\gamma = 1$): measures calibration-in-the-large on the log-odds scale. $\hat\alpha_{\mathrm{offset}} > 0$ means systematic underprediction (observed outcomes exceed forecasts); $\hat\alpha_{\mathrm{offset}} < 0$ means systematic overprediction.
    2. Joint calibration slope $\hat\gamma$: $\hat\gamma < 1$ diagnoses overconfident / overfitted predictions whose extreme logits must be pulled toward zero; $\hat\gamma > 1$ diagnoses underconfident predictions (common under heavy $L_2$ regularization) whose compressed logits need expansion.

    Reliability Diagrams, ECE, MCE, and a Worked $N=800$ Check

    Partition $[0,1]$ into $B$ disjoint bins $B_1,\dots,B_B$ containing $n_b = |B_b|$ validation predictions ($N = \sum_{b=1}^B n_b$). Within bin $b$, compute the mean forecast $\bar p_b = \frac{1}{n_b}\sum_{i\in B_b}\hat p_i$ and empirical positive rate $\bar y_b = \frac{k_b}{n_b} = \frac{1}{n_b}\sum_{i\in B_b} y_i$. Plotting $(\bar p_b, \bar y_b)$ against the $45^\circ$ diagonal forms the reliability diagram, summarized by Expected Calibration Error (ECE) and Maximum Calibration Error (MCE):

    $$\mathrm{ECE} = \sum_{b=1}^{B}\frac{n_b}{N}\,\big|\bar p_b - \bar y_b\big|, \qquad \mathrm{MCE} = \max_{1 \le b \le B}\big|\bar p_b - \bar y_b\big|.$$

    Because $\widehat{\mathrm{ECE}}$ is a plug-in absolute-deviation estimator, narrow bins inflate finite-sample upward bias ($\mathbb{E}[|\bar y_b - \bar p_b|] \approx \sqrt{\frac{2\bar p_b(1-\bar p_b)}{\pi n_b}} > 0$ even under perfect calibration!) while wide bins cancel opposite-sign errors. Always report the binning rule (equal-width vs equal-mass quantile bins) and $B$ alongside $\mathrm{ECE}$.

    Murphy's Brier Decomposition and the Continuous-Binning Correction

    The Brier score $\mathrm{Brier} = \frac{1}{N}\sum_{i=1}^N (\hat p_i - y_i)^2$ is a strictly proper quadratic scoring rule. When a model issues forecasts from a finite discrete set $\{q_1,\dots,q_B\}$ (so $\hat p_i \equiv \bar p_b$ identically inside each group $B_b$), expanding $(\bar p_b - y_i)^2 = [(\bar p_b - \bar y_b) + (\bar y_b - y_i)]^2$ and adding/subtracting $\bar y = \frac{1}{N}\sum_i y_i$ yields Murphy's (1973) exact three-term identity:

    $$\mathrm{Brier}_{\text{discrete}} = \underbrace{\sum_{b=1}^{B}\frac{n_b}{N}\big(\bar p_b - \bar y_b\big)^2}_{\mathrm{REL}\text{ (reliability, }\downarrow\text{)}} - \underbrace{\sum_{b=1}^{B}\frac{n_b}{N}\big(\bar y_b - \bar y\big)^2}_{\mathrm{RES}\text{ (resolution, }\uparrow\text{)}} + \underbrace{\bar y\,(1 - \bar y)}_{\mathrm{UNC}\text{ (uncertainty)}}.$$
    Qualification for continuous probabilities $\hat p_i$: Logistic regression outputs continuous $\hat p_i \in (0,1)$, so $\hat p_i \ne \bar p_b$ inside bin $B_b$! Writing $\hat p_i - y_i = (\hat p_i - \bar p_b) + (\bar p_b - y_i)$ proves that the exact binned identity carries two extra within-bin terms (Stephenson, Coelho, & Jolliffe, 2008): $$\mathrm{Brier} = \mathrm{REL}_B - \mathrm{RES}_B + \mathrm{UNC} + \underbrace{\frac{1}{N}\sum_{b=1}^{B}\sum_{i \in B_b}(\hat p_i - \bar p_b)^2}_{W_B\text{ (within-bin forecast variance)}} - \underbrace{\frac{2}{N}\sum_{b=1}^{B}\sum_{i \in B_b}(\hat p_i - \bar p_b)(y_i - \bar y_b)}_{C_B\text{ (within-bin covariance)}}.$$ Never claim $\mathrm{Brier} = \mathrm{REL}_B - \mathrm{RES}_B + \mathrm{UNC}$ holds with zero remainder on continuous binned scores unless $W_B - C_B = 0$!

    Post-Hoc Recalibration: Platt Scaling, Temperature Scaling, and PAV Isotonic

    When a frozen model ranks well ($\mathrm{AUC}$ is high) but misstates probabilities, fit a lightweight map $g : (0,1) \to (0,1)$ on a disjoint calibration split (or out-of-fold cross-validation predictions—never on training predictions!):

    • Platt scaling (Platt, 1999): fits $\hat p_{\mathrm{Platt},i} = \sigma(\alpha + \gamma z_i)$ with $z_i = \operatorname{logit}(\hat p_i)$ (or raw margin $s_i$). Having only $2$ parameters makes it resistant to overfitting on small calibration sets ($N_{\mathrm{cal}} \approx 100\text{--}500$), and $\hat\gamma > 0$ strictly preserves every rank.
    • Temperature scaling (Guo et al., 2017): fits a single positive scalar $T > 0$ in $\hat p_{\mathrm{temp},i} = \sigma(z_i / T)$ (or $\operatorname{softmax}(\mathbf{z}_i / T)$ for $K$ classes). $T > 1$ softens overconfident neural logits without altering top-1 accuracy or AUC, but having $\alpha \equiv 0$ means temperature scaling cannot fix a shift in overall prevalence.
    • Isotonic regression via Pool-Adjacent-Violators (PAV; Zadrozny & Elkan, 2002): solves the shape-restricted quadratic program $\min_{m_1 \le \dots \le m_m} \sum_{i=1}^m (y_{(i)} - m_i)^2$ after sorting $\hat p_{(1)} \le \dots \le \hat p_{(m)}$. Whenever an adjacent block violates monotonicity ($m_k > m_{k+1}$), PAV replaces both blocks by their count-weighted average until the sequence is non-decreasing. Flexible for non-sigmoid distortions, but overfits severely below $N_{\mathrm{cal}} \approx 1{,}000$ and introduces flat step ties.

    Leakage-Free Splitting and Prior-Shift Recalibration

    Fitting or evaluating a calibrator on training rows leaks in-sample optimism—for example, a severely overfitted tree or high-$d$ logistic model looks sharp on training data while needing $\hat\gamma < 1$ on unseen rows. Separate responsibilities strictly:

    1. Train split fits base weights $\hat\beta$ (or generates out-of-fold predictions via CalibratedClassifierCV).
    2. Calibration split fits $g$ (Platt or PAV isotonic) on frozen out-of-sample scores.
    3. Validation split selects any downstream cost threshold $\tau^\star$ on calibrated probabilities (calibrate first, threshold second!).
    4. Held-out test split audits final log-loss, Brier score, ECE, and realized decision cost once.

    Under pure label / prior shift ($P_{\mathrm{new}}(X\mid Y) = P_{\mathrm{old}}(X\mid Y)$ while prevalence changes from $\pi_{\mathrm{old}}$ to $\pi_{\mathrm{new}}$), Bayes' theorem updates calibrated probabilities via an exact log-odds intercept shift $\operatorname{logit}(p_{\mathrm{new}}) = \operatorname{logit}(p_{\mathrm{old}}) + \operatorname{logit}(\pi_{\mathrm{new}}) - \operatorname{logit}(\pi_{\mathrm{old}})$ without touching $\gamma = 1$. Whenever the Cox slope $\hat\gamma$ also drifts away from $1$, class-conditional distributions $P(X\mid Y)$ or feature pipelines have changed, requiring full recalibration or model refitting.

    Show the complete numerical check 
    import numpy as np
from scipy.optimize import minimize
from sklearn.isotonic import IsotonicRegression

# 1. 5-bin validation reliability check (N = 800)
n_b = np.array([200, 150, 120, 150, 180], dtype=float)
p_bar = np.array([0.10, 0.30, 0.50, 0.70, 0.90])
k_b = np.array([36, 57, 60, 93, 135], dtype=float)
y_bar = k_b / n_b
ece = np.sum((n_b / n_b.sum()) * np.abs(p_bar - y_bar))
mce = np.max(np.abs(p_bar - y_bar))
assert np.isclose(ece, 0.08375) and np.isclose(mce, 0.15)

# 2. Exact continuous Brier decomposition (Stephenson et al., 2008) + Platt vs PAV isotonic
p_cal = np.array([0.05, 0.12, 0.25, 0.35, 0.62, 0.74, 0.88, 0.95])
y_cal = np.array([0, 1, 0, 0, 1, 0, 1, 1], dtype=float)
brier_raw = np.mean((p_cal - y_cal) ** 2)

bins_2 = [slice(0, 4), slice(4, 8)]  # [0, 0.5) and [0.5, 1.0]
rel = sum(len( p_cal[s] ) / 8 * (p_cal[s].mean() - y_cal[s].mean()) ** 2 for s in bins_2)
res = sum(len( p_cal[s] ) / 8 * (y_cal[s].mean() - y_cal.mean()) ** 2 for s in bins_2)
unc = y_cal.mean() * (1 - y_cal.mean())
w_var = sum(np.sum((p_cal[s] - p_cal[s].mean()) ** 2) for s in bins_2) / 8
w_cov = 2 * sum(np.sum((p_cal[s] - p_cal[s].mean()) * (y_cal[s] - y_cal[s].mean())) for s in bins_2) / 8
assert np.isclose(brier_raw, rel - res + unc + w_var - w_cov)

z_cal = np.log(p_cal / (1 - p_cal))
opt = minimize(lambda th: np.mean(np.logaddexp(0, th[0] + th[1] * z_cal) - y_cal * (th[0] + th[1] * z_cal)), [0.0, 1.0])
p_platt = 1 / (1 + np.exp(-(opt.x[0] + opt.x[1] * z_cal)))
p_iso = IsotonicRegression(out_of_bounds="clip").fit_transform(p_cal, y_cal)
assert np.allclose(p_iso, [0.0, 1/3, 1/3, 1/3, 0.5, 0.5, 1.0, 1.0])
print(f"ECE={ece:.4f}, Raw Brier={brier_raw:.6f}, 3-term={rel-res+unc:.6f}, +W-C={rel-res+unc+w_var-w_cov:.6f}, Platt=({opt.x[0]:+.4f}, {opt.x[1]:.4f})")
