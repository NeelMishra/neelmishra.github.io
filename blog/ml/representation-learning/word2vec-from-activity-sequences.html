    Word2Vec for User Behavior: From Sequences to Training Pairs

    September 2026 · 4 min read

    Before you start: Embedding table lookups and the sigmoid function.

    A user views boots, then socks, then a jacket. Another user follows a similar sequence. Repeated local co-occurrence can teach a model that these items belong in related contexts. Word2Vec learns this from prediction tasks over sequences; it does not require a human to assign semantic coordinates to each item.

    Predict nearby items from a center item

    Keep two embedding tables: input vectors $v_w$ and output/context vectors $u_c$. For a center $w$, full-softmax skip-gram defines $P(c\mid w)=\exp(u_c^\top v_w)/\sum_j\exp(u_j^\top v_w)$. A positive pair asks the model to increase the observed context’s probability relative to all other context IDs.

    The denominator touches the entire vocabulary. For a catalog with millions of items, that is expensive. Negative sampling replaces the normalized multiclass task with binary classification of observed pairs versus sampled noise pairs. It is a different training objective, not an exact cheap calculation of that softmax probability.

    $$\ell(w,c)=-\log\sigma(u_c^\top v_w)-\sum_{j=1}^{K}\log\sigma(-u_{n_j}^\top v_w).$$

    For one positive pair with dot product 0 and two negative pairs also at 0, the loss is 3log2≈2.079. The derivative with respect to the positive dot product is σ(0)−1=−0.5, so gradient descent increases it. Each negative derivative is σ(0)=0.5, so descent decreases those dot products. The shared center vector changes in response to all three comparisons.

    Negative examples define what the vectors distinguish

    A noise distribution proportional to item frequency raised to 3/4 is a classic choice; it softens the dominance of the most frequent tokens while still sampling them often. The number of negatives and distribution change the learned task. Do not interpret a sampled negative as a human judgment of dislike. It is an item chosen to contrast with the observed context.

    Behavioral data adds complications: users may compare substitutes, buy complements, or browse randomly. Co-occurrence can make complementary products close even when a search query asks for substitutes. Decide whether the intended neighborhood means “similar appearance,” “often bought together,” or “used in the same session.” Those are different objectives.

    Session construction is model design

    Order events by event time, handle late arrivals, deduplicate accidental repeats, and choose session boundaries. Do not join the last click of one user to the first click of another. A large context window captures broad interests; a narrow window emphasizes local intent. Separate event types or weights when a purchase should carry different meaning from an impression.

    These choices can change embeddings more than a small optimizer adjustment.
    DecisionPossible consequence
    Keep every repeated viewFrequently refreshed items can dominate training
    Mix impressions with purchasesThe model learns exposure as well as preference
    Use a very long windowUnrelated intents in one session become positives
    Train on future sessionsOffline retrieval evaluates information unavailable at the decision time

    An auditable pair generator

    def skipgram_pairs(tokens, radius=1):
    if radius < 1:
        raise ValueError("radius must be positive")
    for i, center in enumerate(tokens):
        left, right = max(0, i-radius), min(len(tokens), i+radius+1)
        for j in range(left, right):
            if i != j:
                yield center, tokens[j]

session = ["boots", "socks", "jacket"]
assert list(skipgram_pairs(session)) == [
    ("boots", "socks"), ("socks", "boots"),
    ("socks", "jacket"), ("jacket", "socks"),
]

    At scale, partition and sort sessions carefully before generating pairs. A distributed Word2Vec implementation has its own optimizer, partitioning, and vocabulary rules; record them instead of assuming it reproduces a single-process run. Save the token-to-row mapping with the vectors. Row 17 has no meaning without its vocabulary version.

    Which embedding table should retrieval use?

    Training has separate input and context tables. Exporting input vectors, output vectors, or a combination creates different retrieval spaces. Choose explicitly and validate downstream. Cosine similarity compares normalized directions, while dot product also reflects vector norms. The next chapter turns these choices into an evaluation plan rather than relying on a few attractive nearest-neighbor examples.

    Check your understanding: Is a randomly sampled negative item necessarily something the user dislikes?

    No. It is a contrastive training sample. It may even be a useful unobserved item. The sampling scheme and false-negative rate affect the learned representation.
