    Shapley Values for Model Explanations

    September 2026 · 5 min read

    Suppose a model’s prediction is higher than its usual output. How much of that difference should each feature receive? Shapley values average what a feature adds across every order in which features could be revealed.

    Start with two features

    Call the features A and B. A set of revealed features is a coalition, written $S$. Its value $v(S)$ is the expected model output when those features are known and the others are averaged out under a chosen rule.

    For this illustrative game, the values are: neither feature 0.10, A only 0.40, B only 0.20, and both 0.80. The 0.10 is the baseline; the total increase to allocate is 0.70. These numbers are supplied model-output units, not measured probabilities.

    Reveal A first: it adds 0.40 − 0.10 = 0.30. Reveal A after B instead: it adds 0.80 − 0.20 = 0.60. Its contribution, written $\phi_A$, is the average: (0.30 + 0.60) / 2 = 0.45. B similarly gets (0.10 + 0.40) / 2 = 0.25.

    The result reconstructs the prediction: 0.10 + 0.45 + 0.25 = 0.80. A’s effect depends on whether B was already known; averaging orders accounts for that interaction without giving either order special status.

    Use the same rule with more features

    Imagine shuffling all feature names, revealing them one at a time, and recording each increase in expected output. Average each feature’s increase over all shuffles. That is the general Shapley rule.

    Let $F$ be the full set of $M$ features, and let $j$ be the feature whose contribution we want. The set $S$ contains features revealed before $j$.

    The formula and why its weights are unequal

    There are $M!$ reveal orders, where factorial counts all permutations. A particular preceding set $S$ occurs in $|S|!(M-|S|-1)!$ of those orders: arrange the earlier features, fix $j$ next, and arrange the remaining features. Therefore:

    $$\phi_j=\sum_{S\subseteq F\setminus\{j\}} \frac{|S|!(M-|S|-1)!}{M!} \,[v(S\cup\{j\})-v(S)].$$

    The bracket is the increase from revealing $j$. The fraction is how often that preceding set occurs. With three features, the four possible preceding sets have weights 1/3, 1/6, 1/6, and 1/3. Equal weighting of those sets would not equal averaging all reveal orders.

    Choose how to average hidden features

    The original predictor still needs complete inputs. An explainer might fill unrevealed features from background rows, use conditional distributions, or use tree-specific branch statistics. Those choices define the coalition values; they can change the resulting contributions.

    For correlated features, such as a total and its components, some replacements can create unrealistic combinations. Name the background rule and the model output being explained. The TreeSHAP background example shows the same prediction receiving different explanations under different references.

    Know what the allocation guarantees

    PropertyMeaning for a fixed game
    EfficiencyContributions add to the full prediction minus the baseline.
    SymmetryFeatures with identical marginal effects receive equal credit.
    DummyA feature that never changes a coalition’s value receives zero.
    AdditivityAdding two games adds their feature contributions.

    These properties determine an allocation once the game is fixed. They do not choose the right background or establish causal effects.

    Avoid enumerating every feature set

    Each feature can be revealed or hidden, giving $2^M$ feature sets. Evaluating them all becomes expensive. Kernel SHAP estimates the allocation through weighted regression; TreeSHAP reuses tree structure for supported models.

    Keep contributions in the declared output units when displaying them. The production explanation notes cover reconstruction and concise displays.
