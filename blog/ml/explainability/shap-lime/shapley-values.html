    Shapley Values for Model Explanations

    September 2026 · 5 min read

    A prediction can depend on features working together. Shapley values divide the difference from a baseline by asking how much each feature adds when it joins every possible set of already-known features. Start with two features so every calculation fits in one table.

    Two features, four coalition values

    There are two arrival orders: A then B, or B then A. If A arrives first, it adds 0.40−0.10=0.30. If it arrives after B, it adds 0.80−0.20=0.60. Average them: φA=0.45. B similarly receives [(0.20−0.10)+(0.80−0.40)]/2=0.25.

    $$v(\varnothing)+\phi_A+\phi_B=0.10+0.45+0.25=0.80=v(\{A,B\}).$$

    The interaction above the additive baseline is 0.80−0.40−0.20+0.10=0.30. Each feature receives half of that interaction in this two-player game. This allocation follows from averaging orders; it does not prove that the features caused the outcome.

    The formula is an average over arrival orders

    $$\phi_j=\sum_{S\subseteq F\setminus\{j\}}\frac{|S|!(M-|S|-1)!}{M!}\,[v(S\cup\{j\})-v(S)].$$

    F is the feature set, M its size, and S the features that arrived before j. There are |S|! ways to order those earlier features and (M−|S|−1)! ways to order the later ones, out of M! total permutations. That explains the weight. It is generally not correct to take an unweighted average over distinct coalitions.

    With three features, a particular empty coalition has weight 1/3, either one-feature coalition has weight 1/6, and the two-feature coalition has weight 1/3. All four weights sum to one, but they are unequal. Equal averaging would overemphasize the middle coalition size and compute a different attribution.

    What does “feature unknown” mean?

    A predictive model normally expects all input features. To define v(S), an explainer needs a rule for the missing ones. It may integrate them over a background dataset, condition on observed features, or use tree-path statistics under a specified method. These choices can produce different values for the same coalition and therefore different SHAP values.

    For correlated features such as an aggregate and its components, the missing-feature rule matters greatly. Some generated combinations may be unlikely or impossible. State the background, dependence assumption, and output being explained. A contribution has meaning only relative to this definition of the game.

    What the allocation guarantees

    These characterize the Shapley allocation for a fixed cooperative game. They do not determine which missing-feature game is appropriate for a model.
    PropertyMeaning
    EfficiencyContributions sum to v(F)−v(∅)
    SymmetryFeatures with identical marginal effects receive equal credit
    DummyA feature with zero marginal effect in every coalition receives zero
    AdditivityThe allocation for a sum of games is the sum of their allocations

    Why exact enumeration becomes expensive

    There are 2^M coalitions. Direct enumeration becomes expensive as feature count grows, especially when each value requires integration over background rows. Sampling permutations estimates the average; structure-specific algorithms such as TreeSHAP avoid naive enumeration for supported models. An approximation should report its sampling variability when that affects interpretation.

    For a raw-logit explanation, baseline and contributions add in logit space. Applying sigmoid separately to each contribution breaks additivity. The production explanation chapter shows how to preserve output units, validate reconstruction, and display only a few features without losing the residual contribution.

    Check your understanding: For three features, can you average all four coalitions for one feature with weight 1/4?

    No. Shapley weights are 1/3, 1/6, 1/6, and 1/3 for coalition sizes 0, 1, 1, and 2. The weights reflect equally likely feature permutations.
