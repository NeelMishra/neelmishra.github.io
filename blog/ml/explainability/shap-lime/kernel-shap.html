    Kernel SHAP: SHAP as Weighted Regression

    September 2026 · 5 min read

    The previous chapter defined feature contributions by averaging reveal orders. Kernel SHAP reaches the same allocation through a specially weighted regression problem. It can query a predictor without inspecting how that predictor is implemented.

    Fit predictions for sets of revealed features

    A mask has one entry per feature. For three features, 101 means reveal A and C while hiding B. Fill hidden features from each background row, query the original model, and average those outputs to obtain the mask’s coalition value.

    Fit an additive surrogate whose prediction is a baseline plus the contributions of the revealed features. Its coefficients are the quantities we want. The fitting weights are chosen to recover the Shapley allocation; they are not ordinary distances between nearby inputs.

    ▶ Coalition Masks Become a Weighted Regression

    For three features, there are eight reveal masks. A 1 keeps that feature from the explained row; a 0 uses background values. Empty and full masks provide exact endpoint constraints.

    Let $M$ be the number of features and $s$ the number revealed by a mask. For an interior mask, $1\leq s\leq M-1$, the Kernel SHAP weight is:

    $$w(s)=\frac{M-1}{\binom{M}{s}\,s(M-s)}.$$

    The binomial term counts how many masks reveal $s$ features. With three features, every one-feature or two-feature mask has weight 1/3. Do not substitute the empty or full mask into this formula: their denominator is zero. Instead, constrain the surrogate baseline to the empty-mask value and its full-mask prediction to the original output.

    Connect the weighted fit to the small example

    Reuse the earlier two-feature values: empty 0.10, A only 0.40, B only 0.20, both 0.80. The constraints fix the baseline at 0.10 and the sum of the two contributions at 0.70. Fitting the two interior values with the SHAP weights gives A: 0.45 and B: 0.25.

    The surrogate predicts 0.55 for A only and 0.35 for B only. Those do not exactly match 0.40 and 0.20: a purely additive surrogate cannot match this game’s interaction at every mask. The coefficients still give the Shapley allocation, and both endpoint constraints hold.

    choose the explained row and a background dataset
fix the empty-mask value as the baseline
fix baseline + contributions = the full prediction
sample interior masks
for each mask:
    average model outputs over background replacements
    assign the SHAP kernel weight
solve the constrained weighted regression

    With all coalition values and the required constraints, this recovers the exact allocation for the defined game. Sampling, feature selection, and numerical approximations can change the estimate; record the settings and check stability when using a library.

    The background is part of the question

    Replacing a hidden feature with zero is not the same as averaging it over a background dataset. Likewise, background replacement and conditioning on correlated revealed features are different rules. The missing-feature explanation covers this distinction.

    For tree models, TreeSHAP can avoid much of the generic querying work. For other models, inspect whether the background, output scale, and number of model evaluations suit your task.
