    Kernel SHAP: SHAP as Weighted Regression

    September 2026 · 14 min read

    Shapley values average reveal orders. Kernel SHAP computes that allocation by fitting a weighted regression to the same coalition values. Its regression inputs are reveal masks; its targets are outputs of the already-trained model.

    First we will fit the previous chapter’s two-feature example by hand. Then a four-feature example will show why the special weights matter and why a perfect reconstruction check is not enough.

    Turn a reveal mask into a regression row

    A mask has one entry per feature: 10 reveals A and hides B; 01 does the opposite. The background replacement rule produces a complete input for each reference row, and averaging the resulting predictions gives the coalition value. Keep the reference and model output fixed throughout the fit.

    Our two-feature game has mask values 00: 0.10, 10: 0.40, 01: 0.20, and 11: 0.80. Write the mask as $z=(z_A,z_B)$, where each entry is 0 or 1. The additive explanation $g$ has an intercept $\phi_0$ and two coefficients, $\phi_A$ and $\phi_B$:

    $$g(z)=\phi_0+z_A\phi_A+z_B\phi_B.$$

    The empty mask fixes $\phi_0=0.10$. The full mask requires $0.10+\phi_A+\phi_B=0.80$, so the two contributions must sum to 0.70. These are exact constraints. Only one coefficient remains free: whenever A’s share changes, B’s share must be 0.70 minus A’s.

    Find the constrained fit by hand

    Each interior mask gets weight 1/2 in this two-feature game. For A only, the surrogate predicts $0.10+\phi_A$ rather than 0.40. For B only, it predicts $0.10+\phi_B$ rather than 0.20. We minimize the weighted sum of those two squared errors.

    At the minimum, both interior residuals are +0.15. The weighted error is 0.5 × 0.15² + 0.5 × 0.15² = 0.0225. A receives 0.45 and B receives 0.25, exactly the reveal-order result. The surrogate cannot match every coalition because it has no interaction term.

    Optional: one line of algebra gives the minimum

    Substitute $\phi_B=0.70-\phi_A$. The residuals become $\phi_A-0.30$ and $0.60-\phi_A$. The weighted error is

    $$L(\phi_A)=\tfrac12(\phi_A-0.30)^2+\tfrac12(0.60-\phi_A)^2.$$

    Its derivative is $2\phi_A-0.90$. Setting it to zero gives $\phi_A=0.45$. This is a small constrained least-squares problem, not a new way to train the original predictor.

    Fitting just the two interior points without the full-mask constraint would give A = 0.30 and B = 0.10. Those coefficients match the interior targets but reconstruct only 0.50 at mask 11. The constraint is what makes the interaction part of the allocated 0.70 increase.

    Why ordinary regression weights are insufficient

    Let $M$ be the number of features and $s$ the number of 1s in a mask. There are $\binom{M}{s}$ masks of that size; the binomial symbol means “choose $s$ features from $M$.” For each individual interior mask, the SHAP kernel assigns

    $$w(s)=\frac{M-1}{\binom{M}{s}\,s(M-s)},\qquad 1\le s\le M-1.$$

    This is a weighting over feature sets, not geometric distance from the explained input. Empty and full masks are excluded from the formula because their denominator would be zero; we already enforce their values as constraints. Lundberg and Lee, Theorem 2, derive the kernel that yields the Shapley allocation with all coalition values and an unpenalized additive fit.

    With two or three features, all interior masks happen to have the same weight. Four features reveal the difference: each size-1 or size-3 mask gets 1/4, while each size-2 mask gets 1/8.

    Extend the three-feature game with D, a feature the predictor completely ignores. Its rules are: baseline 0.10; standalone effects A: 0.30, B: 0.10, C: 0.20; an A–B bonus of 0.30; and an A–B–C bonus of 0.60. Explain (1, 1, 1, 1) against (0, 0, 0, 0). The prediction is 1.60 and D should receive zero.

    The true allocation shares the A–B bonus between A and B and the three-way bonus among A, B, and C. Equal mask weights give A: 0.6375, B: 0.4375, C: 0.3875, and D: 0.0375. An endpoint check accepts both fits, so it cannot certify that a computation recovered Shapley values.

    Sampling saves queries but can lose information

    With many features, querying every coalition is expensive. Sample a subset of masks, average the model outputs over the chosen background for each, and fit the constrained regression. This introduces a second question: do the sampled masks supply enough independent information, and do they represent the full fitting problem well?

    The four singleton masks yield a unique fit, but they never directly query an interacting pair or triple. They allocate A: 0.525, B: 0.325, C: 0.425, D: 0.225. Reconstruction still passes. This deliberately restricted design is an illustration of missing coverage, not the library’s default sampler.

    When A and B are always revealed together, their mask columns are identical. The fit can identify their combined effect but cannot split it uniquely. The figure reports this instead of presenting an arbitrary split. After enforcing the full-mask constraint there are three free coefficients; this design has only two independent directions, called rank 2.

    More samples help only when they add the needed information. When sampling masks nonuniformly, the sampling probabilities and regression weights must together represent the intended kernel objective; do not attach the full-enumeration weights to an arbitrary sampling scheme and assume equivalence.

    Keep the explanation settings inspectable

    The background lesson defines the comparison once. Increasing its size improves coverage of that chosen reference, but also increases the number of complete model inputs per mask. A batch of 100 background rows can require 100 predictions for one mask, even if evaluated in one model call.

    Name the scalar output, such as one class probability or a raw score. With the identity link, contributions use those units. KernelExplainer also offers a logit link: then the contributions sum in log-odds units, and probability is recovered only after combining the baseline and all contributions. The API documentation specifies links, sampling, and feature-selection options; record those settings explicitly.

    For a numerical check, start with a small game whose exact reveal-order answer is known. Then check reconstruction, repeated sampling seeds, and a larger query budget. A plausible second background tests a different comparison question; a second seed tests computation of the same question. Keep those two changes distinct.

    The NumPy reproduction script exports every mask, weight, coefficient, and residual. It eliminates the last coefficient using the endpoint constraint, solves weighted least squares, and rejects rank-deficient designs. Run it beside the game calculator with python kernel_shap_demo.py > assets/kernel-shap-demo.json. This direct implementation supports the lesson’s exact small examples; it does not run the SHAP package.
