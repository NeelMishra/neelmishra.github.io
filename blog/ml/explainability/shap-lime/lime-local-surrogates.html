    LIME: Local Surrogate Explanations

    September 2026 · 5 min read

    A complicated model can behave approximately like a simple line in a small neighborhood. LIME fits that local approximation and uses its coefficients to explain one prediction. The original model stays fixed.

    Fit the nearby behavior more closely

    Call the original predictor $f$ and the explained row $x_0$. Generate nearby rows $z_i$, query their predictions $f(z_i)$, and give each a nonnegative weight $w_i$ based on its distance from $x_0$. Nearby rows receive greater weight.

    Now fit a simple predictor $g$, such as a line using a few features. It should match those model outputs while remaining easy to read. Write $C(g)$ for its complexity cost and $\lambda$ for the strength of that cost. In this numeric-input setting, the fitting objective is:

    $$\min_g\;\sum_i w_i\,[f(z_i)-g(z_i)]^2+\lambda C(g).$$

    The squared difference measures how poorly the approximation matches the original model. The weight says where that error matters most. The last term discourages a complicated explanation. Ribeiro, Singh and Guestrin introduce this local fidelity–complexity tradeoff.

    ▶ LIME Fits a Local Line

    The green curve is a constructed model output. The orange point is the row being explained. Larger blue points receive more weight in the fitted orange line.

    Here the surrogate is a one-feature line with an intercept and no extra complexity penalty. Its slope is computed by weighted least squares on the shown samples. A positive slope means the fitted model output rises with this feature in this neighborhood; it is not a global effect.

    Read one LIME explanation carefully

    1. Name the output. A probability for a particular class and a raw score are different targets.
    2. Define a neighborhood. Choose how to generate modified inputs and measure their distance from the row.
    3. Fit and inspect the surrogate. Check its error on nearby samples and its prediction at the original row.
    4. Read the coefficients with their units. Rescaling a numeric feature changes its coefficient; a discretized condition has a different interpretation again.

    For text or images, the interpretable inputs may instead indicate whether words or image regions are present. The perturbed model input and the simple explanation representation must correspond; the numeric example above keeps them the same.

    Ask whether the local approximation is stable

    A narrower neighborhood can fit very local behavior but use less information. A wider one may cross several tree splits or other changes in the model’s behavior. Try another random seed or nearby width and inspect whether the main conclusion survives.

    Generated inputs also need to make sense. Independently changing correlated measurements can create unrealistic rows. A low fitting error on those rows does not make the explanation appropriate for real observations.

    LIME need not reconstruct the original prediction exactly. If your question is how to allocate a prediction difference among features under a declared background rule, continue to Shapley values.
