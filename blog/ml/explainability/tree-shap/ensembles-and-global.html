    Tree SHAP for Ensembles and Global Summaries

    September 2026 · 5 min read

    There are two different ways to combine SHAP values: combine trees for one row, or summarize many rows for one feature. They answer different questions, so keep them separate.

    Follow the model’s own combination rule

    If the model adds tree outputs, add their baselines and feature contributions. If it averages trees, average their explanations. If a tree has a model weight, apply that same weight to its explanation. Use matching output and missing-feature conventions throughout.

    For example, suppose three regression trees supply these contributions for features A, B, and C. Each has baseline 0.10:

    ▶ Add Local Contributions Across Trees

    These supplied regression contributions illustrate addition across three trees. Each tree has baseline 0.10. The figure combines values; it does not run the TreeSHAP algorithm.

    The A contributions add to 0.08 + 0.03 − 0.01 = 0.10. B contributes 0.07 and C contributes 0.05. The summed model therefore predicts 0.30 + 0.10 + 0.07 + 0.05 = 0.52.

    A forest that averages those same three trees predicts 0.52 / 3, about 0.1733. Its baseline and each feature contribution must also be divided by 3. Adding explanations without this averaging would explain a different model.

    For a boosted classifier, the summed output may be a raw score that is later converted to a probability. In that case the contributions explain the raw score, not percentage points. Converting each contribution separately does not preserve addition through a nonlinear probability transform. Use a supported probability-output explainer when that is the quantity you need; check the output options.

    Summarize a feature across rows

    Now hold the model fixed and explain a dataset. One feature may push a prediction up for one row and down for another. Contributions +2 and −2 have signed average 0, although both are large.

    A global importance bar commonly averages absolute contributions: for those two rows, (2 + 2) / 2 = 2. It measures typical contribution size on this dataset and intentionally discards direction.

    ViewWhat to read from it
    One-row waterfallHow signed contributions connect the baseline to one prediction
    Global barWhich features have large average contribution magnitudes
    BeeswarmHow contributions vary across rows, including their direction
    Dependence scatterHow one feature’s value relates to its contribution

    Name the dataset behind a global plot: production traffic, a held-out month, or a selected segment. Changing that population can change the ranking even when the model is unchanged. The next chapter covers background choices and validation.
