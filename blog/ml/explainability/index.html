    Machine Learning Explainability

    September 2026 · 8 min read

    Explainability starts with a question, not a plot. You might want to explain one prediction, approximate the model near one input, or find which features support its performance on new data. Those tasks require different evidence. A feature can strongly influence a prediction while providing little useful information about the true outcome.

    This section teaches the differences with small models you can inspect. Begin with the question below, then follow the corresponding series. Each worked chapter supplies the model or calculation behind its figures, defines its symbols before using them, and keeps longer derivations optional.

    Choose what you want to explain

    For SHAP, a positive contribution means “above the selected reference,” in the units of the explained output. For LIME, a positive coefficient describes a direction in a fitted local approximation. For permutation importance, an increase in held-out error after shuffling a feature measures the fixed model’s reliance under that perturbation. Treating all three as interchangeable “importance scores” loses their meaning.

    The SHAP paper develops an additive attribution framework, while the LIME paper fits an interpretable approximation near a prediction. These ideas guide the worked calculations in the two series.

    Separate the reference from the population you summarize

    A local explanation describes one row. A global summary combines explanations across a selected dataset. For SHAP, two populations can be involved: the background that defines each comparison and the rows included in the final summary.

    In the forest example, the two A=0 rows instead give a mean absolute B contribution of about 0.4167. That change comes from the summary population. Changing the background itself is a separate operation that can change each local explanation.

    Also choose what the summary preserves. A signed average can cancel large positive and negative contributions. A mean absolute value preserves typical magnitude but removes direction. Inspect a row-level plot alongside the global bars when that variation matters.

    Keep prediction explanations separate from outcome evidence

    A faithful explanation can expose a model’s shortcut. It does not show that the shortcut predicts well on new data or that changing the feature would change the real outcome. For performance questions, evaluate the model on an appropriate held-out dataset before interpreting an importance ranking.

    Permutation importance then measures how a chosen score changes when a feature is shuffled. Correlated features can substitute for one another, and shuffling can create unusual combinations. Interpret the result alongside the dataset, metric, and perturbation used. The scikit-learn guide develops these checks; our worked comparison keeps output attribution and measured performance side by side.

    Move from the small case to an implementation

    Start with a model whose outputs you can enumerate. Check the prediction units, the reference average, and the intermediate calculations before trusting a large plot. SHAP reconstruction checks that contributions add to the chosen output; LIME additionally needs an error check on the local approximation. Neither check alone establishes usefulness on unseen outcomes.

    The C++ companions implement small examples of permutation importance, LIME, and Kernel SHAP. The worked ML chapters also link Python reproductions, data exports, and downloadable plots, so you can change a reference or neighborhood and inspect what changes.

    Carry the explanation’s context into a report

    Record the model and preprocessing, explained output, reference settings, and row population. Report the result in those terms: a contribution relative to a named baseline, a local fit with measured fidelity, or an evaluation-score change. The production explanation notes cover versioning and concise displays. The anomaly review-queue chapter connects explanations to evidence a reviewer can inspect.

    References and further reading

    • Lundberg & Lee: SHAP — additive feature attribution for individual predictions.
    • Ribeiro, Singh & Guestrin: LIME — interpretable local approximations and their neighborhood dependence.
    • Permutation feature importance — evaluation metrics, held-out data, repeated shuffles, and correlated features.
