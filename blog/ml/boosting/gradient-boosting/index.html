    Gradient Boosting — Algorithm Walkthrough & StatQuest Notes

    September 2026 · 11 min read · Algorithm guide & four worked lectures

    AdaBoost works specifically by reweighting training rows under exponential loss. What if your regression dataset contains extreme outliers calling for Mean Absolute Error or Huber loss, or your classification task requires calibrated probabilities under binary log-loss? Gradient Boosting Machines (GBMs), introduced by Jerome Friedman (2001), turn gradient descent in function space into a universal four-step recipe that works with any differentiable loss function.

    This guide walks through the complete four-step GBM loop, explains how shrinkage $\nu$, tree count $M$, interaction depth, and stochastic row subsampling regularize the ensemble, and organizes the four worked StatQuest companion chapters below.

    1. The Complete Four-Step Gradient Boosting Algorithm

    Given $n$ training examples $\{(x_i, y_i)\}_{i=1}^n$, a differentiable per-example loss $L\bigl(y_i, F(x_i)\bigr)$, tree count $M$, terminal leaf budget $J_m$ (or max_depth), and shrinkage rate $\nu \in (0, 1]$:

    1. Step 1 — Constant initialization ($m = 0$): Start with the single scalar constant $F_0(x)$ that minimizes total training loss across all $n$ rows:
      $$F_0(x) = \arg\min_{\gamma \in \mathbb R} \sum_{i=1}^{n} L(y_i, \gamma).$$
      Under squared error, $F_0(x) = \bar y$ (sample mean); under MAE, $F_0(x) = \operatorname{median}(y)$; under binary log-loss with $y_i \in \{0, 1\}$, $F_0(x) = \ln\bigl(\frac{\bar y}{1 - \bar y}\bigr)$ (initial log-odds).
    2. Step 2a — Compute pseudo-residuals ($m = 1, \dots, M$): Evaluate the negative derivative of each row's loss with respect to its current prediction $F_{m-1}(x_i)$:
      $$r_{im} = -\left[\frac{\partial L\bigl(y_i, F(x_i)\bigr)}{\partial F(x_i)}\right]_{F = F_{m-1}(x_i)}, \qquad i = 1, \dots, n.$$
    3. Step 2b & 2c — Fit regions $R_{jm}$ and refit optimal leaf outputs $\gamma_{jm}$: Fit a shallow CART regression tree to pairs $\{(x_i, r_{im})\}_{i=1}^n$, partitioning input space into $J_m$ disjoint terminal leaves $R_{1m}, \dots, R_{J_m, m}$. Then, inside each leaf $R_{jm}$ separately, find the best constant shift $\gamma_{jm}$ for the original loss $L$:
      $$\gamma_{jm} = \arg\min_{\gamma \in \mathbb R} \sum_{x_i \in R_{jm}} L\bigl(y_i,\, F_{m-1}(x_i) + \gamma\bigr), \qquad j = 1, \dots, J_m.$$
    4. Step 2d — Shrinkage update: Add a damped fraction $\nu$ of the leaf value reached by $x$:
      $$F_m(x) = F_{m-1}(x) + \nu \sum_{j=1}^{J_m} \gamma_{jm}\,\mathbf{1}\{x \in R_{jm}\}.$$
      Because a given input $x$ lands in exactly one leaf $R_{jm}$ of tree $m$, only one $\gamma_{jm}$ fires per tree. After $M$ rounds, return $F_M(x)$ (converting log-odds to probability $\hat p(x) = \frac{1}{1 + e^{-F_M(x)}}$ for binary classification).

    2. Shrinkage $\nu$, Tree Count $M$, Depth, and Stochastic Subsampling

    Unlike Random Forests—where you fix deep trees and simply make $B$ large—a Gradient Boosting Machine is governed by three coupled regularization controls:

    • Shrinkage $\nu$ vs. number of trees $M$: Full steps ($\nu = 1.0$) commit hard to the greedy splits of the very first few trees; any noisy cut in $h_1$ permanently scars the model. Setting $\nu \in [0.01, 0.1]$ scales down every tree's contribution, allowing dozens of overlapping trees to average out threshold boundaries smoothly. Because $\nu$ and $M$ trade off inversely, fix a small $\nu$ (such as $0.05$) and select $M$ automatically via validation early stopping.
    • Number of leaves $J$ / max_depth controls interaction order: An additive sum of stumps ($J = 2$, max_depth = 1) has the form $F(x) = c + \sum_{j=1}^p g_j(x_j)$—it can fit arbitrary non-linear main effects per feature, never two-way interactions $x_1 x_2$! In general, a tree with $J$ leaves can represent interactions of order at most $J - 1$. In tabular practice, max_depth between $3$ and $6$ ($4 \le J \le 32$) captures main effects plus two- and three-way interactions without high leaf variance.
    • Stochastic Gradient Boosting (subsample, Friedman 2002): Drawing a random fraction $\eta_{\text{sub}} \in [0.5, 0.8]$ of rows without replacement at each round injects mini-batch randomness that decorrelates consecutive trees, cuts per-round split-search time by $(1 - \eta_{\text{sub}})$, and supplies out-of-bag residuals for monitoring progress.

    Reproduce the shrinkage vs. M benchmark in Python 
    import numpy as np
from sklearn.datasets import make_friedman1
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.metrics import mean_squared_error

X, y = make_friedman1(n_samples=400, n_features=10, noise=2.0, random_state=42)
X_tr, X_val, y_tr, y_val = X[:200], X[200:], y[:200], y[200:]

for lr in [1.0, 0.3, 0.1]:
    gbr = GradientBoostingRegressor(
        learning_rate=lr, n_estimators=200, max_depth=3, random_state=42
    ).fit(X_tr, y_tr)
    mses = [mean_squared_error(y_val, p) for p in gbr.staged_predict(X_val)]
    best_m = int(np.argmin(mses)) + 1
    print(f"lr={lr:.2f} | M=5:{mses[4]:.2f} M=25:{mses[24]:.2f} M=100:{mses[99]:.2f} | best M={best_m} ({mses[best_m-1]:.2f})")
