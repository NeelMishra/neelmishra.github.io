    Boosting as Gradient Descent in Function Space

    October 2026 · 13 min read

    When students first hear the name Gradient Boosting, a natural question arises: a decision tree is made of discrete if-then threshold rules—what on earth are we taking the gradient with respect to? Jerome Friedman's landmark 2001 paper (Greedy Function Approximation: A Gradient Boosting Machine) answered that question with one of the cleanest conceptual shifts in machine learning: instead of differentiating loss with respect to model parameters, differentiate loss directly with respect to the model's predicted outputs, then train a shallow regression tree to approximate that downhill direction.

    1. Plain-English Intuition: Parameter Space vs. Function Space

    Compare how linear regression optimizes a loss versus how tree boosting works:

    • Parameter-space gradient descent ($\theta \in \mathbb R^p$): You commit up front to a smooth formula $f_\theta(x) = x^\top\theta$ parameterized by $p$ numbers $\theta = (\theta_1, \dots, \theta_p)^\top$. At step $m$, you compute $\nabla_\theta \mathcal L(\theta_{m-1}) \in \mathbb R^p$ and nudge the weights: $\theta_m = \theta_{m-1} - \eta \nabla_\theta \mathcal L(\theta_{m-1})$.
    • Why trees break parameter-space calculus: A CART tree selects discrete feature indices $j \in \{1,\dots,p\}$ and hard indicator cuts $\mathbf{1}\{x_j < t\}$ whose derivative with respect to $t$ is zero almost everywhere and undefined at the split. You cannot run $\theta \leftarrow \theta - \eta \nabla_\theta \mathcal L$ on split rules.
    • Function-space gradient descent ($\mathbf F \in \mathbb R^n$): Forget how $F(x)$ is represented internally and list its predictions on the $n$ training rows as an $n$-dimensional vector: $$\mathbf F = \bigl(F(x_1), F(x_2), \dots, F(x_n)\bigr)^\top \in \mathbb R^n.$$ Even when $F$ comes from a discontinuous tree ensemble, the per-row loss $L\bigl(y_i, F(x_i)\bigr)$—such as $\frac{1}{2}(y_i - F)^2$, Huber loss, or binary log-loss—is a smooth function of the scalar number $F(x_i)$! We can therefore ask, independently at every row $i$: would nudging $F(x_i)$ slightly up or slightly down reduce $L\bigl(y_i, F(x_i)\bigr)$?

    2. Deriving Pseudo-Residuals and the Least-Squares Tree Projection

    Define every quantity explicitly. Given training pairs $\{(x_i, y_i)\}_{i=1}^n$ and a pointwise loss $L\bigl(y_i, F(x_i)\bigr)$ differentiable in its second argument $F(x_i) \in \mathbb R$, write the total empirical risk of the ensemble function $F: \mathcal X \to \mathbb R$ as

    $$\mathcal L(F) = \sum_{i=1}^{n} L\bigl(y_i, F(x_i)\bigr).$$

    At round $m \in \{1, \dots, M\}$, the ensemble built so far is $F_{m-1}(x)$. We seek a weak learner $h \in \mathcal H$ (for instance, a depth-$d$ regression tree) and a small positive step size $\eta > 0$ to minimize $\mathcal L(F_{m-1} + \eta h)$.

    Step A — First-order Taylor expansion in function space: Expand each row's loss around its current prediction $F_{m-1}(x_i)$:

    $$\mathcal L(F_{m-1} + \eta h) \approx \mathcal L(F_{m-1}) + \eta \sum_{i=1}^{n} \left[\frac{\partial L\bigl(y_i, F(x_i)\bigr)}{\partial F(x_i)}\right]_{F = F_{m-1}} h(x_i).$$

    Define row $i$'s pseudo-residual $r_{im}$ as the negative functional derivative evaluated at $F_{m-1}(x_i)$:

    $$r_{im} = -\left[\frac{\partial L\bigl(y_i, F(x_i)\bigr)}{\partial F(x_i)}\right]_{F = F_{m-1}}.$$

    Notice why there is no summation over $k \ne i$ inside $r_{im}$: row $k$'s loss $L\bigl(y_k, F(x_k)\bigr)$ does not depend on coordinate $F(x_i)$ when $\mathbf F \in \mathbb R^n$ is treated as an unconstrained vector of $n$ coordinates. Dropping the constant $\mathcal L(F_{m-1})$ reduces the linearized problem to maximizing alignment $\sum_{i=1}^n r_{im} h(x_i)$ (equivalently minimizing $-\sum_{i=1}^n r_{im} h(x_i)$).

    Step B — Why we fit a tree instead of adding $\eta r_{im}$ directly: Setting $h(x_i) = r_{im}$ would move straight down $-\nabla_{\mathbf F}\mathcal L$, but $r_{im} = -\partial L(y_i, F) / \partial F$ requires knowing the true label $y_i$! On a new test query $x_{\text{new}}$, $y_{\text{new}}$ is unknown. Restricting $h \in \mathcal H$ to a shallow tree forces nearby feature vectors $x_i$ to share leaf predictions so $h_m(x_{\text{new}})$ generalizes across $\mathcal X$.

    Step C — Completing the square into ordinary least-squares CART: Fix the scale of candidate trees on the training set ($\sum_{i=1}^n h(x_i)^2 = c$; scaling will be absorbed by line search / $\eta$ anyway). Because both $c$ and $\sum_{i=1}^n r_{im}^2$ are constant with respect to $h$'s direction,

    $$\begin{aligned} \arg\min_{\substack{h \in \mathcal H \\ \sum_i h(x_i)^2 = c}} \left(-2\sum_{i=1}^{n} r_{im}\,h(x_i)\right) &= \arg\min_{\substack{h \in \mathcal H \\ \sum_i h(x_i)^2 = c}} \sum_{i=1}^{n} \Bigl(r_{im}^2 - 2 r_{im} h(x_i) + h(x_i)^2\Bigr) \\ &= \arg\min_{h \in \mathcal H} \sum_{i=1}^{n} \bigl(r_{im} - h(x_i)\bigr)^2. \end{aligned}$$

    That single algebraic identity explains why every gradient-boosting implementation grows its tree structure using a standard squared-error CART splitter on the pseudo-residuals $r_{im}$, even when the outer task is classification, quantile regression, or survival analysis!

    3. Loss Functions, Pseudo-Residuals, and Optimal Leaf Values $\gamma_{jm}$

    Growing the CART tree on $r_{im}$ partitions feature space into $J_m$ disjoint terminal leaves $R_{1m}, \dots, R_{J_m, m}$. Friedman (2001) noticed a second crucial refinement: once the regions $R_{jm}$ are fixed, the first-order Taylor approximation has done its job. Because leaves are disjoint, we can choose each leaf's scalar output $\gamma_{jm}$ to minimize the exact outer loss $L$ inside that leaf:

    $$\gamma_{jm} = \arg\min_{\gamma \in \mathbb R} \sum_{x_i \in R_{jm}} L\bigl(y_i,\, F_{m-1}(x_i) + \gamma\bigr), \qquad F_m(x) = F_{m-1}(x) + \eta \sum_{j=1}^{J_m} \gamma_{jm}\,\mathbf{1}\{x \in R_{jm}\}.$$

    Only under squared error does $\gamma_{jm}$ equal the simple mean of $r_{im}$. Compare the four workhorse losses side by side (writing $e_i = y_i - F_{m-1}(x_i)$ for regression error and $p_i = \sigma\bigl(F_{m-1}(x_i)\bigr) = \frac{1}{1+e^{-F_{m-1}(x_i)}}$ for binary log-odds):

    4. Concrete 4-Row Function-Space Step (Verified in Python)

    Trace one exact function-space gradient step on four rows $(x_i, y_i) = (1, 10), (2, 14), (3, 22), (4, 26)$ under half squared error $L(y_i, F) = \frac{1}{2}(y_i - F)^2$, using a depth-1 regression stump ($J_1 = 2$ leaves) and learning rate $\eta = 0.5$:

    1. Constant initialization: $F_0 = \bar y = \frac{10 + 14 + 22 + 26}{4} = 18.0$, so $\mathbf F_0 = (18, 18, 18, 18)^\top \in \mathbb R^4$ with initial total loss $\mathcal L(\mathbf F_0) = \frac{1}{2}\bigl((-8)^2 + (-4)^2 + 4^2 + 8^2\bigr) = 80.0$.
    2. Functional gradient & pseudo-residuals: $\nabla_{\mathbf F}\mathcal L(\mathbf F_0) = \mathbf F_0 - \mathbf y = (+8, +4, -4, -8)^\top$, so the unconstrained steepest-descent vector is $\mathbf r_1 = -\nabla_{\mathbf F}\mathcal L(\mathbf F_0) = (-8, -4, +4, +8)^\top$.
    3. Project $\mathbf r_1$ onto a 2-leaf stump $h_1 \in \mathcal H$: A depth-1 tree can output only two distinct values across ordered $x$. Splitting at $x < 2.5$ minimizes $\sum_{i=1}^4 (r_{i1} - h(x_i))^2$, assigning $\gamma_{1,1} = \frac{-8 + (-4)}{2} = -6.0$ to $R_{1,1} = \{x < 2.5\}$ and $\gamma_{2,1} = \frac{4 + 8}{2} = +6.0$ to $R_{2,1} = \{x \ge 2.5\}$. Thus $\mathbf h_1 = (-6, -6, +6, +6)^\top$.
    4. Verify downhill inner product & loss drop: The directional inner product with the gradient is strictly negative, $$\bigl\langle \nabla_{\mathbf F}\mathcal L(\mathbf F_0),\, \mathbf h_1 \bigr\rangle = 8(-6) + 4(-6) + (-4)(6) + (-8)(6) = -144 < 0.$$ Stepping with $\eta = 0.5$ gives $\mathbf F_1 = \mathbf F_0 + 0.5\,\mathbf h_1 = (15, 15, 21, 21)^\top$, cutting total loss from $\mathbf{80.0}$ down to $\frac{1}{2}(25 + 1 + 1 + 25) = \mathbf{26.0}$!

    Reproduce the function-space inner product, projection, and binary log-loss check in Python 
    import numpy as np
from sklearn.tree import DecisionTreeRegressor

X = np.array([[1.0], [2.0], [3.0], [4.0]])
y = np.array([10.0, 14.0, 22.0, 26.0])

# 1. Squared-error function-space step
F0 = np.full_like(y, y.mean())
grad = F0 - y          # dL/dF for L = 0.5*(y - F)^2
r1 = -grad             # pseudo-residuals [-8, -4, +4, +8]
stump = DecisionTreeRegressor(max_depth=1).fit(X, r1)
h1 = stump.predict(X)  # [-6, -6, +6, +6]
F1 = F0 + 0.5 * h1     # [15, 15, 21, 21]

assert np.isclose(grad @ h1, -144.0)
assert np.isclose(0.5 * np.sum((y - F0)**2), 80.0)
assert np.isclose(0.5 * np.sum((y - F1)**2), 26.0)
print("F1:", F1, "| Half-SSE:", 0.5 * np.sum((y - F1)**2))

# 2. Binary log-loss Newton leaf check on y_bin = [0, 0, 1, 1] from F0 = 0 (p0 = 0.5)
y_bin = np.array([0.0, 0.0, 1.0, 1.0])
p0 = np.full(4, 0.5)
r_bin = y_bin - p0                     # [-0.5, -0.5, +0.5, +0.5]
gamma_right = r_bin[2:].sum() / (p0[2:] * (1 - p0[2:])).sum()  # 1.0 / 0.5 = +2.0 log-odds!
print("Log-loss right-leaf Newton gamma:", gamma_right)
    Where first-order GBM meets second-order XGBoost: Friedman's GBM uses a first-order gradient $r_{im}$ to choose tree splits and only uses curvature inside the post-split leaf update $\gamma_{jm}$. XGBoost pushes the second derivative $h_i = \partial^2 L / \partial F^2$ plus explicit $L_2$ leaf regularization $\lambda$ directly into the split-finding criterion itself.
