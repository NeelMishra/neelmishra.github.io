    Newton Boosting & XGBoost: Leaves, Gains & Constraints

    September 2026 · 12 min read

    The classification example introduced a Newton update using gradients and curvature. Here we derive that leaf value and use it to compare whole tree structures. XGBoost makes this regularized objective central to its tree construction.

    Keep the scale straight: a leaf returns a correction to the current response or score. It does not return a brand-new prediction independent of the ensemble. We will use a squared-loss dataset for the split calculation because its curvature is especially simple.

    Use slope and curvature to choose a leaf value

    At the current prediction, the gradient says which direction increases a row’s loss. The Hessian, or second derivative, measures how quickly that slope changes. Write their values as $g_i$ and $h_i$ for row $i$; here $h_i$ means curvature, not a tree.

    Inside one candidate leaf, add the gradients into $G$ and the Hessians into $H$. Let $\lambda\geq0$ penalize large leaf values. The quadratic approximation gives this correction $w$, provided $H+\lambda>0$:

    $$w=-\frac{G}{H+\lambda}.$$

    For $G=-6$, $H=2$, and $\lambda=1$, the leaf value is +2. The negative slope favors raising predictions; curvature and the penalty limit the step. Learning rate 0.1 makes the actual score correction +0.2.

    Derive the leaf formula

    Let $F_i$ be the current score and $w$ a constant added to every row in the leaf. A second-order Taylor expansion of each row loss, summed over the leaf and with constant terms removed, gives

    $$Q(w)=Gw+\frac12(H+\lambda)w^2.$$

    Its derivative is $G+(H+\lambda)w$. Setting that to zero gives the formula above. Positive curvature makes it a minimum. This version omits L1 regularization and additional constraints.

    Compare one leaf with two

    Take four rows with feature values $x=[1,2,3,4]$ and targets $y=[3,3,-3,-3]$. Suppose the current prediction is 0 for every row. Using half squared error, each row has gradient $g_i=F_i-y_i$ and curvature $h_i=1$, where $F_i$ is its current prediction. So the gradients are $[-3,-3,+3,+3]$.

    A split at $x<2.5$ separates rows that need an upward correction from rows that need a downward correction. With $\lambda=1$, the statistics become:

    The opposite gradient sums cancel in one parent leaf. Separating them lets the children correct in opposite directions. Substituting their best values into $Q$ gives −6 for each child and 0 for the parent: an improvement of 12.

    Let $\gamma$ be the cost of adding one leaf. Two children replace one parent, so a cost of 0.5 leaves gain 12 − 0.5 = 11.5.

    With learning rate 0.1, the new predictions are $[0.2,0.2,-0.2,-0.2]$. Half squared training error falls from $4\times\tfrac12(3)^2=18$ to $4\times\tfrac12(2.8)^2=15.68$. That decrease, 2.32, differs from the split gain: the gain includes regularization and compares full candidate leaf values before shrinkage. It is not a promised change in the evaluation metric.

    Check your understanding: what if $\lambda$ rises from 1 to 4?

    The child values shrink from $\pm6/(2+1)=\pm2$ to $\pm6/(2+4)=\pm1$. The split gain becomes $\tfrac12(36/6+36/6)-0.5=5.5$. This candidate still passes the gain test, assuming the other split constraints hold; increasing the penalty reduced both its correction and its score.

    Write the general split-gain equation

    Use subscripts $L$ and $R$ for the child sums. Parent sums are their totals. Substituting each optimal leaf value into the quadratic and comparing the costs gives

    $$\mathrm{Gain}=\frac12\left[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right]-\gamma.$$

    This scores the unshrunk quadratic approximation. Other split constraints must still hold. For half squared loss each row has curvature 1; for binary log loss it is $p(1-p)$, so minimum curvature support is not generally the same as minimum row count.

    Where the penalties enter

    A common tree penalty is $\Omega(f)=\gamma T+\tfrac12\lambda\sum_{j=1}^{T}w_j^2$, where $T$ is leaf count and $w_j$ is leaf $j$'s correction. The first term charges for extra regions; the second discourages large corrections. The round objective is the current data loss after adding the tree plus this penalty.

    Dropping the unchanged part of the current loss and grouping the Taylor approximation by leaf gives $\sum_j[G_jw_j+\tfrac12(H_j+\lambda)w_j^2]+\gamma T$. This is why the row statistics $g_i,h_i$ suffice to evaluate a candidate partition. Once rows have been assigned to leaves, each leaf's unconstrained quadratic can be optimized independently.

    Check: if a split only separates two groups with the same useful correction, must it help?

    No. The parent may already represent that correction sufficiently well, and each extra leaf incurs a complexity cost. Compute the optimized child-versus-parent objective and enforce all support constraints. More regions alone are not evidence of better generalization.

    Three regularizers with different jobs

    ControlWhat it changesCommon confusion
    L2 leaf penalty λShrinks values through H + λ and changes split gainsNot equivalent to a smaller learning rate; it can change which tree is selected.
    Minimum split improvement γCharges for one additional leaf in this objective conventionA positive raw gain may still fail this penalty.
    Learning rate ηScales the fitted correction added after the tree is chosenDoes not turn the unshrunk gain into the observed validation improvement.

    An optional L1 penalty adds $\alpha|w|$ per leaf. The optimum becomes $w=-S(G,\alpha)/(H+\lambda)$, where $S(G,\alpha)=\operatorname{sign}(G)\max(|G|-\alpha,0)$. This can set a small-gradient leaf exactly to zero. Here $\alpha$ is an L1 coefficient, unrelated to the AdaBoost vote notation in an earlier chapter.

    For $G=-6,H=2,\lambda=1,\alpha=2$, soft thresholding gives $S=-4$, so $w=4/3$. Setting $\alpha=6$ gives zero. The associated optimized leaf contribution also changes; do not use the L2-only gain formula while claiming to evaluate an L1-regularized objective.

    Curvature support is not a row count

    Under half squared loss, every row contributes curvature 1, so a minimum Hessian sum resembles a minimum sample count. Under binary log loss, each contributes $p(1-p)$. Ten rows at $p=0.5$ contribute $H=2.5$, whereas ten rows at $p=0.99$ contribute $H=0.099$. Equal row counts can therefore produce very different support under the quadratic objective.

    Small curvature can produce a large unregularized Newton correction. Leaf penalties, minimum child curvature, depth/leaf limits, and sometimes explicit step constraints help control it. For a custom objective, check the required gradient/Hessian convention and whether the approximation assumes nonnegative curvature. A formula valid for convex log loss is not automatically valid for any arbitrary loss.

    Reduce the work required to search splits

    Histogram methods group feature values into bins and accumulate gradient statistics per bin. Search scans bin boundaries instead of every distinct value. This can reduce compute and memory at the cost of threshold precision; multiple libraries support it.

    Reuse the four rows above. Exact search can test the three gaps: 1.5, 2.5, and 3.5. Suppose a deliberately coarse histogram puts $x=1,2,3$ in one bin and $x=4$ in another. Its only available split is at 3.5. The ideal 2.5 boundary lies inside a bin and cannot be tested.

    Same data, $\lambda=1$ and $\gamma=0.5$; the binning alone changes which candidate is available. These bins are illustrative, not a library’s default bin assignment.

    For the coarse split, the gain is $\tfrac12(9/4+9/2)-0.5=2.875$. This is the tradeoff: fewer boundaries mean less search work, but a useful distinction can disappear. More bins can recover finer choices while increasing memory and work; compare validation results rather than assuming finer bins always help.

    XGBoost’s original paper also develops sparsity-aware split search, approximate proposals, and efficient data access. Its learned default branch can route missing values at prediction time. The GBM systems chapter follows these choices through a numeric histogram example.

    Missing values participate in split search

    A missing feature value cannot be compared with a numeric threshold in the usual way. A learned default direction compares the candidate objective when missing rows go left versus when they go right. The selected direction becomes part of the stored split and is reused at inference. It can capture predictive missingness, but it cannot protect against a changed data-collection process.

    A zero, an absent sparse entry, and a missing value need not mean the same thing. Validate the input representation and library settings. For example, a real measured zero should not accidentally be turned into an “unknown” category by a preprocessing conversion.

    Encode known shape restrictions deliberately

    A monotonic constraint asks that increasing a feature, while holding the others fixed, never decrease or never increase the model response. Interaction constraints restrict which features can share tree paths. Both reduce the set of permitted models; use them when the domain claim is defensible, then verify the resulting behavior and predictive tradeoff.

    They do not establish causality. A constrained price model can enforce increasing predicted price with area at fixed covariates, but that is a property of the fitted response surface, not an estimate of an intervention effect.

    The objective is only half of the system

    We now know how a candidate leaf and split are scored. The next chapter asks which candidate splits are searched, which leaf grows next, and how categories are represented.
