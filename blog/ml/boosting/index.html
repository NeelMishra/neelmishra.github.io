    Boosting: Build a Model One Correction at a Time

    September 2026 · 4 min read

    Bagging trains several models and averages their opinions. Now suppose those models share a simple error: they systematically underpredict a particular region. Averaging alone may leave that error in place. Boosting asks a new question: what should the next learner do differently given the predictions we already have?

    Start here after bagging, or go directly to the first chapter if you already understand tree leaves and weighted averages. Before the gradient chapter, refresh the idea that a derivative measures the local change in a loss. Each symbol will be defined where it first matters.

    Understand one update before its formula

    A regression model currently predicts 6 where the target is 2. A new tree proposes correction −3. If we trust half of that correction, the ensemble moves to 4.5. The next tree sees the error that remains, 2 − 4.5 = −2.5. Earlier trees stay fixed; the new training problem changes.

    The questions that connect the chapters

    1. Which mistakes matter next?

      Fit weighted classifiers and derive AdaBoost votes.

    2. What correction improves a numeric prediction?

      Follow actual residual stumps, then replay the changing training targets.

    3. What changes for probabilities and other losses?

      Derive log-loss gradients and compare first-order, Newton, robust, and quantile corrections.

    4. How do we score a leaf and a split?

      Calculate regularized Newton values and understand the meaning of constraints.

    5. How do modern systems build the trees efficiently?

      Connect histograms, leaf-wise growth, and ordered categorical processing to examples.

    6. How much model should we fit?

      Choose capacity, work an early-stopping trace, and design validation and serving.

    7. Can you calculate, code, and defend the choices?

      Complete a 60-minute workshop with answer explanations and executable examples.

    Read one chapter per session and work its central example before moving on. The mathematics builds in order: weighted error → loss derivative → score update → curvature → split gain. Optional proofs and answer disclosures let you control the depth without losing the main story.

    Keep these two conventions separate

    AdaBoost here uses labels −1 and +1 and returns weighted classifier votes. Binary log-loss boosting uses labels 0 and 1 and adds corrections to a real-valued score, then uses sigmoid to obtain a probability. These are related loss-minimization ideas, but their numerical update rules are not interchangeable.

    Boosting can improve a model with shared approximation errors; it can also chase noisy labels. We will therefore connect every training improvement to a separate question: does it help on validation data?
