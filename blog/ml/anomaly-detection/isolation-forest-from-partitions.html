    Isolation Forest: Follow One Point Through a Forest

    September 2026 · 4 min read

    Before you start: Decision-tree splits and averages. No supervised anomaly labels are required to follow the derivation.

    Imagine values [1,2,3,4,20] on a number line. To isolate 20, a random cut anywhere between 4 and 20 succeeds immediately. To isolate 3, several cuts are usually needed because other values surround it. Isolation Forest turns this asymmetry into an anomaly score: unusual points tend to separate from the sample quickly.

    How an isolation tree grows

    At each node, select a feature randomly, then choose a split between its minimum and maximum values in the current sample. Send rows to the corresponding child. Stop when the node contains one row, no useful split remains, or a depth limit is reached. Unlike a supervised decision tree, there is no label impurity to minimize. Random partitioning itself supplies the signal.

    Trees typically train on subsamples of size ψ, which keeps construction cheap and reduces the chance that a large cluster of unusual points masks itself. Subsampling is part of the model, not just an approximation forced by memory. More trees reduce random variability in the average path length; they do not fix a feature space in which the anomalies look ordinary.

    Normalize paths for the sample size

    The score uses the expected path length $E[h(x)]$ across trees. A reference path-length normalization is $c(n)=2H_{n-1}-2(n-1)/n$ for $n>1$, with $c(1)=0$, where $H_j$ is the harmonic sum. An unfinished leaf containing $n$ rows adds $c(n)$ to the traversed depth.

    $$s(x,\psi)=2^{-E[h(x)]/c(\psi)}.$$

    Short paths make the negative exponent closer to zero, so the score moves toward 1. A path equal to c(ψ) gives 0.5. Longer paths give smaller scores. For ψ=5, the exact harmonic formula gives c(5)=2.5667. A point with mean path 1 scores about 0.763; mean path 3 gives about 0.445. This is a normalized isolation score, not a probability of fraud or maliciousness.

    Implementations can approximate harmonic numbers, especially for larger leaves. Check the chosen library rather than expecting bit-for-bit equality with a hand calculation using exact harmonic sums. Our figure shows traversed depths, while the formula explains forest scoring.

    Keep score direction and threshold separate

    from sklearn.ensemble import IsolationForest

model = IsolationForest(
    n_estimators=200, max_samples=256,
    contamination="auto", random_state=7,
)
model.fit(X_train)
normality = model.score_samples(X_test)  # Lower is more abnormal.
anomaly_rank_score = -normality          # Higher is more abnormal.
decision = model.decision_function(X_test)
is_outlier = decision < 0

    In scikit-learn, score_samples has the opposite direction to “higher means more anomalous.” decision_function subtracts an offset, and predict uses that decision boundary. A contamination setting determines a threshold from the training-score distribution; it does not teach the model what a malicious application is. Record the score convention in every dataset so sorting cannot silently invert the queue.

    What random cuts can and cannot see

    Constant features contain no partition information. IDs represented as arbitrary numbers create artificial order. Many irrelevant dimensions can dilute useful splits. Sparse behavior can make “no activity” dominate the sample, and a large legitimate customer may be isolated simply because it is large. Feature construction and the reference population matter at least as much as the tree count.

    Axis-aligned random partitions can have geometric artifacts. Rotations or alternative isolation methods may behave differently. Evaluate on representative cases and compare simple baselines: robust univariate scores, group-normalized rates, and a supervised model when trustworthy labels exist. An elaborate forest should outperform these for the task it serves.

    Test the behavior you intend to deploy

    Fit preprocessing and the forest on training data only. Score a held-out period, examine stability across seeds, and inspect both the top queue and a random background sample. Vary ψ and tree count separately. If a feature is absent during serving, define a consistent missing-data policy; silently substituting zero can produce a large false-positive cohort.

    Check your understanding: Does contamination=0.01 mean each flagged point has a 99% chance of being malicious?

    No. It sets a score threshold related to the training distribution. An anomaly score describes isolation relative to a reference population; maliciousness needs labels or additional evidence.
