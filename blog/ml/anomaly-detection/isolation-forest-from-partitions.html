    Isolation Forest: Follow One Point Through a Forest

    September 2026 · 6 min read

    Put [1, 2, 3, 4, 20] on a number line. A cut anywhere between 4 and 20 separates 20 immediately. Separating 3 is harder because nearby points surround it. Isolation Forest scores points by how quickly random cuts separate them.

    Build many random partition trees

    Choose a random feature, then a random threshold between its smallest and largest values at the current node. Split the rows and repeat. Stop at a single row, an unsplittable group, or the depth limit. No labels or impurity calculation are needed.

    One tree can be lucky. A forest averages across many trees built from different random choices and training subsamples. Call the number of rows sampled for each tree $\psi$ (psi). More trees stabilize the average; changing $\psi$ changes the sample each tree tries to isolate.

    Turn path length into a score

    A path length counts splits from the root to a point’s leaf. If a depth limit leaves several rows together, add an estimate of the cuts still needed to separate them. Let $\bar h(x)$ be this corrected path length, averaged across trees, for point $x$.

    Larger samples generally need more cuts. The reference length $c(\psi)$ adjusts for that sample size. Divide the average path by this reference, negate the ratio, and use it as an exponent of 2:

    $$s(x)=2^{-\bar h(x)/c(\psi)}.$$

    This makes shorter paths produce larger scores. If the average path equals the reference length, the score is $2^{-1}=0.5$. For $\psi=5$, an exact harmonic-number calculation gives $c(5)\approx2.5667$:

    2.5667About 0.500Near the reference length

    These are hand calculations, not measured forest outputs. The score describes isolation relative to a sample; 0.763 is not a 76.3% probability of harmful behavior.

    Where does the reference length come from?

    For a group of $n>1$ rows, the paper uses a reference from random search-tree analysis. Let $H_{n-1}=1+1/2+\cdots+1/(n-1)$ be a harmonic sum. Then:

    $$c(n)=2H_{n-1}-\frac{2(n-1)}{n},\qquad c(1)=0.$$

    Use $c(\psi)$ to normalize the forest score. Use $c(n)$ to estimate the remaining path inside a leaf containing $n$ rows. Implementations may approximate the harmonic sum, so their small-sample numbers can differ from the exact calculation above. See Liu, Ting and Zhou, Section 2.

    Check the library’s score direction

    Scikit-learn’s score_samples uses the opposite sign: lower means more abnormal. Negate it if you want a score to sort from most to least unusual. Here X_train and X_test use the same feature columns and preprocessing:

    from sklearn.ensemble import IsolationForest

model = IsolationForest(
    n_estimators=200, max_samples=256,
    contamination="auto", random_state=7,
)
model.fit(X_train)
anomaly_score = -model.score_samples(X_test)  # Higher = more unusual.
is_outlier = model.decision_function(X_test) < 0

    decision_function shifts the score by a threshold offset. A numeric contamination chooses that cutoff from training scores; "auto" uses the library’s built-in rule. Neither supplies labels about which observations are harmful. The API reference documents these conventions.

    Make the comparison meaningful

    A large legitimate customer may be isolated because its raw counts are large. Arbitrary numeric IDs create meaningless cut points, and constant features provide no useful split. Before adding trees, inspect what the features and training population make “ordinary.” The next chapter works through counts, exposure, and missing observations.

    Evaluate the ranking on later data

    Fit preprocessing and the forest on training data, then inspect a held-out period. Check the highest-scoring cases, a sample outside that group, and stability across random seeds. Tune sample size and tree count separately. Finally, choose an investigation policy appropriate to the review budget.
