    1. Regression: Main Ideas

    September 2026 · Lecture 1 / 4 · 10 min read

    Notes on StatQuest with Josh Starmer · Gradient Boost Part 1 · 15:52 video. Explanations and redrawn figures follow the lecture’s worked example.

    A boosted regression model starts with one simple prediction. Each new tree learns how to correct what the model still gets wrong. The final prediction adds those corrections together.

    1. Start with the average weight

    Video 5:50 ↗

    The lecture predicts weight from height, favorite color, and gender. Before using any feature, predict the average training weight for everybody: about 71.2 kg.

    The lecture’s six rows. Residual = actual weight − current prediction. This page uses the video’s rounded starting value, 71.2.
    RowHeight (m)ColorGenderWeight (kg)Residual
    11.6BlueMale88+16.8
    21.6GreenFemale76+4.8
    31.5BlueFemale56−15.2
    41.8RedMale73+1.8
    51.5GreenMale77+5.8
    61.4BlueFemale57−14.2

    The six weights add to 427 kg, so the exact mean is $427/6=71.1666\ldots$. We use 71.2 below to follow the video. This first prediction is deliberately simple: it gives us a starting point whose mistakes we can measure.

    It is already a model, just one that ignores the features. Someone short and someone tall both get 71.2. The first tree’s job is to explain which people should move above or below that common starting value.

    2. Why predict the residual?

    Video 7:17 ↗

    Row 1 weighs 88 kg, but the model predicts 71.2. The missing amount is $88-71.2=16.8$. Train the new tree to predict that missing amount from the features.

    The tree’s output is added to the prediction we already have.

    Current prediction + predicted residual = updated prediction.

    $$71.2+16.8=88.$$

    That is why an output of 16.8 is useful: it fills the gap. Predicting 88 again and adding it would give 159.2. The new tree must learn the remaining error.

    We know actual weights during training, so we can calculate those errors. For a new person we cannot calculate the true error; the tree estimates a correction from their height, color, and gender.

    The training target changes; the input columns do not

    There are two different questions in the training data. The original task asks “what does this person weigh?” The new tree asks “how much should the current prediction move for a person with these features?” The answer to that second question is the residual.

    For row 3, the same reasoning goes downward: the model predicts 71.2 but the actual weight is 56. Its training target for the new tree is $56-71.2=-15.2$. A tree can output a negative number because it is predicting an adjustment, not someone’s weight.

    Training on the gaps also keeps the ensemble’s work cumulative. Once earlier trees have explained part of the data, later trees concentrate on the part left unexplained. Training every new tree on the original weights and adding its prediction would repeatedly count the same signal.

    3. Fit a small tree to those residuals

    Video 7:35 ↗

    The inputs stay the same. The training target changes from weight to residual. Feature rules group rows with similar residuals into leaves. If several rows share a leaf, the tree uses their mean residual as its output.

    Rows 3 and 6 share a leaf, so its output is $(-15.2-14.2)/2=-14.7$. Their individual errors differ, but both need roughly the same downward correction. A region is simply the group of inputs that follows the rules into one leaf.

    Walk through one region

    In the pictured tree, a female row follows the left branch. If her height is below 1.6 m, she reaches the leaf containing rows 3 and 6. The complete rule for that region is therefore “female and height below 1.6 m.” Its training rows need corrections of −15.2 and −14.2, so −14.7 is a reasonable shared correction.

    For a new person, those feature rules are enough to reach the region. We do not check whether her residual is close to −14.7; her true residual is unknown. The association between that feature region and that correction was learned during training.

    Why use one value for both training rows? That is what a tree leaf can represent: one constant output for all inputs reaching it. To give the rows different values, the tree would need another split that separates their features. Small trees deliberately limit that flexibility.

    4. Add only part of the correction

    Video 9:11 ↗

    The lecture scales each tree by a learning rate of 0.1. For row 1:

    $$F_1(x_1)=71.2+0.1(16.8)=72.88.$$

    It is closer to 88, but it has not tried to fix the whole error at once. Small updates let many trees build the fit gradually and can reduce overfitting. A perfect match to a training row alone tells us little about a new person.

    The learning rate scales the tree’s contribution; it does not change the actual target, 88.

    Every row after the first tree; learning rate 0.1.

    Rows 4 and 5 both receive $0.1(3.8)=0.38$, because they share a leaf. Their new predictions are equal, but their new residuals are not: the actual weights remain 73 and 77. The next tree sees those different remaining errors.

    The tree’s full fitted correction for rows 3 and 6 would predict 56.5 for both. That lies between their actual weights, 56 and 57. Shrinking the contribution to one tenth moves both predictions only to 69.73 in this round. There is still work for later trees.

    5. Recalculate the errors and build the next tree

    Video 10:28 ↗

    For row 1 the remaining residual is now $88-72.88=15.12$. Recalculate residuals for all rows using the whole updated model, fit the next tree to those values, and add its scaled output.

    If the second tree predicts 15.12 for this row, its next prediction is:

    $$72.88+0.1(15.12)=74.392.$$

    The video displays these as 72.9, 15.1, and 74.4 after rounding. A shared leaf may only approximate a row’s residual, and later trees may use different feature rules.

    What stays fixed while the next tree is trained?

    The actual weights and input features stay fixed. The initial prediction and the first tree also stay fixed. What changes is the residual column: it is recalculated from the sum of everything fitted so far.

    A later tree can use a different feature at its root, create different regions, and put rows together that the first tree separated. It is answering a new correction problem. It is not editing the old tree’s leaves.

    The conditional calculation above assumes the second tree gives row 1 a correction of 15.12. If it groups that row with others, its shared output can differ. Boosting predicts the residual; it does not automatically know or exactly remove every training error.

    6. Predict for a new person

    Video 13:50 ↗

    Start at 71.2. Send the new person’s features through each trained tree, take the one leaf output reached in each, multiply it by 0.1, and add everything:

    $$F_M(x)=F_0+\nu h_1(x)+\nu h_2(x)+\cdots+\nu h_M(x).$$

    Here $h_m(x)$ is tree $m$’s correction and $\nu$ is the learning rate. No actual weight or residual is needed to route the new person through a tree.

    Training and prediction use different information

    The label is needed to learn corrections, but not to use them.
    During trainingFor a new person
    Use features and actual weights.Use only the person’s features.
    Calculate residuals from the current ensemble.No residual is calculated.
    Choose feature splits and fit leaf corrections.Follow the saved feature splits.
    Append the newly fitted tree to the model.Add the saved contribution from every tree.

    For example, a new male with favorite color blue follows the first tree to its +16.8 leaf. After that tree, the ensemble predicts $71.2+0.1(16.8)=72.88$ kg. Later trees supply their own corrections for the same person. Nothing in this calculation requires knowing his true weight.

    Adding more trees gives the model more opportunities to learn useful corrections, but also more opportunities to fit noise. Choose the number of rounds using held-out data. A smaller training residual alone does not establish a better prediction for new people.
