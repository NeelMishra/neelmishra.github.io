    Gradient Boosted Machines: Foundations

    September 2026 · 4 min read

    A gradient-boosted machine keeps an existing prediction and adds trees that correct it. This series concentrates on the choices inside that loop: loss, leaf values, regularization, and efficient split search. For the full first derivation, use the four-row boosting example.

    Add a correction to the current prediction

    Let $F_{m-1}(x)$ be the prediction before round $m$, $h_m(x)$ the new tree’s correction, and $\nu$ the learning rate scaling that correction. The update is:

    $$F_m(x)=F_{m-1}(x)+\nu h_m(x).$$

    If the current prediction is 5, the tree suggests +2, and the learning rate is 0.1, the new prediction is 5.2. At inference, retain the starting prediction and add every learned, scaled tree.

    For squared error, fit what remains

    Begin with the mean training target. For each row, subtract the current prediction from the target. A positive residual asks for an increase; a negative one asks for a decrease. Fit a small regression tree to these residuals and add its scaled output.

    Each step searches all gaps between the ten ordered inputs and chooses the stump with the smallest squared residual error. Its leaves store mean residuals. The readout reports the actual training MSE. Individual rows can get worse even while the total loss improves.

    Other losses define different corrections

    The residual is the negative loss derivative for squared error. More generally, a loss derivative asks how changing a row’s predicted score would change its loss. Fit a tree to the negative derivatives to approximate a useful correction.

    The next chapter explains why classification and count models update scores on different scales. It also separates the target used to fit a tree’s structure from the final value stored in each leaf.

    Limit each correction’s complexity

    A stump changes predictions using one feature split. A deeper tree can condition one feature’s effect on another. More capacity can capture useful interactions or fit noise, so choose depth, leaf support, and learning rate using validation.

    Boosting rounds depend on earlier predictions; work inside a round can still parallelize. This dependency distinguishes the training loop from fitting forest trees independently. It does not guarantee that boosting beats a forest or one well-chosen tree.
