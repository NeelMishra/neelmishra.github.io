    Loss Functions and Pseudo-Residuals

    September 2026 · 6 min read

    The loss decides what counts as an error. A tree then groups rows that can share a useful correction. Keep the target, the model’s score, and the quantity reported to a user separate.

    Ask how one prediction should move

    For row $i$, let $y_i$ be its observed target, $F_i$ its current score, and $\ell(y_i,F_i)$ its loss. The correction target $r_i$, often called a pseudo-residual, is the negative derivative with respect to that score:

    $$r_i=-\frac{\partial\ell(y_i,F_i)}{\partial F_i}.$$

    This says which small score change would reduce loss. A fitted tree approximates those targets with shared leaf values. See why gradients supply correction targets for the derivation.

    Choose the prediction scale first

    In this table, $y$ is the observed target and $F$ is the score updated by trees. For binary labels, $p$ is the positive-class probability. For counts, $\mu$ is the expected count over the stated observation interval. For Huber loss, $e=y-F$ is the residual and $\delta>0$ is the threshold.

    Start at the loss’s best constant

    Before the first tree, give every training row the same raw score $c$. Choose $c^*$ to minimize $J(c)=\sum_i\ell(y_i,c)$, then start the ensemble at $F_0(x)=c^*$. The reported prediction may be a transformation of that score.

    Loss — open its derivationReported predictionInitial raw score $c^*$

    Poisson, equal exposure$\bar y$$\log\bar y$

    The finite binary score requires both classes; the finite Poisson score requires a positive mean count. The linked pages derive each result and explain the boundary cases. Start with the best-constant overview and loss explorer to compare them.

    Why pseudo-residuals help the tree form regions

    Boosting adds each new tree’s output to the model’s current score. So the new tree must learn what correction to make. That is why we train it on pseudo-residuals.

    With squared error, the correction is actual value − current prediction. If the model predicts 10 but the actual value is 7, the correction is $7-10=-3$: lower the prediction by 3.

    The new tree gets the original features as inputs and the pseudo-residuals as training targets. It is learning which inputs need which corrections.

    Suppose rows with $x=1,2,3,4$ need corrections −3, −2, +2, +3. Every row in one leaf must share one correction. The tree therefore looks for a feature rule that groups similar correction targets. Here, $x<2.5$ works:

    • Left: $x=1,2$ need −3 and −2. Their average, −2.5, is a useful shared correction.
    • Right: $x=3,4$ need +2 and +3. Their average, +2.5, is a useful shared correction.

    Those feature-defined groups are the regions. The pseudo-residuals help the tree choose a useful grouping. The feature rule tells us where any row belongs: a new row with $x=1.8$ goes left and gets the left correction, scaled by the learning rate.

    For other losses, pseudo-residuals are negative gradients: positive means raise the score; negative means lower it. They guide the grouping in the same way, although the final correction amount may need refinement.

    Quantile loss

    Quantile loss gives unequal penalties to underprediction and overprediction to estimate a chosen conditional percentile. Two fitted quantiles can form an interval, but its coverage still needs validation. Continue to how a tree groups these correction targets.
