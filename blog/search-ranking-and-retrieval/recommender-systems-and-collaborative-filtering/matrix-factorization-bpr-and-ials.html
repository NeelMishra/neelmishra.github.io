1. Matrix Factorization, Implicit Feedback (iALS) & Bayesian Personalized Ranking (BPR)

Collaborative Filtering · 13 min read

Unlike search—where a user provides an explicit text query—a recommender system must infer what a user wants from their past interactions alone. Collaborative Filtering (CF) discovers latent tastes by factoring the sparse user–item interaction matrix $R \in \mathbb{R}^{M \times N}$ into compact user vectors $\mathbf{p}_u \in \mathbb{R}^d$ and item vectors $\mathbf{q}_i \in \mathbb{R}^d$. This chapter traces the evolution from explicit-rating Matrix Factorization to Implicit Alternating Least Squares (iALS) and Bayesian Personalized Ranking (BPR).

1. Explicit Matrix Factorization vs. The Implicit Feedback Reality

In the classic Netflix Prize formulation, we observe explicit star ratings $r_{ui} \in \{1, 2, 3, 4, 5\}$ on a tiny subset of observed user–item pairs $\mathcal{K} = \{(u, i) : r_{ui} \text{ is observed}\}$ (typically $< 1\%$ of the matrix) and minimize regularized squared error over observed ratings only:

$$\mathcal{L}_{\text{explicit}} = \sum_{(u, i) \in \mathcal{K}} \left(r_{ui} - (\mu + b_u + b_i + \mathbf{p}_u^\top \mathbf{q}_i)\right)^2 + \lambda \left(\|\mathbf{p}_u\|_2^2 + \|\mathbf{q}_i\|_2^2 + b_u^2 + b_i^2\right)$$

Why explicit MF fails on implicit feedback: In production (clicks, video watches, purchases, song plays), users rarely leave $1$-star ratings. Instead, we observe positive-only implicit counts $r_{ui} \ge 0$ (e.g., user $u$ watched video $i$ three times). If you train $\mathcal{L}_{\text{explicit}}$ only on observed positive interactions ($r_{ui} > 0$), the model trivially predicts $\hat{r}_{ui} \approx 1$ for everything! Yet treating all $99.9\%$ unobserved entries ($r_{ui} = 0$) as hard negative labels destroys sparsity—turning a $10^8$-interaction problem into a dense $M \times N = 10^{13}$-cell matrix.

2. Implicit Alternating Least Squares (iALS) & The Gram-Matrix Trick

Hu, Koren, and Volinsky (2008) solved this in Implicit ALS (iALS) by separating preference $p_{ui} \in \{0, 1\}$ from confidence $c_{ui} \ge 1$:

$$p_{ui} = \begin{cases} 1 & \text{if } r_{ui} > 0 \\ 0 & \text{if } r_{ui} = 0 \end{cases}, \qquad c_{ui} = 1 + \alpha \, r_{ui}$$

Unobserved pairs $(r_{ui} = 0)$ have a weak negative preference ($p_{ui} = 0$) with baseline confidence $c_{ui} = 1$, whereas repeated positive interactions ($r_{ui} > 0$) carry high confidence $c_{ui} = 1 + \alpha r_{ui}$ (typically $\alpha \in [10, 40]$):

$$\mathcal{L}_{\text{iALS}} = \sum_{u=1}^M \sum_{i=1}^N c_{ui} \left(p_{ui} - \mathbf{p}_u^\top \mathbf{q}_i\right)^2 + \lambda \left(\sum_{u=1}^M \|\mathbf{p}_u\|_2^2 + \sum_{i=1}^N \|\mathbf{q}_i\|_2^2\right)$$

When item vectors $Q \in \mathbb{R}^{N \times d}$ are held fixed, the exact closed-form ridge regression update for user $u$ with diagonal confidence matrix $C^u = \operatorname{diag}(c_{u1}, \dots, c_{uN})$ is:

$$\mathbf{p}_u = \left(Q^\top C^u Q + \lambda I_d\right)^{-1} Q^\top C^u \mathbf{p}_u^{\text{pref}}$$

Naively computing $Q^\top C^u Q$ takes $O(N d^2)$ per user—impossible when $N = 10^7$. The iALS Gram-Matrix Trick rewrites $Q^\top C^u Q$ by splitting $C^u = I_N + (C^u - I_N)$:

$$Q^\top C^u Q = \underbrace{Q^\top Q}_{\text{Precomputed once in } O(N d^2)} + \sum_{i \in \mathcal{R}_u} \underbrace{(c_{ui} - 1)\,\mathbf{q}_i \mathbf{q}_i^\top}_{\text{Only over } |\mathcal{R}_u| \text{ clicked items!}}$$

Because $c_{ui} - 1 = \alpha r_{ui} = 0$ for every unclicked item, each user update now costs only $O(d^2 |\mathcal{R}_u| + d^3)$—completely independent of catalog size $N$!

3. Bayesian Personalized Ranking (BPR)

Whereas iALS reconstructs point values $p_{ui} \in \{0, 1\}$, Bayesian Personalized Ranking (BPR) (Rendle et al., 2009) optimizes a pairwise ranking objective directly. For each user $u$, observed item $i^+ \in \mathcal{R}_u$, and sampled unobserved item $j^- \notin \mathcal{R}_u$, BPR maximizes the log-posterior probability that $u$ prefers $i^+$ over $j^-$:

$$\mathcal{L}_{\text{BPR}} = -\sum_{(u, i^+, j^-)} \ln \sigma\!\left(\hat{r}_{u i^+} - \hat{r}_{u j^-}\right) + \lambda \|\Theta\|_2^2 = \sum_{(u, i^+, j^-)} \ln\!\left(1 + e^{-(\mathbf{p}_u^\top \mathbf{q}_{i^+} - \mathbf{p}_u^\top \mathbf{q}_{j^-})}\right) + \lambda \|\Theta\|_2^2$$

Differentiating with respect to the score margin $\hat{r}_{u i^+ j^-} = \mathbf{p}_u^\top (\mathbf{q}_{i^+} - \mathbf{q}_{j^-})$ yields the clean SGD update weight $\Delta = 1 - \sigma(\hat{r}_{u i^+} - \hat{r}_{u j^-})$—equivalent to maximizing each user's personalized ROC-AUC.

4. Worked Numerical Example: 1-Step iALS vs. 1-Step BPR

Since only item $1$ is watched ($c_{u1} - 1 = 2 \times 2 = 4$), we add $4 \mathbf{q}_1 \mathbf{q}_1^\top = \begin{bmatrix} 4 & 0 \\ 0 & 0 \end{bmatrix}$ and $\lambda I_2 = \begin{bmatrix} 0.5 & 0 \\ 0 & 0.5 \end{bmatrix}$: $$A_u = Q^\top C^u Q + \lambda I = \begin{bmatrix} 6.14 & 0.48 \\ 0.48 & 1.86 \end{bmatrix}, \quad \mathbf{b}_u = c_{u1} \mathbf{q}_1 = \begin{bmatrix} 5.0 \\ 0.0 \end{bmatrix} \implies \mathbf{p}_u = A_u^{-1} \mathbf{b}_u \approx \begin{bmatrix} 0.831 \\ -0.215 \end{bmatrix}$$

5. Runnable Python Implementation: iALS (with Gram Trick) & BPR

import numpy as np

def ials_user_step(Q: np.ndarray, watched_idx: list[int], counts: list[float], alpha: float = 2.0, reg: float = 0.5) -> np.ndarray:
    """Solve p_u in O(d^2 |R_u| + d^3) using precomputed Gram matrix Q^T Q."""
    d = Q.shape[1]
    QtQ = Q.T @ Q  # Precomputed once across all users!
    A = QtQ + reg * np.eye(d)
    b = np.zeros(d)
    for idx, r_ui in zip(watched_idx, counts):
        q_i = Q[idx]
        c_ui = 1.0 + alpha * r_ui
        A += (c_ui - 1.0) * np.outer(q_i, q_i)
        b += c_ui * q_i
    return np.linalg.solve(A, b)

def bpr_sgd_step(p_u: np.ndarray, q_pos: np.ndarray, q_neg: np.ndarray, lr: float = 0.1, reg: float = 0.01):
    """Single BPR pairwise gradient ascent step on triplet (u, i+, j-)."""
    margin = float(p_u @ (q_pos - q_neg))
    err = 1.0 / (1.0 + np.exp(margin))  # 1 - sigma(margin)
    grad_pu = err * (q_pos - q_neg) - reg * p_u
    grad_qpos = err * p_u - reg * q_pos
    grad_qneg = -err * p_u - reg * q_neg
    return p_u + lr * grad_pu, q_pos + lr * grad_qpos, q_neg + lr * grad_qneg

if __name__ == "__main__":
    Q = np.array([[1.0, 0.0], [0.8, 0.6], [0.0, 1.0]])
    p_u = ials_user_step(Q, watched_idx=[0], counts=[2.0], alpha=2.0, reg=0.5)
    print("iALS user vector p_u:", np.round(p_u, 3))
    print("iALS item scores:    ", np.round(Q @ p_u, 3))
