    Inverted Indexes, Posting Lists & Skip-Pointer Intersection

    October 2026 · 6 min read

    Scanning $N = 10{,}000{,}000$ documents with grep on every user query takes seconds. Search engines answer in milliseconds by flipping the mapping upside down: instead of mapping each document to the words it contains (a forward index), an inverted index maps each unique word $t$ to a sorted list of document IDs where $t$ appears.

    1. Anatomy of an Inverted Index

    After tokenizing, lowercasing, and stemming documents, an inverted index stores two structures:

    1. Term Dictionary (Vocabulary): Every unique term $t$ alongside its document frequency $\text{df}_t$ (how many documents contain $t$) and a pointer to its posting list.
    2. Posting List: A list of postings sorted in strictly increasing order of document ID ($\text{doc}_1 < \text{doc}_2 < \dots < \text{doc}_{\text{df}_t}$). Each posting stores the document ID, the term frequency $\text{tf}_{t,d}$ (how many times $t$ appears in document $d$), and optional token positions for phrase queries like "machine learning".

    2. Two-Pointer Boolean Intersection & Query Optimization

    Because every posting list is sorted by document ID, we can intersect two lists of lengths $L_1$ and $L_2$ for a query like "neural" AND "search" in $O(L_1 + L_2)$ linear time using two pointers $p_1, p_2$:

    • If $\text{doc}(p_1) = \text{doc}(p_2)$, record a match and advance both pointers.
    • Otherwise, advance whichever pointer points to the smaller document ID.

    When intersecting three or more terms (e.g., "neural" AND "search" AND "index"), always sort the terms by increasing document frequency $\text{df}_t$ and intersect the shortest lists first. Intersecting $\text{df} = 50$ with $\text{df} = 100$ produces at most $50$ candidates to check against a long list of $\text{df} = 500{,}000$.

    3. Skip Pointers and Delta-Gap Compression

    When a rare term ($\text{df}_1 = 10$) is intersected with a very common term ($\text{df}_2 = 1{,}000{,}000$), stepping through the long list one element at a time is wasteful. Search engines add two classic optimizations:

    1. Skip Pointers: Placing a forward jump pointer every $\lfloor\sqrt{L}\rfloor$ postings lets the cursor jump over blocks of non-matching document IDs whenever $\text{doc}(\text{skip}(p)) \le \text{target docID}$, reducing intersection cost toward $O(L_1 \sqrt{L_2})$ (or $O(L_1 \log L_2)$ with multi-level skiplists).
    2. Delta-Gap Encoding: Instead of storing raw 32-bit integers $[1003, 1009, 1014, 1025]$, we store the positive gaps between consecutive document IDs:
      $$\Delta_1 = d_1, \qquad \Delta_i = d_i - d_{i-1} \quad\Longrightarrow\quad [1003, +6, +5, +11].$$
      Frequent words have tiny gaps ($\Delta_i \approx 1\text{–}5$), which compress into $1$ byte each using Variable-Byte (VarInt) or SIMD-BP128 bit-packing.

    4. Reference Python Implementation

    from typing import Dict, List

def intersect_two_postings(list_a: List[int], list_b: List[int]) -> List[int]:
    """Two-pointer O(L1 + L2) intersection of sorted posting lists."""
    i, j, result = 0, 0, []
    while i < len(list_a) and j < len(list_b):
        if list_a[i] == list_b[j]:
            result.append(list_a[i])
            i += 1
            j += 1
        elif list_a[i] < list_b[j]:
            i += 1
        else:
            j += 1
    return result

def boolean_and_query(index: Dict[str, List[int]], terms: List[str]) -> List[int]:
    """Intersects shortest posting lists first."""
    postings = sorted((index.get(t, []) for t in terms), key=len)
    if not postings or not postings[0]:
        return []
    result = postings[0]
    for plist in postings[1:]:
        result = intersect_two_postings(result, plist)
        if not result:
            break
    return result

def delta_encode(doc_ids: List[int]) -> List[int]:
    return [doc_ids[0]] + [doc_ids[i] - doc_ids[i - 1] for i in range(1, len(doc_ids))]

inv_index = {"neural": [1, 3, 7, 12], "search": [2, 3, 8, 12], "index": [3, 5, 12]}
print("neural AND search :", boolean_and_query(inv_index, ["neural", "search"]))
print("Delta gaps [3,9,14,25]:", delta_encode([3, 9, 14, 25]))
