    Disjoint Set Union (DSU): Handwritten Notes, Templates & 11-Part Problem Pattern Guide

    Whenever a problem maintains dynamic equivalence classes—merging groups online, testing whether two vertices already belong to the same connected component, detecting the exact edge that closes a cycle, or tracking component sizes in near-constant $\mathcal{O}(\alpha(N))$ time—Disjoint Set Union (DSU / Union-Find) replaces repeated $\mathcal{O}(V + E)$ DFS/BFS traversals with two compact array operations: findPar(u) and unite(u, v).

    Universal DSU Template Cheat Sheet

    In competitive programming, Union by Size is almost always preferred over Union by Rank because sz[findPar(u)] gives you the exact cardinality of any connected component at zero extra cost (used directly in LC 1020, LC 128, LC 952, LC 928, and LC 1319).

    struct DSU {
    vector<int> parent, sz;
    int components;

    explicit DSU(int n) : parent(n), sz(n, 1), components(n) {
        iota(parent.begin(), parent.end(), 0); // parent[i] = i
    }

    int findPar(int node) {
        if (node == parent[node]) return node;
        return parent[node] = findPar(parent[node]); // Path compression
    }

    bool unite(int u, int v) {
        int pu = findPar(u), pv = findPar(v);
        if (pu == pv) return false; // Already in same group (redundant / cycle!)
        if (sz[pu] < sz[pv]) swap(pu, pv);
        parent[pv] = pu;
        sz[pu] += sz[pv];
        --components;
        return true;
    }

    int compSize(int u) { return sz[findPar(u)]; }
};

    Four Rules Highlighted Across the 11 Handwritten Notes

    1. Always guard if (pu == pv) return false; first: Prevents corrupting sz[pu] += sz[pu], avoids double-decrementing component counts on grid corners (Note 02), and directly flags cycles (Note 05).
    2. Update metadata on roots (pu, pv), never raw inputs (u, v): Attaching or incrementing rank[u] or parent[u] instead of rank[pu] / parent[pu] silently breaks tree balance and loses subtrees (Notes 01, 02, 06).
    3. Prefer flat 0-indexed arrays over hash maps inside DSU: Flatten 2D grids via $i \cdot C + j$ (Notes 02, 03) and map sparse integers onto $0 \dots n - 1$ externally via dic[val] = i (Notes 08, 10).
    4. Custom root tie-breaking is safe when the domain is tiny: Over 26 letters (Note 06), setting parent[maxRoot] = minRoot drops rank[] on $\le 26$ nodes so findPar(c) returns the smallest equivalent character directly.
