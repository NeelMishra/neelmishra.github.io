    1. LC 200: Number of Islands — 1D Grid Flattening & 2-Direction Scan

    Given an $R \times C$ binary grid of '1' (land) and '0' (water), count the number of 4-directionally connected islands. While DFS/BFS flood-fill is standard, the handwritten notes highlight five engineering optimizations that make grid DSU remarkably fast and essential when land cells arrive online (as in LC 305: Number of Islands II):

    1. Flat arrays beat tuple hash maps: Storing parent[(i, j)] in a hash map incurs hashing/allocation overhead per lookup. Instead, map every 0-indexed cell $(i, j)$ in an $R \times C$ grid onto a unique integer in $[0, R \cdot C - 1]$:
      $$\text{id}(i, j) = i \cdot C + j \quad \text{where } C = \text{number of columns (row width)}$$
      (Note: In the handwritten sheet, the width multiplier is written as $m \times i + j$—just ensure the multiplier is always the column count $C$ so row $i$ advances by $C$ slots!)
    2. Natural raster scan needs only 2 directions, with no visited array: As we iterate $i = 0 \to R - 1$ (top to bottom) and $j = 0 \to C - 1$ (left to right), every undirected adjacency between two land cells is encountered once from the second cell looking back at its top neighbor $(i - 1, j)$ and left neighbor $(i, j - 1)$. Checking all 4 directions is redundant, and no visited matrix is required.
    3. Track live island count inside unite: Count total '1' cells initially (or increment islands++ as each '1' is seen), then decrement islands-- inside unite(u, v) only when pu != pv. That eliminates a second post-processing loop to count distinct roots.
    4. Always update rank/size on roots, and guard pu != pv: When a cell touches both a top land cell and a left land cell that are already connected around a corner, pu == pv prevents subtracting islands twice.
    // LC 200: Number of Islands — Flat 1D DSU + Top/Left 2-Direction Scan
class Solution {
public:
    int numIslands(vector<vector<char>>& grid) {
        int R = grid.size(), C = grid[0].size();
        vector<int> parent(R * C), rnk(R * C, 0);
        iota(parent.begin(), parent.end(), 0);

        auto findPar = [&](auto& self, int x) -> int {
            return parent[x] == x ? x : parent[x] = self(self, parent[x]);
        };

        int islands = 0;
        auto unite = [&](int u, int v) {
            int pu = findPar(findPar, u), pv = findPar(findPar, v);
            if (pu == pv) return; // Crucial: avoid duplicate decrements!
            if (rnk[pu] < rnk[pv]) swap(pu, pv);
            parent[pv] = pu;
            if (rnk[pu] == rnk[pv]) rnk[pu]++;
            --islands;
        };

        for (int i = 0; i < R; ++i) {
            for (int j = 0; j < C; ++j) {
                if (grid[i][j] != '1') continue;
                ++islands;
                int cur = i * C + j;
                if (i > 0 && grid[i - 1][j] == '1') unite(cur, (i - 1) * C + j); // Top
                if (j > 0 && grid[i][j - 1] == '1') unite(cur, i * C + (j - 1)); // Left
            }
        }
        return islands;
    }
};

    2. LC 1020: Number of Enclaves — Virtual Boundary Dummy Node

    Given an $R \times C$ binary matrix where 1 represents land and 0 sea, return the number of land cells from which we cannot walk off the boundary of the grid in any number of 4-directional moves.

    The Border-Union Idea & Subtle Cell-vs-Component Pitfall

    Only a land component containing at least one cell on the outer border ($i \in \{0, R - 1\}$ or $j \in \{0, C - 1\}$) can escape the grid. Introducing a single virtual boundary node BORDER = R * C makes DSU exceptionally clean:

    • Whenever $(i, j)$ is a land cell on the border, call unite(id(i, j), BORDER).
    • For every land cell $(i, j)$, union it with its top and left land neighbors just like LC 200.
    • Finally, scan interior cells ($1 \le i \le R - 2$, $1 \le j \le C - 2$): any land cell with findPar(id(i, j)) != findPar(BORDER) is trapped inside an enclave!

    Watch Out: Counting Enclave Cells vs. Enclave Components

    On Page 2 of the handwritten note, the snippet checks if parent[(i, j)] == (i, j) and grid[i][j] == 1: counter += 1 # component detected. Notice two subtleties:

    1. Checking findPar(x) == x counts 1 per connected component (which solves LC 1254: Number of Closed Islands if non-boundary roots are counted), whereas LC 1020 asks for the total number of land cells inside enclaves (so a 3-cell island contributes $+3$, not $+1$).
    2. Always call findPar(x) rather than reading raw parent[x] directly, because path compression happens lazily—a node two hops below BORDER only updates parent[x] after findPar(x) runs!
    // LC 1020: Number of Enclaves — Virtual BORDER Dummy Node DSU
class Solution {
public:
    int numEnclaves(vector<vector<int>>& grid) {
        int R = grid.size(), C = grid[0].size();
        int BORDER = R * C;
        vector<int> parent(R * C + 1), sz(R * C + 1, 1);
        iota(parent.begin(), parent.end(), 0);

        auto findPar = [&](auto& self, int x) -> int {
            return parent[x] == x ? x : parent[x] = self(self, parent[x]);
        };
        auto unite = [&](int u, int v) {
            int pu = findPar(findPar, u), pv = findPar(findPar, v);
            if (pu == pv) return;
            if (sz[pu] < sz[pv]) swap(pu, pv);
            parent[pv] = pu;
            sz[pu] += sz[pv];
        };

        for (int i = 0; i < R; ++i) {
            for (int j = 0; j < C; ++j) {
                if (grid[i][j] == 0) continue;
                int cur = i * C + j;
                if (i == 0 || i == R - 1 || j == 0 || j == C - 1)
                    unite(cur, BORDER);
                if (i > 0 && grid[i - 1][j] == 1) unite(cur, (i - 1) * C + j);
                if (j > 0 && grid[i][j - 1] == 1) unite(cur, i * C + (j - 1));
            }
        }

        int enclaves = 0, borderRoot = findPar(findPar, BORDER);
        for (int i = 1; i < R - 1; ++i)
            for (int j = 1; j < C - 1; ++j)
                if (grid[i][j] == 1 && findPar(findPar, i * C + j) != borderRoot)
                    ++enclaves;
        return enclaves;
    }
};

    3. LC 684: Redundant Connection — Streaming Cycle Detection

    A tree on $n$ vertices ($1 \dots n$) has $n - 1$ edges and no cycles. When one extra undirected edge is added ($n$ nodes, $n$ edges total), the graph contains exactly one simple cycle. We must return the cycle edge that appears last in the input array edges.

    Why the First Same-Root Edge Is Automatically the Last Cycle Edge

    Process edges $[n_1, n_2]$ sequentially from left to right:

    • Every edge before the cycle closes joins two hitherto disconnected subtrees ($\text{findPar}(n_1) \ne \text{findPar}(n_2)$), maintaining an acyclic spanning forest.
    • For the unique cycle $C$, its first $|C| - 1$ edges in input order merely connect vertices along a path $n_1 - \dots - p - \dots - n_2$ under a shared root $p$.
    • At the exact moment the final edge $[n_1, n_2]$ of $C$ arrives, $\text{findPar}(n_1) == \text{findPar}(n_2) == p$ holds for the very first time! Returning that edge immediately guarantees both cycle removal and last-in-input tie-breaking in $\mathcal{O}(n \cdot \alpha(n))$ time.
    // LC 684: Redundant Connection — O(n * alpha(n)) Time, O(n) Space
class Solution {
public:
    vector<int> findRedundantConnection(vector<vector<int>>& edges) {
        int n = edges.size();
        vector<int> parent(n + 1), rnk(n + 1, 0);
        iota(parent.begin(), parent.end(), 0);

        auto findPar = [&](auto& self, int x) -> int {
            return parent[x] == x ? x : parent[x] = self(self, parent[x]);
        };

        for (const auto& e : edges) {
            int p1 = findPar(findPar, e[0]);
            int p2 = findPar(findPar, e[1]);
            if (p1 == p2) return e; // Path n1 - p - n2 already exists -> cycle closed!
            if (rnk[p1] < rnk[p2]) swap(p1, p2);
            parent[p2] = p1;
            if (rnk[p1] == rnk[p2]) rnk[p1]++;
        }
        return {};
    }
};

    4. LC 1319: Number of Operations to Make Network Connected

    Given $n$ computers ($0 \dots n - 1$) and an array connections of existing cables, in one operation you may unplug any cable between two connected computers and rewire it between any pair of disconnected computers. Return the minimum operations to connect all $n$ computers, or -1 if impossible.

    The Necessary & Sufficient Cable Invariant

    1. Feasibility check: Any connected graph on $n$ vertices requires at least a spanning tree of $n - 1$ edges. If connections.size() < n - 1, connecting the network is impossible $\implies$ return -1.
    2. Component merge count: Suppose after unioning all existing cables, the $n$ computers split into $C$ connected components (including isolated singleton computers of size $1$, which the handwritten Python note tracks explicitly!). Connecting $C$ components into $1$ component requires at least $C - 1$ cables.
    3. Do we always have $\ge C - 1$ spare cables? Yes! Inside component $k$ of $V_k$ vertices, a spanning tree uses $V_k - 1$ edges, so all remaining edges are redundant cycle edges (parent1 == parent2 in union). Summing across all $C$ components:
      $$\text{Spare Cables} = |E| - \sum_{k=1}^{C} (V_k - 1) = |E| - (n - C) \ge (n - 1) - (n - C) = C - 1$$
      Hence whenever $|E| \ge n - 1$, the answer is exact: $C - 1$!
    // LC 1319: Number of Operations to Make Network Connected (C++)
class Solution {
public:
    int makeConnected(int n, vector<vector<int>>& connections) {
        if ((int)connections.size() < n - 1) return -1;

        vector<int> parent(n), sz(n, 1);
        iota(parent.begin(), parent.end(), 0);
        int components = n;

        auto findPar = [&](auto& self, int x) -> int {
            return parent[x] == x ? x : parent[x] = self(self, parent[x]);
        };

        for (const auto& c : connections) {
            int p1 = findPar(findPar, c[0]), p2 = findPar(findPar, c[1]);
            if (p1 != p2) {
                if (sz[p1] < sz[p2]) swap(p1, p2);
                parent[p2] = p1;
                sz[p1] += sz[p2];
                --components;
            }
        }
        return components - 1;
    }
};

    Below is the cleaned-up Python version faithful to 11_1319 in the notes (which also tracks per-component size and edges):

    class DSU:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.size = [1] * n
        self.edges = [0] * n  # Number of cables inside root's component

    def find_parent(self, node: int) -> int:
        if node != self.parent[node]:
            self.parent[node] = self.find_parent(self.parent[node])
        return self.parent[node]

    def union(self, u: int, v: int) -> None:
        p1, p2 = self.find_parent(u), self.find_parent(v)
        if p1 != p2:
            if self.size[p1] < self.size[p2]:
                p1, p2 = p2, p1
            self.parent[p2] = p1
            self.size[p1] += self.size[p2]
            self.edges[p1] += self.edges[p2] + 1
        else:
            self.edges[p1] += 1  # Redundant cable inside existing component


class Solution:
    def makeConnected(self, n: int, connections: list[list[int]]) -> int:
        if len(connections) < n - 1:
            return -1
        dsu = DSU(n)
        for u, v in connections:
            dsu.union(u, v)
        roots = {dsu.find_parent(node) for node in range(n)}
        return len(roots) - 1
