    Topological Sort on DAGs: DFS Post-Order Stack vs. Kahn's BFS

    October 2026 · 6 min read · 2-Part Series (6 Handwritten Pages)

    Expanded from handwritten competitive coding study notes (01_DFS_topological_sort_STRIVER.pdf & 02_BFS_KAHN_s_algorithm.pdf)

    A topological sort of a Directed Acyclic Graph (DAG) $G = (V, E)$ is a linear permutation of all vertices such that for every directed edge $u \to v$, vertex $u$ appears strictly before vertex $v$. Whenever a problem models prerequisite courses, build targets, alien dictionary letter constraints, or DP transitions over a DAG, topological sorting turns a graph dependency network into a clean left-to-right array.

    Master Comparison: DFS Post-Order Stack vs. Kahn's BFS

    Head-to-head comparison of the two linear-time topological sort paradigms.
    Dimension DFS Post-Order Stack (Part 1) Kahn's BFS Indegree (Part 2)
    Core Invariant Push $u$ onto stack after all descendants finish; reverse finish times obey $u \prec v$. Repeatedly peel vertices whose current indegree == 0 and decrement outgoing neighbors.
    Auxiliary Structures visited[V] + recursion call stack + result stack indegree[V] + FIFO queue + output array
    Time & Space Time $\mathcal{O}(V + E)$, Space $\mathcal{O}(V)$ Time $\mathcal{O}(V + E)$, Space $\mathcal{O}(V)$
    Cycle Handling Plain visited[] silently returns garbage on cyclic graphs! Needs extra pathVis[] to detect cycles. Built-in cycle detection: if topo.size() < V, a directed cycle exists!
    Contest Superpowers Natural fit for subtree/post-order DAG DP where $dp[u]$ pulls from $dp[v]$. Swap queue for a min-heap to get the lexicographically smallest topo sort; level-by-level waves count minimum parallel semesters (LC 1136)!
