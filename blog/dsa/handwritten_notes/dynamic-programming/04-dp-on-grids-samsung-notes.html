    DP on Grids (Samsung Notes): Unique Paths, Obstacles, Min/Max Path Sum, Triangle & Two Start Points

    October 2026 · 13 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 04_DP_on_grid_samsung_notes.pdf

    When we move from a 1D array to an $m \times n$ matrix, a single index can no longer pinpoint our position—every DP state naturally becomes a coordinate pair $(i, j)$ (or a synchronized triple $(i, j_1, j_2)$ for two simultaneous walkers). This Samsung R&D interview study notebook maps out the entire six-problem taxonomy of 2D Grid Dynamic Programming and proves visually why nearly every $O(m \cdot n)$ grid table collapses into a single $O(n)$ row.

    1. The Six-Problem Grid DP Taxonomy (Page 1)

    # Grid Pattern Start $\to$ Destination Core Transition Time / Best Space
    1 Count Unique Paths (LC 62) Fixed $(0,0) \to (m-1,n-1)$ $dp[i-1][j] + dp[i][j-1]$ $O(mn)$ / $O(n)$
    2 Paths with Obstacles (LC 63) Fixed $(0,0) \to (m-1,n-1)$ $0$ if blocked, else $\text{up} + \text{left}$ $O(mn)$ / $O(n)$
    3 Minimum Path Sum (LC 64) Fixed $(0,0) \to (m-1,n-1)$ $g[i][j] + \min(\text{up}, \text{left})$; OOB $= 10^9$ $O(mn)$ / $O(n)$
    4 Max Falling Path Sum (LC 931) Any $(0, j_1) \to$ any $(m-1, j_2)$ $g[i][j] + \max(\text{upLeft}, \text{up}, \text{upRight})$ $O(mn)$ / $O(n)$
    5 Triangle Min Path (LC 120) Fixed $(0,0) \to$ any $(n-1, j)$ $T[i][j] + \min(\text{down}, \text{diag})$ $O(n^2)$ / $O(n)$
    6 Two Start Points (LC 1463) $(0,0) \text{ & } (0,n-1) \to$ row $m-1$ $3 \times 3 = 9$ joint moves on $(i, j_1, j_2)$ $O(mn^2)$ / $O(n^2)$

    2. Count Unique Paths & $O(n)$ Row-Rolling Space Optimization

    To count paths from $(0, 0)$ to $B = (m-1, n-1)$ moving only down or right, page 1 notes two equivalent symmetries:

    • Forward from $(0, 0)$: $f(i, j) = f(i + 1, j) + f(i, j + 1)$
    • Backward from $(m-1, n-1)$ to $(0, 0)$: $f(i, j) = f(i - 1, j) + f(i, j - 1)$ with $f(0, 0) = 1$ and $f(i < 0 \text{ or } j < 0) = 0$.

    Complexity transition (p.1): Plain recursion branches two ways at each step, taking $O(2^{m+n})$ time (loosely bounded by $2^{m \times n}$ in the notebook) with recursion stack equal to the path length $(m - 1) + (n - 1) = O(m + n)$. Memoizing all $m \times n$ distinct coordinate pairs immediately reduces time to $\Theta(m \cdot n)$!

    Pattern 2: Count Paths with Obstacles (Page 3)

    When blocked cells (grid[i][j] == 1) appear, add one priority check before anything else—even before (i == 0 && j == 0) in case the start cell itself is blocked: if (grid[i][j] == 1) temp[j] = 0;.

    #include <bits/stdc++.h>
using namespace std;

// Covers both Unique Paths (all 0s) and Unique Paths II (1 = obstacle) in O(mn) time, O(n) space
int uniquePathsWithObstacles(const vector<vector<int>>& grid) {
    int m = (int)grid.size(), n = (int)grid[0].size();
    vector<long long> prev(n, 0);

    for (int i = 0; i < m; ++i) {
        vector<long long> temp(n, 0);
        for (int j = 0; j < n; ++j) {
            if (grid[i][j] == 1) {
                temp[j] = 0; // Blocked cell contributes 0 paths
            } else if (i == 0 && j == 0) {
                temp[j] = 1;
            } else {
                long long up   = (i > 0) ? prev[j] : 0;
                long long left = (j > 0) ? temp[j - 1] : 0;
                temp[j] = up + left;
            }
        }
        prev = move(temp);
    }
    return (int)prev[n - 1];
}

    3. Minimum & Maximum Path Sum: The $+10^9$ Pruning Rule (Page 4)

    Given non-negative cell costs $\text{grid}[i][j]$, find the minimum path sum from $(0, 0)$ to $(m-1, n-1)$. Page 4 traces all three trajectories on $\begin{bmatrix} 5 & 9 & 2 \\ 11 & 5 & 2 \end{bmatrix}$:

    • $5 \to 9 \to 2 \to 2 = \mathbf{18}$ (optimal!)
    • $5 \to 9 \to 5 \to 2 = 21$
    • $5 \to 11 \to 5 \to 2 = 23$

    Why Out-of-Bounds Must Return $10^9$ (Never $0$, Never INT_MAX!)

    In forward recursion $f(i, j) = \text{grid}[i][j] + \min\bigl(f(i+1, j),\; f(i, j+1)\bigr)$ with destination base case if (i == m - 1 && j == n - 1) return grid[m - 1][n - 1];:

    • Returning 0 when $i > m - 1$ or $j > n - 1$ makes stepping off the grid look free ($0 < \text{positive cells}$), corrupting every border minimum!
    • Returning INT_MAX overflows signed 32-bit int into a negative number as soon as grid[i][j] + INT_MAX is evaluated!
    • As starred on page 4: set invalid min-problem branches to $10^9$ (and invalid max-problem branches, such as Max Falling Path Sum, to $-10^9$) so $\min$ / $\max$ automatically prunes them!
    int minPathSum(const vector<vector<int>>& grid) {
    int m = (int)grid.size(), n = (int)grid[0].size();
    const int INF = 1e9;
    vector<int> prev(n, INF);

    for (int i = 0; i < m; ++i) {
        vector<int> temp(n, INF);
        for (int j = 0; j < n; ++j) {
            if (i == 0 && j == 0) {
                temp[j] = grid[0][0];
            } else {
                int up   = (i > 0) ? prev[j] : INF;
                int left = (j > 0) ? temp[j - 1] : INF;
                temp[j] = grid[i][j] + min(up, left);
            }
        }
        prev = move(temp);
    }
    return prev[n - 1];
}

    4. Variable Endpoints: Triangle DP & Two Start Points

    4.1 Triangle Minimum Path Sum (Page 5, LeetCode 120)

    In a lower-triangular array $T$ where row $i$ has $i + 1$ elements, we start at fixed apex $(0, 0)$ and can finish at any column $j$ on row $n - 1$, stepping either straight down $(i + 1, j)$ or diagonally $(i + 1, j + 1)$:

    $$f(i, j) = T[i][j] + \min\bigl(f(i + 1, j),\; f(i + 1, j + 1)\bigr), \qquad f(n - 1, j) = T[n - 1][j]$$

    Handwritten Triangle Trace ([[2], [3,4], [6,5,7], [4,1,8,3]])

    Seed front = [4, 1, 8, 3] (row $3$) and sweep $i = 2 \downarrow 0$:

    • $i = 2$: $[6 + \min(4,1),\; 5 + \min(1,8),\; 7 + \min(8,3)] = [7, 6, 10]$
    • $i = 1$: $[3 + \min(7,6),\; 4 + \min(6,10)] = [9, 10]$
    • $i = 0$: $[2 + \min(9,10)] = [\mathbf{11}]$ (optimal path $2 \to 3 \to 5 \to 1$).

    4.2 Two Start Points / 3D Grid DP (Cherry Pickup II, LeetCode 1463)

    What about item 6 on page 1's list—2 Start Points? Two robots start at $(0, 0)$ and $(0, n-1)$ and move down simultaneously one row per step into $(i+1, j_1 + d_1)$ and $(i+1, j_2 + d_2)$ where $d_1, d_2 \in \{-1, 0, +1\}$. Because both share the exact same row $i$ at every step, we do not need 4D state $(i_1, j_1, i_2, j_2)$—only 3D state $dp[i][j_1][j_2]$ (compressible to $O(n^2)$), avoiding double-counting when $j_1 == j_2$!

    // Triangle DP: O(n^2) time, O(n) space
int minimumTotalTriangle(const vector<vector<int>>& T) {
    int n = (int)T.size();
    vector<int> front = T[n - 1];
    for (int i = n - 2; i >= 0; --i)
        for (int j = 0; j <= i; ++j)
            front[j] = T[i][j] + min(front[j], front[j + 1]);
    return front[0];
}

// Two Start Points (Cherry Pickup II): O(9 * m * n^2) time, O(n^2) space
int cherryPickupTwoStarts(const vector<vector<int>>& grid) {
    int m = (int)grid.size(), n = (int)grid[0].size();
    const int NEG_INF = -1e9;
    vector<vector<int>> front(n, vector<int>(n, 0));

    for (int j1 = 0; j1 < n; ++j1)
        for (int j2 = 0; j2 < n; ++j2)
            front[j1][j2] = (j1 == j2) ? grid[m - 1][j1] : (grid[m - 1][j1] + grid[m - 1][j2]);

    for (int i = m - 2; i >= 0; --i) {
        vector<vector<int>> cur(n, vector<int>(n, NEG_INF));
        for (int j1 = 0; j1 < n; ++j1) {
            for (int j2 = 0; j2 < n; ++j2) {
                int gain = (j1 == j2) ? grid[i][j1] : (grid[i][j1] + grid[i][j2]);
                int best = NEG_INF;
                for (int d1 = -1; d1 <= 1; ++d1) {
                    for (int d2 = -1; d2 <= 1; ++d2) {
                        int nj1 = j1 + d1, nj2 = j2 + d2;
                        if (nj1 >= 0 && nj1 < n && nj2 >= 0 && nj2 < n)
                            best = max(best, gain + front[nj1][nj2]);
                    }
                }
                cur[j1][j2] = best;
            }
        }
        front = move(cur);
    }
    return front[0][n - 1];
}
