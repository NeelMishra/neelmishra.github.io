    DP on Strings (Part 1): Longest Common Subsequence, $+1$ Index Shifting & Printing LCS

    October 2026 · 12 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 02_DP_String_notes_1.pdf

    A single index cannot track independent progress across two strings $\text{str}_1$ (length $m$) and $\text{str}_2$ (length $n$). As noted on page 1 of 02_DP_String_notes_1.pdf, we need two indices $(\text{idx}_1, \text{idx}_2)$—and once we pair that dual-prefix state with $+1$ index shifting, Longest Common Subsequence (LeetCode 1143) becomes the master blueprint for an entire family of string DP problems.

    1. Formulating Longest Common Subsequence (Page 1)

    Given $\text{str}_1 = \texttt{"acd"}$ and $\text{str}_2 = \texttt{"ced"}$, their subsequences share $\texttt{"cd"}$ of maximum length $2$ (whereas brute-forcing all $2^m$ and $2^n$ subsequences takes exponential time). Define $f(i, j)$ as the LCS length of 0-based prefixes $\text{str}_1[0 \dots i]$ and $\text{str}_2[0 \dots j]$:

    • Match ($\text{str}_1[i] == \text{str}_2[j]$): Both characters pair up in a valid common subsequence of length at least $1$, shrinking both prefixes simultaneously: $$f(i, j) = 1 + f(i - 1, j - 1)$$
    • Mismatch ($\text{str}_1[i] \ne \text{str}_2[j]$): They cannot both be the final matched character together. Try moving the first index back or the second index back and take whichever yields more: $$f(i, j) = \max\bigl(f(i - 1, j),\; f(i, j - 1)\bigr)$$
    • Base Case: Whenever either prefix becomes empty ($i < 0$ or $j < 0$), return $0$.

    2. The $+1$ Index-Shifting Trick for Clean Tabulation (Pages 1–2)

    Why Shift Indices Right by $+1$?

    In 0-based recursion, the base case triggers at $i = -1$ or $j = -1$, which cannot index dp[-1][j] in C++ without out-of-bounds undefined behavior! Instead of littering every transition with if (i > 0) checks, shift every coordinate right by $+1$:

    $$-1 \mapsto 0, \qquad 0 \mapsto 1, \qquad 1 \mapsto 2, \qquad \dots, \qquad m - 1 \mapsto m$$

    Now $dp[i][j]$ represents the LCS of the first $i$ characters of $\text{text}_1$ and first $j$ characters of $\text{text}_2$ (comparing text1[i - 1] == text2[j - 1]), and the base cases sit cleanly along row $0$ ($dp[0][j] = 0$) and column $0$ ($dp[i][0] = 0$)!

    Full $(m+1) \times (n+1)$ Table & Backtracking Trace on $\texttt{"acd"}$ vs. $\texttt{"ced"}$

    $i \backslash j$$0$ ($\varepsilon$)$1$ (c)$2$ (e)$3$ (d)
    $0$ ($\varepsilon$)$0$$0$$0$$0$
    $1$ (a)$0$$0$$0$$0$
    $2$ (c)$0$$\mathbf{1}$ ↖$1$ ←$1$ ←
    $3$ (d)$0$$1$ ↑$1$$\mathbf{2}$ ↖

    Printing the LCS from $(3, 3)$: At $(3, 3)$, 'd' == 'd' $\implies$ append 'd', step diagonally to $(2, 2)$. At $(2, 2)$, 'c' != 'e' and $dp[2][1] = 1 \ge dp[1][2] = 0$ $\implies$ step left to $(2, 1)$. At $(2, 1)$, 'c' == 'c' $\implies$ append 'c', step diagonally to $(1, 0)$ ($j = 0$, stop). Reversing "dc" prints "cd"!

    3. Complete C++ Implementations (Length, Printing & $O(n)$ Space)

    #include <bits/stdc++.h>
using namespace std;

// 1. LeetCode 1143 2D Tabulation (with +1 index shift from 02_DP_String_notes_1.pdf p.2)
int longestCommonSubsequence(const string& text1, const string& text2) {
    int m = (int)text1.size(), n = (int)text2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (text1[i - 1] == text2[j - 1])
                dp[i][j] = 1 + dp[i - 1][j - 1];
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[m][n];
}

// 2. Tabulation + Backtracking to Print One Actual LCS — O(mn) time, O(mn) space
string printLCS(const string& s1, const string& s2) {
    int m = (int)s1.size(), n = (int)s2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (s1[i - 1] == s2[j - 1])
                dp[i][j] = 1 + dp[i - 1][j - 1];
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }

    string lcs;
    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (s1[i - 1] == s2[j - 1]) {
            lcs.push_back(s1[i - 1]); // Matched character belongs to LCS!
            --i; --j;
        } else if (dp[i - 1][j] > dp[i][j - 1]) {
            --i;
        } else {
            --j;
        }
    }
    reverse(lcs.begin(), lcs.end());
    return lcs;
}

// 3. Space-Optimized LCS Length Only — O(mn) time, O(min(m, n)) space
int lcsLengthSpaceOpt(const string& text1, const string& text2) {
    if (text1.size() < text2.size()) return lcsLengthSpaceOpt(text2, text1);
    int m = (int)text1.size(), n = (int)text2.size();
    vector<int> prev(n + 1, 0), cur(n + 1, 0);

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (text1[i - 1] == text2[j - 1])
                cur[j] = 1 + prev[j - 1];
            else
                cur[j] = max(prev[j], cur[j - 1]);
        }
        swap(prev, cur);
    }
    return prev[n];
}

    4. Four Direct String Variations Sketched in Pages 2–6

    Pages 2–6 of 02_DP_String_notes_1.pdf immediately adapt the LCS $(m+1) \times (n+1)$ table to four downstream problems (each also explored in dedicated posts in this series):

    1. Max Length of Repeated Subarray (#718, p.2–3): On $\text{nums}_1 = [1, 2, 3, 2, 1]$ and $\text{nums}_2 = [3, 2, 1, 4, 7]$, subarray contiguity breaks on mismatch, so else dp[i][j] = 0;! Notice the crucial complexity note at the top of page 3: calling memoized dp(i, j) across all $(i, j)$ pairs to find $\max_{i,j} dp(i, j)$ takes $O(n^2)$ total work (NOT $O(n^4)$!) because every memoized state still computes at most once! (Full deep dive in DP-27: Longest Common Substring.)
    2. Longest Palindromic Substring (#5, p.3–4): Tested on $s = \texttt{"babad"}$ using an upper-triangular boolean table dp[i][j] = true when s[i] == s[j] and (j - i == 1 || dp[i + 1][j - 1]). (Full deep dive in Longest Palindromic Substring.)
    3. Minimum Insertion Steps to Make a String Palindrome (#1312, p.4–5): Keep $\text{LPS}(s) = \text{LCS}(s, \text{reverse}(s))$ intact and mirror-insert the remaining characters in $\Theta(m^2)$ time: $$\text{Min Insertions} = m - \text{LCS}\bigl(s,\; \text{reverse}(s)\bigr)$$ (Full deep dive in DP-28: Longest Palindromic Subsequence.)
    4. Shortest Common Supersequence (#1092, p.5–6) & Edit Distance (#72, p.6): Merging $\texttt{"abac"}$ and $\texttt{"cab"}$ along LCS $\texttt{"ab"}$ yields $\texttt{"cabac"}$, and transforming $\texttt{"horse"} \to \texttt{"ros"}$ replaces $0$-mismatch with $1 + \min(\text{replace}, \text{delete}, \text{insert})$. (Expanded alongside Wildcard Matching in DP on Strings Part 2.)
    // LeetCode 1312: Minimum Insertion Steps to Make a String Palindrome (02_DP_String_notes_1.pdf p.4-5)
int minInsertions(const string& s) {
    int m = (int)s.size();
    string s1 = s;
    string s2(s.rbegin(), s.rend());
    if (s1 == s2) return 0;

    vector<vector<int>> dp(m + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (s1[i - 1] == s2[j - 1])
                dp[i][j] = 1 + dp[i - 1][j - 1];
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return m - dp[m][m];
}

    5. Complexity Proof & Key Edge Cases

    • Time Complexity: $(m \times n)$ cells $\times\; O(1)$ transition per cell $= \Theta(m \cdot n)$ (backtracking to print LCS walks at most $m + n$ steps).
    • Space Complexity: $\Theta(m \cdot n)$ if printing the LCS string is required; $\Theta(\min(m, n))$ if only the LCS length is needed.
    • Printing All Distinct LCS Strings: Notice that when $dp[i-1][j] == dp[i][j-1]$ on a mismatch, our while loop picks one tie-break (--j) to print a single LCS in $O(m + n)$. Printing all distinct LCS strings requires memoized DFS over ties when dp[i-1][j] == dp[i][j-1].
