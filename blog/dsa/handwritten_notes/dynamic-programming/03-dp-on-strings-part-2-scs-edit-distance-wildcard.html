    DP on Strings (Part 2): Shortest Common Supersequence, Edit Distance, Distinct Subsequences & Wildcard Matching

    October 2026 · 14 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 03_DP_String_notes_2.pdf

    Once dual-prefix alignment $(i, j)$ and $+1$ index shifting feel second nature from DP on Strings Part 1, five richer string transformations unlock rapidly—moving from LCS-derived merges and deletions into Levenshtein edits, subsequence counting, and wildcard pattern matching with arbitrary-length '*' stars.

    1. Two-String Deletions (#583) & Shortest Common Supersequence (#1092)

    1.1 Delete Operation for Two Strings (Page 3, LeetCode 583)

    To make $\text{word}_1$ (length $m$) and $\text{word}_2$ (length $n$) identical using the minimum number of character deletions, both strings must shrink to their Longest Common Subsequence:

    $$\text{Min Deletions} = \underbrace{\bigl(m - \text{LCS}(w_1, w_2)\bigr)}_{\text{delete from } w_1} + \underbrace{\bigl(n - \text{LCS}(w_1, w_2)\bigr)}_{\text{delete from } w_2} = m + n - 2 \cdot \text{LCS}(w_1, w_2)$$

    (Notice this exact same formula solves Striver DP-30: Minimum Insertions and Deletions to Convert $s_1 \to s_2$—delete $m - \text{LCS}$ unmatched characters from $s_1$ and insert $n - \text{LCS}$ characters from $s_2$!)

    1.2 Constructing the Shortest Common Supersequence (LeetCode 1092)

    Conversely, to build the shortest string containing both $s_1$ and $s_2$ as subsequences, include every non-LCS character from $s_1$ and $s_2$, and include their shared $\text{LCS}(s_1, s_2)$ only once instead of twice:

    $$|\text{SCS}(s_1, s_2)| = m + n - \text{LCS}(s_1, s_2)$$

    For $s_1 = \texttt{"abac"}$ and $s_2 = \texttt{"cab"}$, $\text{LCS} = \texttt{"ab"}$ has length $2$, so $|\text{SCS}| = 4 + 3 - 2 = 5$ ($\texttt{"cabac"}$). Backtrack from $(m, n)$ through the LCS table: emit matched characters once on diagonal steps, emit the skipped character whenever you step up (--i) or left (--j), flush whichever non-empty prefix remains (while i > 0 / while j > 0), and reverse!

    // LeetCode 583: Delete Operation for Two Strings — O(m*n) time, O(n) space
int minDeleteTwoStrings(const string& word1, const string& word2) {
    int m = (int)word1.size(), n = (int)word2.size();
    vector<int> prev(n + 1, 0), cur(n + 1, 0);
    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (word1[i - 1] == word2[j - 1])
                cur[j] = 1 + prev[j - 1];
            else
                cur[j] = max(prev[j], cur[j - 1]);
        }
        swap(prev, cur);
    }
    return m + n - 2 * prev[n];
}

// LeetCode 1092: Shortest Common Supersequence — O(m*n) time & space
string shortestCommonSupersequence(const string& s1, const string& s2) {
    int m = (int)s1.size(), n = (int)s2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (int i = 1; i <= m; ++i)
        for (int j = 1; j <= n; ++j)
            dp[i][j] = (s1[i - 1] == s2[j - 1])
                       ? (1 + dp[i - 1][j - 1])
                       : max(dp[i - 1][j], dp[i][j - 1]);

    string ans;
    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (s1[i - 1] == s2[j - 1]) {
            ans.push_back(s1[i - 1]); // Shared LCS char emitted ONCE
            --i; --j;
        } else if (dp[i - 1][j] > dp[i][j - 1]) {
            ans.push_back(s1[i - 1]); // Emit s1[i-1] before stepping up
            --i;
        } else {
            ans.push_back(s2[j - 1]); // Emit s2[j-1] before stepping left
            --j;
        }
    }
    while (i > 0) ans.push_back(s1[--i]); // Flush remaining prefix!
    while (j > 0) ans.push_back(s2[--j]);
    reverse(ans.begin(), ans.end());
    return ans;
}

    2. Edit Distance / Levenshtein Distance (LeetCode 72)

    Convert $\text{word}_1$ into $\text{word}_2$ (e.g., $\texttt{"horse"} \to \texttt{"ros"}$ in $3$ steps: $\texttt{horse} \xrightarrow{h\to r} \texttt{rorse} \xrightarrow{-\text{r}} \texttt{rose} \xrightarrow{-\text{e}} \texttt{ros}$) using minimum single-character insert, delete, or replace operations:

    • Non-Zero Base Cases: Converting $w_1[0..i-1]$ into an empty string costs $dp[i][0] = i$ deletions; converting an empty string into $w_2[0..j-1]$ costs $dp[0][j] = j$ insertions!
    • Transitions: $$dp[i][j] = \begin{cases} dp[i - 1][j - 1] & \text{if } w_1[i - 1] == w_2[j - 1] \text{ (0 ops)} \\ 1 + \min\bigl(\underbrace{dp[i - 1][j - 1]}_{\text{replace}},\; \underbrace{dp[i - 1][j]}_{\text{delete } w_1[i-1]},\; \underbrace{dp[i][j - 1]}_{\text{insert } w_2[j-1]}\bigr) & \text{otherwise} \end{cases}$$
    // Space-Optimized Edit Distance — O(m*n) time, O(n) space
int minDistance(const string& w1, const string& w2) {
    int m = (int)w1.size(), n = (int)w2.size();
    vector<int> prev(n + 1), cur(n + 1);
    iota(prev.begin(), prev.end(), 0); // dp[0][j] = j insertions

    for (int i = 1; i <= m; ++i) {
        cur[0] = i;                    // dp[i][0] = i deletions!
        for (int j = 1; j <= n; ++j) {
            if (w1[i - 1] == w2[j - 1])
                cur[j] = prev[j - 1];
            else
                cur[j] = 1 + min({prev[j - 1], prev[j], cur[j - 1]});
        }
        swap(prev, cur);
    }
    return prev[n];
}

    3. Distinct Subsequences / String Matching (Pages 3–4, LeetCode 115)

    Given source string $s$ and target string $t$, count how many distinct index subsequences of $s$ equal $t$. On the handwritten example $s = \texttt{"rabbbit"}$ ($m = 7$) and $t = \texttt{"rabbit"}$ ($n = 6$), any $2$ of the $3$ $\texttt{'b'}$s in $s$ can match the $2$ $\texttt{'b'}$s in $t$, yielding $\binom{3}{2} = \mathbf{3}$ ways.

    • Recurrence (Page 4):
      • If $s[i - 1] == t[j - 1]$, we can either use $s[i - 1]$ to match $t[j - 1]$ ($dp[i - 1][j - 1]$) or skip $s[i - 1]$ to match $t[j - 1]$ earlier in $s$ ($dp[i - 1][j]$): $$dp[i][j] = \underbrace{dp[i - 1][j - 1]}_{\text{take}} + \underbrace{dp[i - 1][j]}_{\text{notTake}}$$
      • If $s[i - 1] \ne t[j - 1]$, we have no choice except skipping $s[i - 1]$: $dp[i][j] = dp[i - 1][j]$.
    • Base-Case Priority: Whenever target $t$ is completely matched ($j = 0$), return $\mathbf{1}$ (so $dp[i][0] = 1$ for all $i \ge 0$, including $dp[0][0] = 1$!). Only if $j > 0$ and $i = 0$ (source $s$ ran out first) do we return $0$.
    1-Array Reverse-Loop Space Optimization ($O(n)$ Space) Notice that $dp[i][j]$ only depends on the row directly above: $dp[i-1][j]$ and $dp[i-1][j-1]$ (never $dp[i][j-1]$!). Sweeping $j = n \downarrow 1$ right-to-left updates a single 1D array in-place via one line: if (s[i-1] == t[j-1]) dp[j] += dp[j - 1];! 
    int numDistinct(const string& s, const string& t) {
    int m = (int)s.size(), n = (int)t.size();
    vector<unsigned long long> dp(n + 1, 0); // unsigned 64-bit avoids intermediate overflow on LC 115
    dp[0] = 1; // j == 0 base case: empty target matched in 1 way

    for (int i = 1; i <= m; ++i) {
        for (int j = n; j >= 1; --j) {
            if (s[i - 1] == t[j - 1]) {
                dp[j] += dp[j - 1];
            }
        }
    }
    return (int)dp[n];
}

    4. Wildcard Matching: The Binary '*' Split & Three Base Cases (Pages 4–6, LeetCode 44)

    Match pattern $p$ (length $m$) containing literal characters, '?' (matches any single character), and '*' (matches any sequence of length $\ge 0$, including empty $\varepsilon$) against text $s$ (length $n$), e.g., $p = \texttt{"ab*cd"}$ against $s = \texttt{"abdefcd"}$.

    4.1 Eliminating the Inner Loop When $p[i - 1] == \texttt{'*'}$ (Page 5)

    Naively, a '*' in $\texttt{"ab*"}$ against $\texttt{"abdef"}$ could match $0, 1, 2, 3, \dots$ characters via a for loop, degrading DP to $O(m \cdot n^2)$. Page 5 draws the recursive insight that shrinks '*' to $O(1)$ per cell:

    4.2 The Three Exact Base Cases (Page 6)

    1. Both pattern and text exhausted ($i = 0$ and $j = 0$): dp[0][0] = true.
    2. Pattern exhausted, text still left ($i = 0$ and $j > 0$): Nothing left to consume $s$ $\implies$ dp[0][j] = false.
    3. Text exhausted, pattern still left ($i > 0$ and $j = 0$): An empty string can only be matched if every remaining character in $p[0 \dots i-1]$ is '*' (since '?' and letters each require $\ge 1$ character)!
    bool isMatchWildcard(const string& s, const string& p) {
    int m = (int)p.size(), n = (int)s.size();
    vector<bool> prev(n + 1, false), cur(n + 1, false);
    prev[0] = true; // Base case 1: dp[0][0] = true; prev[1..n] = false (Base case 2)

    for (int i = 1; i <= m; ++i) {
        // Base case 3: dp[i][0] is true iff p[0..i-1] are ALL '*'
        cur[0] = (p[i - 1] == '*') && prev[0];

        for (int j = 1; j <= n; ++j) {
            if (p[i - 1] == s[j - 1] || p[i - 1] == '?') {
                cur[j] = prev[j - 1];
            } else if (p[i - 1] == '*') {
                cur[j] = prev[j] || cur[j - 1]; // 0 chars OR (1 char + keep '*')
            } else {
                cur[j] = false;
            }
        }
        swap(prev, cur);
    }
    return prev[n]; // Time O(m*n), Space O(n)
}
