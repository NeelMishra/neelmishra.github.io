    DP-55: Maximal Rectangle Area with All 1s in a Binary Matrix

    October 2026 · 9 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 05_DP_55_Maximal_rectangle_Area.pdf

    Given an $m \times n$ binary matrix of 0s and 1s, find the area of the largest axis-aligned rectangle containing only 1s (Code360 Maximum Size Rectangle Sub-matrix With All 1's / LeetCode 85 / Striver DP-55). Unlike Maximal Square (where $dp[i][j] = 1 + \min(\text{up}, \text{left}, \text{diag})$ works because height and width grow equally), a rectangle can trade height for width—e.g., $1 \times 6$ vs. $2 \times 4$ vs. $3 \times 2$—so a single scalar per cell cannot represent all Pareto-optimal $(h, w)$ pairs!

    1. Brute $\to$ Better $\to$ Optimal Progression

    Approach Core Idea Time Space
    1. Naive Corner Pairs Pick $(r_1, c_1), (r_2, c_2)$ and scan interior for 0s $O(m^3 n^3)$ $O(1)$
    2. 2D Prefix Sums $O(1)$ submatrix sum check == $(r_2-r_1+1)(c_2-c_1+1)$ $O(m^2 n^2)$ $O(mn)$
    3. Row Width DP Track consecutive horizontal $1$s and scan upward per cell $O(m^2 n)$ $O(mn)$
    4. DP Row Histograms + Stack Maintain vertical $1$-streaks $\text{height}[j]$ + Largest Histogram $\Theta(m \cdot n)$ $\Theta(n)$

    2. Where Dynamic Programming Lives: Row-Accumulated Vertical Heights

    Every rectangle in the matrix rests its bottom edge on some row $i \in \{0 \dots m-1\}$. Fix row $i$ as the ground floor and remember from row $i - 1$ the vertical streak of consecutive 1s ending at row $i$ in each column $j$:

    $$\text{height}[j] = \begin{cases} \text{height}[j] + 1 & \text{if } \text{mat}[i][j] == 1 \\ \mathbf{0} & \text{if } \text{mat}[i][j] == 0 \quad \text{(a } 0 \text{ snaps vertical continuity to zero!)} \end{cases}$$

    3. Single-Pass Monotonic Stack Dry Run on $\text{height} = [3, 1, 3, 2, 2]$

    For each bar $p$, the widest rectangle of full height $h[p]$ stretches between its Previous Smaller Element ($\text{PSE}$) on the left and its Next Smaller Element ($\text{NSE}$) on the right: $\text{width} = \text{NSE} - \text{PSE} - 1$. Maintaining a monotonically non-decreasing stack of indices discovers both boundaries on the fly when bar $p$ is popped by a shorter bar at index $k$ (with a virtual $0$-height sentinel at $k = n$ to flush remaining bars):

    Stack Trace on Row $i = 2$: $h = [3, 1, 3, 2, 2]$ (+ virtual $h[5] = 0$)

    • $k = 0$ ($h=3$): push $0$ $\implies$ stack $[0]$
    • $k = 1$ ($h=1 < 3$): pop $0$ ($h=3$, empty stack $\implies w = 1$, area $= 3 \times 1 = 3$); push $1$ $\implies$ stack $[1]$
    • $k = 2$ ($h=3 \ge 1$): push $2$ $\implies$ stack $[1, 2]$
    • $k = 3$ ($h=2 < 3$): pop $2$ ($h=3$, new top $= 1 \implies w = 3 - 1 - 1 = 1$, area $= 3$); push $3$ $\implies$ stack $[1, 3]$
    • $k = 4$ ($h=2 \ge 2$): push $4$ $\implies$ stack $[1, 3, 4]$
    • $k = 5$ (sentinel $h=0$):
      • pop $4$ ($h=2$, top $= 3 \implies w = 5 - 3 - 1 = 1$, area $= 2$)
      • pop $3$ ($h=2$, top $= 1 \implies w = 5 - 1 - 1 = 3$ across cols $2..4$, area $= 2 \times 3 = \mathbf{6}$ ★)
      • pop $1$ ($h=1$, empty stack $\implies w = 5$, area $= 1 \times 5 = 5$)

    4. Clean C++ Implementation

    #include <bits/stdc++.h>
using namespace std;

int largestRectangleArea(const vector<int>& h) {
    int n = (int)h.size();
    stack<int> st;
    int maxA = 0;

    for (int k = 0; k <= n; ++k) {
        int curH = (k == n) ? 0 : h[k]; // Virtual 0 flushes all remaining bars
        while (!st.empty() && curH < h[st.top()]) {
            int height = h[st.top()];
            st.pop();
            int width = st.empty() ? k : (k - st.top() - 1);
            maxA = max(maxA, height * width);
        }
        st.push(k);
    }
    return maxA;
}

int maximalAreaOfSubMatrixOfAll1(const vector<vector<int>>& mat, int m, int n) {
    vector<int> height(n, 0);
    int maxArea = 0;

    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < n; ++j) {
            if (mat[i][j] == 1) height[j] += 1;
            else                height[j] = 0; // Reset vertical streak!
        }
        maxArea = max(maxArea, largestRectangleArea(height));
    }
    return maxArea;
}

    5. Amortized Complexity Proof & Edge Cases

    • Time Complexity Proof: For each of the $m$ rows, updating height[0..n-1] performs $n$ operations, and in largestRectangleArea each of the $n + 1$ indices is pushed once and popped at most once ($\le 2n + 1$ stack operations). Total work across all rows is $\Theta(m \cdot n)$.
    • Space Complexity: $\Theta(n)$ for the rolling height vector and the monotonic stack.
    • Equal-Height Duplicate Bars ([2, 2]): Notice at $k = 4$ ($h = 2$) in our trace above: whether you pop on <= or <, the leftmost duplicate bar ($k = 3$) always computes the full combined width across all equal bars!
    • char vs int Input Trap: LeetCode 85 passes vector<vector<char>> ('1' vs '0'), whereas Code360 passes vector<vector<int>> (1 vs 0). Writing mat[i][j] == 1 on char '1' (ASCII $49$) silently resets every height to $0$!
