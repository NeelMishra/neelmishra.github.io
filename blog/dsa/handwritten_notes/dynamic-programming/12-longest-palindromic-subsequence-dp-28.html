    DP-28: Longest Palindromic Subsequence & Minimum Palindrome Insertions/Deletions

    October 2026 · 7 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 12_Vid_28_Longest_palindromic_subsequence.pdf

    Sometimes the cleanest DP solution writes zero new DP logic—it reduces an unfamiliar problem to one you have already perfected! 12_Vid_28_Longest_palindromic_subsequence.pdf solves Longest Palindromic Subsequence (LPS, LeetCode 516) in a single surgical observation: comparing a string against its own reverse via LCS.

    1. Why $\text{LPS}(s) = \text{LCS}\bigl(s,\; \text{reverse}(s)\bigr)$ Always Holds

    A palindrome is any string $p$ that reads identically forward and backward ($p = \text{reverse}(p)$). Why does every common subsequence of $s_1 = s$ and $s_2 = \text{reverse}(s)$ yield a valid palindromic subsequence of diameter $\text{LPS}(s)$?

    Two-Way Correctness Proof

    1. $\text{LPS}(s) \le \text{LCS}(s, \text{rev}(s))$: Take any palindromic subsequence $p$ of $s$. Because $p$ is a subsequence of $s$, $\text{rev}(p)$ is automatically a subsequence of $\text{rev}(s)$. Since $p = \text{rev}(p)$, $p$ appears as a subsequence in both $s$ and $\text{rev}(s)$!
    2. $\text{LCS}(s, \text{rev}(s)) \le \text{LPS}(s)$: Suppose $c = c_1 c_2 \dots c_L$ is a longest common subsequence occurring at indices $i_1 < i_2 < \dots < i_L$ in $s$ and mirrored indices $j_1 > j_2 > \dots > j_L$ in $s$. Look at the midpoint where $i_k \le j_k$: either $i_k = j_k$ (forming odd-length palindrome $c_1 \dots c_k \dots c_1$ of length $2k - 1$) or $i_k < j_k$ and $i_{k+1} > j_{k+1}$ (forming even-length palindrome of length $2k$). At least one of the two symmetric halves has length $\ge L$, which by maximality forces equality $L = \text{LPS}(s)$!

    Handwritten Alignment Trace (12_Vid_28 Page 1)

    For $s_1 = \texttt{"bbabcbcab"}$ (length $9$), construct $s_2 = \text{reverse}(s_1) = \texttt{"bacbcbabb"}$:

    $$\begin{aligned} s_1 &= \texttt{b\;\underline{b}\;\underline{a}\;\underline{b}\;\underline{c}\;\underline{b}\;c\;\underline{a}\;\underline{b}} \\ s_2 &= \texttt{\underline{b}\;\underline{a}\;c\;\underline{b}\;\underline{c}\;\underline{b}\;\underline{a}\;\underline{b}\;b} \end{aligned}$$

    Running $\text{LCS}(s_1, s_2)$ extracts $\texttt{"babcbab"}$ of length $\mathbf{7}$!

    2. Alternative View: Direct Interval DP $dp[i][j]$ Without Reversing

    Besides calling $\text{LCS}(s, \text{rev}(s))$, you can also solve LPS directly on $s[i \dots j]$ with $dp[i][i] = 1$:

    $$dp[i][j] = \begin{cases} 2 + dp[i + 1][j - 1] & \text{if } s[i] == s[j] \\ \max\bigl(dp[i + 1][j],\; dp[i][j - 1]\bigr) & \text{if } s[i] \ne s[j] \end{cases}$$

    Notice that the direct upper-triangular interval DP touches only $\frac{n(n-1)}{2}$ cells (roughly $2\times$ fewer iterations than the full $n \times n$ LCS table) while sharing the exact same $\Theta(n^2)$ asymptotic time and $\Theta(n)$ space optimization!

    3. C++ & Python Implementations + Palindrome Insertion/Deletion Corollaries

    Two interview favorites collapse into one-line corollaries of $\text{LPS}(s)$:

    • Minimum Deletions to Make a String Palindrome: Delete everything outside the LPS $\implies |s| - \text{LPS}(s)$.
    • Minimum Insertions to Make a String Palindrome (LeetCode 1312, Striver DP-29): Keep the LPS intact as the palindromic skeleton and insert mirrored copies of the remaining $|s| - \text{LPS}(s)$ characters $\implies$ exact same answer $|s| - \text{LPS}(s)$! (In $\texttt{"bbabcbcab"}$, inserting $9 - 7 = 2$ characters mirrors the unmatched $\texttt{'b'}$ and $\texttt{'c'}$ into $\texttt{"bbabcbbcbabb"}$ or $\texttt{"babcbcabcbab"}$.)
    #include <bits/stdc++.h>
using namespace std;

// Approach A: Via Space-Optimized LCS(s, reverse(s)) — O(n^2) time, O(n) space
int longestPalindromeSubseqLCS(const string& s) {
    string rev(s.rbegin(), s.rend());
    int n = (int)s.size();
    vector<int> prev(n + 1, 0), cur(n + 1, 0);

    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (s[i - 1] == rev[j - 1])
                cur[j] = 1 + prev[j - 1];
            else
                cur[j] = max(prev[j], cur[j - 1]);
        }
        swap(prev, cur);
    }
    return prev[n];
}

// Approach B: Direct 1D-Compressed Upper-Triangle Interval DP — ~2x faster constant factor!
int longestPalindromeSubseqInterval(const string& s) {
    int n = (int)s.size();
    if (n == 0) return 0;
    vector<int> dp(n, 0);

    for (int i = n - 1; i >= 0; --i) {
        dp[i] = 1;           // Base case: single character s[i..i]
        int prevDiag = 0;    // Holds dp[i + 1][j - 1] from previous row!
        for (int j = i + 1; j < n; ++j) {
            int temp = dp[j]; // Save dp[i + 1][j] before overwriting
            if (s[i] == s[j])
                dp[j] = 2 + prevDiag;
            else
                dp[j] = max(dp[j], dp[j - 1]);
            prevDiag = temp;
        }
    }
    return dp[n - 1];
}

// LeetCode 1312 (Min Insertions) & Min Deletions to Make Palindrome:
int minInsertionsOrDeletionsToPalindrome(const string& s) {
    return (int)s.size() - longestPalindromeSubseqInterval(s);
}
    def longest_palindrome_subseq(s: str) -> int:
    rev = s[::-1]
    n = len(s)
    prev = [0] * (n + 1)
    for ch in s:
        cur = [0] * (n + 1)
        for j in range(1, n + 1):
            if ch == rev[j - 1]:
                cur[j] = 1 + prev[j - 1]
            else:
                cur[j] = prev[j] if prev[j] > cur[j - 1] else cur[j - 1]
        prev = cur
    return prev[n]

    4. Warning: Do NOT Generalize reverse(s) to Palindromic Substring!

    Subsequence Works with reverse(s) — Substring Does NOT!

    Because $\text{LPS}(s) = \text{LCS}(s, \text{reverse}(s))$ is so clean, the #1 interview trap is assuming $\text{LongestPalindromicSubstring}(s) = \text{LCSubstring}(s, \text{reverse}(s))$. Our very next note (Longest Palindromic Substring) disproves that assumption with a concrete counterexample!
