    Dynamic Programming: Subproblem Geometries, Transitions & 14-Part Reading Roadmap

    October 2026 · 8 min read · Handwritten Notes

    1-to-1 series roadmap & master cheat sheet across all 14 handwritten DP notebooks (MIT 6.006 lectures & Striver / Samsung DP notes, 48 pages)

    Dynamic Programming is controlled brute force over a Directed Acyclic Graph (DAG) of overlapping subproblems. Nearly every competitive programming DP question reduces to two design choices: picking the minimal subproblem state (prefix, suffix, 2D coordinate, dual-string alignment, monotonic tail, or interval $[i \dots j]$) that makes future decisions independent of how we arrived there, and ordering those states topologically so each subproblem is evaluated once.

    Every one of the 14 original handwritten DP PDFs now has its own dedicated standalone deep-dive post below, arranged in pedagogical reading order from foundational 1D recurrences and MIT 6.006's 5-step framework through 2D grids, row histograms, dual-string alignments, palindromes, patience-sorted LIS, and boolean interval parenthesization.

    Two Complementary Mental Models

    STEP 01 Subproblems Pick prefixes $x[:i]$, suffixes $x[i:]$, substrings $x[i:j]$, or augmented coordinates, and count $\#\text{states}$.
    STEP 02 Guess Identify the local choice (pick/skip, next line break $j$, operator split $k$) and count $\#\text{choices}$.
    STEP 03 Recurrence Relate $\text{DP}(\text{state})$ by aggregating guesses ($\sum$, $\min$, $\max$) plus exact base cases.
    STEP 04 Topological DAG Verify acyclicity! Memoize top-down or iterate bottom-up in dependency order.
    STEP 05 Original & Space Solve target state (and follow parent pointers); compress table to rolling rows or scalars.

    The Universal DP Time Complexity Formula

    $$\text{Total Time} \;=\; \bigl(\text{Number of Distinct Subproblems}\bigr) \;\times\; \bigl(\text{Non-Recursive Work per Subproblem}\bigr)$$

    Fibonacci / Stairs / Robber: $\Theta(n) \times O(1) = O(n)$ · Text Justification / LIS: $\Theta(n) \times O(n) = O(n^2)$ · Grids / Strings: $\Theta(mn) \times O(1) = O(mn)$ · Matrix Chain / Boolean Eval: $\Theta(n^2) \times O(n) = O(n^3)$.

    02 · MIT Framework Suffix $w[i:]$, Interval $[i..j]$, $(i, f)$ Text Justify $O(n^2)$, MCM $O(n^3)$, Fingering $O(nF^2)$ Poly Parent ptrs

    05 · House Robber $f(i)$: max non-adj sum in $a[0..i]$ $\max\bigl(a[i] + f(i-2),\; f(i-1)\bigr)$ $O(n)$ $O(1)$
    06 · Grid DP (Samsung) $dp[i][j]$ on $m \times n$ or Triangle Paths: $\text{up}+\text{left}$; MinSum: $g[i][j]+\min(\text{up},\text{left})$ $O(mn)$ $O(n)$
    07 · Maximal Rectangle $h[j]$: vertical $1$-streak at row $i$ $h[j] = g[i][j] ? h[j]+1 : 0$ + Monotonic Stack $O(mn)$ $O(n)$
    08 · LCS & Print LCS $dp[i][j]$: LCS of $s_1[:i], s_2[:j]$ Match: $1+dp[i-1][j-1]$; else $\max(\text{up}, \text{left})$ $O(mn)$ $O(n)$ ($O(mn)$ print)
    09 · LC Substring $dp[i][j]$: common suffix at $i,j$ Match: $1+dp[i-1][j-1]$; else $0$ (global max) $O(mn)$ $O(n)$
    10 · LP Subsequence $\text{LCS}(s, \text{reverse}(s))$ Min Palindrome Insertions/Deletions $= |s| - \text{LPS}(s)$ $O(n^2)$ $O(n)$
    11 · LP Substring $dp[i][j] \in \{0, 1\}$ on $s[i..j]$ $s[i]==s[j] \land (j-i \le 2 \lor dp[i+1][j-1])$ $O(n^2)$ $O(n^2)$ ($O(1)$ expand)
    12 · SCS / Edit / Wildcard $dp[i][j]$ on $(w_1[:i], w_2[:j])$ Edit: $1+\min(\text{rep},\text{del},\text{ins})$; '*': $\text{up} \lor \text{left}$ $O(mn)$ $O(n)$
    13 · LIS (DP 41–43) 1D $dp[i]$ + hash[], or tails[] $\max_{j<i, a_j<a_i}(1+dp[j])$, or lower_bound replace $O(n \log n)$ $O(n)$
    14 · Boolean Eval (DP-52) $dp[i][j] = (w_T, w_F)$ on $[i..j]$ Combine $(l_T, l_F) \otimes_{\text{op}_k} (r_T, r_F)$ over odd $k \in (i, j)$ $O(n^3)$ $O(n^2)$

    Five Recurring Pitfalls Highlighted Across the 14 Notes

    Checklist Before Submitting Any DP Solution
    1. Verify the subproblem graph is acyclic: Cyclic equations loop forever unless unrolled into acyclic layers (e.g., edge count $k$ in Bellman-Ford).
    2. Use $+10^9$, never $0$ or INT_MAX, to prune invalid min-cost branches: Returning $0$ off-grid makes walking off the board look free; INT_MAX + cell overflows signed int.
    3. Shift negative base-case indices by $+1$ for tabulation: Mapping -1 to 0 cleans up both Dual-String DP and 2D LIS (dp[ind][prev_ind + 1]).
    4. Subsequences propagate; substrings reset to $0$: Never carry max(up, left) into Longest Common Substring, and never use LCSubstring(s, reverse(s)) for Longest Palindromic Substring ("abcxyzcba" falsely matches "abc"!).
    5. Augment state when greedy single-value subproblems lose information: Piano Fingering needs current finger $f$, and Boolean Parenthesization needs both waysTrue and waysFalse because False ^ True = True and False | True = True.
