    Frog Jump: Minimum Energy Staircase DP & $K$-Step Generalization

    October 2026 · 8 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 09_Vid_3.pdf

    In Climbing Stairs, every step had uniform cost and we counted paths by summing recursive branches. 09_Vid_3.pdf switches the aggregation rule to minimization over weighted transitions (CodeStudio Frog Jump / AtCoder Educational DP Contest Problem A)—and preserves a candid "Self Attempt" whose boundary edge cases teach two of the most important debugging lessons in 1D DP.

    1. Problem Statement & Why Greedy Fails

    A frog starts on the $1^{\text{st}}$ step (index $0$) of an $N$-staircase with heights $\text{HEIGHT}[0 \dots N-1]$. From stair $i$, the frog can jump to $i + 1$ or $i + 2$, spending energy equal to the absolute height difference $|\text{HEIGHT}[i] - \text{HEIGHT}[j]|$. Find the minimum total energy required to reach the $N^{\text{th}}$ stair (index $N - 1$).

    Why Local Greedy Picks a Suboptimal Path

    Consider $\text{HEIGHT} = [30, 10, 60, 10, 60, 50]$:

    • Greedy choice from index $0$ ($30$): Jumping to index $1$ ($10$) costs $|30 - 10| = 20$, which looks cheaper than jumping to index $2$ ($60$, cost $30$). From index $1$ ($10$), jumping to index $3$ ($10$) costs $0$, and from index $3$ ($10$) to index $5$ ($50$) costs $|10 - 50| = 40$ $\implies$ greedy total $= 20 + 0 + 40 = \mathbf{60}$.
    • Global DP optimum: Pay slightly more up front by jumping $0 \to 2$ ($30 \to 60$, cost $30$), then $2 \to 4$ ($60 \to 60$, cost $0$), then $4 \to 5$ ($60 \to 50$, cost $10$) $\implies$ optimal total $= 30 + 0 + 10 = \mathbf{40}$!

    2. Auditing & Fixing the Handwritten "Self Attempt"

    In 09_Vid_3.pdf, the initial forward formulation uses 1-based stair index $i \in \{1 \dots N\}$ (reading 0-based HEIGHT[i - 1]):

    $$\text{Self Attempt: } f(i) = \min\Bigl(\text{HEIGHT}[i] - \text{HEIGHT}[i-1] + f(i+1),\;\; \text{HEIGHT}[i+1] - \text{HEIGHT}[i-1] + f(i+2)\Bigr)$$

    Walking through a dry run immediately catches two classic bugs before a single line is submitted:

    1. Signed difference vs. absolute difference: Stepping from height $30$ down to height $10$ still expends $+20$ energy, never $-20$! Every jump cost must wrap in $|\text{HEIGHT}[\text{to}] - \text{HEIGHT}[\text{from}]|$.
    2. Overshoot base case (if i > N: return 0): In Climbing Stairs, returning $0$ on $i > N$ discarded invalid paths because $0$ is neutral for $+$. Under $\min(\cdot)$, returning $0$ on $i = N + 1$ lets a frog standing on stair $N - 1$ jump two steps past the roof to $N + 1$ (reading out-of-bounds HEIGHT[N]) and pay $0$ remaining cost!
      Fix: Stop at if (i == N - 1) return 0; (0-indexed), and guard the 2-step branch with if (i + 2 < N) (or return $+\infty = 10^9$ when $i \ge N$).

    3. Clean Backward Recurrence & Dry Run

    Using 0-based index $\text{ind} \in \{0 \dots N-1\}$ where $f(\text{ind})$ is the minimum energy to reach stair $\text{ind}$ from stair $0$:

    $$f(0) = 0, \qquad f(\text{ind}) = \min\Bigl(\underbrace{f(\text{ind} - 1) + |h[\text{ind}] - h[\text{ind} - 1]|}_{\text{1-step jump}},\;\; \underbrace{f(\text{ind} - 2) + |h[\text{ind}] - h[\text{ind} - 2]|}_{\text{2-step jump (only if } \text{ind} > 1\text{)}}\Bigr)$$

    Dry Run on $h = [30, 10, 60, 10, 60, 50]$

    • $dp[0] = 0$
    • $dp[1] = dp[0] + |10 - 30| = 20$
    • $dp[2] = \min\bigl(dp[1] + |60 - 10|,\; dp[0] + |60 - 30|\bigr) = \min(20 + 50,\; 0 + 30) = \mathbf{30}$
    • $dp[3] = \min\bigl(dp[2] + |10 - 60|,\; dp[1] + |10 - 10|\bigr) = \min(30 + 50,\; 20 + 0) = \mathbf{20}$
    • $dp[4] = \min\bigl(dp[3] + |60 - 10|,\; dp[2] + |60 - 60|\bigr) = \min(20 + 50,\; 30 + 0) = \mathbf{30}$
    • $dp[5] = \min\bigl(dp[4] + |50 - 60|,\; dp[3] + |50 - 10|\bigr) = \min(30 + 10,\; 20 + 40) = \mathbf{40}$

    4. All Four Stages + $K$-Jump Generalization (C++ & Python)

    #include <bits/stdc++.h>
using namespace std;

// 1. Repaired Forward Memoization (matching 09_Vid_3.pdf structure) — O(N) time, O(N) space
int frogForwardMemo(int i, const vector<int>& h, vector<int>& dp) {
    int n = (int)h.size();
    if (i == n - 1) return 0; // Already on the N-th stair: 0 energy left
    if (dp[i] != -1) return dp[i];

    int jumpOne = abs(h[i + 1] - h[i]) + frogForwardMemo(i + 1, h, dp);
    int jumpTwo = INT_MAX;
    if (i + 2 < n) {
        jumpTwo = abs(h[i + 2] - h[i]) + frogForwardMemo(i + 2, h, dp);
    }
    return dp[i] = min(jumpOne, jumpTwo);
}

// 2. Bottom-Up Tabulation — O(N) time, O(N) space
int frogJumpTab(const vector<int>& h) {
    int n = (int)h.size();
    vector<int> dp(n, 0);
    for (int i = 1; i < n; ++i) {
        int left  = dp[i - 1] + abs(h[i] - h[i - 1]);
        int right = (i > 1) ? (dp[i - 2] + abs(h[i] - h[i - 2])) : INT_MAX;
        dp[i] = min(left, right);
    }
    return dp[n - 1];
}

// 3. Optimal O(1) Space Rolling Variables — O(N) time, O(1) space
int frogJumpSpaceOpt(const vector<int>& h) {
    int n = (int)h.size();
    if (n <= 1) return 0;
    int prev2 = 0, prev = 0;
    for (int i = 1; i < n; ++i) {
        int left  = prev + abs(h[i] - h[i - 1]);
        int right = (i > 1) ? (prev2 + abs(h[i] - h[i - 2])) : INT_MAX;
        int curr  = min(left, right);
        prev2 = prev;
        prev  = curr;
    }
    return prev;
}

// 4. Follow-Up (Frog Jump with K Distances / AtCoder DP B): O(N * K) time, O(N) space
int frogJumpKSteps(const vector<int>& h, int k) {
    int n = (int)h.size();
    vector<int> dp(n, INT_MAX);
    dp[0] = 0;
    for (int i = 1; i < n; ++i) {
        for (int step = 1; step <= k && i - step >= 0; ++step) {
            dp[i] = min(dp[i], dp[i - step] + abs(h[i] - h[i - step]));
        }
    }
    return dp[n - 1];
}
    def frog_jump(heights: list[int]) -> int:
    n = len(heights)
    if n <= 1:
        return 0
    prev2, prev = 0, 0
    for i in range(1, n):
        one_step = prev + abs(heights[i] - heights[i - 1])
        two_step = prev2 + abs(heights[i] - heights[i - 2]) if i > 1 else float("inf")
        prev2, prev = prev, min(one_step, two_step)
    return prev

    5. Complexity Proof & Edge Cases

    • Time Complexity: Each index $i \in \{1 \dots N-1\}$ evaluates at most $2$ transitions in $O(1)$ arithmetic $\implies \Theta(N)$ time (or $\Theta(N \cdot K)$ when jumps up to $K$ stairs are allowed).
    • Space Complexity: $\Theta(1)$ auxiliary space using prev and prev2 (or $O(K)$ circular buffer for the $K$-step generalization, though $O(N)$ is simpler when $N \le 10^5$).
    • Single-stair edge case ($N = 1$): The frog starts already on stair $1 = N$, so energy spent is $0$.
