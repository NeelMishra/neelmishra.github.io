    Curated Backtracking Question Bank: 26 LeetCode Problems by Tree Archetype

    October 2026 · 9 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 11_Question_banks.pdf

    11_Question_banks.pdf bookmarks the classic LeetCode Backtracking Practice Study Guide (backtracking-algorithm-problems-to-practice). Solving backtracking problems in random order feels overwhelming until you recognize that almost every interview problem belongs to one of four recursion-tree archetypes—and problems inside the same archetype share 90% of their code skeleton. Below is the complete, structured practice roadmap cross-linked with the dedicated derivations in this series.

    10-Second Interview Diagnostic Checklist

    Four Questions That Write the Skeleton for You
    1. Does relative order matter?
      • Order irrelevant ({1, 2} == {2, 1}) → Forward loop for (int j = i; j < n; ++j).
      • Order matters ([1, 2] != [2, 1]) → Full loop for (int j = 0; j < n; ++j) with vis[j] (or in-place suffix swaps).
    2. Can an element be reused?
      • Unlimited reuse → Recurse with dfs(j, ...).
      • At most once → Recurse with dfs(j + 1, ...).
    3. Does the input contain duplicate values?
      • Order of input flexible → Sort first; skip siblings with if (j > i && a[j] == a[j - 1]) continue; (Combinations/Subsets) or if (j > 0 && a[j] == a[j - 1] && !vis[j - 1]) continue; (Permutations).
      • Order of input fixed (e.g., LC 491) → Declare a local unordered_set<int> usedAtDepth inside each call frame.
    4. Are we counting / checking existence with path-independent state?
      • If the remaining subproblem depends only on (idx, rem) and not on which cells/elements are marked visited, memoize it—your exponential tree collapses into polynomial DP!

    LC 473 / 698 / 2305 · $K$-Buckets
    (Matchsticks, K Equal Subsets, Fair Cookies)    		 Place item idx into one of $k$ buckets 3-Rule Symmetry Prune (see template below!)

    Bonus Template: The 3-Rule $K$-Bucket Symmetry Prune (LC 473 / 698 / 2305)

    Partitioning $n \le 16$ items into $k$ equal-sum buckets (Partition to K Equal Sum Subsets, Matchsticks to Square, Fair Distribution of Cookies) is the hardest recurring medium/hard pattern in the question bank. Without symmetry breaking it explores $k^n$ states and TLEs; with three 1-line rules it runs in 0 ms:

    #include <algorithm>
#include <functional>
#include <numeric>
#include <vector>
using namespace std;

class Solution {
    bool dfs(int idx, const vector<int>& nums, vector<int>& bucket, int target) {
        if (idx == (int)nums.size()) return true;

        for (int b = 0; b < (int)bucket.size(); ++b) {
            if (bucket[b] + nums[idx] > target) continue;

            // Rule 2: Skip bucket with identical load to previous bucket (symmetric!)
            if (b > 0 && bucket[b] == bucket[b - 1]) continue;

            bucket[b] += nums[idx];
            if (dfs(idx + 1, nums, bucket, target)) return true;
            bucket[b] -= nums[idx];

            // Rule 3: If placing nums[idx] into an EMPTY bucket failed, every later
            // empty bucket is indistinguishable — break out of all remaining buckets!
            if (bucket[b] == 0) break;
        }
        return false;
    }

public:
    bool canPartitionKSubsets(vector<int>& nums, int k) {
        int sum = accumulate(nums.begin(), nums.end(), 0);
        if (sum % k != 0) return false;
        int target = sum / k;

        // Rule 1: Sort DESCENDING so large items hit capacity overflows immediately!
        sort(nums.begin(), nums.end(), greater<int>());
        if (nums[0] > target) return false;

        vector<int> bucket(k, 0);
        return dfs(0, nums, bucket, target);
    }
};
