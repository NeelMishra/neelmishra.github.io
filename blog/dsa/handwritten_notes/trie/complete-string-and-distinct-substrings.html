    Complete String (All Prefixes Present) & Number of Distinct Substrings

    October 2026 · 9 min read · Handwritten Notes

    Expanded from handwritten competitive coding study notes (05_Striver_L3_Longest_Word_With_All_Prefixes.pdf & 06_Striver_L4_Number_of_distinct_Substring_in_string.pdf)

    Once basic Trie insertion is in place, two structural properties of prefix trees unlock clean solutions to string problems that are awkward or cubic with hash sets: (1) every node along a root-to-word path represents one prefix of that word, letting us validate all prefixes of a candidate word in a single $O(L)$ walk; and (2) inserting every suffix of a string $S$ into a Trie implicitly inserts every substring of $S$ while deduplicating shared prefixes on the fly in $O(N^2)$ time.

    1. Longest Word With All Prefixes / Complete String (Striver L3)

    Problem Statement — Complete String

    Given an array A of $N$ strings, a string $w \in A$ is called a complete string if every non-empty prefix of $w$ is also present as a word in A. Find the longest complete string in A. If multiple complete strings tie for the maximum length, return the lexicographically smallest one; if no complete string exists, return "None".

    Handwritten Dry Run: Why "ninja" Beats "ninga"

    Consider the two sample test cases from 05_Striver_L3_Longest_Word_With_All_Prefixes.pdf:

    • Sample 1: A = ["n", "ni", "nin", "ninj", "ninja", "ninga"] ($N = 6$).
      • Notice that "ninga" and "ninja" both have length $5$, and lexicographically "ninga" < "ninja"!
      • Yet the answer is "ninja": its prefixes "n", "ni", "nin", "ninj", and "ninja" are all in A, so every node along its path in the Trie has flag == true.
      • For "ninga", the 4-letter prefix "ning" is missing from A—node 'g' has flag == false, immediately disqualifying "ninga"!
    • Sample 2: A = ["ab", "bc"] ($N = 2$) $\to$ Output: "None" (neither "a" nor "b" is in A, so both fail at depth $1$).

    Two-Pass Trie Algorithm & C++ Implementation

    1. Pass 1 (Insert all words): Insert every string $w \in A$ into the Trie, setting flag = true at each word's terminal node. Time: $O\left(\sum_{i=0}^{N-1} |A_i|\right)$.
    2. Pass 2 (Verify all prefixes): For each $w \in A$, walk from root character by character. If every visited node along $w$ has node->isEnd() == true, $w$ is a complete string! Update longest whenever w.size() > longest.size() or (w.size() == longest.size() && w < longest).
    #include <bits/stdc++.h>
using namespace std;

struct Node {
    Node* links[26] = {nullptr};
    bool flag = false;

    bool containsKey(char ch) const { return links[ch - 'a'] != nullptr; }
    Node* get(char ch) const { return links[ch - 'a']; }
    void put(char ch, Node* node) { links[ch - 'a'] = node; }
    void setEnd() { flag = true; }
    bool isEnd() const { return flag; }
};

class Trie {
    Node* root;
public:
    Trie() : root(new Node()) {}

    void insert(const string& word) {
        Node* node = root;
        for (char ch : word) {
            if (!node->containsKey(ch)) node->put(ch, new Node());
            node = node->get(ch);
        }
        node->setEnd();
    }

    // Returns true iff EVERY prefix of `word` exists as a complete word in the Trie
    bool checkAllPrefixes(const string& word) const {
        Node* node = root;
        for (char ch : word) {
            if (!node->containsKey(ch)) return false;
            node = node->get(ch);
            if (!node->isEnd()) return false; // Missing prefix!
        }
        return true;
    }
};

string completeString(int n, vector<string>& a) {
    Trie trie;
    for (const string& w : a) {
        trie.insert(w);
    }

    string longest = "";
    for (const string& w : a) {
        if (trie.checkAllPrefixes(w)) {
            if (w.size() > longest.size() ||
                (w.size() == longest.size() && w < longest)) {
                longest = w;
            }
        }
    }
    return longest.empty() ? "None" : longest;
}
// Time Complexity: O(N * L)  (precisely O(sum of |a[i]|))
// Space Complexity: O(N * L * 26) worst-case Trie nodes

    2. Number of Distinct Substrings in a String (Striver L4)

    Given a string S of length $N$, count the total number of distinct substrings of S, including the empty string "".

    Substring vs. Subsequence (Handwritten Clarification on "abc" & "sds")

    A substring must be contiguous—you may only delete characters from the front or from the back of S, never from the middle!

    • For S = "abc" (or "abs"): the $7$ distinct substrings are {"", "a", "b", "c", "ab", "bc", "abc"}. Note that "ac" is crossed out in the handwritten note because deleting the middle 'b' forms a subsequence, not a substring!
    • For S = "sds": enumerating all contiguous slices yields "", "s", "d", "s" (duplicate!), "sd", "ds", "sds" $\implies$ $6$ distinct substrings.

    Why a Suffix Trie Beats Brute-Force Hash/Tree Sets

    • Brute Force (Set of Strings): Two nested loops generate all $\frac{N(N+1)}{2}$ slices S.substr(i, len) and insert each slice into an unordered_set<string> or set<string>. Constructing and hashing each substring of length $O(N)$ costs $O(N)$, pushing total time to $O(N^3)$ (or $O(N^3 \log N)$ with std::set) and storing every prefix redundantly in $O(N^3)$ characters of memory!
    • Optimal Suffix-Trie Compression ($O(N^2)$ Time & Shared Memory): Every substring S[i..j] is simply a prefix of the suffix starting at index $i$!
      • For each starting index $i \in [0, N-1]$, reset Node* node = root and extend $j$ from $i$ to $N-1$ one character at a time.
      • If !node->containsKey(S[j]), the substring S[i..j] has never appeared anywhere earlier in S! Allocate the new child node and increment cnt++.
      • If node->containsKey(S[j]) is already true (like i = 2 seeing 's' in "sds"), just step into the existing child without incrementing cnt.
      • Notice we don't even need a bool flag inside Node—every node in this Trie is a distinct non-empty substring, and adding $+1$ at the end accounts for the empty substring ""!
    #include <bits/stdc++.h>
using namespace std;

struct SubNode {
    SubNode* links[26] = {nullptr};

    bool containsKey(char ch) const { return links[ch - 'a'] != nullptr; }
    SubNode* get(char ch) const { return links[ch - 'a']; }
    void put(char ch, SubNode* node) { links[ch - 'a'] = node; }
};

int countDistinctSubstrings(const string& s) {
    SubNode* root = new SubNode();
    int cnt = 0; // Counts distinct non-empty substrings (= total created Trie nodes)
    int n = s.size();

    for (int i = 0; i < n; i++) {
        SubNode* node = root;
        for (int j = i; j < n; j++) {
            if (!node->containsKey(s[j])) {
                node->put(s[j], new SubNode());
                cnt++; // Brand-new substring s[i..j] discovered!
            }
            node = node->get(s[j]);
        }
    }

    return cnt + 1; // +1 includes the empty substring ""
}
// Time Complexity: O(N^2)
// Space Complexity: At most N*(N+1)/2 Trie nodes (shared prefixes stored once!)
    Maximum Possible Distinct Substrings When all characters of $S$ are distinct (like "abc" of length $N = 3$), no two substrings collide, giving the upper bound $1 + \frac{N(N+1)}{2}$ distinct substrings ($1 + \frac{3 \times 4}{2} = 7$ for "abc"). Every duplicate substring in $S$ (such as the second "s" in "sds": $7 - 1 = 6$) corresponds to an existing Trie transition where cnt is not incremented.
