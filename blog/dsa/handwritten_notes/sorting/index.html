    Core Invariants & Practical Trade-Offs

    BUBBLE Sorted Suffix Adjacent swaps bubble the maximum of [0..i] into index i each pass.
    SELECTION Min Writes ($\le n-1$) Scans [i..n-1] for the minimum and performs just 1 swap per pass, but ignores existing order.
    INSERTION Adaptive Sorted Prefix Runs in $O(n + \text{inversions})$ time—used inside std::sort & Timsort on tiny subarrays ($n \le 16$).
    MERGE Guaranteed $O(n \log n)$ Deterministic worst-case bound, stable, and ideal for linked lists ($O(1)$ extra space) & external disk sorting.
    QUICK Cache-Friendly In-Place Partition places pivot at its final index; fastest average constant factor in RAM when randomized.
    How Standard Libraries Combine Them
    • C++ std::sort (Introsort): Starts with Quick Sort (median-of-three pivot), switches to Heap Sort if recursion depth exceeds $2\lfloor\log_2 n\rfloor$ to prevent Quick Sort's $O(n^2)$ worst case, and finishes subarrays of size $\le 16$ with Insertion Sort.
    • C++ std::stable_sort & Python list.sort (Timsort): Exploits natural sorted runs with Insertion Sort and merges runs stably using Merge Sort.
