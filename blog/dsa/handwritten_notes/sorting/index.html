    Sorting Algorithms: Master Comparison Table & Reading Guide

    October 2026 · 6 min read · Handwritten Notes

    1-to-1 reading guide for handwritten competitive coding notes: 01_Bubble_sort.pdf – 05_Quick_sort.pdf

    Comparison-based sorting is the bedrock of algorithmic thinking: elementary quadratic sorts teach loop invariants, boundary guards, write minimization, and $\Theta(n + I)$ inversion adaptivity, while divide-and-conquer sorts introduce recursion trees, auxiliary buffer index offsets, and in-place two-pointer pivot partitioning. Each note below corresponds 1-to-1 to its original handwritten PDF.

    1-to-1 Study Notes Roadmap

    01
    Bubble Sort: Adjacent Swaps & $O(n)$ Early-Exit Optimization

    Sorted-suffix invariant ("push maximum right"), pass-by-pass dry run on [13, 46, 24, 52, 20, 9], why j stops at i - 1, and early-exit swapped_flag optimization (01_Bubble_sort.pdf).

     02
    Selection Sort: Select Minimum, Swap Bounds & Why Best Case Stays $\Theta(n^2)$

    Sorted-prefix selection trace on [13, 46, 24, 52, 20, 9], why the outer loop stops at n - 2, minimum memory writes ($\le n - 1$ swaps), and long-range swap instability (02_Selection_sort.pdf).

     03
    Insertion Sort: Adaptive Sorted Prefix & Natural $O(n)$ Best Case

    Leftward prefix delivery on [14, 9, 15, 12, 6, 8, 13], short-circuit j > 0 guard, swap vs. right-shift C++ code, and exact $\Theta(n + I)$ inversion runtime (03_Insertion_sort.pdf).

     04
    Merge Sort: Divide-and-Merge Recursion Tree & Index Offset Proof

    Full 9-element recursion tree on [3, 1, 2, 4, 1, 5, 2, 6, 4], two-pointer merge trace, arr[idx] = temp[idx - low] offset proof, and $\Theta(n \log n)$ derivation (04_Merge_Sort.pdf).

     05
    Quick Sort: Two-Pointer Pivot Partitioning & Recurrence Analysis

    Four pivot choices, two-pointer crossing trace on [4, 6, 2, 5, 7, 9, 1, 3], why pivot swaps with j, bounds-safe C++ loops, and $F(n) = 2F(n/2)$ vs. $F(n) = F(0) + F(n - 1)$ recurrences (05_Quick_sort.pdf).

    Core Invariants & Practical Trade-Offs

    01 · BUBBLE Sorted Suffix Adjacent swaps bubble the maximum of [0..i] into index i each pass.
    02 · SELECTION Min Writes ($\le n-1$) Scans [i..n-1] for the minimum and performs just 1 swap per pass, but ignores existing order.
    03 · INSERTION Adaptive Sorted Prefix Runs in $\Theta(n + I)$ time—used inside std::sort & Timsort on tiny subarrays ($n \le 16$).
    04 · MERGE Guaranteed $\Theta(n \log n)$ Deterministic worst-case bound, stable, and ideal for linked lists ($O(1)$ extra space) & external disk sorting.
    05 · QUICK Cache-Friendly In-Place Partition places pivot at its final index; fastest average constant factor in RAM when randomized.
    How Industrial Standard Libraries Combine Them
    • C++ std::sort (Introsort): Starts with Quick Sort (median-of-three pivot), switches to Heap Sort if recursion depth exceeds $2\lfloor\log_2 n\rfloor$ to prevent Quick Sort's $\Theta(n^2)$ worst case, and finishes subarrays of size $\le 16$ with Insertion Sort.
    • C++ std::stable_sort & Hybrid Merge Sorts (Timsort): Exploit natural sorted runs with Insertion Sort and merge runs stably in guaranteed $\Theta(n \log n)$ time using Merge Sort.
