    Minimum Spanning Tree (MST) Theory: Spanning Tree Axioms, Cut Property & Prim's vs. Kruskal's

    October 2026 · 9 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 02_MST_Theory.pdf · View original handwritten page

    1. Problem Setup & Spanning Tree Axioms

    As stated in 02_MST_Theory.pdf, the input is a connected, undirected, weighted graph $G = (V, E)$ with $n$ nodes and $m$ edges, where $n$ and $m$ have no fixed ratio (for any connected simple graph, $n - 1 \le m \le \frac{n(n-1)}{2}$):

    Spanning Tree & Minimum Spanning Tree (MST)

    • Spanning Tree: A subgraph $T = (V, E_T)$ with $E_T \subseteq E$ containing all $n$ vertices and exactly $n - 1$ edges such that every vertex is reachable from every other vertex. Equivalently, any two of $\{ \text{connected},\; \text{acyclic},\; |E_T| = n - 1 \}$ imply the third!
    • Minimum Spanning Tree (MST): A spanning tree minimizing total weight $w(T) = \sum_{e \in E_T} w(e)$.
    • Multiplicity Note: A cyclic graph has more than 1 spanning tree (up to $n^{n-2}$ on $K_n$ by Cayley's formula!), and can even possess multiple distinct MSTs whenever tied edge weights allow equal-cost swaps—though every MST of $G$ has the exact same minimum weight sum.

    3. Brute Enumeration $\to$ The Cut & Cycle Exchange Theorems

    • Brute Force (Infeasible): Enumerating all $\binom{m}{n-1}$ edge subsets and testing connectivity costs exponential time ($n^{n-2}$ trees on complete graphs).
    • Optimal Greedy Characterization ($\mathcal{O}(E \log E)$): MSTs form a matroid governed by two dual exchange laws:
      1. Cut Property (Inclusion Rule): For any partition $(S, V \setminus S)$, a lightest crossing edge $e^*$ belongs to some MST. (Drives both Prim's and Kruskal's!)
      2. Cycle Property (Exclusion Rule): For any simple cycle $C$ in $G$, a strictly heaviest edge $e_{\max} \in C$ cannot belong to any MST (removing $e_{\max}$ splits any tree containing it into two components reconnectable by a strictly cheaper edge of $C$). (Explains why 8 and 7 above were immediately eliminated!)

    Classic Interview Trap: Minimum Spanning Tree $\neq$ Shortest-Path Tree!

    Consider triangle $\{0, 1, 2\}$ with edges $(0,1)=3,\; (1,2)=3,\; (0,2)=5$ rooted at source $0$. The MST chooses $(0,1)$ and $(1,2)$ for total wire cost $3 + 3 = 6$ (giving distance $6$ from $0$ to $2$). The Shortest-Path Tree (Dijkstra) from $0$ chooses $(0,1)=3$ and $(0,2)=5$ (total tree weight $8$, but shortest distance $5$ to vertex $2$!). Also unlike Dijkstra, both Prim's and Kruskal's work 100% unmodified with negative edge weights because shifting every edge weight by $+C$ shifts every spanning tree's weight by $(n-1)C$ identically!

    4. Overview of the Two Classic MST Algorithms

    The bottom of 02_MST_Theory.pdf introduces the two standard $\mathcal{O}(E \log E)$ algorithms studied in the next two notes:

    1. 1) Prim's Algorithm: Starts at any single vertex $s$, maintains cut $(S, V \setminus S)$ of visited vs. unvisited vertices, and repeatedly pops the cheapest crossing edge from a Min-Heap Priority Queue.
    2. 2) Kruskal's Algorithm: Sorts all $m$ edges in non-decreasing weight order and uses a Disjoint Set Union (DSU) data structure to greedily merge different connected components while skipping cycle-forming edges.
    // Structural Spanning-Tree Verifier (Checks all 3 equivalent tree axioms in O(V + E))
bool isValidSpanningTree(int n, const vector<pair<int, int>>& chosenEdges) {
    if (static_cast<int>(chosenEdges.size()) != n - 1) return false; // Axiom 1: n - 1 edges

    vector<vector<int>> adj(n);
    for (auto [u, v] : chosenEdges) {
        if (u == v) return false; // Self-loop immediately creates a cycle
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    // Axiom 2: All n nodes reachable from node 0 (with n-1 edges, connected <=> acyclic!)
    vector<char> vis(n, 0);
    queue<int> q;
    vis[0] = 1;
    q.push(0);
    int reached = 0;

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ++reached;
        for (int v : adj[u]) {
            if (!vis[v]) {
                vis[v] = 1;
                q.push(v);
            }
        }
    }
    return reached == n;
}

    5. Key Structural Edge Cases

    • Single Vertex ($n = 1$): Every spanning tree has $n - 1 = 0$ edges and total MST weight $0$.
    • Disconnected Graph ($c > 1$ components, or $m < n - 1$): No spanning tree exists; a Minimum Spanning Forest has $n - c$ edges across the $c$ components.
    • Self-Loops & Parallel Multi-Edges: Self-loops $(u, u)$ never belong to any spanning tree; among parallel edges between $(u, v)$, only the minimum-weight copy can ever participate in an MST.
    • Distinct Edge Weights Theorem: If all $m$ edge weights in a connected graph are strictly distinct, the Minimum Spanning Tree is guaranteed to be unique!
