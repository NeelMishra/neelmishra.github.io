    Minimum Spanning Trees (MST): Visited Timing, Cut Property, Prim's PQ & Kruskal's DSU

    October 2026 · 6 min read · 4-Note Series (7 Handwritten Pages)

    Given a connected, undirected, weighted graph $G = (V, E)$ with $n = |V|$ vertices and $m = |E|$ edges, a spanning tree connects all $n$ vertices using exactly $n - 1$ edges with zero cycles. Among all spanning trees of $G$, a Minimum Spanning Tree (MST) minimizes the total sum of edge weights—powering minimum-cost network wiring, clustering, and bottleneck minimax path problems. Every handwritten PDF in this folder has its own dedicated standalone walkthrough below.

    Why Greedy Works: The MST Cut Property

    The Cut Property (Exchange Proof Intuition)

    Partition vertex set $V$ into any two non-empty disjoint subsets $S$ and $V \setminus S$. If $e = (u, v)$ is a minimum-weight edge crossing the cut ($u \in S,\; v \in V \setminus S$), then $e$ belongs to some Minimum Spanning Tree of $G$.

    Why? If a spanning tree $T$ omits $e$, adding $e$ to $T$ closes a unique cycle that must cross back from $V \setminus S$ to $S$ via another crossing edge $e'$ with $w(e) \le w(e')$. Swapping $T' = T \cup \{e\} \setminus \{e'\}$ preserves connectivity with weight $w(T') = w(T) + w(e) - w(e') \le w(T)$!

    Master Comparison: Prim's PQ vs. Kruskal's DSU

    Choosing between Prim's and Kruskal's in competitive programming.
    Dimension Prim's Algorithm (Note 03) Kruskal's Algorithm (Note 04)
    Growth Strategy Vertex-centric: grows one connected tree outward from any source node. Edge-centric: merges $V$ isolated components into a forest until $1$ tree remains.
    Core Data Structure Min-Heap Priority Queue (wt, node, parent) + vis[V] Sorted edge list (wt, u, v) + Disjoint Set Union (findUPar, unionBySize)
    Cycle Prevention Skip popped vertex if vis[node] == 1 (mark visited on pop, never on push!) Skip edge if ds.findUPar(u) == ds.findUPar(v)
    Time Complexity $\mathcal{O}(E \log E)$ (or $\mathcal{O}(V^2)$ without heap on dense $E \approx V^2$ graphs like LC 1584!) $\mathcal{O}(E \log E + E \cdot \alpha(V)) = \mathcal{O}(E \log E)$
    Disconnected Graph? Covers only the starting component unless wrapped in a 0..V-1 loop. Naturally computes the Minimum Spanning Forest across all components in one pass!
    Best Input Format Adjacency list adj[u] = {{v, wt}, ...} Flat edge list edges = {{u, v, wt}, ...} (and problems already using DSU!)
