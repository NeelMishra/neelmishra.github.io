    Striver Array Lecture 8: Kadane's Maximum Subarray Sum (LC 53) & Max Absolute Subarray Sum (LC 1749)

    October 2026 · 9 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 09_Striver_lecture_8.pdf (2 pages) · Jump to original scans

    Given an integer array containing positives, zeros, and negatives — such as Page 1's arr = [-2, -3, 4, -1, -2, 1, 5, -3] — find the contiguous non-empty subarray with the largest sum (ans = 7, achieved by [4, -1, -2, 1, 5]). Lecture 8 distils Kadane's Algorithm (LeetCode 53) down to a single greedy/DP principle, then immediately extends it to LeetCode 1749: Maximum Absolute Sum of Any Subarray.

    1. Maximum Subarray Sum: Brute Force $\to$ Kadane's Reset Rule

    • Brute Force ($\mathcal{O}(N^3) \to \mathcal{O}(N^2)$ time, $\mathcal{O}(1)$ space): Enumerate every start index $l \in [0, N - 1]$ and accumulate sum += arr[r] for $r = l \dots N - 1$, tracking the maximum across all $\binom{N + 1}{2}$ non-empty subarrays.

    Kadane's Philosophy (09_Striver_lecture_8.pdf, Page 1)

    "If a subarray has a negative sum, it cannot contribute positively to any future subarray — hence there is no use in expanding that subarray. In such case, we should drop the subarray (sum = 0) and start fresh!"

    Formally, let $dp[i]$ be the maximum sum among all non-empty subarrays ending at index $i$. Either we extend the best subarray ending at $i - 1$, or we discard it and start fresh at $i$:

    $$dp[i] = \max\bigl(\text{nums}[i],\; dp[i - 1] + \text{nums}[i]\bigr) = \text{nums}[i] + \max\bigl(0,\, dp[i - 1]\bigr)$$

    Notice the subtle converse: if a prefix sum dips downward yet stays positive, we keep it! On [4, -1, -2, 1, 5], after reading 4, -1, -2 our running sum drops from $4$ down to $+1 > 0$ — carrying that $+1$ prefix boosts the upcoming [1, 5] from $6$ up to the optimal $7$!

    Two Classic Coding Bugs (Including the Slip on Page 1!)

    1. Order of operations on all-negative arrays: Always update ans = max(ans, sum) before executing if (sum < 0) sum = 0! If nums = [-5, -2, -8] and you reset first, every element gets wiped to 0 and you falsely return empty-subarray sum 0 instead of the required non-empty answer -2.
    2. Return ans, NEVER sum! Look closely at the last line of the pseudocode on Page 1: the note accidentally wrote return SUM instead of return ans (and SUM += nums for SUM += num). On [-2, -3, 4, -1, -2, 1, 5, -3], the final -3 pulls SUM down from 7 to 4 — only ans remembers the peak 7!

    2. Variation: LeetCode 1749 — Maximum Absolute Sum of Any Subarray

    Given an integer array nums, return $\max_{l \le r} \bigl|\sum_{k=l}^{r} \text{nums}[k]\bigr|$ (empty subarray sum $0$ is also allowed). Examine the two handwritten examples on the bottom half of Page 1:

    • nums = [1, -3, 2, 3, -4] $\longrightarrow$ subarray [2, 3] has sum $+5 \implies |+5| = \mathbf{5}$.
    • nums = [2, -5, 1, -4, 3, -2] $\longrightarrow$ subarray [-5, 1, -4] has sum $-8 \implies |-8| = \mathbf{8}$!

    2.1 Completing Page 2's Derivation: Dual-Kadane & Prefix-Range Equivalence

    At the bottom of Page 1, the note observes: "The MAX abs SUM will come from either MAX negative SUM OR MAX positive SUM", and Page 2 opens with "$\Rightarrow$ So just..." — let's complete both ways to finish that sentence!

    1. Dual-Kadane ($\mathcal{O}(N)$ time, $\mathcal{O}(1)$ space): Since $|S| = \max(S, -S)$ for every subarray sum $S$: $$\max_{l, r} |S(l, r)| = \max\Bigl(\max_{l, r} S(l, r),\; -\min_{l, r} S(l, r)\Bigr)$$ So just maintain two Kadane accumulators in one loop: standard curMax = max(0, curMax + x) (dropping negative prefixes) and mirror curMin = min(0, curMin + x) (dropping positive prefixes to find the most negative subarray sum!), then return max(maxPos, -minNeg)!
    2. Prefix-Sum Peak-Minus-Valley Identity ($\mathcal{O}(N)$ time, $\mathcal{O}(1)$ space): Let $P_k = \sum_{i=0}^{k-1} \text{nums}[i]$ with $P_0 = 0$. Every subarray sum is $P_r - P_l$, and reversing $(l, r)$ just flips its sign, so: $$\max_{0 \le l \le r \le N} |P_r - P_l| = \max_{0 \le a, b \le N} (P_a - P_b) = \max_{0 \le k \le N} P_k - \min_{0 \le k \le N} P_k$$ On [2, -5, 1, -4, 3, -2], prefix sums are $P = [0, 2, -3, -2, -6, -3, -5]$, giving $\max P - \min P = 2 - (-6) = \mathbf{8}$ in four lines of code!

    3. Clean Reference Implementations (C++ & Python)

    #include <bits/stdc++.h>
using namespace std;

// 1a. LeetCode 53: Kadane's Maximum Subarray Sum — O(N) time, O(1) space
long long maxSubArray(const vector<int>& nums) {
    long long ans = LLONG_MIN, sum = 0;
    for (int x : nums) {
        sum += x;
        ans = max(ans, sum); // MUST precede reset for all-negative arrays!
        if (sum < 0) sum = 0;
    }
    return ans; // return ans, never sum!
}

// 1b. Follow-up: Also recover exact indices [ansStart..ansEnd] of maximum subarray
long long maxSubArrayWithIndices(const vector<int>& nums, int& ansStart, int& ansEnd) {
    long long ans = LLONG_MIN, sum = 0;
    int candStart = 0;
    ansStart = ansEnd = 0;
    for (int i = 0; i < (int)nums.size(); ++i) {
        if (sum == 0) candStart = i;
        sum += nums[i];
        if (sum > ans) {
            ans = sum;
            ansStart = candStart;
            ansEnd = i;
        }
        if (sum < 0) sum = 0;
    }
    return ans;
}

// 2. LeetCode 1749: Maximum Absolute Sum of Any Subarray — O(N) time, O(1) space
int maxAbsoluteSum(const vector<int>& nums) {
    int curMax = 0, curMin = 0;
    int maxPos = 0, minNeg = 0;
    for (int x : nums) {
        curMax = max(0, curMax + x);
        curMin = min(0, curMin + x);
        maxPos = max(maxPos, curMax);
        minNeg = min(minNeg, curMin);
    }
    return max(maxPos, -minNeg);
}
    from math import inf

def max_sub_array(nums: list[int]) -> int:
    """LeetCode 53: Kadane's algorithm in O(N) time, O(1) space."""
    ans = -inf
    cur = 0
    for x in nums:
        cur += x
        if cur > ans:
            ans = cur
        if cur < 0:
            cur = 0
    return int(ans)


def max_absolute_sum(nums: list[int]) -> int:
    """LeetCode 1749 via prefix peak - valley (equivalent to Dual-Kadane)."""
    pref = max_pref = min_pref = 0
    for x in nums:
        pref += x
        max_pref = max(max_pref, pref)
        min_pref = min(min_pref, pref)
    return max_pref - min_pref
