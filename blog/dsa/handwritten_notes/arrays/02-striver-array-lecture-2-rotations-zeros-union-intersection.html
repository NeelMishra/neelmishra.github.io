    Striver Array Lecture 2: Cyclic Rotations, 3-Reverse Proof, Move Zeros & Sorted Set Operations

    October 2026 · 12 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 02_Striver_lec_2.pdf (5 pages) · Jump to original scans

    Lecture 2 is the longest notebook in the Arrays series (5 handwritten pages) and bridges single-array pointer compaction with multi-array two-pointer merging. Every problem on these pages revolves around rearranging or combining elements without paying for auxiliary $\mathcal{O}(N)$ buffers or $\mathcal{O}(N \log N)$ tree sets.

    1. Left Rotate an Array by One Place

    Given arr = [1, 2, 3, 4, 5], shift every element one index to the left and wrap the first element around to the back: [2, 3, 4, 5, 1], using no new array ($\mathcal{O}(1)$ extra space).

    • Algorithm: Because arr[0] gets overwritten first, stash temp = arr[0]. Then shift arr[i] into arr[i - 1] (written on Page 1 with write pointer j = 0 and read pointer i = 1 .. n - 1: arr[j] = arr[i]; j += 1), and finally place arr[n - 1] = temp.
    Total Space vs. Extra Auxiliary Space (Page 1 Remark) When an interviewer asks for the space complexity of an in-place array algorithm, state both quantities explicitly just as noted on Page 1:
    • Space used in the algorithm: $\mathcal{O}(N)$ (we read and mutate the given $N$-element array).
    • Extra (auxiliary) space used: $\mathcal{O}(1)$ (only scalar variables temp, i, j).

    2. Prerequisite Helper: Reverse an Array in $\mathcal{O}(1)$ Extra Space

    Before tackling $D$-place rotation in $\mathcal{O}(1)$ space, Page 2 isolates in-place reversal on arr = ['h', 'e', 'l', 'l', 'o'] $\to$ ['o', 'l', 'l', 'e', 'h'] ($N = 5$):

    • Place two pointers at opposite ends: i = 0, j = n - 1.
    • While i < j (which stops after $\lfloor N / 2 \rfloor$ swaps — here $5 // 2 = 2$ swaps, leaving middle index $2$ untouched), swap arr[i] with arr[j] and step inward (i++, j--).
    • Note on Page 2's Temp-Free Arithmetic Swap: Page 2 writes out the classic 3-step sum/difference swap: arr[i] = arr[j] + arr[i] $\to$ arr[j] = arr[i] - arr[j] $\to$ arr[i] = arr[i] - arr[j]. While neat algebraically ($(i + j) - j = i$ and $(i + j) - i = j$), in C++ always prefer std::swap(arr[i], arr[j]) because arr[i] + arr[j] invokes signed integer overflow UB when values approach INT_MAX!

    3. Left Rotate an Array by $D$ Places (and LeetCode 189 Right Rotate)

    Now suppose we must left-rotate arr = [1, 2, 3, 4, 5, 6, 7] ($N = 7$) by $k$ (or $d$) places, where $k$ may even satisfy $k \gg N$.

    3.1 Step 0 (Modular Reduction) & Temporary-Buffer Brute Force

    • Observation ($k \gets k \bmod N$): Rotating an array of length $N$ by exactly $N$ places restores the exact original array. Hence $k$ rotations is identical to $d = k \bmod N$ rotations (e.g., rotating $N = 7$ by $k = 17$ places is just $17 \bmod 7 = 3$ rotations; if $d == 0$, return immediately!).
    • Brute Force ($\mathcal{O}(N + d)$ time, $\mathcal{O}(d)$ extra space): Copy the $d$ elements that fall off the left end (temp = arr[0..d-1]) into a temporary buffer, shift the remaining $N - d$ elements left via arr[i - d] = arr[i] for $i = d \dots N - 1$, and copy temp into arr[N - d .. N - 1].

    3.2 Optimal $\mathcal{O}(1)$-Space 3-Step Block Reversal

    Split the array at index $d$ into prefix block $A = \text{arr}[0..d-1]$ and suffix block $B = \text{arr}[d..N-1]$. Left rotation turns $A B$ into $B A$. Look at Page 2's diagram on [1, 2, 3 | 4, 5, 6, 7] ($d = 3$):

    • If we reversed the entire array right away, $(A B)^R = B^R A^R = [7, 6, 5, 4 \mid 3, 2, 1]$ — the blocks $B$ and $A$ landed on the correct sides, except the digits inside each block are upside-down!
    • Therefore, if we reverse $A$ and $B$ individually first (or reverse the full array first and then un-reverse each landed block), the second reversal cancels the internal inversion:
    $$\bigl(A^R \, B^R\bigr)^R = (B^R)^R (A^R)^R = B A$$

    4. Move All Zeros to the End of the Array (LeetCode 283)

    Given arr = [1, 0, 2, 3, 2, 0, 0, 4, 5, 1], move all 0s to the tail while preserving the relative order of non-zero elements: [1, 2, 3, 2, 4, 5, 1, 0, 0, 0].

    • Brute Force ($\mathcal{O}(2N)$ time, $\mathcal{O}(N)$ space): Copy all non-zero elements into a temporary vector, copy them back to the front of arr, and zero-fill the remaining slots.
    • Optimal Variant A — Two-Pointer Overwrite + Zero-Fill (Page 3's exact 3-step note, $\mathcal{O}(N)$ time, $\mathcal{O}(1)$ space):
      1. Keep write pointer j = 0 and scan pointer i = 0 .. N - 1.
      2. Whenever arr[i] != 0, write arr[j] = arr[i] and increment j++.
      3. Once i finishes scanning the whole list, fill arr[j] = 0 while incrementing j++ up to $N - 1$.
    • Optimal Variant B — Single-Loop Partition Swap ($\mathcal{O}(N)$ time, $\mathcal{O}(1)$ space): Whenever arr[i] != 0, execute swap(arr[j++], arr[i]). Invariant: arr[0..j-1] holds all seen non-zeros in order, and arr[j..i-1] holds only zeros!

    5. Union & Intersection of Two Sorted Arrays

    5.1 Union of Two Sorted Arrays (Without Duplicates)

    Given arr1 = [1, 1, 2, 3, 4, 5] ($m = 6$) and arr2 = [2, 3, 4, 5] ($n = 4$), return their sorted set union [1, 2, 3, 4, 5] with no repeated elements.

    • Brute Force — Ordered Set: Insert both arrays into a set and dump back out. As tallied on Page 3: $\mathcal{O}(m \log(m+n) + n \log(m+n) + (m + n))$ time and $\mathcal{O}(m + n)$ auxiliary tree space.
    • Optimal — Deduplicating Two-Pointer Merge ($\mathcal{O}(m + n)$ time, $\mathcal{O}(1)$ auxiliary space beyond output): Walk i = 0 over arr1 and j = 0 over arr2 (watch 0-based loop bounds: while i < m and j < n, rather than <=!). At each step, pick the smaller of arr1[i] and arr2[j], advance that pointer, and append to unionArr only if unionArr.empty() || unionArr.back() != candidate. Drain whichever array still has leftover elements with the exact same duplicate guard.

    5.2 Intersection of Two Sorted Arrays

    Given A = [1, 2, 2, 2, 3, 3, 4, 5, 6] and B = [2, 3, 3, 5, 6, 6, 7], find the common elements in sorted order using two pointers i = 0, j = 0:

    • If A[i] < B[j]: since B is sorted, no element from B[j..] can ever match A[i] $\implies$ i++.
    • If A[i] > B[j]: symmetrically, no element from A[i..] can match B[j] $\implies$ j++.
    • If A[i] == B[j]: we found a match! Advance both i++ and j++.
      • For unique set intersection (LeetCode 349, matching Pages 4–5's if ans == [] or ans[-1] != A[i] check): guard the push to get [2, 3, 5, 6].
      • For multiset bag intersection (LeetCode 350, where each shared pair counts once): omit the guard to get [2, 3, 3, 5, 6]!

    6. Clean Reference Implementations (C++ & Python)

    #include <bits/stdc++.h>
using namespace std;

// 1. Left rotate by 1 place in O(N) time, O(1) extra space
void leftRotateByOne(vector<int>& arr) {
    if (arr.size() <= 1) return;
    int temp = arr[0];
    for (size_t i = 1; i < arr.size(); ++i) arr[i - 1] = arr[i];
    arr.back() = temp;
}

// 2. Left rotate by d places via 3-step reversal: O(2N) = O(N) time, O(1) extra space
void leftRotateByD(vector<int>& arr, int d) {
    int n = (int)arr.size();
    if (n <= 1) return;
    d %= n;
    if (d == 0) return;

    reverse(arr.begin(), arr.begin() + d); // O(d)
    reverse(arr.begin() + d, arr.end());   // O(n - d)
    reverse(arr.begin(), arr.end());       // O(n)
}

// 3. LeetCode 283: Move all zeros to end preserving order: O(N) time, O(1) space
void moveZeroes(vector<int>& nums) {
    int j = 0;
    for (int i = 0; i < (int)nums.size(); ++i) {
        if (nums[i] != 0) swap(nums[j++], nums[i]);
    }
}

// 4. Union of two sorted arrays (unique elements): O(m + n) time, O(1) aux space
vector<int> unionSorted(const vector<int>& a, const vector<int>& b) {
    vector<int> res;
    auto pushUnique = [&](int x) {
        if (res.empty() || res.back() != x) res.push_back(x);
    };
    size_t i = 0, j = 0;
    while (i < a.size() && j < b.size()) {
        if (a[i] <= b[j]) pushUnique(a[i++]);
        else pushUnique(b[j++]);
    }
    while (i < a.size()) pushUnique(a[i++]);
    while (j < b.size()) pushUnique(b[j++]);
    return res;
}

// 5. Intersection of two sorted arrays (unique elements, matching Pages 4-5): O(m + n) time
vector<int> intersectionSortedUnique(const vector<int>& a, const vector<int>& b) {
    vector<int> ans;
    size_t i = 0, j = 0;
    while (i < a.size() && j < b.size()) {
        if (a[i] < b[j]) ++i;
        else if (a[i] > b[j]) ++j;
        else {
            if (ans.empty() || ans.back() != a[i]) ans.push_back(a[i]);
            ++i;
            ++j;
        }
    }
    return ans;
}
    def reverse_slice(arr: list[int], l: int, r: int) -> None:
    while l < r:
        arr[l], arr[r] = arr[r], arr[l]
        l += 1
        r -= 1


def left_rotate_by_d(arr: list[int], d: int) -> None:
    n = len(arr)
    if n <= 1:
        return
    d %= n
    if d == 0:
        return
    reverse_slice(arr, 0, d - 1)
    reverse_slice(arr, d, n - 1)
    reverse_slice(arr, 0, n - 1)


def move_zeroes_overwrite(arr: list[int]) -> None:
    """Page 3 two-pointer insert + zero-fill formulation."""
    j = 0
    for x in arr:
        if x != 0:
            arr[j] = x
            j += 1
    while j < len(arr):
        arr[j] = 0
        j += 1


def union_sorted(a: list[int], b: list[int]) -> list[int]:
    res: list[int] = []
    i, j = 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            val = a[i]; i += 1
        else:
            val = b[j]; j += 1
        if not res or res[-1] != val:
            res.append(val)
    for val in a[i:]:
        if not res or res[-1] != val:
            res.append(val)
    for val in b[j:]:
        if not res or res[-1] != val:
            res.append(val)
    return res
