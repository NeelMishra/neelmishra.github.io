    Arrays: Handwritten Notes, Core Patterns & Complete 13-Notebook Index

    October 2026 · 7 min read · 13 Dedicated Posts (13 PDFs · 25 Scanned Pages)

    Expanded 1-to-1 from handwritten competitive coding study notes (01_Striver_lec_1.pdf through 13_Pingalas_triangle.pdf)

    Array problems look deceptively ad-hoc until you recognize that almost every optimal $\mathcal{O}(n)$-time, $\mathcal{O}(1)$-space solution comes from maintaining a prefix or pointer invariant. Each of the 13 handwritten notebooks in this folder has its own dedicated standalone post below, complete with intuition, Brute $\to$ Better $\to$ Optimal progression, step-by-step dry runs, C++ & Python implementations, complexity proofs, and the original scanned notebook pages.

    Interview Progression Rule (from Lecture 1, Page 1) Even when you immediately recognize the $\mathcal{O}(n)$ optimal trick, drive the interview deliberately: clarify duplicate/sign/empty edge cases first, state the sorting or nested-loop baseline, pinpoint the redundant work, and then introduce the invariant that eliminates extra passes or auxiliary memory. (Skip the ceremony only on trivial warmups like finding the maximum element.)

    Pattern Decision Cheat Sheet

    Before jumping into code, ask what structural property of the array lets you discard $\mathcal{O}(n^2)$ pairs or $\mathcal{O}(n)$ extra memory:

    Selecting the right $\mathcal{O}(n)$ array technique from input constraints.
    Constraint / Query Shape Canonical Technique Why It Works (Core Invariant)
    In-place filtering or compaction (preserve relative order) Read / Write Two Pointers (j = write, i = scan) Prefix arr[0..j] always holds valid compacted output; i scans each element once.
    3-bucket in-place classification (e.g., 0, 1, 2) Dutch National Flag (low, mid, high) Unknown zone [mid..high] shrinks by 1 every step between sorted extremes.
    Cyclic shift by $k$ places in $\mathcal{O}(1)$ extra space 3-Step Block Reversal ($k \gets k \bmod n$) $(A^R B^R)^R = B A$: reversing blocks individually then globally swaps blocks without scrambling order.
    Missing / unpaired element in paired domain Bitwise XOR Cancellation $x \oplus x = 0$ and $x \oplus 0 = x$ cancel every duplicate pair in $\mathcal{O}(1)$ space with zero integer overflow.
    Contiguous subarray with exact sum $K$ (negatives allowed) Prefix Sum + Earliest-Index Map $P[r] - P[l] = K \iff P[l] = P[r] - K$; keeping earliest $l$ maximizes $r - l$ even across zeros.
    Contiguous subarray with exact sum $K$ (all elements $\ge 0$) Variable Sliding Window Window sum is monotonic in $l$ and $r$, dropping space from $\mathcal{O}(n)$ down to $\mathcal{O}(1)$.
    Maximum (or max-absolute) contiguous subarray sum Kadane's Reset Rule A negative running prefix never helps any future suffix; record ans first, then reset sum = 0 if sum < 0.
    Pair / boundary governed by $\min(\text{left}, \text{right})$ Opposite-End Two Pointers (l = 0, r = n - 1) The shorter wall is already bottlenecked; either its exact contribution is finalized (Rain Water) or all narrower partners are dominated (Container).
    Longest alternating-sign difference subsequence Greedy Peak / Valley Tracking Inside a monotonic run, keeping only the extreme endpoint widens the valid range for the next opposite step.
