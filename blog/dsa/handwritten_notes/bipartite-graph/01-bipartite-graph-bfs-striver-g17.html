    1. Definition & Cycle-Parity Diagrams (Page 1)

    Bipartite Graph (2-Colorability)

    A graph $G = (V, E)$ is bipartite if every vertex can be colored using one of two colors—0 and 1 in code (or labels 1 and 2 in the handwritten diagrams)—such that no two adjacent vertices share the same color:

    $$\forall (u, v) \in E, \quad \text{color}[u] \neq \text{color}[v]$$

    Page 1 draws two contrasting benchmark graphs—an even 6-cycle with linear tails on top versus an odd 5-cycle (pentagon) with tails underneath—to expose the exact structural law behind bipartiteness:

    Starred Observations on Page 1 (König's Theorem)

    1. Graphs without a cycle / linear graphs (trees & forests) are ALWAYS bipartite.
    2. Any graph whose cycles all have EVEN length is ALWAYS bipartite.
    3. Odd-Cycle Characterization: $G$ is bipartite $\iff G$ contains zero odd-length cycles.

    2. Progression: $2^V$ Brute Coloring $\to$ Deterministic $\mathcal{O}(V + 2E)$ BFS

    • Brute Force ($\mathcal{O}(2^V \cdot E)$): Trying every binary assignment color[0..V-1] in $\{0, 1\}^V$ is exponential—completely unnecessary because fixing color[start] = 0 at one vertex deterministically forces the color of every reachable vertex in its connected component!
    • Optimal BFS 2-Coloring (Pages 1–2):
      • Replace visited[] with color[V] initialized to -1 (uncolored).
      • Push only the vertex number into queue $Q$—unlike undirected cycle detection, we do not need to carry parent! Why? Because color[parent] was set to 1 - color[current], so color[parent] == color[current] is automatically false!
      • For each neighbor adj of popped current: if color[adj] == -1, set color[adj] = 1 - color[current] and enqueue adj; else if color[adj] == color[current], immediately return false.

    4. Clean C++, Python & Java Implementations

    // Bipartite Graph Check via Multi-Component BFS (LeetCode 785 / Striver G-17) — C++
class Solution {
    bool checkComponent(int start, const vector<vector<int>>& adj, vector<int>& color) {
        queue<int> q;
        q.push(start);
        color[start] = 0;

        while (!q.empty()) {
            int node = q.front();
            q.pop();

            for (int it : adj[node]) {
                if (color[it] == -1) {
                    // Uncolored neighbor: assign opposite color (0 -> 1, 1 -> 0) & explore
                    color[it] = 1 - color[node];
                    q.push(it);
                } else if (color[it] == color[node]) {
                    // Someone colored `it` with the SAME color on another path -> odd cycle!
                    return false;
                }
            }
        }
        return true;
    }

public:
    bool isBipartite(vector<vector<int>>& graph) {
        int V = graph.size();
        vector<int> color(V, -1);

        // Outer loop is mandatory for disconnected graphs!
        for (int i = 0; i < V; ++i) {
            if (color[i] == -1) {
                if (!checkComponent(i, graph, color)) return false;
            }
        }
        return true;
    }
};
    # Bipartite Graph Check via Multi-Component BFS (matching Page 1 pseudocode) — Python
from collections import deque

class Solution:
    def isBipartite(self, adjList: List[List[int]]) -> bool:
        V = len(adjList)
        color = [-1] * V

        for start in range(V):
            if color[start] != -1:
                continue
            color[start] = 0
            Q = deque([start])

            while Q:
                current = Q.popleft()
                currentColor = color[current]
                for adj in adjList[current]:
                    if color[adj] == -1:
                        color[adj] = 1 - currentColor
                        Q.append(adj)
                    elif color[adj] == currentColor:
                        return False
        return True

    5. Complexity Proof & Key Edge Cases

    • Time Complexity: $\mathcal{O}(V + 2E)$ — Identical to standard BFS (noted explicitly on Page 2: "Same time complexity as BFS"): every vertex transitions -1 → {0, 1} once and enters $Q$ once; every undirected edge is inspected from both endpoints.
    • Space Complexity: $\mathcal{O}(V)$ — color[V] array plus FIFO queue of size $\le V$.
    • Disconnected Components Trap: In LC 785, vertex 0 is often completely isolated (graph[0] = []) while {1, 2, 3} forms a triangle! Without the outer 0..V-1 loop (shown in Striver's Page 2 screenshot), starting only at 0 falsely returns true.
    • Self-Loops (u in adj[u]): A self-loop is a cycle of odd length $1$; when u scans adj = u, color[u] == color[u] immediately returns false.
