    LC 2742: Painting the Walls — From Greedy Ratio Failure to $1 + \text{time}[i]$ 0/1 Knapsack

    October 2026 · 8 min read · Handwritten Notes

    Expanded from handwritten competitive coding study note: 08_2742.pdf

    1. Problem Statement & Constraints

    You are given two 0-indexed integer arrays cost and time of length $n$ ($1 \le n \le 500$, $1 \le \text{cost}[i] \le 10^6$, $1 \le \text{time}[i] \le 500$) representing $n$ walls to paint using two painters:

    • Paid Painter: Paints wall $i$ in time[i] units of time for cost[i] units of money.
    • Free Painter: Paints any single wall in $1$ unit of time for $0$ money, but can only work while the paid painter is currently occupied!

    Return the minimum money required to paint all $n$ walls.

    2. Scratchpad Insight (08_2742.pdf): Why Greedy cost / time Fails

    In 08_2742.pdf, the first instinct we test on Example 1—cost = [1, 2, 3, 2], time = [1, 2, 3, 2] ($n = 4$)—is computing the unit rate:

    $$\frac{\text{cost}}{\text{time}} = [1, 1, 1, 1]$$

    Why Neither cost / time Nor cost / (1 + time) Greedy Works

    On cost = [1, 2, 3, 2], time = [1, 2, 3, 2], every wall has identical cost / time = 1, yet subset choices behave completely differently due to discrete capacity overshoot:

    • Paying for wall 2 alone (cost = 3, time = 3) keeps the paid painter busy for $3$ units while the free painter finishes the other $3$ walls $\implies 1 + 3 = 4$ walls for total cost $3$.
    • Paying for walls 1 and 3 (both cost = 2, time = 2) covers $(1 + 2) + (1 + 2) = 6 \ge 4$ walls, wasting $2$ units of unneeded free capacity for cost $4 \gt 3$!
    • Even sorting by cost / (1 + time) fails on cost = [2, 3, 4, 2], time = [1, 1, 2, 1] ($n = 4$): wall 2 has the best ratio $4 / 3 \approx 1.33$, forcing a second paid wall of cost $2$ (total $4 + 2 = 6$), whereas picking the two cost = 2, time = 1 walls covers $2 + 2 = 4$ walls for cost $4 \lt 6$!

    Whenever items have discrete weights and we want minimum cost to reach capacity $\ge n$ ($n \le 500$), we are looking straight at 0/1 Knapsack!

    3. Algebraic Reduction to Min-Cost 0/1 Knapsack

    The $1 + \text{time}[i]$ Coverage Transformation

    Suppose we assign a subset $S \subseteq \{0, 1, \dots, n - 1\}$ of walls to the paid painter, and assign the remaining $n - |S|$ walls to the free painter:

    • Total time the paid painter spends working is $\sum_{i \in S} \text{time}[i]$.
    • During that window, the free painter can complete at most $\sum_{i \in S} \text{time}[i]$ walls (at $1$ unit of time per wall).

    Therefore, a paid subset $S$ is valid if and only if:

    $$\sum_{i \in S} \text{time}[i] \ge n - |S| \iff \sum_{i \in S} \bigl(1 + \text{time}[i]\bigr) \ge n$$

    Physical Interpretation: Paying cost[i] for wall $i$ buys $w_i = 1 + \text{time}[i]$ total walls ($1$ wall painted by the paid painter $+ \text{time}[i]$ walls painted concurrently by the free painter)! We simply choose a subset of items of minimum total price whose weights sum to $\ge n$.

    4. Step-by-Step 1D Knapsack Dry Run on cost = [1, 2, 3, 2], time = [1, 2, 3, 2]

    Define dp[w] = minimum cost to cover at least $w$ walls ($0 \le w \le n$), initialized to dp = [0, ∞, ∞, ∞, ∞]. For each wall $i$ with coverage $c_i = 1 + \text{time}[i]$, update $w = n \to 1$ backwards via dp[w] = min(dp[w], dp[max(0, w - c_i)] + cost[i]):

    5. Clean C++ Implementation

    // LC 2742: Painting the Walls — 1D Min-Cost 0/1 Knapsack (O(n^2) Time, O(n) Space)
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int paintWalls(vector<int>& cost, vector<int>& time) {
        int n = (int)cost.size();
        const int INF = 1e9; // Max valid answer <= 500 * 10^6 = 5e8 < INF
        vector<int> dp(n + 1, INF);
        dp[0] = 0;

        for (int i = 0; i < n; ++i) {
            int cover = 1 + time[i]; // 1 paid wall + time[i] free walls
            for (int w = n; w > 0; --w) {
                int prev = max(0, w - cover); // Clamp overshoot to 0!
                dp[w] = min(dp[w], dp[prev] + cost[i]);
            }
        }
        return dp[n];
    }
};

    6. Complexity Proof & Key Edge Cases

    • Time Complexity — $\mathcal{O}(n^2)$: Outer loop over $n$ walls $\times$ inner loop over $n$ coverage states $= 500^2 = 2.5 \times 10^5$ transitions.
    • Space Complexity — $\mathcal{O}(n)$: Single 1D array dp of size $n + 1 \le 501$, iterating $w = n \to 1$ backwards so each wall is used at most once (0/1 constraint).
    • Key Edge Cases:
      • Single Slow Wall Covers Everything ($1 + \text{time}[i] \ge n$): Clamping prev = max(0, w - cover) maps directly to dp[0] + cost[i] = cost[i] without needing an array up to $\sum \text{time}[i] \approx 2.5 \times 10^5$!
      • Choosing INF Safely in C++: Worst-case valid answer is $500 \times 10^6 = 5 \times 10^8$ (all costs $10^6$). Setting INF = 1e9 guarantees INF > 5e8 (no false minimum) while INF + 1e6 < INT_MAX (zero signed 32-bit overflow!).
