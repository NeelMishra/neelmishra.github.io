    FAQ

    What is a projective dependency tree?

    A tree whose arcs do not cross when the words stay in sentence order. Some languages and some analyses need non-projective arcs. A parser that only builds projective trees cannot return those analyses.

    What is an oracle in transition-based parsing?

    A procedure that, given a gold tree, says which action the parser should have taken in a configuration. It creates training labels for the action classifier. It is not available at test time.

    How does graph-based parsing differ from left-to-right actions?

    It scores candidate arcs and searches for a tree, classically a maximum spanning tree. It does not have to commit to an early action before later words are scored.

    Does a correct unlabeled head mean the parse is right?

    Not if the evaluation includes labels. An arc can attach the right head and still have the wrong relation. Check which score the paper or chapter is reporting.
