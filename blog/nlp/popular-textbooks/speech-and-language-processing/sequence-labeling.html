    FAQ

    Why is an HMM a joint model of tags and words?

    It has a transition model over tags and an emission model from a tag to a word. Decoding searches for the tag sequence that best explains the observed words, not each word in isolation.

    What does Viterbi avoid?

    Enumerating every tag sequence. It keeps the best path into each tag at each position and reuses those partial paths.

    How is a CRF different from an HMM tagger?

    A CRF scores a tag sequence with features of the observation and the tags, and normalizes over tag sequences. It is not limited to the HMM's transition-plus-emission factorization.

    Does a correct entity type with the wrong span count as success?

    Not under a span-based named-entity score. The predicted span and type have to match the annotation. Token accuracy can hide span errors.
