    FAQ

    Does every noun phrase need a coreference link?

    No. Some expressions do not refer, and some mentions are the first introduction of an entity. Mention detection and antecedent selection are separate decisions.

    How is mention ranking different from mention-pair classification?

    A pair classifier scores one candidate link at a time. A ranker compares antecedent candidates for the same mention, including the choice to start a new entity. Those training signals are not the same.

    Is entity linking the same task as coreference?

    No. Coreference clusters mentions in a document. Entity linking maps a mention to an entry in an external inventory. A document cluster can be right while the inventory link is wrong.

    Why does the chapter treat gender bias as an evaluation issue?

    Coreference decisions can depend on stereotypes rather than the text. A score on a standard test set can hide systematically worse or skewed errors on gender contrasts.
