    FAQ

    Does a dictionary sense inventory define the only possible meanings?

    No. Inventories split senses differently. Word-in-context evaluation can compare uses without forcing a shared sense list.

    What does the Lesk baseline compare?

    Overlap between the context and a sense's definition or example. It is a baseline, not a neural disambiguator.

    Is a contextual embedding a sense label?

    No. It is a vector that can be used to choose a sense, or to decide that two uses match. The vector itself is not a WordNet synset.

    What is sense induction?

    Discovering clusters of uses from data instead of selecting from a fixed inventory. The clusters still need an evaluation. They are not automatically dictionary senses.
