    FAQ

    Does a strong word-sense classifier prove the model uses dictionary senses?

    No. It shows that the extracted vectors support that external classifier. The model may keep a useful distinction without using that sense inventory.

    A probe is perfectly accurate. What else should you ask?

    Whether the model's own output depends on that information. A readout can see a feature the rest of the computation ignores.

    Does the logit lens have to name the model's final answer?

    No. Later layers can change the hidden state. The lens applies the output map early. It is not the finished network.

    In an induction pattern, does the current position attend to a future copy?

    No. It attends backward to an earlier match. Information from that earlier position can then affect the next-token prediction.
