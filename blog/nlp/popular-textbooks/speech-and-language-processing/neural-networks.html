    FAQ

    Why does a stack of affine layers need a nonlinearity?

    Without one, the stack multiplies out to a single affine map. A hidden nonlinearity, such as ReLU, lets the response change by region of the input.

    Does a zero ReLU gradient mean that unit is useless forever?

    No. It means that unit was inactive for this input and these parameters. Another input can turn it on. A unit that never activates during training is a different problem.

    What is the computation graph for?

    It records the operations that produced the loss so each parameter can collect its local derivative. You do not differentiate the whole network as one opaque formula.

    What changes when the classifier reads embeddings instead of counts?

    The token's vector becomes a learned parameter. The token ID stays a lookup key. Gradient descent moves the vector, not the vocabulary index.
