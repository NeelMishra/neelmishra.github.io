    LLM.int8: isolate the outlier features

    October 2026 · 5 min read

    LLM.int8 addresses a failure of ordinary activation quantization: a few feature dimensions can have much larger magnitudes than the rest. A scale large enough to preserve those values gives ordinary features a coarse grid. Simply clipping the extremes can also be damaging, because those features contribute to the output rather than being disposable noise.

    First give each dot product its scales

    Write the layer as $Y=XW$, with $X$ shaped tokens by input features and $W$ shaped input features by output features. Vector-wise quantization gives each row of $X$ and each column of $W$ an absmax scale. For an ordinary dot product, integer codes accumulate in a wider integer type and the result is rescaled:

    $$\widehat Y_{ij}=s_{X,i}s_{W,j}\sum_k q_{X,ik}q_{W,kj}.$$

    This is more local than using one activation scale for an entire tensor, but it cannot solve an extreme feature inside a row. That row's largest activation still controls its step size. The paper's second ingredient is a mixed-precision decomposition along the shared feature axis.

    Split the inner dimension, not the tokens

    Let $O$ be the set of feature indices whose activation magnitudes cross an outlier threshold, and let $R$ contain the remaining indices. The exact decomposition is

    $$XW=X_{:,R}W_{R,:}+X_{:,O}W_{O,:}.$$

    LLM.int8 approximates the first term with its eight-bit path and computes the second with a higher-precision floating-point path, then combines them. An activation at one token can cause its whole feature column to enter the outlier set for that operation. This is not a rule that sends an entire token or all large weights to FP16.

    Why the split helps: a toy dot product

    Take $x=(0.2,-0.3,12)$ and $w=(1,2,0.5)$. Their exact dot product is $5.6$. A symmetric eight-bit activation grid with absmax 12 has step $12/127\approx0.09449$. It reconstructs the first two activations as about $0.18898$ and $-0.28346$. Holding weights exact to isolate activation error gives $0.18898-0.56693+6\approx5.62205$.

    Now put feature 3 on the floating-point path. The remaining activation scale is $0.3/127\approx0.002362$. The reconstructed first activation is $85(0.3/127)\approx0.200787$, and the second is exactly $-0.3$. The ordinary contribution becomes approximately $-0.399213$; add the outlier contribution $6$ to obtain $5.600787$. Actual LLM.int8 also quantizes the ordinary weights, so this example demonstrates the scale effect, not a complete implementation or accuracy guarantee.

    Thresholds are a runtime choice

    The paper uses an outlier threshold of 6 in its experiments. That value belongs to its method and evaluation, not to an invariant law of every model. Lowering the threshold routes more work through floating point; raising it leaves more extreme values on the integer grid. Inspect the distribution of outlier channels and evaluate the resulting accuracy rather than choosing a threshold from a memory target alone.

    Unlike methods that learn offline weight scales from a calibration corpus, this decomposition detects outliers from the activations being processed. Representative evaluation remains necessary: changing prompts or context length can change the outlier workload. There must also be suitable integer kernels, a working floating-point branch, and efficient gathering and recombination. Eight-bit storage does not make those costs disappear.

    Is this simply weight-only quantization?

    No. The ordinary matrix multiplication quantizes both weights and activations, while exceptional feature contributions remain floating point. “Mixed-precision W8A8 with an outlier path” is more informative than assuming every multiply is INT8.
