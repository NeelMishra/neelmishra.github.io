    GPTQ: the layer objective and compensation loop

    October 2026 · 3 min read

    Quantization grid vs. layer compensation

    A $b$-bit quantizer with scale $s$ and zero-point $z$ maps a floating-point weight $w_q$ onto a discrete grid:

    $$t = \operatorname{quant}(w_q) = s \cdot \Bigl(\operatorname{clip}\bigl(\lfloor w_q / s \rceil + z,\, 0,\, 2^b - 1\bigr) - z\Bigr).$$

    Round-to-nearest applies $\operatorname{quant}(\cdot)$ independently to every weight (using per-row or per-groupsize parameters $s, z$). GPTQ uses the same grid, but after rounding $w_q \to t$, it adjusts the remaining unquantized weights so the layer output changes as little as possible. Note that groupsize (columns sharing $s, z$) is independent of blocksize (columns batched together for solver updates).

    The layer output objective and its Hessian

    For one output channel $w \in \mathbb{R}^d$ and calibration activations $A \in \mathbb{R}^{n \times d}$ (or $X = A^{\mathsf T} \in \mathbb{R}^{d \times n}$ in the paper’s column-sample convention), the original output across $n$ tokens is $y = Aw^{(0)}$. Rounding coordinate $q$ to $t = \operatorname{quant}(w_q)$ without touching other weights shifts the output by:

    $$\Delta y = (t - w_q) A_{:,q} = -a A_{:,q}, \qquad a = w_q - t.$$

    Let $\delta \in \mathbb{R}^d$ be the weight update on the remaining free coordinates $F$, holding $\delta_q = t - w_q = -a$ fixed and keeping already-quantized coordinates at zero change. Expanding the squared output error $E(\delta) = \lVert A\delta\rVert_2^2$ and differentiating twice with respect to $\delta$ gives the $d \times d$ Hessian matrix $H$:

    $$E(\delta) = \lVert A\delta\rVert_2^2 = \delta^{\mathsf T}(A^{\mathsf T}A)\delta, \qquad \nabla_\delta E(\delta) = 2A^{\mathsf T}A\delta, \qquad H = \nabla_\delta^2 E(\delta) = 2A^{\mathsf T}A.$$

    In both PyTorch’s row-sample layout ($Y = AW^{\mathsf T}$) and the paper’s column-sample layout ($WX = WA^{\mathsf T} = Y^{\mathsf T}$), the Hessian is the same $d \times d$ input-feature correlation matrix (depending only on the calibration inputs, never on the weights of a specific row):

    $$WX = WA^{\mathsf T} = Y^{\mathsf T}, \qquad H = 2A^{\mathsf T}A = 2XX^{\mathsf T} \in \mathbb{R}^{d \times d}, \qquad H_{ij} = 2\sum_{s=1}^{n} A_{s,i} A_{s,j}.$$

    Because $E(\delta) = \tfrac{1}{2}\delta^{\mathsf T} H \delta$, GPTQ’s compensation step on the free coordinates $F$ is the constrained quadratic minimization:

    $$\min_{\delta_F:\,e_q^{\mathsf T}\delta_F + a = 0}\;\frac{1}{2}\delta_F^{\mathsf T} H_F \delta_F = \min_{\delta_F:\,\delta_q = t - w_q}\;\lVert A_F\delta_F\rVert_2^2,$$

    whose closed-form Lagrangian solution $\delta_F = -\frac{a}{(G_F)_{qq}}(G_F)_{:,q}$ (with $G_F = H_F^{-1}$) is derived in Part 2.

    OBQ vs. GPTQ: why fixed column order matters

    Optimal Brain Quantization (OBQ) greedily selects whichever remaining weight $q \in F$ in a row incurs the smallest compensated error, so each output row quantizes columns in a different order and requires its own active inverse $G_F = H_F^{-1}$. GPTQ quantizes all output rows in the same fixed column order: because every output row receives the same calibration input matrix $A$, all rows share the same free set $F$, the same Hessian $H = 2A^{\mathsf T}A$, and one inverse-Cholesky factorization (Part 3).

    The GPTQ loop

    1. Collect calibration inputs $A \in \mathbb{R}^{n \times d}$ from a forward pass on representative tokens.
    2. Factor the shared damped inverse Hessian $U^{\mathsf T}U = G = (H + \lambda I_d)^{-1}$ once for the layer.
    3. Round column $q$: set $\widehat W_{:,q} = \operatorname{quant}(W_{:,q})$ across all $m$ output rows using the current compensated weights.
    4. Compensate remaining columns: update unquantized columns in the current block using the shared direction from $U$ to minimize $\lVert A_F\delta_F \rVert_2^2$.
    5. Advance across blocks: apply deferred outer updates at each block boundary until all $d$ columns are quantized.

    In Part 2’s 3-weight check, rounding $w_1 = -0.85 \to -1$ alone gives $\lVert A\delta \rVert_2^2 = 0.05265$; compensating the other two weights drops the error to $0.003090$.

    Does calibration retrain the model?

    No. GPTQ solves a local layer-output least-squares problem without backpropagation or gradient descent on the training loss.
