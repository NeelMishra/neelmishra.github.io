    AWQ: scale fusion, weight clipping, and W4A16 execution

    October 2026 · 6 min read

    In the main AWQ guide, we derived how scaling each input channel by $s = s_X^{\,\alpha}$ before rounding shrinks the quantization error of high-activation channels by $\frac{\Delta'}{\Delta}\cdot\frac{1}{s_c}$, and how a 20-point grid search over $\alpha \in [0, 1]$ finds the optimal scale vector $s^*$.

    This companion post covers the three engineering steps that turn $s^*$ into a fast deployed checkpoint in the official llm-awq pipeline:

    1. Scale fusion (auto_scale): how to absorb the inverse scale $(s^*)^{-1}$ into the preceding Transformer operation so inference pays zero runtime cost.
    2. Weight clipping search (auto_clip): how a second 20-point grid search trims non-salient weight outliers inside each quantization group.
    3. W4A16 kernel execution: how packed 4-bit weights are dequantized on the fly inside GPU registers during matrix multiplication.

    1. Scale fusion: absorbing $S^{-1}$ into the Transformer block

    For a linear layer computing $Y = W X$ (with $W \in \mathbb{R}^{D \times C}$ and input $X \in \mathbb{R}^{C \times N}$), AWQ replaces the layer with

    $$\widehat{Y} = Q(W S)\,(S^{-1} X), \qquad S = \operatorname{diag}(s_1^*, \dots, s_C^*).$$

    If we had to multiply the activation vector $X$ by $S^{-1}$ at runtime before every linear layer, we would add an extra elementwise kernel launch. Instead, AWQ folds $S^{-1}$ offline into whichever operation produces $X$. In a standard Transformer block (such as LLaMA or Mistral), there are four linear sub-blocks per layer:

    How AWQ shares and fuses channel scales $s^*$ across the four linear sub-blocks of a Transformer layer.
    Linear consumer(s)Shared scale search objectiveWhere $(s^*)^{-1}$ is fused offline
    Attention $W_q, W_k, W_v$Search one shared $s^*$ minimizing $\lVert \widehat{W}_{qkv} X - W_{qkv} X \rVert_F^2$ across all three projections simultaneously.Divide the preceding attention RMSNorm scale vector: $\gamma_{\mathrm{attn}} \leftarrow \gamma_{\mathrm{attn}} \oslash s^*$.
    Attention output $W_o$Search $s^*$ minimizing $\lVert \widehat{W}_o X_{\mathrm{attn}} - W_o X_{\mathrm{attn}} \rVert_F^2$.Divide the output rows of $W_v$: $W_v \leftarrow \operatorname{diag}(s^*)^{-1} W_v$.
    MLP $W_{\mathrm{gate}}, W_{\mathrm{up}}$Search one shared $s^*$ minimizing combined reconstruction error of both gate and up projections.Divide the preceding MLP RMSNorm scale vector: $\gamma_{\mathrm{mlp}} \leftarrow \gamma_{\mathrm{mlp}} \oslash s^*$.
    MLP $W_{\mathrm{down}}$Search $s^*$ minimizing $\lVert \widehat{W}_{\mathrm{down}} X_{\mathrm{act}} - W_{\mathrm{down}} X_{\mathrm{act}} \rVert_F^2$ after $\operatorname{SiLU}(W_{\mathrm{gate}}X)\odot(W_{\mathrm{up}}X)$.Divide the output rows of $W_{\mathrm{up}}$: $W_{\mathrm{up}} \leftarrow \operatorname{diag}(s^*)^{-1} W_{\mathrm{up}}$.

    Why must $W_q$, $W_k$, and $W_v$ share a single scale vector $s^*$? Because all three projections read the exact same output tensor from the attention RMSNorm. Searching one $\alpha^*$ for the stacked matrix $W_{qkv} = [W_q; W_k; W_v]$ allows a single modification $\gamma_{\mathrm{attn}} \leftarrow \gamma_{\mathrm{attn}} \oslash s^*$ to feed all three matrices without duplicating the normalization layer.

    2. Per-group weight clipping search (auto_clip)

    Activation-aware scaling protects channels whose activations are large. What if a quantization group $g$ contains a single large weight $w_m$ whose input activation $x_m$ is small? That single weight stretches the group's step size $\Delta = \max_{j \in g}|w_j| / (2^{b-1}-1)$, coarsening the grid for all $G = 128$ weights in the group even though $w_m$ itself barely contributes to the output.

    After applying $s^*$, AWQ runs a second lightweight grid search called weight clipping on each group $g$. For a clipping ratio $\gamma \in (0, 1]$, define the clipped quantizer $Q_\gamma$ on group $g$ with original maximum $M_g = \max_{j \in g}|w_j|$:

    $$\Delta_g(\gamma) = \frac{\gamma M_g}{2^{b-1}-1}, \qquad Q_\gamma(w_j) = \Delta_g(\gamma)\cdot\operatorname{clip}\!\left(\operatorname{round}\!\left(\frac{w_j}{\Delta_g(\gamma)}\right),\, -(2^{b-1}-1),\, 2^{b-1}-1\right).$$
    Algorithm 2: AWQ Per-Group Weight Clipping Search (auto_clip)
    1. Inputs: scaled weight group $w_g \in \mathbb{R}^{1 \times G}$, corresponding calibration activations $X_g \in \mathbb{R}^{G \times N}$, grid steps $K = 20$.
    2. Compute the unclipped group maximum $M_g = \max_{j \in g}|w_j|$ and exact group contribution $y_g = w_g X_g \in \mathbb{R}^{1 \times N}$.
    3. Grid-search $\gamma \in [0.5, 1.0]$: initialize $\mathcal{E}_{\min} = \infty$. For $k = 0, 1, \dots, K$:
      • Set $\gamma = 1.0 - 0.5\frac{k}{K} \in [0.5, 1.0]$.
      • Compute $\widehat{w}_g(\gamma) = Q_\gamma(w_g)$ using the clipped bound $\gamma M_g$.
      • Measure group output MSE: $\mathcal{E}(\gamma) = \lVert \widehat{w}_g(\gamma) X_g - y_g \rVert_2^2$.
      • If $\mathcal{E}(\gamma) < \mathcal{E}_{\min}$, update $\mathcal{E}_{\min} \leftarrow \mathcal{E}(\gamma)$ and $\gamma_g^* \leftarrow \gamma$.
    4. Output: clamp $w_g$ to $[-\gamma_g^* M_g,\, +\gamma_g^* M_g]$ and quantize with step size $\Delta_g(\gamma_g^*)$.

    Numerical check of weight clipping. Suppose a 4-bit group ($-7$ to $7$) has weights $w_g = [0.24,\, -0.26,\, 0.70]$ and activations $x_g = [5.0,\, 5.0,\, 0.2]^{\mathsf T}$. Notice that the largest weight $w_3 = 0.70$ has a tiny activation ($0.2$), while the smaller weights $w_1, w_2$ have large activations ($5.0$). The exact dot product is $y_g = 0.24(5.0) - 0.26(5.0) + 0.70(0.2) = 1.20 - 1.30 + 0.14 = 0.04$.

    • Unclipped ($\gamma = 1.0$): Group max is $M_g = 0.70 \implies \Delta = 0.70 / 7 = 0.10$. The weights round to $[0.20,\, -0.30,\, 0.70]$, giving $\widehat{y}_g(1.0) = 0.20(5.0) - 0.30(5.0) + 0.70(0.2) = -0.36$ (squared error $(-0.36 - 0.04)^2 = \mathbf{0.1600}$).
    • Clipped at $\gamma^* = 0.5$: Clamping the group max to $0.5 \times 0.70 = 0.35$ halves the step size to $\Delta' = 0.35 / 7 = 0.05$. Now $w_1 = 0.24$ rounds to $0.25$, $w_2 = -0.26$ rounds to $-0.25$, and $w_3 = 0.70$ clips to $0.35$. The reconstructed output is $\widehat{y}_g(0.5) = 0.25(5.0) - 0.25(5.0) + 0.35(0.2) = 0.07$ (squared error $(0.07 - 0.04)^2 = \mathbf{0.0009}$—a $177\times$ reduction in error).

    Note: In llm-awq, auto_clip is applied to all linear layers except query and key projections ($W_q, W_k$), where extreme weight entries can participate directly in attention logit scaling.

    3. W4A16 execution: why uniform INT4 beats mixed precision

    During inference, an AWQ checkpoint stores two tensors per linear layer:

    • Packed 4-bit weights $W_q$: eight 4-bit integers packed into each 32-bit word (int32).
    • Group metadata: one FP16 step size $\Delta_g$ and one 4-bit zero-point $z_g$ for every group of $G = 128$ weights (adding $20 / 128 \approx 0.156$ bits per weight, for an effective footprint of $4.156$ bits per weight).

    During single-batch decoding, LLM inference is memory-bandwidth bound: the GPU spends most of its time loading weight matrices from HBM into SRAM/registers rather than performing arithmetic. Because AWQ folded $(s^*)^{-1}$ into the preceding layer and kept every weight in uniform 4-bit groups, the W4A16 kernel loads $4\times$ fewer bytes from HBM, unpacks each 4-bit integer to FP16 inside registers via $\widehat{w}_j = (q_j - z_g)\Delta_g$, and immediately multiplies by the FP16 activation via Tensor Cores.

    Does scaling a channel change the number of bits stored for that channel?

    No. Every channel in an AWQ checkpoint is stored using the exact same number of bits (such as 4 bits). Salient channels gain higher effective precision because multiplying by $s_c > 1$ lets them span more integer steps of their group's 4-bit grid before being divided back by $s_c$.
