    Transformers: From the First Attention Calculation to Hybrid Language Models

    Updated September 2026 · 10 min read

    ∑ Read the explanation
    Learn the model as a sequence of decisions. Begin with one attention calculation, assemble a complete causal decoder, then ask what changes when context grows: computation, cached memory, retrieval, feed-forward capacity, and connections across depth.

    Choose your starting point

    If Transformers are new, begin with the Foundations model diagram. The same clickable diagram appears in all eight foundation chapters, highlighting the component you are learning and connecting it to the rest of the decoder. If you know Q/K/V but struggle to connect the pieces, follow it through GPT-2 as a complete language model. If you can already implement a decoder, jump to prefill, decode, and complexity.

    The chapters use original worked examples, explicit shapes, diagrams, and small interactive experiments. Definitions live in one main chapter and are linked from later ones. Model-specific facts link to original papers or official implementations; numerical examples are labelled as illustrations unless they come from an actual configuration.

    A coherent route into modern language models

    1. Build the reference model. Attention → the residual block → GPT-2 → training.
    2. Understand growing history. The quadratic problem → KV caching → head sharing → latent attention.
    3. Replace token history with a recurrent state. Linear attention → DeltaNet → Gated DeltaNet → KDA.
    4. Compose a modern model. Hybrid attention → MoE → AttnRes → Kimi K3.
    5. Verify and compare. Use the math lab, then the evolution and comparison map.

    Keep the notation steady

    $n$ denotes sequence length, $d$ residual width, $H$ head count, and $d_k,d_v$ the key/query and value widths. Batched arrays add a leading $B$ dimension. Token vectors are rows in attention matrices. Recurrent update chapters explicitly use column key vectors and $S\in\mathbb R^{d_k\times d_v}$, so the read is $S^\top q$.

    Cache estimates state layer count, head count, scalar precision, and whether the budget is per sequence or per batch. Arithmetic estimates distinguish MACs from FLOPs. These conventions make comparisons across chapters meaningful.

    Transformer Foundations: Follow the Model Diagram

    Follow one clickable transformer diagram through all eight foundation chapters, with the current component highlighted and clear connections from token IDs to next-token predictions.

     Transformer Math Lab: Test the Identities Behind the Diagrams

    Foundations

    Token Embeddings: Just a Table Lookup

    See how cat sat cat becomes token IDs and vectors, click tokens to trace a lookup, and learn what the embedding table does in a few lines of PyTorch.

     Attention from First Principles: One Complete Calculation

    Work through queries, keys, stable softmax, masking, weighted values, gradients, and tensor shapes using a numerical example that can be reproduced.

     Multi-Head Attention: Separate Reads, One Residual Update

    Follow split, attend, concatenate, and project with exact shapes; understand what extra heads change and what they do not guarantee.

     Causal Attention: The Information Boundary

    Derive the causal mask from next-token likelihood, implement offset masks for cached decoding, and test that future tokens cannot change earlier outputs.

     Feed-Forward Networks: Expansion, Nonlinearity, and Gates

    Derive the position-wise MLP, understand why its nonlinear expansion matters, and compare GELU and SwiGLU at matched parameter budgets.

     LayerNorm, RMSNorm, and Residual Scale

    Compute normalization by hand, distinguish feature-wise statistics from batch statistics, and derive what pre-norm residual paths do and do not guarantee.

     A Transformer Block, Line by Line

    Trace a pre-norm block through attention, residual addition, normalization, and an MLP, with shapes, parameter counts, and causal correctness conditions.

     Dropout: What Is Random, What Is Preserved

    Derive inverted dropout, distinguish activation and attention dropout, and understand expectation, variance, evaluation mode, and reproducibility.

    Position and architecture

    Position Encodings: Order Must Enter Somewhere

    Derive why attention is permutation equivariant, compute sinusoidal positions, and compare additive absolute encodings with relative attention mechanisms.

     RoPE: Relative Position Through Rotated Queries and Keys

    Derive the relative-position identity for rotary embeddings, compute a two-dimensional example, and understand frequency schedules, caching, and length extension.

     ALiBi: A Distance Bias in Attention Logits

    Derive causal linear position biases, calculate their effect on probability ratios, and separate recency preference from content matching and length generalization.

     Cross-Attention: Queries Read a Different Sequence

    Trace a rectangular attention matrix, source/target dimensions, encoder–decoder conditioning, multimodal inputs, and reusable source caches.

    Attention and memory

    The Quadratic Problem: Prefill, Decode, and a Complexity Explorer

    Count attention operations, score storage, KV bytes, and recurrent state with explicit assumptions, then explore which costs grow during prefill and decoding.

     KV Caching: Why the Prefix Can Stay Put

    Derive cached autoregressive decoding from causality, account for memory and per-token work, and distinguish prefill, cache reuse, and output generation.

     MHA, MQA, and GQA: Sharing the KV Cache

    Derive query-to-KV grouping, cache bytes, projection counts, and the tradeoffs between independent and shared keys and values.

     Multi-Head Latent Attention: Derive the Compressed Cache

    Derive joint KV compression, absorb key/value projections algebraically, account for the positional cache, and distinguish latent attention from head sharing.

     Sparse Attention: Windows, Global Tokens, and Information Paths

    Compare local, global, dilated, and block patterns as graphs; derive their edge counts and receptive fields without confusing a dense mask with a sparse kernel.

    Recurrent and hybrid models

    Linear Attention: From Pairwise Reads to a Recurrent State

    Derive normalized kernel attention, its parallel and recurrent forms, state dimensions, and why reassociation does not preserve ordinary softmax attention.

     DeltaNet: Write the Error, Not Another Copy

    Derive the delta-rule state update as gradient descent on an association, analyze overwrite behavior and key interference, and connect recurrence to chunkwise training.

     Gated DeltaNet: Forget Globally, Update Selectively

    Separate state decay from delta-rule learning, derive the order of operations, and measure retention over time with a controlled example.

     Kimi Delta Attention: Channel-Wise Memory Control

    Derive KDA from a diagonal forget gate and a delta update, inspect noncommuting transitions, and distinguish the recurrent core from a complete KDA layer.

     Hybrid Attention: Combine Retrieval with Recurrent Memory

    Follow the data flow and cache budget of a stack that alternates recurrent updates with token-addressable attention.

    Architecture and model families

    Transformer Architectures: Choose the Information Flow

    Compare encoder-only, decoder-only, and encoder-decoder graphs using the same source and target sequence, then separate architecture from training objective.

     The Transformer Encoder: Context, Padding, and Task Heads

     The Transformer Decoder: From a Prefix to the Next Token

     GPT-2 as a Starting Point: Build the Whole Language Model

     BERT: Learn Bidirectional Representations by Reconstructing Tokens

    Explain why bidirectional attention needs a reconstruction target, how the original masking policy works, and what BERT does and does not define as a generative model.

     Vision Transformers: Turn an Image into a Sequence of Patches

    Trace patch extraction and projection, positional information, classification, resolution changes, and the cost of smaller patches.

     Mixture of Experts: Conditional MLPs and the Cost of Routing

    Derive top-k expert routing, distinguish active from total parameters, and trace dispatch, balancing, shared experts, and latent expert spaces.

     Attention Residuals: Let a Layer Choose Its Sources Across Depth

     Kimi K3: Read a Modern Hybrid Model from Its Configuration

    Connect KDA, NoPE MLA, latent MoE, and block Attention Residuals using the July 2026 report and a pinned official model configuration.

    Efficient execution

    FlashAttention: Exact Softmax Without the Full Matrix

    Derive online softmax and mergeable attention statistics, work through a numerical example, and separate arithmetic, activation storage, and memory traffic.

     FlashAttention-2 and -3: From Algebra to GPU Scheduling

    Separate online-softmax correctness from work partitioning, GPU occupancy, asynchronous pipelines, and FP8 quantization in later FlashAttention implementations.

     PagedAttention: Manage the Cache Without Moving the Sequence

    Explain logical versus physical KV blocks, allocation waste, prefix sharing, copy-on-write, and the boundary between memory management and attention mathematics.

     Ring Attention: Distributed Reads with Online Softmax

    Derive how local queries attend to circulating key/value shards, why per-shard outputs cannot simply be averaged, and when communication can overlap computation.

     Speculative Decoding: Draft, Verify, and Correct

    Derive exact acceptance and residual sampling, work through a three-token distribution, and understand multi-token verification, cache rollback, and speed limits.

    Training

     Training a Transformer: Targets, Gradients, Batches, and Evaluation

    Trace shifted next-token targets through cross-entropy, masked loss reduction, AdamW, accumulation, and held-out evaluation.
