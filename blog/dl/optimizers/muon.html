    Muon, Part 1: A Matrix Has More Than Coordinates

    September 2026 · 6 min read + interactive lab

    Jump to the loss-contour trajectory demo ↓

    Understand singular directions, why orthogonalizing the momentum matrix equalizes singular values, and which parameters belong in Muon.

    Coordinate-wise optimizers (Adam, RMSprop, Lion) treat a weight matrix $W\in\mathbb R^{m\times n}$ as a flat list of $mn$ independent numbers. Muon instead treats $W$ as a linear map: it accumulates a momentum matrix $M_t$, then replaces $M_t=U\Sigma V^\top$ with its orthogonal polar factor $Q_t=UV^\top$ so that every active singular direction takes an equal-sized step.

    1. Why a linear layer’s gradient has skewed singular values

    For a linear layer $y=Wx$ ($W\in\mathbb R^{m\times n}$) and a batch of $B$ examples, let $\delta_b=\partial\ell_b/\partial y_b\in\mathbb R^m$ be the backpropagated output gradient. The batch gradient is a sum of rank-$1$ outer products:

    $$G=\frac{\partial\ell}{\partial W}=\frac{1}{B}\sum_{b=1}^B\delta_b x_b^\top.$$

    Write the singular value decomposition (SVD) of the momentum-filtered gradient matrix $M\in\mathbb R^{m\times n}$ of rank $r\le\min(m,n)$:

    $$M=U\Sigma V^\top=\sum_{i=1}^r\sigma_i u_i v_i^\top,\qquad\sigma_1\ge\sigma_2\ge\cdots\ge\sigma_r>0.$$

    Here $v_i\in\mathbb R^n$ are orthonormal input directions, $u_i\in\mathbb R^m$ are orthonormal output directions, and $\sigma_i$ measures how strongly $M$ stretches $v_i$ into $u_i$. In neural networks, activations $x_b$ and gradients $\delta_b$ concentrate along a few dominant directions, making $\sigma_1\gg\sigma_r$. A raw momentum step $\Delta W=-\eta M=-\eta\sum_{i=1}^r\sigma_i u_i v_i^\top$ updates the dominant direction $\sigma_1 u_1 v_1^\top$ aggressively while barely moving weaker directions $(\sigma_i\ll\sigma_1)$.

    2. The idealized polar update: $\Sigma\to I$

    Muon replaces every nonzero singular value $\sigma_i$ with $1$, mapping $M$ to its orthogonal polar factor $Q$:

    $$\begin{aligned}\text{Raw momentum:}\quad M&=U\Sigma V^\top=\sum_{i=1}^r\sigma_i u_i v_i^\top,\\\text{Muon polar factor:}\quad Q&=\operatorname{polar}(M)=UV^\top=\sum_{i=1}^r 1\cdot u_i v_i^\top.\end{aligned}$$

    For a full-rank matrix ($r=\min(m,n)$), $Q$ is orthogonal if square and semi-orthogonal if rectangular:

    $$Q^\top Q=I_n\quad(\text{tall, }m\ge n),\qquad QQ^\top=I_m\quad(\text{wide, }m\le n).$$
    Muon orthogonalizes the update $\Delta W$, not the weight matrix $W$

    Updating $W_t=W_{t-1}-\eta Q_t$ adds a semi-orthogonal step $-\eta Q_t$ to $W_{t-1}$; the sum $W_t$ itself does not need to stay orthogonal.

    3. Derivation: steepest descent under the spectral norm $\|D\|_2$

    Why is $Q=UV^\top$ the natural matrix step? For a linear layer $\Delta y=(D)x$, the maximum output change produced by a unit input vector $\|x\|_2=1$ is governed by the spectral norm (largest singular value) $\|D\|_2=\max_{\|x\|_2=1}\|Dx\|_2=\sigma_{\max}(D)$.

    Seek the matrix step $D\in\mathbb R^{m\times n}$ that minimizes the first-order loss change $\langle M,D\rangle_F=\operatorname{tr}(M^\top D)$ subject to a spectral-norm budget $\|D\|_2\le\eta$. Substitute $M=U\Sigma V^\top$ and define $\widetilde D=U^\top DV$:

    $$\langle M,D\rangle_F=\operatorname{tr}\!\bigl((U\Sigma V^\top)^\top D\bigr)=\operatorname{tr}\!\bigl(\Sigma(U^\top DV)\bigr)=\sum_{i=1}^r\sigma_i\widetilde D_{ii}.$$

    Because $U$ and $V$ have orthonormal columns, $|\widetilde D_{ii}|=|u_i^\top Dv_i|\le\|D\|_2\le\eta$ for every $i$. Since each $\sigma_i>0$, the sum is minimized by setting every diagonal entry to its lower bound $\widetilde D_{ii}=-\eta$ (and off-diagonals to $0$), giving $\widetilde D=-\eta I_r$:

    $$D^\star=U\widetilde DV^\top=-\eta UV^\top,\qquad\langle M,D^\star\rangle_F=-\eta\sum_{i=1}^r\sigma_i=-\eta\|M\|_*.$$

    Different norm budgets on $D$ yield three classic optimizer families:

    $$\begin{aligned}\text{Frobenius norm }\|D\|_F\le\eta\text{ (SGD/Momentum):}\quad D^\star&=-\eta\frac{M}{\|M\|_F},\\\text{Entrywise norm }\|D\|_\infty\le\eta\text{ (SignSGD/Lion):}\quad D^\star&=-\eta\operatorname{sign}(M),\\\text{Spectral norm }\|D\|_2\le\eta\text{ (Muon):}\quad D^\star&=-\eta UV^\top.\end{aligned}$$

    6. Complete Muon update, aspect-ratio scaling, and state memory

    Combining momentum $B_t$, optional Nesterov lookahead $\widetilde B_t$, polynomial orthogonalization (derived in Part 2), and decoupled weight decay $\lambda$ gives the full Muon update for a weight matrix $W_t\in\mathbb R^{m\times n}$:

    $$\begin{aligned}B_t&=\beta B_{t-1}+G_t,\\ \widetilde B_t&=\begin{cases}G_t+\beta B_t&\text{(Nesterov = True)}\\B_t&\text{(Nesterov = False)}\end{cases},\\ Q_t&=\operatorname{NewtonSchulz}_5\!\left(\frac{\widetilde B_t}{\|\widetilde B_t\|_F+\epsilon}\right)\approx UV^\top,\\ W_t&=(1-\eta\lambda)W_{t-1}-\eta\sqrt{\max\!\left(1,\frac{m}{n}\right)}\,Q_t.\end{aligned}$$

    Notice two scale properties:

    • Scale invariance of the input: for any scalar $c>0$, $\operatorname{polar}(c\widetilde B_t)=\operatorname{polar}(\widetilde B_t)$, so EMA momentum $(1-\beta)G_t+\beta B_{t-1}$ and heavy-ball momentum $G_t+\beta B_{t-1}$ yield the exact same normalized matrix $\widetilde B_t/\|\widetilde B_t\|_F$.
    • Aspect-ratio factor $\sqrt{\max(1,m/n)}$ (or $\sqrt{m/n}$): an exact full-rank polar factor $Q\in\mathbb R^{m\times n}$ has $\min(m,n)$ unit singular values, so $\|Q\|_F=\sqrt{\min(m,n)}$ and its root-mean-square entry size is $\|Q\|_F/\sqrt{mn}=1/\sqrt{\max(m,n)}$. Multiplying by $\sqrt{\max(1,m/n)}$ prevents tall layers ($m\gg n$) from receiving tiny per-coordinate updates.
    # Conceptual matrix-only Muon step (Newton-Schulz derived in Part 2)
B = beta * B + grad
B_tilde = grad + beta * B if nesterov else B
Q = newton_schulz_5(B_tilde)
scale = max(1.0, rows / cols) ** 0.5
W *= 1 - lr * weight_decay
W -= lr * scale * Q

    Optimizer state memory: Unlike AdamW (which stores two buffers $m_t$ and $v_t$, $+8\text{ bytes/parameter}$ in FP32), Muon stores only one state number per parameter—the momentum buffer $B_t$ ($+4\text{ bytes/parameter}$ in FP32, matching SGD with Momentum)—because the orthogonalized direction $Q_t$ is computed on the fly via matrix multiplications.

    7. Parameter routing: why embeddings and heads still use AdamW

    Muon is designed specifically for dense hidden-layer weight matrices (such as MLP projections and attention $W_Q,W_K,W_V,W_O$). Other parameters must be routed to AdamW:

    • 1D parameters (biases, RMSNorm/LayerNorm gains): have no 2D row-column linear map structure.
    • Token embeddings: for a one-hot token input $x=e_k$, the gradient $G=\delta e_k^\top$ is nonzero only on row $k$; rows represent separate vocabulary items rather than a dense basis to orthogonalize.
    • Unembedding / classification head: maps hidden states directly to vocabulary logits, where coordinate-wise second-moment adaptation in AdamW remains standard.

    8. Questions worth answering

    How does Muon differ from dividing the gradient matrix by its Frobenius norm $\|M\|_F$?

    Dividing by $\|M\|_F=\sqrt{\sum_i\sigma_i^2}$ rescales all singular values by the same scalar, keeping their skewed ratios $\sigma_1/\sigma_i$ unchanged. Muon sets all nonzero singular values to $1$, equalizing step sizes across all active singular directions.

    Why doesn’t Muon compute an exact SVD (`torch.linalg.svd`) on every step?

    Full SVD on large matrices is slow on GPUs and poorly suited to low-precision Tensor Core matmuls. Part 2 shows how $5$ steps of a quintic Newton–Schulz matrix polynomial approximate $UV^\top$ using fast `bfloat16` matrix multiplications.
