    Muon, Part 1: A Matrix Has More Than Coordinates

    September 2026 · 6 min read + interactive lab

    Jump to the loss-contour trajectory demo ↓

    Why treating a 2D weight matrix as a flat list of numbers starves most learning directions—and how Muon fixes it by setting every active singular value of the update to $1$.

    Optimizers like SGD, RMSprop, Adam, and Lion treat a weight matrix $W\in\mathbb R^{m\times n}$ as a flat list of $mn$ independent numbers, updating each entry $W_{ij}$ on its own. Muon (MomentUm Orthogonalized by Newton–schulz) instead treats $W$ as a 2D transformation: it accumulates a momentum matrix $M_t$, then equalizes its singular values so every active direction of the layer takes a step of the exact same size.

    01 · MOMENTUMSmooth the gradientAccumulate the 2D batch gradient $G_t$ into a momentum matrix $M_t$.
    02 · DIRECTIONSView as $M_t = U\Sigma V^\top$Every matrix is a set of perpendicular directions stretched by singular values $\sigma_i$.
    03 · ORTHOGONALIZESet every $\sigma_i \to 1$Replace $\Sigma$ with $I$ to get $Q_t = UV^\top$ (approximated fast via Newton–Schulz).
    04 · UPDATEStep along $Q_t$Update the 2D weight matrix: $W_t = W_{t-1} - \eta\,\text{scale}\cdot Q_t$.

    1. The problem: one loud direction drowns out the rest

    A linear layer $y=Wx$ multiplies an input vector $x\in\mathbb R^n$ by a weight matrix $W\in\mathbb R^{m\times n}$ to produce an output vector $y\in\mathbb R^m$. Any momentum matrix $M\in\mathbb R^{m\times n}$ (of rank $r\le\min(m,n)$) can be written via the Singular Value Decomposition (SVD) as a sum of perpendicular directions:

    $$M=U\Sigma V^\top=\sum_{i=1}^r\sigma_i u_i v_i^\top,\qquad\sigma_1\ge\sigma_2\ge\cdots\ge\sigma_r>0.$$

    Each term $\sigma_i u_i v_i^\top$ has three simple parts:

    • Input direction $v_i\in\mathbb R^n$: a unit vector in the layer’s input space (all $v_i$ are mutually perpendicular: $V^\top V=I$).
    • Output direction $u_i\in\mathbb R^m$: a unit vector in the layer’s output space (all $u_i$ are mutually perpendicular: $U^\top U=I$).
    • Singular value $\sigma_i>0$: the stretch factor measuring how strongly $M$ pushes input direction $v_i$ toward output direction $u_i$.

    Why are the singular values $\sigma_i$ so skewed in neural networks? For a batch of $B$ examples with input activations $x_b$ and backpropagated output gradients $\delta_b=\partial\ell_b/\partial y_b$, the batch gradient is a sum of outer products:

    $$G=\frac{\partial\ell}{\partial W}=\frac{1}{B}\sum_{b=1}^B\delta_b x_b^\top.$$

    In real networks, activations $x_b$ and gradients $\delta_b$ concentrate heavily along a few dominant directions. As a result, the top singular value $\sigma_1$ is huge while the remaining singular values are tiny ($\sigma_1\gg\sigma_2\gg\cdots\gg\sigma_r$). If you update with raw momentum $\Delta W=-\eta M$, the optimizer takes a giant step along the single loudest direction $\sigma_1 u_1 v_1^\top$ while barely moving the quieter directions that still carry useful learning signal.

    2. Muon’s fix: set every active singular value to $1$

    Muon keeps the input and output directions $(U,V)$ of the momentum matrix intact, but replaces every nonzero singular value $\sigma_i$ with $1$. In linear algebra, this matrix $Q=UV^\top$ is called the orthogonal polar factor of $M$:

    $$\begin{aligned}\text{Raw momentum:}\quad M&=U\Sigma V^\top=\sigma_1 u_1 v_1^\top+\sigma_2 u_2 v_2^\top+\cdots+\sigma_r u_r v_r^\top,\\\text{Muon update:}\quad Q&=\operatorname{polar}(M)=UV^\top=1\cdot u_1 v_1^\top+1\cdot u_2 v_2^\top+\cdots+1\cdot u_r v_r^\top.\end{aligned}$$

    Think of $Q=UV^\top$ as the matrix version of the $\operatorname{sign}(\cdot)$ function: just as $\operatorname{sign}(g)$ normalizes every nonzero scalar to $\pm 1$, Muon normalizes every nonzero singular value $\sigma_i$ to $1$. When $M$ has full rank ($r=\min(m,n)$), the resulting update matrix $Q$ has perpendicular unit columns or rows:

    $$Q^\top Q=I_n\quad(\text{tall matrix, }m\ge n),\qquad QQ^\top=I_m\quad(\text{wide matrix, }m\le n).$$
    Muon orthogonalizes the update $\Delta W$, not the weight matrix $W$

    Each step updates $W_t=W_{t-1}-\eta Q_t$. Only the step $Q_t$ is orthogonalized; the weight matrix $W_t$ itself is a sum of many steps and stays completely unconstrained.

    3. Why $UV^\top$? Steepest descent with a cap on layer stretch

    Why is $Q=UV^\top$ the right geometry for a linear layer? When we nudge a weight matrix by $D=\Delta W$, a unit input vector $\|x\|_2=1$ sees its output change by $\Delta y=Dx$. The largest possible output change across all unit inputs is the spectral norm (the largest singular value of $D$):

    $$\|D\|_2=\max_{\|x\|_2=1}\|Dx\|_2=\sigma_{\max}(D).$$

    Suppose we want our update $D$ to decrease the loss as much as possible—minimizing the first-order change $\langle M,D\rangle_F=\operatorname{tr}(M^\top D)$—while capping the maximum output stretch at $\|D\|_2\le\eta$. Writing $D$ in the SVD coordinates of $M$ via $\widetilde D=U^\top DV$ turns $\langle M,D\rangle_F$ into a weighted sum along each singular direction:

    $$\langle M,D\rangle_F=\operatorname{tr}\!\bigl((U\Sigma V^\top)^\top D\bigr)=\operatorname{tr}\!\bigl(\Sigma\,\widetilde D\bigr)=\sum_{i=1}^r\sigma_i\widetilde D_{ii}.$$

    Because the spectral-norm budget $\|D\|_2\le\eta$ bounds each direction’s step by $|\widetilde D_{ii}|\le\eta$ and each $\sigma_i>0$, the sum is minimized by pushing every single direction to the full limit $\widetilde D_{ii}=-\eta$ (so $\widetilde D=-\eta I_r$):

    $$D^\star=U\widetilde DV^\top=-\eta UV^\top,\qquad\langle M,D^\star\rangle_F=-\eta\sum_{i=1}^r\sigma_i=-\eta\|M\|_*.$$

    Changing which norm bounds the step $D$ yields three classic optimizer families:

    Optimizer FamilyStep Budget ($\|D\|\le\eta$)Optimal Step $D^\star$What It Does to the Matrix
    SGD / MomentumFrobenius norm $\|D\|_F=\sqrt{\sum_{i,j}D_{ij}^2}\le\eta$$-\eta\,\dfrac{M}{\|M\|_F}$Divides the whole matrix by one number; keeps $\sigma_1\gg\sigma_r$ skewed.
    SignSGD / LionMax-entry norm $\|D\|_\infty=\max_{i,j}|D_{ij}|\le\eta$$-\eta\operatorname{sign}(M)$Pushes every coordinate $M_{ij}$ to $\pm\eta$; ignores matrix directions $(U,V)$.
    MuonSpectral norm $\|D\|_2=\sigma_{\max}(D)\le\eta$$-\eta\,UV^\top$Pushes every active singular value $\sigma_i$ to $\eta$ while preserving $(U,V)$.

    6. Complete Muon algorithm, shape scaling, and memory

    Computing an exact SVD on every weight matrix is slow on GPUs, so Muon approximates $UV^\top$ using $5$ fast matrix-multiply steps of a Newton–Schulz polynomial (derived in Part 2). Putting momentum $B_t$, optional Nesterov lookahead $\widetilde B_t$, Newton–Schulz orthogonalization, and decoupled weight decay $\lambda$ together gives the complete update for a 2D weight matrix $W_t\in\mathbb R^{m\times n}$:

    $$\begin{aligned}B_t&=\beta B_{t-1}+G_t\qquad&\text{(1. Momentum buffer)}\\ \widetilde B_t&=\begin{cases}G_t+\beta B_t&\text{(Nesterov = True)}\\B_t&\text{(Nesterov = False)}\end{cases}\qquad&\text{(2. Lookahead direction)}\\ Q_t&=\operatorname{NewtonSchulz}_5\!\left(\frac{\widetilde B_t}{\|\widetilde B_t\|_F+\epsilon}\right)\approx UV^\top\qquad&\text{(3. Orthogonalize }\Sigma\to I\text{)}\\ W_t&=(1-\eta\lambda)W_{t-1}-\eta\sqrt{\max\!\left(1,\frac{m}{n}\right)}\,Q_t\qquad&\text{(4. Weight decay + step)}\end{aligned}$$

    Two practical details make this work cleanly across layers:

    • Input scale doesn’t matter: because $\widetilde B_t$ is immediately divided by its Frobenius norm $\|\widetilde B_t\|_F$, multiplying the gradient or momentum buffer by any positive constant $c>0$ cancels out completely.
    • Why multiply by $\sqrt{\max(1,m/n)}$? An orthogonal matrix $Q\in\mathbb R^{m\times n}$ has $\min(m,n)$ singular values equal to $1$, so the sum of squares of all $mn$ entries is $\|Q\|_F^2=\min(m,n)$. That means the typical (RMS) size of each entry $Q_{ij}$ is $\sqrt{\min(m,n)/(mn)}=1/\sqrt{\max(m,n)}$. When a matrix has many more rows than columns ($m\gg n$), its individual entries get smaller; multiplying by $\sqrt{\max(1,m/n)}$ keeps the per-parameter step size consistent across tall layers.
    # One Muon step for a 2D hidden weight matrix W of shape (m, n)
B = beta * B + grad
B_tilde = grad + beta * B if nesterov else B
Q = newton_schulz_5(B_tilde)               # Fast 5-step bfloat16 approximation of U @ V.T
scale = max(1.0, rows / cols) ** 0.5       # Aspect-ratio scaling for tall matrices
W *= 1 - lr * weight_decay                 # Decoupled weight decay
W -= lr * scale * Q

    Optimizer state memory: Unlike AdamW (which stores two buffers $m_t$ and $v_t$, costing $+8\text{ bytes/parameter}$ in FP32), Muon stores only one buffer per parameter—the momentum matrix $B_t$ ($+4\text{ bytes/parameter}$ in FP32, matching SGD with Momentum)—because $Q_t$ is computed on the fly and immediately discarded.

    7. Parameter routing: which layers use Muon vs. AdamW?

    Muon is built specifically for dense 2D hidden-layer weight matrices. In a Transformer or MLP, non-matrix and vocabulary parameters should still be optimized with AdamW:

    Parameter GroupTypical ShapeOptimizerWhy
    Hidden linear layers (MLP up/down/gate, Attention $W_Q,W_K,W_V,W_O$)2D $(m\times n)$MuonDense linear maps between hidden states where equalizing singular directions speeds up learning.
    Norm gains & biases (RMSNorm, LayerNorm, biases)1D $(d,)$AdamW1D vectors have no 2D row-column matrix geometry to orthogonalize.
    Token embeddings2D $(V\times d)$AdamWEach token lookup updates only a single row $e_k$; rows are separate vocabulary words, not a dense basis.
    Output / LM head (unembedding / classifier)2D $(V\times d)$AdamWMaps hidden states directly to rare and frequent class logits, which benefit from AdamW’s per-coordinate second moment $v_t$.

    8. Questions worth answering

    How is Muon different from simply dividing the momentum matrix by its Frobenius norm $\|M\|_F$?

    Dividing $M$ by the single number $\|M\|_F=\sqrt{\sum_i\sigma_i^2}$ shrinks all singular values by the same factor, leaving their lopsided ratios $\sigma_1/\sigma_i$ completely unchanged. Muon sets every nonzero singular value to $1$, giving quiet directions the same step size as dominant ones.

    Why doesn’t Muon call torch.linalg.svd(M) at every step?

    Exact SVD on large matrices is slow on GPUs and cannot fully utilize low-precision Tensor Cores. Part 2 shows how $5$ steps of a degree-$5$ Newton–Schulz matrix polynomial push all singular values toward $1$ using only fast bfloat16 matrix multiplications.
