    Muon, Part 2: Newton–Schulz Without the Mystery

    September 2026 · 6 min read + interactive lab

    How do you set every singular value of a matrix to $1$ without computing an SVD? Run $5$ steps of a simple matrix-multiply loop that pushes every $\sigma_i\in(0,1]$ up to $\approx 1$ in parallel.

    Part 1 showed that Muon wants to turn a momentum matrix $M=U\Sigma V^\top$ into its orthogonal polar factor $Q=UV^\top$ by replacing every nonzero singular value $\sigma_i$ with $1$. Calling an exact SVD (`torch.linalg.svd`) on every weight matrix at every training step is slow on GPUs. Newton–Schulz iteration replaces SVD with $5$ fast `bfloat16` matrix multiplications that run directly on GPU Tensor Cores.

    01 · SCALE TO [0, 1]Divide by $\|M\|_F$Ensure every singular value starts safely inside $[0,1]$ so high powers don’t explode.
    02 · MULTIPLY 5×Apply odd powersRepeat $X\leftarrow aX+(bA+cA^2)X$ with $A=XX^\top$ for $5$ iterations in bfloat16.
    03 · ORTHOGONAL QAll $\sigma_i \approx 1$Directions $U$ and $V^\top$ stay fixed while every active singular value is pushed to $\approx 1$.

    1. Step 0: Divide by $\|M\|_F$ so all singular values start in $[0,1]$

    Before running the polynomial loop, Muon divides the momentum matrix $M$ by its Frobenius norm $\|M\|_F$:

    $$X_0=\frac{M}{\|M\|_F+\epsilon},\qquad\|M\|_F=\sqrt{\sum_{i,j}M_{ij}^2}=\sqrt{\sum_{i=1}^r\sigma_i^2}.$$

    Why is this single division enough? Because no individual singular value $\sigma_i$ can exceed the square root of the sum of all squared singular values ($\sigma_i\le\sqrt{\sum_{j=1}^r\sigma_j^2}=\|M\|_F$). Dividing by $\|M\|_F$ guarantees that every singular value of $X_0$ starts between $0$ and $1$:

    $$0\le\sigma_i(X_0)=\frac{\sigma_i(M)}{\sqrt{\sum_{j=1}^r\sigma_j^2}+\epsilon}\le 1.$$
    Why $[0,1]$ matters

    Polynomials with powers like $s^3$ and $s^5$ only behave well inside $[0,1]$. If a singular value started above $1$, raising it to the 3rd and 5th power repeatedly would make it explode to $\pm\infty$.

    2. The key insight: why odd matrix products only change $\Sigma$

    How can we change the singular values $\Sigma$ of a matrix $X=U\Sigma V^\top$ without ever computing $U$ or $V$? Look at what happens when we multiply $X$, $X^\top$, and $X$ together. Because $U$ and $V$ have perpendicular unit columns ($V^\top V=I$ and $U^\top U=I$), the inner matrices cancel out like dominoes:

    $$\begin{aligned}(X X^\top)X&=(U\Sigma\underbrace{V^\top)(V}_{=\,I}\Sigma\underbrace{U^\top)(U}_{=\,I}\Sigma V^\top)=U\Sigma^3 V^\top,\\(X X^\top)^2 X&=(U\Sigma^2\underbrace{U^\top)(U}_{=\,I}\Sigma^2\underbrace{U^\top)(U}_{=\,I}\Sigma V^\top)=U\Sigma^5 V^\top.\end{aligned}$$

    Notice what happened: $U$ and $V^\top$ stay completely untouched on the outside, while the diagonal matrix $\Sigma$ in the middle gets raised to odd powers ($\Sigma^3$, $\Sigma^5$). Therefore, combining $X$, $(XX^\top)X$, and $(XX^\top)^2 X$ applies an ordinary 1D polynomial $\phi(s)=as+bs^3+cs^5$ to every singular value $s=\sigma_i$ at the exact same time:

    $$X_{k+1}=a X_k+b(X_k X_k^\top)X_k+c(X_k X_k^\top)^2 X_k=U\,\phi(\Sigma_k)\,V^\top,\qquad\sigma_{k+1,i}=\phi(\sigma_{k,i}).$$

    This turns the entire matrix problem into a simple 1D question: choose a curve $\phi(s)$ that pushes any number $s\in(0,1]$ up to $1$ in as few steps as possible!

    3. Where the classical cubic $\phi(s)=\tfrac32 s-\tfrac12 s^3$ comes from

    For a matrix $X=U\Sigma V^\top$, notice that $XX^\top=U\Sigma^2 U^\top$, so multiplying $X$ on the left by $(XX^\top)^{-1/2}=U\Sigma^{-1}U^\top$ cancels $\Sigma$ and gives the exact target $Q=UV^\top$:

    $$Q=(XX^\top)^{-1/2}X=(U\Sigma^{-1}U^\top)(U\Sigma V^\top)=UV^\top.$$

    To avoid computing an inverse square root, write $X_k X_k^\top=I-E_k$, where $E_k=I-X_k X_k^\top$ measures how far $X_k$ is from being orthogonal. Using the first-order Taylor approximation $(I-E_k)^{-1/2}\approx I+\tfrac12 E_k$ for small $E_k$ gives the classical cubic Newton–Schulz iteration:

    $$X_{k+1}=\left(I+\frac12(I-X_k X_k^\top)\right)X_k=\frac32 X_k-\frac12(X_k X_k^\top)X_k.$$

    On each singular value $s\in(0,1]$, this applies the cubic curve $\phi_{\text{cubic}}(s)=\tfrac32 s-\tfrac12 s^3$. Whenever $s\in(0,1)$, $\phi_{\text{cubic}}(s)>s$, pulling $s$ steadily upward toward the fixed point $\phi_{\text{cubic}}(1)=1$.

    4. Why Muon upgrades to a tuned 5-step quintic

    Why doesn’t Muon just use the classical cubic? When a large weight matrix has hundreds of singular values, dividing by $\|M\|_F=\sqrt{\sum_j\sigma_j^2}$ makes the smaller singular values very close to zero ($s_0\ll 1$). Near $s=0$, $s^3$ is negligible, so the cubic curve $\phi_{\text{cubic}}(s)\approx 1.5s$ only multiplies a small singular value by $1.5\times$ per step—at most $1.5^5\approx 7.6\times$ across $5$ steps.

    To lift quiet singular directions much faster, Muon adds a degree-$5$ term $A_k^2 X_k$ with tuned coefficients $(a,b,c)=(3.4445,-4.7750,2.0315)$:

    $$\begin{aligned}A_k&=X_k X_k^\top,\\X_{k+1}&=a X_k+\bigl(b A_k+c A_k^2\bigr)X_k,\qquad\phi_{\text{quintic}}(s)=3.4445s-4.7750s^3+2.0315s^5.\end{aligned}$$

    6. Why code transposes tall matrices ($m > n$) before looping

    Whether you form the left product $X_k X_k^\top\in\mathbb R^{m\times m}$ or the right product $X_k^\top X_k\in\mathbb R^{n\times n}$, matrix associativity guarantees the exact same answer:

    $$(X_k X_k^\top)X_k=X_k(X_k^\top X_k),\qquad(X_k X_k^\top)^2 X_k=X_k(X_k^\top X_k)^2.$$

    However, the matrix-multiply cost is very different when $m\neq n$. If $X_k$ is a tall matrix (say $4096\times 1024$), then $X_k X_k^\top$ is a large $4096\times 4096$ matrix, whereas $X_k^\top X_k$ is a $16\times$ smaller $1024\times 1024$ matrix! Transposing $X$ at the start whenever $m>n$ (and transposing back at the end) guarantees that $A=XX^\top$ always has the smaller shape $\min(m,n)\times\min(m,n)$:

    def newton_schulz_5(G, steps=5, eps=1e-7):
    a, b, c = (3.4445, -4.7750, 2.0315)
    X = G.bfloat16()
    if G.size(0) > G.size(1):
        X = X.T                    # Make sure rows <= cols so A = X @ X.T is small
    X = X / (X.norm() + eps)       # Step 0: put all singular values into [0, 1]
    for _ in range(steps):         # 5 fast bfloat16 Tensor Core iterations
        A = X @ X.T
        B = b * A + c * (A @ A)
        X = a * X + B @ X
    if G.size(0) > G.size(1):
        X = X.T                    # Restore original (m, n) shape
    return X

    7. Questions worth answering

    Does “Newton–Schulz” mean Muon computes second derivatives (the Hessian) of the training loss?

    No. “Newton” here refers only to finding the root $s=1$ of $s^2-1=0$ for the singular values of the momentum matrix $M_t$. Muon only ever uses standard first-order backpropagated gradients.

    Why can the polynomial only use odd powers ($s, s^3, s^5$) and not even powers ($s^2, s^4$)?

    Two reasons: (1) for a rectangular matrix $X\in\mathbb R^{m\times n}$, $X^2$ does not even exist because the inner dimensions $m$ and $n$ don’t match—only alternating odd products like $X(X^\top X)^k\in\mathbb R^{m\times n}$ preserve the shape of $X$; and (2) odd powers preserve the sign/orientation of every singular direction.

    What happens to a zero singular value ($\sigma_i=0$)?

    Because $\phi(0)=a(0)+b(0)^3+c(0)^5=0$, any zero singular value stays strictly $0$ at every step rather than amplifying noise.
