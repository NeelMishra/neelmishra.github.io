    Muon, Part 2: Newton–Schulz Without the Mystery

    September 2026 · 6 min read + interactive lab

    Derive the cubic polar iteration, see why odd matrix polynomials act independently on every singular value, and understand Muon’s tuned quintic.

    Part 1 showed that Muon’s target is the orthogonal polar factor $Q=UV^\top$ of a momentum matrix $M=U\Sigma V^\top$. Computing a full SVD on every layer at every step is expensive on GPUs; Newton–Schulz iterations replace SVD with $5$ fast matrix multiplications that push every nonzero singular value $\sigma_i$ toward $1$ simultaneously.

    1. Step 0: Frobenius normalization puts all $\sigma_i\in[0,1]$

    Before running a polynomial iteration, divide $M$ by its Frobenius norm:

    $$X_0=\frac{M}{\|M\|_F+\epsilon},\qquad\|M\|_F=\sqrt{\sum_{i,j}M_{ij}^2}=\sqrt{\sum_{i=1}^r\sigma_i^2}.$$

    Because each singular value satisfies $\sigma_i\le\sqrt{\sum_{j=1}^r\sigma_j^2}=\|M\|_F$, normalizing guarantees that every singular value of $X_0$ starts inside $[0,1]$:

    $$0\le\sigma_i(X_0)=\frac{\sigma_i(M)}{\sqrt{\sum_{j=1}^r\sigma_j^2}+\epsilon}\le 1.$$

    Without this step, any $\sigma_i>\sqrt{3}$ in the cubic map (or $\sigma_i>1$ in the quintic map) would cause odd powers $\sigma_i^3,\sigma_i^5$ to explode to $\pm\infty$.

    2. Deriving the classical cubic Newton–Schulz iteration

    For a full-row-rank matrix $X=U\Sigma V^\top$, the exact polar factor can be written without an explicit SVD by cancelling $\Sigma$ using $(XX^\top)^{-1/2}=(U\Sigma^2 U^\top)^{-1/2}=U\Sigma^{-1}U^\top$:

    $$Q=(XX^\top)^{-1/2}X=(U\Sigma^{-1}U^\top)(U\Sigma V^\top)=UV^\top.$$

    Define the orthogonality residual $E_k=I-X_k X_k^\top$, so $X_k X_k^\top=I-E_k$. Using the first-order Taylor / binomial expansion $(I-E_k)^{-1/2}=I+\tfrac12 E_k+\tfrac38 E_k^2+\cdots$ around $E_k=0$:

    $$\begin{aligned}X_{k+1}&=\left(I+\frac12 E_k\right)X_k=\left(I+\frac12(I-X_k X_k^\top)\right)X_k\\&=\frac32 X_k-\frac12(X_k X_k^\top)X_k.\end{aligned}$$

    This requires only matrix multiplication and addition—no matrix inversion or square roots.

    3. Why odd matrix polynomials act on each singular value $\sigma_i$

    Substitute the SVD $X_k=U\Sigma_k V^\top$ (where $U^\top U=I$ and $V^\top V=I$) into the odd matrix powers:

    $$\begin{aligned}(X_k X_k^\top)X_k&=(U\Sigma_k V^\top V\Sigma_k U^\top)(U\Sigma_k V^\top)=U\Sigma_k^3 V^\top,\\(X_k X_k^\top)^2 X_k&=(U\Sigma_k^2 U^\top)^2(U\Sigma_k V^\top)=U\Sigma_k^5 V^\top.\end{aligned}$$

    Because $U$ and $V^\top$ factor out on the left and right of every odd term, any odd matrix polynomial updates the diagonal singular values $\sigma_{k,i}$ independently via a 1D scalar polynomial $\phi(s)$ while keeping $U$ and $V$ fixed:

    $$X_{k+1}=U\,\phi(\Sigma_k)\,V^\top,\qquad\sigma_{k+1,i}=\phi(\sigma_{k,i}).$$

    For the classical cubic $\phi_{\text{cubic}}(s)=\tfrac32 s-\tfrac12 s^3$, the distance to $1$ shrinks quadratically near $s=1$:

    $$1-\phi_{\text{cubic}}(s)=1-\frac32 s+\frac12 s^3=\frac12(1-s)^2(2+s)\approx\frac32(1-s)^2.$$

    4. Why Muon uses a tuned 5-step quintic

    When a weight matrix has many singular values, Frobenius normalization $X_0=M/\|M\|_F$ makes weaker singular values very small ($s_0\ll 1$). Near $s=0$, $\phi(s)\approx as$, so the cubic map ($\phi(s)=\tfrac32 s-\tfrac12 s^3$) can multiply a small singular value by at most $1.5^5\approx 7.6\times$ in $5$ steps.

    Muon instead runs $5$ iterations of a degree-$5$ odd polynomial tuned to maximize the slope $a$ at the origin while keeping $\phi(s)$ inside $[0.7,1.2]$ across $[0,1]$:

    $$\begin{aligned}A_k&=X_k X_k^\top,\\X_{k+1}&=a X_k+\bigl(b A_k+c A_k^2\bigr)X_k,\qquad(a,b,c)=(3.4445,-4.7750,2.0315).\end{aligned}$$

    The scalar map is $\phi_{\text{quintic}}(s)=3.4445s-4.7750s^3+2.0315s^5$:

    • Fast boost near zero: slope $\phi'(0)=3.4445$ (up to $3.4445^5\approx 484\times$ amplification over $5$ steps, pushing $s_0=0.05$ to $1.077$ in $5$ steps).
    • Tradeoff at $s=1$: $\phi_{\text{quintic}}(1)=3.4445-4.7750+2.0315=0.701\neq 1$. Unlike the cubic, this quintic does not converge to $1.000$ as $k\to\infty$; instead, singular values oscillate inside $[0.7,1.2]$, which is sufficient for a $5$-step `bfloat16` optimizer update.

    6. Why implementations transpose tall matrices ($m > n$)

    By associativity, forming the left Gram matrix $X_k X_k^\top\in\mathbb R^{m\times m}$ or the right Gram matrix $X_k^\top X_k\in\mathbb R^{n\times n}$ produces the exact same polynomial update:

    $$(X_k X_k^\top)X_k=X_k(X_k^\top X_k),\qquad(X_k X_k^\top)^2 X_k=X_k(X_k^\top X_k)^2.$$

    However, their matrix-multiplication costs differ whenever $m\neq n$. If $X_k\in\mathbb R^{m\times n}$ is tall ($m>n$), $X_k X_k^\top$ is a large $m\times m$ matrix, whereas $X_k^\top X_k$ is a smaller $n\times n$ matrix. Transposing $X_0$ whenever $m>n$ guarantees the Gram matrix $A_k$ always has the smaller dimension $\min(m,n)\times\min(m,n)$:

    def newton_schulz_5(G, steps=5, eps=1e-7):
    a, b, c = (3.4445, -4.7750, 2.0315)
    X = G.bfloat16()
    if G.size(0) > G.size(1):
        X = X.T  # Ensure rows <= cols so A = X @ X.T is min(m, n) x min(m, n)
    X = X / (X.norm() + eps)
    for _ in range(steps):
        A = X @ X.T
        B = b * A + c * (A @ A)
        X = a * X + B @ X
    if G.size(0) > G.size(1):
        X = X.T
    return X

    Each iteration performs three matrix multiplications (`A = X @ X.T`, `A @ A`, and `B @ X`), which run in `bfloat16` on GPU Tensor Cores.

    7. Questions worth answering

    Is Newton–Schulz computing second-order curvature (the Hessian) of the neural network loss?

    No. Despite the name “Newton,” Newton–Schulz here is purely a root-finding polynomial applied to the momentum matrix $M_t$ to approximate $M_t(M_t^\top M_t)^{-1/2}=UV^\top$. It never differentiates the loss a second time.

    Why must the polynomial only contain odd powers ($s, s^3, s^5$)?

    Because for a rectangular matrix $X\in\mathbb R^{m\times n}$, only odd alternating products $X(X^\top X)^k=(XX^\top)^k X=U\Sigma^{2k+1}V^\top$ have the same $m\times n$ shape as $X$ and preserve the sign of each singular direction.

    What happens to a zero singular value ($\sigma_i=0$)?

    Because $\phi(0)=a(0)+b(0)^3+c(0)^5=0$, zero singular values remain exactly $0$ at every step.
