    Classification Metrics: Confusion Matrix, $F_\beta$, MCC, and Cohen’s $\kappa$

    October 2026 · 6 min read

    When a classifier thresholds predicted probabilities $\hat p(y=1\mid x)$ at $\tau$ into hard labels $\hat y = \mathbf 1[\hat p \ge \tau]$, every test example lands in one of four confusion-matrix cells: True Positives ($TP$), False Negatives ($FN$), False Positives ($FP$), or True Negatives ($TN$). Different metrics summarize these four counts along different directions—and can rank the same two models in opposite orders.

    1. Row-Conditioned vs. Column-Conditioned Rates

    Let $N = TP + FN + FP + TN$ be the total sample size and $\pi = \frac{TP + FN}{N}$ be the positive class prevalence. Overall Accuracy is a prevalence-weighted average of the two true-class rates:

    $$\operatorname{Accuracy} = \frac{TP + TN}{N} = \pi\cdot\operatorname{TPR} + (1 - \pi)\cdot\operatorname{TNR}.$$

    When positives are rare ($\pi = 0.001$), predicting $\hat y = 0$ for every row gives $\operatorname{TPR} = 0$, $\operatorname{TNR} = 1$, and $\operatorname{Accuracy} = 99.9\%$ while catching zero positives. To separate class imbalance from classifier quality, condition either across rows (true class $y$) or down columns (predicted class $\hat y$):

    Row-conditioned metrics depend only on the classifier; column-conditioned metrics shift with class prevalence $\pi$.
    MetricConditioningFormulaWhat it answers
    Recall (TPR / Sensitivity)Row ($Y = 1$)$\dfrac{TP}{TP + FN}$Of all actual positives, what fraction did we catch?
    Specificity (TNR)Row ($Y = 0$)$\dfrac{TN}{TN + FP}$Of all actual negatives, what fraction did we clear?

    2. Why $F_1$ Uses the Harmonic Mean (and $F_\beta$ Generalizes It)

    If a model flags every row as positive on a $2\%$-positive dataset, it gets $R = 1.00$ and $P = 0.02$. The arithmetic mean $\frac{P+R}{2} = 0.510$ rewards that trivial rule. The $F_1$ score instead takes the harmonic mean—the reciprocal of the average of $\frac{1}{P}$ and $\frac{1}{R}$:

    $$F_1 = \left(\frac{\frac{1}{P} + \frac{1}{R}}{2}\right)^{-1} = \frac{2PR}{P + R} = \frac{2\,TP}{2\,TP + FP + FN}.$$

    In confusion-matrix counts, $F_1$ replaces $TN$ with zero and divides $TP$ by $TP + \frac{FP + FN}{2}$ (the average of the two error counts). When false negatives are $\beta$ times as costly as false positives, $F_\beta$ weights $\frac{1}{R}$ by $\beta^2$ relative to $\frac{1}{P}$:

    $$F_\beta = \left(\frac{1}{1+\beta^2}\frac{1}{P} + \frac{\beta^2}{1+\beta^2}\frac{1}{R}\right)^{-1} = \frac{(1 + \beta^2)\,PR}{\beta^2 P + R} = \frac{(1 + \beta^2)\,TP}{(1 + \beta^2)\,TP + \beta^2 FN + FP}.$$
    • $\beta = 0.5$ ($F_{0.5}$): Weights Precision $2\times$ Recall (penalizes $FP$ $4\times$ more than $FN$) for precision-critical alerts.
    • $\beta = 2.0$ ($F_2$): Weights Recall $2\times$ Precision (penalizes $FN$ $4\times$ more than $FP$) for medical screening or safety recall.

    3. Matthews Correlation Coefficient (MCC) and Cohen’s $\kappa$

    Because $TN$ never appears in $F_1 = \frac{2TP}{2TP + FP + FN}$, swapping which class is called "$1$" vs. "$0$" can dramatically change $F_1$ on the exact same predictions. The Matthews Correlation Coefficient (MCC) is the Pearson correlation between the binary vectors $Y$ and $\hat Y$, using all four cells symmetrically:

    $$\operatorname{MCC} = \frac{TP\cdot TN - FP\cdot FN}{\sqrt{(TP + FP)(TP + FN)(TN + FP)(TN + FN)}} \in [-1, +1].$$

    Cohen’s $\kappa$ measures agreement $p_o = \operatorname{Accuracy}$ relative to the chance agreement $p_e$ expected if $Y$ and $\hat Y$ were independent with the same marginal totals:

    $$\kappa = \frac{p_o - p_e}{1 - p_e}, \qquad p_o = \frac{TP + TN}{N}, \qquad p_e = \frac{(TP+FN)(TP+FP) + (TN+FP)(TN+FN)}{N^2}.$$

    Worked example: $F_1$ vs. MCC under label swapping

    Suppose $N = 100$ with $TP = 1,\; FN = 1,\; FP = 8,\; TN = 90$. Now swap the class labels ($0 \leftrightarrow 1$) on the exact same predictions so $TP' = 90,\; FN' = 8,\; FP' = 1,\; TN' = 1$:

    4. Multiclass Aggregations: Macro, Weighted, and Micro

    For $C$ classes with per-class counts $TP_c, FP_c, FN_c$, support $s_c = TP_c + FN_c$ ($\sum_{c=1}^C s_c = N$), and per-class score $F_{1,c}$:

    $$\operatorname{Macro-}F_1 = \frac{1}{C}\sum_{c=1}^C F_{1,c}, \qquad \operatorname{Weighted-}F_1 = \sum_{c=1}^C \frac{s_c}{N}F_{1,c}, \qquad \operatorname{Micro-}F_1 = \frac{2\sum_{c=1}^C TP_c}{2\sum_{c=1}^C TP_c + \sum_{c=1}^C FP_c + \sum_{c=1}^C FN_c}.$$

    In single-label multiclass classification, every wrong prediction is simultaneously one false positive for the predicted class and one false negative for the true class ($\sum_c FP_c = \sum_c FN_c = N - \sum_c TP_c$), which makes $\operatorname{Micro-Precision} = \operatorname{Micro-Recall} = \operatorname{Micro-}F_1 = \operatorname{Accuracy}$. Use Macro-$F_1$ when rare classes should carry equal weight to common classes.

    5. PyTorch Implementation

    import torch

def binary_classification_report(y_true: torch.Tensor, y_pred: torch.Tensor, beta: float = 1.0):
    tp = ((y_true == 1) & (y_pred == 1)).sum().float()
    tn = ((y_true == 0) & (y_pred == 0)).sum().float()
    fp = ((y_true == 0) & (y_pred == 1)).sum().float()
    fn = ((y_true == 1) & (y_pred == 0)).sum().float()
    n = tp + tn + fp + fn

    acc = (tp + tn) / n
    prec = tp / (tp + fp + 1e-12)
    rec  = tp / (tp + fn + 1e-12)
    spec = tn / (tn + fp + 1e-12)
    bal_acc = 0.5 * (rec + spec)
    f_beta = (1 + beta**2) * prec * rec / (beta**2 * prec + rec + 1e-12)

    mcc = (tp * tn - fp * fn) / (torch.sqrt((tp + fp) * (tp + fn) * (tn + fp) * (tn + fn)) + 1e-12)
    p_e = ((tp + fn) * (tp + fp) + (tn + fp) * (tn + fn)) / (n * n)
    kappa = (acc - p_e) / (1.0 - p_e + 1e-12)
    return {"Acc": round(acc.item(), 4), "BalAcc": round(bal_acc.item(), 4),
            "P": round(prec.item(), 4), "R": round(rec.item(), 4),
            f"F_{beta}": round(f_beta.item(), 4), "MCC": round(mcc.item(), 4), "Kappa": round(kappa.item(), 4)}

y_true = torch.tensor([1, 1] + [0]*8 + [0]*90)
y_pred = torch.tensor([1, 0] + [1]*8 + [0]*90)
print("Original:", binary_classification_report(y_true, y_pred))
print("Swapped :", binary_classification_report(1 - y_true, 1 - y_pred))
