    Explainability (XAI), Attribution Faithfulness & Fairness Metrics: Deletion/Insertion AUC, ERASER, Infidelity, and Equalized Odds

    October 2026 · 8 min read

    A visually appealing saliency map $\Phi(f, x) \in \mathbb{R}^d$ is not automatically a faithful explanation of what a model $f$ actually computed. As Jacovi & Goldberg (2020) emphasize, XAI evaluation separates Faithfulness (does $\Phi(f,x)$ reflect the model's true causal mechanism, including spurious shortcuts?) from Plausibility (does $\Phi(f,x)$ align with human domain expectations?). This chapter covers perturbation faithfulness curves, discrete ERASER rationale metrics, local Infidelity and Max-Sensitivity, weight-randomization sanity checks, and algorithmic group fairness.

    1. Perturbation Faithfulness & ERASER Rationale Metrics

    Let $\pi = \operatorname{argsort}_{\text{desc}}(\Phi(f, x))$ order features from most to least attributed, let $S_k = \{\pi_1, \dots, \pi_k\}$ be the top-$k$ features, and let $x^{(0)}$ be an uninformative baseline. Progressive ablation and progressive insertion trace the Deletion (MoRF) and Insertion curves:

    $$c_{\text{del}}(k/d) = f\big(x_{\setminus S_k}\big), \qquad c_{\text{ins}}(k/d) = f\big(x_{S_k}\big), \qquad \operatorname{AUC}_{\text{del}} = \int_0^1 c_{\text{del}}(\alpha)\,d\alpha \;(\downarrow), \qquad \operatorname{AUC}_{\text{ins}} = \int_0^1 c_{\text{ins}}(\alpha)\,d\alpha \;(\uparrow).$$

    For a discrete rationale subset $r \subseteq x$, the ERASER benchmark (DeYoung et al., 2020) pairs Comprehensiveness (does removing $r$ collapse the predicted probability $m(x)_y$?) with Sufficiency (does keeping only $r$ reproduce $m(x)_y$?):

    $$\operatorname{Comprehensiveness}(x, r) = m(x)_y - m(x \setminus r)_y \;(\uparrow), \qquad \operatorname{Sufficiency}(x, r) = m(x)_y - m(r)_y \;(\downarrow).$$

    Reporting both prevents trivial gaming: selecting $r = x$ maximizes Comprehensiveness effortlessly, while Sufficiency penalizes incomplete rationales.

    Worked Perturbation Example: On a $4$-token input with $m(x)_y = 0.90$, suppose MoRF deletion at $\alpha \in \{0, 0.25, 0.50, 0.75, 1.0\}$ yields $c_{\text{del}} = [0.90, 0.30, 0.10, 0.06, 0.04]$ and insertion yields $c_{\text{ins}} = [0.04, 0.72, 0.86, 0.88, 0.90]$:

    MetricFormulaPlugged-in CalculationScore
    Deletion AUC ($\downarrow$)$\sum_{j=1}^4 \Delta\alpha\,\frac{c_{\text{del}}(\alpha_{j-1}) + c_{\text{del}}(\alpha_j)}{2}$$0.25(0.60 + 0.20 + 0.08 + 0.05)$$\mathbf{0.2325}$
    Insertion AUC ($\uparrow$)$\sum_{j=1}^4 \Delta\alpha\,\frac{c_{\text{ins}}(\alpha_{j-1}) + c_{\text{ins}}(\alpha_j)}{2}$$0.25(0.38 + 0.79 + 0.87 + 0.89)$$\mathbf{0.7325}$
    Comprehensiveness ($\alpha=0.5$)$m(x)_y - m(x \setminus r)_y$$0.90 - 0.10$$\mathbf{0.8000}$
    Sufficiency ($\alpha=0.5$)$m(x)_y - m(r)_y$$0.90 - 0.86$$\mathbf{0.0400}$

    2. Completeness, Infidelity, Max-Sensitivity & Sanity Checks

    Beyond discrete masking, axiomatic and local perturbation metrics test whether $\Phi(f, x)$ is mathematically consistent with $f$:

    MetricFormulaWhat It Verifies
    Completeness ($\Delta_{\text{conv}}$)$\left|\sum_{i=1}^d \Phi_i(f, x) - \big(f(x) - f(x^{(0)})\big)\right|$Integrated Gradients & SHAP attributions sum exactly to the output change from baseline $x^{(0)}$.
    Infidelity ($\downarrow$)$\mathbb{E}_{\mathbf{I}\sim\mu_I}\!\left[\big(\mathbf{I}^\top\Phi(f,x) - (f(x) - f(x-\mathbf{I}))\big)^2\right]$Whether $\mathbf{I}^\top\Phi(f,x)$ accurately predicts function drops under random perturbations $\mathbf{I}$ (Yeh et al., 2019).
    Max-Sensitivity ($\downarrow$)$\max_{\|\delta\|\le r} \frac{\|\Phi(f, x+\delta) - \Phi(f, x)\|_2}{\|\Phi(f, x)\|_2}$Stability of the explanation within a small $\epsilon$-ball around $x$ (stabilized via SmoothGrad).
    EBPG ($\uparrow$)$\frac{\sum_{(h,w)\in M_{\text{gt}}} |S_{h,w}|}{\sum_{h,w} |S_{h,w}|}$Fraction of total saliency energy inside ground-truth object mask $M_{\text{gt}}$ (plausibility/localization).
    Weight Randomization$\rho_{\text{Spearman}}\!\big(|S(x;\theta)|,\, |S(x;\tilde\theta_{\ge l})|\big) \approx 0$Adebayo et al. (2018) sanity check: randomizing network weights must destroy the explanation (exposes edge detectors like Guided Backprop).

    3. Algorithmic Group Fairness & The Impossibility Theorem

    For a binary decision $\hat Y \in \{0, 1\}$, true label $Y \in \{0, 1\}$, and protected group attribute $A \in \{0, 1\}$ ($A=0$ unprivileged, $A=1$ privileged), group fairness metrics fall into three families—Independence ($\hat Y \perp A$), Separation ($\hat Y \perp A \mid Y$), and Sufficiency ($Y \perp A \mid \hat Y$):

    $$\operatorname{SPD} = \big|\Pr(\hat Y=1\mid A=0) - \Pr(\hat Y=1\mid A=1)\big|, \qquad \operatorname{DI} = \frac{\Pr(\hat Y=1\mid A=0)}{\Pr(\hat Y=1\mid A=1)} \ge 0.80,$$
    $$\operatorname{EOD} = \big|\operatorname{TPR}_{A=0} - \operatorname{TPR}_{A=1}\big|, \qquad \Delta_{\text{EOdds}} = \frac{1}{2}\Big(\big|\operatorname{TPR}_{A=0} - \operatorname{TPR}_{A=1}\big| + \big|\operatorname{FPR}_{A=0} - \operatorname{FPR}_{A=1}\big|\Big).$$

    Chouldechova's Impossibility Theorem (2017): By Bayes' rule, $\operatorname{FPR}_a = \frac{\pi_a}{1-\pi_a}\frac{1-\operatorname{PPV}_a}{\operatorname{PPV}_a}\operatorname{TPR}_a$. Whenever two demographic groups have unequal base rates ($\pi_0 \ne \pi_1$) and the classifier is imperfect, a model cannot simultaneously satisfy Predictive Parity ($\operatorname{PPV}_0 = \operatorname{PPV}_1$) and Equalized Odds ($\operatorname{TPR}_0 = \operatorname{TPR}_1, \operatorname{FPR}_0 = \operatorname{FPR}_1$).

    Worked Fairness Audit: Given Group $A=0$ ($TP=30, FN=20, FP=6, TN=44$) and Group $A=1$ ($TP=40, FN=10, FP=10, TN=40$):

    Fairness MetricGroup $A=0$Group $A=1$Disparity CalculationResult
    Statistical Parity Diff (SPD)$\Pr(\hat Y=1) = 0.36$$\Pr(\hat Y=1) = 0.50$$|0.36 - 0.50|$$\mathbf{0.1400}$
    Disparate Impact (DI)$0.36$$0.50$$0.36 / 0.50$ ($< 0.80$ four-fifths rule)$\mathbf{0.7200}$
    Equal Opportunity Diff (EOD)$\operatorname{TPR}_0 = \frac{30}{50} = 0.60$$\operatorname{TPR}_1 = \frac{40}{50} = 0.80$$|0.60 - 0.80|$$\mathbf{0.2000}$
    Equalized Odds ($\Delta_{\text{EOdds}}$)$\operatorname{FPR}_0 = \frac{6}{50} = 0.12$$\operatorname{FPR}_1 = \frac{10}{50} = 0.20$$\frac{1}{2}(|0.60 - 0.80| + |0.12 - 0.20|)$$\mathbf{0.1400}$

    4. Reference Python Implementation

    from typing import Sequence, Dict

def trapezoidal_auc(curve: Sequence[float]) -> float:
    m = len(curve) - 1
    return sum((0.5 / m) * (curve[j - 1] + curve[j]) for j in range(1, len(curve))) if m > 0 else 0.0

def group_fairness_audit(cm0: Dict[str, int], cm1: Dict[str, int]) -> Dict[str, float]:
    def rates(cm: Dict[str, int]):
        n = cm["TP"] + cm["FN"] + cm["FP"] + cm["TN"]
        return (cm["TP"] + cm["FP"]) / n, cm["TP"] / (cm["TP"] + cm["FN"]), cm["FP"] / (cm["FP"] + cm["TN"])
    sel0, tpr0, fpr0 = rates(cm0)
    sel1, tpr1, fpr1 = rates(cm1)
    return {
        "SPD": round(abs(sel0 - sel1), 4),
        "Disparate_Impact": round(sel0 / sel1, 4),
        "EOD": round(abs(tpr0 - tpr1), 4),
        "Equalized_Odds": round(0.5 * (abs(tpr0 - tpr1) + abs(fpr0 - fpr1)), 4),
    }

print("Deletion AUC :", round(trapezoidal_auc([0.90, 0.30, 0.10, 0.06, 0.04]), 4))
print("Insertion AUC:", round(trapezoidal_auc([0.04, 0.72, 0.86, 0.88, 0.90]), 4))
print("Fairness     :", group_fairness_audit({"TP": 30, "FN": 20, "FP": 6, "TN": 44}, {"TP": 40, "FN": 10, "FP": 10, "TN": 40}))
