    Search, Retrieval & Recommendation Ranking Metrics: Precision@K, MRR, MAP@K, nDCG@K, ERR, and Diversity

    October 2026 · 8 min read

    A search engine or recommender system outputs an ordered slate $L_q(K) = (d_1, d_2, \dots, d_K)$ where user attention decays rapidly with rank position $k$. Evaluating ranked lists requires choosing between unordered set metrics (for candidate generation), position-aware binary metrics (MRR, MAP@$K$), graded logarithmic discounting (nDCG@$K$, ERR), and catalog-level diversity metrics.

    1. Top-$K$ Unordered Set Metrics

    Let $\mathcal{R}_q \subseteq \mathcal{I}$ denote the ground-truth relevant items for query $q$, and let $\text{rel}_k = \mathbf{1}[d_k \in \mathcal{R}_q] \in \{0, 1\}$. Treating the top-$K$ slate $L_q(K)$ as an unordered set gives Precision@$K$, Recall@$K$, and Hit Rate@$K$:

    $$\operatorname{Precision@}K = \frac{1}{K}\sum_{k=1}^{K} \text{rel}_k, \qquad \operatorname{Recall@}K = \frac{1}{|\mathcal{R}_q|}\sum_{k=1}^{K} \text{rel}_k, \qquad \operatorname{HR@}K = \mathbf{1}\!\left[\sum_{k=1}^{K} \text{rel}_k \ge 1\right].$$

    In two-stage retrieval architectures, Stage-1 ANN candidate generation is evaluated with Recall@$100$ (since Stage 2 will re-order all $100$ candidates anyway), whereas Stage-2 reranking must be evaluated with position-sensitive metrics because set metrics assign the exact same score whether a hit sits at rank $k=1$ or rank $k=K$.

    2. Position-Aware Binary Ranking: MRR and MAP@$K$

    When a user needs a single target answer (navigational search or question answering), only the rank of the first relevant hit $k_q^* = \min\{k : \text{rel}_k = 1\}$ matters, giving Mean Reciprocal Rank (MRR@$K$):

    $$\operatorname{MRR@}K = \frac{1}{|\mathcal{Q}|}\sum_{q \in \mathcal{Q}} \frac{\mathbf{1}[k_q^* \le K]}{k_q^*}.$$

    When multiple relevant items exist ($|\mathcal{R}_q| > 1$), Average Precision ($\operatorname{AP@}K$) averages $\operatorname{Precision@}k$ at each rank where a relevant hit occurs, normalized by $\min(K, |\mathcal{R}_q|)$ so missing relevant items are penalized:

    $$\operatorname{AP@}K(q) = \frac{1}{\min(K, |\mathcal{R}_q|)} \sum_{k=1}^{K} \operatorname{Precision@}k(q) \cdot \text{rel}_k, \qquad \operatorname{MAP@}K = \frac{1}{|\mathcal{Q}|}\sum_{q \in \mathcal{Q}} \operatorname{AP@}K(q).$$

    3. Graded Relevance: DCG, IDCG, and nDCG@$K$

    When relevance is graded ($r_k \in \{0, 1, 2, 3\}$), Discounted Cumulative Gain ($\operatorname{DCG@}K$) applies exponential gain $2^{r_k} - 1$ divided by a logarithmic position discount $\log_2(k+1)$. Dividing by the Ideal DCG ($\operatorname{IDCG@}K$)—computed by sorting all ground-truth relevant items in the entire corpus in descending order $r_{(1)} \ge r_{(2)} \ge \dots \ge r_{(K)}$—yields Normalized DCG ($\operatorname{nDCG@}K$):

    $$\operatorname{DCG@}K = \sum_{k=1}^{K} \frac{2^{r_k} - 1}{\log_2(k + 1)}, \qquad \operatorname{IDCG@}K = \sum_{k=1}^{K} \frac{2^{r_{(k)}} - 1}{\log_2(k + 1)}, \qquad \operatorname{nDCG@}K = \frac{\operatorname{DCG@}K}{\operatorname{IDCG@}K} \in [0, 1].$$

    Note that $\operatorname{IDCG@}K$ must always be computed over the full ground-truth corpus for query $q$, never just the model's retrieved top-$K$ items; otherwise a ranker returning a single grade-$1$ item at $k=1$ and four grade-$0$ items would falsely score $\operatorname{nDCG@}5 = 1.0$.

    4. User Browsing Cascade Models: RBP and ERR

    Logarithmic discounting in $\operatorname{nDCG@}K$ is static: rank $k=2$ receives weight $1/\log_2 3$ regardless of whether rank $k=1$ already satisfied the user. Two browsing-model metrics capture sequential user stopping:

    • Rank-Biased Precision ($\operatorname{RBP}_p$, Moffat & Zobel 2008): Assumes the user continues from rank $k$ to $k+1$ with persistence probability $p \in (0, 1)$:
      $$\operatorname{RBP}_p = (1 - p)\sum_{k=1}^{K} r_k\,p^{k-1}.$$
    • Expected Reciprocal Rank ($\operatorname{ERR@}K$, Chapelle et al. 2009): Maps each grade $r_k \in \{0,\dots,r_{\max}\}$ to satisfaction probability $R_k = \frac{2^{r_k} - 1}{2^{r_{\max}}}$ and computes the expected reciprocal rank at which the user stops scanning:
      $$\operatorname{ERR@}K = \sum_{k=1}^{K} \frac{1}{k}\, R_k \prod_{i=1}^{k-1} (1 - R_i).$$

    6. Beyond-Accuracy Metrics: Diversity, Novelty, Coverage & Gini

    Optimizing purely for click accuracy creates filter bubbles and popularity bias. Production recommenders track four ecosystem metrics alongside $\operatorname{nDCG@}K$:

    MetricDefinitionWhat It Prevents
    Intra-List Diversity (ILD)$\frac{2}{K(K-1)}\sum_{k < j} d(d_k, d_j)$Recommending $K$ near-duplicate items in one slate
    Self-Information Novelty$\frac{1}{K}\sum_{i \in L_u(K)} \big(-\log_2 P(i)\big)$Popularity bias toward ubiquitous blockbusters
    Catalog Coverage$\big|\bigcup_{u \in \mathcal{U}} L_u(K)\big| \big/ |\mathcal{I}|$Dead-catalog items that are never surfaced to any user
    Gini Exposure Index$\frac{1}{M-1}\sum_{j=1}^M (2j - M - 1)p_{(j)}$Impression monopoly where a tiny fraction of items gets all traffic

    7. Reference Python Implementation

    import math
from typing import Sequence

def average_precision_at_k(rels: Sequence[int], k: int, total_relevant: int) -> float:
    if total_relevant == 0:
        return 0.0
    hits, total = 0, 0.0
    for idx, r in enumerate(rels[:k], start=1):
        if r > 0:
            hits += 1
            total += hits / idx
    return total / min(k, total_relevant)

def dcg_at_k(rels: Sequence[float], k: int) -> float:
    return sum((2.0 ** r - 1.0) / math.log2(idx + 1.0) for idx, r in enumerate(rels[:k], start=1))

def ndcg_at_k(rels: Sequence[float], all_corpus_rels: Sequence[float], k: int) -> float:
    ideal = dcg_at_k(sorted(all_corpus_rels, reverse=True), k)
    return dcg_at_k(rels, k) / ideal if ideal > 0 else 0.0

def err_at_k(rels: Sequence[float], k: int, r_max: float = 3.0) -> float:
    p_unsat, err, denom = 1.0, 0.0, 2.0 ** r_max
    for idx, r in enumerate(rels[:k], start=1):
        r_prob = (2.0 ** r - 1.0) / denom
        err += (1.0 / idx) * r_prob * p_unsat
        p_unsat *= (1.0 - r_prob)
    return err

top5 = [3, 0, 2, 1, 0]
corpus = [3, 0, 2, 1, 0, 0, 0, 2]
print("AP@5  :", round(average_precision_at_k(top5, 5, total_relevant=4), 4))
print("nDCG@5:", round(ndcg_at_k(top5, corpus, 5), 4))
print("ERR@5 :", round(err_at_k(top5, 5, r_max=3.0), 4))
