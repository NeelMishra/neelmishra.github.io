    Vision, Segmentation, Clustering & Generative Metrics: IoU, Dice, COCO mAP, Panoptic PQ, SSIM, FID, and ARI/NMI

    October 2026 · 8 min read

    Evaluating structured spatial predictions, generative image distributions, and unsupervised clusters requires geometry-aware metrics. This chapter covers spatial box and mask overlap (IoU, Dice, GIoU, $\text{HD}_{95}$), object detection and panoptic segmentation ($\text{COCO mAP}$, $\text{PQ}$), perceptual fidelity (PSNR, SSIM, LPIPS), distributional generation quality (IS, FID, CLIPScore), and clustering indices (Silhouette, ARI, NMI).

    1. Spatial Overlap & Boundary Geometry: IoU, Dice, GIoU, and $\text{HD}_{95}$

    Given a ground-truth region $A$ and a predicted region $B$, Intersection over Union ($\operatorname{IoU}$ / Jaccard Index) and the Sørensen–Dice Coefficient (pixel-wise $F_1$) are linked by a monotonic bijection:

    $$\operatorname{IoU}(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{TP}{TP + FP + FN}, \qquad \operatorname{Dice}(A, B) = \frac{2|A \cap B|}{|A| + |B|} = \frac{2\,\operatorname{IoU}}{1 + \operatorname{IoU}} \ge \operatorname{IoU}.$$

    When two bounding boxes do not overlap ($|A \cap B| = 0$), $\operatorname{IoU} = 0$ everywhere and provides zero gradient for box regression. Let $C$ be the smallest axis-aligned box enclosing both $A$ and $B$; Generalized IoU ($\operatorname{GIoU}$) subtracts the empty fraction of $C$, while Complete IoU ($\operatorname{CIoU}$) penalizes normalized center distance $\rho^2(\mathbf{b}, \mathbf{b}^{gt}) / c^2$ and aspect-ratio mismatch $\alpha v$:

    $$\operatorname{GIoU}(A, B) = \operatorname{IoU}(A, B) - \frac{|C \setminus (A \cup B)|}{|C|} \in (-1, 1], \qquad \operatorname{CIoU}(A, B) = \operatorname{IoU}(A, B) - \frac{\rho^2(\mathbf{b}, \mathbf{b}^{gt})}{c^2} - \alpha v.$$

    Because interior pixels dominate area metrics on large organs, medical segmentation pairs $\operatorname{Dice}$ with the Hausdorff Distance between boundary contours $\partial A$ and $\partial B$ (specifically $\text{HD}_{95}$, the $95\text{th}$ percentile of directed boundary distances):

    $$d_H(\partial A, \partial B) = \max\!\left\{\,\sup_{a \in \partial A}\inf_{b \in \partial B}\|a - b\|_2,\;\; \sup_{b \in \partial B}\inf_{a \in \partial A}\|a - b\|_2\,\right\}.$$

    Worked Box Example: For $A = [0, 0, 4, 4]$ ($|A|=16$) and $B = [2, 2, 6, 6]$ ($|B|=16$), the intersection is $[2, 2, 4, 4]$ ($|A\cap B|=4$), union is $16+16-4=28$, and enclosing hull is $C = [0, 0, 6, 6]$ ($|C|=36$):

    MetricFormulaPlugged-in CalculationScore
    IoU (Jaccard)$|A \cap B| / |A \cup B|$$4 / 28 = 1 / 7$$\mathbf{0.1429}$
    Dice ($F_1$)$2|A \cap B| / (|A| + |B|)$$2(4) / (16 + 16) = 8 / 32$$\mathbf{0.2500}$
    GIoU$\operatorname{IoU} - |C \setminus (A \cup B)| / |C|$$\frac{1}{7} - \frac{36 - 28}{36} = \frac{1}{7} - \frac{2}{9} = -\frac{5}{63}$$\mathbf{-0.0794}$

    2. Object Detection (COCO mAP) & Panoptic Quality (PQ)

    In object detection, predictions $(B_i, c_i, s_i)$ for class $c$ are sorted by confidence $s_i$ and matched greedily to unmarked ground-truth boxes with $\operatorname{IoU} \ge \tau$ (any duplicate detection of an already-matched ground-truth box is counted as a False Positive). COCO mAP integrates the upper-envelope Precision–Recall curve at $101$ recall checkpoints and averages over all $C$ classes and $10$ IoU thresholds $\tau \in \{0.50, 0.55, \dots, 0.95\}$:

    $$\operatorname{mAP}@[\text{.50:.05:.95}] = \frac{1}{10\,C}\sum_{c=1}^{C}\sum_{j=0}^{9} \operatorname{AP}_{0.50 + 0.05j}^{(c)}.$$

    For unified semantic ("stuff") and instance ("things") segmentation, non-overlapping masks guarantee that at most one predicted mask $p$ can overlap a ground-truth mask $g$ with $\operatorname{IoU}(p, g) > 0.5$. Panoptic Quality ($\operatorname{PQ}$) factors into Segmentation Quality ($\operatorname{SQ}$) times Recognition Quality ($\operatorname{RQ}$):

    $$\operatorname{PQ} = \underbrace{\left(\frac{1}{|TP|}\sum_{(p, g) \in TP} \operatorname{IoU}(p, g)\right)}_{\operatorname{SQ}\text{ (Mean Matched IoU)}} \times \underbrace{\left(\frac{|TP|}{|TP| + \frac{1}{2}|FP| + \frac{1}{2}|FN|}\right)}_{\operatorname{RQ}\text{ (Instance } F_1\text{)}}.$$

    3. Image Fidelity & Generative Distribution Metrics

    Pixel-aligned reconstruction metrics compare a restored image $\hat x$ against a reference $x$, whereas generative metrics evaluate the distribution $p_g$ of synthesized images against the real data distribution $p_r$ in deep feature space:

    MetricFormulaWhat It Measures & Limitations
    PSNR$10\log_{10}\!\left(\frac{\text{MAX}_I^2}{\operatorname{MSE}(x, \hat x)}\right)$ (dB)Logarithmic pixel MSE ($+3\text{ dB} \approx 2\times$ lower MSE); favors blurry posterior-mean averages over sharp textures.
    SSIM$\frac{(2\mu_x\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)}$Local patch luminance, contrast, and structural correlation in $[-1, 1]$.
    LPIPS$\sum_l \frac{1}{H_l W_l}\sum_{h,w}\|w_l \odot (\hat\phi_l(x) - \hat\phi_l(\hat x))\|_2^2$Deep perceptual patch distance in calibrated VGG/AlexNet feature space.
    Inception Score (IS)$\exp\!\big(\mathbb{E}_{x\sim p_g}[D_{\text{KL}}(p(y\mid x)\,\|\,p(y))]\big)$Rewards sharp class predictions $p(y\mid x)$ and diverse marginal $p(y)$, but ignores real data $p_r$.
    FID$\|\boldsymbol{\mu}_r - \boldsymbol{\mu}_g\|_2^2 + \operatorname{Tr}\!\big(\boldsymbol{\Sigma}_r + \boldsymbol{\Sigma}_g - 2(\boldsymbol{\Sigma}_r\boldsymbol{\Sigma}_g)^{1/2}\big)$Squared $2$-Wasserstein distance between real and generated Inception-v3 feature Gaussians.
    CLIPScore$w \cdot \max(\cos(\mathbf{e}_x, \mathbf{e}_c), 0)$Text–image cosine alignment in joint CLIP embedding space ($w = 2.5$).

    Worked 2D FID Example: Suppose real features follow $\boldsymbol{\mu}_r = [0, 0]^\top, \boldsymbol{\Sigma}_r = \operatorname{diag}(4, 9)$ and generated features follow $\boldsymbol{\mu}_g = [1, 2]^\top, \boldsymbol{\Sigma}_g = \operatorname{diag}(1, 4)$. Then $\|\boldsymbol{\mu}_r - \boldsymbol{\mu}_g\|_2^2 = 1^2 + 2^2 = 5$, $(\boldsymbol{\Sigma}_r\boldsymbol{\Sigma}_g)^{1/2} = \operatorname{diag}(2, 6)$, and $\operatorname{Tr}(\boldsymbol{\Sigma}_r + \boldsymbol{\Sigma}_g - 2(\boldsymbol{\Sigma}_r\boldsymbol{\Sigma}_g)^{1/2}) = (4+1-4) + (9+4-12) = 2$, giving $\operatorname{FID} = 5 + 2 = \mathbf{7.0}$.

    4. Unsupervised Clustering: Silhouette, ARI, and NMI

    Internal clustering metrics evaluate geometry using only pairwise distances $d(i, j)$, whereas external metrics compare predicted clusters $U = \{U_1,\dots,U_R\}$ against ground-truth classes $V = \{V_1,\dots,V_C\}$ with contingency counts $n_{ij} = |U_i \cap V_j|$:

    $$s(i) = \frac{b(i) - a(i)}{\max\big(a(i),\, b(i)\big)} \in [-1, 1], \qquad \operatorname{NMI}(U, V) = \frac{2\,I(U; V)}{H(U) + H(V)} \in [0, 1],$$
    $$\operatorname{ARI} = \frac{\sum_{i,j}\binom{n_{ij}}{2} - \left[\sum_i\binom{a_i}{2}\sum_j\binom{b_j}{2}\right] \big/ \binom{N}{2}}{\frac{1}{2}\left[\sum_i\binom{a_i}{2} + \sum_j\binom{b_j}{2}\right] - \left[\sum_i\binom{a_i}{2}\sum_j\binom{b_j}{2}\right] \big/ \binom{N}{2}} \in [-1, 1].$$

    Subtracting the hypergeometric chance expectation in $\operatorname{ARI}$ (and normalizing by $H(U)+H(V)$ in $\operatorname{NMI}$) prevents the singleton-cluster trap where increasing $K \to N$ trivially inflates unadjusted mutual information or raw Rand Index.

    5. Reference Python Implementation

    from typing import Sequence, Tuple

Box = Tuple[float, float, float, float]  # (x1, y1, x2, y2)

def box_iou_dice_giou(a: Box, b: Box) -> Tuple[float, float, float]:
    area_a = max(0.0, a[2] - a[0]) * max(0.0, a[3] - a[1])
    area_b = max(0.0, b[2] - b[0]) * max(0.0, b[3] - b[1])
    inter = max(0.0, min(a[2], b[2]) - max(a[0], b[0])) * max(0.0, min(a[3], b[3]) - max(a[1], b[1]))
    union = area_a + area_b - inter
    iou = inter / union if union > 0 else 0.0
    dice = (2.0 * inter) / (area_a + area_b) if (area_a + area_b) > 0 else 0.0
    area_c = max(0.0, max(a[2], b[2]) - min(a[0], b[0])) * max(0.0, max(a[3], b[3]) - min(a[1], b[1]))
    giou = iou - (area_c - union) / area_c if area_c > 0 else iou
    return round(iou, 4), round(dice, 4), round(giou, 4)

def adjusted_rand_index(u_labels: Sequence[int], v_labels: Sequence[int]) -> float:
    n = len(u_labels)
    u_set, v_set = sorted(set(u_labels)), sorted(set(v_labels))
    comb2 = lambda k: k * (k - 1) // 2
    grid = {(u, v): 0 for u in u_set for v in v_set}
    for u, v in zip(u_labels, v_labels):
        grid[(u, v)] += 1
    sum_nij = sum(comb2(c) for c in grid.values())
    sum_a = sum(comb2(sum(grid[(u, v)] for v in v_set)) for u in u_set)
    sum_b = sum(comb2(sum(grid[(u, v)] for u in u_set)) for v in v_set)
    expected = (sum_a * sum_b) / comb2(n)
    max_ri = 0.5 * (sum_a + sum_b)
    return round((sum_nij - expected) / (max_ri - expected), 4) if max_ri != expected else 1.0

print("IoU, Dice, GIoU:", box_iou_dice_giou((0, 0, 4, 4), (2, 2, 6, 6)))
print("ARI            :", adjusted_rand_index([0, 0, 1, 1, 2, 2], [1, 1, 0, 0, 2, 1]))
