    CUPED & CUPAC: Pre-Experiment Covariate Variance Reduction ($1 - \rho^2$)

    October 2026 · ML System Design · Control Variates in Online Experimentation

    The largest source of variance in an online A/B test is not the treatment effect—it is pre-existing between-user heterogeneity. Power users watch $180\text{ minutes/day}$ while casual users watch $5\text{ minutes/day}$. By subtracting out the predictable component of each user's behavior measured before the experiment began, CUPED (Controlled-experiment Using Pre-Experiment Data, Deng et al. 2013) reduces estimator variance by a factor of $(1 - \rho^2)$—often equivalent to doubling or tripling your A/B test traffic for free.

    1. Mathematical Derivation of CUPED

    For each user $u$, let $Y_u$ be the post-treatment metric measured during the experiment, and let $X_u$ be a pre-experiment covariate measured strictly prior to treatment assignment (most commonly, the exact same metric $Y_u$ computed over the 7 or 14 days before the test started).

    Because $X_u$ is measured before randomization, treatment assignment is statistically independent of $X_u$, meaning the population expectation of $X_u$ is identical in Treatment and Control: $\mathbb{E}[X_T] = \mathbb{E}[X_C] = \mu_X$. Now define the CUPED-adjusted user metric for any scalar constant $\theta \in \mathbb{R}$:

    $$\tilde{Y}_u(\theta) = Y_u - \theta\left(X_u - \mu_X\right)$$

    1.1 Proof of Unbiasedness

    Taking the expectation of the difference between Treatment and Control means:

    $$\mathbb{E}\!\left[\bar{\tilde{Y}}_T - \bar{\tilde{Y}}_C\right] = \left(\mathbb{E}[Y_T] - \mathbb{E}[Y_C]\right) - \theta\underbrace{\left(\mathbb{E}[X_T] - \mathbb{E}[X_C]\right)}_{= \, \mu_X - \mu_X \, = \, 0} = \mu_{Y,T} - \mu_{Y,C} = \delta$$

    Thus $\hat{\Delta}_{\text{CUPED}} = \bar{\tilde{Y}}_T - \bar{\tilde{Y}}_C$ is unbiased for any fixed $\theta$!

    1.2 Finding the Variance-Minimizing $\theta^*$

    Next, write the variance of $\tilde{Y}_u(\theta)$ as a quadratic function of $\theta$:

    $$\text{Var}\!\left(\tilde{Y}_u(\theta)\right) = \text{Var}(Y_u - \theta X_u) = \text{Var}(Y_u) - 2\theta\,\text{Cov}(Y_u, X_u) + \theta^2\,\text{Var}(X_u)$$

    Differentiating with respect to $\theta$ and setting to zero yields the optimal control-variate coefficient $\theta^*$ (which is simply the OLS slope of regressing $Y$ on $X$ pooled across both arms):

    $$\frac{\partial}{\partial \theta}\text{Var}\!\left(\tilde{Y}_u(\theta)\right) = -2\,\text{Cov}(Y, X) + 2\theta\,\text{Var}(X) = 0 \implies \boxed{\theta^* = \frac{\text{Cov}(Y, X)}{\text{Var}(X)}}$$

    Substituting $\theta^*$ back into $\text{Var}(\tilde{Y}_u(\theta))$ and recalling the Pearson correlation $\rho = \frac{\text{Cov}(Y, X)}{\sqrt{\text{Var}(Y)\text{Var}(X)}}$:

    $$\text{Var}\!\left(\tilde{Y}_u(\theta^*)\right) = \text{Var}(Y) - \frac{\text{Cov}(Y, X)^2}{\text{Var}(X)} = \text{Var}(Y)\!\left(1 - \frac{\text{Cov}(Y, X)^2}{\text{Var}(Y)\text{Var}(X)}\right) = \boxed{\text{Var}(Y)\left(1 - \rho^2\right)}$$
    Equivalent Traffic Multiplier & MDE Shrinkage: Because sample size scales linearly with variance ($n \propto \sigma^2$), reducing variance by $(1-\rho^2)$ provides an Effective Traffic Multiplier of $\frac{1}{1-\rho^2}$ and shrinks the Minimum Detectable Effect by $\sqrt{1-\rho^2}$:
    • If $\rho = 0.50 \implies 1 - \rho^2 = 0.75$ ($25\%$ variance drop, $1.33\times$ effective traffic).
    • If $\rho = 0.70 \implies 1 - \rho^2 = 0.51$ ($49\%$ variance drop, $1.96\times$ effective traffic).
    • If $\rho = 0.80 \implies 1 - \rho^2 = 0.36$ ($64\%$ variance drop, $2.78\times$ effective traffic, MDE shrinks by $40\%$).

    2. From Single-Covariate CUPED to ML-Driven CUPAC

    Instead of using a single linear pre-experiment metric $X_u$, CUPAC (Control Using Predictions as Covariates, DoorDash / Uber / Meta) trains a Gradient Boosted Decision Tree (LightGBM) or neural network $g(\mathbf{x}_u^{\text{pre}})$ on historical data to predict $Y_u$ from dozens of pre-experiment features $\mathbf{x}_u^{\text{pre}}$ (7-day, 14-day, and 28-day engagement, device OS, account tenure, historical conversion rate).

    We then set the scalar covariate to the out-of-fold ML prediction $X_u = \hat{Y}_u^{\text{pre}} = g(\mathbf{x}_u^{\text{pre}})$ and apply standard CUPED. Because $g(\mathbf{x}_u^{\text{pre}})$ captures nonlinear interactions across multiple lookback windows, $\rho(Y, \hat{Y}^{\text{pre}})$ is higher than any single pre-period metric—while remaining $100\%$ unbiased as long as $\mathbf{x}_u^{\text{pre}}$ and model weights $g$ depend strictly on pre-experiment data!

    3. Combining CUPED with the Delta Method for Ratio Metrics

    What if our target metric is a clustered ratio $\hat{R} = \bar{Y}/\bar{X}$ (like $\text{CTR}$ or $\text{AOV}$)? As shown in Note 01.3, we first compute the linearized user-level metric during the experiment ($L_u = \frac{Y_u - \hat{R}_C X_u}{\bar{X}_C}$) and during the pre-experiment window ($L_u^{\text{pre}} = \frac{Y_u^{\text{pre}} - \hat{R}_{\text{pre}} X_u^{\text{pre}}}{\bar{X}_{\text{pre}}}$), and then apply CUPED directly to the pair $(L_u, L_u^{\text{pre}})$! For new users who have no pre-experiment history ($X_u = \text{missing}$), we impute $X_u = \mu_X$ so their adjustment $\theta^*(X_u - \mu_X)$ is zero.

    4. Production Python Implementation: Pooled CUPED Estimator

    import numpy as np
from scipy import stats

def cuped_ab_test(
    y_c: np.ndarray, x_c: np.ndarray,
    y_t: np.ndarray, x_t: np.ndarray,
) -> dict:
    """
    Runs a two-sample A/B test with CUPED pre-experiment covariate adjustment.
    Note: theta* and mu_X MUST be pooled across Control and Treatment.
    """
    y_pool = np.concatenate([y_c, y_t])
    x_pool = np.concatenate([x_c, x_t])

    mu_x = x_pool.mean()
    cov_yx = np.cov(y_pool, x_pool, ddof=1)[0, 1]
    var_x = x_pool.var(ddof=1)
    theta = cov_yx / var_x
    rho = np.corrcoef(y_pool, x_pool)[0, 1]

    # CUPED-adjusted user metrics
    y_c_adj = y_c - theta * (x_c - mu_x)
    y_t_adj = y_t - theta * (x_t - mu_x)

    # Compare raw vs CUPED standard errors
    se_raw = np.sqrt(y_c.var(ddof=1) / len(y_c) + y_t.var(ddof=1) / len(y_t))
    se_cuped = np.sqrt(y_c_adj.var(ddof=1) / len(y_c_adj) + y_t_adj.var(ddof=1) / len(y_t_adj))

    delta_raw = y_t.mean() - y_c.mean()
    delta_cuped = y_t_adj.mean() - y_c_adj.mean()
    z_cuped = delta_cuped / se_cuped
    p_cuped = 2.0 * (1.0 - stats.norm.cdf(abs(z_cuped)))

    return {
        "theta": round(float(theta), 4),
        "rho": round(float(rho), 4),
        "variance_reduction_pct": round(float((1.0 - (se_cuped / se_raw) ** 2) * 100), 2),
        "effective_traffic_multiplier": round(float((se_raw / se_cuped) ** 2), 2),
        "delta_raw": round(float(delta_raw), 4),
        "delta_cuped": round(float(delta_cuped), 4),
        "se_raw": round(float(se_raw), 4),
        "se_cuped": round(float(se_cuped), 4),
        "p_value_cuped": float(p_cuped),
    }

if __name__ == "__main__":
    rng = np.random.default_rng(123)
    # Pre-experiment baseline watch time ~ N(40, 15^2)
    x_c = rng.normal(40.0, 15.0, size=20_000)
    x_t = rng.normal(40.0, 15.0, size=20_000)
    # In-experiment watch time strongly correlated with pre-experiment (rho ~ 0.78)
    y_c = 0.8 * x_c + rng.normal(8.0, 9.5, size=20_000)
    y_t = 0.8 * x_t + rng.normal(8.45, 9.5, size=20_000)  # +0.45 min true lift
    print(cuped_ab_test(y_c, x_c, y_t, x_t))

    5. Self-Check & Interview Exercises

    Exercise 1 — What Happens If the Covariate $X_u$ Is Affected by the Treatment?

    Suppose an engineer accidentally computes $X_u$ over a window that overlaps with the first 2 days of the A/B test, or uses an in-experiment feature like "number of sessions during the test" as the CUPED covariate $X_u$. What goes wrong mathematically?

    Check solution

    If $X_u$ is influenced by the treatment, then $\mathbb{E}[X_T] - \mathbb{E}[X_C] = \delta_X \ne 0$. Consequently, $\mathbb{E}[\bar{\tilde{Y}}_T - \bar{\tilde{Y}}_C] = \delta_Y - \theta \delta_X$, introducing severe post-treatment conditioning bias (often absorbing and erasing the true treatment effect $\delta_Y$!). Covariates in CUPED/CUPAC must be strictly frozen prior to a user's first exposure to the experiment.
