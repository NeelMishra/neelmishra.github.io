    Ratio Metrics, Intra-User Clustering & the Delta Method Linearization

    October 2026 · ML System Design · Variance of Clustered Ratio Estimators

    One of the most frequent follow-up questions in Senior/Staff ML System Design interviews is: "In our A/B test, we randomize by user ID, but our primary metric is global $\text{CTR} = \text{Total Clicks} / \text{Total Impressions}$ (or $\text{AOV} = \text{Total Revenue} / \text{Total Orders}$). Can we use a standard binomial $z$-test across impressions?" The answer is an emphatic no. Because impressions from the same user are positively correlated, the naïve binomial formula underestimates the true variance by $3\times$ to $10\times$, turning noise into false positives. Here we derive the Delta Method and User-Level Linearization.

    1. Why Unit of Analysis $\ne$ Unit of Randomization Breaks Naïve Variance

    Suppose $n$ users are independently randomized into an arm. User $u \in \{1, \dots, n\}$ generates $X_u$ impressions (or sessions, or orders) and $Y_u$ clicks (or revenue). The global ratio metric is:

    $$\hat{R} = \frac{\sum_{u=1}^{n} Y_u}{\sum_{u=1}^{n} X_u} = \frac{\frac{1}{n}\sum_{u=1}^{n} Y_u}{\frac{1}{n}\sum_{u=1}^{n} X_u} = \frac{\bar{Y}}{\bar{X}}$$

    Notice two crucial properties of $\hat{R} = \bar{Y} / \bar{X}$:

    1. Both numerator $\bar{Y}$ and denominator $\bar{X}$ are random variables! A ranking treatment can change not only how often users click ($Y_u$), but also how many pages/impressions ($X_u$) they view per session.
    2. Intra-user clustering (Design Effect): Two impressions shown to the same user $u$ are not independent. If a cluster of size $m$ has intra-cluster correlation $\rho_{\text{ICC}}$, its variance is inflated by Kish's Design Effect $\text{DEFF} \approx 1 + (m - 1)\rho_{\text{ICC}}$. Only the user-level pairs $(Y_u, X_u)$ are independent and identically distributed ($\text{i.i.d.}$) across $u=1,\dots,n$.

    2. First-Order Taylor Expansion: The Bivariate Delta Method

    Let $(Y_u, X_u)$ be $\text{i.i.d.}$ across $u = 1, \dots, n$ with mean vector $\boldsymbol{\mu} = (\mu_Y, \mu_X)^\top$, true ratio $R = \mu_Y / \mu_X$, variances $\sigma_Y^2 = \text{Var}(Y_u)$, $\sigma_X^2 = \text{Var}(X_u)$, and covariance $\sigma_{YX} = \text{Cov}(Y_u, X_u)$. Define $f(y, x) = y / x$. Its gradient at $(\mu_Y, \mu_X)$ is:

    $$\nabla f(\mu_Y, \mu_X) = \begin{bmatrix} \frac{\partial f}{\partial y} \\[4pt] \frac{\partial f}{\partial x} \end{bmatrix}_{(\mu_Y, \mu_X)} = \begin{bmatrix} \frac{1}{\mu_X} \\[6pt] -\frac{\mu_Y}{\mu_X^2} \end{bmatrix} = \frac{1}{\mu_X} \begin{bmatrix} 1 \\ -R \end{bmatrix}$$

    Applying a first-order Taylor expansion of $\hat{R} = f(\bar{Y}, \bar{X})$ around $(\mu_Y, \mu_X)$:

    $$\hat{R} - R \approx \frac{1}{\mu_X}(\bar{Y} - \mu_Y) - \frac{R}{\mu_X}(\bar{X} - \mu_X) = \frac{1}{\mu_X}\left(\bar{Y} - R\bar{X}\right)$$

    Taking the variance of the right-hand side and noting that $\text{Var}(\bar{Y}) = \sigma_Y^2 / n$, $\text{Var}(\bar{X}) = \sigma_X^2 / n$, and $\text{Cov}(\bar{Y}, \bar{X}) = \sigma_{YX} / n$:

    $$\boxed{\text{Var}(\hat{R}) \approx \frac{1}{n \, \mu_X^2}\left(\sigma_Y^2 - 2 R \, \sigma_{YX} + R^2 \, \sigma_X^2\right)}$$

    Dividing through by $R^2 = \mu_Y^2 / \mu_X^2$ gives the symmetric relative-variance form:

    $$\frac{\text{Var}(\hat{R})}{R^2} \approx \frac{1}{n}\left(\frac{\sigma_Y^2}{\mu_Y^2} - 2\frac{\sigma_{YX}}{\mu_Y \mu_X} + \frac{\sigma_X^2}{\mu_X^2}\right)$$

    3. Per-User Linearization Trick ($L_u = Y_u - R_{\text{ctrl}} X_u$)

    Looking closely at the Taylor expansion $\hat{R} - R \approx \frac{1}{\mu_X}(\bar{Y} - R\bar{X})$, notice that if we define the linearized user-level metric $L_u$:

    $$L_u = \frac{1}{\bar{X}_C}\left(Y_u - \hat{R}_C X_u\right)$$

    then the sample variance of $L_u$ across users is algebraically identical to the Delta Method variance:

    $$\text{Var}(L_u) = \frac{1}{\bar{X}_C^2}\text{Var}(Y_u - \hat{R}_C X_u) = \frac{1}{\bar{X}_C^2}\left(\sigma_Y^2 - 2\hat{R}_C \sigma_{YX} + \hat{R}_C^2 \sigma_X^2\right)$$

    This result (popularized by Deng et al. at Microsoft/Airbnb) is a superpower for experimentation infrastructure: once you transform each user's $(Y_u, X_u)$ into a single scalar $L_u$, you can feed $L_u$ directly into standard user-level $t$-tests, quantile regressions, and CUPED variance reduction!

    Double-Ratio Warning — Average of Ratios vs. Ratio of Averages: Notice the difference between the Global Ratio $\hat{R}_{\text{global}} = \frac{\sum_u Y_u}{\sum_u X_u}$ (which weights impressions equally and measures total platform revenue/clicks per impression) and the Mean User Ratio $\bar{R}_{\text{user}} = \frac{1}{n}\sum_{u=1}^n \frac{Y_u}{X_u}$ (which weights every active user equally, whether they did 1 search or 500 searches). Both are useful: $\hat{R}_{\text{global}}$ aligns with total business volume, whereas $\bar{R}_{\text{user}}$ prevents heavy power users (or undetected bots) from dominating the metric.

    4. Worked Numerical Example: Naïve Binomial vs. Delta Method

    Suppose $n = 10{,}000$ users see ads, with average impressions per user $\bar{X} = 20$, average clicks per user $\bar{Y} = 1.0$, so $\hat{R} = \text{CTR} = 1.0 / 20 = 5.0\%$ across $N_{\text{imp}} = 200{,}000$ total impressions. Suppose user-level variances are $\sigma_Y^2 = 2.2$, $\sigma_X^2 = 150.0$, and covariance $\sigma_{YX} = 12.0$:

    • Naïve Binomial SE (Treating $200{,}000$ impressions as independent): $$\text{SE}_{\text{naïve}} = \sqrt{\frac{0.05 \times 0.95}{200{,}000}} = \sqrt{2.375 \times 10^{-7}} = 0.000487 \;\;(0.0487\%)$$
    • Exact Delta Method SE (Accounting for user clustering): $$\text{Var}(\hat{R}) = \frac{2.2 - 2(0.05)(12.0) + (0.05)^2(150.0)}{10{,}000 \times 20^2} = \frac{2.2 - 1.2 + 0.375}{4{,}000{,}000} = \frac{1.375}{4\times 10^6} = 3.4375 \times 10^{-7}$$ $$\text{SE}_{\text{Delta}} = \sqrt{3.4375 \times 10^{-7}} = 0.000586 \;\;(0.0586\%)$$

    Here $\text{Var}_{\text{Delta}} / \text{Var}_{\text{naïve}} = 1.45\times$ (and when $\sigma_Y^2$ is heavy-tailed, often $4\times\text{–}8\times$). Using the naïve SE shrinks confidence intervals artificially and produces rampant false discoveries.

    5. Production Python Implementation: Delta Method & Linearization

    import numpy as np
from scipy import stats

def delta_method_ratio_test(
    y_c: np.ndarray, x_c: np.ndarray,
    y_t: np.ndarray, x_t: np.ndarray,
) -> dict:
    """
    Two-sample A/B test for a clustered ratio metric R = sum(Y) / sum(X)
    using the bivariate Delta Method and user-level linearization.
    Inputs y_c, x_c, y_t, x_t are 1D arrays aggregated per randomization unit (user).
    """
    def _ratio_stats(y: np.ndarray, x: np.ndarray):
        n = len(y)
        mu_y, mu_x = y.mean(), x.mean()
        r = mu_y / mu_x
        var_y = y.var(ddof=1)
        var_x = x.var(ddof=1)
        cov_yx = np.cov(y, x, ddof=1)[0, 1]
        var_r = (var_y - 2.0 * r * cov_yx + (r ** 2) * var_x) / (n * (mu_x ** 2))
        return r, var_r, mu_x

    r_c, var_rc, mux_c = _ratio_stats(y_c, x_c)
    r_t, var_rt, _ = _ratio_stats(y_t, x_t)

    delta_abs = r_t - r_c
    delta_rel = delta_abs / r_c
    se_diff = np.sqrt(var_rc + var_rt)
    z_stat = delta_abs / se_diff
    p_val = 2.0 * (1.0 - stats.norm.cdf(abs(z_stat)))

    # Equivalent user-level linearized metric L_u
    l_c = (y_c - r_c * x_c) / mux_c
    l_t = (y_t - r_c * x_t) / mux_c

    return {
        "ratio_control": round(float(r_c), 6),
        "ratio_treatment": round(float(r_t), 6),
        "relative_lift_pct": round(float(delta_rel * 100), 4),
        "se_delta": round(float(se_diff), 6),
        "z_stat": round(float(z_stat), 4),
        "p_value": float(p_val),
        "linearized_diff_check": round(float(l_t.mean() - l_c.mean()), 6),
    }

if __name__ == "__main__":
    rng = np.random.default_rng(7)
    x_ctrl = rng.poisson(lam=20, size=10_000)
    p_user_c = rng.beta(2, 38, size=10_000)  # heterogeneous user CTR ~ 5%
    y_ctrl = rng.binomial(x_ctrl, p_user_c)

    x_trt = rng.poisson(lam=20, size=10_000)
    p_user_t = rng.beta(2.1, 37.9, size=10_000)  # ~5.25% CTR
    y_trt = rng.binomial(x_trt, p_user_t)

    print(delta_method_ratio_test(y_ctrl, x_ctrl, y_trt, x_trt))

    6. Self-Check & Interview Exercises

    Exercise 1 — Sign of the Covariance Term $-2R\sigma_{YX}$

    In $\text{Var}(\hat{R}) \approx \frac{1}{n\mu_X^2}(\sigma_Y^2 - 2R\sigma_{YX} + R^2\sigma_X^2)$, why does positive covariance $\sigma_{YX} > 0$ between user clicks $Y_u$ and user impressions $X_u$ reduce the variance of the ratio $\bar{Y}/\bar{X}$?

    Check solution

    When $Y_u$ and $X_u$ move together ($Y_u \approx R X_u$), users who generate $10\times$ more impressions also generate roughly $10\times$ more clicks, so the fluctuations in the numerator $\bar{Y}$ and denominator $\bar{X}$ cancel out in the division $\bar{Y}/\bar{X}$. In the extreme case where $Y_u = R X_u$ deterministically for every user, $\sigma_Y^2 - 2R\sigma_{YX} + R^2\sigma_X^2 = \text{Var}(Y_u - RX_u) = 0$.
