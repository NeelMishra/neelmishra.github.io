    Production LLMs, Code Copilots & Autonomous Agents: A/B Test Metrics Reading Guide

    October 2026 · Subdomain 07 · 3 Deep-Dive Notes

    Offline LLM benchmarks ($\text{MMLU}$, $\text{HumanEval}\text{ pass}@k$, $\text{RAGAS}$, or $\text{LLM-as-a-Judge}$ win rates) frequently fail to predict real-world user satisfaction once a model, prompt router, or agent workflow is deployed in production. In online A/B tests of conversational assistants (ChatGPT, Claude, Gemini), enterprise RAG support bots, and IDE code copilots (GitHub Copilot, Cursor), you must infer success from sparse explicit feedback ($<1\%$ Thumbs Up/Down), implicit behavioral telemetry (Copy/Export, Regeneration, Prompt Scolding, and 30-Minute Code Persistence), and strict systems/safety guardrails ($\text{TTFT}$, $\text{TPOT}$, Token Cost Per Resolved Task, and False-Refusal Rate).

    Deep-Dive Notes in Subdomain 07

    7.1
    Task Resolution / Deflection Rate, Thumbs Feedback, Copy Rate & Regeneration Rate

    Define True Automated Support Deflection Rate (resolved without human escalation AND without 24-hour re-contact); correct extreme reporting bias in sparse Thumbs Up/Down feedback via Inverse Propensity Weighting ($\text{IPW}$); and combine positive implicit signals (Copy/Apply/Share Rate) with frustration signals (Regeneration Rate, Prompt Reformulation / Scolding Rate).

    7.2
    Code Copilot Acceptance Rate, 30-Minute Code Persistence & Keystroke Savings

    Expose why raw Copilot Acceptance Rate ($\text{AR} = N_{\text{accepted}}/N_{\text{shown}}$) can be gamed by suppressing triggers or suggesting trivial single-token completions; derive $k$-Minute Code Survival / Persistence Rate via Myers diff and AST node matching at 30 minutes or `git commit`; and compute Net Keystrokes Saved and Percentage of Committed Code Written by AI.

    7.3
    TTFT, TPOT, Token Cost Per Resolved Task & Over-Refusal / Safety Guardrails

    Separate prefill latency ($\text{TTFT}$ $p_{50}/p_{95}$) from decode streaming latency ($\text{TPOT} / \text{ITL}$); formulate Token Cost Per Resolved Task accounting for multi-turn retries, agent tool loops, and KV-cache prefix hit rates; and balance safety filters using Prompt Injection Block Rate against False Refusal (Over-Refusal) Rate on benign queries.

    Generative AI & Copilot Online Metric Architecture

    Metric Formula Primary Gaming / Failure Mode Production Fix / Guardrail
    True Support Deflection Rate $\dfrac{N_{\text{no esc}} \cap N_{\text{no 24h repeat}}}{N_{\text{support sessions}}}$ Hiding the "Talk to Human" button inflates naïve containment while angry users open a new ticket 10 minutes later Require zero human escalation, zero repeat contact within 24–72h, and no negative CSAT/scolding
    Thumbs Up / Down Ratio $\sum_i \dfrac{R_i Y_i}{\hat{e}(X_i)} \Big/ \sum_i \dfrac{R_i}{\hat{e}(X_i)}$ Only $0.5\%\text{–}2\%$ of turns receive thumbs feedback, heavily skewed toward angry users ($R_i \not\perp Y_i$) Use IPW / Doubly-Robust propensity adjustment + implicit behavioral composite score
    Copilot Acceptance Rate ($\text{AR}$) $\dfrac{N_{\text{accepted}}}{N_{\text{shown}}}$ Triggering suggestions only on trivial `)` or `return` lines raises $\text{AR}$ while slashing total code written by AI Pair $\text{AR}$ with Accepted Characters per Active Coding Hour and 30-Minute Persistence Rate
    $30\text{-Min}$ Code Persistence $\dfrac{\sum_{s \in \mathcal{A}} \text{KeptChars}_{30\text{m}}(s)}{\sum_{s \in \mathcal{A}} \text{AcceptedChars}_0(s)}$ Users reflexively press `Tab` to inspect a multiline suggestion and immediately delete 80% of it Measure character/AST Levenshtein survival at $t + 30\text{m}$ and at `git commit`
    Cost Per Resolved Task ($\text{CPRT}$) $\dfrac{\sum_{\text{all turns}} C_{\text{tokens + tools}}}{N_{\text{resolved tasks}}}$ A cheaper smaller model lowers cost-per-request by $-60\%$ but requires $3.5\times$ more retry turns and fails more tasks Always normalize serving cost by successfully resolved tasks, never by single API calls
