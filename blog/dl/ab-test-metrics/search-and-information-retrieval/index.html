    Subdomain 03: Web, E-Commerce & Enterprise Search A/B Test Metrics

    October 2026 · Subdomain 03 Reading Guide · 3 Deep-Dive Notes

    In digital advertising or social feeds, more clicks and longer dwell time on the platform are almost always positive signals. In search engines, the exact opposite often holds: a great search system helps the user find the exact document, product, or instant answer as fast as possible and leave the Search Engine Results Page (SERP) satisfied. Optimizing raw SERP Click-Through Rate ($\text{CTR}$) or queries per user rewards degraded ranking that forces users to click multiple irrelevant links and reformulate queries repeatedly. This subdomain builds the complete mathematical and statistical framework for evaluating search systems online.

    Why Search Online Evaluation Differs from Feed & Ad Ranking

    When transitioning from offline evaluation ($\text{nDCG}@10$, $\text{MRR}$, $\text{Recall}@100$ on human-graded relevance sets) to live A/B testing, search engineers encounter three structural paradoxes:

    PARADOX 01 Raw CTR Can Move Inverse to Quality If a ranking bug demotes the exact navigational result from rank $1$ to rank $4$, users may click ranks $1$, $2$, and $4$ before finding what they need—inflating total clicks per query while degrading user satisfaction.
    PARADOX 02 Zero Clicks Can Mean 100% Satisfaction Modern SERPs embed direct answers (weather cards, calculators, package tracking, LLM AI Overviews, knowledge panels). A user who reads the answer and leaves without clicking is a Good Abandonment, not a failure.
    PARADOX 03 Query-Level Denominators Are Endogenous If Treatment reduces query reformulations by $15\%$, the total number of queries $\sum_u Q_u$ drops—removing the "easiest follow-up queries" or "hardest retry queries" and biasing any metric normalized per query rather than per session or per user.

    Deep-Dive Notes in Subdomain 03

    01
    Session Success Rate, Time-to-First-Click (TTFC) & Mean Reciprocal Click Rank (MRCR)

    Define Search Sessions ($30$-minute inactivity or intent-boundary segmentation), construct composite Session Success Rate uniting satisfied clicks ($\tau_{\text{dwell}} \ge 30\text{s}$ or terminal task completion) with Good Abandonment, model Time-to-First-Click ($\text{TTFC}$) via log-normal / Weibull survival analysis, and pair $\text{TTFC}$ with Online Mean Reciprocal Click Rank ($\text{MRCR}$) to separate ranking improvements from snippet-reading latency.

    02
    Search Abandonment (Good vs. Bad Abandonment) & Pogo-Sticking / Short-Dwell Bounces

    Decompose clickless queries into Good Abandonment (direct SERP satisfaction via answer cards or LLM summaries) vs. Bad Abandonment (frustrated exit or immediate retry), formalize probabilistic Good-Abandonment attribution using viewport dwell and query-intent classifiers, and measure Pogo-Sticking Rate—consecutive clicks with short dwell ($d_j < \tau_{\text{short}}$) that expose misleading snippets and clickbait titles.

    03
    Query Reformulation Rate (QRR), Zero-Result Rate (ZRR) & Autocomplete Keystroke Savings

    Quantify user query-refinement friction through Query Reformulation Rate ($\text{QRR}$) using character Levenshtein similarity, token Jaccard overlap, and dense bi-encoder cosine similarity inside a session window; evaluate retrieval recall via Zero-Result Rate ($\text{ZRR}$) and soft-relaxation fallback conversion; and measure typeahead efficiency with Keystroke Savings ($\text{KSS}$).

    Search & IR Online Metrics Reference Matrix

    Metric Name Mathematical Definition Healthy Direction Primary Blind Spot / Guardrail Pair
    Session Success Rate ($\text{SSR}$) $\dfrac{1}{|\mathcal{S}|}\sum_{s \in \mathcal{S}} \mathbb{I}\!\left[\text{SatClick}(s) \lor \text{GoodAband}(s)\right]$ Higher ($\uparrow$) Sensitive to the dwell threshold $\tau_{\text{sat}}$ (typically $30\text{s}$); pair with task-specific terminal actions (cart add, file download).
    Time-to-First-Click ($\text{TTFC}$) $\exp\!\left(\dfrac{1}{|\mathcal{Q}_c|}\sum_{q \in \mathcal{Q}_c}\ln(t_{\text{click},q} - t_{\text{render},q})\right)$ Lower ($\downarrow$) Only observed on clicked queries $\mathcal{Q}_c$ (selection bias); richer snippets can increase $\text{TTFC}$ while reducing Pogo-Sticking.
    Online $\text{MRCR}$ $\dfrac{1}{|\mathcal{Q}|}\sum_{q \in \mathcal{Q}}\dfrac{\mathbb{I}[\text{clicked}(q)]}{r_{\text{first}}(q)}$ Higher ($\uparrow$) Penalizes Good Abandonment if unadjusted ($r_{\text{first}}=\infty \implies 0$); compute both unconditional and conditional on click.
    Bad Abandonment Rate $\dfrac{1}{|\mathcal{Q}|}\sum_{q \in \mathcal{Q}}\mathbb{I}[\text{NoClick}(q) \land \neg\text{GoodAband}(q)]$ Lower ($\downarrow$) Requires accurate instant-answer viewport tracking to avoid misclassifying Knowledge Panel reads as bad abandonment.
    Pogo-Sticking Rate $\dfrac{1}{|\mathcal{S}|}\sum_{s \in \mathcal{S}}\mathbb{I}\!\left[\exists\, c_j \in s : d(c_j) < \tau_{\text{short}} \land \text{NextAction}(c_j) \in \text{SERP}\right]$ Lower ($\downarrow$) Fast factual lookups (e.g., checking a phone number on a target page) can have $d(c_j) < 10\text{s}$ without dissatisfaction; require a subsequent SERP click or reformulation.
    Query Reformulation Rate ($\text{QRR}$) $\dfrac{1}{|\mathcal{Q}|}\sum_{i}\mathbb{I}\!\left[\Delta t_{i,i+1} \le \tau_w \land \text{sim}(q_i,q_{i+1}) \ge \gamma \land \neg\text{Sat}(q_i)\right]$ Lower ($\downarrow$) Exploratory browsing naturally involves topic pivots; filter to unsatisfied same-intent reformulations.
    Zero-Result Rate ($\text{ZRR}$) $\dfrac{1}{|\mathcal{Q}|}\sum_{q \in \mathcal{Q}}\mathbb{I}[|\mathcal{D}(q)| = 0]$ Lower ($\downarrow$) Naïvely relaxing boolean filters drives $\text{ZRR} \to 0\%$ by showing junk results; always pair $\text{ZRR}$ with Post-Fallback Pogo-Sticking and Conversion Rate.
    Keystroke Savings ($\text{KSS}$) $1 - \dfrac{\text{chars\_typed}(q)}{\text{chars\_submitted}(q)}$ Higher ($\uparrow$) Aggressive autocomplete can steer users into popular head queries that do not match their specific tail intent (increasing subsequent $\text{QRR}$).
