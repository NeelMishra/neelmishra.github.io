    2. Output-Layer Loss Gradients: MSE, Sigmoid + BCE, and Softmax + Cross-Entropy

    October 2026 · 6 min read

    Every backward pass starts at the output layer with $\delta^{(L)} = \partial \mathcal{L} / \partial z^{(L)}$. For Linear + MSE, Sigmoid + BCE, and Softmax + Cross-Entropy, the derivative simplifies to the same residual: $\delta^{(L)} = \hat{y} - y$.

    1. Identity output + Mean Squared Error (MSE)

    For continuous regression on $y \in \mathbb{R}^{d_L}$, the final layer applies the identity map $a_i^{(L)} = \hat{y}_i = z_i^{(L)}$ and minimizes the half squared Euclidean error:

    $$\mathcal{L}_{\text{MSE}}(\hat{y}, y) = \frac{1}{2}\|\hat{y} - y\|_2^2 = \frac{1}{2}\sum_{k=1}^{d_L} \bigl(\hat{y}_k - y_k\bigr)^2.$$

    Differentiating with respect to output coordinate $\hat{y}_i = a_i^{(L)}$ affects only the $k=i$ term in the sum:

    $$\frac{\partial \mathcal{L}_{\text{MSE}}}{\partial a_i^{(L)}} = \frac{1}{2} \cdot 2\bigl(a_i^{(L)} - y_i\bigr) = \hat{y}_i - y_i, \qquad \phi_L'\!\bigl(z_i^{(L)}\bigr) = \frac{d}{dz_i^{(L)}}\bigl(z_i^{(L)}\bigr) = 1.$$

    Multiplying the two factors via BP1 gives:

    $$\delta_i^{(L)} = \frac{\partial \mathcal{L}_{\text{MSE}}}{\partial z_i^{(L)}} = \hat{y}_i - y_i \quad \Longleftrightarrow \quad \delta^{(L)} = \hat{y} - y \in \mathbb{R}^{d_L}.$$

    2. Logistic Sigmoid + Binary Cross-Entropy (BCE)

    For binary classification ($y_k \in \{0, 1\}$), each output unit applies the logistic sigmoid $\hat{p}_i = a_i^{(L)} = \sigma\bigl(z_i^{(L)}\bigr) = \frac{1}{1 + e^{-z_i^{(L)}}}$ and minimizes the Binary Cross-Entropy loss:

    $$\mathcal{L}_{\text{BCE}}(\hat{p}, y) = -\sum_{k=1}^{d_L} \Bigl[y_k \log \hat{p}_k + (1 - y_k)\log(1 - \hat{p}_k)\Bigr].$$

    Computing the two factors of BP1 ($\delta_i^{(L)} = \frac{\partial \mathcal{L}}{\partial \hat{p}_i} \frac{\partial \hat{p}_i}{\partial z_i^{(L)}}$):

    1. Derivative of BCE loss with respect to probability $\hat{p}_i$:
      $$\frac{\partial \mathcal{L}_{\text{BCE}}}{\partial \hat{p}_i} = -\left(\frac{y_i}{\hat{p}_i} - \frac{1 - y_i}{1 - \hat{p}_i}\right) = \frac{\hat{p}_i - y_i}{\hat{p}_i(1 - \hat{p}_i)}.$$
    2. Derivative of the logistic sigmoid $\hat{p}_i = \sigma\bigl(z_i^{(L)}\bigr)$ with respect to logit $z_i^{(L)}$:
      $$\frac{\partial \hat{p}_i}{\partial z_i^{(L)}} = \frac{e^{-z_i^{(L)}}}{\bigl(1 + e^{-z_i^{(L)}}\bigr)^2} = \hat{p}_i(1 - \hat{p}_i).$$
    3. Multiplying the two factors together (BP1): The $\hat{p}_i(1 - \hat{p}_i)$ terms cancel directly:
      $$\delta_i^{(L)} = \frac{\hat{p}_i - y_i}{\hat{p}_i(1 - \hat{p}_i)} \cdot \hat{p}_i(1 - \hat{p}_i) = \hat{p}_i - y_i \quad \Longleftrightarrow \quad \delta^{(L)} = \hat{p} - y \in \mathbb{R}^{d_L}.$$

    3. Softmax Jacobian + Categorical Cross-Entropy

    For $C$-class classification ($d_L = C$), the Softmax head maps logits $z = z^{(L)} \in \mathbb{R}^C$ to probabilities:

    $$\hat{p}_k = \operatorname{Softmax}_k(z) = \frac{e^{z_k}}{\sum_{m=1}^C e^{z_m}} = \frac{e^{z_k}}{S(z)}, \qquad \text{where } S(z) \triangleq \sum_{m=1}^C e^{z_m}.$$

    Because changing a single logit $z_i$ changes the denominator $S(z)$, it changes all $C$ output probabilities $\hat{p}_1, \dots, \hat{p}_C$ simultaneously:

    Step 3a: Deriving $\frac{\partial \hat{p}_k}{\partial z_i}$ for diagonal ($k = i$) and off-diagonal ($k \neq i$) entries

    Since $\frac{\partial S(z)}{\partial z_i} = e^{z_i}$, applying the quotient rule to $\hat{p}_k = \frac{e^{z_k}}{S(z)}$ gives:

    • Diagonal ($k = i$): $\dfrac{\partial \hat{p}_i}{\partial z_i} = \dfrac{e^{z_i} S(z) - e^{z_i} e^{z_i}}{S(z)^2} = \hat{p}_i - \hat{p}_i^2 = \hat{p}_i(1 - \hat{p}_i).$
    • Off-diagonal ($k \neq i$): $\dfrac{\partial \hat{p}_k}{\partial z_i} = -\dfrac{e^{z_k} e^{z_i}}{S(z)^2} = -\hat{p}_k \hat{p}_i.$
    $$\frac{\partial \hat{p}_k}{\partial z_i} = \hat{p}_k\bigl(\delta_{ki} - \hat{p}_i\bigr) \quad \Longleftrightarrow \quad J_{\operatorname{Softmax}}(z) = \operatorname{diag}(\hat{p}) - \hat{p}\hat{p}^\top \in \mathbb{R}^{C \times C}.$$

    Step 3b: Summing over all $C$ paths into Categorical Cross-Entropy

    For $\mathcal{L}_{\text{CE}}(\hat{p}, y) = -\sum_{k=1}^C y_k \log \hat{p}_k$ (where $\sum_{k=1}^C y_k = 1$), we have $\frac{\partial \mathcal{L}_{\text{CE}}}{\partial \hat{p}_k} = -\frac{y_k}{\hat{p}_k}$. Summing over all $k = 1, \dots, C$:

    $$\delta_i^{(L)} = \sum_{k=1}^C \frac{\partial \mathcal{L}_{\text{CE}}}{\partial \hat{p}_k} \, \frac{\partial \hat{p}_k}{\partial z_i} = \sum_{k=1}^C \left(-\frac{y_k}{\hat{p}_k}\right) \hat{p}_k\bigl(\delta_{ki} - \hat{p}_i\bigr) = -\sum_{k=1}^C y_k \delta_{ki} + \hat{p}_i \sum_{k=1}^C y_k = \hat{p}_i - y_i.$$
    $$\delta^{(L)} = \operatorname{Softmax}\!\bigl(z^{(L)}\bigr) - y = \hat{p} - y \in \mathbb{R}^C.$$

    Sources
