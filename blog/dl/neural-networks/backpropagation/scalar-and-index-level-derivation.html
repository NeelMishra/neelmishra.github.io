    2. The Four Fundamental Equations of Backpropagation: Index-by-Index Scalar Derivation

    October 2026 · 17 min read

    When deriving matrix gradients, guessing where transposes $(\cdot)^\top$ and outer products go by "matching dimensions" is error-prone and obscures the underlying calculus. The cleanest way to derive backpropagation with zero ambiguity is to drop down to scalar coordinates with explicit summation indices, apply the single-variable and multivariable chain rules step by step, and then recognize the resulting index sums as standard vector-matrix operations.

    1. Forward equations in explicit index notation

    Consider an $L$-layer feed-forward network evaluated on a single input $a^{(0)} = x \in \mathbb{R}^{d_0}$ with scalar loss $\mathcal{L}\bigl(a^{(L)}, y\bigr) \in \mathbb{R}$. For every layer $\ell \in \{1, 2, \dots, L\}$ and every neuron index $i \in \{1, 2, \dots, d_\ell\}$, the forward pass computes:

    $$z_i^{(\ell)} = \sum_{j=1}^{d_{\ell-1}} W_{ij}^{(\ell)}\, a_j^{(\ell-1)} + b_i^{(\ell)}, \qquad a_i^{(\ell)} = \phi_\ell\!\bigl(z_i^{(\ell)}\bigr),$$

    where:

    • $W_{ij}^{(\ell)} \in \mathbb{R}$ is the weight connecting source unit $j$ in layer $\ell-1$ to destination unit $i$ in layer $\ell$ (so $W^{(\ell)} \in \mathbb{R}^{d_\ell \times d_{\ell-1}}$ has row index $i$ and column index $j$).
    • $b_i^{(\ell)} \in \mathbb{R}$ is the bias of unit $i$ in layer $\ell$.
    • $z_i^{(\ell)} \in \mathbb{R}$ is the pre-activation (weighted input) of unit $i$ in layer $\ell$.
    • $a_i^{(\ell)} \in \mathbb{R}$ is the post-activation of unit $i$ in layer $\ell$, with $\phi_\ell : \mathbb{R} \to \mathbb{R}$ applied coordinate-wise.

    Defining the error sensitivity (adjoint) $\delta_i^{(\ell)}$

    Every parameter $W_{ij}^{(\ell)}$ and $b_i^{(\ell)}$ influences the loss $\mathcal{L}$ exclusively through the pre-activation scalar $z_i^{(\ell)}$. We therefore define the error sensitivity (or adjoint) of neuron $i$ in layer $\ell$ as the partial derivative of the loss with respect to clamping its pre-activation $z_i^{(\ell)}$:

    $$\boxed{\delta_i^{(\ell)} \triangleq \frac{\partial \mathcal{L}}{\partial z_i^{(\ell)}}, \qquad \ell \in \{1, \dots, L\}, \quad i \in \{1, \dots, d_\ell\}.}$$

    Stacking these $d_\ell$ scalars into a column vector gives $\delta^{(\ell)} \triangleq \nabla_{z^{(\ell)}} \mathcal{L} = \bigl[\delta_1^{(\ell)}, \dots, \delta_{d_\ell}^{(\ell)}\bigr]^\top \in \mathbb{R}^{d_\ell}$. Let us now derive the four equations (BP1–BP4) that compute $\delta^{(L)}$, propagate $\delta^{(\ell+1)} \to \delta^{(\ell)}$, and extract $\frac{\partial \mathcal{L}}{\partial b_i^{(\ell)}}$ and $\frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}}$.

    2. Derivation of BP1: Output-layer sensitivity $\delta^{(L)}$

    At the final layer $\ell = L$, the loss $\mathcal{L}\bigl(a_1^{(L)}, \dots, a_{d_L}^{(L)}\bigr)$ is a function of the output activations $a_k^{(L)} = \phi_L\bigl(z_k^{(L)}\bigr)$. If $\phi_L$ is an element-wise activation function (such as the identity for regression or element-wise logistic sigmoid $\sigma$ for binary/multi-label classification), then $z_i^{(L)}$ affects $\mathcal{L}$ only through the $i$-th output activation $a_i^{(L)}$ (since $\frac{\partial a_k^{(L)}}{\partial z_i^{(L)}} = 0$ for $k \neq i$).

    Applying the single-variable chain rule through $a_i^{(L)} = \phi_L\bigl(z_i^{(L)}\bigr)$:

    $$\delta_i^{(L)} = \frac{\partial \mathcal{L}}{\partial z_i^{(L)}} = \frac{\partial \mathcal{L}}{\partial a_i^{(L)}} \cdot \frac{\partial a_i^{(L)}}{\partial z_i^{(L)}} = \frac{\partial \mathcal{L}}{\partial a_i^{(L)}} \, \phi_L'\!\bigl(z_i^{(L)}\bigr), \qquad i = 1, \dots, d_L.$$

    Since each coordinate $i$ multiplies $\frac{\partial \mathcal{L}}{\partial a_i^{(L)}}$ by $\phi_L'(z_i^{(L)})$ element-wise, the vector form uses the Hadamard (element-wise) product $\odot$:

    $$\boxed{\text{(BP1)} \qquad \delta_i^{(L)} = \frac{\partial \mathcal{L}}{\partial a_i^{(L)}} \, \phi_L'\!\bigl(z_i^{(L)}\bigr) \quad \Longleftrightarrow \quad \delta^{(L)} = \nabla_{a^{(L)}} \mathcal{L} \odot \phi_L'\!\bigl(z^{(L)}\bigr) \in \mathbb{R}^{d_L}.}$$

    Note on coupled output heads (Softmax): When $\phi_L = \operatorname{Softmax}$, every output $a_k^{(L)}$ depends on every logit $z_i^{(L)}$, so the chain rule sums over all $k=1,\dots,d_L$: $\delta_i^{(L)} = \sum_{k=1}^{d_L} \frac{\partial \mathcal{L}}{\partial a_k^{(L)}} \frac{\partial a_k^{(L)}}{\partial z_i^{(L)}}$. As we prove in Chapter 4, for all canonical exponential-family pairs (Linear+MSE, Sigmoid+BCE, Softmax+CE), BP1 simplifies to $\delta^{(L)} = a^{(L)} - y = \hat{y} - y$.

    3. Derivation of BP2: Hidden-layer sensitivity recursion $\delta^{(\ell)}$ from $\delta^{(\ell+1)}$

    Now fix any hidden layer $\ell \in \{1, 2, \dots, L-1\}$ and a specific neuron $j \in \{1, 2, \dots, d_\ell\}$ in layer $\ell$. Assume we have already computed $\delta_k^{(\ell+1)} = \frac{\partial \mathcal{L}}{\partial z_k^{(\ell+1)}}$ for all neurons $k \in \{1, 2, \dots, d_{\ell+1}\}$ in the next layer $\ell+1$. How does $z_j^{(\ell)}$ influence the loss $\mathcal{L}$?

    1. First, $z_j^{(\ell)}$ passes through the activation function of neuron $j$ in layer $\ell$ to produce a single scalar activation: $$a_j^{(\ell)} = \phi_\ell\!\bigl(z_j^{(\ell)}\bigr).$$
    2. Second, that activation $a_j^{(\ell)}$ fans out across all $d_{\ell+1}$ outgoing synapses to enter the pre-activation of every neuron $k \in \{1, \dots, d_{\ell+1}\}$ in layer $\ell+1$: $$z_k^{(\ell+1)} = \sum_{m=1}^{d_\ell} W_{km}^{(\ell+1)}\, a_m^{(\ell)} + b_k^{(\ell+1)}, \qquad k = 1, \dots, d_{\ell+1}.$$

    Let us apply the multivariable chain rule from Chapter 1 step by step:

    1. Step 2a (Derivative of $\mathcal{L}$ with respect to $a_j^{(\ell)}$): Since $a_j^{(\ell)}$ has children $\operatorname{Ch}\bigl(a_j^{(\ell)}\bigr) = \bigl\{z_1^{(\ell+1)}, z_2^{(\ell+1)}, \dots, z_{d_{\ell+1}}^{(\ell+1)}\bigr\}$, the multivariable chain rule sums over all $k = 1, \dots, d_{\ell+1}$: $$\frac{\partial \mathcal{L}}{\partial a_j^{(\ell)}} = \sum_{k=1}^{d_{\ell+1}} \frac{\partial \mathcal{L}}{\partial z_k^{(\ell+1)}} \, \frac{\partial z_k^{(\ell+1)}}{\partial a_j^{(\ell)}}.$$ Now differentiate $z_k^{(\ell+1)} = \sum_{m=1}^{d_\ell} W_{km}^{(\ell+1)} a_m^{(\ell)} + b_k^{(\ell+1)}$ with respect to $a_j^{(\ell)}$. Every term in the sum over $m$ vanishes except $m = j$, giving: $$\frac{\partial z_k^{(\ell+1)}}{\partial a_j^{(\ell)}} = W_{kj}^{(\ell+1)}.$$ Substituting $\frac{\partial \mathcal{L}}{\partial z_k^{(\ell+1)}} = \delta_k^{(\ell+1)}$ and $\frac{\partial z_k^{(\ell+1)}}{\partial a_j^{(\ell)}} = W_{kj}^{(\ell+1)}$ yields: $$\frac{\partial \mathcal{L}}{\partial a_j^{(\ell)}} = \sum_{k=1}^{d_{\ell+1}} \delta_k^{(\ell+1)} \, W_{kj}^{(\ell+1)} = \sum_{k=1}^{d_{\ell+1}} \Bigl[\bigl(W^{(\ell+1)}\bigr)^\top\Bigr]_{jk} \delta_k^{(\ell+1)} = \Bigl[\bigl(W^{(\ell+1)}\bigr)^\top \delta^{(\ell+1)}\Bigr]_j.$$ Look closely at the indices in $\sum_{k=1}^{d_{\ell+1}} W_{kj}^{(\ell+1)} \delta_k^{(\ell+1)}$: the summation runs over the first (row) index $k$ of $W_{kj}^{(\ell+1)}$, not the second index $j$. By definition of the matrix transpose, $\bigl[(W^{(\ell+1)})^\top\bigr]_{jk} = W_{kj}^{(\ell+1)}$, so summing over $k$ is literally the $j$-th component of the matrix-vector product $\bigl(W^{(\ell+1)}\bigr)^\top \delta^{(\ell+1)} \in \mathbb{R}^{d_\ell}$!
    2. Step 2b (Chain rule through $\phi_\ell$ from $a_j^{(\ell)}$ to $z_j^{(\ell)}$): Since $z_j^{(\ell)}$ affects $\mathcal{L}$ only through $a_j^{(\ell)} = \phi_\ell\bigl(z_j^{(\ell)}\bigr)$, we multiply by $\frac{\partial a_j^{(\ell)}}{\partial z_j^{(\ell)}} = \phi_\ell'\bigl(z_j^{(\ell)}\bigr)$: $$\delta_j^{(\ell)} = \frac{\partial \mathcal{L}}{\partial z_j^{(\ell)}} = \frac{\partial \mathcal{L}}{\partial a_j^{(\ell)}} \, \frac{\partial a_j^{(\ell)}}{\partial z_j^{(\ell)}} = \left(\sum_{k=1}^{d_{\ell+1}} W_{kj}^{(\ell+1)} \, \delta_k^{(\ell+1)}\right) \phi_\ell'\!\bigl(z_j^{(\ell)}\bigr).$$

    Writing both the index form and the vector form side by side gives BP2:

    $$\boxed{\text{(BP2)} \qquad \delta_j^{(\ell)} = \left(\sum_{k=1}^{d_{\ell+1}} W_{kj}^{(\ell+1)} \, \delta_k^{(\ell+1)}\right) \phi_\ell'\!\bigl(z_j^{(\ell)}\bigr) \quad \Longleftrightarrow \quad \delta^{(\ell)} = \Bigl(\bigl(W^{(\ell+1)}\bigr)^\top \delta^{(\ell+1)}\Bigr) \odot \phi_\ell'\!\bigl(z^{(\ell)}\bigr) \in \mathbb{R}^{d_\ell}.}$$

    4. Derivation of BP3: Bias gradient $\frac{\partial \mathcal{L}}{\partial b_i^{(\ell)}}$

    Fix layer $\ell \in \{1, \dots, L\}$ and unit $i \in \{1, \dots, d_\ell\}$. How does the scalar bias $b_i^{(\ell)}$ enter the computational graph? It appears only in the single pre-activation equation

    $$z_i^{(\ell)} = \sum_{j=1}^{d_{\ell-1}} W_{ij}^{(\ell)}\, a_j^{(\ell-1)} + b_i^{(\ell)}.$$

    Differentiating $z_i^{(\ell)}$ with respect to $b_i^{(\ell)}$ holding $W^{(\ell)}$ and $a^{(\ell-1)}$ fixed gives $\frac{\partial z_i^{(\ell)}}{\partial b_i^{(\ell)}} = 1$ (and $\frac{\partial z_k^{(\ell)}}{\partial b_i^{(\ell)}} = 0$ for all $k \neq i$). Therefore, by the chain rule:

    $$\frac{\partial \mathcal{L}}{\partial b_i^{(\ell)}} = \frac{\partial \mathcal{L}}{\partial z_i^{(\ell)}} \cdot \frac{\partial z_i^{(\ell)}}{\partial b_i^{(\ell)}} = \delta_i^{(\ell)} \cdot 1 = \delta_i^{(\ell)}.$$

    In other words, the gradient of the loss with respect to the bias vector $b^{(\ell)}$ is identical to the error sensitivity vector $\delta^{(\ell)}$ itself:

    $$\boxed{\text{(BP3)} \qquad \frac{\partial \mathcal{L}}{\partial b_i^{(\ell)}} = \delta_i^{(\ell)} \quad \Longleftrightarrow \quad \nabla_{b^{(\ell)}} \mathcal{L} = \delta^{(\ell)} \in \mathbb{R}^{d_\ell}.}$$

    5. Derivation of BP4: Weight gradient $\frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}}$

    Finally, fix layer $\ell \in \{1, \dots, L\}$, destination row index $i \in \{1, \dots, d_\ell\}$, and source column index $j \in \{1, \dots, d_{\ell-1}\}$. Where does the specific scalar weight $W_{ij}^{(\ell)}$ appear in the network? In the pre-activation equations of layer $\ell$,

    $$z_k^{(\ell)} = \sum_{m=1}^{d_{\ell-1}} W_{km}^{(\ell)}\, a_m^{(\ell-1)} + b_k^{(\ell)}, \qquad k = 1, \dots, d_\ell,$$

    the weight $W_{ij}^{(\ell)}$ appears only in the equation for $k = i$ and the summation term $m = j$: namely $z_i^{(\ell)} = \dots + W_{ij}^{(\ell)} a_j^{(\ell-1)} + \dots$. Consequently:

    $$\frac{\partial z_k^{(\ell)}}{\partial W_{ij}^{(\ell)}} = \begin{cases} a_j^{(\ell-1)}, & \text{if } k = i, \\ 0, & \text{if } k \neq i. \end{cases}$$

    Applying the chain rule through $z_i^{(\ell)}$ immediately gives:

    $$\frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}} = \frac{\partial \mathcal{L}}{\partial z_i^{(\ell)}} \cdot \frac{\partial z_i^{(\ell)}}{\partial W_{ij}^{(\ell)}} = \delta_i^{(\ell)}\, a_j^{(\ell-1)}.$$

    Recall from linear algebra that if $u \in \mathbb{R}^{d_\ell}$ and $v \in \mathbb{R}^{d_{\ell-1}}$ are column vectors, their outer product $u v^\top \in \mathbb{R}^{d_\ell \times d_{\ell-1}}$ is the matrix whose $(i, j)$ entry is $[u v^\top]_{ij} = u_i v_j$. Therefore, assembling $\frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}} = \delta_i^{(\ell)} a_j^{(\ell-1)}$ over all $(i, j)$ produces the rank-1 outer product $\delta^{(\ell)} \bigl(a^{(\ell-1)}\bigr)^\top$:

    $$\boxed{\text{(BP4)} \qquad \frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}} = \delta_i^{(\ell)}\, a_j^{(\ell-1)} \quad \Longleftrightarrow \quad \nabla_{W^{(\ell)}} \mathcal{L} = \delta^{(\ell)} \bigl(a^{(\ell-1)}\bigr)^\top \in \mathbb{R}^{d_\ell \times d_{\ell-1}}.}$$
    Physical intuition of BP4 ($\frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}} = \delta_i^{(\ell)} a_j^{(\ell-1)}$):

    Every synaptic weight $W_{ij}^{(\ell)}$ connects a pre-synaptic source unit $a_{\text{in}} = a_j^{(\ell-1)}$ to a post-synaptic destination unit with error signal $\delta_{\text{out}} = \delta_i^{(\ell)}$. Its gradient is simply:

    $$\frac{\partial \mathcal{L}}{\partial W_{\text{out, in}}} = \delta_{\text{out}} \cdot a_{\text{in}}.$$

    This immediately explains two fundamental behaviors of neural network training:

    1. Zero-activation freeze: If the incoming activation $a_j^{(\ell-1)} = 0$ (for example, a ReLU unit in layer $\ell-1$ that is inactive on the current sample), then $\frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}} = 0$ for every outgoing weight $i = 1, \dots, d_\ell$.
    2. Zero-sensitivity freeze (Dead ReLU): If neuron $i$ in layer $\ell$ has $\phi_\ell'(z_i^{(\ell)}) = 0$, then by BP2 $\delta_i^{(\ell)} = 0$, which by BP3 and BP4 zeroes out $\frac{\partial \mathcal{L}}{\partial b_i^{(\ell)}} = 0$ and $\frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}} = 0$ for the entire $i$-th row of $W^{(\ell)}$.

    6. Complete single-sample Backpropagation algorithm

    Putting BP1–BP4 together yields the complete forward-backward procedure for a single training pair $(x, y)$:

    1. Input initialization: Set $a^{(0)} = x \in \mathbb{R}^{d_0}$.
    2. Forward sweep ($\ell = 1, 2, \dots, L$): Compute and cache in memory both pre-activations and activations: $$z^{(\ell)} = W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}, \qquad a^{(\ell)} = \phi_\ell\!\bigl(z^{(\ell)}\bigr).$$
    3. Output error sensitivity ($\ell = L$, BP1): Compute $$\delta^{(L)} = \nabla_{a^{(L)}} \mathcal{L} \odot \phi_L'\!\bigl(z^{(L)}\bigr) \quad \bigl(\text{or } \delta^{(L)} = a^{(L)} - y \text{ for canonical link + loss}\bigr).$$
    4. Backward sweep ($\ell = L-1, L-2, \dots, 1$, BP2): Propagate error sensitivities backward layer by layer: $$\delta^{(\ell)} = \Bigl(\bigl(W^{(\ell+1)}\bigr)^\top \delta^{(\ell+1)}\Bigr) \odot \phi_\ell'\!\bigl(z^{(\ell)}\bigr).$$
    5. Parameter gradients ($\ell = 1, 2, \dots, L$, BP3 & BP4): Compute local weight and bias gradients (either on the fly during step 4 or right after): $$\nabla_{b^{(\ell)}} \mathcal{L} = \delta^{(\ell)}, \qquad \nabla_{W^{(\ell)}} \mathcal{L} = \delta^{(\ell)} \bigl(a^{(\ell-1)}\bigr)^\top.$$

    In real deep learning systems, we never run this loop over one sample $x$ at a time: we process a mini-batch of $B$ samples simultaneously as dense matrix-matrix multiplications (GEMMs). In Chapter 3, we derive the exact mini-batch tensor equations using matrix differentials and the Frobenius inner product.
