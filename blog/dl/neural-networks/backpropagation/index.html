    Backpropagation: Deriving BP1–BP4 & Mini-Batch Implementation

    October 2026 · 6 min read

    Perturbing one weight at a time takes one forward pass per parameter. Backpropagation applies the chain rule from the output layer back to the input, computing every weight and bias gradient in a single reverse pass.

    1. Forward equations and layer sensitivity $\delta^{(\ell)}$

    In an $L$-layer feed-forward network with input $a^{(0)} = x \in \mathbb{R}^{d_0}$ and scalar loss $\mathcal{L}\bigl(a^{(L)}, y\bigr) \in \mathbb{R}$, neuron $i \in \{1, \dots, d_\ell\}$ in layer $\ell \in \{1, \dots, L\}$ computes:

    $$z_i^{(\ell)} = \sum_{j=1}^{d_{\ell-1}} W_{ij}^{(\ell)}\, a_j^{(\ell-1)} + b_i^{(\ell)}, \qquad a_i^{(\ell)} = \phi_\ell\!\bigl(z_i^{(\ell)}\bigr).$$

    Every weight $W_{ij}^{(\ell)}$ and bias $b_i^{(\ell)}$ in row $i$ affects the loss $\mathcal{L}$ exclusively through the pre-activation $z_i^{(\ell)}$. We therefore define the error sensitivity of layer $\ell$ as:

    $$\delta_i^{(\ell)} \triangleq \frac{\partial \mathcal{L}}{\partial z_i^{(\ell)}}, \qquad \delta^{(\ell)} \triangleq \nabla_{z^{(\ell)}} \mathcal{L} = \begin{bmatrix} \delta_1^{(\ell)} & \cdots & \delta_{d_\ell}^{(\ell)} \end{bmatrix}^\top \in \mathbb{R}^{d_\ell}.$$

    2. Deriving the four equations (BP1–BP4)

    BP1: Output-layer sensitivity $\delta^{(L)}$

    For an element-wise output activation $a_i^{(L)} = \phi_L\bigl(z_i^{(L)}\bigr)$, $z_i^{(L)}$ affects $\mathcal{L}$ only through $a_i^{(L)}$, so:

    $$\text{(BP1)} \qquad \delta_i^{(L)} = \frac{\partial \mathcal{L}}{\partial a_i^{(L)}} \, \phi_L'\!\bigl(z_i^{(L)}\bigr) \quad \Longleftrightarrow \quad \delta^{(L)} = \nabla_{a^{(L)}} \mathcal{L} \odot \phi_L'\!\bigl(z^{(L)}\bigr) \in \mathbb{R}^{d_L}.$$

    For the three standard output-head + loss pairings, the activation derivative cancels the loss denominator so $\delta^{(L)}$ simplifies to the prediction residual $\hat{y} - y$:

    • Linear + MSE ($\hat{y} = z^{(L)}$, $\mathcal{L} = \frac{1}{2}\|\hat{y} - y\|_2^2$): $\dfrac{\partial \mathcal{L}}{\partial \hat{y}_i} = \hat{y}_i - y_i$ and $\phi_L'\bigl(z_i^{(L)}\bigr) = 1 \implies \delta^{(L)} = \hat{y} - y$.
    • Sigmoid + BCE ($\hat{p}_i = \sigma(z_i^{(L)})$, $\mathcal{L} = -\sum_k [y_k \log \hat{p}_k + (1-y_k)\log(1-\hat{p}_k)]$): $\dfrac{\partial \mathcal{L}}{\partial \hat{p}_i} = \dfrac{\hat{p}_i - y_i}{\hat{p}_i(1-\hat{p}_i)}$ and $\sigma'(z_i^{(L)}) = \hat{p}_i(1-\hat{p}_i) \implies \delta^{(L)} = \hat{p} - y$.
    • Softmax + Cross-Entropy ($\hat{p}_k = \frac{e^{z_k}}{\sum_m e^{z_m}}$, $\mathcal{L} = -\sum_k y_k \log \hat{p}_k$ with $\sum_k y_k = 1$): Since $\frac{\partial \hat{p}_k}{\partial z_i} = \hat{p}_k(\delta_{ki} - \hat{p}_i)$, summing over all $C$ outputs gives $\delta_i^{(L)} = \sum_{k=1}^C \bigl(-\frac{y_k}{\hat{p}_k}\bigr)\hat{p}_k(\delta_{ki} - \hat{p}_i) = \hat{p}_i - y_i \implies \delta^{(L)} = \hat{p} - y$.

    BP2: Hidden-layer recursion $\delta^{(\ell)}$ from $\delta^{(\ell+1)}$

    In hidden layer $\ell \in \{1, \dots, L-1\}$, pre-activation $z_j^{(\ell)}$ passes through $a_j^{(\ell)} = \phi_\ell\bigl(z_j^{(\ell)}\bigr)$, which then feeds into all $d_{\ell+1}$ pre-activations in layer $\ell+1$:

    $$z_k^{(\ell+1)} = \sum_{m=1}^{d_\ell} W_{km}^{(\ell+1)}\, a_m^{(\ell)} + b_k^{(\ell+1)}, \qquad \text{so} \qquad \frac{\partial z_k^{(\ell+1)}}{\partial a_j^{(\ell)}} = W_{kj}^{(\ell+1)}.$$

    By the multivariable chain rule, summing over all $k = 1, \dots, d_{\ell+1}$ and multiplying by $\frac{\partial a_j^{(\ell)}}{\partial z_j^{(\ell)}} = \phi_\ell'\bigl(z_j^{(\ell)}\bigr)$ yields BP2:

    $$\frac{\partial \mathcal{L}}{\partial a_j^{(\ell)}} = \sum_{k=1}^{d_{\ell+1}} \frac{\partial \mathcal{L}}{\partial z_k^{(\ell+1)}} \frac{\partial z_k^{(\ell+1)}}{\partial a_j^{(\ell)}} = \sum_{k=1}^{d_{\ell+1}} \delta_k^{(\ell+1)} W_{kj}^{(\ell+1)} = \sum_{k=1}^{d_{\ell+1}} \Bigl[\bigl(W^{(\ell+1)}\bigr)^\top\Bigr]_{jk} \delta_k^{(\ell+1)} = \Bigl[\bigl(W^{(\ell+1)}\bigr)^\top \delta^{(\ell+1)}\Bigr]_j,$$
    $$\text{(BP2)} \qquad \delta_j^{(\ell)} = \left(\sum_{k=1}^{d_{\ell+1}} W_{kj}^{(\ell+1)} \, \delta_k^{(\ell+1)}\right) \phi_\ell'\!\bigl(z_j^{(\ell)}\bigr) \quad \Longleftrightarrow \quad \delta^{(\ell)} = \Bigl(\bigl(W^{(\ell+1)}\bigr)^\top \delta^{(\ell+1)}\Bigr) \odot \phi_\ell'\!\bigl(z^{(\ell)}\bigr) \in \mathbb{R}^{d_\ell}.$$

    BP3 & BP4: Bias and weight gradients

    In $z_i^{(\ell)} = \sum_{j=1}^{d_{\ell-1}} W_{ij}^{(\ell)} a_j^{(\ell-1)} + b_i^{(\ell)}$, the local derivatives with respect to the parameters of neuron $i$ are $\frac{\partial z_i^{(\ell)}}{\partial b_i^{(\ell)}} = 1$ and $\frac{\partial z_i^{(\ell)}}{\partial W_{ij}^{(\ell)}} = a_j^{(\ell-1)}$. Applying the chain rule through $z_i^{(\ell)}$ gives BP3 and BP4:

    $$\text{(BP3)} \qquad \frac{\partial \mathcal{L}}{\partial b_i^{(\ell)}} = \delta_i^{(\ell)} \cdot 1 = \delta_i^{(\ell)} \quad \Longleftrightarrow \quad \nabla_{b^{(\ell)}} \mathcal{L} = \delta^{(\ell)} \in \mathbb{R}^{d_\ell},$$
    $$\text{(BP4)} \qquad \frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}} = \delta_i^{(\ell)}\, a_j^{(\ell-1)} \quad \Longleftrightarrow \quad \nabla_{W^{(\ell)}} \mathcal{L} = \delta^{(\ell)} \bigl(a^{(\ell-1)}\bigr)^\top \in \mathbb{R}^{d_\ell \times d_{\ell-1}}.$$

    3. Mini-batch matrix form & summary

    For a mini-batch of $B$ examples stacked as rows ($A^{(\ell-1)} \in \mathbb{R}^{B \times d_{\ell-1}}$, $Z^{(\ell)} = A^{(\ell-1)}(W^{(\ell)})^\top + \mathbf{1}_B(b^{(\ell)})^\top \in \mathbb{R}^{B \times d_\ell}$), let $G^{(\ell)} \triangleq \nabla_{Z^{(\ell)}} \mathcal{L} \in \mathbb{R}^{B \times d_\ell}$ stack the $B$ row sensitivities. Then each layer executes two backward matrix multiplications:

    $$G^{(\ell-1)} = \bigl(G^{(\ell)} W^{(\ell)}\bigr) \odot \phi_{\ell-1}'\!\bigl(Z^{(\ell-1)}\bigr), \qquad \nabla_{W^{(\ell)}} \mathcal{L} = \bigl(G^{(\ell)}\bigr)^\top A^{(\ell-1)}, \qquad \nabla_{b^{(\ell)}} \mathcal{L} = \bigl(G^{(\ell)}\bigr)^\top \mathbf{1}_B.$$
    Equation Role Single-Sample Vector Form Mini-Batch Matrix Form ($B$ rows)
    BP1 Output-layer sensitivity $\delta^{(L)} = \nabla_{a^{(L)}} \mathcal{L} \odot \phi_L'\!\bigl(z^{(L)}\bigr)$ (or $\hat{y} - y$) $G^{(L)} = \frac{1}{B}(\hat{Y} - Y)$
    BP2 Hidden-layer recursion ($\ell = L-1 \downarrow 1$) $\delta^{(\ell)} = \Bigl(\bigl(W^{(\ell+1)}\bigr)^\top \delta^{(\ell+1)}\Bigr) \odot \phi_\ell'\!\bigl(z^{(\ell)}\bigr)$ $G^{(\ell)} = \bigl(G^{(\ell+1)} W^{(\ell+1)}\bigr) \odot \phi_\ell'\!\bigl(Z^{(\ell)}\bigr)$
    BP3 Bias vector gradient $\nabla_{b^{(\ell)}} \mathcal{L} = \delta^{(\ell)}$ $\nabla_{b^{(\ell)}} \mathcal{L} = \bigl(G^{(\ell)}\bigr)^\top \mathbf{1}_B$
    BP4 Weight matrix gradient $\nabla_{W^{(\ell)}} \mathcal{L} = \delta^{(\ell)} \bigl(a^{(\ell-1)}\bigr)^\top$ $\nabla_{W^{(\ell)}} \mathcal{L} = \bigl(G^{(\ell)}\bigr)^\top A^{(\ell-1)}$

    4. Minimal NumPy implementation

    The mini-batch equations in Section 3 translate line-for-line into NumPy:

    import numpy as np

def softmax(Z):
    Z_shifted = Z - np.max(Z, axis=1, keepdims=True)
    exp_Z = np.exp(Z_shifted)
    return exp_Z / np.sum(exp_Z, axis=1, keepdims=True)

def mlp_forward_backward(X, Y, params):
    """
    2-layer MLP with ReLU hidden layer and Softmax + Cross-Entropy output.
    X: (B, d0), Y: (B, C) one-hot or soft probability targets
    """
    W1, b1, W2, b2 = params["W1"], params["b1"], params["W2"], params["b2"]
    B = X.shape[0]

    # ---- Forward Pass ----
    Z1 = X @ W1.T + b1[None, :]          # (B, d1)
    A1 = np.maximum(0.0, Z1)             # ReLU: (B, d1)
    Z2 = A1 @ W2.T + b2[None, :]         # (B, C)
    P = softmax(Z2)                      # (B, C)

    loss = -np.sum(Y * np.log(P + 1e-15)) / B

    # ---- Backward Pass (BP1 - BP4 in Mini-Batch Form) ----
    G2 = (P - Y) / B                     # BP1: (B, C)
    dW2 = G2.T @ A1                      # BP4: (C, d1)
    db2 = np.sum(G2, axis=0)             # BP3: (C,)

    dA1 = G2 @ W2                        # (B, d1)
    G1 = dA1 * (Z1 > 0.0)                # BP2: (B, d1)
    dW1 = G1.T @ X                       # BP4: (d1, d0)
    db1 = np.sum(G1, axis=0)             # BP3: (d1,)

    grads = {"W1": dW1, "b1": db1, "W2": dW2, "b2": db2}
    return loss, grads
