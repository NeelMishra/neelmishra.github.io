    Backpropagation: Reverse-Mode Differentiation & Complete Derivations

    October 2026 · 8 min read

    If a neural network has $P = 10^9$ parameters and a scalar loss $\mathcal{L}(\theta) \in \mathbb{R}$, how do we compute all $10^9$ partial derivatives $\frac{\partial \mathcal{L}}{\partial \theta_p}$? Perturbing one weight at a time via finite differences requires $P + 1$ full forward passes—a billion times slower than a single inference pass. Backpropagation (reverse-mode automatic differentiation) exploits the dynamic-programming structure of the multivariable chain rule to compute the entire gradient vector $\nabla_\theta \mathcal{L} \in \mathbb{R}^P$ in a single reverse sweep costing only $\approx 2\times$ the FLOPs of one forward pass.

    1. The credit assignment problem and why $O(1)$ reverse sweeps beat $O(P)$ perturbations

    Consider a deep feed-forward network trained with Empirical Risk Minimization:

    $$\mathcal{L}(\theta) = \ell\bigl(f_\theta(x), y\bigr), \qquad z^{(\ell)} = W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}, \qquad a^{(\ell)} = \phi_\ell\bigl(z^{(\ell)}\bigr), \quad \ell = 1, \dots, L.$$

    To take a gradient descent step $\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}$, we need $\frac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}}$ and $\frac{\partial \mathcal{L}}{\partial b_i^{(\ell)}}$ for every layer $\ell \in \{1, \dots, L\}$ and every matrix entry $(i, j)$.

    • Naive finite differences ($O(P)$ forward passes): Approximating $\frac{\partial \mathcal{L}}{\partial \theta_p} \approx \frac{\mathcal{L}(\theta + \varepsilon e_p) - \mathcal{L}(\theta - \varepsilon e_p)}{2\varepsilon}$ evaluates the network twice per scalar parameter. If a single forward pass takes $F \propto P$ FLOPs, computing $\nabla_\theta \mathcal{L}$ by finite differences costs $O(P^2)$ total FLOPs—utterly intractable beyond a few thousand weights.
    • Reverse-mode automatic differentiation ($1$ forward + $1$ backward pass): Because all $P$ parameters funnel into a single scalar output $\mathcal{L} \in \mathbb{R}$, the shared suffix of the chain rule from layer $\ell$ to layer $L$ is identical for every weight inside layer $\ell$. By defining the error sensitivity (adjoint) vector $$\delta^{(\ell)} \triangleq \nabla_{z^{(\ell)}} \mathcal{L} = \begin{bmatrix} \frac{\partial \mathcal{L}}{\partial z_1^{(\ell)}} & \cdots & \frac{\partial \mathcal{L}}{\partial z_{d_\ell}^{(\ell)}} \end{bmatrix}^\top \in \mathbb{R}^{d_\ell},$$ and propagating $\delta^{(L)} \to \delta^{(L-1)} \to \dots \to \delta^{(1)}$ backward once, every weight gradient in layer $\ell$ is obtained locally by multiplying the incoming activation $a_j^{(\ell-1)}$ from the forward pass with the outgoing sensitivity $\delta_i^{(\ell)}$ from the backward pass.

    2. The Four Fundamental Equations of Backpropagation (BP1–BP4) at a glance

    Every derivation in this six-part series builds up—first index-by-index with explicit summation symbols, then via matrix differentials and Frobenius inner products—to four equations that completely specify backpropagation for any $L$-layer MLP:

    Eq. Name Scalar / Index Form Vector / Matrix Form (Single Sample) Mini-Batch Form ($B$ samples)
    BP1 Output-layer sensitivity $\delta_i^{(L)} = \dfrac{\partial \mathcal{L}}{\partial a_i^{(L)}} \, \phi_L'\!\bigl(z_i^{(L)}\bigr)$
    (or $\hat{y}_i - y_i$ for canonical link + loss)    		 $\delta^{(L)} = \nabla_{a^{(L)}} \mathcal{L} \odot \phi_L'\!\bigl(z^{(L)}\bigr) \in \mathbb{R}^{d_L}$ $G^{(L)} = \dfrac{1}{B}\bigl(\hat{Y} - Y\bigr) \in \mathbb{R}^{B \times d_L}$
    BP2 Hidden-layer sensitivity recursion ($\ell = L-1 \downarrow 1$) $\delta_j^{(\ell)} = \left(\sum_{k=1}^{d_{\ell+1}} W_{kj}^{(\ell+1)} \delta_k^{(\ell+1)}\right) \phi_\ell'\!\bigl(z_j^{(\ell)}\bigr)$ $\delta^{(\ell)} = \Bigl(\bigl(W^{(\ell+1)}\bigr)^\top \delta^{(\ell+1)}\Bigr) \odot \phi_\ell'\!\bigl(z^{(\ell)}\bigr)$ $G^{(\ell)} = \bigl(G^{(\ell+1)} W^{(\ell+1)}\bigr) \odot \phi_\ell'\!\bigl(Z^{(\ell)}\bigr)$
    BP3 Bias gradient $\dfrac{\partial \mathcal{L}}{\partial b_i^{(\ell)}} = \delta_i^{(\ell)}$ $\nabla_{b^{(\ell)}} \mathcal{L} = \delta^{(\ell)} \in \mathbb{R}^{d_\ell}$ $\nabla_{b^{(\ell)}} \mathcal{L} = \bigl(G^{(\ell)}\bigr)^\top \mathbf{1}_B \in \mathbb{R}^{d_\ell}$
    BP4 Weight matrix gradient $\dfrac{\partial \mathcal{L}}{\partial W_{ij}^{(\ell)}} = \delta_i^{(\ell)} a_j^{(\ell-1)}$ $\nabla_{W^{(\ell)}} \mathcal{L} = \delta^{(\ell)} \bigl(a^{(\ell-1)}\bigr)^\top \in \mathbb{R}^{d_\ell \times d_{\ell-1}}$ $\nabla_{W^{(\ell)}} \mathcal{L} = \bigl(G^{(\ell)}\bigr)^\top A^{(\ell-1)} \in \mathbb{R}^{d_\ell \times d_{\ell-1}}$

    3. Six chapters: complete derivations from chain rule to Hessians

    01
    Multivariable Chain Rule, Computational Graphs, and Forward (JVP) vs. Reverse Mode (VJP)

    Derive the multivariable chain rule on general directed acyclic graphs (summing over all directed paths), write the total Jacobian chain $J_f = J_L J_{L-1} \cdots J_1$, define Jacobian-Vector Products (JVPs) vs. Vector-Jacobian Products (VJPs), and prove via matrix-chain multiplication complexity why reverse mode is $O(d_0)$ faster when mapping $\mathbb{R}^P \to \mathbb{R}$.

    02
    The Four Fundamental Equations of Backpropagation: Index-by-Index Scalar Derivation

    No hand-waving matrix transposes: derive BP1, BP2, BP3, and BP4 component-by-component using explicit summation indices $z_i^{(\ell)} = \sum_{j=1}^{d_{\ell-1}} W_{ij}^{(\ell)} a_j^{(\ell-1)} + b_i^{(\ell)}$, showing exactly why the transpose $(W^{(\ell+1)})^\top$ and outer product $\delta^{(\ell)} (a^{(\ell-1)})^\top$ emerge from the chain rule.

    03
    Matrix Calculus & Mini-Batch Tensor Derivation: Differentials, Outer Products, and the 3-GEMM Rule

    Derive the mini-batch backward pass for $Z^{(\ell)} = A^{(\ell-1)}(W^{(\ell)})^\top + \mathbf{1}_B (b^{(\ell)})^\top$ using matrix differentials $d\mathcal{L} = \langle G^{(\ell)}, dZ^{(\ell)} \rangle_F$ and trace cyclic permutations $\operatorname{Tr}(A^\top B)$, proving why every linear layer executes 1 GEMM forward ($2Bd_{\ell-1}d_\ell$ FLOPs) and 2 GEMMs backward ($4Bd_{\ell-1}d_\ell$ FLOPs).

    04
    Output Layer & Loss Gradients: MSE, Sigmoid + BCE, and the Softmax + Cross-Entropy Jacobian

    Derive the exact initial adjoint $\delta^{(L)} = \frac{\partial \mathcal{L}}{\partial z^{(L)}}$ for linear + MSE, logistic Sigmoid + Binary Cross-Entropy (showing the $\hat{p}(1-\hat{p})$ cancellation), and the full $C \times C$ Softmax Jacobian $\frac{\partial \hat{p}_k}{\partial z_i} = \hat{p}_k(\delta_{ki} - \hat{p}_i)$ contracted with categorical cross-entropy for both one-hot and soft label distributions.

    05
    Complete Worked Numerical Backprop By Hand, Finite-Difference Gradient Checking, and NumPy Implementation

    Work through every floating-point number of a 2-layer network forward pass, backward pass, and 1-step parameter update by hand; derive the $O(\varepsilon^2)$ truncation error vs. $O(\epsilon_{\text{mach}}/\varepsilon)$ roundoff tradeoff of centered finite-difference gradient checking; and run a self-contained NumPy verification script.

    06
    Deep Backpropagation Pathologies & Higher-Order Calculus: Vanishing/Exploding Jacobians, Residual Highways, Checkpointing, and Hessian-Vector Products

    Unroll BP2 into the layerwise Jacobian product $\prod_{k=\ell+1}^L D^{(k)}(W^{(k)})^\top$, analyze singular value cascades, Sigmoid $\le 1/4$ saturation, Dead ReLUs, and residual identity highways $I + J_{F_k}$, derive $O(\sqrt{L})$ activation checkpointing, and derive Pearlmutter’s $O(P)$ Hessian-Vector Product ($Hv$) trick.
