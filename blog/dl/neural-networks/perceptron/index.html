    Perceptrons: Overview & Reading Guide

    October 2026 · 3 min read

    Introduced by Frank Rosenblatt in 1958, the perceptron is the foundational building block of neural networks: a single linear threshold neuron that slices input space $\mathbb{R}^d$ with a hyperplane and learns by nudging its weight vector whenever it makes a mistake.

    1. The Single-Neuron Decision Boundary

    Given an input vector $x = (x_1, \dots, x_d)^\top \in \mathbb{R}^d$, weights $w = (w_1, \dots, w_d)^\top \in \mathbb{R}^d$, and bias $b \in \mathbb{R}$, a perceptron computes a pre-activation score $z = w^\top x + b$ and applies a sign threshold:

    $$z(x) = w^\top x + b = \sum_{j=1}^d w_j x_j + b, \qquad \hat{y}(x) = \operatorname{sign}\!\bigl(w^\top x + b\bigr) = \begin{cases} +1 & \text{if } w^\top x + b \ge 0, \\ -1 & \text{if } w^\top x + b < 0. \end{cases}$$
