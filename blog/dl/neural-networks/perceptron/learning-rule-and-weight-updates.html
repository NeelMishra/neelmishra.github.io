    The Perceptron in Detail: Geometry, Weight Update Rule & Convergence

    October 2026 · 6 min read

    A perceptron classifies points in $\mathbb{R}^d$ using the sign of an inner product $w^\top x$. When it misclassifies a point $(x, y)$, adding $y\,x$ to $w$ rotates the weight vector toward positive mistakes and away from negative mistakes—tilting the decision hyperplane until every linearly separable point lies on the correct side.

    1. Hyperplane geometry with absorbed bias

    Appending a constant $1$ coordinate to the input vector absorbs the bias $b$ into the weight vector $w$:

    $$\tilde{x} = \begin{bmatrix} x \\ 1 \end{bmatrix} \in \mathbb{R}^{d+1}, \qquad \tilde{w} = \begin{bmatrix} w \\ b \end{bmatrix} \in \mathbb{R}^{d+1}, \qquad \tilde{w}^\top \tilde{x} = w^\top x + b.$$

    Writing $x$ and $w$ for these augmented vectors, a binary perceptron with labels $y \in \{-1, +1\}$ predicts:

    $$\begin{aligned} \hat{y}(x) &= \operatorname{sign}\!\bigl(w^\top x\bigr) = \begin{cases} +1 & \text{if } w^\top x \ge 0, \\ -1 & \text{if } w^\top x < 0, \end{cases} \\[6pt] w^\top x &= \|w\|_2\,\|x\|_2 \cos\theta(w, x). \end{aligned}$$

    The decision boundary $H = \{x : w^\top x = 0\}$ is the hyperplane orthogonal to $w$. The weight vector $w$ is the normal vector to $H$ pointing into the positive half-space:

    • If the angle $\theta(w, x) < 90^\circ$, then $w^\top x > 0$ and the perceptron predicts $\hat{y} = +1$.
    • If the angle $\theta(w, x) > 90^\circ$, then $w^\top x < 0$ and the perceptron predicts $\hat{y} = -1$.
    • A labeled example $(x, y)$ with $y \in \{-1, +1\}$ is correctly classified when $y\,(w^\top x) > 0$ and misclassified when $y\,(w^\top x) \le 0$.

    2. The Perceptron update rule and what it does to $w$

    The perceptron is mistake-driven: if $(x, y)$ is correctly classified ($y\,(w^\top x) > 0$), $w$ is unchanged. If $(x, y)$ is misclassified ($y\,(w^\top x) \le 0$), $w$ is updated by:

    $$\boxed{w_{\text{new}} = w + y\,x} \quad \Longleftrightarrow \quad \begin{cases} w_{\text{new}} = w + x & \text{if } y = +1 \text{ was misclassified as } -1 \;\;(w^\top x \le 0), \\[4pt] w_{\text{new}} = w - x & \text{if } y = -1 \text{ was misclassified as } +1 \;\;(w^\top x \ge 0). \end{cases}$$

    Algebraic effect on the score of $x$

    Evaluating the new pre-activation score $w_{\text{new}}^\top x$ on the same input $x$ shows why the update always moves the prediction in the right direction:

    $$\begin{aligned} w_{\text{new}}^\top x &= (w + y\,x)^\top x = w^\top x + y\,\|x\|_2^2, \\[6pt] y = +1 \;\;(\text{false negative, } w^\top x \le 0): &\quad w_{\text{new}}^\top x = w^\top x + \|x\|_2^2 > w^\top x \quad (\text{score increases toward } +1), \\ y = -1 \;\;(\text{false positive, } w^\top x \ge 0): &\quad w_{\text{new}}^\top x = w^\top x - \|x\|_2^2 < w^\top x \quad (\text{score decreases toward } -1). \end{aligned}$$

    Because the bias is absorbed as $x_{d+1} = 1$, the last coordinate of $w_{\text{new}} = w + y\,x$ automatically performs the bias update $b_{\text{new}} = b + y$, shifting the hyperplane's threshold alongside its orientation.

    Geometric effect: rotating the normal vector $w$

    Subgradient interpretation (Perceptron criterion)

    Although $\operatorname{sign}(w^\top x)$ has zero derivative everywhere except at the jump $w^\top x = 0$, the update rule is exact stochastic subgradient descent (with learning rate $\eta = 1$) on the piecewise-linear Perceptron loss:

    $$\mathcal{L}_{\text{perc}}(w; x, y) = \max\!\bigl(0,\, -y\,(w^\top x)\bigr), \qquad \nabla_w \mathcal{L}_{\text{perc}}(w; x, y) = \begin{cases} -y\,x & \text{if } y\,(w^\top x) \le 0, \\ \mathbf{0} & \text{if } y\,(w^\top x) > 0. \end{cases}$$

    3. Novikoff's Perceptron Convergence Theorem

    Suppose the training set $\{(x^{(i)}, y^{(i)})\}_{i=1}^N$ is linearly separable by some unit vector $w^\star$ ($\|w^\star\|_2 = 1$) with margin $\gamma$ and maximum input norm $R$:

    $$\gamma = \min_{1 \le i \le N} y^{(i)} \bigl(w^{\star\top} x^{(i)}\bigr) > 0, \qquad R = \max_{1 \le i \le N} \|x^{(i)}\|_2.$$

    Starting from $w^{(0)} = \mathbf{0}$, every mistake $k$ on a misclassified sample $(x, y)$ where $y\,(w^{(k-1)\top} x) \le 0$ sets $w^{(k)} = w^{(k-1)} + y\,x$. Tracking both the alignment with $w^\star$ and the squared norm $\|w^{(k)}\|_2^2$:

    $$\begin{aligned} \text{1. Alignment grows linearly:} &\quad w^{(k)\top} w^\star = w^{(k-1)\top} w^\star + y\bigl(w^{\star\top} x\bigr) \ge w^{(k-1)\top} w^\star + \gamma \implies w^{(k)\top} w^\star \ge k\gamma, \\[6pt] \text{2. Squared norm grows at most linearly:} &\quad \|w^{(k)}\|_2^2 = \|w^{(k-1)}\|_2^2 + \underbrace{2\,y\bigl(w^{(k-1)\top} x\bigr)}_{\le 0} + \|x\|_2^2 \le \|w^{(k-1)}\|_2^2 + R^2 \implies \|w^{(k)}\|_2^2 \le k R^2, \\[6pt] \text{3. Cauchy–Schwarz bound:} &\quad k^2 \gamma^2 \le \bigl(w^{(k)\top} w^\star\bigr)^2 \le \|w^{(k)}\|_2^2 \,\|w^\star\|_2^2 \le k R^2 \quad \Longrightarrow \quad \boxed{k \le \left(\frac{R}{\gamma}\right)^2}. \end{aligned}$$

    Thus the perceptron is guaranteed to find a separating hyperplane in at most $(R/\gamma)^2$ updates, independent of the ambient dimension $d$.

    4. Minimal NumPy implementation

    import numpy as np

def perceptron_fit(X, y, max_epochs=100):
    """
    X: (N, d) feature matrix; bias is absorbed by appending a column of 1s.
    y: (N,) binary labels in {-1, +1}.
    """
    X_aug = np.hstack([X, np.ones((X.shape[0], 1))])  # (N, d + 1)
    w = np.zeros(X_aug.shape[1])                      # (d + 1,)

    for _ in range(max_epochs):
        mistakes = 0
        for x_i, y_i in zip(X_aug, y):
            if y_i * (w @ x_i) <= 0.0:                # Misclassified
                w = w + y_i * x_i                     # Rotate w toward y_i * x_i
                mistakes += 1
        if mistakes == 0:
            break
    return w
