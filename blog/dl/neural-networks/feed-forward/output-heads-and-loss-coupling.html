    Output Heads, Exponential-Family Link Functions, and Loss Coupling

    October 2026 · 9 min read

    Hidden activations ($\operatorname{ReLU}, \operatorname{GELU}, \operatorname{SiLU}$) are chosen for representation and gradient flow; the output activation $\phi_L$ and loss $\mathcal{L}$ are chosen together to parameterize a conditional probability distribution $p_\theta(y \mid x)$ via Maximum Likelihood Estimation.

    1. Why output heads and losses are paired: Maximum Likelihood on $z^{(L)}$

    The first $L-1$ layers of a feed-forward network transform raw input $x \in \mathbb{R}^{d_0}$ into a learned feature representation $h = a^{(L-1)}(x) \in \mathbb{R}^{d_{L-1}}$. The final affine layer then produces unconstrained real scores (logits):

    $$z^{(L)} = W^{(L)} h + b^{(L)} \in \mathbb{R}^{d_L}.$$

    Instead of picking an arbitrary output activation $\phi_L$ and an arbitrary loss function $\mathcal{L}$, statistical learning models the conditional distribution $p_\theta(y \mid x)$ in the canonical exponential family, where $z^{(L)}$ serves as the natural parameter $\eta = z^{(L)}$, and defines the per-sample loss as the Negative Log-Likelihood (NLL):

    $$\mathcal{L}(\theta; x, y) = -\log p_\theta(y \mid x).$$

    2. The four canonical output head + loss pairs

    1. Continuous Regression ($y \in \mathbb{R}^K$): Identity Head + Gaussian NLL (MSE)

      Modeling $Y \mid X=x \sim \mathcal{N}\bigl(\hat{y}(x), \sigma^2 I_K\bigr)$ with identity output activation $\hat{y} = \phi_L(z^{(L)}) = z^{(L)}$ gives negative log-likelihood:

      $$-\log p(y \mid z^{(L)}) = \frac{1}{2\sigma^2}\|\hat{y} - y\|_2^2 + \frac{K}{2}\log(2\pi\sigma^2) \quad\Longrightarrow\quad \mathcal{L}_{\text{MSE}}(z^{(L)}, y) = \frac{1}{2}\|\hat{y} - y\|_2^2.$$
      If the noise variance itself depends on $x$ (heteroscedastic regression), the output layer predicts $2K$ numbers $\bigl(\mu_k(x), s_k(x)\bigr)$ where $s_k(x) = \log \sigma_k^2(x) \in \mathbb{R}$, and minimizes $\frac{1}{2}\sum_{k=1}^K \bigl(e^{-s_k}(y_k - \mu_k)^2 + s_k\bigr)$.
    2. Binary Classification ($y \in \{0, 1\}$): Sigmoid Head + Binary Cross-Entropy (BCE)

      Modeling $Y \mid X=x \sim \operatorname{Bernoulli}(\hat{p})$ requires mapping the scalar logit $z = z^{(L)} \in (-\infty, \infty)$ into $(0, 1)$. Setting $z = \log\frac{\hat{p}}{1-\hat{p}}$ (log-odds) inverts to the logistic sigmoid $\hat{p} = \sigma(z) = \frac{1}{1 + e^{-z}}$, with Bernoulli NLL:

      $$\mathcal{L}_{\text{BCE}}(\hat{p}, y) = -\bigl[y \log \hat{p} + (1 - y)\log(1 - \hat{p})\bigr].$$
      Numerical stability (Fused `BCEWithLogitsLoss`): Evaluating $\hat{p} = 1/(1+e^{-z})$ first and then taking $\log(\hat{p})$ overflows when $z \ll -88$ (in float32) and rounds $\hat{p} \to 1.0$ when $z \gg 18$, causing $\log(1-\hat{p}) = \log(0) = -\infty$. Substituting $\hat{p} = (1+e^{-z})^{-1}$ and $1-\hat{p} = e^{-z}(1+e^{-z})^{-1}$ directly into $\mathcal{L}_{\text{BCE}}$ yields the overflow-proof identity:
      $$\mathcal{L}_{\text{BCE-logits}}(z, y) = \log(1 + e^z) - z y = \max(z, 0) - z y + \log\!\left(1 + e^{-|z|}\right),$$
      where $-|z| \le 0$ guarantees $e^{-|z|} \in (0, 1]$ for every finite floating-point number $z$!
    3. Mutually Exclusive Multiclass ($y \in \{1, \dots, C\}$): Softmax Head + Cross-Entropy

      For $C$ mutually exclusive classes with logits $z = z^{(L)} \in \mathbb{R}^C$, the Softmax activation maps $z$ onto the probability simplex $\Delta^{C-1} = \{p \in \mathbb{R}_+^C : \sum_{c=1}^C p_c = 1\}$:

      $$\hat{p}_c = \operatorname{Softmax}(z)_c = \frac{e^{z_c}}{\sum_{k=1}^C e^{z_k}} = \frac{e^{z_c - m}}{\sum_{k=1}^C e^{z_k - m}}, \qquad m = \max_{1 \le k \le C} z_k.$$
      Subtracting $m = \max_k z_k$ leaves $\hat{p}_c$ mathematically invariant while ensuring the largest exponent is $e^0 = 1$. For target distribution $y \in \Delta^{C-1}$ (or one-hot $y_c = \mathbf{1}[c = y^*]$), the Categorical Cross-Entropy loss is fused via Log-Sum-Exp:
      $$\mathcal{L}_{\text{CE}}(z, y) = -\sum_{c=1}^C y_c \log \hat{p}_c = \left(m + \log\sum_{k=1}^C e^{z_k - m}\right) - \sum_{c=1}^C y_c z_c.$$
    4. Non-Negative Count Regression ($y \in \{0, 1, 2, \dots\}$): Exponential Head + Poisson NLL

      With $\hat{\lambda} = \exp(z) > 0$, Poisson NLL minimizes $\mathcal{L}_{\text{Poisson}}(z, y) = \hat{\lambda} - y \log \hat{\lambda} = e^z - y z$ (dropping $\log(y!)$).

    3. Complete comparison of output heads and losses

    Task & Target Support Output Activation $\hat{y} = \phi_L(z)$ Canonical Loss $\mathcal{L}(z, y)$ Why Never Pair With MSE?
    Regression ($y \in \mathbb{R}^K$) Identity $\hat{y} = z$ $\frac{1}{2}\|\hat{y} - y\|_2^2$ (or Huber / L1) MSE is the exact Gaussian NLL here.
    Binary Classification ($y \in \{0, 1\}$) Sigmoid $\hat{p} = \sigma(z) \in (0, 1)$ $\max(z,0) - zy + \log(1+e^{-|z|})$ MSE on $\sigma(z)$ gives gradient $(\hat{p}-y)\sigma'(z)$, which vanishes when $\hat{p} \approx 0$ even if $y=1$ (confidently wrong)!
    Multiclass ($y \in \{1,\dots,C\}$) $\hat{p}_c = \dfrac{e^{z_c-m}}{\sum_k e^{z_k-m}} \in \Delta^{C-1}$ $-\sum_{c=1}^C y_c \log \hat{p}_c$ Cross-entropy cancels the Softmax Jacobian saturation so $\nabla_z \mathcal{L} = \hat{p} - y$ scales linearly with error.
    Multi-Label ($y \in \{0, 1\}^C$) Independent Sigmoids $\hat{p}_c = \sigma(z_c)$ $\sum_{c=1}^C \mathcal{L}_{\text{BCE}}(z_c, y_c)$ Softmax forces $\sum_c \hat{p}_c = 1$ (competition), which is wrong when multiple labels co-occur.

    4. Questions worth answering

    Why shouldn’t you apply ReLU on the final layer $z^{(L)}$ before Softmax or Cross-Entropy?

    Clamping negative logits to $0$ via $\operatorname{ReLU}(z^{(L)})$ destroys all relative ordering among negative scores, forces every clamped class to receive identical unnormalized probability $e^0 = 1$, and blocks gradients ($\operatorname{ReLU}'(z_c) = 0$) for any class whose logit happens to dip below zero!

    What happens if we add a constant $+100$ to every logit $z_c^{(L)}$ before Softmax?

    The Softmax output is strictly shift-invariant: $\operatorname{Softmax}(z + c\mathbf{1}) = \operatorname{Softmax}(z)$ because $e^{z_i + c} / \sum_k e^{z_k + c} = (e^c e^{z_i}) / (e^c \sum_k e^{z_k}) = \hat{p}_i$. This exact shift invariance is what allows the numerical stability trick $m = \max_k z_k$ to subtract the maximum logit without changing a single probability.
