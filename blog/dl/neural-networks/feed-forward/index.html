    Feed-Forward Networks (MLPs): Overview & Reading Guide

    October 2026 · 7 min read

    A feed-forward neural network—also called a Multilayer Perceptron (MLP)—is a directed acyclic composition of affine projections and point-wise nonlinearities. Before deriving backpropagation, we must understand what the forward pass computes, how tensor shapes and FLOPs scale across batches, why depth creates exponentially many linear regions, and how output heads couple to loss functions.

    1. The canonical feed-forward recurrence

    Given an input vector $x \in \mathbb{R}^{d_0}$, an $L$-layer feed-forward network sets $a^{(0)} = x$ and evaluates layers $\ell = 1, 2, \dots, L$ sequentially without feedback loops:

    $$z^{(\ell)} = W^{(\ell)} a^{(\ell-1)} + b^{(\ell)} \in \mathbb{R}^{d_\ell}, \qquad a^{(\ell)} = \phi_\ell\bigl(z^{(\ell)}\bigr) \in \mathbb{R}^{d_\ell}, \qquad \hat{y} = a^{(L)}.$$

    Written as a single nested function composition over parameter set $\theta = \{W^{(\ell)}, b^{(\ell)}\}_{\ell=1}^L$:

    $$f_\theta(x) = \phi_L\!\left(W^{(L)}\,\phi_{L-1}\!\left(W^{(L-1)} \cdots \phi_1\!\left(W^{(1)} x + b^{(1)}\right) \cdots + b^{(L-1)}\right) + b^{(L)}\right).$$

    Why is it called feed-forward? Because the computational graph is a strict directed acyclic graph (DAG): layer $\ell$ depends only on layers $0, \dots, \ell-1$, never on future layers or recurrent past states $a_t^{(\ell)} \leftarrow a_{t-1}^{(\ell)}$.

    2. Five chapters, one progression

    01
    Layer Equations, Index Notation, and Mini-Batch Tensor Shapes

    Translate seamlessly between scalar index sums $z_i^{(\ell)} = \sum_j W_{ij}^{(\ell)} a_j^{(\ell-1)} + b_i^{(\ell)}$, column-vector equations $W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}$, and row-major mini-batch GEMMs $Z^{(\ell)} = A^{(\ell-1)}(W^{(\ell)})^\top + \mathbf{1}_B (b^{(\ell)})^\top$. Derive exact parameter counts, forward FLOPs, and work through a complete numerical 3-layer trace.

    02
    Why Nonlinearity Is Mandatory: Linear Collapse and Piecewise-Linear Polytope Geometry

    Prove by induction that stacking $L$ linear layers collapses to one affine matrix of rank at most $\min_\ell d_\ell$. Then derive how ReLU activations partition $\mathbb{R}^{d_0}$ into convex polytopes on which $f_\theta(x) = A_R x + c_R$ is locally affine, and derive Zaslavsky’s and Montúfar’s bounds on the number of linear regions.

    03
    Universal Approximation Theorems: Width vs. Depth from Cybenko to Telgarsky

    Construct explicit 1D step and hat approximators with 2 sigmoids or 4 ReLUs, state Cybenko’s (1989), Hornik’s (1991), and Leshno’s (1993) arbitrary-width theorems alongside Barron’s Fourier moment rate $O(1/N)$, and prove Telgarsky’s depth-separation theorem via iterated triangle waves $T^{\circ L}(x)$.

    04
    Output Heads, Exponential-Family Link Functions, and Loss Coupling

    Connect the final layer logits $z^{(L)}$ to probabilistic targets via maximum likelihood estimation: identity + Gaussian MSE, logistic sigmoid + Binary Cross-Entropy (with log-sum-exp stability), Softmax + Categorical Cross-Entropy, and Poisson count heads.

    05
    Modern Feed-Forward Blocks: Expansion Ratios, GLU / SwiGLU, Residuals, and Memory Profile

    Trace how classical MLPs became the FFN sub-block inside every modern Transformer: $4\times$ expand-and-project bottlenecks, key-value memory interpretation, gated linear units ($\operatorname{SwiGLU}$ with $\frac{8}{3}d_{\text{model}}$ width parity), Pre-LN residual highways, and activation memory budgets.

    3. Reference table: feed-forward design decisions

    Component Mathematical Form What It Controls Chapter
    Affine projection $Z^{(\ell)} = A^{(\ell-1)} (W^{(\ell)})^\top + \mathbf{1}_B (b^{(\ell)})^\top$ Feature mixing across coordinates; costs $2 B d_{\ell-1} d_\ell$ FLOPs Ch. 01
    Hidden nonlinearity $\phi_\ell$ $\operatorname{ReLU}(z)$, $\operatorname{GELU}(z)$, $\operatorname{SiLU}(z)$ Prevents linear rank collapse; bends hyperplane arrangements into polytopes Ch. 02
    Width $d_\ell$ vs. Depth $L$ $O(d^{d_0})$ shallow vs. $\Omega((d/d_0)^{d_0(L-1)} d^{d_0})$ deep regions Expressive efficiency: depth composes symmetries and oscillations exponentially Ch. 03
    Output head $\phi_L$ + Loss $\mathcal{L}$ Identity+MSE, $\sigma(z)$+BCE, $\operatorname{Softmax}(z)$+CE Matches prediction support ($\mathbb{R}$, $(0,1)$, $\Delta^{C-1}$) and yields $\delta^{(L)} = \hat{y} - y$ Ch. 04
    Gated FFN + Residual $x + (\operatorname{SiLU}(xW_g) \odot xW_u)W_d$ Multiplicative feature gating and unimpeded gradient highway Ch. 05
