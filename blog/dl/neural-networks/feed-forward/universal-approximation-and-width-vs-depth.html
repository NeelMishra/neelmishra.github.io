    Universal Approximation Theorems: Width vs. Depth from Cybenko to Telgarsky

    October 2026 · 10 min read

    Build explicit 1D bump and hat functions from pairs of sigmoids or triples of ReLUs, state the classic Cybenko–Hornik–Leshno Universal Approximation Theorem and Barron’s spectral bound, and prove Telgarsky’s depth-separation theorem showing why shallow networks need exponentially more width than deep ones.

    1. Constructive intuition: building localized bumps and hats in 1D

    Before invoking functional analysis, we can see directly why a single hidden layer $f_N(x) = \sum_{j=1}^N v_j \phi(w_j x + b_j) + c$ can approximate any continuous 1D curve $f : [0, 1] \to \mathbb{R}$:

    • With Sigmoids (localized rectangular pulses): For large steepness $s \gg 1$, $\sigma\bigl(s(x - a)\bigr)$ acts like a unit step jumping from $0$ to $1$ at $x = a$. Subtracting two shifted sigmoids creates a localized rectangular bump on $[a, b]$:
      $$B_{a,b}^{(s)}(x) = \sigma\bigl(s(x - a)\bigr) - \sigma\bigl(s(x - b)\bigr) \xrightarrow{s \to \infty} \mathbf{1}_{[a, b]}(x) \quad \text{for } x \notin \{a, b\}.$$
      Summing $M$ such bumps weighted by sample heights $f(x_m)$ produces a Riemann-sum step approximation of $f(x)$ using $N = 2M$ hidden neurons.
    • With ReLUs (piecewise-linear splines and hat functions): A single ReLU $\max(0, x - t_j)$ changes the slope of $f_N(x)$ by $+v_j$ at knot $t_j$. Even better, combining three ReLUs constructs a localized triangular hat (tent) function on $[a - \Delta, a + \Delta]$:
      $$\Lambda_{a,\Delta}(x) = \frac{1}{\Delta}\Bigl[\operatorname{ReLU}\bigl(x - (a - \Delta)\bigr) - 2\operatorname{ReLU}(x - a) + \operatorname{ReLU}\bigl(x - (a + \Delta)\bigr)\Bigr],$$
      which equals $0$ outside $[a-\Delta, a+\Delta]$, rises linearly to $1$ at $x = a$, and acts as a finite-element linear B-spline basis function.

    2. The Classical Universal Approximation Theorem (Arbitrary Width)

    Cybenko (1989) proved universal approximation for sigmoidal activations using the Hahn–Banach and Riesz Representation theorems; Hornik (1991) extended it to general bounded activations; and Leshno, Lin, Pinkus, and Schocken (1993) established the exact necessary and sufficient condition:

    Theorem (Cybenko 1989; Hornik 1991; Leshno et al. 1993 — Universal Approximation at Depth 2).

    Let $\phi : \mathbb{R} \to \mathbb{R}$ be a continuous activation function. The span of single-hidden-layer ridge functions

    $$\mathcal{H}_\phi = \left\{ f_N(x) = \sum_{j=1}^N v_j\,\phi\bigl(w_j^\top x + b_j\bigr) : N \in \mathbb{N},\; w_j \in \mathbb{R}^d,\; v_j, b_j \in \mathbb{R} \right\}$$

    is dense in $C(K)$ under the supremum norm $\|f - g\|_\infty = \sup_{x \in K} |f(x) - g(x)|$ for every compact set $K \subset \mathbb{R}^d$ if and only if $\phi$ is not a polynomial.

    Why must $\phi$ be non-polynomial? If $\phi(z) = \sum_{m=0}^p c_m z^m$ is a polynomial of degree $p$, then for any width $N$, $\sum_{j=1}^N v_j \phi(w_j^\top x + b_j)$ is a multivariate polynomial of degree at most $p$, which can never span higher-degree polynomials! Conversely, if $\phi$ is non-polynomial (such as ReLU, Sigmoid, Tanh, GELU, SiLU), taking finite differences with respect to bias shifts approximates derivatives of arbitrary order, generating all polynomials and hence (by Stone–Weierstrass) all continuous functions on $K$.

    3. Barron’s Theorem vs. the Curse of Dimensionality

    The Universal Approximation Theorem is purely an existence statement: it says some width $N(\varepsilon)$ suffices to achieve $\|f - f_N\|_\infty < \varepsilon$, without bounding how fast $N(\varepsilon)$ grows with dimension $d$:

    • Worst-case Lipschitz functions suffer the curse of dimensionality: To approximate an arbitrary $1$-Lipschitz function on $[0, 1]^d$ to accuracy $\varepsilon$, a shallow network requires $N = \Omega(\varepsilon^{-d})$ hidden units—exponential in $d$.
    • Barron’s Theorem (1993) breaks the curse for spectrally smooth functions: If the Fourier transform $\hat{f}(\omega)$ has finite first spectral moment $C_f = \int_{\mathbb{R}^d} \|\omega\|_2 |\hat{f}(\omega)|\,d\omega < \infty$, then for any probability measure $\mu$ on the unit ball $B_1(0) \subset \mathbb{R}^d$, there exists a 1-hidden-layer network of width $N$ satisfying
      $$\|f - f_N\|_{L_2(\mu)}^2 = \int_{B_1(0)} \bigl|f(x) - f_N(x)\bigr|^2\,d\mu(x) \le \frac{(2 C_f)^2}{N},$$
      an $O(1/N)$ squared-error rate whose exponent is independent of $d$ (constructed by Monte Carlo importance sampling of frequencies $\omega_j \sim |\hat{f}(\omega)|\|\omega\|_2 / C_f$).

    4. Telgarsky’s Depth Separation: why depth beats width exponentially

    If a 1-hidden-layer network can already approximate any continuous function, why do we need deep networks? Consider the 1D triangle wave (sawtooth map) $T : [0, 1] \to [0, 1]$, which can be implemented exactly by a 2-unit ReLU block:

    $$T(x) = \operatorname{ReLU}(2x) - 2\operatorname{ReLU}(2x - 1) = \begin{cases} 2x, & 0 \le x \le \tfrac{1}{2}, \\ 2(1 - x), & \tfrac{1}{2} < x \le 1, \\ 0, & \text{otherwise.} \end{cases}$$

    Now compose $T$ with itself $L$ times—simply stacking $L$ identical 2-ReLU layers in series:

    $$f_L(x) = \underbrace{(T \circ T \circ \cdots \circ T)}_{L \text{ layers}}(x) = T^{\circ L}(x).$$
    • Deep representation cost: $f_L(x)$ has depth $L$, width $2$, and only $O(L)$ parameters, yet it oscillates between $0$ and $1$ with $2^{L-1}$ triangular peaks and $2^L$ linear pieces of slope $\pm 2^L$!
    • Shallow lower bound (Telgarsky, 2016): Any shallow 1-hidden-layer ReLU network $g(x) = \sum_{j=1}^N v_j \operatorname{ReLU}(w_j x + b_j)$ has at most $N + 1$ linear pieces, so it can cross the horizontal line $y = 1/2$ at most $N + 1$ times. Since $f_L(x)$ crosses $y = 1/2$ exactly $2^L$ times, any shallow network with $N < 2^{L-1}$ hidden units suffers massive $L_1$ approximation error:
      $$\inf_{\text{shallow width } N \le 2^{L-2}} \int_0^1 \bigl|T^{\circ L}(x) - g_N(x)\bigr|\,dx \ge \frac{1}{8}.$$

    For $L = 30$, the deep network needs only $60$ ReLU units, whereas a shallow network needs more than $2^{29} \approx 5.3 \times 10^8$ ReLU units to match it! Furthermore, Lu et al. (2017) and Kidger & Lyons (2020) proved Dual (Arbitrary-Depth) Universal Approximation: a narrow deep ReLU network of fixed width $d_{\text{min}} = d_0 + 4$ can approximate any Lebesgue-integrable function on $\mathbb{R}^{d_0}$ as depth $L \to \infty$.

    5. Questions worth answering

    Does the Universal Approximation Theorem guarantee that SGD will find the approximating weights?

    No. Universal approximation is strictly an expressivity (approximation error) theorem—it proves that a parameter vector $\theta^*$ exists in the hypothesis space, saying nothing about optimization error (whether gradient descent reaches $\theta^*$) or estimation/generalization error (whether finite training samples determine $\theta^*$ without overfitting).

    What is the minimum hidden width required for a deep ReLU network to be a universal approximator on $\mathbb{R}^{d_0}$?

    If all hidden layers have width $d_\ell \le d_0$, a ReLU network cannot even create a bounded level set (every pre-image is unbounded along a nullspace ray). Hanin & Sellke (2017) proved that width $d_{\text{min}} = d_0 + 1$ is necessary and sufficient to approximate any continuous scalar function $f : K \to \mathbb{R}$ on a compact domain $K \subset \mathbb{R}^{d_0}$.
