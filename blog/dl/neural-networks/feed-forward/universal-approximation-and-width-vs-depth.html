    2. Polytope Geometry, Universal Approximation, and Width vs. Depth

    October 2026 · 17 min read

    As shown in Why Neural Networks Need Activation Functions, stacking linear layers without a nonlinearity collapses to a single matrix $W_{\text{eff}} = W^{(L)}\cdots W^{(1)}$ of rank at most $\min_\ell d_\ell$. Once we insert coordinate-wise nonlinearities, what functions can a feed-forward network represent—and why does a deep network need exponentially fewer neurons than a shallow one?

    1. Piecewise-linear polytope geometry and activation sign patterns

    Consider an $L$-layer network with $\operatorname{ReLU}(z) = \max(0, z)$ on all hidden layers $\ell = 1, \dots, L-1$ and a linear readout on layer $L$. At any input $x \in \mathbb{R}^{d_0}$, each hidden unit $i$ in layer $\ell$ is either strictly active ($z_i^{(\ell)}(x) > 0$) or inactive ($z_i^{(\ell)}(x) < 0$). Define its binary activation sign pattern $s^{(\ell)}(x) \in \{0, 1\}^{d_\ell}$ and diagonal gating matrix $D^{(\ell)}(x)$:

    $$s_i^{(\ell)}(x) = \mathbf{1}\!\left[z_i^{(\ell)}(x) > 0\right], \qquad D^{(\ell)}(x) = \operatorname{diag}\!\bigl(s^{(\ell)}(x)\bigr) \in \{0, 1\}^{d_\ell \times d_\ell}, \qquad a^{(\ell)}(x) = D^{(\ell)}(x)\,z^{(\ell)}(x).$$

    Within any connected open region $R \subset \mathbb{R}^{d_0}$ where the full sign pattern $S(x) = \bigl(s^{(1)}(x), \dots, s^{(L-1)}(x)\bigr)$ remains constant, every matrix $D_R^{(\ell)}$ is fixed, so the entire deep network simplifies to a locally affine function $f_\theta(x) = A_R x + c_R$ with local Jacobian

    $$A_R = \nabla_x f_\theta(x) = W^{(L)} D_R^{(L-1)} W^{(L-1)} \cdots D_R^{(1)} W^{(1)}.$$

    In layer $1$, each hidden unit $i \in \{1, \dots, d_1\}$ defines a flat hyperplane $H_i^{(1)} = \{x : (w_i^{(1)})^\top x + b_i^{(1)} = 0\}$ that slices $\mathbb{R}^{d_0}$ into two half-spaces. Intersecting those half-spaces produces convex polyhedra $R_{s^{(1)}}$. Inside each layer-1 cell, $a^{(1)}(x)$ is affine, so each layer-2 boundary $\{x : z_k^{(2)}(x) = 0\}$ is a hyperplane inside each cell that refracts (bends) whenever it crosses a layer-1 boundary, subdividing cells recursively.

    Counting linear regions: Zaslavsky’s shallow bound vs. Montúfar’s deep bound

    • Shallow 1-hidden-layer network (Zaslavsky, 1975): $d_1$ hyperplanes in general position in $\mathbb{R}^{d_0}$ partition space into exactly
      $$\mathcal{N}_{\text{shallow}}(d_0, d_1) = \sum_{j=0}^{d_0} \binom{d_1}{j} = \mathcal{O}\!\left(d_1^{d_0}\right)\quad\text{convex regions,}$$
      which grows only polynomially in width $d_1$ for fixed input dimension $d_0$.
    • Deep $L$-layer ReLU network (Montúfar et al., 2014): An $L$-layer ReLU network with hidden width $d \ge d_0$ can fold its domain $\lfloor d/d_0 \rfloor$ times along each coordinate axis at every layer, achieving an exponential number of linear regions in depth $L$:
      $$\mathcal{N}_{\text{deep}}(d_0, d, L) \ge \left(\prod_{\ell=1}^{L-2} \left\lfloor \frac{d}{d_0} \right\rfloor^{d_0}\right) \sum_{j=0}^{d_0} \binom{d}{j} = \Omega\!\left(\left(\frac{d}{d_0}\right)^{d_0(L-2)} d^{d_0}\right).$$

    2. Constructive 1D intuition: bumps, hats, and Telgarsky’s sawtooth

    Before stating the general $d$-dimensional Universal Approximation Theorem, see how a 1-hidden-layer network builds localized basis functions on $[0, 1]$, and how composing layers multiplies oscillations exponentially:

    • Two sigmoids form a localized rectangular bump: With large gain $s \gg 1$, $\sigma(s(x - a)) \approx \mathbf{1}[x > a]$. Subtracting a second shifted sigmoid at $x = b$ creates a pulse on $[a, b]$: $$B_{a,b}(x) = \sigma\bigl(s(x - a)\bigr) - \sigma\bigl(s(x - b)\bigr) \approx \mathbf{1}\bigl[x \in (a, b)\bigr].$$
    • Three ReLUs form a triangular hat (linear B-spline) basis function: $$\Lambda_{a,\Delta}(x) = \frac{1}{\Delta}\operatorname{ReLU}\bigl(x - (a - \Delta)\bigr) - \frac{2}{\Delta}\operatorname{ReLU}(x - a) + \frac{1}{\Delta}\operatorname{ReLU}\bigl(x - (a + \Delta)\bigr),$$ which equals $0$ outside $[a-\Delta, a+\Delta]$ and peaks at $1$ at $x = a$.
    • Composing $L$ 2-ReLU layers creates $2^{L-1}$ sawtooth peaks (Telgarsky, 2016): The triangle wave $T(x) = \operatorname{ReLU}(2x) - 2\operatorname{ReLU}(2x-1)$ on $[0,1]$ uses just $2$ ReLUs. Composing it $L$ times in a deep network $f_L(x) = T^{\circ L}(x)$ produces $2^L$ linear pieces and $2^{L-1}$ peaks using only $2L$ units!

    3. The Classical Universal Approximation Theorem (Arbitrary Width)

    Cybenko (1989) proved universal approximation for sigmoidal activations using the Hahn–Banach and Riesz Representation theorems; Hornik (1991) extended it to general bounded activations; and Leshno, Lin, Pinkus, and Schocken (1993) established the exact necessary and sufficient condition:

    Theorem (Cybenko 1989; Hornik 1991; Leshno et al. 1993 — Universal Approximation at Depth 2).

    Let $\phi : \mathbb{R} \to \mathbb{R}$ be a continuous activation function. The span of single-hidden-layer ridge functions

    $$\mathcal{H}_\phi = \left\{ f_N(x) = \sum_{j=1}^N v_j\,\phi\bigl(w_j^\top x + b_j\bigr) : N \in \mathbb{N},\; w_j \in \mathbb{R}^d,\; v_j, b_j \in \mathbb{R} \right\}$$

    is dense in $C(K)$ under the supremum norm $\|f - g\|_\infty = \sup_{x \in K} |f(x) - g(x)|$ for every compact set $K \subset \mathbb{R}^d$ if and only if $\phi$ is not a polynomial.

    Why must $\phi$ be non-polynomial? If $\phi(z) = \sum_{m=0}^p c_m z^m$ is a polynomial of degree $p$, then for any width $N$, $\sum_{j=1}^N v_j \phi(w_j^\top x + b_j)$ is a multivariate polynomial of degree at most $p$, which can never span higher-degree polynomials! Conversely, if $\phi$ is non-polynomial (such as ReLU, Sigmoid, Tanh, GELU, SiLU), taking finite differences with respect to bias shifts approximates directional derivatives of arbitrary order, generating all multivariate polynomials and hence (by Stone–Weierstrass) all continuous functions on $K$.

    4. Quantitative Rates: Barron’s Theorem vs. Telgarsky’s Depth Separation

    • Worst-case curse of dimensionality vs. Barron’s $O(1/N)$ spectral rate (1993): Approximating an arbitrary $1$-Lipschitz function on $[0, 1]^d$ to uniform error $\varepsilon$ with a 1-hidden-layer network requires $N = \Omega(\varepsilon^{-d})$ hidden units. However, if the Fourier transform $\hat{f}(\omega)$ has finite first spectral moment $C_f = \int_{\mathbb{R}^d} \|\omega\|_2 |\hat{f}(\omega)|\,d\omega < \infty$, Barron (1993) proved that a 1-hidden-layer network of width $N$ achieves dimension-independent $L_2(\mu)$ squared error:
      $$\|f - f_N\|_{L_2(\mu)}^2 \le \frac{(2 C_f)^2}{N}.$$
    • Telgarsky’s Depth Separation Theorem (2016): For the $L$-layer sawtooth function $f_L(x) = T^{\circ L}(x)$ (which uses $2L$ ReLU units and crosses $y = 1/2$ exactly $2^L$ times), any shallow 1-hidden-layer ReLU network $g_N(x)$ with $N \le 2^{L-2}$ hidden units has at most $N+1$ linear pieces and therefore incurs a constant $L_1$ error bounded away from zero:
      $$\inf_{\text{shallow width } N \le 2^{L-2}} \int_0^1 \bigl|T^{\circ L}(x) - g_N(x)\bigr|\,dx \ge \frac{1}{8}.$$
    • Dual Arbitrary-Depth Universal Approximation (Lu et al. 2017; Kidger & Lyons 2020): Rather than fixing depth $L=2$ and letting width $N \to \infty$, fixing width to $d_{\min} = d_0 + 4$ (for ReLU) and letting depth $L \to \infty$ is also universally approximative in $L_1(\mathbb{R}^{d_0})$.

    5. Questions worth answering

    If a 1-hidden-layer MLP is already a universal approximator, why do we ever use deep networks?

    First, expressive efficiency: as Telgarsky’s theorem proves, functions built by hierarchical composition require exponentially many units ($O(2^L)$) in a shallow network versus $O(L)$ units in a deep network. Second, inductive bias: gradient-based optimization on deep compositions learns reusable intermediate features rather than memorizing a flat lookup table of local bumps.

    Is a ReLU network differentiable at the boundary between two polytopes?

    A ReLU network is continuous everywhere and infinitely differentiable inside the open interior of every polytope $R$ (where the Hessian $\nabla_x^2 f_\theta(x) = 0$). Along the $(d_0-1)$-dimensional boundary hyperplanes $\{x : z_i^{(\ell)}(x) = 0\}$—a set of Lebesgue measure zero—the Jacobian jumps between $A_{R_1}$ and $A_{R_2}$, and autodiff frameworks evaluate a subgradient (conventionally $\operatorname{ReLU}'(0) = 0$).
