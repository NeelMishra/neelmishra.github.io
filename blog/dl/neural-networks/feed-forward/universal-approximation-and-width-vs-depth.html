    2. Polytope Regions, Universal Approximation, and Width vs. Depth

    October 2026 · 8 min read

    A ReLU network cuts input space into flat polytope regions and fits a linear function inside each one. A single wide layer can approximate any continuous function, but composing layers across depth creates exponentially more regions per neuron.

    1. Piecewise-linear polytope regions

    In an $L$-layer ReLU network, each hidden unit $i$ in layer $\ell$ is either active ($z_i^{(\ell)}(x) > 0$) or inactive ($z_i^{(\ell)}(x) < 0$). Collecting the binary indicator $s_i^{(\ell)}(x) = \mathbf{1}[z_i^{(\ell)}(x) > 0]$ into a diagonal matrix $D^{(\ell)}(x) = \operatorname{diag}(s^{(\ell)}(x))$ gives:

    $$a^{(\ell)}(x) = D^{(\ell)}(x)\,z^{(\ell)}(x).$$

    Inside any region $R \subset \mathbb{R}^{d_0}$ where the active pattern $S(x) = (s^{(1)}(x), \dots, s^{(L-1)}(x))$ stays constant, the network reduces to a single linear function $f_\theta(x) = A_R x + c_R$ with slope matrix

    $$A_R = W^{(L)} D_R^{(L-1)} W^{(L-1)} \cdots D_R^{(1)} W^{(1)}.$$

    Layer 1 slices $\mathbb{R}^{d_0}$ with $d_1$ flat hyperplanes into convex cells. Each subsequent layer adds boundaries that bend whenever they cross an earlier layer’s hyperplane, subdividing the cells further.

    • Shallow 1-hidden-layer network: $d_1$ hyperplanes in $\mathbb{R}^{d_0}$ create $\sum_{j=0}^{d_0} \binom{d_1}{j} = \mathcal{O}(d_1^{d_0})$ regions (polynomial in width $d_1$).
    • Deep $L$-layer ReLU network: Composing $L$ layers of width $d \ge d_0$ folds space repeatedly, creating $\Omega\bigl((d/d_0)^{d_0(L-1)}\bigr)$ regions (exponential in depth $L$).

    2. Building 1D functions: steps, hats, and sawtooth waves

    • Two sigmoids form a step bump: For large $s$, $\sigma(s(x - a)) - \sigma(s(x - b)) \approx \mathbf{1}[x \in (a, b)]$.
    • Three ReLUs form a triangular hat: $\Lambda_{a,\Delta}(x) = \frac{1}{\Delta}\bigl[\operatorname{ReLU}(x - a + \Delta) - 2\operatorname{ReLU}(x - a) + \operatorname{ReLU}(x - a - \Delta)\bigr]$ peaks at $1$ at $x=a$ and vanishes outside $[a-\Delta, a+\Delta]$.
    • $L$ layers of 2 ReLUs create $2^{L-1}$ peaks (Telgarsky, 2016): One triangle wave $T(x) = \operatorname{ReLU}(2x) - 2\operatorname{ReLU}(2x-1)$ uses $2$ ReLUs. Composing it $L$ times ($T^{\circ L}(x)$) creates $2^L$ linear pieces using only $2L$ neurons, whereas a 1-hidden-layer network needs $\Omega(2^L)$ neurons to match it.

    3. The Universal Approximation Theorem

    Theorem (Cybenko 1989; Leshno et al. 1993).

    For a continuous activation $\phi : \mathbb{R} \to \mathbb{R}$, single-hidden-layer networks $f_N(x) = \sum_{j=1}^N v_j\,\phi\bigl(w_j^\top x + b_j\bigr)$ can approximate any continuous function $f \in C(K)$ on a compact set $K \subset \mathbb{R}^d$ to arbitrary accuracy $\sup_{x \in K} |f(x) - f_N(x)| < \varepsilon$ if and only if $\phi$ is not a polynomial.

    If $\phi$ were a polynomial of degree $p$, then $\sum_{j=1}^N v_j \phi(w_j^\top x + b_j)$ would always be a polynomial of degree at most $p$ regardless of width $N$. Any non-polynomial activation (ReLU, Sigmoid, Tanh, GELU) avoids this trap.

    4. Key takeaway

    If a 1-hidden-layer MLP is already a universal approximator, why use deep networks?

    A 1-hidden-layer network may need exponentially many neurons ($\Omega(2^L)$ or $\Omega(\varepsilon^{-d})$) to build functions that a deep $L$-layer network builds by composing $O(L)$ units.

    Sources

    Cybenko, Approximation by superpositions of a sigmoidal function (MCSS 1989); Leshno et al., Multilayer feedforward networks with a nonpolynomial activation function can approximate any function (Neural Networks 1993); Montúfar et al., On the Number of Linear Regions of Deep Neural Networks (NeurIPS 2014); Telgarsky, Benefits of depth in neural networks (COLT 2016).
