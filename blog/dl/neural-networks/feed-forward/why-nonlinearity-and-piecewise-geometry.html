    Why Nonlinearity Is Mandatory: Linear Collapse and Piecewise-Linear Polytope Geometry

    October 2026 · 10 min read

    Prove by induction why an $L$-layer network without nonlinear activations has no more expressive power than a 1-layer linear model, then derive how ReLU activations slice $\mathbb{R}^{d_0}$ into convex polytopes and why depth multiplies the number of linear regions exponentially.

    1. Proof of linear collapse across $L$ layers

    Suppose we omit the nonlinear activation functions—setting $\phi_\ell(z) = z$ (or any affine function $\phi_\ell(z) = \alpha_\ell z + \beta_\ell$) at every hidden layer $\ell = 1, \dots, L-1$. What class of functions can the $L$-layer network represent?

    Theorem (Closure of Affine Maps / Linear Collapse).

    For any $L \ge 1$ layers with $a^{(\ell)} = W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}$ and $a^{(0)} = x \in \mathbb{R}^{d_0}$, the end-to-end mapping $f(x) = a^{(L)}$ is a single affine transformation

    $$f(x) = W_{\text{eff}} x + b_{\text{eff}},$$

    where the effective weight matrix $W_{\text{eff}} \in \mathbb{R}^{d_L \times d_0}$ and effective bias $b_{\text{eff}} \in \mathbb{R}^{d_L}$ are given explicitly by

    $$W_{\text{eff}} = W^{(L)} W^{(L-1)} \cdots W^{(1)} = \prod_{\ell=L}^1 W^{(\ell)}, \qquad b_{\text{eff}} = \sum_{k=1}^L \left(\prod_{\ell=L}^{k+1} W^{(\ell)}\right) b^{(k)},$$

    and the rank of the linear operator is upper-bounded by the narrowest layer width: $\operatorname{rank}(W_{\text{eff}}) \le \min_{0 \le \ell \le L} d_\ell$.

    Proof by induction on $L$:

    • Base case ($L=1$): $a^{(1)} = W^{(1)} x + b^{(1)}$, which matches $W_{\text{eff}} = W^{(1)}$ and $b_{\text{eff}} = b^{(1)}$ (where the empty product $\prod_{\ell=1}^2 W^{(\ell)} = I_{d_1}$).
    • Inductive step ($L-1 \implies L$): Assume $a^{(L-1)} = W_{\text{eff}}^{(L-1)} x + b_{\text{eff}}^{(L-1)}$. Substituting into layer $L$ yields
      $$a^{(L)} = W^{(L)}\!\left(W_{\text{eff}}^{(L-1)} x + b_{\text{eff}}^{(L-1)}\right) + b^{(L)} = \underbrace{\left(W^{(L)} W_{\text{eff}}^{(L-1)}\right)}_{W_{\text{eff}}^{(L)}} x + \underbrace{\left(W^{(L)} b_{\text{eff}}^{(L-1)} + b^{(L)}\right)}_{b_{\text{eff}}^{(L)}}.$$
      Finally, since $\operatorname{rank}(AB) \le \min\bigl(\operatorname{rank}(A), \operatorname{rank}(B)\bigr)$ and $\operatorname{rank}(W^{(\ell)}) \le \min(d_\ell, d_{\ell-1})$, induction gives $\operatorname{rank}(W_{\text{eff}}) \le \min_{0 \le \ell \le L} d_\ell$. $\square$

    Notice the implication: if any hidden layer is narrower than the input and output ($d_\ell < \min(d_0, d_L)$), a deep linear network is strictly less expressive than a single linear layer (it is a low-rank factored linear model), and if $d_\ell \ge \min(d_0, d_L)$, it represents the exact same hypothesis class as a single matrix $W \in \mathbb{R}^{d_L \times d_0}$.

    2. Activation patterns and continuous piecewise-linear (CPWL) polytopes

    Now replace the identity activation with $\operatorname{ReLU}(z) = \max(0, z)$. For any fixed input $x \in \mathbb{R}^{d_0}$, let $s_i^{(\ell)}(x) = \mathbf{1}\!\left[z_i^{(\ell)}(x) > 0\right] \in \{0, 1\}$ denote the binary activation state of unit $i$ in layer $\ell$, and define the diagonal gating matrix

    $$D^{(\ell)}(x) = \operatorname{diag}\!\left(s_1^{(\ell)}(x), \dots, s_{d_\ell}^{(\ell)}(x)\right) \in \{0, 1\}^{d_\ell \times d_\ell}.$$

    Because $\operatorname{ReLU}(z^{(\ell)}) = D^{(\ell)}(x)\,z^{(\ell)}$, the forward recurrence at point $x$ can be written as a gated linear product:

    $$a^{(\ell)}(x) = D^{(\ell)}(x)\bigl(W^{(\ell)} a^{(\ell-1)}(x) + b^{(\ell)}\bigr).$$

    Unrolling this recurrence across all $L$ layers (with a linear output layer $f_\theta(x) = z^{(L)}(x)$) proves that within any connected region $R \subset \mathbb{R}^{d_0}$ where the binary activation pattern $S(x) = \bigl(s^{(1)}(x), \dots, s^{(L-1)}(x)\bigr)$ remains constant, the entire deep ReLU network simplifies to an exact local affine function:

    $$f_\theta(x) = A_R\,x + c_R \qquad \forall x \in R,$$

    where the local Jacobian matrix $A_R \in \mathbb{R}^{d_L \times d_0}$ on region $R$ is

    $$A_R = \nabla_x f_\theta(x) = W^{(L)} D_R^{(L-1)} W^{(L-1)} \cdots D_R^{(1)} W^{(1)}.$$

    Why is each activation region $R$ a convex polytope? In layer $1$, each hidden unit $i \in \{1, \dots, d_1\}$ defines a hyperplane $H_i^{(1)} = \{x : (w_i^{(1)})^\top x + b_i^{(1)} = 0\}$ that slices $\mathbb{R}^{d_0}$ into two open half-spaces. Fixing $s^{(1)} \in \{0, 1\}^{d_1}$ intersects $d_1$ half-spaces, forming a convex polyhedron $R_{s^{(1)}}$. Inside $R_{s^{(1)}}$, $a^{(1)}(x)$ is strictly affine in $x$, so each layer-2 pre-activation $z_k^{(2)}(x) = (w_k^{(2)})^\top a^{(1)}(x) + b_k^{(2)}$ is also an affine function of $x$! Thus layer 2’s zero-crossings slice each layer-1 polyhedron with new hyperplanes, recursively subdividing $\mathbb{R}^{d_0}$ into finer and finer convex polytopes.

    3. Counting linear regions: Zaslavsky’s theorem vs. Montúfar’s exponential depth bound

    How many distinct linear regions can a single ReLU layer of width $d_1$ create in $\mathbb{R}^{d_0}$? A naive guess is $2^{d_1}$ (since there are $d_1$ binary switches $s_i^{(1)} \in \{0,1\}$), but when $d_1 > d_0$, most of those $2^{d_1}$ binary sign patterns are geometrically impossible. By Zaslavsky’s Theorem (1975) on hyperplane arrangements, $d_1$ hyperplanes in general position in $\mathbb{R}^{d_0}$ partition space into exactly

    $$\mathcal{N}_{\text{shallow}}(d_0, d_1) = \sum_{j=0}^{d_0} \binom{d_1}{j} = \mathcal{O}\!\left(d_1^{d_0}\right)\quad\text{regions.}$$

    Notice that for fixed input dimension $d_0$, a shallow 1-hidden-layer network grows only polynomially in width $d_1$. What happens when we instead arrange the neurons into $L-1$ hidden layers of width $d \ge d_0$? Montúfar, Pascanu, Cho, and Bengio (2014) proved that each hidden layer can fold its domain $d/d_0$ times along each of the $d_0$ coordinate axes, yielding an exponential number of linear regions in depth $L$:

    $$\mathcal{N}_{\text{deep}}(d_0, d, L) \ge \left(\prod_{\ell=1}^{L-2} \left\lfloor \frac{d}{d_0} \right\rfloor^{d_0}\right) \sum_{j=0}^{d_0} \binom{d}{j} = \Omega\!\left(\left(\frac{d}{d_0}\right)^{d_0(L-2)} d^{d_0}\right).$$

    For example, even in 1D ($d_0 = 1$), a shallow ReLU network with $2L$ hidden units has at most $2L + 1$ linear pieces, whereas a deep ReLU network with $L$ layers of width $2$ (the exact same $2L$ hidden units!) can fold the interval in half at every layer to produce $2^L$ linear pieces.

    4. Questions worth answering

    If a deep linear network $W^{(L)} \cdots W^{(1)} x$ has the exact same expressive power as $W_{\text{eff}} x$, does it also have the same gradient descent training dynamics?

    No! While the set of representable functions is identical (when $d_\ell \ge \min(d_0, d_L)$), the optimization landscape $\mathcal{L}(W^{(1)}, \dots, W^{(L)})$ is non-convex with saddle points, and gradient descent on factored weights induces an implicit Riemannian preconditioner that learns leading singular values of the target mapping sequentially (Saxe et al., 2014)—a phenomenon behind LoRA and matrix factorization dynamics.

    Is a ReLU network differentiable at the boundary between two polytopes?

    A ReLU network is continuous everywhere (it is a Continuous Piecewise-Linear, or CPWL, function) and infinitely differentiable in the open interior of every polytope $R$ (where the Hessian $\nabla_x^2 f_\theta(x) = 0$!). Along the $(d_0-1)$-dimensional boundary hyperplanes $\{x : z_i^{(\ell)}(x) = 0\}$—a set of Lebesgue measure zero—the Jacobian jumps from one constant matrix $A_{R_1}$ to another $A_{R_2}$, where autodiff frameworks evaluate a subgradient (conventionally setting $\operatorname{ReLU}'(0) = 0$).

    Sources

    Montúfar et al., On the Number of Linear Regions of Deep Neural Networks (NeurIPS 2014); Zaslavsky, Facing Up to Arrangements: Face-Count Formulas for Partitions of Space by Hyperplanes (AMS Memoirs 1975); Saxe, McClelland, and Ganguli, Exact solutions to the nonlinear dynamics of learning in deep linear neural networks (ICLR 2014).
