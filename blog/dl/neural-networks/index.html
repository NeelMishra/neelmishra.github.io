    Neural Networks: Foundations, Feed-Forward Pass, and Backpropagation

    October 2026 · 10 min read

    A neural network is a parameterized composition of simple affine transformations and nonlinear activations trained by alternating two passes: a feed-forward pass that maps inputs to predictions and caches intermediate states, and a backpropagation pass that propagates local sensitivities in reverse to compute exact gradients with respect to every weight and bias.

    Classical linear models such as linear regression and logistic regression require the practitioner to design the feature map $\phi(x)$ by hand: if the decision boundary is curved, you must explicitly supply polynomial terms, splines, or interaction columns. A neural network instead learns the representation $\phi_\theta(x)$ jointly with the output predictor by stacking multiple layers of learned linear projections followed by point-wise nonlinearities.

    1. The two-pass engine: Feed-Forward and Backpropagation

    Every training step of a deep neural network consists of two tightly coupled computational passes over a directed acyclic graph (DAG) of $L$ layers:

    $$\underbrace{x = a^{(0)} \xrightarrow{W^{(1)}, b^{(1)}} z^{(1)} \xrightarrow{\phi_1} a^{(1)} \xrightarrow{\;\cdots\;} z^{(L)} \xrightarrow{\phi_L} \hat{y} \xrightarrow{y} \mathcal{L}}_{\text{Feed-Forward Pass: compute predictions and cache } \{a^{(\ell-1)}, z^{(\ell)}\}} \qquad\Longleftrightarrow\qquad \underbrace{\nabla_\theta \mathcal{L} \xleftarrow{a^{(\ell-1)}} \delta^{(1)} \xleftarrow{(W^{(2)})^\top, \phi_1'} \cdots \xleftarrow{(W^{(L)})^\top, \phi_{L-1}'} \delta^{(L)} \xleftarrow{\partial\mathcal{L}/\partial z^{(L)}} \mathcal{L}}_{\text{Backpropagation Pass: reverse-mode AD via error sensitivities } \delta^{(\ell)} = \partial\mathcal{L}/\partial z^{(\ell)}}$$
    • The Feed-Forward Pass (Subseries 1): Starting from input $a^{(0)} = x \in \mathbb{R}^{d_0}$, each layer $\ell \in \{1, \dots, L\}$ computes pre-activations $z^{(\ell)} = W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}$ and post-activations $a^{(\ell)} = \phi_\ell(z^{(\ell)})$. During training, the intermediate tensors $a^{(\ell-1)}$ and $z^{(\ell)}$ are saved on the forward tape because the backward pass needs them to evaluate local Jacobians.
    • The Backpropagation Pass (Subseries 2): Rather than perturbing each of the $P$ parameters individually (which would require $O(P)$ forward evaluations), backpropagation applies the multivariable chain rule in reverse mode (from the scalar loss $\mathcal{L} \in \mathbb{R}$ back to layer $1$). It computes the error sensitivity $\delta^{(\ell)} \triangleq \frac{\partial \mathcal{L}}{\partial z^{(\ell)}} \in \mathbb{R}^{d_\ell}$ via the transpose weight matrix $(W^{(\ell+1)})^\top$, and then forms each layer’s weight gradient as the outer product $\nabla_{W^{(\ell)}} \mathcal{L} = \delta^{(\ell)} (a^{(\ell-1)})^\top$ in a single backward sweep.

    3. Unified notation used across both subseries

    Confusion in backpropagation derivations almost always comes from ambiguous matrix dimensions or inconsistent superscripts. Across every chapter in this series, we use one strict, unambiguous convention:

    Symbol Dimensions Definition & Role
    $L$, $\ell \in \{1,\dots,L\}$ Scalar integer Total number of parameterized layers $L$, and layer index $\ell$ ($\ell=0$ is the input layer; $\ell=L$ is the output layer).
    $d_\ell$ Scalar integer Width (number of neurons / features) of layer $\ell$, with $d_0$ input features and $d_L$ outputs.
    $W^{(\ell)}$ $\mathbb{R}^{d_\ell \times d_{\ell-1}}$ Weight matrix of layer $\ell$. Entry $W_{ij}^{(\ell)}$ connects from unit $j$ in layer $\ell-1$ to unit $i$ in layer $\ell$ (row = destination $i$, column = source $j$). Matches PyTorch nn.Linear.weight shape [out_features, in_features].
    $b^{(\ell)}$ $\mathbb{R}^{d_\ell}$ Bias vector of layer $\ell$, with one scalar offset $b_i^{(\ell)}$ per output unit $i \in \{1,\dots,d_\ell\}$.
    $z^{(\ell)}$ $\mathbb{R}^{d_\ell}$ (single) or $Z^{(\ell)} \in \mathbb{R}^{B \times d_\ell}$ (batch) Pre-activation (affine score / logit) vector at layer $\ell$: $z^{(\ell)} = W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}$, or in row-major batch form $Z^{(\ell)} = A^{(\ell-1)} (W^{(\ell)})^\top + \mathbf{1}_B (b^{(\ell)})^\top$.
    $a^{(\ell)}$ $\mathbb{R}^{d_\ell}$ (single) or $A^{(\ell)} \in \mathbb{R}^{B \times d_\ell}$ (batch) Post-activation vector at layer $\ell$: $a^{(\ell)} = \phi_\ell(z^{(\ell)})$, with $a^{(0)} = x$ and $a^{(L)} = \hat{y}$.
    $\delta^{(\ell)}$ $\mathbb{R}^{d_\ell}$ (single) or $G^{(\ell)} \in \mathbb{R}^{B \times d_\ell}$ (batch) Backpropagated error sensitivity (adjoint) wrt pre-activations: $\delta_i^{(\ell)} \triangleq \dfrac{\partial \mathcal{L}}{\partial z_i^{(\ell)}}$. Has the exact same shape as $z^{(\ell)}$ and $b^{(\ell)}$.
    $\nabla_{W^{(\ell)}} \mathcal{L}$ $\mathbb{R}^{d_\ell \times d_{\ell-1}}$ Gradient of scalar loss $\mathcal{L}$ wrt $W^{(\ell)}$ in denominator-layout (numerator-shape) convention, so $W^{(\ell)} - \eta \nabla_{W^{(\ell)}} \mathcal{L}$ is directly well-typed.

    5. How this series connects to the rest of Deep Learning

    Once you understand how the forward pass builds representations and how backpropagation computes exact gradients, every other deep-learning component plugs into a specific slot of the recurrence:

    • Activation Functions choose the point-wise nonlinearity $\phi_\ell(z)$ and its local derivative $\phi_\ell'(z)$ that gates backward error signals.
    • Weight Initialization sets the starting variance $\operatorname{Var}(W_{ij}^{(\ell)})$ so neither $a^{(\ell)}$ nor $\delta^{(\ell)}$ explodes or vanishes at step $0$.
    • Normalization Layers (BatchNorm, LayerNorm, RMSNorm) standardize $z^{(\ell)}$ or $a^{(\ell)}$ across batch or feature axes to stabilize deep Jacobian products.
    • Regularization modifies either the forward graph (Dropout, Stochastic Depth), the data/targets (Mixup, Label Smoothing), or the parameter update (Weight Decay, SAM).
    • Optimizers turn the raw backpropagation gradients $\nabla_\theta \mathcal{L}$ into parameter steps via momentum, adaptive second moments (Adam), or matrix orthogonalization (Muon, Shampoo).
