    Neural Networks: Foundations, Feed-Forward Pass, and Backpropagation

    October 2026 · 6 min read

    Classical linear models require you to engineer the feature map $\phi(x)$ by hand before fitting a single weight vector. A multilayer neural network learns the representation $\phi_\theta(x)$ and the predictor jointly by composing layers of artificial neurons and alternating two passes: a feed-forward pass that maps inputs to predictions while caching layer states, and a backpropagation pass that propagates error sensitivities in reverse to compute exact gradients for every parameter in one sweep.

    1. Anatomy of a Multilayer Neural Network

    An $L$-layer feed-forward neural network arranges units into sequential layers $\ell = 0, 1, \dots, L$. Layer $0$ holds the raw input features $a^{(0)} = x \in \mathbb{R}^{d_0}$; hidden layers $\ell \in \{1, \dots, L-1\}$ extract progressively folded feature representations $a^{(\ell)} \in \mathbb{R}^{d_\ell}$; and the output layer $\ell = L$ produces the prediction $\hat{y} = a^{(L)} \in \mathbb{R}^{d_L}$ evaluated by a scalar loss $\mathcal{L}(\hat{y}, y)$.
