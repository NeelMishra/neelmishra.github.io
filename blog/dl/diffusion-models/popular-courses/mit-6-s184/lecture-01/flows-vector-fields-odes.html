    Flows, Vector Fields & ODEs

    September 2026 · 24 min read · MIT 6.S184, Lecture 1

    The geometric picture. A vector field assigns a velocity to every point in space. An ODE says that a particle's instantaneous velocity must equal the field at its current location. A flow is the collection of all trajectories produced from all initial points.

    Trajectory: one particle through time

    A trajectory is a function

    $$X:[0,1]\to\mathbb R^d,\qquad t\mapsto X_t.$$

    $X_t$ is the particle's position at time $t$. A trajectory is an entire curve, not just an endpoint. Giving $X_0=x_0$ fixes its initial condition.

    Vector field: one velocity at every point and time

    A time-dependent vector field is

    $$u:\mathbb R^d\times[0,1]\to\mathbb R^d,\qquad (x,t)\mapsto u_t(x).$$

    The input is a position and time; the output is a velocity vector. The field is a rule over the whole space. It does not describe only one particle.

    ODE: the trajectory must follow the field

    The ordinary differential equation is

    $$\boxed{\frac{dX_t}{dt}=u_t(X_t),\qquad X_0=x_0}.$$

    The left side is the trajectory's instantaneous velocity. The right side looks up the velocity prescribed by the field at the particle's current position. Equality means the curve follows the arrows.

    Flow map: move every possible initial point

    For each initial point $x_0$, solving the ODE produces a position at time $t$. The flow map collects that operation:

    $$\psi:\mathbb R^d\times[0,1]\to\mathbb R^d,\qquad (x_0,t)\mapsto\psi_t(x_0).$$
    ObjectMeaning
    $u_t(x)$Velocity assigned at location $x$ and time $t$.
    $X_t$One particle's position along one trajectory.
    $\psi_t(x_0)$Where the initial point $x_0$ has moved by time $t$.
    $\{\psi_t(x_0):x_0\in\mathbb R^d\}$The whole space transported by the flow.

    Why uniqueness matters

    If the vector field is Lipschitz in space (continuous differentiability with bounded spatial derivatives is a convenient sufficient condition), the initial-value problem has a unique solution.

    No ambiguous future. Given the same $x_0$ and the same field, the trajectory cannot split into two different paths. Two trajectories also cannot meet at the same point and time and then have different pasts without violating uniqueness backward in time.

    This makes $\psi_t$ a well-defined map and, under the usual regularity assumptions, invertible by integrating the dynamics backward.

    A solvable example: linear contraction

    Consider the one-dimensional field

    $$u(x)=-\theta x,\qquad \theta>0.$$

    Points to the right move left; points to the left move right. Speed is proportional to distance from zero. The claimed solution is

    $$X_t=e^{-\theta t}x_0.$$

    It satisfies both requirements:

    $$X_0=e^0x_0=x_0,$$
    $$\frac{dX_t}{dt}=-\theta e^{-\theta t}x_0=-\theta X_t=u(X_t).$$

    From one moving point to a moving distribution

    An ODE tells one initial point where to go. A generative model repeats that same rule for a random collection of initial points.

    One fixed starting point

    Choose $X_0=x_0$. The ODE produces one deterministic position:

    $$X_t=\psi_t(x_0).$$

    One random starting point

    Draw $X_0\sim p_{\mathrm{init}}$. Different draws enter the same map at different locations:

    $$X_t=\psi_t(X_0).$$

    The map $\psi_t$ is deterministic in both cases. The second output is random only because its input $X_0$ was random.

    Think of a cloud, not a single dot. The ODE moves every dot in the source cloud. At time $t$, the relocated cloud has a new shape, spread, and therefore a new probability distribution $p_t$.

    A concrete example: contraction changes the whole cloud

    For the linear flow above, $\psi_t(x_0)=e^{-\theta t}x_0$. Suppose the selected time gives $e^{-\theta t}=1/2$. Then every starting point is halved:

    Initial sample $x_0$$-2$$-1$$0$$1$$2$
    Moved sample $\psi_t(x_0)$$-1$$-0.5$$0$$0.5$$1$

    No probability disappears. The same samples now occupy half the width, so their distribution is more concentrated around zero.

    The calculation is exact for a Gaussian source. If

    $$X_0\sim\mathcal N(0,1),$$

    then scaling a random variable by $e^{-\theta t}$ scales its standard deviation by the same factor and its variance by the square:

    $$\boxed{X_t=e^{-\theta t}X_0\sim\mathcal N\!\left(0,e^{-2\theta t}\right)}.$$

    At the particle level, each point moves inward. At the distribution level, the Gaussian becomes narrower. These are two views of the same flow.

    Pushforward is a name for this three-step experiment

    1. Draw$X_0\sim p_{\mathrm{init}}$
    →
    2. Move$X_t=\psi_t(X_0)$
    →
    3. Observe the cloud$X_t\sim p_t$

    The resulting distribution is written

    $$\boxed{p_t=(\psi_t)_\#p_{\mathrm{init}}}.$$

    Read it from right to left: start with $p_{\mathrm{init}}$, apply $\psi_t$ to every sample, and call the output distribution $p_t$. The symbol $\#$ does not perform another operation on individual points; it says that the entire distribution has been carried through the map.

    The formal statement only tracks where probability went

    For any region $A$ in the output space,

    $$\Pr(X_t\in A)=\Pr\!\left(X_0\in\psi_t^{-1}(A)\right).$$

    The probability found inside $A$ after transport is exactly the probability that started in the set of points mapped into $A$. A flow rearranges probability mass; it does not create or destroy it.

    The goal of a generative flow

    At $t=0$, the flow map is the identity, so the distribution is still $p_{\mathrm{init}}$. Training seeks a vector field whose time-one map reshapes that easy source cloud into the data distribution:

    $$X_0\sim p_{\mathrm{init}} \quad\xrightarrow{\ \psi_1\ }\quad X_1\sim p_{\mathrm{data}},$$

    or, in pushforward notation,

    $$\boxed{(\psi_1)_\#p_{\mathrm{init}}\approx p_{\mathrm{data}}}.$$

    The match is between distributions, not between a particular noise sample and a predetermined data point. If many independent source samples are transported, their output cloud should have the same statistical structure as the data.
