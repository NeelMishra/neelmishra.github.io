    Euler Sampling & Neural Flow Models

    September 2026 · 20 min read · MIT 6.S184, Lecture 1

    Knowing the vector field is not enough. A neural network can return the velocity at any position and time, but a generated sample requires the endpoint of an entire trajectory. Numerical integration turns local velocity queries into that endpoint.

    Most ODEs do not have a usable closed form

    The linear ODE $\dot X_t=-\theta X_t$ has the exact solution $X_t=e^{-\theta t}X_0$. A neural vector field can be nonlinear, time-dependent, and high-dimensional, so an analytic formula for $X_1$ is generally unavailable.

    The alternative is to divide $[0,1]$ into small time steps and approximate the trajectory.

    Derive Euler's method

    Start from the definition of a derivative:

    $$\frac{dX_t}{dt}=\lim_{h\to0}\frac{X_{t+h}-X_t}{h}=u_t(X_t).$$

    For a small but finite $h$, replace the limit by an approximation:

    $$\frac{X_{t+h}-X_t}{h}\approx u_t(X_t).$$

    Rearrange:

    $$\boxed{X_{t+h}\approx X_t+h\,u_t(X_t)}.$$

    Euler's method follows the current arrow for a short time, asks for a new arrow at the new position, and repeats.

    Euler simulation

    Euler method for $\dot X_t=u_t(X_t)$
    1Choose the number of steps $n$ and set $h=1/n$.
    2Set $t_0=0$ and $X_0=x_0$.
    3for $k=0,\ldots,n-1$:
    4$X_{k+1}\leftarrow X_k+h\,u_{t_k}(X_k)$
    5$t_{k+1}\leftarrow t_k+h$
    6Return $X_0,\ldots,X_n$ or only the endpoint $X_n$.

    Exact versus Euler on the linear flow

    For $u(x)=-\theta x$, one Euler step is

    $$X_{k+1}=(1-\theta h)X_k.$$

    After $n$ steps with $h=1/n$:

    $$X_n=\left(1-\frac{\theta}{n}\right)^nX_0\longrightarrow e^{-\theta}X_0.$$

    Local and global error

    For a smooth trajectory, Taylor expansion gives

    $$X_{t+h}=X_t+h\,u_t(X_t)+O(h^2).$$

    One Euler step has local error $O(h^2)$. About $1/h$ steps are taken over a unit interval, so the accumulated global error is $O(h)$ once $h$ is in the sufficiently small, stable regime.

    Smaller $h$ is eventually more accurate but more expensive. In the small-step regime, halving $h$ approximately halves first-order Euler error and doubles vector-field evaluations. Coarse steps can behave non-monotonically or become unstable. Modern samplers use better integrators or adaptive steps to improve this trade-off.

    Step size can change qualitative behavior

    For the stable ODE $\dot X=-\theta X$, the Euler multiplier is $1-\theta h$. Euler contracts only when

    $$|1-\theta h|<1\qquad\Longleftrightarrow\qquad0<\theta h<2.$$

    A step that is too large can oscillate or explode even though the true solution smoothly decays. Numerical stability is a property of the solver, not just the differential equation.

    Replace the vector field with a neural network

    A flow model represents the time-dependent field with parameters $\theta$:

    $$u^\theta:\mathbb R^d\times[0,1]\to\mathbb R^d.$$

    The network receives the current sample $X_k$ and time $t_k$, then returns a vector with the same dimension as the sample. That vector is the instantaneous velocity used by the solver.

    Sampling from a flow model

    Flow-model sampler
    1Draw $X_0\sim p_{\text{init}}$, usually Gaussian noise.
    2Set $h=1/n$ and $t=0$.
    3repeat $n$ times:
    4$X\leftarrow X+h\,u^\theta_t(X)$
    5$t\leftarrow t+h$
    6Return $X\approx X_1$.

    What happens to a batch of noise

    Each noise vector follows its own deterministic trajectory through the same learned field. A batch therefore changes shape over time:

    $t=0$simple Gaussian cloud
    →
    $0<t<1$intermediate probability path
    →
    $t=1$data-shaped cloud

    Randomness enters only through $X_0$. Re-running the ODE from the same $X_0$ produces the same output, apart from numerical solver error.

    Where the field comes from

    Lecture 1 treats $u^\theta_t$ as already learned. A later flow-matching objective will construct training targets for velocities along a chosen probability path. Sampling and training should remain conceptually separate:

    • Training: choose $\theta$ so $u^\theta_t$ approximates the desired transport field.
    • Sampling: hold $\theta$ fixed and numerically integrate the ODE from fresh noise.
