    Conditional & Marginal Probability Paths

    September 2026 · 17 min read · MIT 6.S184: Generative AI with Stochastic Differential Equations, Lecture 2

    The training-target problem. Sampling would be easy if the correct velocity field were known. The difficulty is that the data distribution, its intermediate probability path, and the corresponding marginal velocity field are all unknown. The escape route is to construct simple paths one data point at a time.

    What must be learned?

    A neural vector field $u_t^\theta$ should transport an easy source distribution into the data distribution:

    $$X_0\sim p_{\mathrm{init}},\qquad \frac{d}{dt}X_t=u_t^\theta(X_t),\qquad X_1\sim p_{\mathrm{data}}.$$

    A supervised squared-error objective would be natural if a target velocity were available:

    $$\mathcal L(\theta)=\mathbb E\!\left[\left\|u_t^\theta(x)-u_t^{\mathrm{target}}(x)\right\|^2\right].$$

    But the desired marginal target $u_t^{\mathrm{target}}(x)$ is not directly known. Lecture 2 constructs a target that can actually be sampled.

    Conditional means one point; marginal means the whole dataset

    Let $z\sim p_{\mathrm{data}}$ denote one randomly chosen data example.

    Conditional: fix $z$

    $p_t(x\mid z)$ describes a path from noise to this one data point. During the discussion of this path, $z$ is held fixed.

    Marginal: average over $z$

    $p_t(x)$ combines the conditional paths for all possible data points, weighted by how often those points occur in $p_{\mathrm{data}}$.

    Keep this distinction

    Conditional is a single noise-to-example bridge. Marginal is the distribution seen after randomly choosing the example and then forgetting which example was chosen.

    Define a conditional probability path

    Conditional probability path. For every fixed data point $z$, the family $(p_t(\cdot\mid z))_{0\le t\le1}$ is a valid distribution at every time and satisfies $$p_0(\cdot\mid z)=p_{\mathrm{init}},\qquad p_1(\cdot\mid z)=\delta_z.$$

    The Dirac distribution $\delta_z$ puts all its probability at $z$. Thus every conditional path begins at the same noise distribution and ends at its own selected data point.

    A Gaussian path is analytically convenient

    Take $p_{\mathrm{init}}=\mathcal N(0,I_d)$ and choose two scalar schedules $\alpha_t$ and $\beta_t$:

    $$\boxed{p_t(x\mid z)=\mathcal N\!\left(x;\alpha_t z,\beta_t^2 I_d\right)}.$$

    The mean $\alpha_t z$ moves toward $z$ while the standard deviation $\beta_t$ shrinks. The endpoint conditions are

    TimeSchedule valuesResulting distribution
    $t=0$$\alpha_0=0,\ \beta_0=1$$\mathcal N(0,I_d)=p_{\mathrm{init}}$
    $t=1$$\alpha_1=1,\ \beta_1=0$$\delta_z$

    The simplest choice is the straight-line schedule:

    $$\alpha_t=t,\qquad \beta_t=1-t.$$

    Other schedules can be used. The endpoint constraints define where the path starts and ends; the schedule controls how it travels between them.

    Sample the path without evaluating a density

    Draw standard Gaussian noise $\varepsilon\sim\mathcal N(0,I_d)$ and set

    $$\boxed{X_t=\alpha_t z+\beta_t\varepsilon}.$$

    Scaling $\varepsilon$ by $\beta_t$ gives covariance $\beta_t^2I_d$, and shifting by $\alpha_tz$ gives the desired mean. Therefore

    $$X_t\mid z\sim\mathcal N(\alpha_tz,\beta_t^2I_d)=p_t(\cdot\mid z).$$

    This reparameterization is crucial: training can sample $X_t$ using only a data example, Gaussian noise, and a time value.

    Average the bridges to obtain the marginal path

    Choose $Z\sim p_{\mathrm{data}}$ and then $X_t\sim p_t(\cdot\mid Z)$. Once $Z$ is hidden, the density of $X_t$ is

    $$\boxed{p_t(x)=\int p_t(x\mid z)\,p_{\mathrm{data}}(z)\,dz}.$$

    This is simply the law of total probability. The endpoint calculation explains why the construction works:

    0

    Every conditional starts from the same source distribution.

    $$p_0(x)=\int p_{\mathrm{init}}(x)p_{\mathrm{data}}(z)\,dz=p_{\mathrm{init}}(x).$$
    1

    Every conditional ends at its selected data point.

    $$p_1(x)=\int \delta_z(x)p_{\mathrm{data}}(z)\,dz=p_{\mathrm{data}}(x).$$

    So the marginal path has exactly the desired endpoints even though it was built entirely from easy conditional paths.

    Watch conditional paths become a marginal path

    Three details that prevent common confusion

    1. $z$ is data, not the current state. It selects which conditional path is being discussed.
    2. $x$ is a possible location at time $t$. Under the noise representation, one sample is $x=\alpha_tz+\beta_t\varepsilon$.
    3. The marginal path is usually not one Gaussian. Averaging many conditional Gaussians generally produces a complicated mixture, which is exactly how data structure emerges.

    Check yourself
