    Gaussian Conditional Vector Fields

    September 2026 · 18 min read · MIT 6.S184, Lecture 2

    A path says where probability should be; a vector field says how samples must move. For the Gaussian conditional path, the exact velocity can be derived by differentiating the same sample construction used to generate training points.

    Start from the Gaussian sample path

    Fix a data point $z$ and draw $X_0=\varepsilon\sim\mathcal N(0,I_d)$. Define

    $$X_t=\alpha_tz+\beta_tX_0.$$

    Then $X_t\mid z\sim\mathcal N(\alpha_tz,\beta_t^2I_d)$. For each fixed $X_0$, this equation also describes a deterministic trajectory through space.

    Differentiate one trajectory

    The instantaneous velocity is the time derivative:

    $$\frac{d}{dt}X_t=\dot\alpha_tz+\dot\beta_tX_0.$$

    This is already a usable target when $X_0=\varepsilon$ is retained. A vector field, however, is conventionally written as a function of the current location $x$, not the hidden starting point $X_0$.

    Replace the starting point with the current position

    Whenever $\beta_t\ne0$, rearrange the sample path:

    1

    Start from the current location.

    $$x=\alpha_tz+\beta_tX_0.$$
    2

    Solve for the initial noise.

    $$X_0=\frac{x-\alpha_tz}{\beta_t}.$$
    3

    Substitute it into $\dot\alpha_tz+\dot\beta_tX_0$.

    $$u_t^{\mathrm{target}}(x\mid z)=\dot\alpha_tz+\frac{\dot\beta_t}{\beta_t}(x-\alpha_tz).$$

    Expanding the final expression gives the equivalent form commonly displayed in the lecture:

    $$\boxed{u_t^{\mathrm{target}}(x\mid z)=\left(\dot\alpha_t-\frac{\dot\beta_t}{\beta_t}\alpha_t\right)z+\frac{\dot\beta_t}{\beta_t}x}.$$

    Why this field follows the intended path

    Insert $X_t=\alpha_tz+\beta_tX_0$ into the field:

    $$\begin{aligned} u_t^{\mathrm{target}}(X_t\mid z) &=\dot\alpha_tz+\frac{\dot\beta_t}{\beta_t}(X_t-\alpha_tz)\\ &=\dot\alpha_tz+\frac{\dot\beta_t}{\beta_t}(\beta_tX_0)\\ &=\dot\alpha_tz+\dot\beta_tX_0 =\frac{d}{dt}X_t. \end{aligned}$$

    Therefore $X_t$ solves the ODE driven by this field. Since $X_0\sim\mathcal N(0,I_d)$, the ODE's distribution at every time is exactly $p_t(\cdot\mid z)$.

    The straight-line schedule becomes especially simple

    Choose $\alpha_t=t$ and $\beta_t=1-t$. Then $\dot\alpha_t=1$ and $\dot\beta_t=-1$:

    $$X_t=(1-t)\varepsilon+tz.$$

    Differentiating this expression immediately gives

    $$\boxed{\frac{d}{dt}X_t=z-\varepsilon}.$$

    The same velocity expressed using only $x$, $z$, and $t$ is

    $$u_t^{\mathrm{target}}(x\mid z)=\frac{z-x}{1-t}.$$

    These formulas agree on a sampled point because $z-X_t=(1-t)(z-\varepsilon)$.

    Why the denominator is not a training problem. The location-based form appears singular as $t\to1$. Training can use the noise-based form $\dot\alpha_tz+\dot\beta_t\varepsilon$, which equals $z-\varepsilon$ for the straight-line schedule and remains finite.

    Follow one noise-to-data trajectory

    Why conditional fields solve the first obstacle

    The target uses quantities that training can generate:

    Sample$z,\varepsilon,t$
    →
    Construct input$x=\alpha_tz+\beta_t\varepsilon$
    →
    Construct target$\dot\alpha_tz+\dot\beta_t\varepsilon$

    No data density, conditional density, or ODE solve is needed to create a labeled training pair. One problem remains: the conditional target depends on $z$, while the generative ODE must use a field of $x$ and $t$ alone. Marginalization resolves that mismatch.
