    Regularization in Deep Learning: Reading Guide

    September 2026 · 3 min read + interactive lab

    A connected guide with derivations, worked examples, original figures, and interactive experiments.

    Regularization changes the solutions a training procedure tends to choose. It can act on weights, activations, examples, targets, local sensitivity, or the optimization path. Start with the mechanism you want to understand; the chapters make the assumptions and tradeoffs explicit.

    How to study the experiments

    Read the worked calculation, predict what a control will change, then run the experiment. Values come from the equations or a specified small dataset; they are not fabricated benchmark curves. Every interactive result has text readouts, and the main explanation also works with the static figures.

    Keep these distinctions visible

    $L$ is the data loss, $J$ includes any added penalty, and $\lambda$ controls its strength. A smaller training loss is not the same as better generalization. Validation chooses settings; a held-out test set estimates the resulting procedure’s performance. Penalty coefficients must be interpreted together with loss reduction and parameter scaling.
