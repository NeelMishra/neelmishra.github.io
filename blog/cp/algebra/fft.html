    Fast Fourier Transform

    July 2026 · 30 min read

    1 — The Big Picture

    Multiplying two degree-n polynomials takes Θ(n²) in coefficient form. But in point-value form, multiplication is Θ(n)—just multiply corresponding values. The strategy is:

    1. Evaluate both polynomials at N ≥ 2n + 1 carefully chosen points — O(n log n)
    2. Multiply the point values pairwise — O(n)
    3. Interpolate back to coefficients — O(n log n)

    The “carefully chosen points” are the N-th roots of unity, and the conversion is the Discrete Fourier Transform (DFT). The Fast Fourier Transform (FFT) computes the DFT in O(n log n) instead of O(n²).

    Historical note. The algorithm is often attributed to Cooley and Tukey (1965), but Gauss knew it in 1805. It was rediscovered independently by several researchers in the 20th century.

    2 — Roots of Unity

    The N-th roots of unity are the N complex numbers satisfying z^N = 1. They are

    ωₙᵏ = e^{2πik/N} = cos(2πk/N) + i·sin(2πk/N)     k = 0, 1, …, N−1

    where ωₙ = e^{2πi/N} is the primitive N-th root of unity. Key properties:

    Property 1: Cancellation lemma

    ω_{dN}^{dk} = ω_N^k     for any positive integer d

    Proof: ω_{dN}^{dk} = e^{2πi·dk/(dN)} = e^{2πik/N} = ω_N^k. ∎

    Property 2: Halving lemma

    The squares of the N-th roots of unity (N even) are the (N/2)-th roots of unity.

    Proof: (ω_N^k)² = ω_N^{2k} = ω_{N/2}^k (by cancellation with d=2). Also, (ω_N^{k+N/2})² = ω_N^{2k+N} = ω_N^{2k} · ω_N^N = ω_N^{2k} · 1 = (ω_N^k)². So the N squares collapse to N/2 distinct values. ∎

    Property 3: Summation lemma

    Σ_{k=0}^{N−1} (ω_N^j)^k = 0     for j ≢ 0 (mod N)

    Proof: This is a geometric series with ratio r = ω_N^j ≠ 1. Sum = (r^N − 1)/(r − 1) = ((ω_N^N)^j − 1)/(r − 1) = (1 − 1)/(r − 1) = 0. ∎

    When j ≡ 0 (mod N), every term is 1, so the sum is N.

    3 — The Discrete Fourier Transform

    3.1 Definition

    Given a coefficient vector a = (a₀, a₁, …, a_{N−1}), the DFT produces ŷ = (y₀, y₁, …, y_{N−1}) where

    yₖ = Σ_{j=0}^{N−1} aⱼ · ωₙ^{jk}     k = 0, 1, …, N−1

    Equivalently, yₖ = A(ωₙᵏ)—we are evaluating the polynomial A(x) = Σ aⱼxʲ at each N-th root of unity.

    3.2 Matrix form

    Let Fₙ be the N×N matrix with entry F_{k,j} = ω_N^{jk}. Then

    ŷ = Fₙ · a

    The matrix Fₙ is the DFT matrix. It is a Vandermonde matrix evaluated at the roots of unity.

    3.3 The DFT matrix is unitary (up to scaling)

    Theorem: F̄ₙᵀ · Fₙ = N · Iₙ, or equivalently (1/√N)Fₙ is unitary.

    Proof: The (r, s) entry of F̄ₙᵀ · Fₙ is

    (F̄ₙᵀ · Fₙ)_{r,s} = Σ_{k=0}^{N−1} F̄_{k,r} · F_{k,s}
                    = Σ_{k=0}^{N−1} ω_N^{−kr} · ω_N^{ks}
                    = Σ_{k=0}^{N−1} ω_N^{k(s−r)}

    By the summation lemma:

    • If s = r: the sum equals N.
    • If s ≠ r: the sum equals 0.

    Therefore F̄ₙᵀ · Fₙ = N · Iₙ. ∎

    4 — Inverse DFT

    Since Fₙ⁻¹ = (1/N) F̄ₙᵀ, the inverse transform is

    aⱼ = (1/N) Σ_{k=0}^{N−1} yₖ · ω_N^{−jk}     j = 0, 1, …, N−1
    Key observation. The IDFT has exactly the same structure as the DFT, with two differences: (1) we use ω_N^{−1} instead of ω_N, and (2) we divide by N at the end. This means the same code computes both DFT and IDFT!

    Proof of the IDFT formula: Substitute the DFT definition into the right-hand side:

    (1/N) Σ_{k=0}^{N−1} yₖ · ω_N^{−jk}
= (1/N) Σ_{k=0}^{N−1} [Σ_{m=0}^{N−1} aₘ ω_N^{mk}] · ω_N^{−jk}
= (1/N) Σ_{m=0}^{N−1} aₘ · [Σ_{k=0}^{N−1} ω_N^{(m−j)k}]

    By the summation lemma, the inner sum is N if m = j and 0 otherwise. So the entire expression reduces to aⱼ. ∎

    5 — Cooley-Tukey: From O(n²) to O(n log n)

    5.1 Divide and conquer

    Assume N is a power of 2. Split the polynomial into even- and odd-indexed coefficients:

    A(x) = A_even(x²) + x · A_odd(x²)
where
  A_even(y) = a₀ + a₂y + a₄y² + …
  A_odd(y)  = a₁ + a₃y + a₅y² + …

    To compute A(ω_N^k) for k = 0, …, N−1:

    A(ω_N^k) = A_even(ω_N^{2k}) + ω_N^k · A_odd(ω_N^{2k})
         = A_even(ω_{N/2}^k) + ω_N^k · A_odd(ω_{N/2}^k)

    Here we used the halving lemma: ω_N^{2k} = ω_{N/2}^k.

    5.2 The butterfly

    For k = 0, …, N/2 − 1, define:

    e_k = A_even(ω_{N/2}^k)
o_k = A_odd(ω_{N/2}^k)

    Then we get both halves of the output from the same sub-results:

    y_k       = e_k + ω_N^k · o_k       (first half)
y_{k+N/2} = e_k − ω_N^k · o_k       (second half)

    Proof of the second half:

    A(ω_N^{k+N/2}) = A_even(ω_N^{2k+N}) + ω_N^{k+N/2} · A_odd(ω_N^{2k+N})
               = A_even(ω_N^{2k} · ω_N^N) + ω_N^k · ω_N^{N/2} · A_odd(ω_N^{2k} · ω_N^N)
               = A_even(ω_{N/2}^k) · 1  +  ω_N^k · (−1) · A_odd(ω_{N/2}^k)
               = e_k − ω_N^k · o_k   ∎

    We used ω_N^N = 1 and ω_N^{N/2} = e^{πi} = −1.

    5.3 Recurrence and complexity

    Each level of recursion halves the problem size and does O(N) butterfly operations:

    T(N) = 2T(N/2) + O(N)   →   T(N) = O(N log N)

    6 — Polynomial Multiplication via FFT

    6.1 The algorithm

    1. Choose N = 2⌈log₂(m+n+1)⌉ (next power of 2 ≥ m+n+1).
    2. Pad both polynomials to length N with zeros.
    3. Compute ŷ_A = DFT(A) and ŷ_B = DFT(B).
    4. Compute ŷ_C[k] = ŷ_A[k] · ŷ_B[k] for each k.
    5. Compute C = IDFT(ŷ_C). The real parts of C are the product coefficients.

    Total: O(n log n) — two DFTs, one IDFT, and O(n) pointwise multiplications.

    6.2 Correctness

    By the convolution theorem, pointwise multiplication in the frequency domain corresponds to convolution in the time domain:

    DFT(A * B) = DFT(A) ⊙ DFT(B)

    where ⊙ is pointwise multiplication and * is polynomial multiplication (convolution). Applying IDFT to both sides gives A * B = IDFT(DFT(A) ⊙ DFT(B)). ∎

    6.3 C++ implementation (recursive)

    #include <vector>
#include <complex>
#include <cmath>
using cd = std::complex<double>;
const double PI = acos(-1.0);

void fft(std::vector<cd>& a, bool invert) {
    int n = (int)a.size();
    if (n == 1) return;

    std::vector<cd> a0(n / 2), a1(n / 2);
    for (int i = 0; i < n / 2; ++i) {
        a0[i] = a[2 * i];
        a1[i] = a[2 * i + 1];
    }
    fft(a0, invert);
    fft(a1, invert);

    double angle = 2 * PI / n * (invert ? -1 : 1);
    cd w(1), wn(cos(angle), sin(angle));

    for (int i = 0; i < n / 2; ++i) {
        cd t = w * a1[i];         // twiddle factor
        a[i]         = a0[i] + t; // butterfly
        a[i + n / 2] = a0[i] - t;
        w *= wn;
    }

    if (invert) {
        for (auto& x : a) x /= n;
        // Note: division by n should only happen at
        // the top level. This recursive version divides
        // at each level but the net effect is dividing
        // by n once (each element is divided by 2 at
        // each of log(n) levels: 2^log(n) = n).
    }
}

std::vector<long long> multiply(std::vector<int> const& a,
                                 std::vector<int> const& b) {
    std::vector<cd> fa(a.begin(), a.end());
    std::vector<cd> fb(b.begin(), b.end());

    int n = 1;
    while (n < (int)(a.size() + b.size()))
        n <<= 1;
    fa.resize(n);
    fb.resize(n);

    fft(fa, false);   // DFT
    fft(fb, false);

    for (int i = 0; i < n; ++i)
        fa[i] *= fb[i]; // pointwise multiply

    fft(fa, true);    // IDFT

    std::vector<long long> result(n);
    for (int i = 0; i < n; ++i)
        result[i] = llround(fa[i].real());

    // trim trailing zeros
    while (result.size() > 1 && result.back() == 0)
        result.pop_back();
    return result;
}
    Precision warning. Floating-point FFT introduces rounding errors. For integer coefficients up to ~10⁹ and n up to ~10⁶, llround usually gives the correct answer. Beyond that, use the Number Theoretic Transform (Part 5) for exact arithmetic.

    Key takeaways:

    • Roots of unity provide the magic evaluation points that make FFT work.
    • The halving lemma is what enables the divide-and-conquer: the squares of N roots collapse to N/2 roots.
    • IDFT is structurally identical to DFT, so one function handles both.
    • In the next post, we replace complex roots of unity with primitive roots modulo a prime to get exact integer convolution via the Number Theoretic Transform (NTT).
