    Dynamic Programming Patterns by Recurrence Shape: 56 LeetCode Problems to Master DP

    October 2026 · 28 min read · Module 8: Dynamic Programming

    Organizing Dynamic Programming (DP) problems by recurrence shape and state-transition structure rather than surface-level problem topics transforms how you approach both competitive programming and technical interviews. Rather than memorizing 100 disconnected problem solutions, the goal is to recognize a compact set of 17 recurring state and transition archetypes across 56 canonical LeetCode problems.

    How this series is organized. Every pattern in this guide provides four concrete pillars:
    1. How to recognize it from the problem statement and constraints.
    2. The core recurrence or state-transition template in both mathematical and C++ form.
    3. Curated practice problems ordered deliberately from foundational to advanced.
    4. Key observations & structural contrasts between problems that look superficially similar but require different transitions or loop orders.

    The 17 DP Patterns at a Glance

    Below is the complete taxonomy of all 17 recurrence patterns, their state definitions, canonical transition equations, and practice progressions.

    # Pattern Name Recognition Signal Core Recurrence Template Practice Problems (Easy → Hard)
    1 Linear DP: Fibonacci, Take or Skip Answer at index $i$ depends on a small fixed window of preceding states ($i-1, i-2$), or a binary take/skip decision on element $i$. dp[i] = dp[i-1] + dp[i-2]
    dp[i] = max(dp[i-1], nums[i] + dp[i-2])    		 70, 746, 198, 91, 213, 337
    2 Reachability & Minimum-Jump DP Array specifies max jump lengths; determine reachability or minimum jumps to reach the end (often reducible to greedy). canReach[i] |= canReach[j]
    dp[i] = min(dp[i], dp[j] + 1)    		 55, 45
    3 Kadane's Algorithm: Best Subarray Ending Here Optimize a contiguous subarray by choosing at each index $i$ whether to extend the subarray ending at $i-1$ or start fresh at $i$. best[i] = max(nums[i], best[i-1] + nums[i]) 53, 152
    4 State-Machine DP: Stock Buy & Sell At each index $i$, you occupy one of a small set of discrete states (hold, cash, cooldown, tx count $k$) with directed transitions. hold[i] = max(hold[i-1], cash[i-1] - prices[i])
    cash[i] = max(cash[i-1], hold[i-1] + prices[i])    		 121, 122, 714, 309, 123, 188
    5 LIS: Longest Increasing Subsequence Select elements in original order satisfying a strict comparative chain ($nums[j] < nums[i]$ for $j < i$). dp[i] = 1 + max(dp[j]) for $j < i, \text{nums}[j] < \text{nums}[i]$ 646, 300, 673, 354
    6 DAG DP: Longest Increasing Path in a Matrix Transitions move along strictly increasing (acyclic) edges in a matrix or graph; solved via memoized DFS or topological sort. dp[u] = 1 + max(dp[v]) for valid neighbors $v$ 329
    7 Two-Sequence DP: LCS & Alignment Compare two strings/arrays; answer depends on prefixes $s[0..i-1]$ and $t[0..j-1]$. Match: dp[i-1][j-1] + 1
    Mismatch: max(dp[i-1][j], dp[i][j-1])    		 1143, 1035, 583, 72, 97, 115
    8 Pattern-Matching DP: Wildcards & Regex Test whether prefix $s[0..i-1]$ matches pattern prefix $p[0..j-1]$ with wildcard symbols (?, ., *). dp[i][j] = boolean match of prefixes $(i, j)$ 44, 10
    9 Grid Path DP: Min/Max Cost or Ways Navigate a 2D grid or triangle under directional move constraints, optimizing cost, survival health, or path count. dp[r][c] = grid[r][c] + min(dp[r-1][c], dp[r][c-1]) 62, 63, 64, 120, 931, 174
    10 Two-Dimensional Shape DP Discover the largest valid square or rectangle of 1s inside a binary matrix using neighbor boundaries or row histograms. dp[r][c] = 1 + min(dp[r-1][c], dp[r][c-1], dp[r-1][c-1]) 221, 85
    11 Palindrome DP Evaluate whether substring or subsequence on interval $[i, j]$ is palindromic by matching endpoints $s[i]$ and $s[j]$ inward. Substr: s[i]==s[j] && (j-i<=2 || dp[i+1][j-1])
    Subseq: dp[i+1][j-1] + 2 or max(dp[i+1][j], dp[i][j-1])    		 5, 647, 516, 132
    12 Word Segmentation DP Determine whether string prefix $s[0..i-1]$ can be segmented into dictionary words, or reconstruct all valid sentences. dp[i] = any(dp[j] && isWord(s[j..i-1])) for $j < i$ 139, 140
    13 0/1 Knapsack: Each Item at Most Once Select each item $0$ or $1$ time to reach a target sum or optimize a partition; 1D space compression iterates sums backward. dp[s] = dp[s] || dp[s - val] (loop $s$ high → low) 416, 1049, 494
    14 Unbounded Knapsack: Items Can Be Reused Reuse items/coins infinitely to minimize count, count combinations (coins outer), or count permutations (target outer); 1D iterates forward. dp[a] = combine(dp[a], dp[a - coin]) (loop $a$ low → high) 322, 279, 518, 377
    15 Interval DP: Choose a Split Point Optimize over range $[i, j]$ by trying an intermediate split point $k$ or choosing the last operation inside $[i, j]$; fill by increasing length. dp[i][j] = best_k(dp[i][k] + dp[k][j] + cost(i,k,j)) 1039, 1547, 312
    16 Partition DP: Divide Input into Groups Divide an array of length $n$ into $k$ contiguous groups optimizing total or bottleneck group cost. dp[k][i] = best_{j < i}(dp[k-1][j] + cost(j, i)) 410, 1335
    17 Parentheses DP: Longest Valid Structure Find the longest contiguous balanced-parentheses substring ending at each closing parenthesis index $i$. s[i-1]=='(' ? dp[i-2]+2 : dp[i-1]+2+dp[i-dp[i-1]-2] 32

    The 6 Most Important Structural Connections

    After practicing individual problems, mastery comes from understanding why two problems that look nearly identical require subtly different recurrences or loop structures.

    1. 0/1 Knapsack vs. Unbounded Knapsack

    The defining difference is whether the current item may be reused multiple times:

    • 0/1 Knapsack (Pattern 13): In a 1D rolling array, iterate the capacity/sum backward (for (int s = target; s >= x; --s)) so that dp[s - x] still holds the value from the previous item iteration and item $x$ cannot feed into itself twice.
    • Unbounded Knapsack (Pattern 14): Iterate the capacity/sum forward (for (int a = coin; a <= amount; ++a)) so that dp[a - coin] already includes uses of the current coin, permitting unlimited reuse in $O(1)$ transition time.

    2. Coin Change II vs. Combination Sum IV (Combinations vs. Permutations)

    Both problems count ways to form a target sum with unlimited reuse, yet their loop nesting is flipped:

    • 518. Coin Change II (Combinations): Order does not matter ($1+2$ and $2+1$ are the same combination). Place the coin loop outermost and the amount loop innermost. Because coins are processed in a fixed canonical order, no out-of-order sequence can ever be generated.
    • 377. Combination Sum IV (Ordered Sequences / Permutations): Order matters ($1+2$ and $2+1$ are distinct sequences). Place the target amount loop outermost and the number choice loop innermost, choosing which element comes last at every sum.

    3. LCS vs. Edit Distance vs. Distinct Subsequences

    All three operate on the exact same 2D prefix state space $(i, j)$ over two strings $s[0..i-1]$ and $t[0..j-1]$, proving that table dimensions alone do not determine the recurrence:

    • 1143. LCS: Maximizes matched characters — dp[i][j] = (s[i-1]==t[j-1]) ? dp[i-1][j-1] + 1 : max(dp[i-1][j], dp[i][j-1]).
    • 72. Edit Distance: Minimizes edit operations (insert, delete, replace) — dp[i][j] = (s[i-1]==t[j-1]) ? dp[i-1][j-1] : 1 + min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]}).
    • 115. Distinct Subsequences: Counts valid ways $t$ appears as a subsequence of $s$ — dp[i][j] = dp[i-1][j] + (s[i-1]==t[j-1] ? dp[i-1][j-1] : 0).

    4. Palindrome Substring vs. Palindrome Subsequence

    A substring is contiguous; a subsequence can skip characters. That single word changes the transition when $s[i] == s[j]$ and when $s[i] \neq s[j]$:

    • Substring (LC 5, 647): Requires the inner range $[i+1, j-1]$ to also be a contiguous palindrome. If $s[i] \neq s[j]$, isPal[i][j] is immediately false.
    • Subsequence (LC 516): Always extends the best inner subsequence by $+2$ when $s[i] == s[j]$, and falls back to $\max(dp[i+1][j], dp[i][j-1])$ when $s[i] \neq s[j]$.

    5. LIS vs. Longest Increasing Path in a Matrix

    Both extend a strictly increasing chain via 1 + max(next), but:

    • 300. LIS: Follows the 1D index order $j < i$ of an array (and admits an $O(n \log n)$ binary-search tail array optimization).
    • 329. Longest Increasing Path in a Matrix: Moves across 4-directional grid neighbors where values strictly increase. Because strictly increasing values forbid cycles, the grid forms an implicit Directed Acyclic Graph (DAG) solved in $O(RC)$ via memoized DFS or Kahn's topological sort.

    6. Grid Path DP vs. Maximal Square vs. Maximal Rectangle

    Core principle: A grid is a data structure, not a DP pattern. The transition identifies the pattern.
    • Grid Path DP (LC 62, 64, 174): Optimizes or counts paths from start to destination.
    • 221. Maximal Square: Uses local-neighbor shape bottleneck DP: $\text{dp}[r][c] = 1 + \min(\text{up}, \text{left}, \text{diag})$.
    • 85. Maximal Rectangle: Cannot be solved by a single scalar $\min$ of three neighbors because rectangles have independent width and height; instead, it accumulates row-wise histogram heights and applies a monotonic stack per row.

    Recommended 5-Step DP Derivation Strategy

    Before writing a single line of code on any new DP problem, answer these five questions explicitly:

    1. What does the state mean? Write a one-sentence English specification of dp[i], dp[i][j], or dp[i][state] (including whether indices are 0-based or prefix lengths).
    2. What decisions are available at this state? Take or skip? Match or skip? Pick a split point $k$? Transition to another state-machine node?
    3. Where does the transition come from? Translate the legal decisions directly into a $\min$, $\max$, $\sum$, or $\lor$ over smaller states, and ensure the dependency order (left-to-right, increasing interval length, or DAG topological order) computes prerequisites first.
    4. What are the base cases? Check empty prefixes ($i=0$), single-element intervals ($i=j$), unreachable states ($\pm\infty$), and initial day-0 stock holdings (e.g., $\text{hold}[0] = -\text{prices}[0]$).
    5. Can space be optimized? Inspect which rows or columns the recurrence actually reads. If row $i$ only reads row $i-1$, compress 2D tables to 1D (paying strict attention to forward vs. backward iteration).
    The 5-Stage Practice Pipeline: Whenever you learn a new pattern, practice solving its representative problem through all five stages in sequence:
    1. Brute-force recursion → 2. Top-down memoization → 3. Bottom-up tabulation → 4. Space optimization → 5. Time & space complexity analysis.
