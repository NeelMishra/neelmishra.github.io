In Part 4, we studied transitions over 2D spatial matrices. Now we return to a single string $s[0..n-1]$, where subproblems are defined either by a two-ended substring interval $(i, j)$ that shrinks inward, a prefix $s[0..i-1]$ split at a dictionary boundary $j < i$, or a balanced structure ending at index $i$ that jumps over an already-validated inner block.

1. Pattern 11: Palindrome DP

A palindrome reads the same forwards and backwards, which means its structural recurrence always compares the two outer characters $s[i]$ and $s[j]$ and reduces to the strictly smaller inner interval $(i+1, j-1)$. However, there are two distinct recurrence templates depending on whether the problem asks for a contiguous substring or a non-contiguous subsequence: 

// Template A — Palindromic Substring (contiguous):
isPalindrome[i][j] = (s[i] == s[j]) && (j - i <= 2 || isPalindrome[i + 1][j - 1]);

// Template B — Palindromic Subsequence (deletions allowed):
if (s[i] == s[j]) {
    dp[i][j] = dp[i + 1][j - 1] + 2;
} else {
    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]);
}

Why Iteration Order Matters

Notice that in both templates, state $(i, j)$ depends on $(i+1, j-1)$ — a larger row index $i+1$ and a smaller column index $j-1$. If you iterate $i$ from $0$ to $n-1$ and $j$ from $i$ to $n-1$, then `dp[i+1][j-1]` has not been computed yet! You must either:

  • Iterate by increasing interval length $\text{len} = 1, 2, \dots, n$ (diagonal-by-diagonal), or
  • Iterate $i$ downward from $n-1$ down to $0$, and $j$ upward from $i$ to $n-1$.
Structural Connection #4: Palindromic Substring vs. Palindromic Subsequence

Look closely at what happens when $s[i] \neq s[j]$:

  • In Substring Palindrome DP (LC 5, LC 647), a mismatch at the endpoints immediately kills the candidate: isPalindrome[i][j] = false. Even if $s[i] == s[j]$, the inner substring $s[i+1..j-1]$ must also be a palindrome in its entirety.
  • In Subsequence Palindrome DP (LC 516), we are allowed to skip characters. When $s[i] \neq s[j]$, we drop either $s[i]$ or $s[j]$ and carry forward $\max(dp[i+1][j], dp[i][j-1])$. Even when $s[i] == s[j]$, the inner state $dp[i+1][j-1]$ only needs to be the best subsequence inside, not the entire substring.

Bonus Equivalence: The Longest Palindromic Subsequence of $s$ is identical to the Longest Common Subsequence (Pattern 7, LC 1143) between $s$ and $\text{reverse}(s)$!

5. Longest Palindromic Substring Medium · Substring Palindrome / Expand Around Center

State: isPal[i][j] or center expansion $(L, R)$ Time: $O(n^2)$ Space: $O(n^2)$ table or $O(1)$ center expansion

Recurrence & Intuition: Using the 2D table, $s[i..j]$ is a palindrome iff $s[i] == s[j]$ and either $j - i \le 2$ (length 1, 2, or 3) or `isPal[i+1][j-1]` is true. Alternatively, because every palindrome shrinks along a single diagonal of constant $i + j$, we can traverse each of the $2n - 1$ diagonals outward from its center ($n$ odd-length centers $(c, c)$ and $n-1$ even-length centers $(c, c+1)$) in $O(1)$ extra space. Below we show both the canonical DP table recurrence and the $O(1)$-space diagonal expansion. 

class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        int bestStart = 0, maxLen = 1;

        // Expand around center is equivalent to walking each diagonal of isPal[i][j]
        auto expand = [&](int l, int r) {
            while (l >= 0 && r < n && s[l] == s[r]) {
                if (r - l + 1 > maxLen) {
                    maxLen = r - l + 1;
                    bestStart = l;
                }
                --l;
                ++r;
            }
        };

        for (int i = 0; i < n; ++i) {
            expand(i, i);       // odd-length palindromes centered at i
            expand(i, i + 1);   // even-length palindromes centered between i and i+1
        }
        return s.substr(bestStart, maxLen);
    }
};

647. Palindromic Substrings Medium · Count All True States

State: isPal[i][j] = whether $s[i..j]$ is a palindrome Time: $O(n^2)$ Space: $O(n^2)$ (or $O(1)$ via center expansion)

Recurrence & Intuition: Identical recurrence to LC 5, except our aggregation is $\sum_{0 \le i \le j < n} [isPal[i][j]]$ instead of $\arg\max_{(i,j)} (j - i + 1)$. Here we write out the explicit bottom-up 2D table iterating $i$ from $n-1$ down to $0$ so that `isPal[i+1][j-1]` is always ready when needed. 

class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size();
        vector<vector<bool>> isPal(n, vector<bool>(n, false));
        int count = 0;

        for (int i = n - 1; i >= 0; --i) {
            for (int j = i; j < n; ++j) {
                if (s[i] == s[j] && (j - i <= 2 || isPal[i + 1][j - 1])) {
                    isPal[i][j] = true;
                    ++count;
                }
            }
        }
        return count;
    }
};

516. Longest Palindromic Subsequence Medium · Subsequence Interval DP

State: dp[i][j] = LPS length in $s[i..j]$ Time: $O(n^2)$ Space: $O(n)$ rolling 1D array

Recurrence & Intuition: Base cases are $dp[i][i] = 1$ for all $i$. When $i$ moves downward from $n-1$ to $0$ and $j$ moves upward from $i+1$ to $n-1$: if $s[i] == s[j]$, both characters extend the best inner palindrome $dp[i+1][j-1]$ by $2$. Otherwise, we take $\max(dp[i+1][j], dp[i][j-1])$. We can compress space to a single 1D row by tracking `prevDiag = dp[i+1][j-1]`. 

class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        vector<int> dp(n, 0);

        for (int i = n - 1; i >= 0; --i) {
            dp[i] = 1; // base case: dp[i][i] = 1
            int prevDiag = 0; // holds dp[i+1][j-1]
            for (int j = i + 1; j < n; ++j) {
                int temp = dp[j]; // save old dp[i+1][j] before overwriting
                if (s[i] == s[j]) {
                    dp[j] = prevDiag + 2;
                } else {
                    dp[j] = max(dp[j], dp[j - 1]);
                }
                prevDiag = temp;
            }
        }
        return dp[n - 1];
    }
};

132. Palindrome Partitioning II Hard · Two-Stage DP (Palindrome Table + Prefix Cut DP)

State: isPal[j][i] + cuts[i] = min cuts for $s[0..i]$ Time: $O(n^2)$ Space: $O(n^2)$

Recurrence & Intuition: We want the minimum number of cuts to partition $s[0..n-1]$ into palindromic substrings. A naive Interval DP (`dp[i][j] = min over k of dp[i][k] + dp[k+1][j] + 1`) takes $O(n^3)$ and TLEs for $n = 2000$. Instead, we combine Pattern 11 and Pattern 12 into a two-stage $O(n^2)$ DP:

  1. Stage 1 (Pattern 11): Maintain `isPal[j][i]` = true iff $s[j..i]$ is a palindrome.
  2. Stage 2 (Prefix Cut DP): Define `cuts[i]` = minimum cuts for prefix $s[0..i]$. If $s[0..i]$ is itself a palindrome (`isPal[0][i]`), `cuts[i] = 0`. Otherwise, for every $1 \le j \le i$ where `isPal[j][i]` is true, we can place the last cut immediately before $j$, giving `cuts[i] = min(cuts[i], cuts[j - 1] + 1)`.
class Solution {
public:
    int minCut(string s) {
        int n = s.size();
        vector<vector<bool>> isPal(n, vector<bool>(n, false));
        vector<int> cuts(n, 0);

        for (int i = 0; i < n; ++i) {
            int best = i; // worst case: cut after every single character
            for (int j = 0; j <= i; ++j) {
                if (s[j] == s[i] && (i - j <= 2 || isPal[j + 1][i - 1])) {
                    isPal[j][i] = true;
                    best = (j == 0) ? 0 : min(best, cuts[j - 1] + 1);
                }
            }
            cuts[i] = best;
        }
        return cuts[n - 1];
    }
};

2. Pattern 12: Word Segmentation DP

Word Segmentation DP asks whether (or in how many ways) a prefix $s[0..i)$ can be tiled by dictionary words. To compute the answer at prefix length $i$, we scan all possible split points $0 \le j < i$ where the last piece $s[j..i)$ is a valid dictionary word: 

// Core Recurrence Shape:
dp[i] = any_{0 <= j < i} ( dp[j] && isValidWord(s[j..i-1]) );

Notice that the second stage of Palindrome Partitioning II (LC 132) above uses this exact same prefix-split shape, replacing isValidWord(s[j..i-1]) with isPal[j][i] and replacing boolean OR with $\min(\text{cuts}[j-1] + 1)$!

139. Word Break Medium · Prefix Feasibility DP

State: dp[i] = whether prefix $s[0..i)$ can be segmented Time: $O(n \cdot L^2)$ where $L = \max |w|$ Space: $O(n + \sum |w|)$

Recurrence & Intuition: Set `dp[0] = true` (empty prefix is valid). For each prefix end $i = 1 \dots n$, we only need to check split points $j$ such that $i - j \le \text{maxWordLen}$. If `dp[j]` is true and $s[j..i)$ is in our hash set, we set `dp[i] = true` and break early. 

class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> dict(wordDict.begin(), wordDict.end());
        int maxLen = 0;
        for (const string& w : wordDict) {
            maxLen = max(maxLen, (int)w.size());
        }

        int n = s.size();
        vector<bool> dp(n + 1, false);
        dp[0] = true;

        for (int i = 1; i <= n; ++i) {
            for (int len = 1; len <= min(i, maxLen); ++len) {
                int j = i - len;
                if (dp[j] && dict.count(s.substr(j, len))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
};

140. Word Break II Hard · Memoized DAG Path Reconstruction

State: memo[start] = list of all valid sentences for $s[\text{start}..n-1]$ Time: $O(n^2 + 2^n)$ worst-case output size Space: $O(n \cdot 2^n)$

Recurrence & Intuition: Instead of returning a boolean, each state $i$ represents the set of all valid space-separated sentences for suffix $s[i..n-1]$. For every end position $j > i$ where $w = s[i..j-1]$ is in the dictionary, we recursively gather all sentences in `dfs(j)` and prepend $w$. Memoizing by start index $i$ prevents re-solving shared suffixes. 

class Solution {
public:
    vector<string> wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> dict(wordDict.begin(), wordDict.end());
        unordered_map<int, vector<string>> memo;
        int n = s.size();

        function<vector<string>(int)> dfs = [&](int start) -> vector<string> {
            if (memo.count(start)) return memo[start];
            vector<string> res;
            if (start == n) {
                res.push_back("");
                return res;
            }

            for (int end = start + 1; end <= n; ++end) {
                string word = s.substr(start, end - start);
                if (dict.count(word)) {
                    for (const string& tail : dfs(end)) {
                        res.push_back(tail.empty() ? word : word + " " + tail);
                    }
                }
            }
            return memo[start] = res;
        };

        return dfs(0);
    }
};

3. Pattern 17: Parentheses DP — Longest Valid Structure

In Parentheses DP, we define dp[i] as the length of the longest valid parentheses substring ending at index $i$ (similar in spirit to Kadane's "best subarray ending at $i$"). Obviously, if $s[i] == \text{'('}$, no valid parentheses substring can end at $i$, so dp[i] = 0.

When $s[i] == \text{')'}$, we inspect $s[i-1]$: 

// Core Recurrence Shape for s[i] == ')':
if (s[i - 1] == '(') {
    // Case 1: "...()" -> pair (i-1, i) + any valid block ending at i-2
    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
} else {
    // Case 2: "...))" -> jump over the valid block of length dp[i-1] ending at i-1
    int openIdx = i - dp[i - 1] - 1;
    if (openIdx >= 0 && s[openIdx] == '(') {
        dp[i] = dp[i - 1] + 2 + (openIdx >= 1 ? dp[openIdx - 1] : 0);
    }
}

Look at why Case 2 is so elegant: `dp[i-1]` tells us the exact length of the longest valid block ending at $i-1$. Therefore, the character immediately preceding that entire valid block sits at index $\text{openIdx} = i - dp[i-1] - 1$. If $s[\text{openIdx}] == \text{'('}$, then $s[\text{openIdx}]$ and $s[i]$ wrap the inner block `dp[i-1]` (+2 length), and we must also chain any adjacent valid block that ended at $\text{openIdx} - 1$, namely `dp[openIdx - 1]`!

32. Longest Valid Parentheses Hard · Jump-Over-Block DP

State: dp[i] = longest valid substring ending at $i$ Time: $O(n)$ Space: $O(n)$

Recurrence & Intuition: Directly implements Pattern 17. Remember the chaining term `dp[openIdx - 1]` in Case 2: on input `"()(())"`, at $i = 5$, `dp[4] = 2` (for `"()"` at indices $3..4$), so $\text{openIdx} = 5 - 2 - 1 = 2$. Since $s[2] == \text{'('}$, indices $2..5$ form `"(())"` of length $4$, and chaining `dp[1] = 2` (for `"()"` at indices $0..1$) gives the full length $4 + 2 = 6$. 

class Solution {
public:
    int longestValidParentheses(string s) {
        int n = s.size();
        vector<int> dp(n, 0);
        int maxLen = 0;

        for (int i = 1; i < n; ++i) {
            if (s[i] == ')') {
                if (s[i - 1] == '(') {
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else {
                    int openIdx = i - dp[i - 1] - 1;
                    if (openIdx >= 0 && s[openIdx] == '(') {
                        dp[i] = dp[i - 1] + 2 + (openIdx >= 1 ? dp[openIdx - 1] : 0);
                    }
                }
                maxLen = max(maxLen, dp[i]);
            }
        }
        return maxLen;
    }
};
