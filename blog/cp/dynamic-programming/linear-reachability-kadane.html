    Linear DP, Reachability & Jump DP, and Kadane's Algorithm

    October 2026 · 25 min read · Patterns 1–3 (10 Problems)

    The first three recurrence families operate on a 1D sequence where the optimal answer at position $i$ is built from preceding indices. Mastering the distinction between fixed-window lookback (Pattern 1), variable-range jump relaxation (Pattern 2), and extend-or-restart contiguous subarrays (Pattern 3) builds the foundation for every higher-dimensional DP.

    Pattern 1: Linear DP — Fibonacci, Take or Skip

    How to Recognize It

    The answer at index $i$ depends on a small, fixed number of immediately preceding states (typically $i-1$ and $i-2$), or you face a binary decision at each element: take the current element (which forbids adjacent elements) or skip it.

    Core Templates

    For additive step-counting recurrences:

    $$\text{dp}[i] = \text{dp}[i - 1] + \text{dp}[i - 2]$$

    For take-or-skip optimization problems:

    $$\text{dp}[i] = \max\big(\text{dp}[i - 1],\;\text{nums}[i] + \text{dp}[i - 2]\big)$$

    Depending on the problem objective, the aggregation operator changes between $+$ (counting ways), $\min$ (minimum cost), $\max$ (maximum value), or $\lor$ (feasibility).

    ▶ Step-Through: Take-or-Skip Linear Recurrence (House Robber)

    Houses nums = [2, 7, 9, 3, 1]. At each index $i$, compare skipping house $i$ (keep dp[i-1]) against robbing house $i$ (nums[i] + dp[i-2]).

    1.1 70. Climbing Stairs

    State: $\text{dp}[i]$ = number of distinct ways to reach step $i$.

    Transition: The last move into step $i$ is either a $1$-step from $i-1$ or a $2$-step from $i-2$, so $\text{dp}[i] = \text{dp}[i-1] + \text{dp}[i-2]$ with $\text{dp}[0]=1, \text{dp}[1]=1$. Because only the last two states are read, two scalars suffice.

    class Solution {
public:
    int climbStairs(int n) {
        int prev2 = 1, prev1 = 1; // dp[0], dp[1]
        for (int i = 2; i <= n; ++i) {
            int cur = prev1 + prev2;
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}; // Time: O(n), Space: O(1)

    1.2 746. Min Cost Climbing Stairs

    State: $\text{dp}[i]$ = minimum cost to reach step $i$ (where the top floor is index $n$).

    Transition: $\text{dp}[i] = \min(\text{dp}[i-1] + \text{cost}[i-1],\; \text{dp}[i-2] + \text{cost}[i-2])$ with base cases $\text{dp}[0] = 0, \text{dp}[1] = 0$ since we can start at step $0$ or step $1$ for free.

    class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int prev2 = 0, prev1 = 0;
        for (int i = 2; i <= (int)cost.size(); ++i) {
            int cur = min(prev1 + cost[i - 1], prev2 + cost[i - 2]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}; // Time: O(n), Space: O(1)

    1.3 198. House Robber

    State: $\text{dp}[i]$ = maximum money robbed from prefix $\text{nums}[0..i]$.

    Transition: Skip house $i$ ($\text{dp}[i-1]$) or rob house $i$ ($\text{nums}[i] + \text{dp}[i-2]$):

    class Solution {
public:
    int rob(vector<int>& nums) {
        int prev2 = 0, prev1 = 0;
        for (int x : nums) {
            int cur = max(prev1, prev2 + x);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}; // Time: O(n), Space: O(1)

    1.4 91. Decode Ways

    State: $\text{dp}[i]$ = number of ways to decode the prefix of length $i$ ($s[0..i-1]$).

    Transition: Conditional Fibonacci: a 1-digit decode is valid if $s[i-1] \neq \text{'0'}$ (adds $\text{dp}[i-1]$); a 2-digit decode is valid if $10 \le \text{val}(s[i-2..i-1]) \le 26$ (adds $\text{dp}[i-2]$).

    class Solution {
public:
    int numDecodings(string s) {
        if (s.empty() || s[0] == '0') return 0;
        int prev2 = 1, prev1 = 1; // dp[0] = 1, dp[1] = 1
        for (int i = 2; i <= (int)s.size(); ++i) {
            int cur = 0;
            if (s[i - 1] != '0') cur += prev1;
            int twoDigit = (s[i - 2] - '0') * 10 + (s[i - 1] - '0');
            if (twoDigit >= 10 && twoDigit <= 26) cur += prev2;
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}; // Time: O(n), Space: O(1)

    1.5 213. House Robber II

    Circular Constraint Trick: Houses $0$ and $n-1$ are adjacent on a circle, so they cannot both be robbed. This decomposes the circular problem into the maximum of two linear House Robber passes: $\text{nums}[0..n-2]$ and $\text{nums}[1..n-1]$.

    class Solution {
    int robRange(const vector<int>& nums, int l, int r) {
        int prev2 = 0, prev1 = 0;
        for (int i = l; i <= r; ++i) {
            int cur = max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        return max(robRange(nums, 0, n - 2), robRange(nums, 1, n - 1));
    }
}; // Time: O(n), Space: O(1)

    1.6 337. House Robber III

    Tree Adaptation: When the underlying structure changes from an array to a binary tree, each node $u$ returns a pair {skip_u, take_u} from post-order DFS:

    • $\text{take}_u = u.\text{val} + \text{skip}_{\text{left}} + \text{skip}_{\text{right}}$
    • $\text{skip}_u = \max(\text{skip}_{\text{left}}, \text{take}_{\text{left}}) + \max(\text{skip}_{\text{right}}, \text{take}_{\text{right}})$
    class Solution {
    pair<int, int> dfs(TreeNode* root) {
        if (!root) return {0, 0}; // {skip, take}
        auto [skipL, takeL] = dfs(root->left);
        auto [skipR, takeR] = dfs(root->right);
        int skip = max(skipL, takeL) + max(skipR, takeR);
        int take = root->val + skipL + skipR;
        return {skip, take};
    }
public:
    int rob(TreeNode* root) {
        auto [skip, take] = dfs(root);
        return max(skip, take);
    }
}; // Time: O(n), Space: O(h) recursion stack
    Key observation (Pattern 1): House Robber II adds a circular boundary condition (solved by splitting into two linear ranges), while House Robber III moves the same take-or-skip decision onto a binary tree (solved by returning a two-state pair per subtree). See also our dedicated Tree DP guide.

    Pattern 2: Reachability and Minimum-Jump DP

    How to Recognize It

    You are given an array where $\text{nums}[j]$ specifies the maximum jump length from index $j$, and you must determine whether the last index is reachable or compute the minimum jumps required.

    DP Formulation vs. Greedy Frontier

    In pure DP terms:

    $$\text{canReach}[i] = \bigvee_{\substack{0 \le j < i \\ j + \text{nums}[j] \ge i}} \text{canReach}[j], \qquad \text{dp}[i] = \min_{\substack{0 \le j < i \\ j + \text{nums}[j] \ge i}} (\text{dp}[j] + 1)$$

    Evaluating these transitions naively takes $O(n^2)$. However, because reachable intervals from prefix indices are contiguous and monotonically non-decreasing, tracking the furthest reachable frontier reduces both problems to $O(n)$ time and $O(1)$ space.

    2.1 55. Jump Game

    DP-to-Greedy Reduction: Instead of storing $\text{canReach}[0..n-1]$, maintain $\text{farthest} = \max_{j \le i} (j + \text{nums}[j])$. Index $i$ is reachable iff $i \le \text{farthest}$.

    class Solution {
public:
    bool canJump(vector<int>& nums) {
        int farthest = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (i > farthest) return false;
            farthest = max(farthest, i + nums[i]);
        }
        return true;
    }
}; // Time: O(n), Space: O(1) (reduces O(n^2) DP)

    2.2 45. Jump Game II

    Level-by-Level BFS / DP Intervals: Partition indices into level intervals $[l, r]$ where $\text{dp}[i] = k$. Advancing `curEnd` to `farthest` whenever $i$ reaches `curEnd` computes the exact DP level in one pass.

    class Solution {
public:
    int jump(vector<int>& nums) {
        int jumps = 0, curEnd = 0, farthest = 0;
        for (int i = 0; i < (int)nums.size() - 1; ++i) {
            farthest = max(farthest, i + nums[i]);
            if (i == curEnd) {
                ++jumps;
                curEnd = farthest;
            }
        }
        return jumps;
    }
}; // Time: O(n), Space: O(1)

    Pattern 3: Kadane's Algorithm — Best Subarray Ending Here

    How to Recognize It

    The problem asks for the optimal contiguous subarray, and at each index $i$ you decide whether to extend the best subarray ending at $i-1$ or start a fresh subarray at $[i]$.

    Core Template

    $$\text{bestEndingHere}[i] = \max\big(\text{nums}[i],\; \text{bestEndingHere}[i - 1] + \text{nums}[i]\big)$$

    The global answer is $\max_{0 \le i < n} \text{bestEndingHere}[i]$. (For more variations, see our Kadane's Algorithm series.)

    3.1 53. Maximum Subarray

    State: `cur` = maximum subarray sum ending at index $i$. If `cur < 0`, extending it only hurts future sums, so we reset to `nums[i]`.

    class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int cur = nums[0], ans = nums[0];
        for (size_t i = 1; i < nums.size(); ++i) {
            cur = max(nums[i], cur + nums[i]);
            ans = max(ans, cur);
        }
        return ans;
    }
}; // Time: O(n), Space: O(1)

    3.2 152. Maximum Product Subarray

    Why Two States Are Required: Multiplying a large negative product by a negative `nums[i]` turns it into a large positive product. Thus, at each index $i$, we must track both `maxProd` and `minProd` ending at $i$:

    $$\text{maxProd}[i] = \max\big(\text{nums}[i],\; \text{maxProd}[i-1]\cdot\text{nums}[i],\; \text{minProd}[i-1]\cdot\text{nums}[i]\big)$$ $$\text{minProd}[i] = \min\big(\text{nums}[i],\; \text{maxProd}[i-1]\cdot\text{nums}[i],\; \text{minProd}[i-1]\cdot\text{nums}[i]\big)$$ 
    class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int maxP = nums[0], minP = nums[0], ans = nums[0];
        for (size_t i = 1; i < nums.size(); ++i) {
            if (nums[i] < 0) swap(maxP, minP);
            maxP = max(nums[i], maxP * nums[i]);
            minP = min(nums[i], minP * nums[i]);
            ans = max(ans, maxP);
        }
        return ans;
    }
}; // Time: O(n), Space: O(1)
