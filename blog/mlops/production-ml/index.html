    Production ML Case Studies: Reading Guide

    September 2026 · 3 min read

    Build reproducible scoring pipelines, validate explanations, and migrate the surrounding platform safely.

    Reading order

    01
    Build a Reproducible Distributed ML Scoring Pipeline

    Version data and transforms, construct deterministic training samples, validate artifacts, and publish distributed predictions without partial or duplicate results.

    02
    Explainable Scoring at Scale: From SHAP Values to Useful Evidence

    Reconstruct a score from its baseline and contributions, preserve output units, validate background choices, and design an efficient distributed explanation pipeline.

    03
    Migrate an ML Platform Without Losing the Experiment

    Inventory dependencies, preserve datasets and artifacts, replay pipelines, and validate a staged cutover with a tested rollback path.

    How to use these notes

    Start with the worked example in each chapter. Calculate the answer before changing the interactive figure, then use the self-check to test the distinction the chapter teaches. The numerical examples are deliberately small enough to audit by hand; they are teaching examples, not production benchmarks.

    Follow the prerequisites when a concept is unfamiliar. Related notes link to existing foundations so each chapter can concentrate on its own question.
