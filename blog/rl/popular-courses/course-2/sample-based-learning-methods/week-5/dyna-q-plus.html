    Dyna-Q+: Planning with Inaccurate Models

    August 2026 · 19 min read · Sample-based Learning Methods, Week 5

    Planning amplifies knowledge and mistakes. A correct model turns one real transition into many useful updates. A stale model can drive values repeatedly in the wrong direction.

    How a learned model becomes wrong

    • Missing experience: untried actions have no stored transition.
    • Limited samples: stochastic outcomes are estimated from too little data.
    • Changing environment: an old transition no longer matches current dynamics.

    Dyna-Q plans only from previously observed pairs. That is efficient in a stationary world but can prevent the agent from discovering that a once-bad or blocked action has become useful.

    Staleness grows with time since last visit

    Let $\tau(s,a)$ count how many real time steps have passed since $(s,a)$ was tried. A large $\tau$ does not prove the model is wrong, but it marks where the model has gone longest without verification.

    The Dyna-Q+ planning bonus

    Dyna-Q+ adds optimism only to simulated rewards:

    $$\boxed{R_{\text{plan}}^+=R_{\text{model}}+\kappa\sqrt{\tau(s,a)}}.$$
    TermMeaning
    $R_{\text{model}}$The reward predicted by the current model.
    $\tau(s,a)$Time since the pair was last executed in the real environment.
    $\kappa$Small constant controlling the strength of exploration pressure.
    $\sqrt{\tau}$Bonus grows with neglect but sublinearly.

    Representing untried actions

    For a state that has been visited, Dyna-Q+ places every action in the model. An untried action can be initialized as a self-loop with reward zero. Its growing bonus ensures it is not ignored forever.

    Without this step, planning cannot select an action absent from the model, no matter how large its conceptual exploration bonus should be.

    The shortcut-maze failure

    Imagine a wall initially blocks a short route. Dyna-Q learns a longer path and repeatedly plans from it. Later the wall opens. The stored model still says the shortcut is blocked.

    Why the bonus accelerates adaptation

    Dyna-Q exploits the best route according to its current model. If the environment improves elsewhere, nothing attracts it there. Dyna-Q+ periodically probes stale alternatives, updates the model when reality differs, and then planning rapidly propagates the newly discovered shortcut.

    The exploration cost

    In a stationary environment, Dyna-Q+ may waste real actions checking alternatives that have not changed. $\kappa$ sets the trade-off: larger values adapt faster but explore more aggressively.

    Optimism is applied in planning, not by falsifying observed rewards. Real transitions still use real $R$. The bonus changes which actions become attractive enough to verify.
