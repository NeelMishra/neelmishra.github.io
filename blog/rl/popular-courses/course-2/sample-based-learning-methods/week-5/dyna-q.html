    Dyna-Q: Learning and Planning Together

    August 2026 · 20 min read · Sample-based Learning Methods, Week 5

    One real transition, many updates. Dyna-Q learns action values directly from the world, stores the transition in a model, then replays model-generated transitions as planning experience.

    The Dyna architecture

    Three jobs after each real step

    1. Direct RL: update $Q(S,A)$ from the real $(R,S')$.
    2. Model learning: store or update what the model predicts for $(S,A)$.
    3. Planning: sample previously observed pairs, query the model, and perform additional Q-learning updates.

    All value updates use

    $$\begin{aligned}Q(S,A)\leftarrow{}&Q(S,A)+\alpha\big[R\\&+\gamma\max_aQ(S',a)-Q(S,A)\big].\end{aligned}$$

    Tabular Dyna-Q with a deterministic model

    The compact pseudocode below assumes each state-action pair has one reward and next state, so the model can store a single tuple. In a stochastic environment, Model(S,A) must instead maintain an empirical outcome distribution and sample from it during planning.

    initialise Q(s,a) and Model(s,a)

repeat for each real environment step:
    choose A from Q in current state S
    take A; observe R and S_next

    # direct RL
    Q(S,A) += alpha * (R + gamma * max_a Q(S_next,a) - Q(S,A))

    # model learning
    Model(S,A) = (R,S_next)

    # planning
    repeat n times:
        sample a previously observed pair (S_plan,A_plan)
        (R_plan,S_plan_next) = Model(S_plan,A_plan)
        Q(S_plan,A_plan) += alpha * (
            R_plan + gamma * max_a Q(S_plan_next,a)
            - Q(S_plan,A_plan))

    S = S_next

    Search control

    The simple algorithm samples previously observed pairs uniformly. That can waste planning updates on already-correct regions. Better search control prioritises pairs whose values or successors changed, sending information backward quickly.

    StrategyEffect
    Uniform randomSimple and unbiased over stored pairs, but may waste computation.
    Recent experienceConcentrates on the region currently being explored.
    Prioritised sweepingUpdates predecessors of states with large Bellman errors.

    Why Dyna learns faster

    Without planning, reward information moves backward roughly one real transition at a time. With planning, the model can replay predecessor transitions repeatedly between real actions, so the same information travels much farther through $Q$.

    The gain depends on model accuracy. Perfectly replaying a wrong transition only reinforces the wrong answer.
