    Q-Learning: Off-Policy TD Control

    August 2026 · 27 min read · Sample-based Learning Methods, Week 4

    One substitution changes the algorithm. Sarsa bootstraps from the action actually selected next. Q-learning bootstraps from the best next action, whether or not behaviour selected it.

    Start from Bellman optimality

    $$\begin{aligned}q_*(s,a)=\mathbb E\big[&R_{t+1}+\gamma\max_{a'}q_*(S_{t+1},a')\\&\mid S_t=s,A_t=a\big].\end{aligned}$$

    Replace the expectation over the next transition with one observed sample and replace $q_*$ by the current estimate $Q$:

    $$\boxed{\begin{aligned}Q(S_t,A_t)\leftarrow{}&Q(S_t,A_t)+\alpha\big[R_{t+1}\\&+\gamma\max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)\big]\end{aligned}}.$$

    Target policy versus behaviour policy

    RoleQ-learning choice
    Behaviour $b$Often $\varepsilon$-greedy so every useful state-action pair continues to be sampled.
    Target $\pi$Greedy: $\pi(s)\in\arg\max_a Q(s,a)$.

    The update learns about the greedy target while experience is generated by exploratory behaviour. That is the definition of off-policy learning.

    Why there is no importance-sampling ratio

    The short answer is that Q-learning samples only the environment transition. It does not sample the next action used by its target policy. The full argument has two parts.

    When would a ratio be needed?

    Suppose $A'\sim b(\cdot\mid s')$ is sampled from behaviour, but the target requires an average under another policy $\pi$. Assume $b(a'\mid s')>0$ whenever $\pi(a'\mid s')>0$; behaviour must be able to sample every action the target may choose. The uncorrected sample has the wrong expectation:

    $$\mathbb E_{A'\sim b}[Q(s',A')]=\sum_{a'}b(a'\mid s')Q(s',a').$$

    Multiplying by $\rho=\pi(A'\mid s')/b(A'\mid s')$ changes the weights to the target policy:

    $$\begin{aligned} \mathbb E_{A'\sim b}\!\left[\frac{\pi(A'\mid s')}{b(A'\mid s')}Q(s',A')\right] &=\sum_{a'}b(a'\mid s')\frac{\pi(a'\mid s')}{b(a'\mid s')}Q(s',a')\\ &=\sum_{a'}\pi(a'\mid s')Q(s',a'). \end{aligned}$$

    That is the situation importance sampling fixes: an action was randomly drawn with behaviour probabilities, but it must count with target-policy probabilities.

    Part 1: Q-learning never samples that next action

    Its one-step target is

    $$Y_t=R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a').$$

    After observing $S_{t+1}$, Q-learning reads every stored $Q(S_{t+1},a')$ and takes the maximum. There is no random $A_{t+1}\sim b(\cdot\mid S_{t+1})$ inside $Y_t$, so there is no behaviour probability to correct.

    Target constructionFuture value usedRatio?
    Sarsa following $b$Sample $A_{t+1}\sim b$, then use $Q(S_{t+1},A_{t+1})$No, because it deliberately evaluates $b$
    Off-policy sampled target for $\pi$Sample $A_{t+1}\sim b$, but try to evaluate $\pi$Yes: $\pi/b$ corrects the sampled action
    Q-learningCompute $\max_{a'}Q(S_{t+1},a')$ directlyNo next action was sampled

    Part 2: the sampled environment transition is still correct

    The current action $A_t$ did come from behaviour. Under $b$, the joint probability of selecting $a$ and then seeing $(r,s')$ is

    $$\Pr_b(A_t=a,R_{t+1}=r,S_{t+1}=s'\mid S_t=s) =b(a\mid s)\,p(s',r\mid s,a).$$

    Q-learning updates the table entry for the action that was actually selected, so it conditions on $A_t=a$. Assuming $b(a\mid s)>0$,

    $$\begin{aligned} \Pr_b(r,s'\mid s,a) &=\frac{\Pr_b(a,r,s'\mid s)}{\Pr_b(a\mid s)}\\ &=\frac{b(a\mid s)p(s',r\mid s,a)}{b(a\mid s)}\\ &=p(s',r\mid s,a). \end{aligned}$$

    The behaviour probability cancels. Once $(S_t,A_t)=(s,a)$ is fixed, the reward and next state are generated by the environment dynamics, not by the policy that happened to choose $a$.

    The Bellman-operator proof

    Treat the current table $Q$ as fixed during one update and define the Bellman optimality backup

    $$({\cal T}_*Q)(s,a) =\sum_{s',r}p(s',r\mid s,a) \left[r+\gamma\max_{a'}Q(s',a')\right].$$

    Take the expectation of Q-learning's sampled target, conditioned on the state-action pair:

    $$\begin{aligned} \mathbb E_b[Y_t\mid S_t=s,A_t=a,Q] &=\sum_{s',r}\Pr_b(s',r\mid s,a) \left[r+\gamma\max_{a'}Q(s',a')\right]\\ &=\sum_{s',r}p(s',r\mid s,a) \left[r+\gamma\max_{a'}Q(s',a')\right]\\ &=({\cal T}_*Q)(s,a). \end{aligned}$$

    Therefore the expected update is

    $$\mathbb E_b[\Delta Q(s,a)\mid s,a,Q] =\alpha\left[({\cal T}_*Q)(s,a)-Q(s,a)\right].$$

    This is exactly a stochastic approximation to the Bellman optimality equation $Q={\cal T}_*Q$. The behaviour policy changes how often each $(s,a)$ entry is updated, but not the expected backup applied when that entry is updated.

    A small numerical example

    Suppose behaviour reaches $s'$ and chooses left with probability $0.8$ and right with probability $0.2$, while

    $$Q(s',\text{left})=2,\qquad Q(s',\text{right})=5.$$

    A sampled behaviour action has expected value $0.8(2)+0.2(5)=2.6$. If the greedy target always chooses right, the ratios for a behaviour-sampled action would be

    $$\rho(\text{left})=\frac{0}{0.8}=0,\qquad \rho(\text{right})=\frac{1}{0.2}=5.$$

    The corrected sample is therefore $0(2)=0$ when behaviour chooses left and $5(5)=25$ when it chooses right. Its expectation is correct,

    $$0.8(0)+0.2(25)=5,$$

    but individual targets are unnecessarily extreme. Q-learning instead reads the table and uses

    $$\max\{2,5\}=5$$

    on every such update. It obtains the greedy next value directly, with no wrong-policy action sample to reweight.

    What is still required? Behaviour must provide coverage: every state-action pair whose value matters must be visited often enough. In tabular Q-learning, exploration controls visitation frequency rather than inserting an importance ratio into the target. This clean argument does not by itself guarantee stability with function approximation.

    Monte Carlo is different because its return contains an entire sequence of future actions sampled from behaviour. Those action probabilities really do determine the return distribution, so off-policy Monte Carlo uses trajectory ratios. See Off-Policy Monte Carlo & Importance Sampling for that derivation.

    The algorithm

    initialise Q(s,a), with Q(terminal,.) = 0

for each episode:
    initialise S
    until S is terminal:
        choose A using exploratory behaviour, e.g. epsilon-greedy
        take A; observe R and S_next

        target = R + gamma * max_a Q(S_next,a)
        Q(S,A) += alpha * (target - Q(S,A))

        S = S_next

return a greedy policy derived from Q

    Q-learning is sample-based value iteration

    Value iteration repeatedly applies a max backup using a model. Q-learning applies the same optimality logic using sampled environment transitions:

    $$\begin{aligned}\text{value iteration}\\+\ \text{sampled transitions}\\\Longrightarrow\ \text{Q-learning}.\end{aligned}$$

    Sarsa instead resembles policy iteration: evaluate the current exploratory policy while gradually improving it.

    Cliff walking: optimal versus safe while exploring

    Every normal move costs $-1$; stepping into the cliff costs $-100$ and returns to start. The shortest optimal path hugs the cliff. An $\varepsilon$-greedy behaviour can occasionally step off it.

    What convergence needs

    • Every relevant state-action pair must continue to be visited.
    • Step sizes must decrease appropriately in the tabular convergence theorem.
    • The MDP must be finite and rewards bounded.

    In practice with constant $\alpha$ and function approximation, these clean guarantees no longer transfer automatically.
