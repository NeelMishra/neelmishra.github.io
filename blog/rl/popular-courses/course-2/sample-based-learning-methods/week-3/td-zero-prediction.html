    TD(0) Prediction from First Principles

    August 2026 · 21 min read · Sample-based Learning Methods, Week 3

    The problem TD solves. Monte Carlo prediction learns from experience without a model, but it must wait until the episode ends. Temporal-difference learning keeps the model-free advantage and adds online learning: one transition is enough to update.

    The prediction goal has not changed

    For a fixed policy $\pi$, the objective remains the state-value function

    $$v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s].$$

    Monte Carlo uses the realised complete return $G_t$ as a target:

    $$V(S_t)\leftarrow V(S_t)+\alpha\big[G_t-V(S_t)\big].$$

    This is correct but delayed. At time $t+1$, only one new transition has been observed, while the remainder of $G_t$ is still unknown.

    Split the unknown return into known and unknown pieces

    The return always satisfies

    $$G_t=R_{t+1}+\gamma G_{t+1}.$$

    Immediately after the transition, $R_{t+1}$ and $S_{t+1}$ are known. The only unavailable quantity is the future return $G_{t+1}$. TD replaces that unknown future with the current estimate of its expectation:

    $$G_{t+1}\approx V(S_{t+1}).$$

    The resulting one-step target is

    $$\boxed{\text{TD target}=R_{t+1}+\gamma V(S_{t+1})}.$$

    The TD error

    The target says what $V(S_t)$ should move toward. Subtract the current prediction to obtain the temporal-difference error:

    $$\boxed{\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)}.$$

    The update applies a fraction $\alpha$ of that error:

    $$\boxed{V(S_t)\leftarrow V(S_t)+\alpha\delta_t}.$$
    TermMeaning
    $V(S_t)$The current prediction before seeing the transition.
    $R_{t+1}$The reward that just arrived; it is observed, not estimated.
    $\gamma V(S_{t+1})$The estimated discounted value of everything after the new state.
    $\delta_t$The surprise: target minus current prediction.
    $\alpha$The step size controlling how much of the surprise is accepted now.

    Explore one TD update

    Why this is bootstrapping

    The target contains $V(S_{t+1})$, which is itself an estimate. TD therefore improves one estimate using another estimate. This is bootstrapping.

    Observed part

    $R_{t+1}$ came from the environment and is known exactly for this transition.

    Estimated part

    $V(S_{t+1})$ predicts rewards that have not happened yet.

    Bootstrapping introduces temporary bias when the successor value is inaccurate, but it allows information to move backward after every step instead of after every episode.

    Tabular TD(0)

    input: policy pi, step size alpha, discount gamma
initialise V(s) arbitrarily, with V(terminal) = 0

for each episode:
    initialise state S
    until S is terminal:
        choose A from pi(. | S)
        take A; observe reward R and next state S_next

        target = R + gamma * V(S_next)
        delta = target - V(S)
        V(S) = V(S) + alpha * delta

        S = S_next

return V

    TD(0) means the target uses zero additional sampled rewards beyond the immediate one before bootstrapping. The “0” becomes clearer when $n$-step methods are introduced later.

    Terminal transitions

    Terminal value is fixed at zero. If $S_{t+1}$ is terminal, the target becomes only the final reward:

    $$R_{t+1}+\gamma V(S_{t+1})=R_{t+1}.$$

    This is how real rewards enter the value table. Earlier states learn from those changed successor values on later transitions and later episodes.
