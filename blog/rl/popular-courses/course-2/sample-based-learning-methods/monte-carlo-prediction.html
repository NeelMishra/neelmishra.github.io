    Monte Carlo Prediction: Values from Complete Episodes

    August 2026 · 20 min read · Coursera: Sample-based Learning Methods (University of Alberta), Week 2

    Course 2 begins here. Week 1 is orientation, so these notes start with the first technical week. Course 1 ended with dynamic programming: exact Bellman backups using a known model. Monte Carlo methods remove that model and learn values directly from complete sampled episodes.

    What “Monte Carlo” means in reinforcement learning

    Monte Carlo is a broad name for estimating a quantity by repeated random sampling. In reinforcement learning, the quantity is usually a value function and the samples are trajectories:

    $$ S_0,A_0,R_1,S_1,A_1,R_2,\ldots,S_{T-1},A_{T-1},R_T. $$

    Instead of asking for the transition probabilities $p(s',r\mid s,a)$, let the environment produce transitions. Instead of summing every possible future in a Bellman expectation, observe one complete future, compute its return, and average many such observations.

    A value function is already an expectation

    For a fixed policy $\pi$, the state value was defined in Course 1 as

    $$ v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]. $$

    That definition almost writes the algorithm for us. Visit $s$ many times while following $\pi$, record the return that follows each visit, and take their sample mean:

    $$ V_n(s)=\frac{1}{n}\sum_{i=1}^{n}G^{(i)}(s) \xrightarrow[n\to\infty]{} v_\pi(s). $$

    The convergence is the law of large numbers. No Bellman equation must be solved and no successor values are required. The price is that $G_t$ is not known until all later rewards in the episode have arrived, so vanilla MC is naturally an episodic method.

    MC does not bootstrap. Its target is the realised return $G_t$, not $R_{t+1}+\gamma V(S_{t+1})$. The target is complete but noisy; a later course topic, temporal-difference learning, will bootstrap from an incomplete trajectory instead.

    Compute every return with one backward pass

    After an episode ends, all returns can be computed in reverse with

    $$ G_T=0,\qquad G_t=R_{t+1}+\gamma G_{t+1}. $$

    The notes use rewards $(3,4,7,1,2)$. Move the discount slider and watch one backward pass generate all five targets. At $\gamma=0.5$, the returns are $(7,8,8,2,2)$.

    First-visit versus every-visit Monte Carlo

    A state can appear more than once in one episode. Suppose the trajectory visits $A$, then $B$, then $A$ again:

    A
    $t=0$
    first visit
    B
    $t=1$
    A
    $t=2$
    revisit
    C
    $t=3$
    T

    First-visit MC

    For each state, use only the return following its first occurrence in the episode. State $A$ contributes $G_0$ but not $G_2$.

    Each episode contributes at most one sample per state, which makes the textbook convergence argument especially clean.

    Every-visit MC

    Use the return after every occurrence. State $A$ contributes both $G_0$ and $G_2$.

    The samples within an episode are correlated, but the estimator is still consistent under the usual episodic assumptions.

    Your notes implement the every-visit version: the reverse loop updates $V(S_t)$ at every time step. Both methods converge to $v_\pi$; they simply define the sample set differently.

    Every-visit MC prediction

    input: policy pi
initialise V(s) arbitrarily
initialise N(s) = 0

for each episode:
    generate S0, A0, R1, ..., S(T-1), A(T-1), RT following pi
    G = 0
    for t = T-1, T-2, ..., 0:
        G = gamma * G + R(t+1)
        N(S(t)) += 1
        V(S(t)) += (G - V(S(t))) / N(S(t))

return V

    The algorithm does not need to store a list called Returns(s). Maintain a count and update the mean online.

    Why the incremental update is exactly the sample mean

    Let $\bar G_n$ be the mean after $n$ returns. Add a new sample $G_n$:

    $$ \begin{aligned} \bar G_n &=\frac{1}{n}\left(\sum_{i=1}^{n-1}G_i+G_n\right) \\ &=\frac{n-1}{n}\bar G_{n-1}+\frac{1}{n}G_n \\ &=\bar G_{n-1}+\frac{1}{n}\big(G_n-\bar G_{n-1}\big). \end{aligned} $$

    So the familiar update

    $$ \boxed{\,V(s)\leftarrow V(s)+\frac{1}{N(s)}\big[G-V(s)\big]\,} $$

    is not an approximation to the mean; it is the mean, written recursively. The bracket is a sample error and $1/N(s)$ is the exact averaging step size.

    Worked example: blackjack prediction

    Blackjack is a compact episodic MDP with a large enough state space to make model construction annoying and sampling attractive:

    • Episode: one complete game.
    • Actions: hit or stick.
    • Reward: $-1$ for a loss, $0$ for a draw, $+1$ for a win.
    • State: usable ace? (2 choices), player sum $12$–$21$ (10), dealer showing ace–10 (10): $2\cdot10\cdot10=200$ states.
    • Policy to evaluate: hit below 20; stick on 20 or 21.
    • Card model: cards are sampled with replacement, so draws have a stationary distribution.

    Consider an episode with dealer card 10. The player first has 13 with no usable ace, hits and draws 7, reaches 20, sticks, and eventually wins. With $\gamma=1$, the only non-zero reward is the terminal $+1$, so every preceding return is $+1$. The episode contributes one $+1$ sample to both visited states:

    $$ (\text{no ace},13,10)\xrightarrow{\text{hit}} (\text{no ace},20,10)\xrightarrow{\text{stick}}\text{win}, \qquad G_0=G_1=+1. $$

    After 10,000 games, rarely visited states still have jagged estimates. After 500,000, the value surface is much smoother. That is not a mysterious property of blackjack; it is the sample mean revealing itself as variance shrinks with more data.

    What changed from dynamic programming?

    PropertyDynamic programmingMonte Carlo prediction
    Environment knowledgeNeeds $p(s',r\mid s,a)$Needs sampled episodes
    TargetExpected $r+\gamma V(s')$Observed complete return $G_t$
    BootstrappingYesNo
    When an update is availableImmediately from the modelAfter episode termination
    Coupling across state estimatesSuccessor estimates enter the targetEach state averages its own sampled returns
    Per-sample update costMay sum many successorsDoes not grow with total MDP size

    The bargain MC makes

    • No model, but delayed learning. A 10,000-step episode yields no vanilla MC target until step 10,000.
    • Unbiased targets, but high variance. Complete returns include every random action and transition after the state.
    • Local computation, but visitation matters. A state that the policy almost never reaches receives almost no data.
    • Prediction is easy; control exposes exploration. To compare actions, the agent must actually try them. That is Part 2.
