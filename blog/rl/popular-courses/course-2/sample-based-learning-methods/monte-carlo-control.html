    Monte Carlo Control: Exploration, GPI & Epsilon-Soft Policies

    August 2026 · 22 min read · Coursera: Sample-based Learning Methods (University of Alberta), Week 2

    Prediction was the easy half. Part 1 estimated $v_\pi$ from complete returns while the policy stayed fixed. Control must compare actions and improve the policy. Without a model, that immediately creates a new requirement: an action cannot be valued unless it is actually tried.

    Why control needs action values

    A state value averages over the current policy:

    $$ v_\pi(s)=\sum_a\pi(a\mid s)\,q_\pi(s,a). $$

    If the model were known, we could recover each action value with a one-step lookahead. In sample-based learning the model is precisely what we do not have, so we estimate action values directly:

    $$ q_\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a] \approx \text{average return following visits to }(s,a). $$

    Once $Q(s,a)$ is available, policy improvement is model-free:

    $$ \pi_{\text{new}}(s)\in\arg\max_a Q(s,a). $$

    The exploration problem

    Imagine $\pi$ always chooses stick in a blackjack state. MC can estimate $q_\pi(s,\text{stick})$, but it will never observe a return for hit. Initialising the unseen action optimistically does not solve the information problem unless the policy is forced to try it.

    Maintaining exploration: every state–action pair that might be optimal must continue to receive samples. Otherwise a bad early guess can become self-confirming: the policy avoids an action because its estimate is low, and the estimate stays low because the action is avoided.

    Exploring starts

    The clean theoretical device is the exploring starts assumption: each episode begins from a randomly selected pair $(S_0,A_0)$, and every pair has non-zero probability of being chosen.

    $$ \Pr(S_0=s,A_0=a)>0\qquad\text{for every }(s,a). $$

    After the forced first action, the episode follows the current policy. Across infinitely many episodes, every pair gets sampled. This is mathematically convenient and often operationally absurd: we cannot randomly initialise a self-driving car in every physically possible state with every possible first action.

    Monte Carlo generalized policy iteration

    With action-value prediction and coverage, Course 1's generalized policy iteration returns almost unchanged:

    Generate episodessample under the current policy
    →
    Evaluate $Q$average complete returns
    →
    Improve $\pi$greedy or $\varepsilon$-greedy in $Q$

    Evaluation is no longer a DP sweep. It is Monte Carlo prediction over state–action pairs. Improvement still chooses actions with larger estimated value.

    Monte Carlo ES

    initialise Q(s,a) arbitrarily
initialise a deterministic policy pi(s) arbitrarily
initialise N(s,a) = 0

for each episode:
    choose (S0,A0) using exploring starts
    generate the rest of the episode following pi
    first_time = earliest index of each (s,a) pair in the episode
    G = 0

    for t = T-1, ..., 0:
        G = gamma * G + R(t+1)
        if first_time[(S(t),A(t))] == t:     # first-visit MC
            N(S(t),A(t)) += 1
            Q(S(t),A(t)) += (G - Q(S(t),A(t))) / N(S(t),A(t))
            pi(S(t)) = argmax_a Q(S(t),a)

return pi, Q

    The inner loop walks backward through one episode. At each first visit, it improves the action-value estimate and immediately greedifies the policy at that state. This is GPI at episode scale: evaluation and improvement continually chase each other.

    A blackjack episode updates both $Q$ and $\pi$

    Suppose an exploring start places the player at $(\text{no ace},13,8)$ and forces hit. The player draws 7, reaches 20, then the current policy chooses stick. The dealer busts, so the return is $+1$.

    $$ Q((\text{no ace},13,8),\text{hit})\leftarrow \text{mean including }+1, \qquad Q((\text{no ace},20,8),\text{stick})\leftarrow \text{mean including }+1. $$

    After those estimates move, the greedy action in either state may change. Repeated episodes eventually draw a hit/stick boundary across the blackjack state space.

    Replacing exploring starts with $\varepsilon$-soft policies

    A policy is $\varepsilon$-soft if every action receives at least a probability floor:

    $$ \pi(a\mid s)\ge \frac{\varepsilon}{|\mathcal A(s)|} \qquad\text{for every }s,a. $$

    This moves exploration from the episode's initial condition into every decision. A uniform random policy is $\varepsilon$-soft. An $\varepsilon$-greedy policy is a particularly important member of the class:

    $$ \pi(a\mid s)= \begin{cases} 1-\varepsilon+\dfrac{\varepsilon}{|\mathcal A(s)|}, & a=a^*,\\[6pt] \dfrac{\varepsilon}{|\mathcal A(s)|}, & a\ne a^*, \end{cases} \qquad a^*\in\arg\max_a Q(s,a). $$

    Equivalently: with probability $1-\varepsilon$, select a greedy action; with probability $\varepsilon$, sample uniformly from all actions. The uniform branch can select the greedy action too, which is why its total probability is $1-\varepsilon+\varepsilon/|\mathcal A|$.

    Not every $\varepsilon$-soft policy is $\varepsilon$-greedy

    A useful counterexample begins with the base distribution $p=(0.7,0.2,0.1)$ and mixes it with uniform exploration:

    $$ \pi_\varepsilon(a\mid s)=(1-\varepsilon)p(a\mid s)+\frac{\varepsilon}{|\mathcal A|}. $$

    At $\varepsilon=0.2$, the result is approximately $(0.6267,0.2267,0.1467)$. Every action is above the floor $0.0667$, so the policy is $\varepsilon$-soft, but the non-greedy actions are not equal, so it is not the pure $\varepsilon$-greedy construction.

    On-policy MC control with $\varepsilon$-greedy improvement

    choose epsilon > 0
initialise Q(s,a) arbitrarily
initialise pi as any epsilon-soft policy
initialise N(s,a) = 0

for each episode:
    generate an episode following pi
    first_time = earliest index of each (s,a) pair in the episode
    G = 0

    for t = T-1, ..., 0:
        G = gamma * G + R(t+1)
        if first_time[(S(t),A(t))] == t:
            N(S(t),A(t)) += 1
            Q(S(t),A(t)) += (G - Q(S(t),A(t))) / N(S(t),A(t))

            A* = argmax_a Q(S(t),a)
            for each action a:
                pi(a|S(t)) = epsilon / |A(S(t))|
            pi(A*|S(t)) += 1 - epsilon

return pi, Q

    This is on-policy control because the same $\pi$ both generates experience and is improved. Persistent exploration avoids the impossible exploring-start assumption, but fixed $\varepsilon>0$ has a consequence: the policy never becomes deterministic.

    What “optimal” means here. With a fixed $\varepsilon$, the algorithm seeks the best policy inside the constrained class of $\varepsilon$-soft policies. It can perform close to the unconstrained optimum while retaining exploration, but it cannot equal a deterministic optimum that assigns zero probability to inferior actions.

    Three ways to obtain coverage

    StrategyHow coverage is obtainedMain cost
    Exploring startsRandomise the initial $(s,a)$ pairOften impossible to control initial states
    On-policy $\varepsilon$-softThe learned policy itself keeps every action aliveTarget policy must continue exploring
    Off-policy learningA separate behaviour policy explores for the targetRequires importance-sampling correction

    The third row is the escape hatch: learn about a greedy target while a different policy gathers broad experience. That is Part 3.
