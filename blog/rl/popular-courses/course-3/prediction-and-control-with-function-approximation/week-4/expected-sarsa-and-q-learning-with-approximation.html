    Expected Sarsa & Q-learning with Function Approximation

    September 2026 · 18 min read · Prediction and Control with Function Approximation, Week 4

    Only the target changes. Sarsa bootstraps off the action it happened to take next. Expected Sarsa averages over every action the target policy could take. Q-learning takes the maximum. All three share the same weights, the same gradient, and the same semi-gradient update.

    The tabular starting point

    Tabular Sarsa uses the next action it actually sampled:

    $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\Big(R_{t+1}+\gamma \,Q(S_{t+1},A_{t+1})-Q(S_t,A_t)\Big).$$

    Expected Sarsa replaces that one sample with the expectation of $Q(S_{t+1},\cdot)$ under the target policy:

    $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\Big(R_{t+1}+\gamma \sum_{a'}\pi(a'\mid S_{t+1})\,Q(S_{t+1},a')-Q(S_t,A_t)\Big).$$

    The sampled $A_{t+1}$ is gone. The target no longer depends on which action the agent will pick next, only on the policy's distribution over actions.

    The same move under function approximation

    Nothing about this argument used a table. Replace $Q(s,a)$ with $\hat q(s,a,\mathbf w)$ and the tabular increment with a semi-gradient step, and both algorithms carry over unchanged.

    1

    Sarsa with approximation.

    $$\mathbf w\leftarrow\mathbf w+\alpha\Big(R_{t+1}+\gamma\,\hat q(S_{t+1},A_{t+1},\mathbf w)-\hat q(S_t,A_t,\mathbf w)\Big)\nabla\hat q(S_t,A_t,\mathbf w).$$
    2

    Expected Sarsa with approximation.

    $$\boxed{\mathbf w\leftarrow\mathbf w+\alpha\Big(R_{t+1}+\gamma\sum_{a'}\pi(a'\mid S_{t+1})\,\hat q(S_{t+1},a',\mathbf w)-\hat q(S_t,A_t,\mathbf w)\Big)\nabla\hat q(S_t,A_t,\mathbf w).}$$

    Read the mechanics off the formula. At every step we

    1. evaluate $\hat q(S_{t+1},a',\mathbf w)$ from the current weight vector for every action $a'$ available in the next state;
    2. average those values under the target policy $\pi$ to form the bootstrapped target;
    3. correct $\hat q(S_t,A_t,\mathbf w)$ towards it, moving only the weights the gradient touches.

    The gradient term is untouched. With the stacked linear features from earlier in the week, it is still $\mathbf x(S_t,A_t)$, so the update still writes only to the block of $A_t$ — even though the target read from all three blocks of $S_{t+1}$.

    Three targets, one state

    Everything that distinguishes these algorithms lives in one scalar. Fix a next state, look at its three action values, and compare what each algorithm would bootstrap from.

    Q-learning is the greedy special case

    Suppose the target policy is greedy with respect to the current estimates. Then $\pi(a'\mid S_{t+1})=1$ for an action attaining the maximum and $0$ for everything else, so the sum collapses:

    $$\sum_{a'}\pi(a'\mid S_{t+1})\,\hat q(S_{t+1},a',\mathbf w) \;\;\xrightarrow[\ \pi\text{ greedy}\ ]{}\;\; \max_{a'}\hat q(S_{t+1},a',\mathbf w).$$

    Substituting gives Q-learning with function approximation:

    $$\boxed{\mathbf w\leftarrow\mathbf w+\alpha\Big(R_{t+1}+\gamma\max_{a'}\hat q(S_{t+1},a',\mathbf w)-\hat q(S_t,A_t,\mathbf w)\Big)\nabla\hat q(S_t,A_t,\mathbf w).}$$
    Q-learning is Expected Sarsa with a greedy target policy. Taking an expectation under a policy that puts all its mass on the argmax is taking a maximum. There is no separate derivation to do, and no separate implementation either: one code path with a pluggable target distribution covers both.

    This is also why the two behave so differently in practice while looking so similar on paper. Expected Sarsa with an $\varepsilon$-greedy target learns the value of the policy the agent actually follows, exploration included. Q-learning learns the value of the greedy policy regardless of what the agent does, which is exactly the on-policy versus off-policy distinction.

    What the expectation costs

    Sarsa evaluates $\hat q$ once for the next state. Expected Sarsa and Q-learning evaluate it $|\mathcal A|$ times. Whether that matters depends entirely on the parameterization.

    ParameterizationCost of the next-state targetComment
    Stacked tile coding, $n$ tilings$n\,|\mathcal A|$ additionsEach action reads a different block, so nothing is shared, but $n$ is small.
    Network with one output per actionone forward passAll action values already come out together; the expectation is free.
    Network taking the action as input$|\mathcal A|$ forward passesThe expensive layout, and the reason the multi-output form is standard for discrete actions.

    Note that the extra cost is entirely in the target. The update itself still writes to the same weights as Sarsa would, because $\nabla\hat q(S_t,A_t,\mathbf w)$ has not changed.

    Why replace the sample with the expectation

    The Sarsa target inherits two sources of randomness: the environment's transition, and the agent's choice of $A_{t+1}$. Expected Sarsa removes the second one exactly rather than averaging it away over time.

    $$\operatorname{Var}\big[\hat q(S_{t+1},A_{t+1},\mathbf w)\big] =\sum_{a'}\pi(a'\mid S_{t+1})\Big(\hat q(S_{t+1},a',\mathbf w)-\textstyle\sum_{a''}\pi(a''\mid S_{t+1})\hat q(S_{t+1},a'',\mathbf w)\Big)^2.$$

    That variance is what the third metric in the figure reports, and it is what Expected Sarsa deletes. Two consequences follow:

    • Larger step sizes become usable. With less noise per update, a bigger $\alpha$ does not immediately destabilize the weights.
    • The benefit grows with exploration. At $\varepsilon=0$ the sampled action is the greedy one every time and the variance is zero, so Expected Sarsa buys nothing. The gap widens as $\varepsilon$ rises and the action values spread apart.

    One caveat worth stating early

    Off-policy bootstrapping with function approximation has no general convergence guarantee. On-policy semi-gradient TD and Sarsa converge to a bounded region around the best linear solution, but combining off-policy targets, bootstrapping, and approximation can diverge outright. Q-learning with approximation sits squarely in that combination. It works well in many problems, including the Mountain Car setup from the previous post, but "it worked here" is the honest claim, not "it is guaranteed".
    Takeaway

    Sarsa, Expected Sarsa, and Q-learning differ only in how they turn the next state into one bootstrap number: sample it, average it under $\pi$, or maximize over it. Function approximation changes the cost of that choice, not the choice itself.
