    Exploration under Function Approximation

    September 2026 · 19 min read · Prediction and Control with Function Approximation, Week 4

    Optimistic initialization is a tabular idea that only partly survives. With weights instead of table cells you have to work out which weights produce optimistic values, and generalization can spend the optimism on states the agent has never visited. $\varepsilon$-greedy has neither problem, which is why it remains the default.

    What optimism means when you own weights

    In the tabular case, optimistic initialization is trivial: write a large number into every cell of $Q$. Under approximation you never touch values directly. You choose $\mathbf w$, and the values fall out of the parameterization:

    $$\text{choose }\mathbf w_0\ \text{ such that }\ \hat q(s,a,\mathbf w_0)\ \ge\ q_*(s,a)\quad\text{for all }s,a.$$

    So the question becomes: given a parameterization, which weight vectors produce uniformly high values? The answer ranges from "obvious" to "no idea".

    The linear case is easy

    With $\hat q(s,a,\mathbf w)=\mathbf w^\top\mathbf x(s,a)$ and non-negative features, raising every weight raises every value. Set each weight to a large number and you are done:

    $$\mathbf w\leftarrow\begin{bmatrix}100\\100\\100\\100\\\vdots\end{bmatrix}.$$

    One arithmetic detail is worth getting right. With binary features, the value is the sum of the active weights, so if exactly $n$ features are active for every state-action pair, then

    $$\hat q(s,a,\mathbf w)=\sum_{i\ \text{active}}w_i=n\,w,\qquad\text{so set } w=\frac{q_{\max}}{n}$$

    to target an optimistic value of $q_{\max}$. With 8 tilings, initializing each weight to 100 gives values of 800, not 100. Overshooting is not fatal, but it does control how long the agent keeps exploring before the estimates come down.

    Mountain Car in the previous post is the degenerate version of this: every reward is $-1$, so all true values are negative, and $\mathbf w=\mathbf 0$ is already optimistic without any tuning at all.

    The non-linear case is hard

    For a neural network there is no simple map from weights to values. The relationship between the parameters and the outputs runs through several non-linearities, and "large weights" does not imply "large outputs".

    A concrete failure. Take a network built from $\tanh$ activations. $\tanh$ is odd and saturates, so a hidden unit driven by large positive weights can still produce a large negative activation once the input sign or a downstream weight sign flips. The network can output negative values everywhere despite being initialized with positive weights. There is no general recipe for "initialize this network optimistically".

    Worse, whatever optimism you do manage to inject is not stable. Weight decay, normalization layers, and ordinary gradient updates all pull the outputs back toward their typical scale, and they do it everywhere at once.

    Optimism versus generalization

    Even when you can make the initial values optimistic, function approximation can undo the mechanism that makes optimism work.

    Recall why optimism drives exploration in the tabular case. Trying an action lowers only that action's estimate, which makes the untried ones look relatively better, which forces the agent to sweep through them. The argument depends on updates being local.

    The extreme counterexample. Suppose the representation has a single feature that is always $1$. Then $\hat q(s,a,\mathbf w)=w$ for every state and action. You can initialize $w$ optimistically, but the first update lowers the estimate for the entire state space at once. By the time the agent reaches a state it has never visited, that state's value has already been driven down, and there is nothing left to attract the agent to it.

    Real representations sit between the two extremes, and where they sit is the whole story:

    Tile coding keeps optimism alive

    An update writes to the tiles containing the visited state, so distant states keep their initial values. Optimism is spent locally, and the systematic sweep through unvisited regions survives. This is why the Mountain Car agent could explore with no randomness at all.

    Networks spend it fast

    A network can learn localized updates, but it can also generalize aggressively, and early in training it usually does. In practice, without special measures, a network loses its optimism quickly and the agent stops being drawn to unvisited states.

    Notice the tension. Broad generalization is the reason we use function approximation at all: it lets one experience inform many states. The same breadth is what erases optimism. You cannot maximize both, and the balance is set by the same feature-design knobs from week 3.

    Why $\varepsilon$-greedy remains the default

    $\varepsilon$-greedy sidesteps every problem above:

    $$A_t=\begin{cases}\displaystyle\operatorname*{arg\,max}_a\hat q(S_t,a,\mathbf w) &\text{with probability }1-\varepsilon,\\[4pt]\text{a uniformly random action} &\text{with probability }\varepsilon.\end{cases}$$

    The only thing it needs is a set of action-value estimates. It does not care how those estimates were produced, whether the parameterization is linear or a deep network, or how the weights were initialized. That makes it generally applicable and trivial to implement, which is exactly why it survives as the default even though its exploration is undirected.

    Takeaway

    Optimistic initialization needs two things that function approximation does not guarantee: a way to pick weights that make values high, and updates local enough that unvisited states stay optimistic. Tile coding gives you both; a neural network usually gives you neither, which is why $\varepsilon$-greedy is the safe default.
