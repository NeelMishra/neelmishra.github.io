    Generalization Geometry in Coarse Coding

    September 2026 · 20 min read · Prediction and Control with Function Approximation, Week 3

    Generalization is geometry. Receptive-field size decides how far an update spreads; shape decides its direction; the joint overlap pattern decides which states remain distinguishable.

    Size controls breadth

    When feature $i$ is updated, every state inside its receptive field uses the changed weight $w_i$. A larger field therefore spreads information across a larger neighborhood.

    Small fields

    Fine local distinctions and less bias, but each sample teaches fewer neighboring states.

    Large fields

    Faster broad transfer, but sharp local differences may be smoothed away.

    Shape controls direction

    Generalization is not only “more” or “less.” An elongated receptive field shares a feature farther along its long axis than along its short axis.

    • A wide horizontal ellipse generalizes strongly across horizontal position.
    • A tall vertical ellipse generalizes strongly across vertical position.
    • A circular field treats directions more symmetrically.

    Overlap controls discrimination

    Each state is represented by its complete activation pattern:

    $$\mathbf x(s)=(x_1(s),\ldots,x_d(s)).$$

    Two states with identical patterns receive identical linear estimates for every possible $\mathbf w$. The overlap boundaries partition the state space into regions of distinguishable patterns.

    Finer discrimination comes from smaller pattern regions. This can be achieved by shrinking fields, adding more overlapping fields, or changing their shapes and placements.

    Three independent design knobs

    KnobPrimary effectTrade-off
    Field sizeBreadth of generalizationLarge fields learn broadly but can blur local structure.
    Field shapeDirection of generalizationAnisotropic shapes assume some directions vary more slowly.
    Number and offsetsFineness of activation patternsMore fields improve discrimination but cost memory and computation.

    These knobs interact. Many large overlapping fields can preserve broad transfer while their intersections still provide fine discrimination.

    Broad does not always mean better

    If the true value function varies slowly, broad fields can learn it quickly from few samples. If it contains sharp local changes, the same fields can introduce irreducible approximation error. Feature width therefore encodes an assumption about the smoothness of the value function.

    Representation bias survives unlimited data. More samples improve the best fit within the feature space; they do not create distinctions that the activation patterns cannot express.

    A practical design checklist

    1. Which state dimensions should share information?
    2. Over what distance should one sample influence another state?
    3. Does generalization need to be wider in one direction?
    4. Are important value discontinuities finer than the overlap regions?
    5. Does every reachable state activate at least one feature?
