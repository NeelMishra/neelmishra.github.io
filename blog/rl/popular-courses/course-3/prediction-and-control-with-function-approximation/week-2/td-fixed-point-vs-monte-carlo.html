    The TD Fixed Point & TD versus Monte Carlo

    September 2026 · 25 min read · Prediction and Control with Function Approximation, Week 2

    TD is principled, but it solves a different equation. Gradient Monte Carlo minimizes value error directly. Linear semi-gradient TD instead drives its expected bootstrap update to zero, producing the projected Bellman fixed point.

    TD does not minimize MSVE

    The semi-gradient update looks like regression, but its target changes with $\mathbf w$. Therefore the limiting TD weights are not generally

    $$\arg\min_{\mathbf w}\overline{\mathrm{VE}}(\mathbf w).$$

    This does not mean TD converges arbitrarily. In the on-policy linear case, its expected update has a precise fixed point.

    Write the expected linear TD update

    Let $\mathbf x_t=\mathbf x(S_t)$ and $\hat v(S_t,\mathbf w)=\mathbf w^\top\mathbf x_t$. One update direction is

    $$\delta_t\mathbf x_t =\left[R_{t+1}+\gamma\mathbf w^\top\mathbf x_{t+1}-\mathbf w^\top\mathbf x_t\right]\mathbf x_t.$$

    Rearrange the terms containing $\mathbf w$:

    $$\delta_t\mathbf x_t =R_{t+1}\mathbf x_t-\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^\top\mathbf w.$$

    Taking expectations under the on-policy state-transition distribution gives

    $$\boxed{\mathbb E[\Delta\mathbf w_t]=\alpha(\mathbf b-\mathbf A\mathbf w_t)},$$

    where

    $$\mathbf b=\mathbb E[R_{t+1}\mathbf x_t],\qquad \mathbf A=\mathbb E[\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^\top].$$

    The TD fixed point

    At convergence, the expected update is zero:

    $$\mathbf b-\mathbf A\mathbf w_{\mathrm{TD}}=0.$$

    If $\mathbf A$ is invertible,

    $$\boxed{\mathbf w_{\mathrm{TD}}=\mathbf A^{-1}\mathbf b}.$$

    This is the linear TD fixed point. Under standard finite, on-policy conditions and suitable decreasing step sizes, linear TD(0) converges to it.

    The Bellman operator

    The projection in the next section is stated in terms of one object, so define it first. For a fixed policy $\pi$, the Bellman operator $T_\pi$ takes a value function and returns another one:

    $$(T_\pi v)(s)\doteq\mathbb E_\pi\big[R_{t+1}+\gamma\,v(S_{t+1})\;\big|\;S_t=s\big] =\sum_a\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\big[r+\gamma\,v(s')\big].$$

    It is a one-step lookahead: take one real reward, then fall back on the current estimate. With finitely many states it is affine, $T_\pi v=\mathbf r_\pi+\gamma P_\pi v$. Its defining property is that $v_\pi$ is its unique fixed point, $T_\pi v_\pi=v_\pi$ — which is just the Bellman equation restated. Tabular TD is a sample-based way of solving it.

    Why a projection is needed

    Under approximation the representable functions are only a $d$-dimensional subspace $\{X\mathbf w\}$ of $\mathbb R^{|\mathcal S|}$. Applying the operator to a representable function gives $\mathbf r_\pi+\gamma P_\pi X\mathbf w$, which lands back in that subspace only if $\mathbf r_\pi$ happens to be representable and the subspace happens to be invariant under $P_\pi$. Features are designed to describe states, not to satisfy either condition, so in general the backup leaves the subspace and no weight vector reproduces it.

    The remedy is to take the closest representable function instead. $\Pi$ projects onto the subspace in the same $\mu$-weighted norm the value-error objective uses, and for linear features has the closed form $\Pi=X(X^\top DX)^{-1}X^\top D$ with $D=\operatorname{diag}(\mu)$.

    Current approximation$\hat v_{\mathbf w}$
    →
    Bellman backup$T_\pi\hat v_{\mathbf w}$, off the subspace
    →
    Project back$\Pi T_\pi\hat v_{\mathbf w}$, representable again

    TD settles on the fixed point of that composition,

    $$\boxed{\hat v_{\mathbf w_{\mathrm{TD}}}=\Pi T_\pi\hat v_{\mathbf w_{\mathrm{TD}}}},$$

    which is the same $\mathbf w_{\mathrm{TD}}=\mathbf A^{-1}\mathbf b$ found above, seen from the operator side. It exists and is unique because $\Pi T_\pi$ is a contraction under the on-policy state distribution — the reason "on-policy" keeps appearing in this note.

    The projected Bellman-error objective

    Let $\mathbf C=\mathbb E[\mathbf x_t\mathbf x_t^\top]$. For linear approximation, the mean squared projected Bellman error can be written

    $$\operatorname{MSPBE}(\mathbf w) =(\mathbf b-\mathbf A\mathbf w)^\top\mathbf C^{-1}(\mathbf b-\mathbf A\mathbf w).$$

    At the TD fixed point, $\mathbf b-\mathbf A\mathbf w_{\mathrm{TD}}=0$, so the MSPBE is zero. Semi-gradient TD is not ordinary gradient descent on this expression; it reaches the same root through its expected update dynamics.

    How far can its value error be?

    The TD solution and the minimum-MSVE solution can differ, but the on-policy linear theory gives the bound

    $$\boxed{\overline{\mathrm{VE}}(\mathbf w_{\mathrm{TD}}) \le \frac{1}{1-\gamma}\min_{\mathbf w}\overline{\mathrm{VE}}(\mathbf w)}.$$
    • When $\gamma$ is small, the multiplier is close to $1$.
    • When $\gamma$ is close to $1$, the bound becomes loose and allows a larger gap.
    • If the features can represent $v_\pi$ exactly, both methods recover it and the gap vanishes.

    The bound is an upper guarantee, not a prediction that TD will always be worse by exactly $1/(1-\gamma)$.

    See two different solutions

    Consider two states with transition matrix, expected reward, stationary weighting, and one shared feature:

    $$P=\begin{bmatrix}0.8&0.2\\0.1&0.9\end{bmatrix},\quad \mathbf r=\begin{bmatrix}0\\1\end{bmatrix},\quad \mu=\begin{bmatrix}1/3\\2/3\end{bmatrix},\quad x(A)=1,\ x(B)=0.3.$$

    The representation is intentionally weak: one weight cannot independently fit both states.

    TD versus Monte Carlo: final fit and learning speed

    QuestionGradient Monte CarloSemi-gradient TD
    Limiting principleMinimize MSVESolve the projected Bellman equation
    Target varianceHigher: complete returnLower: one reward plus bootstrap
    Target biasUnbiased return sampleBiased while the next estimate is imperfect
    Update timingAfter return is knownAfter every transition
    Typical early learningSlowerFaster

    Monte Carlo can achieve the better asymptotic MSVE fit within a fixed representation. TD often reaches a useful estimate much sooner because it updates online and avoids the variance of long returns. These claims are compatible: best eventual fit and fastest useful learning are different goals.

    Do not collapse the distinction

    TD is not “incorrect gradient descent.” It is a bootstrap method converging to a Bellman-consistent projection, with a different bias-variance and speed trade-off from direct return regression.
