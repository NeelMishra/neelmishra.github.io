    The TD Fixed Point & TD versus Monte Carlo

    September 2026 · 25 min read · Prediction and Control with Function Approximation, Week 2

    TD is principled, but it solves a different equation. Gradient Monte Carlo minimizes value error directly. Linear semi-gradient TD instead drives its expected bootstrap update to zero, producing the projected Bellman fixed point.

    TD does not minimize MSVE

    The semi-gradient update looks like regression, but its target changes with $\mathbf w$. Therefore the limiting TD weights are not generally

    $$\arg\min_{\mathbf w}\overline{\mathrm{VE}}(\mathbf w).$$

    This does not mean TD converges arbitrarily. In the on-policy linear case, its expected update has a precise fixed point.

    Write the expected linear TD update

    Let $\mathbf x_t=\mathbf x(S_t)$ and $\hat v(S_t,\mathbf w)=\mathbf w^\top\mathbf x_t$. One update direction is

    $$\delta_t\mathbf x_t =\left[R_{t+1}+\gamma\mathbf w^\top\mathbf x_{t+1}-\mathbf w^\top\mathbf x_t\right]\mathbf x_t.$$

    Rearrange the terms containing $\mathbf w$:

    $$\delta_t\mathbf x_t =R_{t+1}\mathbf x_t-\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^\top\mathbf w.$$

    Taking expectations under the on-policy state-transition distribution gives

    $$\boxed{\mathbb E[\Delta\mathbf w_t]=\alpha(\mathbf b-\mathbf A\mathbf w_t)},$$

    where

    $$\mathbf b=\mathbb E[R_{t+1}\mathbf x_t],\qquad \mathbf A=\mathbb E[\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^\top].$$

    The TD fixed point

    At convergence, the expected update is zero:

    $$\mathbf b-\mathbf A\mathbf w_{\mathrm{TD}}=0.$$

    If $\mathbf A$ is invertible,

    $$\boxed{\mathbf w_{\mathrm{TD}}=\mathbf A^{-1}\mathbf b}.$$

    This is the linear TD fixed point. Under standard finite, on-policy conditions and suitable decreasing step sizes, linear TD(0) converges to it.

    The Bellman operator

    Everything below is stated in terms of one object, so it is worth defining before it is used.

    The Bellman operator for a policy. For a fixed policy $\pi$, the operator $T_\pi$ takes a value function and returns another value function. Evaluated at a state $s$:
    $$(T_\pi v)(s)\doteq\sum_a\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\Big[r+\gamma\,v(s')\Big],$$
    or equivalently, in expectation form,
    $$(T_\pi v)(s)=\mathbb E_\pi\big[R_{t+1}+\gamma\,v(S_{t+1})\;\big|\;S_t=s\big].$$

    Read it as a one-step lookahead: take one real reward, then fall back on the current estimate $v$ for everything after that. It is exactly the right-hand side of the Bellman equation, repackaged as a map from functions to functions.

    With finitely many states, $v$ is a vector in $\mathbb R^{|\mathcal S|}$ and the operator is affine:

    $$\boxed{T_\pi v=\mathbf r_\pi+\gamma P_\pi v},$$

    where $\mathbf r_\pi(s)=\mathbb E_\pi[R_{t+1}\mid S_t=s]$ is the expected one-step reward and $P_\pi$ is the state-to-state transition matrix induced by $\pi$.

    Two properties do all the work:

    PropertyStatementConsequence
    $v_\pi$ is its fixed point$T_\pi v_\pi=v_\pi$This is the Bellman equation. Solving it and finding a fixed point of $T_\pi$ are the same task.
    It is a $\gamma$-contraction$\|T_\pi u-T_\pi v\|_\infty\le\gamma\|u-v\|_\infty$Repeated application converges to $v_\pi$ from any start. That is iterative policy evaluation.

    Why a projection is unavoidable

    In the tabular case there is nothing more to say: $v$ lives in $\mathbb R^{|\mathcal S|}$, $T_\pi v$ lands back in $\mathbb R^{|\mathcal S|}$, and iterating reaches $v_\pi$.

    Function approximation breaks that closure. The functions we can actually represent form a $d$-dimensional subspace of $\mathbb R^{|\mathcal S|}$, with $d\ll|\mathcal S|$:

    $$\mathcal M=\big\{\hat v_{\mathbf w}=X\mathbf w\ :\ \mathbf w\in\mathbb R^{d}\big\}\subset\mathbb R^{|\mathcal S|},$$

    where $X$ stacks the feature vectors $\mathbf x(s)^\top$ as rows.

    The backup leaves the subspace. Start from a representable $\hat v_{\mathbf w}\in\mathcal M$ and apply $T_\pi$. The result is a perfectly good value function, but in general no weight vector reproduces it: there is no $\mathbf w'$ with $X\mathbf w'=T_\pi\hat v_{\mathbf w}$. So the tabular update "set $v\leftarrow T_\pi v$" is not merely inconvenient here, it is not executable.

    Why no such weight vector exists

    That claim deserves an argument rather than an assertion. Use the vector form. Applying the operator to a representable function gives

    $$T_\pi\big(X\mathbf w\big)=\mathbf r_\pi+\gamma P_\pi X\mathbf w,$$

    so asking for a $\mathbf w'$ with $X\mathbf w'=T_\pi(X\mathbf w)$ is asking for

    $$\mathbf r_\pi+\gamma P_\pi X\mathbf w\ \in\ \operatorname{col}(X).$$

    For the subspace to be closed under the operator this must hold for every $\mathbf w$. Setting $\mathbf w=\mathbf 0$ forces $\mathbf r_\pi\in\operatorname{col}(X)$; subtracting that off leaves $\gamma P_\pi X\mathbf w\in\operatorname{col}(X)$ for all $\mathbf w$. So closure requires two separate things to be true at once:

    #ConditionWhy it usually fails
    1$\mathbf r_\pi\in\operatorname{col}(X)$ — the expected-reward vector is itself representable$\mathbf r_\pi$ is a property of the environment. Features are chosen to describe states, with no reference to the reward function, so there is no reason it lands in their span.
    2$P_\pi\operatorname{col}(X)\subseteq\operatorname{col}(X)$ — the span is an invariant subspace of the transition matrixInvariant subspaces of a matrix are spanned by its eigenvectors. Hand-designed features — tiles, coarse codes, aggregations — are not built from the eigenvectors of $P_\pi$, which you do not know.
    The dimension count makes it stark. $\operatorname{col}(X)$ is a $d$-dimensional slice of an $|\mathcal S|$-dimensional space, and the whole point of approximation is $d\ll|\mathcal S|$. Requiring a generic affine map to carry that particular slice back into itself is a coincidence, not a default. Closure is the special case; leaving the subspace is the rule.

    A three-state counterexample

    Take states $\{1,2,3\}$ cycling deterministically $1\to2\to3\to1$, with $\gamma=0.9$ and reward $1$ only on leaving state 1, so $\mathbf r_\pi=(1,0,0)^\top$. Use a single constant feature, $\mathbf x(s)=1$ for all $s$, so $\operatorname{col}(X)=\operatorname{span}\{(1,1,1)^\top\}$ and $\hat v_{\mathbf w}=w\,(1,1,1)^\top$.

    Because the cycle just permutes coordinates, $P_\pi(1,1,1)^\top=(1,1,1)^\top$, and

    $$T_\pi\hat v_{\mathbf w}=(1,0,0)^\top+0.9\,w\,(1,1,1)^\top=\big(1+0.9w,\ 0.9w,\ 0.9w\big)^\top.$$
    $w$$\hat v_{\mathbf w}$$T_\pi\hat v_{\mathbf w}$Representable?
    $0$$(0,0,0)$$(1,0,0)$no
    $1$$(1,1,1)$$(1.9,0.9,0.9)$no
    $2.5$$(2.5,2.5,2.5)$$(3.25,2.25,2.25)$no

    A representable function has all three entries equal. Here the first entry is $1+0.9w$ and the others are $0.9w$, so representability would need $1=0$. No $w$ works — not for one unlucky value, but for every value at once. Here the failure is obstruction 1: the reward vector is not constant, so it cannot be built from a constant feature.

    Obstruction 2 bites independently. Keep the same cycle but set all rewards to zero and use the feature $\mathbf x=(1,1,0)^\top$. Then $T_\pi\hat v_{\mathbf w}=0.9\,P_\pi\,(w,w,0)^\top=(0.9w,\,0,\,0.9w)^\top$, which is not a multiple of $(1,1,0)^\top$: the transition has moved mass onto the very coordinate the feature zeroes out.

    When it does close

    The tabular case takes $X=I$, so $\operatorname{col}(X)=\mathbb R^{|\mathcal S|}$ and both conditions hold trivially. That is precisely why no projection ever appeared before we introduced approximation.

    The other special case

    State aggregation on a lumpable chain, where states in a group share both their expected reward and their aggregate transition behaviour. Then the span really is invariant and the reward really is representable. It is a strong structural assumption, rarely available in practice.

    Since exact closure is out of reach, the only thing left is to accept the closest representable function instead. That is what $\Pi$ does — it projects onto $\mathcal M$, measuring distance in the $\mu$-weighted norm that the value-error objective already uses:

    $$\Pi v\doteq\hat v_{\mathbf w^\star},\qquad \mathbf w^\star=\operatorname*{arg\,min}_{\mathbf w}\big\|\hat v_{\mathbf w}-v\big\|_\mu^2,$$

    and for linear features, writing $D=\operatorname{diag}(\mu)$, the projection has a closed form:

    $$\Pi=X\big(X^\top DX\big)^{-1}X^\top D.$$

    Composing the two gives the update TD is implicitly performing:

    Current approximation$\hat v_{\mathbf w}$
    →
    Bellman backup$T_\pi\hat v_{\mathbf w}$, off the subspace
    →
    Project back$\Pi T_\pi\hat v_{\mathbf w}$, representable again

    and the solution it settles on is the fixed point of that composition:

    $$\boxed{\hat v_{\mathbf w_{\mathrm{TD}}}=\Pi T_\pi\hat v_{\mathbf w_{\mathrm{TD}}}}.$$

    This is the same $\mathbf w_{\mathrm{TD}}=\mathbf A^{-1}\mathbf b$ derived above, seen from the operator side rather than the linear-algebra side.

    Why that fixed point exists at all. $\Pi$ is an orthogonal projection in $\|\cdot\|_\mu$, so it is non-expansive, and $T_\pi$ is a $\gamma$-contraction in $\|\cdot\|_\mu$ when $\mu$ is the on-policy stationary distribution. A non-expansion composed with a $\gamma$-contraction is still a $\gamma$-contraction, so $\Pi T_\pi$ has exactly one fixed point. This is where the "on-policy" qualifier throughout this note comes from: under a different state distribution $T_\pi$ need not contract in that norm, the argument collapses, and the fixed point can fail to exist — which is the root of the instability that shows up later with off-policy bootstrapping.

    TD therefore seeks Bellman consistency after accounting for what the feature space can represent.

    The projected Bellman-error objective

    Let $\mathbf C=\mathbb E[\mathbf x_t\mathbf x_t^\top]$. For linear approximation, the mean squared projected Bellman error can be written

    $$\operatorname{MSPBE}(\mathbf w) =(\mathbf b-\mathbf A\mathbf w)^\top\mathbf C^{-1}(\mathbf b-\mathbf A\mathbf w).$$

    At the TD fixed point, $\mathbf b-\mathbf A\mathbf w_{\mathrm{TD}}=0$, so the MSPBE is zero. Semi-gradient TD is not ordinary gradient descent on this expression; it reaches the same root through its expected update dynamics.

    How far can its value error be?

    The TD solution and the minimum-MSVE solution can differ, but the on-policy linear theory gives the bound

    $$\boxed{\overline{\mathrm{VE}}(\mathbf w_{\mathrm{TD}}) \le \frac{1}{1-\gamma}\min_{\mathbf w}\overline{\mathrm{VE}}(\mathbf w)}.$$
    • When $\gamma$ is small, the multiplier is close to $1$.
    • When $\gamma$ is close to $1$, the bound becomes loose and allows a larger gap.
    • If the features can represent $v_\pi$ exactly, both methods recover it and the gap vanishes.

    The bound is an upper guarantee, not a prediction that TD will always be worse by exactly $1/(1-\gamma)$.

    See two different solutions

    Consider two states with transition matrix, expected reward, stationary weighting, and one shared feature:

    $$P=\begin{bmatrix}0.8&0.2\\0.1&0.9\end{bmatrix},\quad \mathbf r=\begin{bmatrix}0\\1\end{bmatrix},\quad \mu=\begin{bmatrix}1/3\\2/3\end{bmatrix},\quad x(A)=1,\ x(B)=0.3.$$

    The representation is intentionally weak: one weight cannot independently fit both states.

    TD versus Monte Carlo: final fit and learning speed

    QuestionGradient Monte CarloSemi-gradient TD
    Limiting principleMinimize MSVESolve the projected Bellman equation
    Target varianceHigher: complete returnLower: one reward plus bootstrap
    Target biasUnbiased return sampleBiased while the next estimate is imperfect
    Update timingAfter return is knownAfter every transition
    Typical early learningSlowerFaster

    Monte Carlo can achieve the better asymptotic MSVE fit within a fixed representation. TD often reaches a useful estimate much sooner because it updates online and avoids the variance of long returns. These claims are compatible: best eventual fit and fastest useful learning are different goals.

    Do not collapse the distinction

    TD is not “incorrect gradient descent.” It is a bootstrap method converging to a Bellman-consistent projection, with a different bias-variance and speed trade-off from direct return regression.
