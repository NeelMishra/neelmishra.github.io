    MSVE, Gradient Monte Carlo & State Aggregation

    September 2026 · 24 min read · Prediction and Control with Function Approximation, Week 2

    Policy evaluation becomes regression. A state is the input, a sampled return is the target, and $\hat v(s,\mathbf w)$ is the prediction. The new question is how errors across different states should be weighted.

    Value estimation as supervised learning

    Ordinary regression learns from input-target pairs. Monte Carlo policy evaluation supplies the analogous pairs automatically:

    $$\big(S_t,G_t\big),\qquad \mathbb E_\pi[G_t\mid S_t=s]=v_\pi(s).$$

    The sampled return $G_t$ is noisy, but it is an unbiased target for the true value of the visited state. With enough representative samples, fitting $\hat v(S_t,\mathbf w)$ to these returns fits the value function.

    Inputvisited state $S_t$
    →
    Prediction$\hat v(S_t,\mathbf w)$
    →
    Targetsampled return $G_t$

    The mean squared value error

    A small parameter vector usually cannot represent $v_\pi(s)$ perfectly for every state. Improving one region may worsen another, so the objective must say which states matter most.

    Mean Squared Value Error (MSVE). $$\boxed{\overline{\mathrm{VE}}(\mathbf w)=\sum_s\mu(s)\left[v_\pi(s)-\hat v(s,\mathbf w)\right]^2}.$$ The weighting $\mu(s)\ge0$ sums to one. A natural on-policy choice is the long-run fraction of time policy $\pi$ spends in state $s$.

    An error at a frequently visited state contributes more than the same error at a rarely visited state. The objective therefore measures prediction quality where the policy actually operates.

    Why the weighting changes the best answer

    Suppose $v_\pi(A)=0$ and $v_\pi(B)=4$, but the representation has only one constant parameter: $\hat v(A,w)=\hat v(B,w)=w$. It cannot fit both values. The best compromise is

    $$w^*=0\cdot\mu(A)+4\cdot\mu(B)=4\mu(B).$$

    Differentiate the objective

    Use one half in the objective so the derivative cancels the factor of two:

    $$J(\mathbf w)=\frac12\sum_s\mu(s)\left[v_\pi(s)-\hat v(s,\mathbf w)\right]^2.$$
    1

    Differentiate each squared error.

    $$\nabla J(\mathbf w)=-\sum_s\mu(s)\left[v_\pi(s)-\hat v(s,\mathbf w)\right]\nabla\hat v(s,\mathbf w).$$
    2

    Move opposite the gradient.

    $$\mathbf w\leftarrow\mathbf w+\alpha\sum_s\mu(s)\left[v_\pi(s)-\hat v(s,\mathbf w)\right]\nabla\hat v(s,\mathbf w).$$
    3

    Use one visited state as a stochastic estimate of the sum.

    $$\mathbf w\leftarrow\mathbf w+\alpha\left[v_\pi(S_t)-\hat v(S_t,\mathbf w)\right]\nabla\hat v(S_t,\mathbf w).$$
    4

    Replace the unknown true value with the sampled return $G_t$.

    $$\boxed{\mathbf w\leftarrow\mathbf w+\alpha\left[G_t-\hat v(S_t,\mathbf w)\right]\nabla\hat v(S_t,\mathbf w)}.$$

    Where did the state distribution go?

    It is still present through sampling frequency. If policy $\pi$ visits state $A$ twice as often as state $B$, then updates from $A$ appear about twice as often. The stream of on-policy states automatically weights the stochastic updates by $\mu$.

    On-policy matters here. If data comes from a different behaviour distribution, its visit frequencies represent the wrong weighting. Off-policy prediction then needs an appropriate correction.

    Gradient Monte Carlo

    Gradient Monte Carlo for $\hat v\approx v_\pi$
    1Choose differentiable $\hat v(s,\mathbf w)$, step size $\alpha>0$, and initialize $\mathbf w$.
    2for each episode generated by $\pi$:
    3Compute each return $G_t$.
    4for $t=0,\ldots,T-1$:
    5$\mathbf w\leftarrow\mathbf w+\alpha[G_t-\hat v(S_t,\mathbf w)]\nabla\hat v(S_t,\mathbf w)$

    For linear approximation, $\nabla\hat v(S_t,\mathbf w)=\mathbf x(S_t)$, so the update changes weights in proportion to the active features.

    State aggregation

    State aggregation partitions many states into a smaller number of groups. Every state in group $j$ uses the same one-hot group feature and therefore shares one weight:

    $$\hat v(s,\mathbf w)=w_j\qquad\text{when }s\in\text{group }j.$$

    The Gradient Monte Carlo update changes only that group:

    $$w_j\leftarrow w_j+\alpha\left[G_t-w_j\right].$$

    The representation generalizes within a group and discriminates between groups. More groups provide finer detail but require more parameters and more data.

    What state aggregation cannot express

    All states in one group are indistinguishable to the approximator. No amount of training can produce variation inside a group. This is approximation error caused by the representation, not an optimization failure.

    Core lesson

    With linear approximation, Gradient Monte Carlo converges to the best MSVE fit available within the chosen representation. Better optimization cannot recover information that the features do not encode.
