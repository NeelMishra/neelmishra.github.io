    Semi-Gradient TD & Linear Function Approximation

    September 2026 · 22 min read · Prediction and Control with Function Approximation, Week 2

    One substitution creates a new problem. Gradient Monte Carlo regresses toward a return that does not depend on the current weights. TD replaces that return with a bootstrap target containing $\hat v(S_{t+1},\mathbf w)$, so the target moves whenever the weights move.

    From Gradient Monte Carlo to TD

    Gradient Monte Carlo uses

    $$\mathbf w\leftarrow\mathbf w+\alpha\left[G_t-\hat v(S_t,\mathbf w)\right]\nabla\hat v(S_t,\mathbf w).$$

    TD substitutes a one-step target for the complete return:

    $$U_t=R_{t+1}+\gamma\hat v(S_{t+1},\mathbf w).$$

    This gives the semi-gradient TD update

    $$\boxed{\mathbf w\leftarrow\mathbf w+\alpha\left[U_t-\hat v(S_t,\mathbf w)\right]\nabla\hat v(S_t,\mathbf w)}.$$

    The bracketed term is the familiar TD error:

    $$\delta_t=R_{t+1}+\gamma\hat v(S_{t+1},\mathbf w)-\hat v(S_t,\mathbf w).$$

    The TD label moves with the model

    Monte Carlo target

    $G_t$ is determined by the sampled episode. Once that episode is stored, changing $\mathbf w$ does not change its return.

    $$\nabla_{\mathbf w}G_t=0.$$

    TD target

    $U_t$ contains the current next-state estimate. Changing $\mathbf w$ changes the label itself.

    $$\nabla_{\mathbf w}U_t=\gamma\nabla\hat v(S_{t+1},\mathbf w).$$

    Why it is called a semi-gradient

    If TD performed full gradient descent on the instantaneous squared bootstrap error

    $$L_t(\mathbf w)=\frac12\left[U_t(\mathbf w)-\hat v(S_t,\mathbf w)\right]^2,$$

    then differentiating would affect both the prediction and the target:

    $$-\nabla L_t =\left[U_t-\hat v(S_t,\mathbf w)\right] \left[\nabla\hat v(S_t,\mathbf w)-\nabla U_t(\mathbf w)\right].$$

    Semi-gradient TD deliberately treats $U_t$ as a constant during this derivative and drops $\nabla U_t$:

    $$\text{semi-gradient direction} =\left[U_t-\hat v(S_t,\mathbf w)\right]\nabla\hat v(S_t,\mathbf w).$$
    Important: this is not the true gradient of MSVE, and it is not the full gradient of squared TD error. “Semi” means the derivative is taken through the current-state prediction but not through the bootstrap target.

    Why use a biased moving target?

    PropertyGradient Monte CarloSemi-gradient TD
    TargetComplete sampled return $G_t$$R_{t+1}+\gamma\hat v(S_{t+1},\mathbf w)$
    Depends on current weights?NoYes
    Bias as a value targetUnbiasedGenerally biased while $\hat v$ is imperfect
    VarianceOften highUsually lower
    Can update before termination?NoYes

    Bootstrapping trades some target bias for lower variance and immediate updates. That often produces much faster early learning even though the final solution need not minimize MSVE.

    4Initialize $S$.

    6Choose $A\sim\pi(\cdot\mid S)$; take $A$ and observe $R,S'$.

    8$\mathbf w\leftarrow\mathbf w+\alpha\big[U-\hat v(S,\mathbf w)\big]\nabla\hat v(S,\mathbf w)$
    9$S\leftarrow S'$

    The linear TD update

    For $\hat v(s,\mathbf w)=\mathbf w^\top\mathbf x(s)$, the gradient is just $\mathbf x(s)$. Therefore

    $$\boxed{\mathbf w\leftarrow\mathbf w+\alpha\delta_t\mathbf x(S_t)}.$$

    Feature $i$ changes by

    $$w_i\leftarrow w_i+\alpha\delta_tx_i(S_t).$$

    An inactive feature with $x_i(S_t)=0$ does not move. A strongly active feature receives a proportionally larger update.

    Tables and aggregation are special cases again

    Tabular TD

    One-hot features activate only the current state's weight:

    $$w_j\leftarrow w_j+\alpha\delta_t.$$

    TD with state aggregation

    One-hot group features activate only the current state's group weight:

    $$w_{\mathrm{group}(S_t)}\leftarrow w_{\mathrm{group}(S_t)}+\alpha\delta_t.$$

    The formula is unchanged; only the feature vector decides how broadly one transition generalizes.

    Terminal transitions

    As in tabular TD, the terminal value is zero. If $S_{t+1}$ is terminal,

    $$\delta_t=R_{t+1}-\hat v(S_t,\mathbf w).$$

    No bootstrap estimate is used beyond termination.
