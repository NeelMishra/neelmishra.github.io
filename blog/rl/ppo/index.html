    PPO: From Policy Gradients to a Working Agent

    September 2026 · 5 min read + experiments

    An original visual learning path through PPO: derivations, GAE, clipping, runnable PyTorch experiments, continuous actions, diagnostics, and language models.

    Read the explanation

    Read this series as one connected explanation

    PPO is easier to learn when its pieces arrive in the order of the problems they solve. First, turn sampled rewards into a direction for changing a policy. Next, estimate that direction from incomplete, noisy trajectories. Finally, reuse a recent rollout without giving the optimizer an unlimited incentive to exploit it.

    This independent series assumes you have met states, actions, returns, and neural-network gradients. It develops the necessary policy-gradient mathematics, then follows one consistent set of symbols into a working PyTorch agent. If you already know the derivation, jump to the GAE boundary examples, clipping experiment, or implementation lab. Each concept has one main chapter and is linked from later applications.

    Nine chapters, each with a specific job

    Chapter 01PPO Begins with a Contract: Collect, Estimate, Improve

    Build a concrete mental model of the actor, critic, rollout buffer, and two clocks before opening the PPO loss.

    Chapter 02Policy Gradients: Why a Log Probability Times an Advantage Works

    Derive the actor gradient, work through a two-action example, and see why an unbiased baseline need not reduce variance.

    Chapter 03Returns, Values, and GAE: Credit Assignment without Boundary Bugs

    Compute advantages backward by hand, distinguish termination from truncation, and keep value targets separate from normalized actor weights.

    Chapter 04PPO Clipping: The Four Cases, the Geometry, and the Limits

    Derive the likelihood-ratio surrogate, connect it to TRPO, and inspect exactly when clipping removes a sample’s gradient.

    Chapter 05One Complete PPO Update: What Moves and What Stays Frozen

    Follow tensor shapes through collection, GAE, minibatch optimization, entropy regularization, and a KL-based stopping rule.

    Chapter 06Build and Test PPO: A Small Agent You Can Actually Inspect

    Run a complete PyTorch PPO agent, reproduce three seeded experiments, and test the mathematics before trusting a learning curve.

    Chapter 07Continuous-Action PPO: Densities, Squashing, and Vectorized Rollouts

    Build a Gaussian actor, sum the right log probabilities, account for action transforms, and preserve trajectory boundaries in parallel environments.

    Chapter 08Debug PPO with Evidence: Ratios, KL, Values, and Real Evaluation

    Learn what each training metric can tell you, diagnose failure patterns, and design comparisons that separate data budgets from optimizer reuse.

    Chapter 09PPO for Language Models: Tokens, Rewards, and Two Different Anchors

    Apply the general algorithm to text while separating old and reference policies, handling token masks, and making the sampling distribution explicit.

    Choose a route for the question you have

    • “I recognize the loss but cannot explain it.” Read chapters 1–4 in order, then calculate the four clipping cases without looking.
    • “My implementation runs but does not learn.” Start with the two boundary masks, the frozen-buffer contract, and diagnostics.
    • “I want to implement it.” Read chapter 5 beside the complete source; run the checks, reproduce the data, then change one setting.
    • “I care about RLHF.” Learn the shared algorithm through chapter 5, then read the language-model application. The old-policy ratio and reference penalty are different mechanisms.

    Use the figures as small experiments

    Eight chapters include an interactive calculation: a policy-gradient bandit, baseline variance, GAE, the clipping curve, frozen-batch bookkeeping, a transformed Gaussian, KL diagnostics, or token alignment. The lab adds a standalone plot from three recorded training seeds. Read the captions to distinguish exact calculations, constructed illustrations, and measured results.

    The controls work with a keyboard and motion follows your system preference. The explanations and worked numbers remain available without JavaScript. Use the expandable “Check your understanding” questions to test the distinction each chapter is meant to establish.

    Read the primary sources after the examples

    The PPO paper defines the algorithm family, the TRPO paper develops the trust-region motivation, and the GAE paper develops the advantage estimator. Implementation and API references are linked at the relevant choices in later chapters. This series uses original worked examples rather than treating a paper’s pseudocode as a complete software specification.
