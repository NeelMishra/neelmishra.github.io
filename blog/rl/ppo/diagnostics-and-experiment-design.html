    Debug PPO with Evidence: Ratios, KL, Values, and Real Evaluation

    September 2026 · 6 min read + experiments

    Learn what each training metric can tell you, diagnose failure patterns, and design comparisons that separate data budgets from optimizer reuse.

    Read the explanationTry the calculation

    Begin with invariants, before tuning

    When a PPO run fails, first determine whether the computation matches the intended algorithm. Before the first optimizer step on a freshly collected batch, re-score every stored action. Ratios should be approximately one. A mismatch can come from a different policy snapshot, dropout, a changed observation normalizer, action transformation, or a log-probability shape error. This is a stronger clue than a flat reward curve.

    Inspect a short trajectory by hand. Print state, action, reward, old value, successor value, both boundary flags, raw advantage, and target. Verify that critic targets remain in reward units and that the trace does not cross a reset. Then inspect tensor shapes: the actor contribution, critic error, and advantage should each have one scalar per transition in the feed-forward implementation.

    Read each metric as a measurement with limits

    MetricUseful interpretationWhat it cannot establish
    Evaluation return / successBehavior on fresh episodes under a stated protocolA single seed does not establish reliability
    KL(old ∥ current)Policy movement at rollout statesNot a bound on unseen states or a reward metric
    Clip fractionFraction with |ρ − 1| > εNot the fraction with zero actor gradient
    EntropySpread of the action distributionHigh entropy can mean random failure
    Value lossSquared error in chosen return unitsMagnitude changes with reward scale
    Explained varianceHow much target variation values explainUndefined when target variance is zero
    Gradient normScale of the optimizer inputDoes not directly measure policy-space distance

    For explained variance, one common definition is $1-\operatorname{Var}(y-V)/\operatorname{Var}(y)$. If the targets are almost constant, the denominator makes the statistic unstable. A value near one means the critic explains variation in these targets; those targets may still be biased or incorrectly constructed.

    Clip fraction uses only ratios, while a flat surrogate contribution also depends on the sign of the advantage. For example, an advantageous action with ratio 0.5 is outside a 0.2 clip interval yet retains a slope. Logging the four sign-and-ratio regions can be more informative than reporting one clip fraction. See the four-case table.

    A diagnostic you can calculate exactly

    Take an old binary policy $(0.5,0.5)$ and a new right-action probability $p$. The likelihood ratios are $2p$ and $2(1-p)$. Their old-policy-weighted KL is $-\frac12\log(2p)-\frac12\log(2(1-p))$. This tiny example separates genuine policy distance from a thresholded clip statistic.

    At $p=0.6$, the ratios are exactly 1.2 and 0.8, so a strict outside-interval clip fraction is still zero. Yet KL is about 0.0204 nats. Just beyond that point, the clip fraction jumps to one even though KL changes continuously. A jump in the threshold statistic does not imply a discontinuous policy change.

    Turn symptoms into discriminating checks

    KL is large after the first update. First check initial ratios. If they were wrong before optimization, repair the likelihood calculation. If they were correct, inspect learning rate, advantage scale, gradient norms, optimizer state, and the value-loss contribution through shared features. Reducing epochs cannot undo a first step that was already too large.

    Entropy collapses and reward stays low. Inspect which action probabilities collapsed and whether advantageous actions were reinforced with the correct sign. Check reward sparsity, early exploration, task resets, and whether a positive entropy coefficient was accidentally added to a minimized loss. If the signal is valid but rare, a larger collection budget may be more useful than extra passes over a nearly reward-free batch.

    The critic loss remains large. Examine reward scale, target construction, terminal masking, normalization, and observation information. A task with hidden state may not admit a good feed-forward value predictor from the supplied observation. Increasing critic capacity cannot recover information that is absent.

    Actor loss improves while evaluation worsens. The surrogate was optimized on old states with noisy advantages. Check policy drift, evaluator settings, reward exploitation, and whether evaluation samples or takes greedy actions. A stochastic training objective and greedy evaluation are different protocols; report the choice instead of silently switching.

    Compare algorithms under a stated budget

    Suppose run A uses 512 transitions per iteration and four epochs, while run B uses 2,048 transitions and one epoch. Both make 2,048 sample presentations per iteration, but B collects four times as much experience. Plotting against “iteration” hides that difference. Report environment transitions, optimizer steps, evaluation episodes, and elapsed time when speed matters.

    Use multiple training seeds and preserve per-seed curves. A mean without variability can hide a bimodal outcome where half the agents learn and half fail. On a small task, a table of all seeds can be clearer than a confidence band. Keep evaluation randomness separate from training randomness, and hold the evaluation protocol constant across comparisons.

    When changing one setting, write a prediction first: “Removing timeout bootstrapping should reduce targets near interrupted promising states,” or “More epochs should increase policy movement on this fixed buffer.” Then choose a metric that can refute the prediction. This gives a failed run explanatory value rather than another unexplained score.

    What to add after the toy succeeds

    Move to a documented environment with a known task definition, then add observation normalization, action transforms, and any wrappers one at a time. Compare against an explicit reference implementation and configuration, not just the name PPO. Huang et al.’s implementation study is useful for tracing these choices to code and understanding why reported results depend on more than the clipped equation. PPO implementation study.

    The LineWalk results provide a starting sanity check, not a substitute for this process on your target task. For language models, add token masks, reward decomposition, reference-policy divergence, and response-length distributions to the same evidence chain.

    Check your understanding: Can clip fraction be one while every sample still has a nonzero unclipped-side slope?

    Yes. Give each high-ratio action a negative advantage and each low-ratio action a positive advantage. Every move is on its harmful side, so each contribution retains its slope even though all ratios lie outside the clip interval.
