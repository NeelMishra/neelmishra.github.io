    Returns, Values, and GAE: Credit Assignment without Boundary Bugs

    September 2026 · 6 min read + experiments

    Compute advantages backward by hand, distinguish termination from truncation, and keep value targets separate from normalized actor weights.

    Read the explanationTry the calculation

    Give the actor a useful weight

    Chapter 2 ended with return minus the critic’s prediction. That works when an episode is complete. PPO often collects only a short segment, so we need an estimate before all the future rewards arrive. This chapter builds that estimate, called Generalized Advantage Estimation (GAE).

    Throughout this chapter, $t$ is a timestep, $R_t$ is the reward after its action, and $\gamma$ discounts future rewards. $V_{\mathrm{old}}(s_t)$ is the critic prediction saved during collection. “Old” means we keep that prediction fixed while preparing this batch.

    First measure one step of surprise

    Before an action, the critic predicts $V_{\mathrm{old}}(s_t)$. After it, we know the immediate reward and can predict what remains from the next state. Subtract the earlier prediction from this updated estimate. The difference is the TD residual, written $\delta_t$:

    $$\delta_t=\underbrace{R_t+\gamma V_{\mathrm{old}}(s_{t+1})}_{\text{reward plus predicted future}}-\underbrace{V_{\mathrm{old}}(s_t)}_{\text{earlier prediction}}.$$

    This formula assumes the episode continues. At a true terminal state, there is no remaining return, so the next-state value is zero. A positive residual means the one-step evidence was better than the critic expected.

    GAE combines this surprise with surprises observed later. The parameter $\lambda$, between 0 and 1, controls how much later evidence we include. Write $\hat A_t$ for the resulting advantage estimate:

    $$\hat A_t=\delta_t+\gamma\lambda\hat A_{t+1}.$$

    Compute it backward: the advantage at the next step is already available. With $\lambda=0$, use only the current residual. With $\lambda=1$ and a complete episode, the result is the full return minus the saved value prediction. Intermediate settings blend the two, trading dependence on the critic against dependence on a noisy future. This is the estimator developed in Schulman et al., GAE, Section 3.

    Compute backward once

    Use rewards $(1,2,3)$, saved values $(0.5,0.6,0.7)$, $\gamma=0.9$, and $\lambda=0.8$. The last action ends the episode. Start there: $\delta_2=3-0.7=2.3$, and there is no later advantage to add. At the preceding step, $\delta_1=2+0.9(0.7)-0.6=2.03$, so $\hat A_1=2.03+0.72(2.3)=3.686$.

    The three boxes show the actor’s weights. For the critic, add its saved prediction back to obtain a training target: $\hat V_t^{\mathrm{target}}=\hat A_t+V_{\mathrm{old}}(s_t)$. For example, the target at time 1 is $3.686+0.6=4.286$. The target teaches the critic how much return to predict; the advantage tells the actor which actions to encourage.

    At a boundary, ask two separate questions

    Here we are preparing the learning signals for both networks, before updating their parameters. The critic supplies $V_{\mathrm{old}}(s_{t+1})$, called next_value below. It enters the TD residual $\delta_t$, which GAE uses to compute $\hat A_t$. The actor uses $\hat A_t$ to weight the sampled action’s log probability; the critic uses $\hat A_t+V_{\mathrm{old}}(s_t)$ as its return target. So the boundary decision affects both updates.

    Bootstrapping means using a value prediction for the future we did not observe. A task ending has no future to predict. A collector stopping because its time budget expired may still leave future reward. Gymnasium’s time-limit guide explains this termination/truncation distinction.

    What happened?Use next-state value?Carry advantage across reset?
    Ordinary transitionYesNo reset; continue the recurrence
    Task truly endedNoNo
    External time limitYes, from the final observationNo

    In code, these two choices become separate Boolean masks. A value of 1 keeps a term; 0 removes it. Here next_value belongs to the observation before any reset, and next_advantage is the backward carry:

    bootstrap = 1 - terminated
carry = 1 - (terminated | truncated)
delta = reward + gamma * bootstrap * next_value - old_value
advantage = delta + gamma * lam * carry * next_advantage

    Initialize the carry to zero at the end of the stored segment. If the environment automatically resets, save the final observation before using the new episode’s first observation. A time limit that is part of the task itself counts as a true ending.

    Keep the critic’s target in reward units

    Some implementations standardize the actor’s advantage weights to keep their scale manageable. Do this after making the critic targets. Our lab standardizes once over the rollout:

    target = raw_advantage + old_value
actor_weight = (raw_advantage - raw_advantage.mean()) / (
    raw_advantage.std(unbiased=False) + 1e-8)

    Prepare both without gradients and keep them fixed during PPO’s optimizer passes. Standardization is a practical choice; the critic still predicts return in the original reward units. Chapter 5 places this preparation step in the training loop.
