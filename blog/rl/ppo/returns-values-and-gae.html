    Returns, Values, and GAE: Credit Assignment without Boundary Bugs

    September 2026 · 5 min read + experiments

    Compute advantages backward by hand, distinguish termination from truncation, and keep value targets separate from normalized actor weights.

    Read the explanationTry the calculation

    Three quantities that look similar in code

    A return is accumulated reward. A value prediction estimates expected return before the future is known. An advantage estimate compares an action’s outcome with that expectation. PPO needs advantages for its actor and return targets for its critic. Their arrays often have the same shape; that does not make them interchangeable.

    A completed Monte Carlo target is the observed discounted reward-to-go $G_t$. Subtracting the old critic prediction gives $G_t-V_{\mathrm{old}}(s_t)$. With an action-independent baseline and a complete trajectory, this is an unbiased action-value-minus-baseline sample. But a long, stochastic future can make it noisy. At the other extreme, one-step TD uses $R_t+\gamma V_{\mathrm{old}}(s_{t+1})-V_{\mathrm{old}}(s_t)$. It replaces most of the sampled future with a learned prediction, so critic error matters immediately.

    GAE is a discounted sum of residuals

    Write the one-step residual as $\delta_t=R_t+\gamma V_{\mathrm{old}}(s_{t+1})-V_{\mathrm{old}}(s_t)$ for a nonterminal transition. Generalized Advantage Estimation adds successive residuals with weights $(\gamma\lambda)^l$:

    $$\hat A_t^{\mathrm{GAE}}=\sum_{l=0}^{T-t-1}(\gamma\lambda)^l\delta_{t+l}=\delta_t+\gamma\lambda\hat A_{t+1}.$$

    The recurrence is a computation shortcut, not an additional approximation. At $\lambda=0$, you use only the immediate residual. At $\lambda=1$, the interior value terms telescope, leaving the sampled discounted return plus a final bootstrap minus the starting value. At a true terminal endpoint, that bootstrap is zero. At intermediate $\lambda$, the estimator blends horizons. The original GAE paper develops this tradeoff; smaller $\lambda$ generally relies more heavily on critic accuracy, rather than providing a universal promise of lower error. GAE paper.

    A complete three-step calculation

    Take rewards $(1,2,3)$, old values $(0.5,0.6,0.7)$, $\gamma=0.9$, and $\lambda=0.8$. The third action reaches a true terminal state. Then $\gamma\lambda=0.72$, and the calculation is:

    The target for the critic is $\hat V_t^{\mathrm{target}}=\hat A_t+V_{\mathrm{old}}(s_t)$. This is a bootstrapped lambda-return target, not necessarily the full Monte Carlo return. For example, the Monte Carlo return at time 0 is $1+0.9(2)+0.9^2(3)=5.23$. With $\lambda=1$, the advantage becomes $5.23-0.5=4.73$ and recovers that return target.

    Use one mask for bootstrapping and another for carrying

    A termination is an endpoint of the task: the goal was reached, the character died, or a task-defined finite horizon ended. A truncation is an external interruption of an otherwise continuing task, such as a collector time limit. You bootstrap at an external timeout because the underlying task still has future value. If the horizon is part of the task itself, it is terminal; include remaining time in the state when needed for a Markov description. Gymnasium’s time-limit explanation.

    $$b_t=1-\mathrm{terminated}_t,\qquad c_t=1-(\mathrm{terminated}_t\lor\mathrm{truncated}_t)$$
    $$\delta_t=R_t+\gamma b_tV(s_{t+1}^{\mathrm{final}})-V(s_t),\qquad \hat A_t=\delta_t+\gamma\lambda c_t\hat A_{t+1}$$

    At the end of the stored rollout segment, initialize the backward carry to zero. A nonterminal last transition still bootstraps from its successor’s value. If the segment contains a reset in its middle, $c_t=0$ prevents evidence from the new episode leaking backward into the old one. A single generic “done” mask used in both places silently throws away timeout value.

    Autoreset creates another trap: the observation returned to the next policy call may already be the new episode’s initial observation. Compute the timeout bootstrap from the old episode’s final observation instead. Vector-environment APIs expose this differently across autoreset modes; inspect the documented mode and information fields instead of assuming one universal key. Gymnasium vector API. Our lab explicitly saves the successor before resetting.

    Freeze first, normalize second

    raw_advantage, target = gae(reward, old_value, next_value,
                            terminated, truncated)
# target is raw_advantage + old_value, computed without gradients.
actor_weight = (raw_advantage - raw_advantage.mean()) / (
    raw_advantage.std(unbiased=False) + 1e-8)
# Keep target in reward units. Never construct it from actor_weight.

    Advantage normalization is a practical finite-batch rescaling and centering convention. It can change the signs of individual weights and therefore which side of clipping applies. It is not required by the definition of PPO. We normalize once over the rollout, preserving the same weights through all inner epochs. Some implementations normalize per minibatch; that is a different finite-sample choice and should be documented.

    The critic’s regression target stays in return units. If rewards are multiplied by ten, value targets normally grow by ten too. A normalized actor weight does not mean the critic should predict normalized returns. This separation becomes especially useful in diagnostics, where reward scale affects the balance between value loss and other terms.

    Check your understanding: A timeout occurs at t = 0, but the buffer contains t = 1 from the reset episode. What enters A₀?

    Only the old episode’s residual: $R_0+\gamma V(s_1^{\mathrm{final}})-V(s_0)$. The trace carry is zero. With this chapter’s numbers and a final value of 0.6, $A_0=1.04$, regardless of the next episode’s rewards.
