    Stateful LLM Transport & Context Compaction: Persistent WebSockets, generate: false Prewarming, Sticky Routing, and Five-Mode Compaction

    October 2026 · 4-Chapter Sub-Series · Reading Guide

    Even if your prompt builder preserves 100% prefix cache stability, a stateless HTTP/SSE client still pays a brutal tax on multi-step coding tasks: re-uploading megabytes of identical JSON history on every tool step, paying cold TLS + prefill latency on Turn 1, losing replica affinity across load balancers, and freezing the UI whenever the context window fills up. Across four chapters in websocket-client/, codex-api/, and core/src/, we trace how OpenAI Codex turns LLM transport and compaction into a stateful, zero-TTFT pipeline.

    $$B_{\text{SSE}}(S) = \sum_{s=1}^{S} |H_s| = \Theta(S^2) \quad\longrightarrow\quad B_{\text{WS}}(S) = |H_1| + \sum_{s=2}^{S} |\Delta H_s| = \Theta(S), \qquad \text{TTFT}_1^{\text{prewarmed}} \approx c_{\text{prefill}}\,|\Delta u_1|.$$
