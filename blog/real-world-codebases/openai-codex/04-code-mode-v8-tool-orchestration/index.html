    Code Mode: V8 Tool Orchestration, Ambient TypeScript Synthesis, Untruncated Heap Dataflow & Out-of-Process Hardening

    October 2026 · 5-Chapter Sub-Series · Reading Guide

    Classical JSON tool calling forces the LLM to act as a human router: if a task requires fetching 200 Jira tickets from an MCP server, filtering by assignee, joining against 50 GitHub PRs, and printing 3 matches, standard tool calling requires $N$ sequential LLM round-trips and dumps megabytes of raw intermediate JSON straight into the model’s context window. Across four crates (code-mode-protocol, code-mode-runtime, code-mode-host, and code-mode) plus custom patches in third_party/v8/, OpenAI Codex embeds an out-of-process V8 isolate where the model writes async JavaScript against synthesized TypeScript tool declarations—turning multi-step MCP dataflow into one local script execution.

    $$C_{\text{ctx}}^{\text{JSON-tools}} = \sum_{i=1}^{N} \min\!\bigl(|R_i|,\, B_{\text{trunc}}\bigr) \quad\longrightarrow\quad C_{\text{ctx}}^{\text{CodeMode}} = |S_{\text{JS}}| + \bigl|\text{emit}(R_1, \dots, R_N)\bigr| \ll \sum_{i=1}^{N} |R_i|.$$
