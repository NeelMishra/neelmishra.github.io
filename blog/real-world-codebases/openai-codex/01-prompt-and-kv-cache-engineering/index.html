    Prompt & KV-Cache Engineering: Append-Only WorldState Diffs, Incremental Tool Schemas, and Prompt Architecture

    October 2026 · 5-Chapter Sub-Series · Reading Guide

    Most agent harnesses accidentally bust their own LLM prefix cache every few steps—rewriting the system prompt when the working directory moves, adding or removing a tool when Plan Mode toggles, or formatting a live wall-clock timestamp at byte 200. Across five source-level chapters, we dissect how codex-rs enforces a strict append-only context invariant across ~18 typed WorldState sections, incremental UUIDv5 tool declarations, split permission hashes, Collaboration Mode templates, and security-gated AGENTS.md hierarchies.

    $$C_{\text{tokens}}(S) = \sum_{s=1}^{S} \Bigl[ p_{\text{cached}}\, L_{\text{prefix}}(s) + p_{\text{uncached}}\, \Delta L_{\text{tail}}(s) \Bigr] \;\ll\; \sum_{s=1}^{S} p_{\text{uncached}}\, \bigl(L_{\text{prefix}}(s) + \Delta L_{\text{tail}}(s)\bigr).$$
